# 基本設計の残件台帳：2026-10-19棚卸し

**状態：基本設計V1として60件すべて解消（2026-10-19、ユーザーの推奨選定委任に基づく）。** 結論は[HTML基本設計書](../Design/basic-design-v1.html)、[テキスト版](../Design/BASIC_DESIGN_V1.md)、[委任決定・照合記録](../Decisions/2026-10-19_BASIC_DESIGN_V1.md)を参照。以下の60は管理単位数であり、独立した例外の総数・詳細設計の作業量・実装完成率ではない。棚卸し時の問いを履歴として保持する。

目的は検討案を増やし続けることではなく、製品の範囲を固定し、その範囲の基本設計を閉じること。今回の棚卸しは既存の統合案・横断レビュー・実装結果・最新の選択記録を照合したもの。すべての過去資料の一文ずつの完全監査や、未発見の依存事項が存在しないことの証明ではない。

## 数え方と完了条件

- 1件は、関連する基本判断をまとめて採用・保留・対象外にできる単位。旧資料間の重複は同じIDへ集約する。
- 現時点：**採用待ち0／基本設計の完了60**。全件の採用方針・境界・正常／失敗例・受入条件は基本設計書の同じBD-IDに記録。予定受入170件は未実行で、詳細設計・史料採録・実装・性能・素材の完成とは別。
- 既存B優先案がある項目では、その案を出発点に未決定の境界を示す。選択済み方針を未選択に戻さない。
- 各件を閉じる条件：採用案、プレイヤー／NPCへの適用範囲、入力と認識可能な結果、関係する制度・例外境界、代表的な正常／失敗例、実装確認に必要な完成条件を記録する。
- ユーザーが対象外・後続版と決めた機能は、その範囲と既存制度への影響を明記してスコープ上閉じる。単なる未検討を完了扱いにしない。
- 計算係数、速度の最終値、クラスAPI、保存DTOのフィールド、描画最適化の細部等は詳細設計へ別記し、基本設計の終結を妨げる無制限な枝分かれにしない。ただしゲームの成立を左右する時間尺度・人数規模・権限・状態境界は先送りしない。
- 完了件数が変わったときは決定記録と対応させて更新。新たな必須依存は理由・出典・既存IDへ吸収できない理由を記録し、件数変更を明示する。

## すでに採用済みで、選び直さない事項

武将個人主体、身分・役職・権限の分離、共通世界時刻、個人認識と真実の分離、主／補助／委任行動、資源数量整合、帰属の段階更新、重複効果防止・復旧原則を維持。

[PW01〜07](PLAYER_PEACE_WAR_FLOW.md)の全Bは採用済み。特に自動進行＋任意停止＋重要時自動停止の**採否**は残件でない。BD-23/24/28はその具体的な運用境界を扱う。本隊の地点指定＋配下への作戦命令、任務逸脱表示、目的・制約・報告による委任も再選択しない。

同じ世界の連続ズーム、斜め見下ろしを基本とする回転・ズーム・一定範囲の傾斜変更、ゲーム内3Dと立ち絵イラストの方針を維持。BD-05/59は作成可能な人物や対応する立ち絵・会話表現の範囲を扱い、旧2Dスプライト制作に戻さない。現行の317件・3部隊試作は検証実績であり、全国や全制度の基本設計を閉じた証拠ではない。

## 進める順番

1. **製品範囲・主人公の人生（BD-01〜08）**：何を満たせば最初のゲームとして完成なのか、どの人生を遊べるのかを先に決める。
2. **立場・人物・地理・行動（BD-09〜24）**：人物・権限・距離・時間のつながりを固める。
3. **情報・任務・経済・軍事（BD-25〜40）**：平時→出陣→戦闘→帰還の一巡を閉じる。
4. **外交・帰属・在地社会・中央政治（BD-41〜56）**：制度の成立と変化、組織間の境界を固める。
5. **共通導線・NPC・受入（BD-57〜60）**：早期から並行して設計し、最後に全領域を通して抜けを確認する。

各回は4〜6件を目安に、推奨と意味のある代替案、既存採用との関係、正常・失敗例を提示する。最初の一巡はおよそ10〜15回の選択単位になるが、会話回数・所要日数・実装期間の保証ではない。まとめて選べる項目も、依存解決後に再確認する項目もある。

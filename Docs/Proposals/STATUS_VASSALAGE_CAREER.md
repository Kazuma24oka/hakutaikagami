# 未確定：武将の身分・主従関係・出世制度

状態：検討中。以下は選択前の比較案であり、確定仕様ではない。

## 確定構想との接続
武将個人を主体とし、浪人・家臣・城主・国人領主・独立大名としての活動を目指す。全国の国人衆まで扱う。これは既存のGAME_CONCEPT.mdに基づく。

## ① 身分・地位のモデル候補
- A：浪人→家臣→城主→大名の段階制。単純だが兼職・権限の分離に弱い。
- B（推奨）：身分・役職・所領・主従関係を別々に管理。城主でも所領所有者とは限らない状況などを表現できる。
- C：社会的地位を数値化して権限を自動決定。例外的な史実関係に弱い可能性。

## ② 仕官・主従関係の候補
- A：単一勢力所属、大名直属のみ。
- B（推奨）：大名直属、家臣の家臣、与力、従属国人などを区別する。
- C：複数主君・契約関係を詳細に再現する。複雑さと処理負荷が増える。

## ③ 出世・独立の候補
- A：勲功の蓄積で自動昇進。
- B（推奨）：勲功・能力・人脈・主君判断・政治情勢を考慮。独立には所領・軍事力・支持者等も関与。
- C：プレイヤーが自由に昇進・独立を選択。歴史的な関係性との整合が課題。

## 未決定事項
1. 身分と役職の正式な区分、兼任と世襲、浪人・国人の位置づけ。
2. 直属・陪臣・与力・従属勢力の権限、命令系統、移籍・離反時の処理。
3. 勲功、俸禄、知行、任命、昇進、独立の判定とAIの判断。
4. 主従関係が情報共有・書状代理権限に与える影響。
5. 史実・準史実・仮想モードでの出世・独立の制約。

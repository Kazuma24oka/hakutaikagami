# P0共通基盤・第2群：領地帰属／資源会計／組織決議 ABC比較

**状態：未確定（Proposals）／2026-10-17。** 第2群のP0-04、P0-05、P0-06のABC比較。**A/B/Cはいずれも未選択**。Bは既存の優先検討案に整合する推奨候補であり、正式確定ではない。既存の[第1群B選択](P0_FOUNDATION_PHASE1_OPTIONS.md)を前提とするが、具体的な状態遷移や判定式は確定しない。

## ① P0-04 家督・安堵・離反・落城と領地帰属

- **A：一括変更** — 家督相続・独立宣言・落城が成立すると、城・所領・家臣・軍勢・役職をまとめて新勢力に移転する。
- **B（推奨）：段階的な帰属更新** — 家督の継承、所領の権利主張・安堵、城主職、城内占有、実効支配、家臣の所属、守備兵・軍勢の忠誠を個別の状態として保持し、出来事・権限・現地の支持・認識情報に応じて段階的に変更する。
- **C：実効支配のみ** — 正式権利・安堵・主従・役職を扱わず、現在占有する勢力に全てを帰属させる。
- **未決定**：複数相続人・二重安堵の優先関係、暫定所領管理の制限、城主と守備兵の対立、落城と援軍到着が同時刻の場合、条約・俸禄債務の承継、不可逆な結果の境界。
- **整合性**：F01・F03、[武将制度](CHARACTER_SOCIAL_SYSTEM_CONSOLIDATED.md)、[全国マップ](WORLD_MAP_CASTLE_LAND_CONSOLIDATED.md)、[合戦](BATTLE_MILITARY_TACTICS_CONSOLIDATED.md)、[外交](DIPLOMACY_SYSTEM_CONSOLIDATED.md)。権利の発生と情報到達を分離する第1群とも整合。

## ② P0-05 資源・在庫・取引・債務の共通会計

- **A：勢力別一括資源** — 兵糧・銭・収益を勢力全体の共有残高として管理し、保管場所・所有者・輸送中の在庫は区別しない。
- **B（推奨）：所在・権利・取引履歴の分離** — 資源の種類・数量・所有者・保管場所・処分権・引当・輸送中在庫・徴税請求・実徴収・配分・支払・消費・損失・未払債務を区別し、取引履歴を基に二重計上を防ぐ。
- **C：個人単位の全面会計** — 農民・兵士・商人を含む全個人の現物・取引・債務を逐次記録する。
- **未決定**：取引ID・会計粒度、在庫引当と輸送中の所有権、同時刻の入出庫・複数徴税、現物／銭の換算、略奪・徴発・返還、主家交代時の債務承継。
- **整合性**：F03、[内政・経済・兵站](DOMESTIC_ECONOMY_LOGISTICS_CONSOLIDATED.md)、[武将制度](CHARACTER_SOCIAL_SYSTEM_CONSOLIDATED.md)、[全国マップ](WORLD_MAP_CASTLE_LAND_CONSOLIDATED.md)、[合戦](BATTLE_MILITARY_TACTICS_CONSOLIDATED.md)。権利があることと現物を受領したことは別であり、資源の二重生成を認めない。

## ③ P0-06 組織決議・代理行為・通知・責任

- **A：決議即時共有** — 組織の決議成立と同時に全構成員が内容を認識し、自動的に服従・実行する。
- **B（推奨）：決議・通知・認識・実行の分離** — 組織の意思決定方式、決議成立・効力発生、代表者・代理人の権限、通知の発送・到達、個人の認識、賛否・不服従・実行、責任・処罰を別状態として扱う。責任は通知義務・故意／過失・立場・実害・監督責任等で個別判断する。
- **C：個人判断のみ** — 組織決議に拘束力を持たせず、全ての構成員が組織と無関係に判断する。
- **未決定**：代表者・合議の議決要件、拘束力の範囲、反対派・不服従、代理受領後の報告義務、通知されなかった者の責任、複数組織所属・再委任、決議と通知が同時刻の場合。
- **整合性**：F01・F05・F07・F08、[在地社会](LOCAL_SOCIAL_SYSTEM_CONSOLIDATED.md)、[確定情報システム](../Confirmed/INFORMATION_SYSTEM.md)、[P0共通基盤](P0_FOUNDATION_CONSOLIDATED.md)。国人の自治・従属、寺社・村落の合議、組織の保有情報と個人の認識の分離を維持。

## 重複・矛盾レビュー

1. **帰属と安堵**：家督の継承・城の占有・所領権利は同義でない。B案は既存の段階更新方針と整合するが、遷移順序は未決定。
2. **係争地の徴税と会計**：複数の徴税請求を認めても、同じ現物の二重生成・二重消費は認めない。実際の徴収順序・権利調整は未決定。
3. **決議と構成員の認識**：決議の効力、代理人の適法な受領、本人への通知、本人の認識、実際の服従を分離する。未認識者への責任は自動免責でも自動処罰でもない。
4. **時刻の境界**：落城／援軍、徴税／入出庫、決議／通知などの同時刻競合は、第1群の共通イベント処理へ接続する。単純な登録順を採用したとは扱わない。
5. **比較案の制約**：①A/C・②A・③A/Cは確定済みのF01・F03・F05・F07等と衝突する部分がある。採用には別途確定仕様の変更承認が必要。②Cは過度に細かい実装案であり、原則の分離そのものとは必ずしも矛盾しない。

**判定**：第2群B案と既存Confirmedの基本原則に直接矛盾は見当たらない。データモデル・時刻境界・債務承継・決議拘束力は未決定のまま保持する。

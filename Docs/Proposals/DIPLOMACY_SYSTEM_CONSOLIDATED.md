# 外交・同盟・婚姻・人質：統合設計案

> 後続決定（2026-10-19）：[基本設計V1](../Design/BASIC_DESIGN_V1.md)／[委任採用・整合確認](../Decisions/2026-10-19_BASIC_DESIGN_V1.md)で対応する基本判断BD-01〜60と共通境界C01〜10を解消。以下の旧未確定表記は当時の履歴で、現行の方針はV1を優先する。詳細係数・API・個別データ・実装受入は別に引き継ぐ。既存Confirmed原則は維持。


**状態：未確定（Proposals）／2026-10-17。** 基本8項目、詳細5項目、例外6項目のユーザー選択済みB案を統合した優先参照先。Bは優先検討方針であり、Confirmedへの昇格ではない。

## 1. 外交の主体と権限
- 大名・国人領主・家臣・使者などは、役職・委任・自治権に応じて外交に関与できる案。
- **交渉権／締結・批准権／代理回答権／履行指示権**を分離する。越権締結は原則無効としつつ、相手の認識、紛争、事後追認の余地を残す。
- 条約当事者（個人・家・組織等）、締結の効力発生、管轄・再委任・第三者保護は未決定。

## 2. 外交関係と条約の段階
- 同盟・不可侵・停戦・従属・軍事援助・通行許可などを区別し、複数条項・関係の併存を検討する。
- **提案→使者／書状による伝達→交渉→権限者の承認→返答→効力発生→履行／不履行**を別段階として扱う。必要な段階は案件ごとに異なる。
- 期限起点、返答の有効基準、代理受領・開封、紛失・偽書・機密は確定済み情報仕様に従う。
- 条約の正式成立と、通知の到達、当事者の認識、履行・実際の政治効果を混同しない。

## 3. 同盟義務・違反・破棄
- 軍事援助・兵糧・通行・仲裁等の義務は条項別に扱う。援軍要請の到達・承諾・出陣・到着を区別し、条約成立で自動参戦させない。
- 履行／遅延／履行不能／違反を、条項・期限・情報到達・能力・不可抗力・故意等に応じて区別する案。
- 破棄・違反は信用・名分・家臣・周辺勢力の評価・軍事情勢に影響し得る。客観的な違反と、周囲が裏切りと認識することは別。
- 補償・制裁・仲裁、履行不能の免責、破棄の効力発生、秘密条項の開示は未決定。

## 4. 婚姻・養子縁組
- 婚姻・縁組を個人・家の関係として扱い、親族・家督・相続・同盟・人脈・信用に影響し得るが、勢力・所領を自動統合しない。
- 当事者の意思、家の合意・権限、身分、時代の慣行、政治事情を考慮する案。
- 本人と家の意思が対立した場合、説得・延期・再交渉・拒否・対立などへ分岐し得る。婚約／正式成立／養子縁組／相続・安堵を分離。
- 婚姻の具体的成立条件、拒否の帰結、離縁・死別・再婚・子の扱いは未決定。

## 5. 人質と外交保証
- 人質は実在する人物であり、所在・預け先・身分・待遇・保護・返還義務・保証を分離して扱う案。人質がいるだけで忠誠・服従・履行を自動保証しない。
- 返還拒否・遅延は、約定・期限・安全・所在・外交情勢に応じて催促・仲裁・交換・継続交渉・対立へ分岐する。
- 返還義務と実際の返還、本人の安全と外交上の制裁を区別する。暴力的な処遇は自動的に発生させない。
- 選定・移動・交換・護送・逃亡・死亡・返還拒否の責任は未決定。

## 6. 継承・離反・独立と条約
- 家督交代・独立・離反・死亡・離縁・同盟破棄等では、条約当事者・義務・保証・相手方との合意を踏まえ、継続・再交渉・失効・係争を個別判断する。
- 家督継承だけで全条約・保証・人質返還義務・違約債務を自動承継／消滅させない。婚姻関係と外交上の義務も分離する。
- 承継条件、相手方の同意、複数後継者、秘密条項、承継の効力発生は未決定。

## 7. NPC外交判断と情報不一致
- NPCは利害・血縁・忠誠・野心・信用・軍事力・政治情勢と、実際に認識した報告・噂・目撃等に基づいて外交判断する。
- 実際の条約状態、発送・到達、本人の認識、密約・偽書・誤報を分離する。全勢力に情報が即時公開されることはない。
- 情報を知らないNPCは真実を直接参照しないが、既知情報からの推測は可能。詳細評価式と史実モード差は未決定。

## 8. 重複・矛盾・表現差の整理
| 論点 | 統合した解釈 | 判定 |
|---|---|---|
| 交渉権と締結権 | 交渉と正式な承認・締結は別権限 | 整合 |
| 返答の有効性と条約成立 | 期限遵守・返答効力・合意成立・本人認識を分離 | 整合、成立条件未定 |
| 国人の自治と従属 | 従属しても外交権限が全面消滅するとは限らない | 整合、範囲未定 |
| 同盟と自動参戦 | 義務・援軍要請・承諾・出陣・到着を区別 | 整合 |
| 婚姻と勢力統合 | 親族・政治的関係と所領・実効支配は別 | 整合 |
| 人質と忠誠 | 人質の所在・保証と相手の忠誠・行動は別 | 整合 |
| 条約承継と家督継承 | 条約の当事者・義務・保証を個別判断 | 整合、承継条件未定 |
| 越権締結と追認 | 原則無効、相手方の認識・追認・紛争を別処理 | 整合、追認効果未定 |
| 違反と履行不能 | 条項・期限・情報到達・能力・故意等で区別 | 整合、立証未定 |
| 破棄の事実と周囲の認識 | 条約状態と通知・噂・偽書を分離 | 整合、効力時点未定 |

**結論**：選択済みB案と確定基本原則に直接的な矛盾は見当たらない。条約成立・承継・越権追認・婚姻成立・人質返還・違反立証の未決定を「解決済み」とは扱わない。

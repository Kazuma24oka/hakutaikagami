# 旧家の再興と支援の実行

2026-11-05。所領を失った家の旧臣・遺児が、自分の知る情勢から再興を目指し、支援を集めて動く一巡を具体化する。志があっても挙兵を強制せず、待つ・目標を縮める・撤退する判断を残す。統合案§26 Z4と§20 W5をつなぐ既存例に、同日のA案採用による吸収・解散後の同じ家としての再興と、残る権利・約束への対応を加える。

## 2 再興で自動的には戻らないもの

| 対象 | 扱い | 既存の管理先 |
|---|---|---|
| 旧家と候補者 | 家の記録、血縁・養子、家督の主張、支持、代表権を別にする。遺児や旧臣というだけで全員の代表にしない | G-S2、BD-45、[家督と個別引継ぎ](MORI_MOTONARI_SUCCESSION_TRANSFERS.md) |
| 志と好機 | 再興の志は目標選択の重み。旧領の混乱を観測・書状・噂で知った本人が、情報の古さや危険を考えて動く | G-K4、統合案W5・Z4、BD-58 |
| 旧臣と国人 | 現在の主従・職務・義務を保持し、追随・残留・留保を個々に判断する。旧所属から兵を一括生成・移籍しない | BD-46・50、[従属先変更](MORI_MOTONARI_ALLEGIANCE_CHANGES.md) |
| 後援と軍事行動 | 支援の申し出、権限ある合意、実際の兵・米の到着、指揮委任は別。後援者の支援条件も双方の利害になる | BD-41・42、[連合の出陣と精算](MORI_MOTONARI_COALITION_OPERATIONS.md) |
| 旧領と拠点 | 旧来の権利主張、新たな安堵、現地の服従、門や本丸の実占有を分ける。再興宣言だけで旧領を取り戻さない | BD-45〜48、統合案J6 |
| 契約と財産 | 旧原本、当事者、期間・承継条件、債務・保証・第三者の所有を個別に照合する。失効した契約を名前の復活だけで戻さない | BD-48、共通契約CC-03・14 |

「家の再興」という一つの成功フラグで、所属・家督・所領・軍・条約をまとめて書き換えない。正当な代表が結べる範囲と、各人が実際に従うかも別である。複数の候補が争えば既存BD-45の係争を残し、最初に挙兵した者や最も多く支援された者を自動的な正当当主にはしない。

当初の例は、X家が所領と活動拠点を失っているが、家の記録と原本が存続する開始状態である。今回のA案により、吸収・解散済みの家についても、正当な継承を経た同じ家としての再興を扱う。検証開始時には、家の活動履歴、Aの承継根拠・代表権、各原本の残存権利・義務と終了・移転の記録、各人が知る内容を明示する。

同じ家としての継続を、全旧臣の承認や将軍の認定を要する新しい一律制度にしない。BD-45と統合案S1〜S5に従い、争いがあれば係争と有効な暫定権限を保つ。BD-48の継続・承継同意待ち・係争を維持し、旧家の権利だけを取得して残る負担を捨てない。適法に移転・引受け・清算済みの対象や、終了した家法を復活させず、政治的な継続を技術的なIDの再利用へ読み替えない。

## 3 最低限遊べる一巡

X家は活動拠点を失い、成人候補Aと旧臣Bは別の場所にいる。Bは旧領の支配が揺らいだとの知らせを受けるが、旧臣の一部は他家へ仕え、後援候補Y家も自家の戦いを抱えている。誰に連絡し、どこまで支援条件を受け入れ、何を確保してから動くかを選ぶ。

吸収・解散後から始める分岐では、X家の一つの権利と未払い給付が有効に残り、旧城の一つは他家へ適法に移転済みという架空の開始条件を使う。継承の根拠と権限を照合したうえで、同じ支援・実行の一巡へつなぐ。旧城が戻らなくても、同じ家としての再興と残る約束への対応は両立し、旧版の保存をこの開始条件へ書き換えない。

| 段階 | 人物がすること | 実際に進むこと・残る条件 |
|---|---|---|
| 1 情勢を確かめる | Bが知らせの出典・観測時刻を確かめ、既知の相手への照会や調査を手配する | 遠方の真実を全員へ通知しない。返報を待つ間にも現地は動き、動く・待つ判断は本人の知識に限る |
| 2 支持を募る | AとBが面会・使者・書状で目的と条件を伝え、旧臣・国人・Y家へ働きかける | 個人としての相談、家を代表する合意、各人の支持を分離。支持表明だけで現在の主従や軍役を解除しない |
| 3 足場を整える | 権限内で支援条件をまとめ、集合先、補給、指揮範囲と帰還条件を確認する | 約束した兵と到着した兵、出庫した米と実受領した米を区別。支援側の資源・任務との競合も既存規則で扱う |
| 4 実際に進出する | 知っている敵情と実在する戦力から、交渉・出陣・目標縮小・延期を選ぶ | 既存の宣言、命令、移動、合戦、開城の案件を使う。名目だけで正当な処分権や全旧領の占有を得ない |
| 5 確保した範囲を保つ | 一拠点を得たら守備・会計・給付を手配し、国人や村と現地の条件を確かめる | 占有・権利・支持と実際の収入は別。失われた人口・米・建物を復元せず、未回復の領地や反対する旧臣を残す |
| 6 結果から判断し直す | 届いた報告と残量から、維持、追加支援の交渉、次の進出、撤退を選ぶ | 部分回復・撤退後も実消費・損害・約束済みの給付や返還義務を保持。撤退だけで志を消さず、志だけで再出兵させない |

各段を全案件に同じ直列順で強制しない。独立した照会や準備は並行できるが、一括条件の支援案を一部の賛成だけで分割成立させない。複数部隊の一計画は共通契約CC-09の全件検査を通して発送し、発送後の個別到達・拒否と混同しない。

早く動けば好機を逃しにくいが、集まる兵と米が足りないかもしれない。支援を待てば備えられる一方、現地の支配が持ち直すこともある。Y家の条件を受ければ助けを得られる可能性があるが、軍役や外交の制限が再興後にも残り得る。こうした判断を、再興専用の万能ポイントではなく、既存の条約・実物・人間関係で表す。

### 再興後に届く請求と実際の履行

再興したX家へ、旧来の未払い給付や預かり物の返還請求が届いた場合を、同じ一巡の続きとして扱う。請求の到着はAがその内容を知る機会であり、それ自体で新しい債務が成立するわけではない。

1. Aまたは権限内の担当者が、受領した請求と閲覧できる原本を照合する。家の義務、元当主の個人債務・保証、未成立の案を分ける。
2. 過去の支払い・引受け・移転・清算を確かめ、有効に残る分を保持する。履行不能や異議は既存規則で扱い、未確認というだけで消滅させず、同じ請求の再送でも残高を増やさない。
3. 既存条件のまま履行できる部分は手配し、承継への同意や条件改定が必要な部分だけ相手と連絡・交渉する。新しい案を送っただけで元の義務や期日を変更しない。
4. 既存の引当・優先順位と合意条件に従い、使用できる家の資金・物資から実際に支払い・運搬・受渡しを行う。後援者の資金や第三者の預かり物を家の自由な財産にしない。
5. 実際の履行と返報の受領を別々に記録し、残額・未返還分と関係の履歴から次の対応を選ぶ。納入済みでも返報が遅れる場合があり、古い請求書だけで二重払いを確定しない。

原本の残高と本人の知識は一致しないことがある。NPCも既知の請求・支払い・資源から履行、照会、条件交渉を判断し、再興したという理由だけで支払資金や完全な帳簿を与えない。

## 4 記録と本人への表示

目的、候補・代表権の根拠、連絡先、支援の原本と版、任務・指揮委任、兵と物資の所在、拠点の実占有、未履行の約束を既存の記録へ結び付ける。旧家の文書庫を確保しても、閲覧前から全記録を本人の知識にしない。過去に家へ属していたというだけで、現在の旧臣の所在・忠誠・秘密交渉を知ることもない。

画面では、本人が知る「Aへの使者は返報待ち」「旧臣Cは支持を表明」「Y家の米は受取未確認」「旧城の門の引渡しは交渉中」等を示す。世界の真実にある到着時刻や未開封の拒否理由を表示しない。支援の再送・報告の再提出で兵、米、功績、債務を増やさず、過去の消費を取り消さない。

NPCも同じ情報・権限・資源で判断する。新情報、命令、危険、期限、資源変化を再判断の契機にし、同等なら計画を維持するBD-58を使う。画面外の再興だけに兵や成功を与えず、史実の志を持つ人物でも挙兵しない未来を許す。

## 5 実装時の確認条件

以下は既存の対応工程へ割り当てる確認例で、固定の受入170件へ追加したものではなく、未実施。

1. 情勢を知るところから、支持・後援交渉、実集合・補給、部分回復または撤退、残る約束への対応まで、本人とNPCの双方で一巡する。
2. 家督の主張、代表権、個人の支持、権利・実占有を分け、宣言や後援だけで全旧臣・全旧領・全契約を復活させない。
3. 実兵・実物と既存の権限・義務を使い、部分回復・中止・撤退後にも消費・損害・返還・給付を保持する。
4. 使者配送中・集合待ち・部分回復後からの保存再開で、同じ知識、原本、兵、物資、権限期間と将来の判断を再現する。旧保存を新しい再興規則へ無断で読み替えない。
5. 吸収・解散後の同一家再興でも、継承・代表権・個々の支持と、残存権利・未払い・承継同意待ち・適法な移転や清算を分ける。再興後の請求照合から実履行・返報まで進み、権利だけの復帰や義務の二重計上を起こさない。

代表例外は二つに絞る。

- **好機の情報が古い**：旧領の混乱を伝える書状が遅れて届く。現地の回復を知らないBが動くことはあり得るが、世界の真実を事前警告として漏らさない。追加報告や現地接触を受けて延期・交渉・撤退を判断できる。
- **後援の一部が未到着**：支援は成立しているが、兵糧の実納入や一隊の集合が遅れる。到着済みの範囲で可能な行動を検討し、一括条件・命令権限・既存義務を保つ。返報不達と実未納を区別し、不達だけで支援者の裏切りを確定しない。

# 客将の招請から帰還・精算まで

2026-11-05。採用済みの客将招請を、元の家への奉公を残したまま他家で期限付きの任務を担い、帰還して残る約束を履行する一巡へつなぐ。新制度の採用、実装順の変更、実装済みの認定ではない。

## 1 出典と今回の範囲

根拠は[統合案](GETENROKU_INTEGRATION_V1.md)§26 Z6・§15 D4、[バックログ](../References/GETENROKU_BACKLOG.md)G-K6・G-D4、基本設計BD-09・30・48・50と[共通契約](../Design/CommonContractV1/common-contract-v1.json)。毛利元就の動画で確認した具体的場面・発言・時刻を根拠とする資料ではない。史実人物の奉公条件は推測しない。

対象はZ6の「主家が従属家の武将を招く」形とする。以下の甲家・乙家・成人の武将Aは架空で、甲が乙の主家かつ受入先、乙がAの元所属家である。一般の養子・転属・人質や、従属関係のない相手との奉公契約へ自動拡張しない。参考作品の人数制限を新たな全国共通の枠として追加せず、今回は一人の一巡を扱う。

## 2 既存仕様で分けるもの

| 論点 | 管理先 | 変えない境界 |
|---|---|---|
| 招請と受諾 | Z6、D4、BD-09・41 | 受入家の申し入れ、従属家当主の判断、本人の判断、同じ条件への合意・到達・効力を分ける |
| 所属と指揮 | BD-09・11・12・50、CC-03・06 | 元所属と直属主君を保持し、一時的な作戦指揮・任務権限だけを個別に扱う |
| 任務と既存の仕事 | BD-21・22・29〜31 | 目的、所在、期限、費用、裁量と報告を照合し、別地点の仕事を同時に完了させない |
| 兵・米・費用 | BD-12・34〜36・48、CC-14 | 指揮と所有、引当と実受領、消費と支払義務を分ける。預かった兵や米を私有化しない |
| 終了・延長・帰還 | BD-09・31・42・48 | 契約や委任の効力、実際の撤収・帰着、通知と認識、未払い・返還義務は別に残る |

客将になっても乙家の役職・軍役・債務・他の約束が一括で消えるわけではない。甲家の養子・直臣・人質にもならず、家族、乙家の全軍、所領、財産を甲家へ移さない。受入先との親しさや実績が増えても、正式な所属変更や相続資格の取得には別の根拠が必要となる。

## 3 招請条件から実行へ

### 誰が何に合意するか

- 甲家の権限ある者が招請し、乙家当主とAがそれぞれ応諾・留保・拒否を判断する。当主の承諾をAの意思に置き換えず、Aの希望を乙家の代表権にも置き換えない。私的な相談と正式な申し入れも分ける。
- 家が負う条項と本人の受諾を関連づけ、任務・期間・帰還条件などの同じ版について必要な承諾を確かめる。BD-41の適法な到達と発効条件を使い、条件の異なる返答や未着の承諾を寄せ集めて成立させない。
- 新しい招請・改定案を拒否しただけで、その未成立案への不履行にしない。拒否した事実と、事情を知った相手の評価を残す。一方、既存の有効な条項・任務への抵触は別に照合し、成立後のすべての軍令へ新しい任意契約の承諾待ちを強制しない。
- 客将条項の成立だけで、甲家が乙家の人事・全軍・私財を自由に扱えるようにしない。合意する権限、任務を命じる権限、Aが預かった部隊へ指示する権限はそれぞれ確認する。

### 個別に明らかにする条件

| 条件 | 原本で確かめること |
|---|---|
| 任務と勤務地 | 何を達成するか、どこで働くか、報告先・報告条件、許可行為・禁止行為・費用上限 |
| 期間 | 赴任期限、任務・指揮権の開始と終了、途中終了の条件、延長に必要な手続。日付と到着などの出来事のどちらを起点にするか |
| 預かる兵と指揮 | 実在する対象部隊、指揮できる範囲、上位の作戦命令、再委任の可否、指揮を返す相手と条件 |
| 費用と物資 | 旅費・滞在費・兵糧・帰路の費用について、誰が何を負担するか、財源、支給時期、所有・貸与・返納の区別 |
| 帰還と残件 | 任務終了と帰還期限の区別、帰還先、引継ぎ・返納・報告、途中の通行や安全、未払い・紛争の扱い |

条件は既存の条約・委任・任務・実物の記録に結び付ける。必ず同じ期間や負担率にする新制度は作らない。軍役の人数へAや預けた兵をどう算入するかも当該条項で照合し、客将を出しただけで乙家の他の軍役を免除したり、同じ兵を二重計上したりしない。

### 元の仕事、延長、召還

- 出発前にAの既存任務と本人拘束、乙家の有効な義務を確かめる。引継ぎや延期が必要なら権限者が手配し、成立した客将条項だけで旧任務を取消済みにしない。移動中の短い指示などBD-21で許される補助行動は保ち、本人拘束の主行動と別地点での実務を重ねない。
- 甲の作戦命令と乙からの帰還指示などが競合したら、BD-11で対象・期間・委任・効力・明示差替えを照合する。「主家の当主だから」「元の主君だから」「最後に届いたから」だけで決着させず、未解決なら可能な現状維持と照会へ進む。
- 延長の申し入れ、必要な同意、変更の効力、本人や現地部隊への通知を分ける。改定案の発送や返答待ちだけで旧期限を延長せず、受入側の希望を包括的な延長権にしない。既存原本に変更権があれば、その対象・条件・限度を確認する。
- 元の主君による無条件・即時の召還権は新設しない。帰還を求める意思、既存条項に基づく召還・解除の権限、変更命令の到達と認識、実際の撤収を分ける。既存の解除予告や通知義務を消さず、客将任務の終了を両家の従属関係全体の終了にも置き換えない。
- 指揮期間が終わっても未帰還だからという理由で権限を延長せず、通知を知らないことから終了済みの権限を復活させない。直接危険への対応は既存の自衛と権限範囲を照合し、新規攻勢や他隊の動員まで自動許可しない。無権限でも物理的に行ったことは、正当権限と責任を分けて残す。
- 未精算や帰還条件の争いだけで、受入側がAを人質として拘束する権利を得るわけではない。拘束などが起きるなら別の行為・根拠・責任として扱う。本人の独断出奔も物理的可能性と義務違反を別に審査し、免責や全兵の追随を保証しない。

## 4 最低限遊べる一巡

甲家は補給路の警固を担える将を求め、乙家の成人Aを招く。Aには乙家での担当がある。本例では、引継ぎを調整した後にAが赴任し、合意した終了日まで甲家の指定一隊を率いる。甲家が合意した旅費・滞在費・兵糧・帰路の費用を負担し、Aは終了時に指揮を返して乙へ帰る条件とする。これは架空の個別条件であり、受入家の一律全額負担や恒久的な役職取得の規則ではない。

| 段階 | 人物がすること | 世界に残る状態と判断 |
|---|---|---|
| 1 招請を交わす | 甲が既知の評判や実績からAを求め、乙当主とAが任務・期間・待遇・帰還条件を検討する | 条件付き返答、留保・拒否、各人の認識を保持。家の合意と本人の判断を別にする |
| 2 条件と引継ぎを整える | 必要な権限と同じ条件への合意を確かめ、乙での担当の引継ぎ、行先、費用・補給を手配する | 合意・発効・旧任務の変更・現物の引当は別。旧担当の完了部分と消費を残す |
| 3 実際に赴任する | Aが移動し、現地で受入れと指揮委任・物資を確認する | 赴任承諾を到着にしない。人物・部隊・米の所在、実受領、元の家への返報は個別に進む |
| 4 預かった隊で働く | Aが自分の知る敵情と補給から警固を行い、裁量外の変更は照会する | 実在する兵と米を使い、限定された指揮を行使。成果・損耗・逸脱・報告を区別する |
| 5 終了して帰る | 条件に従い引継ぎ・指揮返還・残物の返納を進め、Aが帰路を移動して乙へ帰着する | 権限の終了、隊の実引継ぎ、返納、帰着、双方への報告は別。未帰着の人や物を瞬間移動させない |
| 6 費用と功績を確かめる | 当事者が支出・請求・実受領を照合し、未払い・異議を残しながら支給や追加報告を進める | 既存義務の精算と裁量的な恩賞を分離。支払の決定だけで実給付済みにせず、帰還だけで債務を消さない |

甲は必要な将を得られるが、補給と待遇、帰還期日の負担を負う。乙は主家との関係やAの経験を期待できる一方、自家の仕事を誰に任せるかが問題になる。Aは機会と危険、元の主君への義務を量る。延長して成果を求めるか、合意した期限で戻るかも、各人の利害と届いた情報で変わる。

複数部隊への一計画はCC-09の全件検査後に発送し、無権限の部隊だけを除いて勝手に部分発送しない。実消費・損耗と未使用物を分け、余った米の返納、消費済み分の弁済、損失補償はそれぞれ有効な義務に従う。勝利や帰還から一律の損害補償・借金免除・連帯債務を作らず、既存の支払義務も消さない。

## 5 記録・表示と確認条件

元所属・直属主君、客将条項の原本と版、本人の受諾、任務・指揮の対象と期間、配送、本人・部隊・物資の所在、給付・未払・返納、各人が知った時点を既存の記録で結ぶ。一つの「派遣中／帰還済み」だけで全領域を書き換えない。赴任先の文書庫や他家の秘密を、客将という名称だけで全公開しない。

本人向けには「赴任の返報待ち」「延長は乙家の回答待ち」「帰着は確認したが費用は未受領」など、知っている範囲を表示する。到着・帰還の事実と報告の未着、義務の不履行と本人の認識・故意・免責を分ける。再送で人・兵・給付・請求を二重作成せず、期間終了や取消で過去の適法な行動と消費を巻き戻さない。

以下は既存の対応工程へ割り当てる確認例で、固定の受入170件へ新規追加したものではなく、未実施。

1. 招請、各当事者の判断、同条件への合意、実赴任、限定指揮、実帰還、精算まで、本人とNPCが同じ知識・権限・実物で一巡する。
2. 所属・直属主君と一時指揮が併存し、既存任務・軍役を二重履行しない。拒否・留保・未着を成立扱いせず、養子・転属・人質へ自動変換しない。
3. 元の主君と受入側の競合指示、延長・途中終了を既存の権限・版・効力条件で扱う。肩書による一律優先、無条件召還、発送だけの期限延長を起こさない。
4. 預かった兵・米、実消費、返納、未払、第三者財産を個別に保持する。実帰還と支払・報告の完了が違っていても続行できる。
5. 交渉中・赴任途中・延長回答待ち・帰還途中・精算待ちから保存再開し、原本、権限期間、各人の認識と数量を維持する。旧保存へ新規則を無断適用しない。

代表例外は二つに絞る。

- **延長への回答と帰還指示が行き違う**：甲が延長を申し入れる一方、乙から旧条件に基づく帰還の書状が届く。必要な合意と変更の効力が未成立なら旧期間を伸ばさず、成立していても本人の未認識を分ける。各指示の根拠を照合し、照会・再送・範囲内の安全維持から続ける。
- **実際の到着・帰還と返報がずれる**：甲にはAが到着したが乙への返報は未着、または乙へ帰着したが甲への返報が未着となる。各地点の実所在は保持し、知らない側は確認待ちとする。不達だけで逃亡・未帰還を確定せず、再送で再移動・二重給付を起こさない。

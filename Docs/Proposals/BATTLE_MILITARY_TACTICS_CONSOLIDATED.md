# 合戦・軍制・戦術：統合設計案

**状態：未確定（Proposals）／2026-10-17。** 基本12項目と詳細D01〜D05のユーザー選択済みB案を統合した優先参照先。比較案の採用は正式確定を意味しない。具体的な数値・実装方式・例外は未決定。

## 1. 軍勢・指揮権・動員
- 軍勢・部隊・指揮官・所属・直属主君・軍事指揮権・実際の忠誠を分離する。大名・城主・国人領主・家臣は権限に応じて指揮できる案。
- 命令の有効性、優先度、到達、実際の服従を区別。競合は権限・任務・緊急性・状況で判断する。越権・密命・指揮官交代の責任は未決定。
- 軍役・徴発・常備兵・在地動員を区別し、兵種・装備・練度、農業労働力への影響を扱う。部隊粒度・兵農関係・動員条件は未決定。

## 2. 開戦と野戦
- 遭遇・威嚇・交渉・撤退・追撃・開戦を状況に応じて選択する。接触・命令到達・参戦意思・開戦を同一視しない。
- 陣形・配置・機動・射撃・近接・予備隊・地形・天候・士気・疲労・指揮官能力を戦況へ反映する。
- 士気・疲労・統制・信頼・損害・補給によって命令遂行・潰走・撤退・再集結が変化。潰走と政治的離反を区別する。
- 山・河川・湿地・森林・街道・城郭、雨・雪・風・季節の影響は行動種別に応じて異なる。
- 戦術操作方式（RTS／指示型等）、部隊規模、計算式、地形データ・天候の更新は未決定。

## 3. 攻城・籠城・開城・帰属
- 城の設備・地形・守備兵・兵糧・士気・包囲・強襲・救援・交渉・内応・開城を扱う。
- **城内占有／城主職／守備兵の忠誠／家臣所属／周辺領地の権利主張／実効支配**を分離し、開城・内応・強襲・交渉の結果を段階的に反映する。
- 落城だけで城主職・全家臣・軍勢・周辺所領を一括移転しない。城内分裂、降伏条件、安堵、援軍同時到着、帰属変更の厳密な順序は未決定。

## 4. 兵站・輸送・消耗
- 兵糧・飼料・武器・弾薬などの所有者・保管場所・手持ち在庫・輸送中在庫・引当・消費・損失を分離する。
- 共通世界時刻と取引履歴に沿って数量整合を保ち、戦闘中の物資二重生成・二重消費を防ぐ方向。
- 補給線遮断は即時壊滅を意味しない。備蓄・代替路・現地調達・護衛・敵の妨害を別に判断する。
- 輸送中の所有権・入出庫の同時刻処理・消費タイミング・略奪と住民反発・補給優先度は未決定。

## 5. 武功・損害・人物の帰趨
- 指揮・実働・貢献・損害・救援等を武功評価に接続。負傷・捕縛・逃亡・戦死は人物別に扱う。
- 実際の功績と報告・主君評価・恩賞配分は別。戦死率・捕虜処遇・史実モードの制約は未決定。

## 6. 偵察・偽報・戦場情報
- 偵察・物見・目撃・伝令・報告・噂・偽報の到達・鮮度・信用によって、指揮官・部隊・プレイヤーの認識を区別する。
- 敵の客観的状態を全員が自動共有しない。未知の事実をAI判断に直接使わず、既知情報からの推測は可能。
- 緊急性・戦況・プレイヤー設定から通知・自動停止候補を判定。通知表示と受領・開封・認識は別で、未開封重要書状の本文は漏らさない。
- 視界・伝令遅延・偽報看破・戦場と全国の情報階層の接続・停止優先順位は未決定。

## 7. 世界時刻・複数合戦・軍事AI
- 共通世界時刻を正本とし、合戦内部ステップの経過を換算・反映する。非停止時は全国AI・配送・期限・他の合戦も進行する。
- 手動・自動の世界停止が発動した場合は、合戦・世界時刻・全国AI・配送・期限を一括停止。個別行動の中断とは区別。
- AIは能力・性格・忠誠・人間関係・任務・戦況・補給・本人の認識情報から戦術・撤退・降伏・救援・委任を判断。
- 時間換算・同時刻イベント・遠方合戦の簡略化・委任観戦・決定論的セーブ再現性は未決定。

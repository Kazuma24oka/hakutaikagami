# 元武将の外見対応を制作前に必須化

2026-10-18。ユーザー指摘：BodyBaseV1は形式条件を満たしても元の武将の素体に見えず、約10点。異世界冒険譚でも画素数以外の固定が必要だった。その再現性対策を百代鏡の制作入口へ接続する修正。

## 実際に再確認したもの

異世界冒険譚 `Docs/50_Production/SPRITE_ANIMATION_PIPELINE.md` の原寸/方向別登録、チヨ採用値と限界、共通原点と一度の固定縮小、累積外見比較。`Chiyo/Tools/production_gate.py` の独立した canonical_comparison、元入力の必須化、原本/コード/証拠SHA、累積比較の省略拒否を実コードで確認した。仕組みを適用し、224pxや人物寸法・外見承認は転記しない。

## 実装変更

- `appearance-reference.json` を作者の新しい寸法定義とは独立させ、元の高解像度武将と64×96原画のSHA、既存の等方倍率/移動量を固定。
- `require_appearance_reference` を生成前だけでなく、初期の制御画像/マスク構築前にも接続。元絵は実入力として必要。台帳と計画の登録量、17基準点、実際に構築するgeometryの座標を照合する。
- 観測できる表面は原画座標と許容差で照合。隠れた人体は遮蔽物・理由・範囲を別に定義する。髪頂・肩当て・靴底を裸の頭頂/肩/足底の観測値としない。
- 肌の観測、顔特徴の除外、隠れ面、所属、編集、保持の各制御証拠と、同座標重ね合わせ・頭胴比・姿勢・線と陰影・観測/隠れの実点検記録を必須にする。
- 元絵/条件/マスク変更はハッシュ照合で過去の許可を失効させる。前回素体は技術結果を履歴として残し、外見不採用と表示。以前の完成候補ページを旧制作器が再公開することも拒否。

## 実行結果と限界

34件の回帰検査が成功。元絵の省略/差替え、同一セル内の顎位置ずれ、原画の変更、未確認マスク、甲冑外周を観測人体とする指定、隠れ面範囲外、前回の実計画での再制作を拒否した。テスト用の合成データによる工程検査であり、外見の自動判定ではない。

現在の台帳は `PENDING_SOURCE_CORRESPONDENCE_CONTROLS`。元の武将からの17基準点注記、実マスク、新しい裸素体、同座標の実画像比較は未作成。数値の空欄を前回の汎用4頭身で埋めず、元絵を測定し隠れ面を作画する。台帳のstatusやPASS文字列だけで実画像の意味/美観は証明できない。

この変更は再現性の前提を強制するもので、生成モデルに元絵の画風を完全再現させる保証ではない。出力側の実画素と対応位置、線/陰影を改めて検査する必要がある。新しい画像生成・GPU実行・Godot/Core変更は行っていない。既存画像は削除/上書きしていない。

# 未確定：イベント重要度・自動停止・通知の設計案

状態：検討中。以下の分類・例・ルールはすべて提案であり、確定仕様ではない。

## 目的
全国規模の出来事を扱いながら、武将個人の行動を過度に中断しない。

## 4段階分類案
| 重要度 | 動作案 | 例 |
|---|---|---|
| S 最重要 | 自動停止＋通知 | 主人公の生命に関わる危機、直接参加する合戦、重大な選択 |
| A 重要 | 条件付き停止＋通知 | 主君からの命令、仕官の誘い、家督相続 |
| B 通常 | 通知のみ | 周辺勢力の戦争、知人の死亡、領地変化 |
| C 軽微 | 履歴のみ | 遠方の小競り合い、日常の経済変動 |

## 重要度の再評価
イベントの基本重要度と、主人公への影響度を別に評価する。
- 例：落城した城が主人公の滞在地・居城ならS候補。
- 主君の重要拠点ならA候補、隣接勢力ならB候補、無関係な遠方ならC候補。
- 主従関係、身分、所在地、家族・知人関係、関与度による補正を検討する。

## 処理規則案
- 停止判定と通知表示を分離する。停止時には理由を提示する。
- 同一時刻の複数イベントはまとめ、停止は原則1回。重要度順に提示する。
- 重要度はイベント発生時点の状態で評価し、通知履歴には判定理由を残す。
- 同時イベントの順序、重複排除、未読管理、速度変更中の処理は未決定。

## 未解決の判断
1. Aの停止条件を誰が設定するか（固定・ユーザー設定・状況別）。
2. Sをユーザー設定で通知のみにできるか（重大選択の取り逃し防止）。
3. イベントを知る経路と伝達遅延（全国の情報を即座に知れるべきか）。
4. プレイヤー操作が必要なイベントの期限切れと時間停止中の入力。
5. 重要度補正の優先順位と例外、同時多発時の処理。
6. 合戦中の通知・停止と、イベントの非表示／ネタバレ制御。

# 次の制作前に行う色・顔輪郭の統一

## ユーザー指摘と扱い

肌色・装備色・左右の顔輪郭に方向差がある。「遠目なら許容」は現状での続行許可であり、色・輪郭の最終承認ではない。今回は規約と次工程条件の記録のみで、画像・素体・マスク・リグ・モーションは変更しない。

**交換パーツを増やす前に、この項目を確認・解決する。** 生成時のプロンプト指定だけで色統一を認定しない。未対応のまま次素材を作る場合は、先にユーザーへ未対応事項を明示し、方針を確認する。

## 実装する規格（色値自体は未選定）

- 全方向共通の素材別パレットを、基本色・明部・影・輪郭の役割と具体的な色コードで保存する。肌、赤漆、黒い威し、布、金属を別素材にする。許容する色コード一覧と、遠側・影の表現規則も明記する。
- 既存の素材マスクは候補を含むため、そのまま完成した再配色マスクと扱わない。実画像で肌・漆・布・金属の所属を確認し、髪・髭・瞳などを保護する。色の近さだけで所属を決めない。
- 指定パレット・素材マスクを生成参照へ渡し、生成後も指定外色と全方向の素材別色を検査する。モデルの出力任せにはしない。
- 顔輪郭はパレットと別課題。頭蓋・顎・鼻・耳・首の基準、本人左右、共通座標、髪と顔の合わせを実原画と比較する。現在の顎の登録差を隠さず扱う。

## 変更範囲と再利用

一からの作り直しを前提にしない。既存原画・パーツ・選択ID・リグを保持し、変更が必要な領域だけ新しい版へ反映する。

| 変更 | 対象と影響 |
|---|---|
| 肌色のみ | 全方向の素体に加え、顔パーツ内の肌、耳・首・手などの観測／派生肌面を同じパレットへ対応させる。現在の顔パーツは肌を含む不透明な画素を持つため、素体だけの色替えでは表示中の顔色まで変わらない。 |
| 顔輪郭のみ | 頭部素体・顔パーツ・頭部遮蔽を局所調整。必要なら髪の生え際、耳、襟との接点も調整。変更が顔だけに必ず収まるとは約束しない。胴・肩・身体寸法・リグまで無断で変えない。 |
| 肩幅等も変える場合 | 別の体型変更。甲冑との適合や支点・接点まで影響し得るため、この色／顔の統一作業へ混ぜない。 |

肌色変更ではalpha、輪郭、所属、支点、位置、関節軌道を維持し、許可した肌素材領域以外の色を変えない。甲冑・髪等の素材を生成し直す必要はない。ただし現在のゲームは色を持つ合成済みシートを読むため、原本の変更を反映したシートの再出力・パッケージ更新・回帰検査は必要。これはAIによる一からの再制作とは異なる。

## 次工程の受入条件

1. 素材別パレットと全方向の肌領域台帳を保存し、実画像で範囲を確認する。
2. 色替えだけならalpha／座標／支点の差0、素材マスク外の画素差0を検査する。
3. 顔輪郭変更なら許可した頭部・接点領域を先に固定し、領域外の形状不変を検査する。
4. 4方向の顔／髪なし／裸／全装備／各装備なしを原寸・拡大で確認する。原画は保持し、色統一後の新比較基準を別に保存する。
5. 制作ゲートに新しい入力・マスク・パレット・コードSHAを登録し、変更のあった静止・動作シートを再出力、4方向の全選択・全コマ・Godot表示を再検査する。

具体的色コード、輪郭の最終形、実画像修正、シート再出力、実描画再検査は今回未実施。

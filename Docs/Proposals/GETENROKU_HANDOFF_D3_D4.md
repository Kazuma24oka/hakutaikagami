## 1. 人質（D3）

### 統合案の決定
実在の人物が移り住む保証。条約や従属の保証として、子や兄弟が相手の城下に実際に移り住む。人質はそこで育ち、預かり先との関係が生まれる（徳川家康の今川家時代のように）。約束が破られたときの処遇（返す・留め置く・処断）は預かり先の当主が判断し、処断は周りの家からも「苛烈」と見られる重大な政治責任になる。奪還の計略も可能。忠誠メーターや自動処刑にはしない（BD-44）。

### 本線ですでにできていること（2026-10-30 時点）
| 工程 | 内容 |
|---|---|
| HostageCustodyV1 | 本人同意・受入先承諾・現地受入・現地解放の分離。保証原本・所在・当事者・待遇義務・返還期限の保持。拘束中の通常の仕事・移動の禁止。期限超過で死亡・消失・自動返送しない |
| CustodySuccessionV1 | 預かり中の当主交代。新代表者の現地での了承まで解放を保留。新当主が別拠点なら同行 |
| CustodyFoodV1 | 食事の提供義務を受入側の実在米で履行。二重支給・解放後の支給を拒否 |
| CustodyReturnV1 | 元の家の本拠への陸路の護送。通行止めで停止と再開。到着と受領の分離 |

D3 の土台（実在の人物が実際に移り住む、所在と期限の原本、自動処刑にしない）はできている。

### 足りないこと（D3 との差分）
| # | 差分 | 内容 | つながる決定 |
|---|---|---|---|
| H-1 | 条約・従属との結びつき | 今の人質は単独の保証契約。条約や従属の条項（D4）の一つとして差し出し、どの約束の保証かを原本に持たせる | D4、TreatyV1 |
| H-2 | 未成年の人質 | 今の対象は成人の直属登録家臣だけ。史実の人質の多くは子なので、未成年を対象にする（本人の同意の代わりに親・当主の判断） | S（相続）、6-1 血縁・出生・成人 |
| H-3 | 違反時の処遇 | 約束が破られたとき、預かり先の当主が返す・留め置く・処断を判断する。処断は重大な政治責任で、周りの家から「苛烈」と見られる（名声の悪名、第24節 M2）。自動処刑はしない | BD-44、M2、W（NPCの判断） |
| H-4 | 預かり先との関係 | 預かり中の実際の出来事（食事・面会・仕事）が、人質と預かり先の当主・家の人物との関係の事実として残る（決定11） | 決定11、CharacterRelationsV1 |
| H-5 | 奪還 | 人質を取り戻す計略（調略系・破壊系の延長）。成功すれば預かり先との約束は違反扱いになる | K（計略）、5a・6a |
| H-6 | NPC同士の人質 | NPC の大名同士が条約・従属で人質を差し出し、違反時に判断する（第20節 W8「NPCも使えて完成」） | W8 |

捕虜（第21節 C7）は人質と同じ拘束の仕組みを使う。H-3 の処遇の判断と、捕虜の処遇（登用・返還・身代金・交換・留め置く・処断）は共通の部品にできる。

### 遊べる一巡の候補（P1）
**「条約の保証として子を差し出し、違反されて処遇を判断する」まで**
1. 当主が条約（または従属）の条項の一つとして、一族の子を人質に出す（H-1・H-2）
2. 子が相手の城下へ実際に移る（既存の護送・受入）
3. 相手が約束を破る（不侵略違反など）
4. 預かり先の当主が処遇を判断する（返す・留め置く・処断。H-3）
5. 処断した場合、周りの家にその噂が届き、悪名として残る（M2）

例外は代表1件（例：違反の知らせが不達で、預かり先の判断が遅れる）。未成年の扱いは、出生・成人（6-1）がまだなら「開始時に登録済みの未成年」だけを対象にしてよい。

## 2. 従属の条項（D4）

### 統合案の決定
条約と同じ仕組みで条項を選ぶ。本線の正式条約（条項ごと・版・解除予告）に従属の条項を足す：軍役（何人出すか）、献上、通行、外交の制限（敵と結ばない）、人質、本領安堵（主家が所領を認める）。決めなかったことは自治に残る。条項を守らなければ違反。離脱は解除予告＋独立（BD-46）。

### 本線ですでにできていること
| 工程 | 内容 |
|---|---|
| TreatyV1 | 正式条約。不侵略・通行・補給・防衛援軍の独立条項と解除予告期間。実権者の同一版承諾の物理到達で成立。解除は予告期間と法的到達の遅い方から効力 |
| TreatySupplyV1 | 補給条項の実物供与（実米の引当・運搬・納入） |
| TreatyDefenseV1 | 防衛援軍の実出陣・到着・守備・帰還 |

D4 の土台（条項ごと・版・解除予告・物理到達での成立）はできている。

### 足りないこと（D4 との差分）
| # | 差分 | 内容 | 既存の部品 |
|---|---|---|---|
| V-1 | 条約の向き | 今の条約は対等な家同士。従属では「主家」と「従属する家」の向きを原本に持たせる | TreatyV1 |
| V-2 | 軍役 | 主家の陣触れ（7）に応じて、決めた人数を出す義務。実出陣は防衛援軍の仕組みを流用できる | TreatyDefenseV1 |
| V-3 | 献上 | 決めた時期に決めた物（銭・米など）を主家へ届ける義務 | TreatySupplyV1 の実物運搬 |
| V-4 | 外交の制限 | 主家の敵と条約を結ばない義務。有効な制限に反する条約が成立した時点の事実と、それを主家が知った時点の認識を分ける。主家の対応は本人が得た証拠に基づく | TreatyV1、本人の知識 |
| V-5 | 人質 | 従属の保証としての人質（D3 の H-1） | HostageCustodyV1 |
| V-6 | 本領安堵 | 主家が従属する家の所領を認める（主家側の義務）。主家が所領を奪えば主家側の違反 | 所領・城の占有（既存） |
| V-7 | 違反の判定 | 条項に定めた対象・期限・履行条件に照らした不履行の発生と、相手が証拠から知った嫌疑・責任の判断を分けて記録する。不履行の有無・故意・免責・処遇は別で、自動で戦争にはしない | 本人の知識、W3 |
| V-8 | 離脱 | 解除予告＋独立（BD-46）。既存の解除予告を使う | TreatyV1 の解除 |
| V-9 | NPC の従属 | NPC の小さな家が、周りの力（勧告 D5）を見て従属を選ぶ（W8） | W1〜W3、D5 |

### 遊べる一巡の候補（P1）
**「小さな家が従属し、軍役を果たし、やがて離脱する」まで**
1. 主家と従属する家が、従属の条約（軍役・献上・人質・本領安堵）を結ぶ（V-1・V-2・V-3・V-5・V-6）
2. 主家の陣触れに応じて、従属する家が兵を出す（V-2。防衛援軍の実出陣を流用）
3. 季節ごとの献上を届ける（V-3。補給の実物運搬を流用）
4. 条項の履行条件に照らして献上の不履行が発生する → 主家の当主が証拠を得て未納を認識し、事情・責任・対応を判断する（V-7。発生と認識は別時刻）
5. 従属する家が解除予告を出して離脱する（V-8）

例外は代表1件（例：指定受領者への実物引渡しで履行する契約で、現地には納入済みだが返報が不達となり、主家の当主が未納と誤認する）。履行の判定を発送・引渡し等のどれにするかは個々の条項で明示し、この例を全献上の既定値にはしない。外交の制限（V-4）と NPC の従属（V-9）は、全国NPC（0b）の後でもよい。

## 3. 順番の提案

統合案 第14節では、人質・従属は「本線へ入力として渡す」扱いで順番の表に入れていない。本線の今の工程を区切りまで終えて第14節の順番に移る（P2）とき、次のどちらかで組み込むのがよい。

- **案A（推奨）**：0b（NPCの判断の土台）の後、7（募兵＋陣触れ）と一緒に入れる。軍役（V-2）が陣触れを前提にするため。人質の違反時の処遇（H-3）は、名声（1c）の後なら悪名までつなげられる。
- **案B**：本線の今の続きとして、すぐに H-1・V-1〜V-3 だけ入れる。陣触れがまだないので、軍役は「指名された日に出陣する」簡易版になる。

どちらにするかは本線が依存関係を見て決め、理由を記録する（P2）。

## 4. 本線が守ること（統合案の原則から）
- 人質の処断・離反・戦争を自動で起こさない。判断するのは、その事実を知った当主（BD-44、I03）。
- 違反・不履行が発生した事実、観測・報告の証拠、誰がいつ知ったか、責任・処遇の判断を分ける。訂正は履歴への追加とし、過去の損害や処分を消さない。既存の権限・契約を超える義務の追加や自治縮小の改定案を拒否しただけで、旧契約違反にしない。詳細は[2026-11-05 の明確化](../Decisions/2026-11-05_HOUSE_LAW_SUCCESSION.md)。
- V-7の配下による局地的な攻撃は、[配下の攻撃と主君の責任](MORI_MOTONARI_RETAINER_INCIDENTS.md)の一巡と確認例へ接続する。行為者の逸脱、実際の命令、家が負う条約義務、当該委任の監督・通知、各人の認識を分ける。配下の独断だけで家の有効な義務を免責せず、所属だけから主君の密命・無条件の連帯責任を作らない。補償等は既存の有効な義務または新たに成立した約束に照らし、抗議だけで固定債務を追加しない。資料の具体化であり、実装完了ではない。
- 下天禄の数値・人物データは使わない（仕組みの参考のみ）。
- V-8の従属先変更は、[国人の接近・離脱と従属先変更](MORI_MOTONARI_ALLEGIANCE_CHANGES.md)の一巡へ接続する。新しい条約、旧関係の解除意思・通知・効力、実際の離脱、各人の服従を分ける。家の従属先変更と個人仕官・家の吸収は別で、正当な代表権を保ち、家臣全員の同意を一律に追加しない。旧義務違反と無権代理も別に照合する。兵の所有・指揮、所領と実支配、人質・債務は一括移転しない。旧主の許可をすべての物理的離脱の絶対条件にせず、離脱成功や免責も保証しない。資料の具体化であり、実装完了ではない。

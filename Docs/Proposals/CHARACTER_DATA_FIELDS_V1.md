### NPCの目標・計画・拒否条件の対応（2026-11-06 採用）

[目標・計画・一線に関する3つのA案](../Decisions/2026-11-06_NPC_GOALS_PLANS_BOUNDARIES.md)に従う将来の設計要件。既存の性格・志・忠誠、本人の知識、出来事・任務・原本への参照を共用し、以下の区別を保てるようにする。新規の保存形式や実装済み状態をここで確定しない。

| 区別して持つ内容 | 根拠・知る人・継続の扱い |
|---|---|
| 現在の中長期目標と選択理由 | 本人の性格・志と既知の事情に結び付ける。性格や家の方針そのものとは分け、他人には自動公開しない |
| 目標の見直しのきっかけと結果 | 本人が知った出来事と知った時点、継続・変更を選んだ理由を残す。遠方の未受領の真実では見直さない |
| 選択済みの計画と現在の段階 | 目標、手順、次へ進む条件、進行・返答待ち・保留・中断を既存案件へ対応付ける。予定と成立済みの合意・物資の所在を区別する |
| 現在の拒否条件と文脈 | 対象人物・提案・条件・局面と、判断に使った既知の根拠を結ぶ。永久の忠誠フラグや全場面共通の禁止条件にしない |
| 内部の理由と開示する説明 | 本心と相手へ実際に伝えた内容を分離する。相手やプレイヤーが使えるのは面会・書状などで知った範囲だけ |
| 判断・計画の保存上の継続 | 進行段階・待ち状態・使用済みの根拠を再開できるようにし、ロードだけで再抽選・依頼の重複・物資の二重確保を起こさない |

管理先はBD-14・BD-58とG-X5。具体的な項目名・数値・計画数は未固定で、既存の案件や記録を重複作成しない。史実人物の目標・拒否条件を本決定だけから自動生成せず、初期設定は採録の根拠と区別する。旧保存は版付きの適用方針に従い、実装・保存実動作の検査は今回未実施。

### 再興時の履歴と原本の対応

2026-11-05の[再興に関するA案](../Decisions/2026-11-05_HOUSE_RESTORATION_CONTINUITY.md)では、吸収・解散後も正当な継承を経て同じ家として再興できる。以下は既存の家督履歴・案件・期間付き関係・原本を結び付けるための設計であり、実装済みの認定や保存形式の固定ではない。

- 家の活動履歴に、吸収・解散と再興の出来事、旧家を指す参照、再興案件とその根拠を結び付ける。過去の状態を上書きせず、IDを再利用しない。
- 候補者の主張・継承根拠・代表権・係争と、人物ごとの認識・支持を別に持つ。正統性の点数や全員共通の承認フラグを新設せず、未閲覧の原本を本人の知識にしない。
- 残る権利・契約・債務・保証は既存の原本を参照し、有効な残存分、承継同意待ち、係争、移転・清算済みを区別する。未成立案は交渉履歴であり、債務へ数えない。旧領・旧臣・兵・在庫や、同じ債務を再興用に複製しない。

管理は既存のBD-45・48と再興のG-K4へ接続する。史実の存続状態・権利・債務をこの決定から自動生成せず、採録の根拠と不明な範囲を保持する。実装・シナリオ検査は未実施。

## 8. 3〜3bの実装済みの原本（2026-11-05）
- 人物の仕事：依頼主・使い手・宛先・既知の指定住所・期限・受領証・精算・実物の預り金と荷物。BrokerWork。封書の本文を運搬者へ公開しない。
- 拠点の普請：土地容量の試作定義、人口、種類、開始と工期、確保した働き手、実支出の米・木材・銭、村の協力、適用した権限の版。PublicWorks。史実面積や人口の採録とは別。
- 船：一隻ごとのID・所有する家・建造港・交易船/軍船・完成日、実支出を伴う30日の保守原本。配置・戦闘・実航海は後続。
- 奉行：任命の受領・本人引受と、年度経費・優先分野・収穫期回避の条件書を分離。所属・軍の指揮・所領を自動で付けない。
- 家：実参集した評定を根拠とする版付きの方針。各人が認識した版は物理配送と開封で別に決まる。
- 情報：担当者が現地で観測した時点付きの米・銭・普請原本の月報。届いて当主が開くまで画面へ漏らさない。StandingAdministration。
- 新規の史実人物・史実市場・史実寺社の数値を追加していない。NPCも同じ資源・時計・情報制約と原本を使う。全国長期性能とユーザー試し遊びは未実施。


### 3cの実装原本（2026-11-05）
CraftTradeは試作の職能集団ID・人数・技能・所在地・雇用先・住まい/特権の条件・給付期間・実移動の道路区間を持つ。個々の戦闘武将へ置き換えない。初回の現地給付と移動食は本人の私財、製作と更新給付は現地の家の資源。
原料（鉄・硝石・硫黄・木炭・鉛・原石）と製品（鉄砲・火薬・玉・鉱石・精錬金属・切石・大砲）は所有する家・実所在地・携行者を区別する。原料商の試作在庫と財布、製作の原料消費・工期・費用・未完成品、鉱床の上限を原本から導く。
交易船は一隻と積荷の原本・出航準備・往復の海路・運休待ち・実帰港・実決済・未払いを分ける。船員は地域の労働から確保。宣教師の組織と代表、港の布教許可、本人の入信、商人との面識・取引実績を分け、宗教だけで所属や所領・軍を変えない。
職人・原料商・小教会・価格・産地容量・船足は試作定義であり史実の値を称しない。史実採録・歴史モード別の追加出現・弟子の育成・難破/海賊・征服時の引継ぎは後続。

## 9. 開始設定・判断支援の項目（2026-11-06 採用）

[AIの手強さと判断支援の設計決定](../Decisions/2026-11-06_AI_CHALLENGE_AND_DECISION_SUPPORT.md)に対応する。以下は人物の能力・性格そのものではなく、開始・ルール・表示の設定として分けて管理する。項目の採用であり、新しい保存形式の実装完了ではない。

| 項目 | 内容と境界 |
|---|---|
| AIの手強さ | 控えめ／標準／手強い。候補比較と先読み範囲の有効な設定。人物の実能力・性格・志・目標・一線を上書きしない |
| 判断支援 | 詳しい助言／要点だけ／自分で判断。既知情報の整理と対処・準備・時間・代償の説明量。基本情報や重要警告は保つ |
| 組合せコースと個別変更 | 選んだ組合せと、個別に変更した有効値を区別できるようにする。具体的なコース名・組合せ・既定値は詳細設計で決める |
| 既存設定との区別 | 歴史モード、W7の本人への関わり（入門／標準／対等）を別に保持する。勲功の任務難度評価をAI強度や支援の報酬倍率へ読み替えない |
| 助言の根拠 | 本人が知る情報・報告の出典と時点、目標・任務、行為の必要条件と見込みに結び付ける。作中人物の助言は発言者の知識と実際の伝達を要する |
| 適用と保存 | 有効値と適用の版・時点を明確にし、保存再開で設定と進行中の判断を保つ。途中変更の許可範囲と旧保存の扱いは実装前に具体化する |


## 10. 基礎能力・技能・経験の新方式（2026-11-06 採用）

正本は[能力5種・技能32種・経験成長の決定](../Decisions/2026-11-06_CHARACTER_ABILITIES_SKILLS_GROWTH.md)。統率・武勇・知略・政務・魅力を基礎能力とし、交渉は知略を主に参照する技能へ移す。分野は分類で、分野の総合レベルは持たない。

| 分野 | 技能 |
|---|---|
| 軍事（10） | 戦術・兵站・攻守城・調練・水軍・剣術・槍・弓・騎馬・鉄砲 |
| 内政（5） | 農政・普請・財務・裁許・治水 |
| 外交・人事（4） | 交渉・礼法・調停・人材評価 |
| 情報・謀略（4） | 情報・調略・警固・隠密 |
| 商業・産業（4） | 商取引・鉱山・工房管理・鑑定 |
| 教養・育成（5） | 茶道・連歌・教育・文筆・医術 |

必要なデータは、方式の版、人物別の開始熟練と根拠、行為別の主能力・技能と実働配分、初期経験と開始後の経験、日別の計上実働、確定済み区間と端数、教育者・対象技能・実際の指導時間。技能経験と、基礎能力・勲功・関係・家格の履歴を混ぜない。

技能は0〜100、次レベルの必要経験7200×(L+1)。実務100%、独習50%、師事100〜150%、全技能合計で1日8時間の実働まで。基礎能力は別経験720万で1上昇し、教師の技能学習の上乗せや初期経験を加えない。作成武将の技能予算は標準実務3000時間相当・1技能開始上限50を初期調整値とする。

兵科適性の槍・弓・騎馬・鉄砲は同名技能、輸送は兵站へ統合する。個人武芸を別値にしない旧決定も更新し、武勇と武器技能を分担させる。魅力は実際の関係づくりに作用し、名家は家系・家格に由来する特性として別に表示する。

新規世界へ適用する方式とし、旧保存の交渉能力・7技能・経験は自動変換しない。人物の採録・32技能の実務接続・保存・表示は今後の実装。今回、既存の実装成功記録や完成率を変更しない。

# 人物・家・拠点に持たせる項目（2026-10-31）

統合案（[GETENROKU_INTEGRATION_V1.md](GETENROKU_INTEGRATION_V1.md)）と位階・官職の表（[RANKS_AND_OFFICES_V1.md](RANKS_AND_OFFICES_V1.md)）で決めた内容のうち、**データとして持つ項目**を一か所に集めた一覧。本線が保存データの形・史実の採録・作成武将の画面を作るときの正本にする。

- **既存**：本線で実装済み（2026-10-31 時点）。**新規**：統合案で決めた、まだ持っていない項目。
- **知る人**：画面や NPC がその値を使えるのは誰か（本人の知識の原則）。「本人」＝その人物自身、「関係者」＝会ったり報告を受けたりした人、「公知」＝広く知られている。
- **採録**：史実人物の値をどこから入れるか。作成武将は「作成時に設定」か「ゲームで決まる」。
- 下天禄（参考ゲーム）の数値・人物データは使わない。

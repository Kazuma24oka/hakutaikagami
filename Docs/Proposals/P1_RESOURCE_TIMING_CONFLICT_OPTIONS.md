## 共通の状態・数量不変条件（検討案）
- 利用可能量＝現物保有量－有効な引当量（輸送・保管状態は別に判定）。例：100俵に60俵引当なら利用可能40俵。
- 消費確定と成果確定を分離。例：木材40を使っても普請の成果40%が保証されるわけではない。
- 引当解除は消費済み資源の復活ではない。例：木材40消費後に解除できるのは未使用60。
- 競合結果は因果と制度別裁定に従い、入力順だけで決めない。例：徴税と兵糧が同時に同じ米を要求。
- 確定済み効果の訂正は補償として記録。例：過徴収の返還を別イベントで記録。

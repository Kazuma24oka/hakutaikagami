Godotの「武将表示」タブで、前回の小さな足踏みから腕振り・膝の軌道・足上げを広げた。同じ64×96・1倍、同じ素体/顔/髪/甲冑8部位を維持する。比較欄の右端に「前回」の全装備を同期表示し、改善案と並べて見られる。

## 変更した制御

| 制御 | 前回V4/V5 | 改善V6 |
|---|---:|---:|
| 腕の上下振幅 | 2px | 4px |
| 足上げ | 3.5px | 5.5px |
| 膝の内向き軌道 | なし | 最大1.5px |
| 上体の左右移動 | なし | 最大0.75px |
| 腕の左右振幅 | 0.65px | 1px |
| 歩行 | 8インデックス、上げ/戻しが同形 | 8インデックス、上げ/戻しを分離 |

これらは小数座標の制御値で、描画は最近傍の整数画素。待機4×350ms／歩行8×120msは維持する。輪郭/体型を別人へ作り直したり、コマごとにサイズ合わせをしない。旧V4/V5の素材・設定・検査記録は保持し、新しい素材を `Game/Assets/Trials/OfficerFrontWalkV6/` へ分けた。

大振幅の初期案では、手首の急な重みの減衰が腕を縮め、足の左右端へ異なる重みを与えた案は足先を尖らせた。いずれも提示用に採用せずHistoryへ残した。腕の戻りを65〜87の範囲に分散し、脚の左右の遷移を10pxへ広げ、膝の軌道を足首で0へ戻す制御へ修正した。足の横方向では同じ変換を使い、支持足の構成点を固定する。逆写像は40反復で誤差を検査する。肌・甲冑・遮蔽・素手は同じ変換を参照し、刀は腰に追従する剛体のまま。

元の素体・顔/髪・8部位・所有/限定補完/遮蔽マスクは未変更。生成AIや新しい塗り直しは使わず、固定した2D表面制御で制作した。隠れた関節は元の作者構成点であり、人体の実測や体型の正式採用にはしない。

## 起動・再検査

ゲーム本体の「武将表示」タブを選ぶか、既存のGodot起動引数 `--officer-motion-review` を使う。従来の確認コマンドも現在の検査へ委譲する。

```powershell
./Scripts/Validate-OfficerGodotMotion.ps1
# 同じ現在の検査への直接入口
./Scripts/Validate-OfficerFrontWalk.ps1
```

素材の再構築は `python Scripts/build_officer_front_walk.py --root . --plan front-walk-v6`、新規回帰は `python Scripts/test_officer_front_walk.py`。原本を破壊せず、計画/入力/コードを変更したら関連レビューを取り直す。

## 固定した制作方法

元の甲冑一式の可視2215画素を、実際の原画座標図と単体・除去画像を見て8部位へ分類した。初期の多角形だけの分割では肩・陣羽織・刀の縁が別部位へ残ったため、行ごとの範囲と意味を付けた具体的な画素の所属へ修正。孤立画素を消してごまかさず、原画の全可視画素を保持した。RGBの明暗で意味を判定しない。

原画で隠れている袖、胴、帯下、下衣、陣羽織、鞘、履き口の面は、限定した作画で補う。各補完は、宣言された後段の遮蔽物が持つ元画素領域内にのみ許す。可視画素の所属マスクと、補完マスクと、素体の表示を隠すマスクは別。補完の色・模様・範囲・上下関係を定義/処理コードへ固定し、重ね順の循環や範囲外は拒否する。元絵の見えない面を正確に復元したという意味ではない。

素体に対する遮蔽は、腕が手、脚がすね、履物が足を個別に管理する。その部位を外すと当該遮蔽が解除される。全身を元絵のalphaで一括切り抜かない。籠手を外したときは、元の素手を鞘や陣羽織より手前へ再表示する。これは素体の保存画素を変更する処理ではない。

## 実画像と検査

- 全装備は元絵の可視2722画素とalphaに一致、差分0。完全透明画素に残る元の背景RGBだけ比較時に0へ正規化する。元ファイルは未変更。
- 顔・髪も全解除すると、元の裸素体RGBAに完全一致、差分0。裸素体のSHAも不変。
- 胴/肩/腕/腰/脚/履物/陣羽織/刀を個別に外した8画像と、単体8部品を実際に目視。修正後に無関係な孤立片がないことを再点検。
- 単体監査：胴/腰/脚/刀は1連結、肩/腕/履物/陣羽織は左右等を含む2連結を上限として検査する。所属外のコピー、限定外の補完、観測画素の変更は拒否する。
- 顔・髪を含む10選択の全1024通りを、Pythonの実RGBAとブラウザーの原寸画像でSHA照合。全件一致、拡大との相違0、素体の固定表示の変更0。
- 各8部位のチェック解除、各部位だけ着用、甲冑全解除、顔髪を含む全解除、すべて復元のUIイベントを実行し、検査PNGと差分0。
- 実CSS64×96、4倍256×384。実ブラウザーの市松全装備/白背景の陣羽織なし/黒背景の肩なしを目視。ページエラー0。
- 新しい回帰11件、前段の顔髪回帰9件、既存工程回帰36件が成功（計56件）。前段の8状態の比較を保持。
- 最終計画からの再出力45 PNGのSHA差分0。自動検査用CI入口も追加したが、GitHub上の実行成功は未確認。

これらは作者による正面静止の点検。ユーザーの外見採用や、別装備バリエーションの互換性、変形/歩行の承認ではない。素体の「細すぎて不自然」という課題も継続する。

## 再実行

リポジトリルートで、既存Python依存が導入済みの場合：

```
python Scripts/build_officer_armor_parts.py --root . --plan armor-split-final
python Scripts/review_officer_armor_parts.py --root .
python Scripts/test_officer_armor_layers.py
```

描画は共通の `Scripts/officer_armor_layers.py` を使用。ヘッドレス表示検査は `Scripts/verify_officer_armor_browser.cjs`。全入口で計画とSHAを照合し、変更した素材/マスク/コードへ旧検査結果を流用しない。初期の不適合画像はHistoryに残す。

新しい画像生成、マウス/ネイティブ入力、Godot/Core変更、他方向、関節移動・歩行、6頭身の対応素材は今回実施していない。main/design/foundation/Confirmed、元絵/顔/髪/裸素体と旧不採用素材は変更していない。

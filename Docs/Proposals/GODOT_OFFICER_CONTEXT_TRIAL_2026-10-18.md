# 武将サイズ：合戦・内応交渉の文脈比較（2026-10-18）

ユーザーの「ゲーム画面にあわせてみてみたい。合戦とか内応交渉だと」という追加依頼に対応。単独の寸法比較だけで採用せず、[先のサイズ試料](GODOT_OFFICER_SCALE_TRIAL_2026-10-18.md)を同じ座標条件の仮画面へ配置した。採用サイズ・表示倍率は引き続き未決定。

## 比較画面

[合戦・内応交渉の比較HTML](officer-context-review.html)で、場面2種類×素材サイズ3種類×整数表示倍率2種類の12状態を切り替える。表示画像は生成した完成予想図ではなく、実Godot 4.5.2 .NETの描画を保存した1100×720 PNGである。

- **合戦**：仮の地形・道・川・橋と固定UI、同じ正面人物を12体配置。選択リングと陣営表示を付け、人物同士の重なり・余白・画面占有率を比較する。実ゲームの兵数・戦闘規則・カメラ・背景画風を決めたものではない。
- **内応交渉**：仮の室内に使者と対面相手を同じ試料で配置。下段に顔参照・会話文・選択肢の仮表示を置く。顔カードは固定サイズのまま、小型ドットのサイズと倍率だけを変える。対面相手の外見と会話内容は試料であり、正式キャラクター/会話/交渉仕様ではない。
- すべて正面静止。相手を向く側面・背面・歩行・攻撃・交渉動作は未制作。軍勢の人数はゲーム仕様ではなく、今回の混雑比較用。

## 素材と固定条件

`OfficerScaleV1`の3サイズPNGと変換係数をそのまま使用。背景の矩形が比較を妨げるため、`OfficerContextV1`に別の仮アルファを作った。肌や甲冑を切り分けた部位所属マスクではなく、外周に連結した明るい低彩度の背景候補を除く限定処理。元の不透明試料は変更しない。

処理条件は `Scripts/build_officer_context_trial.py` に保存。背景候補はRGB最大最小差24未満、R-G差12未満、G-B差18未満、平均105超で、4近傍で外周と連結した部分のみ除去する。これらはこの試料専用の暫定値で、一般的な意味分割規則ではない。白・黒背景との[目視比較](Evidence/officer-context-alpha-audit.png)を実施した。境界や未観測面、装備解除を正式受入したとは扱わない。

出力アルファは0/255、RGBは対応する元PNGから変更なし。足底基準・中心・等方倍率・24色パレットを維持し、方向/コマごとの再fitは行わない。元入力・3サイズPNGのSHAも照合し、不一致なら出力しない。基準画・比率の追加生成は行っていない。

顔カードはユーザー提供の6頭身/4頭身設定資料画像から `[655,75,785,215]` を切り出した130×140の参照。人物の表情・成熟した顔立ちの文脈確認用で、正式な6頭身立ち絵へ接続したものではない。顔素材は線画/塗りを維持した参照表示とし、小型ドットのNearestとは別の表示用途で扱う。書籍・購入済み作成機の画像パーツは取り込んでいない。

## 見比べるポイント

素材の画素数と画面上の大きさを分ける。例えば、64×96の1倍は表示枠64×96、48×64の2倍は96×128。高画素の素材の方が、必ず大きく表示されるわけではない。

| 組合せ | 確認する点 |
|---|---|
| 32×48・1倍 | 非常に小さく、人物の存在や陣営は見えても顔の特徴は読みづらい。小表示用の専用手直し後の上限品質とは区別する |
| 48×64・2倍 | 12体とUIの併置で人物の形を読みやすい中間候補。採用は未決定 |
| 64×96・1倍 | 表示面積を抑えつつ、元の画素情報を多く保持する候補として比較する |
| 64×96・2倍 | 人物が大きく、同じ位置の他人物との重なりが増える。寄った画面向けか、配置間隔を変えるか検討する |

内応交渉では顔カードが表情の読み取りを担うので、室内の小型ドットに顔の詳細をどこまで要求するかを別途決められる。この役割分担は今回の比較案であり、正式UIや全会話の構成を確定しない。

## 実測と再現

- Godot用全体再ビルド：警告0・エラー0、インポート成功。
- ヘッドレス：12状態、人数・サイズ・倍率・Nearestを検査。保存PNGは0と明示。
- 実描画：同じ12状態で12PNGを保存。人物の画像枠が上部/下部UI・画面外へはみ出さないことを検査。初期配置では最大サイズが上部へ出たため、全候補共通の配置を修正し、全状態で再検査した。
- 仮透過処理：元RGBの保持と二値アルファを検査。再出力の4PNGハッシュ一致（3サイズ＋顔参照）。画素一致は透過境界や人体の美観を保証しない。
- 比較HTML：インストール済みEdgeのヘッドレス実行で12組合せの画像読込・正しいファイル対応・1100×720 CSS pxを検査。マウス入力は使わず、DOMで選択ボタンを実行した。
- Coreは今回変更なし。直前のサイズ比較工程で233テスト合格済み。今回の文脈追加では、描画シーンと素材処理の検査を実施。

環境はGodot `4.5.2.stable.mono.official.6ce3de25a`、.NET SDK10.0.302 / net8.0、Python/Pillow12.3.0、Windows OpenGL / GeForce RTX4060Ti。

証跡：[実行ログ](Evidence/officer-context-validation.txt)、`Art/Trials/OfficerContextV1/context-contract.json`、`browser-verification.json`。画像はEvidence配下の `officer-context-{battle|dialogue}-{size}[-1x].png`。接尾辞なしが2倍、`-1x`が1倍。

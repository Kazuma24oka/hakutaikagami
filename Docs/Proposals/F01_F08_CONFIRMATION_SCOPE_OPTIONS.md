# F01〜F08：確定可能な基本方針と保留詳細のABC比較

**状態：未確定（Proposals）／2026-10-17。** 今回は「何を確定候補にするか」の比較。A/B/Cを選んでも、別途明示的に確定承認されるまでConfirmedへ昇格しない。既存Confirmedの内容は変更しない。

## 選択肢の共通意味
- **A：最小原則だけを確定候補**。複雑な構造・例外は全て保留。
- **B（推奨）：既存設計と整合する基本原則までを確定候補**。詳細な処理規則・数値・実装は保留。
- **C：具体的な状態遷移・判定方式まで確定候補**。現時点では追加検討を要する。
いずれも**比較案**であり、未承認の仕様を確定するものではない。

## F01 武将・組織・権限（P0）
- A：武将個人が主体であることのみ（これは既にConfirmed）。
- B（推奨）：身分・家督・直属主君・所属・役職・軍事指揮・所領権利・実効支配を分離する原則を確定候補にする。
- C：多重所属・兼任・委任取消・命令衝突・責任判定の厳密な規則まで候補にする。
- **Bの保留詳細**：組織ごとの権限表、陪臣への直接命令、管轄競合、事後追認の詳細、家督・離反の遷移。
- **整合性**：Confirmedの情報認識3階層を組織分類と混同せず、代理権限と本人認識を分離。

## F02 世界時刻・停止（P0）
- A：ゲーム内で時間が進むという抽象原則のみ。
- B（推奨）：共通世界時刻を正本とし、世界全体の停止と個別行動中断を区別する原則を候補にする。
- C：同時刻イベント優先順位、合戦時間換算、速度倍率、AI更新順まで候補にする。
- **Bの保留詳細**：同時刻到達／取消／期限境界、複数合戦、遠方AIの詳細度切替、決定論・セーブ再現性の実装。
- **整合性**：Confirmedの自動進行＋任意停止は「優先検討」と記されており、Bは新たな確定候補であって既に確定済みとはみなさない。

## F03 地理・領地・権利・会計（P0）
- A：城と領地を区別することのみ。
- B（推奨）：地理境界・政治的支配・領有権の主張・知行収益・実徴収・俸禄債務を分離する原則を候補にする。
- C：土地・取引の粒度、二重徴税・債務承継・競合権利の判定式まで候補にする。
- **Bの保留詳細**：所領空間表現、年代別境界、同時徴税の先後、資源残量と取引ID、現物換算、係争地の収益配分。
- **整合性**：城主職・安堵・実効支配は別。二重徴税の紛争を表現しても資源の二重生成を避ける。

## F04 主・補助・委任行動（P1）
- A：武将が複数種類の行動を取れることのみ。
- B（推奨）：主行動・補助行動・委任行動を分離し、長期行動の中断・引継ぎを認める原則を候補にする。
- C：行動併用表、進捗損失、担当者変更時の速度・権限・費用の規則まで候補にする。
- **Bの保留詳細**：主行動1件の例外、併用制限、負荷、進捗・再開条件、委任・引継ぎの責任。
- **整合性**：委任先の認識は本人に自動共有しない。個別行動中断で世界時刻は止まらない案。

## F05 国人衆・寺社・村落（P1）
- A：国人衆を全国で扱うことのみ（既にConfirmed）。
- B（推奨）：国人衆の自治と従属の両立、組織と施設の分離、寺社・村落のNPC主体としての独自性を候補にする。
- C：従属契約、派閥・合議、寺社反発、一揆の発生・動員・終結の規則まで候補にする。
- **Bの保留詳細**：自治権限、従属・離反条件、組織決議の拘束力、一揆類型、寺社交渉・武装化の遷移。
- **整合性**：国人領主・国人所属武将はプレイヤーになり得る。寺社・農民組織の直接プレイは不要。出家武将の操作可否は別途未決定。

## F06 朝廷・幕府・官位・将軍職（P1）
- A：中央権威を政治要素として扱うことのみ。
- B（推奨）：位階・官職・官途名・幕府役職・家中役職・将軍家家督・幕府実権を分離する原則を候補にする。
- C：官位授与資格、将軍就任、命令・仲裁の拘束力、政治工作の具体的効果まで候補にする。
- **Bの保留詳細**：正式任官・自称の判定、取次・奏請、将軍の正統性争い、官位効果、モード別の制度制約。
- **整合性**：官位・将軍職を得ても所領や諸大名の服従を自動取得しない。

## F07 NPCの認識・自律判断（P1）
- A：NPCに自律行動を認めることのみ。
- B（推奨）：NPCの意思決定は各主体が認識した報告・噂・目撃等に基づき、全知の世界状態を直接判断材料にしない原則を候補にする。
- C：AIの評価関数、詳細／簡略処理の切替、記憶の保存形式、セーブ再現性まで候補にする。
- **Bの保留詳細**：組織決議・個人認識の接続、噂の信用度、遠方AIの負荷削減、例外的な推測・推論の扱い。
- **整合性**：ConfirmedのEventTruth／Report／KnowledgeRecordと情報伝達遅延を維持。全知を避けることは推測行動を禁止する意味ではない。

## F08 政治・社会の案件進行（P1/P2）
- A：政治・社会イベントを実装候補として保持するだけ。
- B（推奨）：朝廷工作・将軍家工作・寺社交渉・一揆対応を複数段階の案件として扱い、申請・交渉・返答・実行・不履行を区別する原則を候補にする。
- C：案件ごとの期限・費用・政治効果・紛争・史実制約の具体的規則まで候補にする。
- **Bの保留詳細**：案件別手続、期限起点・返答基準の具体設定、失敗・再申請、政治的信用・権威の数値。
- **整合性**：Confirmedの書状・期限・代理受領・本人認識の基本方針をそのまま適用。寺社・一揆・朝廷・将軍家は既に未確定の比較検討が進んでおり「未着手」ではない。

## 横断レビュー
- **確定済み**：武将個人主体、情報の真実・報告・書状・認識の分離、3階層認識、本人受領・代理受領・開封・期限・偽書の基本方針。これらを再確定しない。
- **新たな確定候補**：F01〜F08のBは原則の範囲を提案するものであり、採用には別途明示承認が必要。
- **未解決の高優先事項**：権限衝突、同時刻の効力／期限境界、係争地会計、家督・落城の帰属遷移、組織決議と通知責任。
- **設計上の注意**：F01の権限とF07の認識は独立、F02の世界停止とF04の行動中断は独立、F03の実効支配とF06の権威は独立、F05の国人組織と操作する武将個人は独立。

## 選択後の管理
1. A/B/Cの選択は「確定候補に含める範囲」の優先検討に過ぎない。
2. 明示的に「確定」と指示されるまではProposalsに記録し、Confirmedには書き込まない。
3. Confirmed・mainの変更、アーカイブ移動・削除・縮約を行わない。
4. 元の設計比較・統合案を検討履歴として保持する。

## 3. 未決定事項：P0（基盤の整合に直結）
1. **イベントID・再実行・競合確定**：同時刻の循環依存、安定した優先判定、再ロード時の二重実行防止。例：同じ徴税イベントをロード後に二重適用しない。
2. **期限・権限の境界**：15時ちょうどの返答を原則有効とするB優先案、取消と代理受領の同時刻効力、追認。例：取消と使者受領が15時に重なる。
3. **帰属遷移の競合**：家督・安堵・城内占有・実効支配・忠誠を更新する順序。例：大名戦死と家臣独立が同時刻。
4. **会計・在庫の一意性**：取引ID、引当、同時徴税、現物残量、債務の発生と承継。例：米100俵に各80俵の徴収請求。
5. **条約・債務承継**：契約当事者・保証・人質・担保と相手方同意、承継の効力時点。例：旧当主の個人保証と家の不可侵条約を別判定。
6. **組織決議・軍令競合**：代理権限、通知到達、本人認識、服従と責任。例：撤退決議を知らない守備隊と総大将の命令が衝突。

## 4. 未決定事項：P1（ゲームの振る舞い）
1. 家臣・国人の安堵拒否、交渉・離反・服従、家中分裂の分岐。例：国人が安堵を要求して出陣を保留。
2. 城内の交渉・退去・捕縛・戦闘、援軍介入。例：門番だけ旧主家に従う。
3. 朝廷・幕府の裁定、条約の再交渉、人質返還、違反時の制裁。例：二重安堵を将軍家へ訴える。
4. AIの情報訂正・誤信・忠誠と評判の更新、遠方AI簡略化。例：独立の偽報で援軍が進路変更。
5. 合戦と全国進行、行動委任・停止通知・補給の接続。例：戦闘中も全国の期限が進む。

## 5. 未決定事項：P2（数値・演出・史料）
1. 忠誠・交渉・徴税・士気・経済の評価式とバランス。例：安堵への期待が忠誠へ何点影響するか。
2. 時間粒度・UI・情報確度・通知の表示、履歴整理。例：係争地を地図に二重表示するか。
3. 年代別の家督・官位・国人・軍役・婚姻の史料と異説。例：史実モードでは年代別の慣行を反映。
4. 出家・隠居・還俗の採用可否、演出・最適化。例：出家した元当主の継承権をどう扱うか。

## 6. 依存関係と次の推奨
**権限・世界時刻・情報** → **イベント競合／帰属状態／会計** → **外交・軍制・NPC・在地社会** → **UI・数値**。
- **次に優先**：P0-1（イベントの一意性・再実行と因果競合）とP0-3（帰属遷移）を具体的なテストケースで設計する。
- **今回の自律確定判断**：既存Confirmedで十分に規定された「分離」「段階更新」「数量整合」を重複して再確定しない。イベントの厳密な裁定、期限ちょうどの包含、承継条件はゲーム結果に影響するため、**新たな確定事項なし**。確定済みの原則は引き続き有効。

# 顔・髪・甲冑一式：元絵へ戻せる正面パーツ

[着脱確認ページ](officer-equipment-review.html) ／ [実画像比較](Evidence/officer-equipment-v2.png) ／ [実ブラウザー](Evidence/officer-equipment-browser.png) ／ [髪なし実表示](Evidence/officer-equipment-hair-off-browser.png)

## 作成したもの

すべて64×96、同じ座標、通常1倍、二値alpha。既存の仮素体 `OfficerBodyBaseV2` は変更せず、その上に以下の独立PNGを重ねる。

- **顔・髭**：元絵の顔画素と、髪に隠れた頭部の肌面。髭単独の交換はまだない。
- **髪・落ち影**：元絵の髪と、別の意味マスクで管理する額への落ち影6画素。
- **甲冑一式**：甲冑、下衣、陣羽織、籠手、脚具、履物、佩刀を含む一式。胴/腕/脚などへの細分交換はまだない。

素材は `Game/Assets/Trials/OfficerEquipmentV2/`。固定した定義・所有マスク・保護範囲・遮蔽・入力SHA・検査は `Art/Officer/EquipmentPartsV2/`。機械可読な構成は `part-manifest.json`。別の髪型や甲冑のバリエーション、6頭身の対応素材を作成したという意味ではない。

## 元絵と素体の保持

元絵 `OfficerContextV1/front-64x96.png` の画素を、原寸で目視した座標から分けた。再生成・拡縮・個別fit・旧不採用マスク・RGBの暗さによる所有判定は使っていない。顔/髪の境界を原画の座標図で確認し、目眉・鼻・口・髭を顔として保護した。

髪を外した初回の実画像に額の落ち影が残り、頭部の補完も平坦だったため修正した。6画素は髪本体とは別の影owner4で保存し、髪の表示に連動する。目眉の暗い画素を髪へ移す方法ではない。隠れた頭部は既存の裸頭の輪郭と肌面を引き継ぐ。初回出力はHistoryに保持した。

仮素体の手・すね・足のうち23画素は、元絵の籠手/脚具/履物の輪郭外にある。素体を削らず、甲冑一式の遮蔽マスクで対応する人体owner ID（8,11,13,14,16,17）の表示を隠す。装備を外すと、その領域が保存されたまま再表示される。元絵alphaで全身を一括切り抜く方式ではない。遮蔽と画素所属は独立したマスクである。

この遮蔽は正面の静止着せ替え用。身体寸法の厳密な適合や、動作中に装備が追従することまで実証したものではない。「細すぎて不自然」という素体の課題は保留のまま。

## 実測と実画像検査

- 顔・髪・甲冑の全8組み合わせをPNG出力し、ブラウザーの原寸/拡大と全てRGBA差分0。
- 全装備は元絵の可視2722画素およびalphaと一致、差分0。元PNGの完全透明画素に残る背景RGBは比較時に0へ正規化する。元ファイル自体は変更しない。
- 全解除は元の裸素体RGBAに一致、差分0。元素体PNGのSHAも不変。
- 髪を外しても保護した顔特徴は元絵と一致。顔を外すと同領域は裸頭に一致。髪/甲冑に顔特徴の画素が混入しない。
- 頭部の限定補完を除き、髪と甲冑の画素は所有元の実画素そのまま。所有1=顔、2=髪、3=装備一式、4=髪の落ち影。
- ブラウザーは実CSS64×96、拡大256×384、ページエラー0。全解除/全装備/髪だけ解除/甲冑だけ解除と個別チェック操作を検証。
- 元絵・全装備・髪なし・甲冑なし・全解除・単体パーツを実画像で目視し、白黒背景と原寸/拡大のブラウザースクリーンショットも確認。
- 新規の実素材回帰9件と既存工程回帰36件が成功。最終のパーツ工程ゲートを通して再出力し、点検済み17 PNG全てSHA不変。

正面の顔付き/髪なし/素体/原寸/白黒市松を実点検してから `parts` 工程を許可した。前回の裸素体だけの診断を根拠に、顔付き等のゲートを省略していない。作者による点検であり、ユーザーの外見採用ではない。別方向・関節の隠れ面・歩行・portraitの段階ゲートは解放していない。

## 再実行

リポジトリルート、既存のPython依存が導入済みの場合：

```
python Scripts/build_officer_equipment_parts.py --root . --plan equipment-parts-final
python Scripts/review_officer_equipment.py --root .
python Scripts/test_officer_equipment_parts.py
```

ヘッドレスのEdgeとPlaywrightによる表示検査は `Scripts/verify_officer_equipment_browser.cjs`。マウスやOSの入力設定は使わない。固定SHAが変わる場合は計画と関連レビューを更新する。今回、新たなAI画像生成やGodot/Core変更はしていない。GitHub CI用の9件の検査入口は追加したが、GitHub上の実行成功は未確認。

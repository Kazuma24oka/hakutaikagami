# P1プレイヤー操作フロー：立場別行動・命令・移動・交渉・委任・結果確認（ABC比較7項目）

**状態：未確定（Proposals）／2026-10-18。** 7項目すべてユーザーがB案を優先検討として選択済み。具体的な操作方式・例外は未確定。既存のP1プレイヤー行動21項目統合とP0確定原則を前提に、操作の流れを具体化する。

## ① 立場別の行動選択
- **A**：全身分に同じ実行メニューを与える。例：陪臣も大名と同じ全軍動員が可能。
- **B（推奨）**：共通行動分類を使い身分・役職・委任・管轄で実行／申請／越権試行を切替。例：国人は自領の徴税を実行し、大名には安堵を嘆願する。
- **C**：身分ごとに完全固定の操作画面。例：国人が城主を兼任しても普請を操作できない。
- **保留**：身分別の初期画面・権限不足の表示・兼任切替。

## ② 命令・嘆願の操作手順
- **A**：行動選択時に相手の承諾と実行が同時成立。例：陪臣が大名に直訴すると即加増される。
- **B（推奨）**：対象選択→権限／条件確認→内容指定→発信／面会→到達／認識→返答→履行。例：国人が主君へ安堵書状を送り返書を待つ。
- **C**：命令も嘆願も必ず対面でしか行えない。例：遠方の主君に書状で申請できない。
- **保留**：代理・期限・費用・越権警告。

## ③ 移動・所在地と行動
- **A**：移動中は全ての操作が不可能。例：使者移動中に受信書状を確認できない。
- **B（推奨）**：本人の移動と使者・軍勢の移動を区別し、所在地・拘束時間・伝達距離に応じ行動可能性を判定。例：城主が隣国へ赴く間も留守居が普請を継続。
- **C**：全移動と指示が即時完了。例：遠方の城へ瞬時に赴いて命令する。
- **保留**：移動速度・同行者・移動中の補助行動・危険。

## ④ 委任・引継ぎの操作
- **A**：委任先を選ぶだけで常に成功。例：奉行が資材不足でも普請を完遂。
- **B（推奨）**：目的・範囲・担当・資源・期限・報告を指定し、進捗確認・中断・再委任を段階管理。例：城主が奉行に普請を委任し災害時に中断を命じる。
- **C**：委任後は全操作と介入を禁止。例：家臣が離反しても担当変更できない。
- **保留**：委任入力UI・引継ぎ損失・中断効力。

## ⑤ 世界時間・停止と入力
- **A**：行動を一つ選ぶたび全世界が1日進む。例：書状閲覧で全国の軍勢が1日進む。
- **B（推奨）**：共通世界時刻を保ち、自動進行＋任意停止を優先案として、操作・確認中の進行と緊急割込みを別途設計。例：重要書状の到達時に停止して開封判断をする。
- **C**：メニュー操作中も必ず時間が進む。例：返書を読んでいる間に回答期限が切れる。
- **保留**：自動進行の採否・速度・停止条件・合戦同期。

## ⑥ 結果確認・通知・情報の秘匿
- **A**：行動実行と同時に全結果を公開。例：独立工作の成功と敵の密偵の正体を即表示。
- **B（推奨）**：進捗・実結果・報告・本人認識・通知を分離し、認識可能な範囲で結果を確認。例：工作が失敗しても使者帰還まで失敗を知らない。
- **C**：結果を一切通知せず履歴も見せない。例：委任した徴税が失敗しても確認できない。
- **保留**：通知重要度・履歴・未開封書状・報告遅延。

## ⑦ 複数身分の操作例と越権
- **A**：役職にかかわらず全行動を合法実行。例：陪臣が独断で他家へ宣戦布告。
- **B（推奨）**：国人・陪臣・城主・大名の行動差を権限と立場で示し、越権試行は正規命令と別処理。例：陪臣は大名に直訴できるが、直属主君の不興を買う可能性。
- **C**：権限のない行為の試行を全て禁止。例：陪臣の直訴や内通を一律禁止。
- **保留**：越権試行範囲・NPC反応・制裁・成功条件。

## 立場別の複合操作例（未確定）
- **国人領主**：自領の徴税を奉行に委任 → 主君へ安堵を嘆願 → 書状到達・返答を待つ。例：返答待ちでも村落の交渉は続く。
- **陪臣**：直属主君の命令を受ける → 大名へ直訴を試みる → 返答と直属主君の反応を別々に受ける。例：大名に評価されても直属主君の不興を買う。
- **城主**：普請を委任 → 本人が外交のため移動 → 災害報告到達 → 工事中断命令を発送。例：停止命令到達前に工事が進む。
- **大名**：軍勢に出陣命令 → 家臣の受領・判断 → 軍勢が実際に移動 → 合戦報告が遅れて到達。例：命令が有効でも家臣が従わないことがある。

# P0 同時刻イベント処理：詳細ABC比較案

**状態：未確定／2026-10-17。** 本書の6項目は未選択。Bは推奨候補であり正式確定ではない。既存の共通世界時刻、因果関係・効力時点・依存関係を考慮する確定原則を前提とする。**比較するのは、その原則の具体的な適用方式**である。

## ① 同時刻イベントの評価単位・依存関係
- **A：登録順処理**。同時刻なら登録された順番で確定する。例：落城イベントが先に登録されると援軍の効果が消える。
- **B（推奨）：同時刻の事象を収集し、前提状態・因果依存・効力時点を評価した後、競合する更新を整合させる**。例：援軍到着と開城を同時刻の候補として照合し、開城成立の前提と援軍の介入条件を確認する。
- **C：全事象を完全同時に成立**。例：同じ城が開城済みかつ開城前という相反する状態を持つ。
- **保留**：時間粒度、イベントID、同一対象への書き込み競合、循環依存、判定不能時の扱い、セーブ再現性。

## ② 権限取消と代理受領が同時刻
- **A：取消を常に優先**。例：取消の通知をまだ受けていない代理人が同時刻に受領しても必ず無効。
- **B（推奨）：取消の効力発生時点、受領の法的時点、代理人と相手方の認識、追認可能性を別々に判定**。例：使者が委任取消を知らず返書を受領した場合、受領の効力と責任・相手方保護を分けて判断する。
- **C：受領を常に優先**。例：取消済みの使者でも同時刻なら無条件に有効受領。
- **保留**：効力の同時刻境界、善意保護、追認の遡及、越権行為の責任。**正式代理受領と本人の認識は別**という確定仕様を維持。

## ③ 返答到達と期限切れが同時刻
- **A：期限と同じ時刻の返答は必ず無効**。例：15時期限の返書が15時ちょうどに到達すると失効。
- **B（推奨）：案件別の期限基準（発送時／到達時）と有効時点を先に特定し、境界の包含規則で判定**。例：15時期限の案件でも、発送時基準か到達時基準かで判断対象が異なる。15時ちょうどを含むかは別途決める。
- **C：同時刻の返答は常に有効**。例：既に効力を失った交渉でも同時刻の返書なら自動復活。
- **保留**：境界を含むか、期限の最小時間単位、失効と再申請、追認・第三者への影響。返答の期限遵守と条約成立は同一視しない。

## ④ 落城・開城と援軍到着
- **A：落城を必ず優先**。例：援軍が城門に到着していても開城が同時刻なら救援不能。
- **B（推奨）：城内占有、開城の合意・履行、守備兵の状態、援軍の位置・指揮命令・到達を独立して評価し、成立済みの効力と介入可能性を照合**。例：開城交渉が成立していても城門引渡し前なら、援軍が介入できる可能性がある。
- **C：援軍を必ず優先**。例：城が既に引き渡されていても援軍が同時刻に来れば落城を取り消す。
- **保留**：開城の効力と占有移転の境界、合戦内部時間換算、城内分裂、援軍が交戦可能になる条件。

## ⑤ 二重徴税・同時刻の在庫移動と消費
- **A：請求額をそれぞれ満額支給**。例：米100俵に対し二勢力が各80俵を同時請求し、160俵が生成される。
- **B（推奨）：請求・引当・実徴収・輸送・消費を別取引とし、同一現物への競合を残量と有効な引当・取引で調停**。例：米100俵に各80俵の請求があっても実際の出庫合計は100俵以下。未徴収分は権利争い・債務として別管理する。
- **C：先に処理した勢力に全現物と権利を付与**。例：最初の徴収が他勢力の安堵・徴税権まで自動消滅させる。
- **保留**：取引一意ID、同時刻の引当優先順位、輸送中の所有権、在庫不足時の未払・不法徴収・紛争。

## ⑥ 同時刻の軍令・組織決議・通知
- **A：上位命令を必ず即時実行**。例：総大将の突撃命令と国人衆の撤退決議が同時刻なら全員が突撃。
- **B（推奨）：決議・命令の効力、指揮権・管轄、伝令到達、本人認識、忠誠、実際の行動を段階判定**。例：国人衆の撤退決議が成立しても、前線の指揮官にまだ届いていなければ、その時点で知らない命令に従うことはできない。
- **C：受信した最後の命令だけを採用**。例：権限のない使者が最後に届けた命令でも有効な軍令を上書き。
- **保留**：同時刻に届いた矛盾命令の優先度、命令の有効期限、本人の拒否と責任、通知重複の集約。

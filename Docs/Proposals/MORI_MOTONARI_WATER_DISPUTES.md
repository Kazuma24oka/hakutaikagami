# 毛利元就研究 水利・土地の争いと裁定の実履行

2026-11-05。既存採用仕様の接続を具体化する資料。新しい根本方針の採用、一般的な裁判権の新設、ゲーム実装の完了を意味しない。

有力者を排除した後にも、村・家臣の間の争いや地域の仕事は残る。今回は「誰が争いを扱えるかを確かめ、調べ、仲裁または裁定を行い、現地で実行する」一巡に絞る。戦で勝っただけで、旧有力者の土地・水路・利用権・人員を一括取得する仕組みにはしない。

## 2 仲裁案・権限に基づく裁定・権限不足

| 扱い | 成立・判断の前提 | 拒否や異議の扱い |
|---|---|---|
| 合意を取り持つ仲裁案 | 対象の権利を扱える当事者が、必要な条件に合意する。取次人は委任された範囲だけを代行する | 不承諾なら提案のまま。拒否しただけで既存の権利・債務・別件の軍役を消さない |
| 既存の管轄・権限による裁定 | その案件・相手に及ぶ既存の管轄、判断者の権限、必要な手続を確認する | 元の成立条件にない「負けた側の個別同意」を新設しない。異議、伝達、実際の協力、実行可能性は別に残す |
| 権限が不足・不明な案件 | 権限を持つ主体への上申、限定委任の取得、当事者間の合意形成等へ回す | 「当主」「奉行」という肩書だけで裁けることにしない。権限外の強行を、有効な裁定として正当化しない |

これは一律の権利優先順位を新設するものではない。古い保証、後の裁定、実占有、慣行のどれを採るかは、その案件の既存条件と判断根拠を照合する。証言や本人の判断を世界の事実に上書きせず、食い違いを残す。

裁定の権限があっても、村の労働徴発、他家の財産処分、補償費の支出などが同じ権限に含まれるとは限らない。調査の立入り、工事場所の使用、費用負担にも、それぞれ既存の根拠が必要。新しい例外権限を、この案件の便宜のために足さない。

## 3 最低限遊べる一巡

初回の検証は二つの村と一件の普請を対象にする。開始条件に、争う範囲、既存の利用・管理の根拠、判断できる主体、使える人と物を明記する。新しい河川流量シミュレーターは作らず、既存の地域・施設・任務・資源・時刻へ接続する。

| 段階 | 選ぶこと | 残す結果・未確定のもの |
|---|---|---|
| 申立てと管轄確認 | 本人に会う、書状を受ける、取次ぎを頼む、権限者へ回す | 誰が何を求めたか、根拠と争点。受領だけで相手の主張が正しいとは決めない |
| 調査の委任 | 担当、対象、期限、費用上限、許される行為、報告先を決める | 現地の施設・利用状況、文書、当事者の証言を出所と時刻付きで返す。調査命令だけで現地情報を取得済みにしない |
| 仲裁・審議 | 合意案を作る、既存権限で裁定する、証拠を追加照会する | 判断者が知る証拠と権限、案または裁定、その理由。新しい合意と既存の有効な義務を区別する |
| 実行手配 | 担当者、工事場所、必要な人手・材料・食料、費用、約束した給付を手配する | 作業の根拠と協力、資源の確保、工期。裁定を出しただけで働き手・資金・土地を発生させない |
| 現地実行・返報 | 現地の進捗・損失・実受領を確認し、未履行や再申立てを扱う | 工事、給付、権利上の争点、本人の認識を別々に記録する。工事終了だけで案件の全項目を解決済みにしない |

任務を持つ者も、判断者も、当事者もNPCになれる。誰に調査を任せるか、誰に取次ぎを頼むかが政治的判断になる。親族関係や利害関係は照合材料だが、それだけで報告を自動的に虚偽と認定しない。

### 遊びの具体例：収穫前の用水修復

洪水後、乙村へ水を届けるための修復案が、甲村で使われている田の一部を通る。甲村側には出陣を支える有力家臣が関わり、乙村側では家の年貢収入への影響が心配されている。この関係や被害は検証用の設定で、史実データではない。

プレイヤーは、必要な権限と本人が知る情報の範囲で次のように動ける。

- **調査を優先する**：古い文書と現地状況を確かめる人を派遣する。その間も時計は進み、既存の地域処理による損失や他の仕事への拘束は止まらない。
- **当面の合意を作る**：必要な当事者が合意できる通水・作業・給付の条件を提案する。臨時の合意を恒久的な権利放棄として扱わず、支給を約束するなら担当・原資・期限を確かめる。
- **既存の権限で裁定する**：その争点を扱える権限がある場合に、把握した証拠と既存条件から判断する。異議があっても裁定が直ちに消えるわけではないが、工事や給付は別に手配する。

どれも「公平度を上げれば全員が納得する」操作にはしない。主君が軍役・収入・費用・時間・関係者との約束を同時に考えることが面白さになる。争いを扱った履歴は次の申立てや協力の判断材料になるが、それだけで管轄や服従が自動拡大するわけではない。

## 4 実装へ渡す情報・画面・既存コードとの境界

以下は既存情報の対応表で、新しい保存形式や独立した裁判エンジンを指定するものではない。

| 情報 | 必要な参照・区別 |
|---|---|
| 案件と争点 | 申立人・相手・村／家、対象の土地・施設・利用、求める対応、未解決の項目 |
| 根拠と証拠 | 原本・版・当事者、保証や権限、現地状況、証言、出所・時刻・取得者。実占有や調査結果だけで所有権を変更しない |
| 権限 | 誰が、どの案件・相手に、どの条件で判断・立入り・工事・支出できるか。仲裁案への同意と裁定への異議は別 |
| 調査と判断 | 任務・担当・範囲・費用・期限、到着した報告、その時点で把握した証拠、案と承否または裁定と理由 |
| 実履行 | 普請の進行、人員・材料・食料・資金の所有者と引当、給付義務と実受領、元の任務・取引ID |
| 認識と残件 | 通知・到達・開封、現地観測、工事の実終了、給付の残り、異議・再申立て。完了報告の到達と実完了を分ける |

画面では既存の「会う・書く・任せる・動く」から案件を開き、既知の争点、権限の根拠、届いた証拠、次に取れる行動、実行の不足条件を示す。例えば「裁定済み／村への通知は到達未確認（返報待ち）／作業員未確保／給付未実行」を、本人が把握した範囲で分ける。原因不明の成功率だけを出したり、未着の証拠や相手の内心を確定表示したりしない。

照合時点で次を読んだが、今回は編集・実行していない。

- [VillageConsultation.cs](../../Core/Contracts/VillageConsultation.cs)：水利協力の提案・村側判断・確認・履行を分けている。裁定を追加するとしても、現在の限定契約の協力確認を無条件に解除しない。
- [CommunityEconomy.cs](../../Core/Contracts/CommunityEconomy.cs)：現行の水利試作は働き手・食料・工期を使う地域の改善処理。今回の土地争い・一般裁定が既に動くことは意味しない。試作の数値をこの資料で改定しない。
- [CommunityStewardship.cs](../../Core/Contracts/CommunityStewardship.cs)：地域・費用・期間等を限定した代理官の委任。これを全地域・全案件の裁判権へ広げない。

## 5 実装時の確認用シナリオ

以下の5件は既存範囲の検査例。固定の受入170件へ追加したものではなく、未実施である。通常の一巡と代表例外を対応工程で検査し、例外の全組合せはPROCESS_V2に従って後段へ回す。

| ケース | 条件と操作 | 確認する結果 |
|---|---|---|
| 合意と実履行 | 必要な当事者が、範囲と給付条件を含む仲裁案に合意する。資源を確保して普請・給付・返報を行う | 合意・通知・工事・給付・認識の時点を分ける。同じ労働と資源を二重使用しない |
| 裁定と異議 | 対象を裁く既存権限と必要手続があり、一方が裁定に異議を述べる | 元の条件にない個別同意を発効要件へ追加しない。異議を消さず、不服から自動処罰・離反・戦争へ飛ばない |
| 権限不足 | 調査または普請だけを任された者が、他家の権利変更を宣言する | 調査・普請の権限を裁判権と混同しない。有効な裁定として処理せず、上申・委任・合意形成等の余地を残す |
| 裁定後の人手・給付不足 | 有効な裁定はあるが、村の食料・空き労働または必要な協力が不足し、給付も未実行 | 裁定を勝手に無効化せず、工事や給付を完了済みにもしない。既存の協力確認と資源制約を保つ |
| NPC・遅着・途中保存 | NPCが調査・判断・実行を担当する。報告を遅着させ、進行中に保存・復旧する | 既知の情報で判断し、未着の情報を使わない。実終了と主君の把握を分け、同じ入力から同じ続きとなり、再読や再報告で給付・工事を重複させない |

## 6 管理先と完了条件

主な管理先はG-V2／BD-49（申立て・権限・評定）とG-N2／BD-33・30（調査・普請の任務）。BD-34〜36の資源・実物、BD-42・48・50の義務・権利・自治、BD-25・26・58の認識・NPCへ接続する。新しい進捗枠や重みは増やさない。

将来の実装完了の確認は「案件を持ち込む→権限を照合する→調査する→仲裁または裁定する→現地実行→本人が把握する」一巡が、通常入口とNPCの双方で既存制約の下に動き、上の代表例外を検査できること。今回完了したのは、この接続と確認条件の文書化だけである。

進捗表はBD-33・49の「残り」と設計参照へ追記し、実装済みの欄・達成率・受入数は変えない。統合案§14の実装順、現在のNpcPurposeV1、凍結基準を維持する。

全領主への一律の裁判権、本資料を根拠に新設する労働徴発権、既存条件を上書きする緊急権、全案件共通の権利優先順位、新しい河川シミュレーションは範囲外。既に有効な労働義務まで、元の条件にない毎回の個別同意を要するものへ変更するわけではない。必要になった場合だけ、別の根本仕様として具体例と選択肢を相談する。

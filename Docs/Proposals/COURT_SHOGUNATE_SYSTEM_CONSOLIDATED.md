# 朝廷・将軍家・官位・将軍職：統合設計案

**状態：未確定（Proposals）／2026-10-17。** 選択済みB案の統合・重複整理であり、確定仕様への昇格ではない。未決定の制度・数値・実装方法は未決定のまま残す。

## 1. 中央権威の基本構造
- 朝廷・公家、将軍家・幕府、武将の主家を異なる権威・政治関係として扱う案。
- **朝廷の位階／朝廷の官職／官途・受領名（正式任官・主君許可・自称等の区別）／幕府役職／家中役職／将軍家家督／幕府の実権**を分離する。
- 名目上の地位・実際の命令権・人脈・政治的信用・所領の権利・実効支配は同一の数値・状態にしない。
- 国人領主・家臣・浪人・大名など武将個人をプレイヤー主体とする既存構想を維持。朝廷や幕府そのものの操作可能性は本書では決めない。

## 2. 朝廷・将軍家への政治工作
- 朝廷：公家との人脈、献金・贈答・取次・奏請などで官位・権威・政治的支援を求める案。
- 将軍家：将軍・奉公衆・取次などを通じて御内書・仲裁・幕府役職・後援を求める案。
- 取次→申請・奏請→審議・判断→返答・文書の配送→本人認識・政治的履行を別状態として管理する。朝廷と幕府の手続を一律に同一視しない。
- 人脈・費用・贈答・政治情勢・関係者の利害が工作の進行・成否に影響し得る。失敗は費用・人脈・信用・政治情勢・再申請条件に影響する。
- **却下／取次不成功／審議停滞／返答不達**を区別する。返答が届かないだけで正式な却下とはしない。

## 3. 官位・官職・官途名
- 正式な位階・官職と、通称・自称・主君による許可等を伴う官途名・受領名を区別する案。
- 正式な任官の事実、使用する呼称、周囲の社会的認知、人物別の知識・噂・信用、実際の権限を別々に扱う。
- 官位等は名誉・信用・外交・人脈・権威に影響し得るが、所領・城主職・軍事指揮権は自動取得しない。
- 自称の官途名でも地域・相手によって通用する余地を認めるが、正式任官と同等の効力を自動付与しない。僭称と受け取られた場合の反発・紛争も検討する。
- 位階・官職・官途名・受領名の制度上の区分や時代差は史料で検証し、具体的な権限・称号効果は未決定。

## 4. 将軍職の継承・擁立・正統性
- 血統・将軍家家督・朝廷任命・政治的正統性・支持勢力・幕府実権・政治情勢を分離して評価する案。
- 将軍職の継承・擁立・廃立・対立候補の支持・和解等を扱うが、具体的な就任資格や手続は未決定。
- 朝廷任命を受けた将軍でも実権を欠く場合、別候補が強い軍事的支持を得る場合などを表現する。
- 将軍就任は全国統一や全大名の自動服従を意味しない。征夷大将軍への任命と幕府・将軍家の実権は別。
- 正式任命の制度上の地位と、政治勢力が各候補を正統と評価する度合いは混同しない。

## 5. 命令・仲裁・政治的効果
- 朝廷・将軍による命令・仲裁の受容／拒否／政治利用は、権威・正統性・利害・軍事力・人間関係・地域情勢に応じて判断する案。
- 命令・仲裁の**発給／配送／到達／受領／本人認識／受容／履行／政治的帰結**を分離する。
- 官位・将軍職・幕府役職が持つ命令権や代理権は、制度・管轄・個別委任に応じて判定。地位が高いだけで無条件の全国命令権を与えない。
- 史実モードでは当時の制度・人物関係を重視し、準史実・仮想では政治行動による分岐を許容。モード別制約は未決定。

## 6. 重複・表現差の整理
| 論点 | 統合した解釈 |
|---|---|
| 位階と官職 | 朝廷の序列と職務・官名を分離 |
| 正式官途と自称官途 | 任官の事実・名乗り・社会的認知を分離 |
| 朝廷工作と幕府工作 | 共通の案件進行を利用できるが、手続・権限は別 |
| 工作失敗と返答不達 | 正式却下と未認識・未到達を区別 |
| 将軍家家督と将軍職 | 家督継承が朝廷任命を自動成立させない |
| 朝廷任命と幕府実権 | 正式任命・支持・実権・領土支配を分離 |
| 権威と命令の効力 | 権威が高くても全国の人物が必ず服従するわけではない |
| 史実尊重と仮想分岐 | 制度の史実性を基盤に、モード別の逸脱許容度を変える |

- **Proposals/CHARACTER_SOCIAL_SYSTEM_CONSOLIDATED.md**：家督・主従・家中役職・知行・実効支配を官位・将軍職と混同しない。
- **Proposals/ACTION_TIME_SYSTEM_CONSOLIDATED.md**：工作・取次・審議・返答の時間経過と、世界時刻・中断・期限を整合させる。
- **Proposals/LOCAL_SOCIAL_SYSTEM_CONSOLIDATED.md**：国人衆・寺社・村落の独自利害と自治を中央権威による命令・任命で自動消滅させない。

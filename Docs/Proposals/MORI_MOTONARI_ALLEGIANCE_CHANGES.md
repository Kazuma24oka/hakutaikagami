# 毛利元就研究 国人の接近・離脱と従属先変更

2026-11-05。既存の調略・独立・条約・自治を、国人の家が従属先を変えようとする一巡へ接続する具体化資料。新しい帰属制度や一律の離脱許可制を追加するものではない。

旧主の軍役負担を軽くしたい国人が、他家へ働きかける。新しい後ろ盾を得ても、旧主のもとに人質が残り、家中には反対者がおり、約束された援軍もまだ来ていないことがある。何を確保してから動くか、何を残して動くかを、本人が知る情報で判断する遊びにする。

## 1 出典と今回の限界

研究の入口は、しかかく「豪族達と往く毛利元就の軌跡」第七話「謀神 VS 謀聖　備後細沢山合戦」。当初の[同作者ニコニコ版の説明欄転載](https://www.nicozon.net/watch/sm41607614)に続け、2026-11-05にYouTube公開ページの日本語自動生成字幕を末尾まで読んだ。4:10〜5:38頃に1525年の接触・説得・帰順を扱うと確認したが、下記の誓紙全文や城の引渡し完了を動画で確認したわけではない。所領給付説への制作者の留保、配信元リンクと確認範囲は[研究台帳M07](../References/MORI_MOTONARI_RESEARCH.md)に記録する。映像・音声・原史料の校合は未実施。

独立した照合先は[広島県史年表（中世2）](https://www.pref.hiroshima.lg.jp/soshiki_file/monjokan/nenpyou/nenpyou-cyusei2.pdf)のPDF34頁。1525年4月6日項に、その頃の志道広良と陶興房の談合、6月26日項に天野興定と元就の誓紙交換、天野興定による大内義興への米山城引渡しと忠節の誓いを記す。確認したのは年表編者の要約であり、引用元文書の全文ではない。談合の実施日を4月6日と確定しない。

[山口県文書館の目録](https://archives.pref.yamaguchi.lg.jp/msearch/detail_doc/284974)は、天野興定宛の毛利元就起請文を「（大永5年［1525］）6月26日」と整理する。括弧付きの年は目録の表記を保持する。本文欄は空で、原本画像・全文翻刻は未確認。目録の標題中の抜粋を全文と扱わない。

談合・誓約・特定の城の引渡しを別々に確認する入口として使う。これだけで、天野氏が毛利氏の直属家臣になった日時、元就の従属先変更の正確な成立日、全資源の移転や旧義務の消滅は確定しない。出典の整理番号と確認範囲は[研究台帳M07](../References/MORI_MOTONARI_RESEARCH.md)に残す。以下は既存仕様から作ったゲーム用の架空例で、1525年の交渉条件を復元したものではない。

## 2 何が変わり、何を別に残すか

照合基準は作業ブランチ df779128fe559036e755d89f35d36ef7950f9725。主な管理先はG-D4／BD-46・50で、調略はG-B6・G-C5／統合案§10 K1〜K5へ接続する。

| 対象 | 扱い | 主な既存仕様 |
|---|---|---|
| 国人の家と当主個人 | X家の従属先変更、当主X個人の仕官、X家の吸収・解散は別案件。外の主家を変えても、同じ家が存続し在所に留まる場合がある | BD-09・46・50、I01・I06 |
| 接触・情報提供・約束 | 誰が何を伝え、何を約束したかを分ける。接触だけで転属しない。ただし接触・情報提供自体を禁じる有効な条項・家法には照合する | 統合案§10 K2・K5、§16 H2 |
| 新しい従属条約 | 権限ある代表、同じ版の条件への必要な合意、適法な到達、発効条件を確認。正当な代表権を尊重し、家臣全員の個別同意を一律に要求しない | BD-41、改革の段階導入 |
| 旧主との関係 | 解除意思、通知の発送・到達、解除効力、既発生の違反・未履行を分ける。新しい約束だけで旧契約を消さない | BD-42・46・48、D4・V-8 |
| 家臣・国人の支持 | 新しい方針や宣言を知った各人が、従う・残る・中立等を判断する。家の有効な義務と実際の服従を分ける | BD-46・50・58 |
| 部隊・兵糧・私財 | 所有者、預かり、指揮権、任務、所在、実消費・返還を保持。預かった旧主の兵や米を自家の物に変えない | BD-29・30・48、I04 |
| 所領・城・役職 | 権利・安堵、任命者と役職の終了条件、門や本丸の実支配を分ける。新主の安堵だけで旧主や第三者の権利主張を消さない | BD-09・47・48、§11 J4・§26 Z9 |
| 人質・債務・保証 | 人質の拘束・返還条件と実護送、元の債務者・保証・担保を保持。自動返還・自動処刑・新主の自動債務引受けはしない | BD-44・48、D3 |
| 家法と自治 | 各家法の対象、権限の根拠、適用・終了条件を確認。当主交代時の家法継続の既定値を、主家変更時の全面継続・全面消滅へ転用しない | BD-50、家法承継の決定 |

秘密か公開かと、正式な効力があるかは別の軸である。密約でも既存の成立条件を満たす場合は、その条件で扱う。秘密だから常に無効、公表したから自動成立とはしない。有効な約束も、実際の服従・出陣・引渡しを強制的に完了させるものではない。

旧契約への違反と、家を代表する権限の欠如も別である。旧主との外交制限に反した場合の問題を、新主との約束を結ぶ代表権の判定と混同しない。新条約の成立・効力と旧義務への抵触は、それぞれの根拠で照合する。

「他家と結ばない」「特定の敵と結ばない」「他国への書状を禁じる」は同じ制限ではない。接触しただけで常に違反とせず、正式条約にならなければ常に無違反とも扱わない。単一の所属欄を上書きして、複数の支持・条約や自治の留保を消さない。

## 3 最低限遊べる一巡

### 架空の場面

甲家に従属するX家は軍役の負担に不満がある。乙家はX家の支援を求め、本領安堵と援軍を提案する。X家の嫡子は甲家で人質となっており、当主Xには自家の兵と、任務のために甲家から預かった兵がいる。家老は甲家との縁を重視し、一部の家臣は乙家への接近に賛成している。

検証用の開始状態では、甲X間の外交制限・軍役・解除条件、乙の提案内容、代表権、指揮委任、資産所有、人質・債務、各人の認識を明示する。画面とNPCへ渡すのは、その人物が知る内容だけ。甲家が秘密交渉を知っているか、家臣が本心で賛成かを当主Xへ先回りして見せない。

| 段階 | プレイヤーがすること | 別に残る結果 |
|---|---|---|
| 1 接近する | 使者・書状・現地会談で条件を探る。乙家は利害・関係・自分の知識から応じるか判断する | 接触、提供情報、返答、約束。調略を一律の成功率メニューにしない |
| 2 足場を確かめる | 家中の協力を求め、旧義務・人質・借りた兵・在所の備えを確認する。甲家への条件改定も交渉できる | 支持の表明と実際の行動、旧契約と新提案。新条件の拒否を旧契約違反にしない |
| 3 条件をまとめる | 乙家との条約を同じ版で詰め、軍役・安堵・援軍・発効条件を定める。旧関係の解除予告や返還も別に手配する | 新条約の成立・発効、旧条約の残存・終了、未決の返還や債務。合意だけで援軍を到着させない |
| 4 方針を実行する | 必要な宣言・通知を送り、各人の判断を受けて指揮・警備・返還・引渡し等を実行する | 実際の服従・中立・対立、部隊と物の所在、城の実支配。全員・全財産を一括で移さない |
| 5 新しい関係を試す | 条件に沿った最初の軍役・献上・援軍要請等を行い、実行と返報を確かめる | 新主が実際に助けるか、自家が義務を履行できるか。旧債務・人質・係争が残れば案件を継続する |

これは代表的な一巡であり、全案件に同じ直列順を強制しない。接触と家中の根回しは並行できる。旧関係の終了後に発効する約束は、その条件を明記した案件だけで待つ。すべての新条約に旧主の許可・旧義務の完全清算を共通の成立条件として追加しない。

条約に沿った解除と、解除前に離脱・反旗を翻す実行は別である。旧主が認めないから物理的に動けない、という一律の禁止にはしない。ただし、脱出の成功、新主の受入れ、違反の免責を保証せず、残存義務・追及・財産や人質を巡る争いも保持する。本人が移動せず、在所で外部への従属方針を変える場合もある。

### プレイヤーが悩むこと

- **甲家に残って条件を交渉する**：旧来の関係と在所の安全を生かせる可能性がある。甲家が軍役軽減に応じるとは限らず、乙家への接触が知られれば説明も必要になる。
- **乙家の支援と家中の協力を確保してから動く**：準備できる一方、交渉中の露見や情勢変化がある。援軍を約束した文書と実際に来た部隊は別に確認する。
- **切迫した状況で先に離脱する**：待つ危険を避けられる可能性があるが、人質・未返還の物・旧義務や反対派を残し、新主にも拒まれ得る。選んだ瞬間の勝利・安全・全員の追従は与えない。

## 4 実装へ渡す情報と画面

新しい「寝返りポイント」を作らず、既存の人物・家・条約・委任・資産・配送・認識へ案件から参照を張る。

| 情報 | 最低限必要な区別 |
|---|---|
| 当事者と権限 | 家ID、当主個人ID、旧主・新主・第三者、代表権と対象行為、家が存続するか。個人の仕官・吸収は別案件 |
| 接触と約束 | 接触・情報提供の履歴、提案・密約・条約の原本と版、当事者、成立・発効条件、各条件の独立性 |
| 旧関係の処理 | 解除意思、指定窓口等への適法な到達、終了効力、未履行・違反・債務・保証・人質、根拠条項 |
| 実際の実行 | 各人の支持と行動、命令・指揮、部隊の所有・所在、返還と引渡し、城の支配、実資源 |
| 証拠と認識 | 誰が何を見たか、密書の押収・密告、配送・開封・本人認識、訂正、他者の主張とその評価 |
| 継続と保存 | 同じ案件・原本・部隊・債務の識別子、途中経過、再送・再開時の重複防止、既存の決定的な再現規則 |

画面例は「乙家との条件案は返答待ち／甲家への解除予告は到達未確認（返報待ち）／嫡子の返還は未合意／家老は反対を表明／乙家の援軍は到着未確認」。未知の到達時刻、押収の成否、家臣の本心、他家の秘密命令は表示しない。到達済み・開封済み・内容を真実と確認済みも分ける。

[HouseholdService.cs](../../Core/Contracts/HouseholdService.cs)の既存処理は、家督交代後の同じ家の中での個人的主従関係を扱い、家所属・役職・財産等を一括変更しない。一般的な他家への従属先変更の完成を示すものではない。この限定処理の任務・預かり返納の条件を、すべての物理的離脱や逃亡を禁止する条件へ広げない。

## 5 実装時の確認用シナリオ

以下の5件は既存範囲の検査例。固定の受入170件へ追加したものではなく、未実施である。代表例外は密書の押収と解除予告の遅着の2件とし、全組合せの網羅は後段へ回す。

| ケース | 条件と操作 | 確認する結果 |
|---|---|---|
| 接近から最初の履行まで | 条件が明示された甲X・乙X関係で、接触、根回し、合意、旧関係の処理、実行、最初の軍役と返報まで進める | 成立・効力・服従・実行が分かれ、旧主への未返還の物や人質・債務が残れば継続する。X家の存続と当主個人の仕官を混同しない |
| 禁止内容と代表権の照合 | 「特定の敵との条約禁止」と「他国への書状禁止」を別入力とし、接触、情報提供、同一版への承諾を比較する | 禁止される行為に即して照合し、接触だけで一律転属・一律無違反にしない。旧義務違反と無権代理を別に判定する |
| 家中の分裂と残る権利 | 正当な代表が条約を結ぶが、家老は反対し、旧主の預けた部隊・人質・第三者の権利が存在する | 全員の同意を成立要件に追加せず、実服従は各人の判断と権限・命令に従って処理。兵の所有者・人質・旧債務・係争を一括移転しない |
| 密書の押収 | 密書を途中で押収し、旧主への報告だけが先に届く。差出人には返報がない | 旧主は得た証拠で対応を判断するが、自動処刑・開戦しない。差出人へ押収の事実を漏らさず、無返答だけで相手の拒否を確定しない |
| 解除予告の遅着・NPC・途中再開 | 条約上の解除条件より先に現地が反旗を翻し、その後通知が到達する。異なる知識のNPCと途中保存から再開する | 宣言・実離脱・通知・解除効力・違反を別時点で残す。遅着で過去を巻き戻さず、知らない通知でNPCを動かさず、兵・支払い・債務を重複させない |

遅着例では、検証用に「所定窓口へ解除予告が適法に到達してから3日後に解除効力」「発送は開始1日目・実到達は5日目」「現地は3日目に乙家へ加担」と入力する。3日の予告期間はこの架空条約だけの条件で、全従属の既定値ではない。新条約も別に成立・発効条件を設定する。旧条約の効力が残る期間の行為を照合し、誰がいつ知ったかを別に検査する。

## 6 管理先と今回の完了範囲

[統合案](GETENROKU_INTEGRATION_V1.md)の§10と§15 D4、[従属の引き継ぎV-8](GETENROKU_HANDOFF_D3_D4.md)、[バックログ](../References/GETENROKU_BACKLOG.md)のG-B6・G-C5・G-D4へ接続する。進捗表ではBD-46・50の残りと資料根拠へ追加し、他の管理枠を増やさない。

将来の実装完了は、接近から新しい関係での最初の履行までを通常入口とNPCの双方で動かし、上の代表例外を検査できること。今回は出典・既存仕様への接続・遊べる一巡・情報と表示・確認条件の文書化まで。ゲームコード、保存形式、実装済みの欄、達成率、60枠・170件、NpcPurposeV1と凍結基準は変更しない。Coreの全件テスト、保存の実動作試験、ゲーム画面の検査は未再実行。

旧主の許可を全離脱の絶対条件にする規則、主家変更に伴う全員・全資源の自動移転、旧契約の自動消滅、新主による全債務引受けは追加しない。こうした新しい根本方針が必要になった場合だけ、A/B/Cを一件提示して相談する。

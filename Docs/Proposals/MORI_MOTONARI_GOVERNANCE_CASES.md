# 毛利元就研究 家中再建における申立てと履行

2026-11-05。既存採用仕様を、実装時に試せる一巡へ具体化する資料。新しい根本方針の採用やゲーム実装の完了を意味しない。

有力家臣を処分しただけでは、残る家臣の要求や統治上の案件は解決しない。今回は「家臣が恩賞・給付について申し立て、主君側が判断し、実際に履行する」流れに絞る。申立てを新設するのではなく、既存の勲功・顔・評定・契約・配送・実物の会計をつなぐ。

## 2 恩賞の期待と成立済みの給付義務

| 種類 | 照合するもの | 申立てを受けたときの扱い |
|---|---|---|
| 働きに対する恩賞への期待 | 任務、報告、主君が知る功績、評価通知、既に受けた恩賞 | 評価や論功行賞を求められる。ただし勲功や不満だけから、一定額の金銭債務を自動生成しない |
| 約束済みの扶持・報酬等の未履行 | 義務の原本・版、当事者、量・期限・条件、支給と受領の事実 | 有効な義務に従って履行を確認する。期限変更・分割等が元の条件にない場合、必要な当事者の合意なしに変更済みとしない |

将来の恩賞を具体的な条件で約束済みなら、名称が「恩賞」でも成立済みの義務として原本を確認する。「扶持だから必ず家の債務」と一律にせず、支払う主体は既存の原本に従う。

新しい誓約に署名しただけでは、未確定の期待を確定債務に変えない。旧義務を消さず、他の家臣を保証人・連帯債務者にもしない。

## 3 最低限遊べる一巡

前提は、申立人、取次候補、権限のある判断者、会計・運搬担当が世界内に存在すること。評定や重臣という名称だけで新たな権限を付与しない。正式な当主と実際の権限者が違う場合も、既存の役職・委任・契約で判断者を決める。

| 段階 | 本人が選ぶこと | 次へ渡す結果と保留するもの |
|---|---|---|
| 申立て | 面会・書状で直接伝える／重臣に取次ぎを頼む／評定へ案件を持ち込む | 本人の主張と提示した根拠。依頼しただけで取次人の受諾や主君の認識は確定しない |
| 取次ぎ・受領 | 取次人は受ける・断る・追加資料を求める。評定への提示も権限・委任の範囲で行う | 届いて把握した人だけの知識。複数人の申立てをまとめても、本人に代わって条件変更へ同意したことにはしない |
| 判断 | 評価・履行を認める／根拠を照会する／条件変更を提案する／応じない | 判断と理由、必要なら新しい提案。判断者が否認しても、世界の実際の義務や過去の出来事は書き換わらない |
| 実行 | 権限のある者が原資・担当・受取先・期限を確認して支給や運搬を手配する | 引当・出納・運搬・実受領を区別する。手配や発送を履行完了にしない |
| 返答と再判断 | 家臣や取次人は、届いた返答と自分が知る履行状況から次の行動を選ぶ | 協力・再申立て・新しい交渉等へ接続する。支給だけで不満が全消去されず、未払いだけで別の軍役義務が消滅もしない |

申立てと支給処理の記録を分ける。主張の異なる案件を統合して消さず、同じ義務の複数申立てから同じ支給を二重実行しない。返答未着や証拠未着を、虚偽・有罪・無罪の確定と混同しない。

### 資源配分に迷う架空例

家の同じ蔵に自由に使える銭が120文ある。既知の出陣計画では100文を残したいが、別件の合意済み扶持40文が期限を迎えている。100文はこの例では計画上の必要額で、既に拘束された引当金ではない。金額は検査用で、歴史的な相場ではない。

- 40文を実際に支給すれば、同じ蔵の残りは80文になる。出陣の規模・時期・調達を考え直す必要が生じる。
- 20文を先に支給し、残り20文の期限変更を提案できる。相手が承諾するまでは元の条件が続く。20文の実受領があっても、残りまで履行済みにはならない。
- 応じず出陣を優先することも、物理的に可能な範囲では選べる。その判断と実際の不履行を残すが、家臣の反応や処分を自動で決めない。

別の家臣が「先の戦で働いたのに恩賞がない」と訴えた場合は、同じ窓口で扱えても、まず既知の働きと評価の問題として扱う。40文の未払いと同じ債務を勝手に作らない。

ここでの面白さは、反対者を排除するだけでなく、残る家臣の要求、次の戦の準備、主君としての履行を限られた人と物で両立させる判断にある。中央集権度や全員共通の忠誠点を増やす操作には置き換えない。

## 4 実装へ渡す情報の対応

以下は既存の情報をどう結び付けるかの照合表であり、新しい独立エンジンや保存型を指定するものではない。実装時に既存の型・IDを確認し、重複する義務・在庫・時計を作らない。

| 情報 | 必要な参照・区別 |
|---|---|
| 申立て | 申立人、対象、期待か成立済み義務か、主張、根拠文書・出来事、発生時刻 |
| 根拠 | 契約原本と版、任務・評価通知・恩賞記録、支給や受領記録。証言と世界の事実を分ける |
| 取次ぎと権限 | 依頼先、受諾の有無、委任された範囲、誰の名で何を上申したか |
| 審議・返答 | 判断者、権限の根拠、その時点で知る証拠、判断理由、条件変更案とその承否 |
| 履行 | 元の義務・支給ID、原資の所有者と保管場所、担当者、量、引当、実移動、受取先と受領量 |
| 認識 | 発送・到達・開封／把握、本人の観測、報告の出所と時刻。受領の事実と主君が知る時刻を分ける |
| 保存と再開 | 未解決案件、提案の版、進行中の配送と引当、既に実行した支給を既存の保存へつなぐ |

画面には、本人が知る申立て・根拠・返答・実受領・残件と手応えを出す。相手の内心や未着の報告を確定情報として表示しない。NPCも、申立て・取次ぎ・判断・支給・再申立てを同じ制約で自ら選ぶ。反応の具体的な重みは既存のNPC工程に従い、本資料では新しい固定確率を採用しない。

## 5 実装時の確認用シナリオ

次の5件は既存範囲の検査例。固定の受入170件へ追加したものではなく、未実施である。通常の一巡と代表例外を対応工程で検査し、例外の全組合せはPROCESS_V2に従って後段へ回す。

| ケース | 条件と操作 | 確認する結果 |
|---|---|---|
| 通常の一巡 | 有効な40文の義務について、申立てが届き、支給判断・手配・実受領・返報まで進む | 同じ原資から40文だけ減り、受領先に40文が渡る。主君は返報等で把握するまで実受領を知らない |
| 期待と債務の区別 | 勲功はあるが金額の約束がない家臣が、同じ評定で恩賞を求める | 評価・論功行賞への案件になるが、申立てだけで40文等の確定債務を作らない |
| 一方的な延期 | 主君が20文を実支給し、残額の延期を提案する。相手はまだ未承諾 | 残る20文と元の条件を保持する。提案中と成立済みを混同せず、軍役等の別条項を自動解除しない |
| 再送と途中保存 | 同じ義務の申立てが再送され、支給の実行中に保存・復旧する | 主張・配送の履歴を保持し、同じ支給を二重実行しない。同じ入力から同じ続きになる |
| NPCと遠方の認識 | 役割をNPCへ置き換え、申立て・返答の片方を遅着させる | NPCが既知の内容で案件を扱う。未着の情報を使わず、未払いから離反・戦争・自動処罰へ飛ばない |

## 7項目のABCD比較
### ① コマンドの分類と階層
- **A**：身分ごとに全コマンドを別々に実装。例：城主兼奉行がメニューを切り替えられない。
- **B（推奨）**：共通5分類にコマンドIDを付け、行動別権限で表示状態を決める。例：国人は徴税を実行、主家全軍動員は申請として表示。
- **C**：全身分で全コマンドを合法実行。例：陪臣が大名の任官権を使用。
- **D：その他（自由記載）**。D選択項目のみ次のチャットで質問。
- **未確定詳細**：コマンドID・階層・検索・表示規則。

### ② 実行・申請・越権・不可の優先判定
- **A**：権限不足なら必ず不可にする。例：陪臣が直訴もできない。
- **B（推奨）**：合法実行→申請可能→越権試行可能→不可を候補として提示し、案件・状況で再評価。例：城主は全軍動員を申請でき、無断動員は別の危険行動。
- **C**：越権を選べば正規権限を自動獲得。例：陪臣の独断出陣で全軍が従う。
- **D：その他（自由記載）**。D選択項目のみ次のチャットで質問。
- **未確定詳細**：複数候補の同時表示・警告・優先順位。

### ③ 内政・軍事の緊急例外
- **A**：緊急でも全て上位命令待ち。例：奇襲されても籠城できない。
- **B（推奨）**：自衛・守備と、動員・遠征・開城を分け、緊急性と事後責任を評価。例：城主は即座に防衛できても他城への動員は別審査。
- **C**：緊急時に全ての権限を無制限に取得。例：城主が主家全城の開城を決定。
- **D：その他（自由記載）**。D選択項目のみ次のチャットで質問。
- **未確定詳細**：緊急性・兵力範囲・事後審査。

### ④ 外交・人事の申請と代理
- **A**：交渉・推薦だけで条約や任命が即時成立。例：陪臣の密約が主家の正式同盟になる。
- **B（推奨）**：嘆願・推薦・代理・正式決裁・追認を別案件として扱う。例：城主が家臣を推薦し大名の返書を待つ。
- **C**：大名以外は外交・人事の試行不可。例：国人が安堵嘆願や他家接触できない。
- **D：その他（自由記載）**。D選択項目のみ次のチャットで質問。
- **未確定詳細**：直訴・代理の有効期間・追認・期限。

### ⑤ 謀略・越権試行の表示
- **A**：謀略は権限がなければ非表示。例：陪臣の内通工作が選べない。
- **B（推奨）**：秘密行動の試行可否と正規権限を分離し、発覚・危険・認識情報をUIに反映。例：国人は独立工作を試せるが密偵の正体は表示しない。
- **C**：謀略を選択すれば必ず成功。例：離間コマンドだけで家臣が寝返る。
- **D：その他（自由記載）**。D選択項目のみ次のチャットで質問。
- **未確定詳細**：発覚確率・対象・情報秘匿・UI警告。

### ⑥ 兼任・解任・所属変更による再評価
- **A**：最初の身分で可否を固定。例：国人が大名になっても任命できない。
- **B（推奨）**：役職・管轄・委任・有効期間・所在地を行動ごとに再判定。例：奉行解任で徴税権を失うが城主の防備権は維持。
- **C**：兼任すると最高役職の権限を全行動に拡張。例：城主兼奉行が主家全軍を指揮。
- **D：その他（自由記載）**。D選択項目のみ次のチャットで質問。
- **未確定詳細**：途中命令・権限取消の同時刻境界。

### ⑦ コマンド実行後の状態と結果表示
- **A**：選択時に全結果を即時公開。例：内通の成否が使者到達前に表示。
- **B（推奨）**：受付・伝達・実行・部分達成・失敗・報告・認識を分ける。例：徴税が半分しか集まらず報告到達後に判明。
- **C**：実行後の状態は一切表示しない。例：委任普請の進捗を確認できない。
- **D：その他（自由記載）**。D選択項目のみ次のチャットで質問。
- **未確定詳細**：結果通知・進捗UI・再試行・補償。

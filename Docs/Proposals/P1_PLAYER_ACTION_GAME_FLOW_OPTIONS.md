# P1 プレイヤー行動・ゲーム進行：7項目のABC比較

**状態：Proposals／2026-10-18。** 7項目すべてユーザーがB案を優先検討として選択済み。具体的な操作方式・例外は未確定。P0基本原則を前提に、プレイヤーが実際に指示・交渉・委任する体験を検討する。

## ① プレイヤーの立場と操作主体
- **A**：勢力単位を直接操作。例：大名を選ぶと全家臣の行動を直接決める。
- **B（推奨）**：武将個人を操作主体とし、身分・役職・所属・実効権限に応じて行動可能範囲を変える。例：国人領主は自身の所領を経営できても、主家全軍には直接命令できない。
- **C**：地位にかかわらず全機能を自由操作。例：陪臣が将軍の任官を直接決定できる。
- **保留する詳細**：プレイ開始時の身分範囲、当主交代後の操作継続、捕縛・死亡時の操作移行。

## ② 行動権限と命令の成立
- **A**：UIで選択できれば必ず実行。例：城主が管轄外の城で徴税を即時実行。
- **B（推奨）**：行動提案・権限審査・相手への伝達・実行・結果を分離し、拒否や不履行も許す。例：家臣への出陣命令が有効でも、未達ならまだ出陣しない。
- **C**：権限が不足する行動は常に選択肢から完全削除。例：越権命令や独立工作の試み自体ができない。
- **保留する詳細**：越権行為の試行可否、UIの警告、権限衝突、行動ごとの必要権限。

## ③ 行動指示と複数行動
- **A**：武将は常に一つの行動しかできない。例：使者派遣中は報告閲覧も不可。
- **B（推奨）**：主行動・補助行動・委任行動を区別し、競合する時間・資源・権限を検査する。例：城の普請を委任しつつ書状を確認する。
- **C**：全行動を無制限に同時実行。例：同じ武将が複数の城で同時に軍勢を直接指揮する。
- **保留する詳細**：併用可能表、行動枠、費用、長期行動の中断・引継ぎ。

## ④ 世界時間・停止・割込み
- **A**：プレイヤーの操作ごとに全国を一律1ターン進める。例：書状を読むだけで全軍が1日進軍。
- **B（推奨）**：共通世界時刻の自動進行と任意停止を基礎候補とし、緊急通知・期限・合戦に応じた停止条件を別途定める。例：遠方で合戦中も使者は移動し、緊急報告を受けて停止する。
- **C**：プレイヤーが停止中も世界を強制進行。例：重要書状を読む間に返答期限が切れる。
- **保留する詳細**：自動進行の正式採否、速度段階、停止対象、複数合戦との同期。

## ⑤ NPC交渉と書状・対面
- **A**：交渉コマンドを押すと結果が即時確定。例：遠方の大名に同盟を申し込んだ瞬間に返答。
- **B（推奨）**：提案・使者／対面・到達・相手の認識・検討・返答・履行を段階管理。例：国人が安堵を要求し、主君の返書を待つ間も世界が進む。
- **C**：交渉は必ず対面だけ。例：遠方の主君への書状交渉が不可能。
- **保留する詳細**：交渉の費用・所要時間、返答期限、代理交渉、交渉決裂の扱い。

## ⑥ 委任とNPCの裁量
- **A**：委任した行動は常に命令通り成功。例：忠誠の低い家臣でも必ず徴税を完遂。
- **B（推奨）**：委任範囲・資源・期限・報告義務を設定し、受任NPCは能力・忠誠・認識情報から実行を判断する。例：奉行に徴税を委任しても災害を認識した奉行が延期を提案。
- **C**：委任するとプレイヤーは一切介入不可。例：軍勢の委任後は撤退命令を送れない。
- **保留する詳細**：委任権限の再委任、途中取消、報告頻度、裁量逸脱・責任。

## ⑦ 行動結果・失敗・プレイヤー通知
- **A**：命令時点で成否をすべて公開。例：偽書の真偽や敵の内応まで画面に表示。
- **B（推奨）**：実際の結果・相手の反応・報告到達・プレイヤー認識を区別し、失敗・遅延・誤認を表示できる範囲で通知する。例：独立工作が失敗しても、使者が戻るまで失敗を知らない。
- **C**：失敗も進捗も一切通知しない。例：委任先が離反しても履歴を確認できない。
- **保留する詳細**：通知重要度、未開封書状、失敗理由の開示範囲、ログと操作導線。

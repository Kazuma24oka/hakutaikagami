# P0同時刻イベント：境界・優先順位の詳細ABC比較

**状態：未確定（Proposals）／2026-10-17。** 5項目はABC未選択。Bは推奨候補。確定済みの共通世界時刻、因果・効力・依存関係を考慮する原則は変更しない。

## 1. 期限ちょうどの返答
- **A**：期限時刻と同じなら無効。例：15時期限に15時到達した返書は失効。
- **B（推奨）**：案件別の発送・到達基準を先に確認し、期限ちょうどは原則有効とする。ただし案件固有の失効条件を優先。例：15時までの案件では15時ちょうどの返答を受理。
- **C**：期限後も猶予を設ける。例：15時期限でも15時5分まで受理。
- **未決定**：時刻精度・失効条件・条約成立。

## 2. 権限取消と代理受領
- **A**：取消を常に優先。例：取消を知らない使者の受領も無効。
- **B（推奨）**：取消の効力・受領成立・相手方認識・追認を分けて判定。例：取消と受領が同じ時刻なら双方の効力と相手の認識を確認。
- **C**：受領を常に優先。例：失効済みでも同時刻なら無条件有効。
- **未決定**：善意保護・追認遡及・越権責任。

## 3. 同時刻イベントの処理順序
- **A**：登録順だけで処理。例：先に登録された落城で援軍の効果が消える。
- **B（推奨）**：同時刻の候補を収集し、因果依存を解決してから競合する状態更新を判定。例：落城と援軍の成立条件を照合して城の状態を更新。
- **C**：乱数で先後を決定。例：条約承認と失効の先後を抽選する。
- **未決定**：循環依存・確定タイミング・再実行防止。

## 4. 二重徴税と在庫引当
- **A**：請求額をすべて満額出庫。例：米100俵に各80俵の請求で160俵出庫。
- **B（推奨）**：有効な引当・残量・取引履歴を確認し、同時刻競合を別途裁定。例：米100俵から合計100俵以内を配分し不足分を別管理。
- **C**：最初の請求者が在庫と徴税権を全取得。例：先に請求した大名が全ての権利を取得。
- **未決定**：引当優先度・部分徴収・不足債務。

## 5. 落城・開城と援軍到着
- **A**：落城を常に優先。例：城門に援軍が来ても救援不能。
- **B（推奨）**：開城合意・占有移転・降伏・援軍の交戦可能時点を分離。例：城門引渡し前なら援軍が介入できる場合がある。
- **C**：援軍を常に優先。例：引渡し後でも援軍到着で落城を取り消す。
- **未決定**：占有移転の効力・戦闘時間換算・城内分裂。

# 毛利元就研究 配下の攻撃と主君の責任

2026-11-05。既存の条約・従属・委任・認識の仕組みを、和睦後の局地的な攻撃へ接続する具体化資料。主君の一律の連帯責任や免責を新設するものではない。

和睦を守りたい当主と、旧領回復や報復を望む国人の利害が食い違う。配下をかばえば相手との和平が危うくなり、強く処分すれば家中の協力を損なうことがある。その板挟みを、実際の行為、各人の権限と約束、知っている証拠に基づく判断として遊べるようにする。

## 1 出典と既存仕様

研究の入口は [第二十九話・毛利元就と足利義輝](https://www.youtube.com/watch?v=A9h446sIYP0)。動画本文は未取得・該当時刻は未特定である。今回は前回と同じ島根県公開の講座別添、PDF2頁の史料11を再照合した。元就・隆元が福屋に関連する再乱を挙げ、和平を続けられないと説明する書状であり、中立的な違反裁定や主君の監督義務を定めた文書ではない。

[研究台帳のM29](../References/MORI_MOTONARI_RESEARCH.md)に、転載翻刻の典拠と確認範囲を記録する。宛所、具体的な命令系統、和平条項、責任の既定値をこの史料から補わない。以下は既存仕様から作ったゲーム用の架空例で、福屋の主従関係や行動を確定した史実再現ではない。照合基準は作業ブランチ 9a67e6109d67f6fff69cf4917e58fad3385c8083。

| 接続先 | 引き継ぐ境界 |
|---|---|
| BD-41・42、G-D4 | 条約の当事者・対象・版・効力、条項照合による不履行と本人の認識、解除意思と解除効力を分ける |
| BD-10・29・30・32、CC-06・11 | 行為別の権限、任務の禁止・許可、通知と必要認識。委任者の監督責任と担当者の故意・過失は別評価 |
| BD-48・50、統合案§15 D4・§16 H3 | 国人の家、主家との条項、実際の指揮委任、自治の留保を分ける。所属だけで無制限の命令権を作らない |
| BD-25・26・56・58、CC-08 | 行為・証拠・当事者の説明・各人の判断を分ける。NPCも未到達の情報を使わない |
| 家法承継の決定§2・中央仲裁の具体化 | 新条件の拒否と既存義務の不履行、訂正と過去の結果、仲介と裁定・保証を分ける |

BD-30には既に委任者の監督責任がある。ただし、委任のない全主従関係へ同じ監督義務を広げたり、配下の全損害を主君へ無条件に付け替えたりしない。必要な責任の根拠は、実際の委任、既存の条約・家法・制度、通知等の義務から照合する。

## 2 責任を調べるときに分けるもの

| 確認対象 | 確認する内容 | 避ける混同 |
|---|---|---|
| 現地の行為 | 誰のどの部隊が、いつ、どこで、誰に何をしたか。損害・占有の変化も残す | 所属表示だけから命令者や黒幕を確定する |
| 命令と関与 | 実際の命令・委任・支援等と、その時点の権限、到達・認識、実行との関係 | 「家臣が行動した」だけで主君の密命があったことにする |
| 家同士の義務 | 甲家・乙家のどちらが、誰・どの部隊や地域・どの行為について約束していたか | 主君が直接命じていないという理由だけで、家の有効な義務も無違反にする |
| 国人・隊長自身の義務 | 本人の条約、従属条項、適用される家法、委任・命令と自治留保 | 主家の対外条約の対象に名前を書いただけで、第三者本人の義務を新設する |
| 委任者の監督・通知 | 当該任務の委任範囲、禁止・許可、報告、取消・変更の通知等の既存条件 | 担当者の故意・過失と委任者の監督責任を一本の点数にする |
| 証拠と責任判断 | 何を見たか、誰の説明か、いつ誰に届いたか、各主体が何を信じどう判断したか | 抗議書の到達を、書かれた非難が客観的に正しいことと同一視する |

条約の「義務を負う当事者」と「保護・禁止の対象になる人や地域」は同じではない。主家の代表が家を拘束できる範囲は既存の代表権で判定し、全構成員の個別同意を一律に追加しない。一方、別家の国人を拘束するなら、その根拠となる従属条項・委任・適用手続を確認する。

主君が自分の家について有効に負った義務と、第三者へ命令できる権限も別である。「国人を動かせなかった」という事情だけで、自分が有効に引き受けた義務を取り消さない。逆に、外に約束しただけで国人への新しい権限が生まれるわけでもない。

## 3 同じ攻撃でも判断が変わる場合

| 場合 | 条項・行為の照合 | 人物が判断すること |
|---|---|---|
| 主君の攻撃命令で、対象部隊が停戦に反する行為を実行した | 命令と実行、条約の有効範囲を別々に記録する。命令しただけの未実行と実害も分ける | 命令・実行の証拠を知る各人が責任を評価する。知らない密命を画面やNPCに漏らさない |
| 対象部隊の隊長が、認識済みの有効な停止命令に背いて攻撃した | 隊長の命令違反と、家が負う停戦義務、当該委任の監督責任を別に照合する | 主君の直接指示を自動認定しない。隊長の独断だけを理由に家の義務を自動免責しない |
| 停戦や取消の知らせが届かず、旧命令で攻撃が続いた | 攻撃の事実と、条項の効力・通知条件、本人の認識、通知する側の義務を照合する | 「知らなかったから全部無違反」「結果が同じだから全員同じ処分」のどちらにも固定しない |
| 自治を持つ別家の国人が、自分の判断で攻撃した | 国人自身の義務、主家との従属条項、当該軍の指揮委任、主家自身の対外義務を確認する | 主家所属だけで義務を自動拡張しない。相手が主家の関与を疑い抗議することはあり得る |
| 誤報・敵の偽装・食い違う証言がある | 実際の行為と各証拠を別に保持し、不明な点を確定しない | 人物は得た証拠で判断する。後の訂正は追加記録とし、先に生じた処分・損害を消さない |

「違反を確認できていない」は「違反がなかった」と同義ではない。反対に、人物が違反だと信じていても、それを世界の事実へ上書きしない。相手は不信や利害から抗議・交渉・開戦を判断できるが、システムがそれを自動的に正当な報復・権利取得へ変換しない。

主君が後から配下の行動を評価・追認しても、過去に存在しなかった事前命令を作らない。追認や援助は、その時点の新しい行為として既存条件に照らして扱う。和平破棄の意思表明、通知、解除効力、実際の攻撃も別のまま保つ。

## 4 最低限遊べる一巡

### 架空の場面

甲家と乙家の間で停戦が発効している。甲家に従属する国人Xが乙家側の拠点を攻撃した、という抗議が届く。Xは甲家の軍事力を支える有力者で、「旧領を取り返した」「先に攻撃された」と弁明する。乙家は甲家の関与を疑っている。

検証用の開始状態として、甲乙の条約の対象・効力、甲Xの従属条項と自治留保、Xへの指揮委任の有無、適用される家法、命令・通知の実際の経過を定義する。画面とNPCへ渡すのは、その人物が知る内容だけとする。最初から「Xは裏切者」「甲当主は無罪」といった世界共通の結論は持たせない。

| 段階 | 取れる行動 | 残る結果 |
|---|---|---|
| 抗議と現地報告を受ける | 書状を開く、現場とXへ事情を照会する、証拠を集める任務を出す | 主張・損害・時刻・出所、本人が知る情報。証拠待ちの間も世界の時間は進む |
| 拡大を止める | 有効な権限内で停止・撤退等を指示する。権限外なら協力を求め、条件を交渉する | 指示・依頼の種類、権限、発送・到達、実際の服従。緊急を理由に新しい強制権を作らない |
| 家中で判断する | 届いた報告と原本から、委任・命令・義務・監督を調べ、追認・叱責・権限内の処遇等を判断する | 功績と違反、本人の説明と責任判断、処遇の根拠。処刑・改易・離反は自動化しない |
| 相手と交渉する | 証拠と講じた措置を説明する、調査継続を申し入れる、必要なら補償・条件変更を提案し、取次へ相談する | 相手の承否、追加の約束と期限、既存条約の存否。抗議だけで新しい補償債務を作らない。既存条項の発動条件を満たした給付義務は保持し、実支出は別に手配する |
| 措置を実行し返報する | 撤退、合意した物の引渡し等を手配し、実行・受領・報告を確認する | 現地の実結果、資源と費用、残った争点、各人が把握したこと |

停止の手配と調査は、権限と人手がある範囲で並行できる。全ての責任が確定するまで現地に何もできない直列処理にはしない。ただし、調査命令だけで証拠を取得済みにしたり、停止命令の発送を停戦履行済みにしたりしない。

### プレイヤーが悩むこと

- **和平を優先してXを抑える**：必要な権限と実力を確かめて止める。Xが不満を持ち、軍事協力や他家との関係に影響する可能性があるが、自動離反にはしない。
- **Xの言い分を調べ、乙家へ交渉する**：不当な処分を避けられる可能性がある一方、調査中の被害や乙家の不信が増えることもある。証拠が揃えば必ず全員が納得する仕組みにはしない。
- **自分の負担で和平維持を図る**：自家の権限・資源で実行できる措置や条件を提案する。Xの私財を無断で取り上げて補償原資にせず、交渉しただけで既存の責任や損害を消さない。

Xへの新しい外交制限や自治縮小を求めるなら、既存権限・必要手続・条項改定へ接続する。新条件の拒否を旧契約違反にせず、今回の事件を口実に無制限の徴発・没収権を追加しない。有効な既存の命令・家法への違反まで、新条件の未合意を理由に消すこともしない。

## 5 実装へ渡す情報と表示

新しい「主君責任値」を一つ作るのではなく、既存の原本・命令・任務・証拠・本人認識を参照して結ぶ。

| 情報 | 最低限必要な区別 |
|---|---|
| 事件と行為 | 事件ID、行為ID、行為者・部隊・所有者・現地指揮者、対象・時刻・場所・結果 |
| 関係と関与 | 行為時点の家・主従・役職、命令・委任・支援の原本と版、有効期間・許可範囲、到達・認識 |
| 義務の照合 | 条約・家法・任務の原本、義務を負う者、対象、履行条件、期限、通知・例外。各違反候補を根拠へ結ぶ |
| 証拠と主張 | 観測・報告・抗議・弁明、出所、観測時刻と取得時刻、何を誰の関与と主張しているか、訂正の参照 |
| 判断と実行 | 判断者が知る証拠、認定・保留・処遇、交渉条件、命令と実行結果、費用・実受領 |
| 認識と保存 | 誰がいつどの証拠を知ったか、配送・再送・報告の同一性、進行中案件、既存の保存・再現規則 |

画面例は「乙家からXの襲撃について抗議／Xの弁明を受領・開封済み／甲当主の指示を示す証拠は未入手／停止指示は到達未確認（返報待ち）／補償案は未合意」。本人に未確認の命令者や、配下の本当の動機を確定表示しない。開封済みの報告も、内容が真実と確認されたことにはしない。

[WorldEngagement.cs](../../Core/Contracts/WorldEngagement.cs)では、実在部隊・指揮・命令を交戦処理へ渡す構造を確認した。ただし、そのシミュレーション用の世界状態を本人向け画面やNPCへ直接渡さない。交戦処理や既知の不侵略の制御が存在することを、今回の一般的な責任審査・国人の従属関係が実装済みという根拠にしない。

## 6 実装時の確認用シナリオ

以下の5件は既存範囲の検査例。固定の受入170件へ追加したものではなく、未実施である。例外の全組合せはPROCESS_V2に従って後段へ回す。

| ケース | 条件と操作 | 確認する結果 |
|---|---|---|
| 事件から交渉・履行まで | 対象・義務が明示された停戦下で攻撃が起き、抗議・調査・停止指示・家中判断・相手との交渉・実履行を行う | 行為、主張、条項照合、責任判断、実措置を分ける。本人が知る根拠と権限で進み、自動制裁しない |
| 独断と委任者の責任 | 認識済みの有効な停止命令に背く隊長と、その任務を委任した主君を扱う | 担当者の故意・過失、委任者の監督、家の対外義務を別評価。独断を密命にせず、家の義務も一律免責しない |
| 取消の通知遅延 | 条約の発効、取消の発送・到達、本人の認識、攻撃の時刻をずらす | 条項の通知条件と通知義務を照合。知らない取消を警告で漏らさず、不知だけで全面免責・同一処分にしない |
| 自治を持つ国人 | 直属部隊の場合と、別家の国人で従属条項・指揮委任が異なる場合を比較し、新しい制限も提案する | 所属だけで義務を広げず、正当な代表権は維持。新条件の拒否と既存違反を区別し、主家自身の義務も別に残す |
| NPC・食い違う報告・保存 | 異なる証拠を持つNPCに判断させ、遅着の訂正・再送・途中保存からの復旧を行う | 誤認と訂正を残し、既発生の損害や処分を消さない。同じ入力から同じ続きとなり、処遇・支払いを重複させない |

通知遅延の検査では、例えば「停戦発効は検証開始3日目の正午」「甲当主が負う停止通知は2日目夕刻までの所定窓口への適法な到達が条件」「実際の到達は4日目」「攻撃は3日目午後、隊長は旧命令だけを認識」という入力を固定する。対象部隊の停戦に反する行為、甲当主の通知の不履行、隊長の認識を別々に記録する。比較では到達だけを2日目へ早め、開封・認識の経過も別入力として変える。到達だけで認識済みにせず、認識の遅れの原因・義務もその例の条件で審査する。これは検査用の仮条件で、全停戦への通知期限・履行基準・免責規則の追加ではない。

## 7 管理先と今回の完了範囲

主な管理先はG-D4／BD-42・50。監督と処遇は既存のBD-30・32、対外的な仲裁はG-D7／BD-56、情報とNPCはBD-25・26・58へ接続する。[人質と従属の引き継ぎ](GETENROKU_HANDOFF_D3_D4.md)のV-7と、[中央仲裁](MORI_MOTONARI_CENTRAL_MEDIATION.md)の現地事件を具体化し、重複する機能枠は作らない。

将来の実装完了は、抗議を受けて実際の措置と報告まで進む一巡を、通常入口とNPCの双方で動かし、上の代表例外を検査できること。今回完了するのは接続・表示・確認条件の文書化である。ゲームコード、保存形式、実装済みの欄、達成率、60枠・170件、現在のNpcPurposeV1と凍結基準は変更しない。

今回は資料のみ。Coreの全件テスト、保存の実動作試験、ゲーム画面の検査は未再実行。

主従関係だけで生じる一律の監督義務、全損害の自動連帯責任、配下独断時の主君の一律免責、全事案に共通する処罰や補償の既定値は新設しない。こうした新しい根本方針が必要になった場合だけ、A/B/Cを一件提示して相談する。

# 全国マップ・城・領地システム：統合設計案

**状態：未確定（Proposals）／2026-10-17。** 既存のユーザー選択B案を統合した優先参照先。数値・地理資料の採否・実装範囲は未決定であり、確定仕様へ昇格しない。

## 1. 地理構造と史実資料
- 全国勢力図→旧国・郡→城・村落・所領へ段階的に詳細表示する案。
- **旧国・郡の地理区分**、**所領の空間範囲**、**政治的な勢力支配境界**は別管理。所領が複数郡にまたがる可能性を残し、表示階層を厳密な包含関係と同一視しない。
- 年代別の地理境界・呼称を史実資料に基づいて扱い、資料不足・異説の箇所は推定と明示する。
- 出典・対象年代・信頼度・異説・推定理由を記録する案。史料自体の確からしさと、ゲーム内人物が報告を信じる度合いは別。

## 2. 城・館・砦・港・寺社・村落
- 城を軍事・行政の主要拠点とし、館・砦・港・寺社・村落などを機能と重要度に応じて管理する。全施設・全村落の網羅は前提にしない。
- 各拠点に主機能＋副機能を持たせ、軍事・経済・交通・宗教・行政の機能を複数組み合わせる案。
- 設備・規模・政策・歴史的出来事によって機能が発展・衰退する。全拠点が同じ機能に無条件で成長するわけではない。
- 拠点の機能変化と、城主職・知行収益権・領有権・実効支配の変化は別判定。寺社や港の固有の権益も表現できる余地を残す。

## 3. 所領・知行・領有権と徴税
- **領有権の主張／知行収益権／城主職／現地の実効支配**を分離し、複数勢力の主張が重なる係争状態を認める。
- 正式な徴税権を持つ者、実際に徴収する者、収益の最終受取人を別管理。権利主張だけで収益や支配が自動移転するわけではない。
- 実効支配・権利・在地勢力の服従状況・軍事力・交渉を踏まえ、徴税可否・実収益・配分・二重徴税・未納・抵抗などを判断する案。
- 同じ生産物を二重計上せず、知行収益・俸禄・債務の会計と整合させる。

## 4. 国人衆・在地勢力
- 国人衆は独自の所領・家臣・軍事力を保持し、大名に従属しつつ自立性を維持できる案。
- 主従・従属・同盟・軍事指揮・年貢・人質などの関係を同一の所属フラグに押し込めない。
- 在地勢力は支配変更や徴税、開城・内応・離反に影響し、独自の利害と情報認識に基づいて判断する。

## 5. 交通・補給と帰属変更
- 道路・峠・河川・海路の接続、距離・地形・季節から移動時間・補給難度を算出する方向で検討。個人・軍勢・使者で条件が異なり得る。
- 落城や独立宣言だけで周辺領地を一括移転しない。城の占有・守備兵・城主・在地勢力・周辺所領の実効支配を個別更新する。
- 交渉・開城・内応・戦闘など複数経路で支配が変化する。城主職と実際の占有、正式な権利と支配の変化は別。

## 6. 地図上の情報
- 全国勢力色分けの確定構想は維持し、**主人公が把握している勢力状況**を表示する案。未確認・古い・矛盾する情報を区別する。
- 世界の実際の状態と、個人が認識する報告・噂・目撃・地図情報を分離。遠方で起きた支配変更を即時に公開しない。
- 史料信頼度（開発用）と報告信用度（ゲーム内）は別。一般的な地理知識の初期公開範囲は未決定。

## 7. 重複・表現差の整理
| 論点 | 統一した解釈 |
|---|---|
| 旧国→郡→所領という表示階層 | 表示上の階層。所領の地理的包含を厳密に固定しない |
| 年代別境界と勢力支配の変動 | 地理境界・政治境界・権利範囲を分離 |
| 拠点の種類と主副機能 | 拠点の分類と機能を別管理。機能は複数かつ可変 |
| 城主と領主 | 役職と土地・収益権を分離 |
| 領有権と徴税実績 | 権利主張、徴収行為、実収益・配分を分離 |
| 落城と領地帰属 | 城の占有変更が周辺領地の一括移転を意味しない |
| 全国勢力色分けと情報遅延 | 実際の勢力図ではなく、本人が把握する状況を原則表示 |
| 史料の確度と噂の確度 | 開発用の出典信頼度とゲーム内の認識を分離 |

**整合性確認**：Confirmed/GAME_CONCEPT.md、Confirmed/INFORMATION_SYSTEM.md、Proposals/CHARACTER_SOCIAL_SYSTEM_CONSOLIDATED.md、Proposals/ACTION_TIME_SYSTEM_CONSOLIDATED.md と直接矛盾する基本方針は見当たらない。ただし実装上の例外・収益配分・境界精度等は未解決であり、解決済みとみなさない。

# 在地社会システム：統合設計案

**状態：未確定（Proposals）／2026-10-17整理。** ユーザーが選択したB案を統合した優先参照先。未承認の詳細・数値・実装方式を確定させない。

## 1. 共通組織基盤と固有機能
- 国人衆・寺社勢力・村落共同体には、構成員・代表者・有力者・財源・所領との関係・対外関係・権限・情報保有などの共通組織概念を用意する案。
- 国人衆は家臣・軍役・従属交渉、寺社は宗教的権益・宗派・人脈、村落共同体は生産・共同意思決定・負担交渉など固有の機能を持つ。
- 組織と拠点を分離する。寺社施設＝寺社組織、村落の位置＝村落共同体、国人衆＝大名直属家臣とは限らない。
- 組織ごとに代表者決裁・有力者協議・合議など意思決定方式を変える。決議の成立、個々の構成員の認識、服従、実行は別の状態。

## 2. 国人衆の自治・従属・離反
- 国人衆は独自の所領・家臣・軍事力を維持しつつ、大名へ従属できる案。
- 軍役・年貢・外交・人事の権限と義務を別管理し、従属だけで自治が全消滅しない。
- 安堵・軍事保護・婚姻・人質・恩賞・在地利害・周辺情勢を考慮して交渉・従属・離反を判断する。
- 従属契約と忠誠、正式な所領権利と実効支配、軍事指揮と主従関係を混同しない。

## 3. 組織内対立・派閥
- 代表者・有力者・合議による組織決定に反対する派閥は、異議申立て・不服従・離反などを選択できる案。
- 決議の有効性、反対派の認識、個人の服従、組織の分裂、制裁を別に扱う。決議成立だけで全員を自動服従させない。
- 派閥の支持者、所領・軍勢の帰属、異議の手続、決議の拘束力は未決定。

## 4. 寺社勢力と権益交渉
- 寺社勢力の所領・権益・人的ネットワーク・政治的影響力・必要に応じた武装力を区別する。すべての寺社が武装するわけではない。
- 所領安堵・課税免除・通行権・宗教的権益・政治的介入などを要求できる案。
- 対応は一部承認・条件付き安堵・代替補償・拒否などに分岐。要求、合意の効力、権利の正式承認、実際の履行を別判定する。
- 反発は不満・嘆願・経済的抵抗・支援拒否・武装化などに変化し得るが、固定順序ではなく、急激な悪化や交渉による沈静化もあり得る。

## 5. 一揆の発生・拡大・終結
- 年貢・飢饉・戦乱・徴発・地域共同体・指導者・権力関係などから発生可能性を判断する案。
- 一揆を農民の暴動だけに限定しない。土一揆・国一揆・一向一揆等は構成員・目的・地域・宗教的背景・時代に応じて区別する。
- 指導者・地域連携・利害・情報伝達によって拡大・分裂・停滞・交渉・終結・再燃し得る。
- 対応は交渉・減免・救済・調停・懐柔・軍事鎮圧など。短期的鎮静化と長期的な反発・信頼を別々に評価する。
- 自発参加・説得・圧力・強制動員を区別。参加・動員・目的への賛同・忠誠は同一ではない。拒否・逃散・中立・離脱も検討対象。

## 6. 在地勢力の連携
- 国人衆・寺社・村落等は、利害・信仰・血縁・地域・軍事保護に基づいて一時的な連合・対立・協力を行える案。
- 連合の意思と参加組織・個人の意思を分離し、参加だけで全組織の権限・所領・知識を一体化しない。
- 指導者、共同軍事指揮、交渉権限、脱退・分裂・内部対立は未決定。

## 7. 既存設計との整合性
| 論点 | 統一した解釈 |
|---|---|
| 国人衆の従属と自治 | 軍役・年貢・外交・人事の権限を個別管理 |
| 寺社・村落と組織 | 施設／地理的拠点と、社会的組織を分離 |
| 組織の決議と服従 | 決議が成立しても、反対・不服従・離反はあり得る |
| 寺社の反発段階 | 段階変化は候補だが必ず順番に進まない |
| 寺社の要求と権利 | 要求・合意・正式な権利・実効支配・履行を分離 |
| 一揆と武装蜂起 | 一揆は共同の結束・行動も含み、武装は必須でない |
| 一揆参加と動員 | 自発的賛同・説得・圧力・強制と実参加を分離 |
| 連合と構成員の認識 | 組織が情報を得ても構成員全員が知るわけではない |
| 税負担と所領権利 | 年貢・徴発・免除の権利と実際の徴収を分離 |

## プレイヤー操作対象の補足（2026-10-17、既存構想との整合確認）
- プレイヤーの操作主体は**武将個人**。国人領主や国人衆に属する武将はプレイヤーになり得る。国人衆をNPC専用組織として固定しない。
- 国人衆に属するプレイヤー武将も、自治・軍役・年貢・外交・人事・従属交渉・離反など、身分と権限に応じた行動を取れる方向で検討する。
- 寺社勢力・僧侶を主体とするプレイ、農民・村落共同体を主体とするプレイは対象外とするユーザー意向。ただし寺社・農民はNPCとして政治・経済・社会・軍事に作用する。
- 寺社や農民のNPC行動が存在することは、その主体をプレイアブルにすることを意味しない。
- 個々の武将が国人衆を率いる場合と、国人衆の内部に所属する場合の操作権限・組織内地位・家督継承は引き続き未決定。Confirmedとmainは変更しない。

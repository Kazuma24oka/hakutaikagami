# 知行替えと移封の実行

2026-11-05。既存採用仕様の具体化。所領を組み替える決定から、旧地の引渡し、人・兵・荷物の移動、新地での初回統治までをつなぐ。家督や主家の変更とは分け、新しい処分権・移封の成立条件・実装順は追加しない。

## 1 出典と今回の範囲

[研究台帳](../References/MORI_MOTONARI_RESEARCH.md)M17・M19の継承・家中再編を入口とする設計上の派生である。以下の移封条件・人物・拠点は架空であり、動画や史料で確認した個別の移封事例ではない。動画本文の該当時刻は未確認。

仕様の根拠は[統合案](GETENROKU_INTEGRATION_V1.md)§26 Z9、§16 H2・H3と[改革の段階導入](../Decisions/2026-11-05_REFORM_ROLLOUT_UNITS.md)。家督交代・隠居は[継承と引継ぎ](MORI_MOTONARI_SUCCESSION_TRANSFERS.md)、主家変更は[従属先変更](MORI_MOTONARI_ALLEGIANCE_CHANGES.md)を参照し、ここで再定義しない。

## 2 権利と実行を分ける境界

| 対象 | 保持する区別 | 既存の管理先 |
|---|---|---|
| 移封要求と手続 | 有効な権限内の命令、必要な条件改定、越権の試行。受領・判断と履行完了は別 | G-K9・G-H3、BD-50、H3 |
| 城と知行 | 城主職、地域収益権、城門・本丸の実占有、周辺統治。任命や安堵だけで全てを取得しない | BD-34・47・48、CC-03 |
| 人と物の移動 | 本人・家族・家臣・部隊それぞれの所在、移動根拠、指揮権。財産の所有・保管・引当・運搬・実受領 | BD-30・48、CC-04・06・11・14 |
| 残る義務と認識 | 元の当事者・原本・期限・部分履行、通知・現地事実・返報・本人の知識 | BD-48、CC-07・08・12・17 |

- 権限内の処分・適正な組織手続で足りる範囲を、全員の新規同意待ちにはしない。自治の縮小や権限を超える条件変更には該当する改定が必要で、改定案の拒否と既存義務への不履行を分ける。地位や「国割り」の名前だけで処分権を作らない。
- 原本にある交換条件、一括条件、期限、引渡しの順序を保つ。独立して成立・実施できる範囲は段階的に進められるが、代替地を渡す義務だけを切り離して旧地を取得した扱いにはしない。物理的な引渡しを同時完了にする必要はない。
- 権利や職務の効力時点と、現場が実際に引き渡される時点を分ける。未引渡しを理由に終了済みの旧権限を復活させず、新任者の到着だけで第三者の権利や守備の判断を消さない。
- 家の財産、本人の私財、借りた兵・物資、第三者の預かり物の権利・指揮・保管の区別を保つ。運搬許可は所有権の譲渡ではない。返還は原本の条件に従い、移封だけで旧債務・保証・未払給付を消したり、新領主へ一括転記したりしない。
- 担当・費用上限・期限・許可行為・報告先を付けて委任する。家族や家臣も一括で瞬間移動させず、移動に必要な既存の根拠、所在、通行、食料、護衛を照合する。同じ兵・米を旧地の守備と移動隊へ二重配置しない。複数部隊への一計画はCC-09の全件検査後に一括発送する。
- 拒否や遅れを知った人物が照会・再交渉・権限内の対応を判断する。自動処罰・離反・開戦にはしない。実力行使が物理的に可能でも、それを正当な権利取得と同一視しない。

## 3 最低限遊べる一巡

主家が、配下X家に旧地Aから新地Bへの移封を求める架空例とする。X家の家督と主家は変わらない。Aには家の兵糧、本人の私財、商人の預かり米があり、Bには引渡し担当の守備がいる。検証開始時に、新旧の権利・自治留保、要求の権限、必要な合意、交換・引渡し条件、原資と各人の認識を明示する。

| 段階 | 人物がすること | 別に残す状態 |
|---|---|---|
| 1 根拠を確かめる | 届いた命令・提案を読み、旧地の権利、新地の受取条件、既存の給付・軍役を調べる。必要なら権限者へ照会する | 既知の根拠と未確認の報告。提案への返書だけで城主職・知行・占有を移さない |
| 2 条件を整える | 必要な改定を同じ版で進め、権限内の決裁、発効、旧地引渡しと新地受領、費用・扶持などの条件を確かめる | 成立済みの範囲、発効待ち、未成立の案。双方の義務と交換条件を保持する |
| 3 移動を手配する | 旧地守備、引渡し、荷の運搬、新地の受取を担当者へ委任する。本人・家族・家臣・兵の移動と生活に必要な物を手配する | 任務、指揮範囲、引当、実在の人・物。発送と出発、出発と到着を分ける |
| 4 現地で引き継ぐ | 条件と通知に従って旧地を渡し、移動先で人・荷・城の受取を進める。未着や拒否は報告する | 区画の実占有、物の実受領、残る旧権利・債務・係争。未履行分は完了にしない |
| 5 新地を治め始める | 有効な権利と現地の状況を確かめ、守備・徴収・約束済み給付を担当者に手配し、返報から計画を見直す | 年貢請求・実徴収・配分・支払を分離。旧地の未精算や第三者の財産も元の根拠から追跡する |

これは共通の直列順を新設するものではない。独立した準備は並行でき、成立・発効・引渡し順は各案件の条件に従う。移封を求める当主、移る側、受取担当のいずれも、本人とNPCに同じ知識・権限・資源の境界を適用する。

遊びの焦点は、旧地の守備を残す費用、新地の収入が実際に入るまでの扶持、荷を運ぶ人手、現地の協力をどう両立するかにある。急げば必ず成功する、費用を払えば全員が従う、という規則は設けない。

## 4 記録と確認条件

原本・版・権限・期間、旧地と新地の権利、担当任務、各人と物の所在、引当・消費・受領、残存義務を既存の案件から参照する。一つの「移封済み」欄で全領域を上書きしない。画面とNPCには本人が知る根拠・報告だけを渡し、遠方の引渡し成否や拒否の真因を先回りして表示しない。

以下は対応工程へ割り当てる確認例であり、受入170件へ追加したものではなく、未実施。

1. 根拠確認から旧地引渡し、新地着任、最初の守備・徴収・給付と返報まで、本人とNPC双方で一巡する。未履行の交換条件を残せる。
2. 城主職、収益権、実占有を分け、権限内の命令と改定案への拒否を混同しない。命令や合意だけで全資産・家臣・家族を移さない。
3. 実在の人・兵・物で移動し、第三者財産、旧債務、保証、未払給付を保持する。新旧両地で同じ物資や納入・徴収を二重計上しない。
4. 一部引渡し・移動中・返報待ちから保存再開して同じ未来になる。再送で任命・引渡し・支給を重複させず、完了済みの消費や実受領を巻き戻さない。

代表例外は二つに絞る。

- **旧地の引渡し後、新地の守備が引渡しを渋る**：順次引渡しを認めた案件の例とする。完了した旧地の引渡し、新地を受ける権利・未履行、実際の占有を保持する。事情を知った人物が照会・交渉・権限内の安全維持を選び、自動で旧地を取り戻したり、無制限の強制退去権を得たりしない。
- **新地の受領・初回収納の返報が未着**：実受領・実徴収は保持し、報告を知らない人物には未確認の範囲を残す。同じ返報の再送で荷・納入・収納を複製せず、未報告を即座に未履行と断定しない。

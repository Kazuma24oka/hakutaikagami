# 武将・画面右向き 静止パーツ試作 V7

64×96・1倍、画面右向き（武将の左側が手前）の静止素材を追加した。正面V6は変更しない。今回の確認画面は `officer-right-review.html`。顔・髪と甲冑8部位を個別に着脱できる。接合確認ボタンは肘付近の共通表面を±1画素動かす。歩行ではない。

## 寸法と制作

生成前に `Art/Officer/RightViewV7/direction-definition.json`、裸素体の17部位ポリゴン/マスク、生成文、参照画像SHAを保存した。頭頂13、顎32、肩38、肘49、手首61、骨盤63、膝77、足首87、足裏91を作画目標とした。裸素体の実輪郭はこの固定マスクそのもの。顔・髪・服・下着・性器を含まない。頭と骨盤は肌色の無地として保護する。

imagegenスキルと組込み画像生成を使用。最初の甲冑案は胴が長く不採用。正面原寸と色分け位置ガイドで再生成した。裸体生成は同じ右向きと裸輪郭ガイドから肌の陰影だけを得る。生成原本3枚と全プロンプトは `generation-history.json` に保存。モデル版とSeedは非公開で、生成し直した画像の完全一致は保証しない。

生成原本1024×1536全体を1/16でnearest縮小、alpha>=200で二値化、甲冑48色/生成肌陰影12色に量子化。裸素体には別途固定の肌色補完・輪郭・頭/骨盤保護色を使うため最終色数が12色とは限らない。甲冑側は全体をy=-1画素だけ登録、部位別の拡縮なし。実外接範囲はx14..46,y4..91。刀先がガイド目標x45を1画素超えたことは記録し、64pxセル内で保持した。

## パーツとマスク

胴・肩・腕・腰・脚・履物・陣羽織・刀、顔（髭を含む）・髪。近側/遠側は同じスロットで着脱する。ownership、素材候補（肌/赤漆/赤い陣羽織布は別ID）、部位ごとの素体境界遮蔽、隠れ面、関節重なり、肘の制御ウェイトを別画像で保存。素材候補マスクは全素材の最終塗り分け承認ではない。腕を外した場合は裸の近側腕を胴より前、肩より後ろへ戻す。

隠れ面は別の限定ポリゴン内の作画補完で、生成原本から復元できた真の内部ではない。現状、一部の胴/布は単色であり完成素材の品質には未到達。静止画の切り抜きだけを将来の歩行リグ完成扱いにしない。

## 実測

- Python回帰89件成功（既存正面81＋右向き8）。素材分類の最終調整後にも右向き8件を再実行して成功。
- 実際のheadless Edgeで全1024状態をPythonの画素ハッシュと比較、差異0、JavaScript例外0。
- 全着用は右向き元絵と0画素差。全部外すと固定の裸素体と一致。素体は着脱の間も不変。
- ブラウザー実測64×96 CSS px、倍率1。通常の接合確認ループで0,+1,-1の3状態を観測し、各状態が異なることを確認。
- ±1px変位では頭と足元を固定。共通座標写像による各層合成と、合成済み画像の変形が画素一致することも検査。
- 保存済み原本からの再構築で全出力PNGとHTMLのSHA一致（`replay-validation.json`）。

実画像は `Art/Officer/RightViewV7/` の比較・単体・着脱・接合・ブラウザーキャプチャを確認した。技術的一致を体型やデザインのユーザー採用へ読み替えない。

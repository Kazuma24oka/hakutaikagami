# P1委任・長期行動・時間進行：詳細ABC比較（7項目）

**状態：未確定（Proposals）／2026-10-18。** 7項目は未選択、Bは推奨。既存F02/F04/F07/F08・情報仕様・P0-A01/A06と、P1行動・権限の選択済みB案を前提とする。

## ① 行動併用・競合
- **A**：武将は常に一件だけ実行。例：書状閲覧中は奉行への委任も不可。
- **B（推奨）**：主・補助・委任を分け、本人拘束・権限・資源の競合を検査。例：外交出張中に普請を委任できるが、同じ米を二つの工事に引き当てない。
- **C**：全行動を無制限に並行。例：同一武将が別々の戦場を同時に直接指揮。
- **保留**：併用表、行動枠、競合時の優先とUI。

## ② 長期行動の中断
- **A**：開始後は完了まで中断不可。例：普請中に落城しても工事を続ける。
- **B（推奨）**：中断要求・実際の停止・進捗・資源・責任を分離。例：普請の中断命令を出しても伝達まで作業が進む。
- **C**：中断で必ず進捗と費用を全返還。例：既に使った木材が全て戻る。
- **保留**：中断効力時点、進捗損失、資材の返還。

## ③ 再開・引継ぎ
- **A**：中断後は必ず最初からやり直す。例：担当奉行が病気になると普請を全消去。
- **B（推奨）**：残存進捗・資材・権限・新担当者の能力を検証して再開・引継ぎ。例：奉行交代後、完成済みの堀は維持し残りを再開。
- **C**：新担当者が無条件に全進捗を継承。例：新担当者に資材も権限もなくても工事再開。
- **保留**：進捗の所有、引継ぎ費用、再開条件。

## ④ NPCへの委任・裁量
- **A**：委任先は全て指示通りに成功。例：凶作でも奉行は徴税目標を必ず達成。
- **B（推奨）**：目的・範囲・期限・資源・報告義務を指定し、NPCは認識・能力・利害で判断。例：奉行が凶作を認識して徴税延期を進言。
- **C**：委任後は全権限を永久に移譲。例：委任者が後から指示を取り消せない。
- **保留**：再委任、裁量逸脱、委任取消、責任。

## ⑤ 世界時間・速度
- **A**：プレイヤー操作ごとに一律1ターン進行。例：書状を読むだけで遠方の軍勢が一日進む。
- **B（推奨）**：共通世界時刻の下で自動進行＋任意停止を優先し、速度と割込み条件を個別設計。例：外交移動中も全国の軍勢・使者・普請が進む。
- **C**：操作画面でも時間が強制的に進む。例：期限付き返書を読む間に期限が切れる。
- **保留**：自動進行の正式採否、速度段階、合戦との同期。

## ⑥ 通知・自動停止
- **A**：全ての出来事で自動停止。例：遠方の小さな商取引でも毎回停止。
- **B（推奨）**：本人が認識可能な報告・危険・期限を重要度で評価し、通知・停止・履歴を区別。例：未開封の緊急書状は外形情報だけで停止判断。
- **C**：全通知を履歴だけに記録。例：城の包囲を直接目撃しても止まらない。
- **保留**：重要度閾値、同時刻集約、未開封の扱い。

## ⑦ 委任中の緊急介入
- **A**：委任中は一切介入できない。例：家臣が離反しても撤退指示を送れない。
- **B（推奨）**：介入指示・配送・受領・権限・実行を分離し、到達前の変化も反映。例：普請停止の書状が届く前に工事が完了することもある。
- **C**：遠方の委任先へ即時強制介入。例：使者が届く前に遠方の軍勢が即時撤退。
- **保留**：介入の優先度、取消と再委任の衝突、期限。

## 既存仕様との整合性・重複・依存関係
- **F04**：主・補助・委任行動の区別、長期行動の中断・引継ぎは既に確定。①②③は併用条件・進捗・資源・担当交代の詳細であり再確定しない。
- **F02**：共通世界時刻と世界停止／個別中断の区別は確定。⑤の「自動進行＋任意停止」は情報仕様で優先検討とされているだけで**正式確定ではない**。

- **P0-A04／R01〜R04**：行動併用による資源の二重引当を防ぎ、取消・補償・セーブ再現性を守る。

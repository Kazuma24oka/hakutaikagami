## 1. 共通モデル
- 武将個人を主体とし、**身分／役職／家督／直属主君／勢力所属／軍事指揮系統／所領の権利／知行収益／実効支配**を別々に管理する案。
- 城主・奉行・軍事指揮官等の兼任を認める。城主職の保有は土地所有・正式安堵を意味しない。
- 大名直属、陪臣、与力、従属国人を区別。陪臣は原則直属主君の指揮下だが、上位権力者が権限・任務・緊急性に応じて直接命令できる例外を検討。与力は直属主君と軍事指揮官が異なる場合がある。
- 命令権、書状代理権、情報閲覧権、実際の情報認識は独立して判定する。

## 2. 命令・密命
- 兼任役職等から競合命令を受けた場合、権限・任務・緊急性・期限から優先度と理由を提示し、確認・保留・拒否を選択できる案。選択しても免責されない。
- 照会・保留中も原則期限は進む。命令者は延長・再指示・取消が可能。
- **期限延長の効力**は案件別に「命令者の決定時／通知到達時」を選ぶ。決定・配送・受領・本人の認識を区別する。
- 大名から陪臣への直接命令は直属主君への報告を原則とし、密命・緊急時には省略・遅延の例外を認める案。秘匿範囲は命令者が指定できる。
- 密命発覚後は正当性・忠誠・実害・人間関係で結果を判断。自動処罰や自動免責にはしない。

## 3. 家督・所領・知行
- 家督は継承可能だが、知行の安堵、所領権利、城主職・他役職の継続は別に判断する。
- 正式安堵前でも通常の徴税・治安維持・既存軍役等の暫定管理を認める案。恒久的譲渡・大規模知行再配分・恒久任命等は制限候補。
- 安堵拒否後は交渉・異議申立て・服従・抵抗・離反などに分岐。正式な権利の否認と実効支配の消失は同義ではない。
- 主君による宛行・加増・減封は勲功・政治情勢・領地事情を総合判断し、全国一律の自動処理にはしない。

## 4. 勲功・出世
- 勲功は軍事・内政・外交など分野別に記録。共同成果は指揮・実働・貢献度で配分し、主君の裁量も反映する案。
- **実際の貢献／申告内容／審査者が認識する証拠／主君の評価／最終恩賞**を分離する。
- 昇進は勲功・能力・人脈・忠誠・主君評価・政治情勢等で総合判断。自動昇進ではない。
- 配分への異議申立て・再評価を認め、主君・奉行・評定など案件別の審査者を設定。審査者と最終決裁者は同一とは限らない。

## 5. 俸禄・財政・債務
- 米・銭・現物・知行収益を区別し、時代・勢力による支給差を認める。知行収益と支給俸禄を二重計上しない。
- 財政難による未払い・減額・代替支給を認める。滞納額は債務として管理する案。
- 家臣は滞納期間・生活状況・忠誠・代替収入・人間関係で催促・忍耐・出奔・離反等を個別判断する。
- 主家交代時の債務承継は旧主家・新主家・家臣間の交渉・契約で判断し、所属変更だけで自動消滅／自動移転させない。
- 債務の存在、支払義務者、債権者、支払実績、合意、認識は別管理する。

## 6. 独立・謀反・城内支配
- 出奔／離反／独立宣言／実効独立を異なる状態として扱う案。兵力・所領・家臣支持・外交・主君との関係で成否を判断する。
- 家臣は忠誠・野心・人間関係・利害と、本人が知る情報に基づいて追随・残留・中立・離反等を個別判断。陪臣・与力・国人を一括処理しない。
- 城や領地は独立宣言だけで自動移転しない。**名目上の領有権／城主職／守備兵の指揮と忠誠／城内施設の実効支配／周辺領地の統治**を区別する。
- 城主と守備兵の意向が割れた場合、守備兵・指揮系統・在地勢力の支持から開城・交渉・内応・籠城・戦闘などへ分岐。戦闘は必須ではない。

## 7. AI武将
- 野心・義理・忠誠・人間関係・利害・政治情勢を用いて、仕官・出世要求・独立・主家交代などを自律判断する案。
- 全知の世界状態ではなく、各武将のKnowledgeRecord等に基づく認識・噂・報告の確度を利用する。
- 史実・準史実・仮想モードで再現度を調整する余地を残す。

## 8. 重複・整合性レビュー
| 論点 | 統一した解釈 |
|---|---|
| 城主と領主 | 役職・正式な権利・実効支配を分離 |
| 家督継承と安堵 | 家督継承は所領・役職の自動承認を意味しない |
| 陪臣と与力 | 直属主君と軍事指揮系統を分離し、同一類型にしない |
| 命令と認識 | 命令の効力、通知到達、本人認識、責任を別判定 |
| 勲功と恩賞 | 貢献の事実、配分・審査、主君評価、任命を分離 |
| 俸禄と知行 | 支給と収益権を別管理し二重計上を避ける |
| 債務と所属 | 主家交代だけで未払い債務を消さない |
| 独立と領有 | 独立宣言、法的主張、軍事・現地支配の変化を分離 |
| NPC判断と情報 | 認識していない情報を判断材料にしない |

**中**

7. 与力・陪臣・国人の所属、軍事指揮、役職兼任の競合。

**低**

## 3. 重複の整理
1. **指揮権・主従・忠誠**：武将制度・軍制・人物関係で重複。権限の有効性は共通権限基盤、服従意思は人物関係、戦場での命令遂行は軍制が担当。
2. **合戦時間・世界停止**：時間進行と軍制で重複。共通世界時刻を正本とし、合戦内部の換算・通知・複数合戦は軍制の未確定詳細とする。
3. **兵糧・輸送・会計**：経済と軍制で重複。物資の所有・所在・取引は経済／共通会計、戦場での必要量・戦術影響は軍制。
4. **落城・独立・安堵**：地理・武将制度・軍制・外交で重複。占有／権利／役職／忠誠／条約／債務を一括更新しない。
5. **書状・偽報・評判**：情報システムと外交・人物・軍制で重複。客観的事件と報告・配送・認識は情報基盤、意思決定・結果は各領域。
6. **国人自治と軍役・徴税・外交**：在地社会・内政・軍制・外交で重複。自治の範囲は組織・権限モデルに接続し、各行動は個別の許可と履行を判定。
7. **婚姻・家督・忠誠・条約**：外交・武将制度・人物関係で重複。親族関係の成立と家督・領地・外交義務の承継を分離。
8. **勲功・能力・評判**：人物能力と武将制度・合戦で重複。実績・他者の認識・主君の評価・恩賞を別管理。

| 指摘 | 解釈・処置 | 状態 |

| 国人衆はNPC組織か、プレイヤー可か | プレイヤー主体は武将個人。国人領主・国人所属武将は可、寺社・村落組織の直接操作は不要 | 整合 |
| 落城で城と領地が一括移転するか | 城内占有・城主職・守備兵・権利・周辺支配を分離 | 整合、遷移未定 |
| 返答期限と条約成立は同時か | 発送・到達・開封・認識、返答有効性、条約効力、履行は別 | 整合、案件別条件未定 |
| 資源を「所有」することと「保管」すること | 所有者・処分権・所在・引当・消費を別管理 | 整合、会計方式未定 |
| 代理人が受領したら本人も知るか | 正式受領の成立と本人の知識更新を分離 | 整合 |
| 同盟が成立したら援軍は自動到着するか | 義務・要請・受領・出陣・移動・到着は別 | 整合 |
| 戦場情報は全軍に共有されるか | 指揮官・部隊・プレイヤーの認識を区別。未開封重要書状は本文秘匿 | 整合 |
| 史実地理の信頼度とNPCが信じる度合い | 開発資料の確度とゲーム内報告の信用を区別 | 整合 |
| 旧資料の「アーカイブ保留」記載 | 旧時点の指示。現行運用はArchiveへの移動を許可し、永久削除のみ要承認 | 管理文言の陳腐化 |
| F01〜F08の選択履歴に「未確定」とある | 選択時点の履歴。**基本原則のみ**後日Confirmedで確定、詳細は未確定 | 履歴と現行状態の区別 |

**総合判定**：現行の基本方針に直接衝突する仕様は確認されない。ただし、実装時に衝突する可能性が高い**同時刻イベント、権限競合、帰属変更、在庫会計、条約効力**は未解決。単に「整合」と書かれた旧レビューをもって解決済みとしない。

## 2. 既に確定している原則（再承認不要）
1. 武将個人が操作主体。浪人・家臣・城主・国人領主・大名としての活動を目指す。全国の城・国人衆、段階的マップ、史実尊重と史実／準史実／仮想モード。
2. 事件の真実・報告・書状・伝達・組織保管・アクセス権・個人認識・通知を分離。勢力／家臣団／個人の3階層、遅延・誤報・記憶保持。
3. 通常書状の本人受領時自動認識、重要書状の開封時認識、代理受領と本人認識の区別、期限起点・返答有効時点・代理権限・偽書・事後追認・重要度別通知／停止の基本方針。具体的な数値・詳細条件は未決定。
4. 自動進行＋任意停止は情報システムの確定文書内でも**優先検討**という位置付けであり、具体的な時間方式を確定済みと読み替えない。

## 4. 未決定事項：重要度別

### P0：基盤設計前に要決定
1. **権限・主体の共通モデル**：個人／家臣団／勢力／国人組織／寺社・村落／朝廷・幕府、役職・委任・決議・命令の効力、組織重複所属をどう表現するか。確定済みの「勢力／家臣団／個人」の情報認識階層と、社会組織の分類を混同しない。
2. **世界時刻とイベント順序**：同時刻の配送・受領・認識・命令・合戦・AI更新・期限・支配変更の順序、セーブ再現性、停止中の挙動。
3. **領地・拠点・権利・会計の正本**：所領の空間表現、城主職・実効支配・収益権・徴税・俸禄債務の分離、二重計上防止。
4. **状態遷移の整合**：家督継承・安堵・離反・独立・落城・国人の従属変更と、家臣・軍勢・城・所領の帰属をどう更新するか。
5. **情報認識と組織行動の接続**：組織の決議や代理受領だけで個人全員が知ることにしない。偽書・秘密・未開封情報・重要度別停止を含む。

### P1：主要機能の詳細設計前に要決定
6. 武将の主／補助／委任行動の同時実行、長期任務・引継ぎ・中断損失。
7. 遠方AIの集約処理、近傍詳細処理への切替、乱数とセーブ／ロードの再現性。
8. 国人衆の従属契約・軍役・年貢・外交・人事の自治権と離反、在地組織の派閥・合議。
9. 寺社の権益・反発段階、一揆の類型・参加・強制動員・終結、政治・経済への影響。
10. 朝廷・将軍家への取次・奏請・返答、正式官位と官途名、将軍の正統性・幕府実権・命令／仲裁の効力。
11. 地理史料の年代差分・異説・推定境界、拠点の主副機能、道路・峠・河川・海路・補給。
12. 合戦中の通知・自動停止・手動停止の優先順位、複数合戦の同期。

### P2：数値・演出・任意機能
13. 時間速度倍率・最小時間粒度、移動／補助行動の補正値、AI評価係数。
14. 地図の情報鮮度・推定境界・係争地の可視化、イベントログ・通知UI。
15. 官位・工作費用・信用・恩賞の数値バランス、史実／準史実／仮想の制約強度。
16. 出家・隠居・還俗システムの採用可否、ゲーム上の役割、操作可能性（将来検討のまま）。

## 5. 横断的な重複・矛盾・記述差
| 論点 | 判定 | 整理・対応 |
|---|---|---|
| 世界の真実と人物の認識 | 整合 | EventTruthとKnowledgeRecordを区別。勢力地図やNPC行動に全知を混入させない |
| 情報認識の3階層と社会組織の種類 | 要設計 | 「勢力／家臣団／個人」は情報保管・認識のレベルであり、国人・寺社・村落の組織分類と同一軸にしない |
| 自動進行と合戦中の一時停止 | 整合 | 非停止時は全国進行。手動・自動停止時は共通世界時刻も停止する案 |
| 個別行動の中断と命令期限 | 整合 | 行動中断でも世界時刻は進む。世界全体の停止時のみ期限停止 |
| 家督・城主・官位・将軍職と実権 | 整合 | 地位・正式任命・主従・権限・支配を分離 |
| 国人衆プレイと寺社・農民NPC | 整合 | 操作主体は武将個人。国人所属武将も対象。寺社・村落組織の直接操作は不要 |
| 寺社・一揆・朝廷の「将来検討」表記 | **記述が古い** | 各統合案で比較検討済み。ただし未確定。出家は依然として将来検討のみ。既存ファイルは今回変更しない |
| 「官位・官職」と官途名 | 整合 | 正式任官、名乗り、社会的認知、実権を分離 |
| 国人衆の離反と所領・軍勢帰属 | 要設計 | 所属変更・権利・実効支配・軍勢忠誠を一括変更しない |
| 寺社・村落組織と施設 | 整合 | 組織と拠点を分離 |
| 二重徴税・俸禄・知行収益 | 要設計 | 生産・徴収・配分・支払・債務の会計を連動し二重計上防止 |
| 中央権威と家中命令の競合 | 要設計 | 管轄・正統性・効力・伝達・本人の認識・拒否を別判定 |

**総評**：基本原則の直接矛盾は見当たらない。古い記述の更新が必要な箇所と、詳細仕様を定義しなければ解決しない接続点がある。今回それらを勝手に確定しない。

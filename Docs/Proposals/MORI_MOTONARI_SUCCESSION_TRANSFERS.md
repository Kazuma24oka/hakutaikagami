## 2 既存仕様へつなぐ境界

| 論点 | 管理先 | 変えないこと |
|---|---|---|
| 養子・既存の後継指名との競合 | BD-43、G-C1・G-S3、統合案§12 S1・S6 | 当人双方と家の権限者の意思、合意と実施、所属・相続資格の変更を別にする。初回の縁組操作は成人に限る |
| 指名・支持・家督・実支配 | BD-45、G-S1・G-S2、S2〜S5 | 血統・家法・誓紙・占有の一つだけで決着しない。全員同意や多数決を共通の新規則にしない |
| 隠居条件・財産・対外義務 | BD-07・48・50、G-A3・G-K9、CC-03・14 | 存命の隠居を死亡相続として処理しない。家・個人・第三者の財産、債務、保証を分ける |
| 旧当主・新当主・後見人の職務 | BD-10・11・45、J4・S7、CC-06・12 | 肩書や血縁だけで権限を作らない。期限、取消、再任、安全維持の範囲と各人の認識を分ける |
| 操作人物の継続 | BD-07 | 生前に指定・認識された適格な成人候補への操作継続と、家督承認は別。記憶の一括コピーをしない |

### 縁組・後継指名・承継

- 打診、本人と家の意思、同じ条件への合意、縁組の実施、後継指名、重臣への働きかけ、家督の承継は別の記録とする。養子の承諾だけで家督・役職・所領・軍の指揮を付与しない。
- 既に別の家の後継に指名された人物は、旧指名や家法、本人と関係する権限者の意思との競合を確かめる。下天禄の「跡継ぎ予定者は対象外」を百代鏡の一律禁止にせず、既存の指名を無条件に消して連れ出せる仕様にも変えない。
- 強い家からの申し入れは交渉材料であり、本人や相手方の拒否を消す強制権ではない。従属条約の改定、受入家の自治縮小、元の家への奉公関係は、それぞれの権限・条項・必要な合意で扱う。「一門になった」だけで別家を吸収しない。
- 誓紙は誰がどの候補・条件について約束したかを示す原本であり、全家臣共通の服従フラグではない。有効な家法・指名手続、支持、異議と実占有を照合する。未着の誓紙、隠された遺言、遠方の家臣の判断は主人公に漏らさない。
- 主家など外部の承認が必要かは、当該家の制度・従属条項による。すべての家に新しい上位者許可を必須化せず、必要な承認と家中での決定、現地の引渡しを区別する。

### 隠居条件と個別の引継ぎ

- 隠居所、扶持、残す所領・職務、返す城・物資、本人や家族の移動、保証は、対象・負担者・期限・継続条件を明示して交渉する。養子入りと同じ文書に含まれていても、どの条件が交換条件かを保持し、一方だけを勝手に切り離さない。
- 存命の旧当主の私財や個人債務は、隠居しただけで新当主に移らない。家の債務、第三者の米、個人保証、本人死亡時の相続財産はBD-48等の別規則で扱う。支払いや引渡しが約束済みなら、交代だけで消さない。
- 扶持の決定、財源の引当、出庫・運搬、実受領、返報は別。隠居料を選択した瞬間に米を生成せず、他の給付や軍備との競合は既存の資源優先規則で処理する。支給の変更には既存原本と権限の確認が要る。
- 本拠の受取は、正当な権限、城番への通知・判断、実際の移動と引渡し確認を伴う。正式承継と実占有が違う状態を残し、返報不達で実際の受取を消さない。無権限の占拠を正当な権利取得へ変換しない。
- 条件未記載の有効な統治家法は[採用済みの家法承継方針](../Decisions/2026-11-05_HOUSE_LAW_SUCCESSION.md)に従って残る。一方、常設職の交代時終了・個別再確認はJ4、既存の安全維持委任はBD-45、条約や個人の約束はBD-48に従う。家法の継続を全役職・全契約の自動継続へ広げない。

### 二人の指示と後見の終了

- 旧当主が隠居しても、別に有効な役職・委任を持つ範囲では行動できる。何もなければ新当主の家に対しては助言・要請であり、血縁や威信だけで新当主より強い命令権を作らない。実際に従う家臣がいても、正当権限と服従を同一視しない。旧当主個人の私財や既存の主従契約に基づく権利は原本に従って別に扱い、新当主の家を代表する権限と混同しない。
- 同じ家臣へ競合する指示が来たら、行為・対象・期間・版・取消・再委任の根拠を照合する。CC-06に従い発送、正式受領、効力時、段階実行時の権限を検査し、複数の有効根拠が衝突すれば既存の制度裁定へつなぐ。「新当主の名前がある方」「最後に届いた方」を無条件に優先しない。
- 終了した権限を未知の通知不達によって復活させない。権限を欠く実力行使は物理的可能性と責任を別に扱い、正当な命令へ読み替えない。逆に、旧当主の時代に適法に完了した支出・所有移転を、交代だけで取り消さない。人物向けには本人が知る情報で説明し、秘密の交代・解任理由を不可能理由として表示しない。
- 未成年が家督を継ぎ成人後見人が元服まで代行するS7を使う。後見は対象職務と期限を持ち、期限終了で正当な代理権が終わることと、帳簿・資源・現場指揮が実際に返ることは別。政務の返還が済むまで代理権を無期限延長することも、期限だけで全現物を移すこともしない。
- 後見人が返還に抵抗すれば、未履行・係争・実占有と各人の支持を保持し、照会・説得・調停などの既存の行動へ進む。自動処刑・自動離反・自動内戦にはしない。新しい委任を受ける場合は別の有効な根拠が必要。
- BD-43の成人縁組と、S7の未成年家督・成人による後見は別の範囲である。歴史上の若年養子を入口に、成人前の縁組実施を初回操作へ追加しない。操作継続に適格な成人がいない場合のBD-07も変更しない。

## 3 最低限遊べる一巡

以下は成人の養子候補Aを迎えるX家の架空例。必要な承認、隠居条件、対象職務は検証時の条件として明示し、史実の吉川・小早川両家の条件や全国共通の制度にはしない。

| 段階 | 人物の行動 | 世界に残る状態 |
|---|---|---|
| 1 条件を持ち寄る | X家の旧当主と候補A、その家の権限者が縁組、旧指名との調整、後継案、隠居所・扶持についてやり取りする | 打診・留保・合意版と未達を分離。相手の家臣の支持や対外承認を先取りしない |
| 2 縁組と指名を進める | 必要な合意と実施を確かめ、後継指名を伝え、重臣へ個別に働きかける | 家族関係、指名、誓紙、異議を別に保持。縁組だけで軍や所領が移らない |
| 3 家督を移す | 適用される手続で承継し、職務・条約・城・支給の個別引継ぎを手配する | 家督の効力、家法、各役職の再確認、安全維持委任、通知と実占有が別々に進む |
| 4 約束を履行する | 扶持の実支給、旧当主の移動、城や帳簿の受取を行い、残す委任を伝える | 実物・原本・債務を保持。受領済みと返報待ち、未履行を区別する |
| 5 届いた問題へ対処する | 競合する指示や引渡しの遅れを知り、根拠を確認して説明・変更・再交渉を行う | 正当権限、各人の認識、従う意思、残った争いを別に残す。旧当主の存在だけで政変を起こさない |

未成年家督の場面では、既存S7の成人後見人による政務を同じ職務・資源の枠で扱う。元服時には代理権の終了、返還の指示・配送、実引継ぎ、結果の確認を続ける。成人養子の一巡を未成年縁組の実装へ読み替えない。

遊びの焦点は、後継の正統性と実際の支持をどうそろえるか、旧当主への保証と家の支出をどう両立するか、誰に何を任せるかにある。支持が足りなければ交渉が続き、承継が済んでも未履行の約束は残る。

## 4 保存・表示と確認条件

原本・版・根拠・期間を既存案件から参照し、縁組成功・隠居済み等の一つのフラグを全領域の正本にしない。旧署名を書き換えず、前主人公の記憶や組織文書庫の全情報を新主人公へコピーしない。本人の閲覧・受領・報告で認識を更新し、再送で家族関係・家督・給付を二重作成しない。

以下は既存の対応工程へ割り当てる確認例であり、固定の受入170件へ新規追加したものではなく、未実施。

1. 成人の打診から、縁組・指名・支持・承継・個別履行・再判断まで一巡できる。本人・両家の意思と権限を検査し、家や領土を自動統合しない。
2. 存命の隠居と死亡相続を区別し、私財・家の債務・第三者財産・隠居料と、その実際の支給を保持する。
3. 家法、役職、安全維持委任、対外契約をそれぞれの規則で処理する。旧当主・新当主・後見人の指示を、知識と正当権限を混ぜずに判定できる。
4. 元服時の後見権限終了と政務・資源の実引継ぎを分ける。返還が遅れても無期限の代理権を作らず、既に完了した効果は消さない。
5. 交渉中・交代通知中・給付運搬中・返還待ちから保存再開して、案件、実物、権限期間と各人の認識が保たれる。現行の限定試作を一般相続の完成と数えない。

代表例外は二つに絞る。

- **交代通知が未着の家臣へ旧当主の指示が届く**：既存の段階別権限検査と本人の認識を分ける。未知の交代理由を漏らさず照会・再送から続け、誤認と故意の違反を同一視しない。
- **本拠は引き渡されたが返報が未着**：実占有と第三者財産は保持し、新当主の表示は未確認の範囲を残す。報告再送で二重引渡し・二重支給を起こさず、受取前提の独立案件を誤って完了させない。

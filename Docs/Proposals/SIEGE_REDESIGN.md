# 攻城の作り直し（案 2026-11-25）

前の攻城の決まり（Core/Proto/ProtoSiege.cs）は引き継がない。ユーザー「作り直しすら考えている」「他のゲームも参考に」。
決まったこと：城の士気は、兵糧が切れたときと調略でしか下がらない。「心」のような新しい値は足さない。力攻めは城兵の10倍で3日。

## 1. 調べたこと

### 史実
- 力攻めは損が大きく、最後のひと押しか、守りの弱い城に使う。
- 多いのは兵糧攻め。周りの支城・砦を落として補給路を断つ（三木城、1年10か月）。陣城を連ねて囲む（鳥取城、包囲網は総延長12km）。
- 調略・内応・降伏の交渉で開く城が多い。交渉が通るかは、後詰（援軍）が来るか、残りの兵糧、兵の差しだい。
- 籠城は後詰を待つための手。後詰が来なければ孤立して持たない（有岡城）。
- 長さは数週間〜数年。

## 2. 今の作りのまずい所
- 待つだけで勝てる。囲むと城の士気が下がり、半日で開く。
- 早すぎる。逃げ込んだ城兵の士気がもともと低い（検査の記録では、城に入った時点で城の士気が0）ので、すぐ開く。
- 数字が多くて食い違う（全軍士気・城の士気・総士気・耐久・兵糧2種類）。
- 一武将の本人は、本陣で立っているだけ。

## 3. 作り直しの考え方
1. **攻城は、日をまたぐ「役目の連なり」にする**。本人は数字を眺めるのではなく、毎日の役目（持ち場・荷駄・見回り・普請・使者・一番乗り）をこなす。こなせば城攻めが進み、勲功になる。
2. **城が持つ値は、兵・兵糧・士気・門の四つだけ**。
   - 兵糧は、城の蓄え（俵）を城兵の数で割った「あと何日」。攻め手には見えない。物見や内応で見積もりが分かる。
   - 士気が下がるのは、兵糧が切れたとき（毎日）と、調略（流言）のときだけ。士気は打ち合いの強さに効き、0で開城。
   - 門は、力攻めでしか削れない。0になると城の利がなくなり、城内での斬り合いになる。
3. **囲みは実際の隊の輪**。城のまわりを6つの持ち場に分け、隊が付く（印03の見た目）。付いていない持ち場があれば、夜のうちに少しずつ兵糧が入り、使いも抜けて後詰を呼べる。付城を普請すると、少ない兵で持ち場を守れる。打って出られたり後詰が来たりすると、その持ち場の隊が離れて戦うので、描写はそのまま。
4. **待つ側にも時計がある**。攻め手の兵糧は本陣の蓄えで、荷駄が鷹野城から運ぶ（道の賊が絡む）。長陣で攻め手の全軍士気が下がる。後詰が来るかもしれない。だから「囲んで待つ」は放っておけば勝てる手ではなく、支えないと崩れる手になる。
5. **力攻めは高くつく**。城の利は大きく（守る側の受ける打撃は3分の1ほど）、門を削れるのは昼だけ。城兵の10倍で3日、5倍なら損ばかり大きい。一番乗りは大きな勲功になるが、手傷を負いやすい。
6. **調略と勧告は、城の事情しだい**。勧告が通るかは、城主の気性に、残りの兵糧・兵の差・門の残り・後詰の当てを足し引きして決まる（太閤立志伝Vと同じ考え）。調略は、城内の武将の内応か、流言で士気を下げる。どちらも使者や密書を人が運ぶ。
7. **後詰**。籠城した城は、使いを抜け出させて味方の家（沢渡城など）へ後詰を頼む。来るかは、その家の当主が決める（自動の戦争はしない原則）。後詰が来れば、囲みの外で野戦になる。それを破れば、勧告が通りやすくなる。

## 4. 長さの見込み（岩切城）
- 今の試作の兵の数（検査の記録、野戦のあと）：岩切の城兵はおよそ180（勝元133・井口47）、鷹野勢はおよそ190。
- 蓄え：城兵180で20日ぶん（案）。囲みに穴があれば延びる。
- 包囲だけなら、兵糧が切れてから士気が落ちきるまでで、3〜4週間。
- 力攻めは、城兵の10倍なら3日。今の兵の差（ほぼ同じ数）では、力攻めで落とすことはまずできない。兵糧が切れて城兵が逃げ散る・討たれる、内応で門が開く、といったことで城兵が減ってから、最後のひと押しに使う手になる。
- 調略・勧告・後詰しだいで、数日〜数週間に縮む。
- 1日は30倍の速さで実時間48分。何も起きない日は、前に作った「次の出来事まで飛ばす」で進める。

## 5. 決めてほしいこと
1. 後詰を入れるか（沢渡城の大野頼母を岩切の味方にするか）。
2. 岩切城の蓄えを20日にするか（長さの見込みが変わる）。
3. 囲みの持ち場を6つにするか（多いほど兵が要り、穴ができやすい）。
4. 毎日の役目の種類：持ち場・荷駄の護衛・見回り・付城の普請・使者・一番乗り。足したい・外したいものがあるか。

# 正面の裸素体：64×96・通常1倍

2026-10-18。顔・髪・髭・服・履物を含めず、骨盤は性器の細部を描かない肌色の面とした正面静止の確認候補。旧OfficerPartsV1およびbody-v2は使用していない。ユーザーによる外見受入、他方向、歩行の合格は含めない。

## 生成前に固定した内容

- [geometry.json](../../Art/Officer/BodyBaseV1/geometry.json)：64×96、頭頂y8・顎y28・足底y91、全身84px/頭部21pxで4頭身相当。肩/肘/手首/骨盤/膝/足首/足裏を独立した構成点で指定。これらは新しい成人男性素体の作者による制作値で、甲冑に隠れた人体の実測やユーザーによる頭身承認ではない。
- 17部位の所有ID、全身輪郭、肌色、編集/保持マスク、顔なし頭部、骨盤の滑らかな面。部位は本人基準の左右であり、正面の画面左が本人右。共通パレット6色を宣言し、出力はそのうち5色を使用。
- [実ワークフロー](../../Art/Officer/BodyBaseV1/workflow-api.json)と[実プロンプト](../../Art/Officer/BodyBaseV1/prompt.txt)：SDXL Base1.0、モデルSHA256 `31e35c80fc4829d14f90153f4c74cd59c90b779f6afe05a74cd6120b893f7e5b`、seed2026101801、steps30、CFG5.5、dpmpp_2m、karras、denoise0.32、LoRAなし。
- 作業解像度768×1152は64×96の整数12倍。出力は固定1/12のBOX縮小と共通パレットへの色対応。縦横別倍率・部位別fit・輪郭高への自動正規化はしない。
- 制作計画は既存[work-record.json](../../Art/Officer/work-record.json)の`control_preparation`、`plans.body-front-v1`へ保存してから実行した。寸法/マスクの準備専用入口は決定的な制御画像だけを作成し、モデル実行や次工程を許可しない。モデル実行は実マスク/設定/モデル/コードSHAを含む共通`require_plan`を通す。

## 実際の制作方法

裸素体の輪郭と部位は、生成後の完成絵から切り抜いたものではない。先に定義した新しい身体の輪郭・接続・17部位・大きな明暗面を、同じ原寸座標上に構成した。目鼻口や髪は入力にも含めていない。旧甲冑の外周へ裸の色を貼り付ける方式ではない。

ComfyUIは内側の陰影候補の試験に限定して使用した。最終パレット整理後の採用画素差分は0であり、生成が見た目を改善したという結果ではない。最終PNGは固定寸法・部位定義からの作画と同じ画素である。562画素が編集可能な範囲であり、562画素すべてが原本と異なるという意味ではない。顔なし頭部・首・骨盤・外周は保持している。生成RGBの編集範囲だけを固定座標で組み立てたため、最終alphaは作者の輪郭に対応する。モデルが透過や人体形状を正しく生成したという主張ではない。

原寸PNGは[body-front.png](../../Game/Assets/Trials/OfficerBodyBaseV1/body-front.png)。所属、肌色、編集、保持の各マスクと17個の単体部位も同じフォルダへ保存した。再パック用の実生成原画像は[material-source.png](../../Art/Officer/BodyBaseV1/material-source.png)、SHA256 `ab24a743371fb8ca0015a2a3d4cedcc3044c947bbf5220ce8524f4c386a882d5`。原画からの再パックとモデルの再生成を区別する。

## 実行環境

ユーザーはComfyUIを必須としていない。今回は設定・マスクを保存できるためComfyUIを選んだ。既存インストールを直接起動するとtorch欠落、次いでcomfy_aimdo.storageの不整合で停止した。既存インストールは修正せず、PCに保存済みの公式配布アーカイブを作業用`.utmp`へ展開して使用した。新規ダウンロード、別モデルへの変更、ユーザーのアプリ終了、マウス/カーソル操作はしていない。

実行はComfyUI0.34.0、Python3.13.12、PyTorch2.12.1+cu130、GeForce RTX4060Ti 8GB。ローカル127.0.0.1:8189、カスタムノードなし、GUI自動起動なし。実環境・受付・履歴はBodyBaseV1のruntime-environment.json、submission.json、generation-history.jsonへ保存。初回実行は19.55秒。再生成の完全なビット再現性は同じseedだけでは保証せず、保存PNGからの決定的再パックを検査する。

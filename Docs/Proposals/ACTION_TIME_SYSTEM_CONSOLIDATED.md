# 武将の行動・時間進行：統合設計案

**状態：未確定（Proposals）／2026-10-17整理。** ユーザーが選択したB案を集約した優先参照先。未承認の数値・実装方式を確定させない。

## 1. 時間の基本原則
- 世界時刻を単一の正本とし、浪人・家臣・城主・大名の行動、全国AI、書状配送、命令期限、合戦の経過時間を整合させる。
- 自動進行＋任意の一時停止を優先検討。速度区分（停止・通常・高速・超高速）、最小時間粒度（例：1時間）、具体的倍率（例：現実10/3/1秒でゲーム内1時間）は**すべて未確定の試算**。
- **世界全体の一時停止**では戦闘内部ステップ・世界時刻・全国AI・配送・期限・イベント進行を同時に止める。**武将の個別行動の中断**では世界時刻は進み続ける。
- ゲーム時刻が進む限り、命令の照会・保留や任務中断だけでは期限は停止しない。命令者による延長・再指示は別途処理する。

## 2. 行動分類・併用
| 分類 | 優先検討方針 |
|---|---|
| 主行動 | 本人は原則1件のみ進行。移動・修行・交渉・内政等 |
| 補助行動 | 主行動との組合せごとに併用可否を判定。書状確認・簡単な指示等は候補 |
| 委任行動 | 役職の基本権限＋個別委任に基づき配下が並行実行。本人の主行動枠は消費しない |

- 補助行動の併用可否と、併用時の負荷は別に判定する。危険度・集中度・場所・本人の状態・状況から主行動の効率や成功率に影響し得る。
- 行動の所要時間は行動種別・距離・能力・地形・季節などに応じて変動。地形や季節をすべての行動へ一律適用しない。
- 委任先が認識した情報は本人に自動共有せず、実際の報告・閲覧等を経て本人のKnowledgeRecordを更新する。

## 3. 長期行動・中断・再開
- 移動・修行・内政等の長期行動は自動継続し、到着・重要イベント・命令変更等で必要に応じて判断を求める。
- 中断・変更は可能だが、既経過時間・費用・機会損失等を考慮する。
- 行動ごとに進捗・現在地・資源状態・担当者・期限を保持し、再開時に状況と条件を再評価する。進捗保存は損失ゼロを意味しない。
- 担当者変更時は引継ぎ時間・能力差・資源損失を考慮。任務種類・状況に応じて引継ぎ中の継続／減速／停止を判定する。
- 引継ぎ時も前任者の個人認識を自動転記しない。引継ぎ資料・報告の伝達と新担当者の権限を区別する。

## 4. 合戦と世界時刻
- 合戦は専用内部ステップで進行するが、経過時間は共通世界時刻へ反映する。
- **非停止時**：合戦中も全国AI・他地域の出来事・書状配送・期限が進む。
- **プレイヤーによる一時停止時**：戦闘と世界時刻、全国AI、配送、期限を同時停止する。
- **自動停止時**：緊急性・戦況・プレイヤー設定に基づいて停止条件を判定し、停止した場合は同じ世界停止規則を適用する案。
- 合戦中に情報が配送された場合でも、戦場での実際の受領・認識と、通知表示・停止可否を区別する。未開封重要書状の本文を漏らさない。

## 5. 全国AIの処理
- 主人公近傍や関与中の活動は詳細処理し、遠方はイベント駆動／粗い時間粒度で簡略処理する。
- 遠方AIも各武将が実際に認識している情報に基づいて判断する。処理の簡略化は情報の瞬間伝達を意味しない。
- 詳細処理と簡略処理の切替前後で、時系列・因果関係・世界状態・セーブ／ロードの再現性を保つ方向で検討する。

## 6. 既存資料の重複・表現差の整理
| 論点 | 統合した解釈 |
|---|---|
| 「重要イベント発生時に停止」vs 認識時通知 | 発生時に内部重要度を評価。原則、主人公の認識時に通知／停止を再評価。直接危険・未開封重要書状の到達は既存の例外 |
| 合戦中も全国進行 vs 合戦停止時は全国停止 | 非停止時は全国進行。手動・自動停止が発動した場合のみ世界時刻も停止 |
| 任務中断 vs 世界停止 | 任務中断では時計と期限は進行。世界停止中のみ時計・期限が止まる |
| 補助行動の併用 | 併用可能かと、併用負荷・効率低下を別判定 |
| 委任行動と本人の知識 | 委任先の認識・権限・報告と本人の認識を分離 |
| 進捗保存 vs 無損失再開 | 進捗保存は認めるが、費用・資源・時間・条件変化の損失は残る |
| 戦闘専用時間 vs 共通世界時刻 | 合戦内部の計算ステップと、世界時刻の正本を分離し同期する |
| 遠方AIの簡略処理 vs 世界の一貫性 | 計算粒度のみ簡略化し、時系列・情報認識・因果関係を維持する |

上記は選択済みの検討案を矛盾なく読むための整理であり、未承認の詳細を新たに確定するものではない。

## 7. 残る未決定事項（重要度別）
**高**
1. 合戦内部ステップから世界時刻への換算、複数同時合戦、世界AI更新順序。
2. 合戦中の自動停止・強制停止・通知集約とプレイヤー設定の優先順位。
3. 遠方AIの簡略処理と詳細処理の切替、決定論、セーブ／ロード再現性。
4. 行動状態遷移（開始・継続・割込み・中断・引継ぎ・再開・終了）の厳密な条件。

**中**
5. 主行動／補助行動の併用許可表、危険度・集中度の負荷計算。
6. 委任権限、代理受領、報告タイミング、引継ぎ中の責任。
7. 中断・再開時の進捗保持、費用・資源損失、途中成果。
8. 移動・修行・内政等の所要時間計算と季節・能力補正。

**低**
9. 時間速度倍率、最小時間粒度、表示UI、詳細ログ・数値調整。

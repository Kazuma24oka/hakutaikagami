# 武将個人の平時・戦時：操作と判断の基本設計

**状態：7項目すべてBをユーザー採用（2026-10-19）。操作・判断の骨格を採用し、数値・例外・実装完了を一括確定しない。** 決定根拠は[選択・整合確認記録](../Decisions/2026-10-19_PLAYER_PEACE_WAR_FLOW.md)。Confirmedの既存基本原則を維持し、その後続となる操作設計を本書で管理する。

## 1. 共通の遊びの流れ

**本人が情報を得る → 自分の目的・任務を決める → 本人が行動する／人に任せる → 届いた結果から判断し直す。** 平時と戦時で別の世界時計・別の情報原則に切り替えない。

| 立場の典型例 | 平時の判断 | 戦時の判断 |
|---|---|---|
| 浪人 | 訪問先、仕官先、仲間、人脈、自分の目的 | 加勢先、引き受ける任務、生還の方法 |
| 家臣・陪臣 | 任務の達成方法、関係構築、上申 | 持ち場・担当部隊、援軍・任務変更の要請 |
| 城主・国人領主 | 所領・城・配下の経営と主家への奉公 | 出陣兵力、留守居、守備・出陣の配分 |
| 大名 | 委任先、外交・家中・所領の統合 | 戦争目的、編成、進軍方針、兵站、講和 |

この表は活動例であり、身分だけで合法実行を保証する可否表ではない。行為者・対象・管轄・権限根拠・期間と制度固有条件を照合する。浪人・家臣・城主等の全開始条件や、死亡後の継続方法は今回決めない。

## 2. 採用した7項目

IDはこの操作設計の識別用。旧63項目のID・過去のA/B/C選択とは別に管理する。

| ID | 採用したB案 | 平時の具体例 | 戦時の具体例 |
|---|---|---|---|
| PW01 | 任務＋自分の目標 | 主君の普請任務と仕官・人脈・所領経営の目標を両立させる | 担当任務を受け、自分が守りたい人物・部隊も考慮する |
| PW02 | 本人の所在を重視し、日常業務は委任 | 面会・視察へ赴き、留守の仕事を配下に任せる | 本人が率いる本隊と、離れて行動する配下を区別する |
| PW03 | 本人の拘束と競合で行動併用を判定 | 移動中の読書・書状閲覧は可能な候補だが、遠隔地の面会に同時出席しない | 移動・直接指揮と、同時に行える伝令指示等を行為別に判定 |
| PW04 | 委任は目的＋制約＋報告条件 | 徴税を任せ、資源上限・期限・減免相談・報告条件を指定 | 橋を守る、対岸への追撃禁止、増援目撃時は報告 |
| PW05 | 自分の本隊は地点指定、配下は作戦命令 | 本人と使者の移動を分離する | 本隊の位置取りを指定し、別部隊には線・経路・目標を送る |
| PW06 | 行動は自由に指定し、任務との食い違いを表示 | 任務中の私的訪問等について競合と食い違いを知らせる | 持ち場からの離脱を表示し、変更の申し出・理由報告を送れる |
| PW07 | 自動進行＋任意停止＋重要時の自動停止 | 通常業務は進行し、本人が認識した重要案件等で停止 | 直接の危険・重要な返答判断等で世界を停止する |

### PW01：任務と自分の目的

任務をこなすだけでも、完全な自由行動だけでもなく、両方を共存させる。今やるべきことと、自分がやりたいことを区別して把握できるようにする。目標達成による報酬・出世・関係変化の数値や、強制的な主筋は未決定。

### PW02・PW03：所在と行動併用

面会・現地視察・直接指揮に本人の所在地を反映し、本人・使者・軍勢を同一の移動体として扱わない。留守中も有効に委任された業務は継続する。現地にいるだけで未接触人物の秘密を知ることはない。

主行動・補助行動・委任行動を維持し、本人の拘束、所在地、時間、権限、資源等の競合で併用を判定する。単純な一日あたりの行動回数制を基本にしない。画面は「本人がしていること」「並行できる用事」「任せている仕事」を分ける。移動中にあらゆる補助行動を許すものではなく、負傷・交戦・経路等を含む具体的な併用表は未決定。

### PW04：委任

担当者、目的、使える資源、期限、裁量、報告条件を設定する。定型方針から必要項目を変更できる形とし、すべての手順を毎回入力させない。再委任は既存の権限原則に従い、委任範囲を超えない。依頼・命令・申請・越権試行は効力が異なる。目的を設定しただけで費用・資源・権限を取得したり、服従・成功を保証したりしない。

### PW05：戦場での操作

主人公が直接率いる本隊は地点指定で位置取りを判断する。別部隊には線・経路・目標を指示し、命令配送・本人認識・権限と服従判断を経て実行する。部隊を持たない武将の操作対象は本人・随行者の範囲であり、軍勢全体を直接操作できない。

左クリックで選択、右クリックで移動先指定、布陣モードで左ドラッグを基本操作として採用する。キー変更・アクセシビリティ・個別の誤操作対策は後続設計。直接操作でも実移動・隊列整理には時間がかかる。プレイヤー入力を物理的な即応や配下の絶対服従に置き換えない。

### PW06：独断と任務

行動を指定した際、本人が認識している任務との食い違いを知らせる。独断を表明する専用モードの選択を全行動の必須条件にはしない。変更の申し出や理由の報告は別途送れる。変更申請の発送だけで旧任務を変更済みにしない。

「行動は自由」は試行可能な範囲の入力の自由であり、物理条件・行動競合・権限・資源の検査や、他武将の拒否を迂回する意味ではない。越権の試行、合法性、実行成否、発覚、功績、違反、追認、事後責任を別に扱う。理由選択による自動免責、勝利による自動合法化、緊急時の無制限な権限取得をしない。

上官等の判断はその人物が得た報告・証言・認識・利害等に基づき、客観的真実を自動公開しない。任務の秘匿された変更を警告文で漏らさない。制裁・恩賞の具体的条件は未決定。

### PW07：共通時計と停止

従来の優先案だった自動進行＋任意停止を、今回の選択で採用する。重要時の自動停止も採用し、具体的な速度・閾値・通知設定は後続設計とする。

通常の面会・書状画面を開くこと自体では自動停止させず、停止状態を常に把握できるようにする。ただし重要情報の到達・認識等の停止条件が同時に成立すれば、その理由で停止し得る。面会・交渉の所要時間、返答入力中の時間保護は未決定で、無時間行動を保証しない。

世界停止時は世界時刻・配送・期限・移動・合戦等を共通に停止し、個人行動の中断とは区別する。主人公が知らない遠方事件を原因に、その真実を漏らす停止挙動をしない。重要書状は外形情報から到達時停止を判定しても、本文は未開封のまま。通常書状の本人適法受領による自動認識、代理人の認識と本人の認識の区別、偽書の真偽秘匿、同時刻通知の集約を保持する。

## 3. 平時から戦時、戦後への操作例

城で報告を読む → 主君の出陣命令を受ける → 兵力と留守居を決める → 自分は本隊と移動し城務を委任する → 軍議で左翼任務を受ける → 本隊を移動し配下へ布陣線を送る → 敵増援を目撃する → 持ち場維持・援軍要請・独断撤退を判断する → 戦後の報告・証言に基づく功績・損害・任務逸脱の評価へつなぐ。

これは操作設計の例であり、この一連の体験が実装済みという意味ではない。内政・軍事・外交・人事・謀略の既存共通分類と、実行／申請／越権試行／不可の判定を置き換えない。

## 4. 実装との対応と残課題

| 対象 | 現在の状態 | この決定による扱い |
|---|---|---|
| 共通時間・配送・期限・取消・保存 | 小規模試作で実装・検査済み | 再利用するが全制度の完成とはしない |
| 作戦線から3部隊展開・連続ズーム | 一地域・一本の線で実装・検査済み | 採用方向。全国地理・全国進軍の完成ではない |
| 本隊地点指定、配下への通常操作 | 新しい骨格は未実装 | PW05として後続実装 |
| 本人移動と平時業務・委任の併用 | 一連の体験は未実装 | PW02〜04に基づき詳細化 |
| 任務逸脱表示・独断・事後責任UI | 未実装 | PW06に基づき詳細化 |
| 重要案件自動停止・通知・面会 | 完成したプレイヤー用機能は未実装 | PW07と情報Confirmedを併せて実装 |
| 斜め見下ろし・回転・傾斜変更 | 方針採用、現在の試作は固定角＋ズーム | 傾斜範囲・地形射影・遮蔽・性能は後続 |

開始身分、死亡後継続、行動併用表、面会・移動・作業の時間、委任既定値、任務変更の効力、緊急権限と制裁、速度・停止閾値、NPC評価式、全国交通・兵站・性能は未確定。旧63項目のうち今回扱っていない詳細を一括採用しない。

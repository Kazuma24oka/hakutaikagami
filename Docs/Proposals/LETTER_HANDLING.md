# 未確定：書状の受領・開封・認識処理

状態：検討中。以下は提案であり確定仕様ではない。

## 基本方向
- 通常書状：宛先に到達した際、原則として内容を自動認識させる案。
- 重要書状：到達時には未開封として受信箱へ登録し、プレイヤーに開封・確認を求める案。
- 書状の到達、開封、内容認識、返答、実行は別の状態として管理する。
- NPCについてはプレイヤーの手動操作を要求せず、行動AIが開封・認識・対応を処理する案。

## 状態遷移案
作成 → 運搬中 → 到達 → （通常：自動認識／重要：未開封） → 開封・認識 → 返信・判断・保管。
紛失・妨害・誤配・偽書などの分岐は今後検討する。

## 重要度判定案
- 書状自体の種別（命令、仕官、軍事機密、私信など）と、宛先の身分・所属・関係性を組み合わせる。
- 重要な選択・期限・軍事行動が伴うものは重要書状候補。
- 単なる到達通知と内容通知を分離し、未開封の機密内容をUIで漏らさない。
- 重要書状の到達時に時間を止めるかは、別資料のS/A/B/Cイベント重要度規則と連携して判定する。

## 認識と機密保持の整合性
- 通常書状は自動認識のタイミングを「到達・受領」とする簡略化案。重要書状は開封まで内容未認識。
- 書状を受け取っただけで、未開封の重要書状の本文をKnowledgeRecordへ登録しない。
- 開封して知った内容は所属変更後も個人の認識として残る。
- 文書の物理的な所持・紛失と、個人が記憶した内容は別に管理する。

## 操作性の案
- 重要書状の未開封件数、差出人、受信日時、回答期限（存在する場合）を表示。
- 一時停止中でも開封・判断できる。
- 大量受信時は同一差出人・同一案件をまとめる。通常書状は履歴から閲覧可能にする。
- 期限がある書状の放置・期限切れ・再通知の挙動は未決定。

## 重要書状の自動停止判定（追加検討案・未確定）
- 緊急性、回答期限までの残り時間、書状の内容・必要な判断を組み合わせて停止を判定する。
- 即時判断が必要な敵軍接近や緊急出陣命令は自動停止候補。
- 期限間近の仕官・外交交渉は自動停止候補。
- 重要でも判断まで猶予がある軍議招集や、判断不要の戦況報告は通知のみを候補とする。
- 到達時点では内部メタデータ（緊急度、期限、要求される対応）に基づいて判定し、未開封本文はプレイヤーに公開しない。
- 到達時に通知のみでも、回答期限が近づけば再評価する。再通知・停止の閾値は未決定。
- 同時刻の緊急書状は集約し、停止処理は原則一度だけ行う。
- 書状の到達と、開封による本文の認識を分離する。自動停止しても本文を自動認識したことにはしない。
- EVENT_NOTIFICATION.md のS/A/B/C分類と整合させるが、具体的な優先順位・数値・例外は未決定。

## 回答期限切れの案件別結果（追加検討案・未確定）
- 期限切れを一律に「拒否・失敗」とせず、案件種別・当事者・情勢に応じた結果を定義する。
- 主君の出陣命令：命令不履行、評価低下、処罰の可能性。
- 仕官の誘い：勧誘取り消し、再交渉、条件変更の可能性。
- 外交交渉：交渉決裂、条件変更、相手側の独自判断の可能性。
- 軍議招集：欠席扱い、軍議は予定どおり進行する可能性。
- 援軍要請：要請元が代替策を採る。戦況次第で結果が変化する可能性。
- 私信：期限なし、または関係性に応じた影響。
- 回答期限と行動・実行期限は別の値として扱う（例：返答期限と出陣期限）。
- 期限はゲーム内時間で扱い、書状の到達遅延、未開封、開封後の判断、返答の配送遅延を区別する。
- 期限経過時の判定は、案件の現在状態と当事者の行動を確認して行う。期限後に届いた返答をどう扱うかは案件別に検討する。

### 追加の未決定事項

- 期限を過ぎた場合の結果定義をデータ駆動で管理する粒度。
- 延期申請、代理回答、催促、取り消し、期限切れ通知の条件。
- 期限前に状況が変わった場合の案件失効・再設定。

## 案件別の回答期限起点（追加検討案・未確定）
- 期限の起点を案件ごとに「発送時」「到達時」「開封時」から選べる設計を優先検討する。
- 発送時起点：軍事命令・外交上の通告など。伝達遅延により受信者の対応可能時間が短くなる可能性がある。
- 到達時起点：仕官の誘い・通常の回答依頼など。受信者に一定の検討時間を確保しやすい。
- 開封時起点：個人的な依頼・特殊イベントなど。ただし未開封のまま無期限に先延ばしできないよう、開封可能期間または案件自体の失効期限を別に設ける案を検討する。
- 回答期限の起点と、回答が成立する時点（返信の発送時／相手への到達時）は別項目として管理する。
- 期限切れの結果は、前述の案件別結果定義に従って処理する。期限後到達や代理受領の例外を想定する。

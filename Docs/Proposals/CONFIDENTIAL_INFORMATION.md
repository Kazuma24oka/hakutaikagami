# 未確定：機密情報の記憶保持とアクセス権失効

状態：検討中。以下はすべて提案であり確定仕様ではない。

## 基本方針案
個人が実際に知った情報は、出奔・離反・独立・移籍後も認識情報として保持する。一方、所属や役職に依存する旧組織の共有情報へのアクセス権は、所属変更時に原則失効する。

## 状況別の挙動案
| 状況 | 挙動 |
|---|---|
| 機密情報を本人が受領 | 個人の認識情報に記録 |
| 旧主家から離反・出奔 | 既知情報を保持 |
| 旧主家が新しい機密を入手 | 原則アクセス不可 |
| 新勢力に仕官 | 既知情報を伝達できる可能性 |
| 旧主家の内通者と連絡 | 別経路で新情報を取得できる可能性 |
| 情報が古くなる | 記憶は保持しつつ鮮度・有効性が低下 |

## 分離すべき概念
1. 個人の記憶：本人が受領・観測した内容。所属変更だけでは消去しない。
2. 組織の情報：勢力・家臣団の共有保管情報。閲覧には現在の権限が必要。
3. 物理資料：書状、軍事文書、地図など。記憶とは別に所持・盗難・奪還を扱う余地を残す。
4. 情報の正確性：本人が信じる内容と事実を区別し、古い計画や誤報も残り得る。

## アクセス制御案
- 所属変更時に組織・役職ベースの閲覧権限を再評価し、旧組織の新規共有更新を遮断する。
- 既に本人の認識へ取り込まれた内容は削除しない。
- 共有情報を「閲覧できた」だけで記憶したとみなすかは未決定。明示的な閲覧・報告受領を条件とする案を検討する。
- 旧組織との秘密連絡や諜報は、新しい情報の伝達経路として別に判定する。
- 情報を新勢力へ伝える行為には、信頼・忠誠・利益・機密性などの判断を加える余地がある。

## 未決定事項
1. 閲覧可能な情報をどの時点で「本人が知った」と判定するか。
2. 家臣団兼属、役職解任、捕縛、家督相続、組織分裂の権限移行。
3. 文書持ち出しの対象・検知・罰則・回収の粒度。
4. 情報の忘却を導入するか、古さ・不確実性のみで表現するか。
5. 秘密漏洩や内通のAI判断とプレイヤーへの通知。
6. セーブ・ロード時の権限と個人記憶の整合性。

## 1. 勲功と恩賞（G-A2）

### 下天禄では
- 仕事をするたびに勲功が貯まる。
- 放置すると不満が募り、忠誠が下がる。
- 論功行賞で知行・昇進・物品・金・感状を与えて消化する。

### 百代鏡での案
勲功を新しい通貨にはしない。**既存の審査（`MissionReview`）が「主君の手元に残る記録」になったもの**として扱う。

```
任務完了 → 返報が主君に届く → 主君の審査（既存）→ 評価通知が本人に届く（既存）
                                  ↓
                         主君の「勲功帳」に1行追加（新規）
                                  ↓
          恩賞の判断（主君NPCが勲功帳・関係・家の財布を見て決める）
                                  ↓
          恩賞の申し渡し（面会 or 書状）→ 本人の受領 → 給付・役目・知行の変更
```

- 勲功帳は**主君が知っていること**の記録。主君に届いていない働きは載らない。
  - 返報が不達なら勲功にならない。これは百代鏡の情報設計そのもの。
- 本人の画面に出すのは「自分が評価通知で知った分」だけ。主君の帳面を直接は見られない。
- 未消化の勲功は、数値の忠誠を減らすのではなく、**本人（NPC）が主君に対して抱く事実**として記録する。
  - 例: 「熱田の点検を3度果たしたが、恩賞の沙汰がない」
- NPCの家臣は、その事実を辞去や他家への仕官を考える判断材料にする（BD-14、BD-58）。

### 例: 本人が家臣側のとき
1. 1560年5月、本人は清洲で信長から熱田街道の点検を3回受けて、すべて返報した。
2. 3通の評価通知は、どれも「達成」だった。
3. 6月1日、信長側の勲功帳に3行がある。信長NPCの月初判断で「恩賞を与える」が選ばれる。
4. 清洲で面会すると、下部会話帯に次のように出る。
   > 信長「熱田の道の見立て、三度とも確かであった。今後は月に米二十を扶持として遣わす」
5. 既存の `HouseSalary` の提示として届く。本人が受ければ月額給付が始まる。
6. 勲功帳の3行に「恩賞済み」と記録される。

### 例: 本人が当主側のとき（録画の論功行賞に相当）
1. 配下の作成武将が、運搬を2回、点検を1回果たした。
2. 当主の画面「家中」に、配下ごとの未消化の勲功が並ぶ（自分の勲功帳なので正確に見える）。
3. 恩賞の種類から選ぶ。
   - 銭（私財から）
   - 扶持の加増（`HouseSalary` の新契約）
   - 役目（`WorkDuty` の担当や城主任命）
   - 物品（G-B5 の実装後）
   - 感状（書状として届く。名声の根拠になる）
4. 申し渡しは、配下が現地にいれば面会、遠方なら書状で行う。書状は配送中に失われることもある。

### データ追加（最小）
- `MeritRecord(Id, Principal, Subject, Task, Review版, KnownAt, Weight, Settled?)`
- `RewardGrant(Id, Principal, Subject, Kind, Amount/Term, Merits[], DeliveredBy, At)`
- 本人（NPC）の事実: `GrievanceFact(Subject, Principal, Merits[], Since)`。既存の `WorkTrustFact` と同じ形にする。

### 決めること
| 論点 | 案 | 推奨 |
|---|---|---|
| 勲功の重み | A: 達成なら一律1点 / B: 任務の種類と難度で変える / C: 金額換算 | **B**（点検1、運搬2、軍務の実働3など。試作値） |
| 不満が出るまでの期間 | A: 一律3ヶ月 / B: 性格で1〜6ヶ月 | **B**。ただし性格の実装（BD-14）までは一律3ヶ月で始める |
| 本人に見せる量 | A: 自分の勲功の数値 / B: 受け取った評価通知の一覧だけ | **B**。数値は主君の頭の中にあるもの |
| 下天禄の「発言力」に相当するもの | A: 消費する通貨として導入 / B: 導入せず、上申の通りやすさは勲功・関係から主君が判断 | **B**。上申の画面に「通りそうか」の手応えだけを出す（G-U1 の翻訳） |

## 2. 仕事の種類を増やす（G-B1）

### 下天禄では
- 酒場の仕事は5種類（退治・探物・護衛・物資・宅配）。
- 報酬の幅は100〜13000ほどあり、序盤の主な遊びになっている（録画の約4分の1）。

### 百代鏡での案
今ある「点検」「小口送金の運搬」に、**既存の部品を組み合わせるだけで作れる3種類**を足す。退治は個人戦が要るので後回しにする。

| 下天禄 | 百代鏡での仕事 | 使う既存部品 | 新規に要るもの |
|---|---|---|---|
| 宅配 | **書状の使い**：指定の相手へ封書を期限内に届ける | 物理配送、受領証、期限 | 本人が伝令役を務める入口 |
| 物資 | **買付納品**：依頼主の銭で米・木材を買い、指定の蔵へ納める | `MaterialMarkets`、`HouseLogistics`、預り金 | 依頼主がNPC商人・寺社の場合の財布 |
| 護衛 | **道中の同行**：商人・使者に付き添って次の拠点まで行く | `PersonalCompanions`（逆向き）、`TransportWork` | 依頼主側が随行される側になる形 |
| 探物 | **名物の探索**：特定の品を市で見つけて買う | 市場、G-B5（名物） | 名物の実装後 |
| 退治 | **賊の討伐** | — | 個人戦かそれに代わる仕組み（G-B2） |

### 例: 書状の使い
1. 熱田の神官NPCから相談される。
   > 神官「この書状を明後日の日没までに、清洲の村井殿へ届けてはもらえぬか。礼は三十文」
2. 引き受けると、本人の荷物に封書（未開封、本文は見えない）が入る。
3. 本人が清洲へ実際に歩く。途中で行先を変えれば、期限に間に合わないこともある。
4. 清洲で村井NPCに手渡すと、受領証を受け取る。
5. 熱田へ戻って神官に受領証を見せ、報酬を受け取る。
   - 戻らずに別の用事へ行ってもよい。その場合、報酬は未払いのまま残る（既存の未払い保持）。
6. 神官→本人の `WorkTrustFact` が1件増える。次は額の大きい依頼が来る（`WorkFollowup` と同じ考え方）。

### 例: 買付納品
1. 甲府の寺の僧から相談される。
   > 僧「普請に木材が二百斤要る。銭二千文を預けるゆえ、府中の市で買い、寺の蔵へ納めてくだされ。手間賃は五十文」
2. 預り金2000文を受け取る。私財とは別の扱い（既存の預り金と同じ）。
3. 市で木材を買う。相場が高ければ買える量が減る。
4. 寺の蔵に納め、余った金を返し、手間賃を受け取る。

### 決めること
| 論点 | 案 | 推奨 |
|---|---|---|
| 依頼の出どころ | A: 拠点ごとの「仕事の口」（下天禄の酒場相当）/ B: 現地のNPCに個別に相談される / C: 両方 | **B**。既存の「現地NPCの自動依頼」（NpcWork）を広げる。口入れ屋は後で拠点の施設として足せばよい |
| 最初に足す種類 | 書状の使い / 買付納品 / 道中の同行 | **書状の使い → 買付納品**の順。どちらも既存部品だけで作れる |
| 報酬の幅 | A: 20〜300文に留める / B: 名物探索などで数千文まで | **A**から始め、名物の実装時に広げる |

## 3. 能力と特技（G-A1）

### 下天禄では
- 4能力（7〜150）と武芸、兵科適性5種、特技のIDリストを持つ。
- 数値が成否や戦闘力に直接効く。

### 百代鏡での案
能力を「成功率」には使わない。**同じ行動をしたときの「質」と「時間」と「分かること」**に効かせる。

| 能力（BD-13） | 効く場面（既存機能） | 例 |
|---|---|---|
| 統率 | 部隊の布陣・再集結の速さ、敗走しにくさ | 再集結の60秒が、統率が高いと45秒になる |
| 武勇 | 接触戦の損害の与え方、士気の崩れにくさ | 士気25で敗走するところ、20まで持ちこたえる |
| 知略 | 点検で分かることの多さ、偽報の見抜き | 点検の報告に「封鎖の原因」まで書ける |
| 政務 | 給付・運搬・市場の手際（時間・手数料） | 買付で相場より安く買える、運搬の準備が早い |
| 交渉 | 相談の条件、不戦交渉の対案 | 運搬の手間賃を1段上で提示される |

- 特技は「固有の才」として、効果の種類と係数をデータ表で持つ（例: 「道に明るい」＝点検の所要時間−20%）。
- **本人の能力は正確に、他人の能力は推定で**見せる（BD-16）。
  - 例: 「知略：高そう（熱田の点検を2度共にした印象、5月）」
  - 一緒に働くほど推定の幅が狭まる。

### 例
- 知略の高い本人が熱田を点検する。
  - 報告に「橋の板が腐っている。十日もすれば通れなくなる」が加わる。
  - 主君の審査で差異の説明が厚くなり、勲功の重みが上がる（第1節とつながる）。
- 政務の低い本人が買付を引き受ける。
  - 市での交渉に時間がかかり、納品の期限ぎりぎりになる。失敗はしない。

### 決めること
| 論点 | 案 | 推奨 |
|---|---|---|
| 値域 | A: 1〜100 / B: 1〜20の段階 / C: 下天禄と同じ1〜150 | **A**（作成武将の予算計算が楽） |
| 兵科適性・個人武芸 | A: 入れる / B: 後で | **A**。データ項目だけ先に持ち、効果は合戦の拡張時に入れる |
| 他人の能力表示 | A: 段階＋推定幅＋出典 / B: 段階のみ | **A**（BD-16 どおり） |

## 4. 寿命・死亡・出生・成人（G-A3）

### 下天禄では
- 没年に達すると確率で死亡する。
- 子がランダムに生まれる。
- 成人すると出仕の会話が出る（録画の最後に発生）。

### 百代鏡での案
既存の**生前の当主交代（`HouseSuccession`）**を土台にし、「死亡による交代」を足す。
死亡も出生も**出来事として、書状や噂で人に伝わる**ようにする。

```
死亡（真実）→ 現地の人だけが即座に知る → 訃報の書状・噂が街道を伝わる → 遠方の人は遅れて知る
                    ↓
         家の当主なら：後継の決定（遺言 / 家中の合議 / 係争）
                    ↓
         既存の HouseSuccession の「適用」と同じ処理で個別に引き継ぐ
```

### 例: 遠方の主君の死（本人は家臣）
1. 本人は小田原への運搬の途中にいる。主君は清洲で病死する（没年の目安＋加齢による判定）。
2. 本人はまだ知らない。画面は今までどおり。
3. 2日後、清洲から本人宛ての書状（重要書状）が届き、自動停止する。差出人は家老。
4. 開封すると「殿、ご逝去。嫡子が家督を継がれた。急ぎ帰参されたし」と書かれている。
5. 本人が運んでいる荷と預り金の契約は、**元の家と元の依頼主のまま**残る（既存の個別承継の原則）。
6. 帰参すると、新当主と現地で奉公を確認し直す。これは既存の「個人奉公の再合意」をそのまま使う。

### 例: 子の成人（録画の場面の翻訳）
1. 1563年正月、本人の子が15歳になる。
2. 本人が自宅の拠点にいれば、下部会話帯でその場で会話が起きる。遠方にいれば、家族から書状が届く。
   > 子「父上、わたしも当家のお役に立ちたく存じます」
3. 選択肢は「主君に推挙する」「自分の随行者にする」「まだ早い」。
   - 推挙は既存の仕官の流れ、随行は `PersonalCompanions` を使う。

### 決めること
| 論点 | 案 | 推奨 |
|---|---|---|
| 死亡の決め方 | A: 史実の没年で確定 / B: 没年の目安＋加齢・病気・負傷で確率 / C: モードで切替 | **C**。史実尊重モードはAに近く、仮想モードはB |
| 出生 | A: 史実の子のみ / B: 架空の子も生まれる / C: モードで切替 | **C** |
| 主人公が死んだとき | A: 認識できる後継へ操作を移す（BD-07）/ B: 年代記を閉じる | **A**。後継がいなければB |
| 成人年齢 | 15歳 / 16歳 | **15歳**（試作値。既存の「成人家臣」の判定に合わせる） |

## 5. 一族を最小の部隊にする（G-B3）

### 下天禄では
- 主人公の家族5人がそのまま1部隊（小隊5つ）になり、合戦に出る（録画）。

### 百代鏡での案
既存の**家中の軍務（HouseholdMilitary）**と**随行（PersonalCompanions）**を合わせる。
**一族は「自分の家の家臣」**として、自分の軍務に連れていける。

### 例
1. 本人（家臣）が主君から軍務を受ける。既存の流れで兵100を預かる。
2. 本人の家には成人した子が2人いる。どちらも本人の家臣になっている。
3. 布陣では、預かった100人を3分隊に分け、分隊の現地指揮を子に任せられる。
   - 指揮の委任は既存の分隊別の命令で、配送も既存のものを使う。
4. 子が育つ（経験・能力の成長）と、分隊の崩れにくさや再集結の速さが良くなる（第3節とつながる）。
5. 戦死すると、家督の候補が減る（第4節とつながる）。

### 決めること
| 論点 | 案 | 推奨 |
|---|---|---|
| 一族の兵 | A: 一族が自前の兵を持つ（下天禄式）/ B: 兵は主家から預かるだけで、一族は指揮役 | **B**から始める（既存の兵の所有原則と合う）。A は所領を持つ身分の実装時に |
| 一族以外の家臣 | 同じ扱いにする / 一族だけ | **同じ扱い**。一族は忠誠の根拠が強い、という差だけを付ける |

## 6. 人物どうしの関係（G-A4）

### 下天禄では
- 全員の組み合わせの友好度（既定値50）を持つ。
- 訪問・贈物・茶会・紹介状で変化する。

### 百代鏡での案
既存の `WorkTrustFact`（仕事を根拠にした方向別の信頼）を**一般化**する。
**数値ではなく「根拠付きの事実」を貯め、判断のときに評価する。**

| 事実の種類 | 例 | 生まれるきっかけ |
|---|---|---|
| 仕事の信頼 | 「熱田の点検を果たした」 | 既存 |
| 恩 | 「恩賞を受けた」「米を分けてもらった」 | 第1節、給付 |
| 不満 | 「恩賞の沙汰がない」 | 第1節 |
| 面識 | 「清洲で会って話した」 | 訪問（新規）、茶会（後で） |
| 紹介 | 「村井殿の紹介状を持っている」 | 紹介状（新規）。面会できる相手が増える |
| 血縁・婚姻 | 「娘婿」 | 第4節、G-C1 |

### 例: 紹介状
1. 本人は浪人で、甲府の武田家に仕官したい。だが家中に面識がない。
2. 小田原で北条家の家臣と仕事を重ね、仕事の信頼が2件たまっている。
3. その家臣に頼むと、甲府の知人宛ての紹介状（封書）を書いてくれる。
4. 甲府でそれを渡すと面会でき、仕官の相談ができるようになる。
5. 紹介状は書状なので、なくすこともある。

### 決めること
| 論点 | 案 | 推奨 |
|---|---|---|
| 表現 | A: 事実の積み上げだけ（数値なし）/ B: 事実から好意・敬意・恐れ・敵意の4軸を計算して内部で持つ | **B**。ただし画面には事実と手応えだけを出す |
| 訪問の入口 | A: 現地の人物を選んで「話す」/ B: 用件を選んでから相手を選ぶ | **A**。既存の下部会話帯に乗せる |

## 7. 入れる順番の案（当初案。決定は第9節の12番）

| 順 | 内容 | 理由 |
|---|---|---|

## 10. 計略（G-B6・G-C5）

2026-10-30 にユーザーと1件ずつ相談して決定した。

### 現状（2026-10-30時点）
- **設計**: 謀略は5つある行動分類の1つ（BD-10）。身分ごとに試せる謀略が決まっている（浪人＝秘密交渉・情報提供、家臣＝内通・離間・密約、城主・国人＝独立の根回し・内応、大名＝密偵・離間・内応の委任）。独立・離反は「秘密の接触 → 支持を集める → 宣言 → 各人が従うか判断 → 独立／係争／失敗」（BD-46）。偽書は本物と同じ外形なら同じように停止する（I07）。
- **実装済み**（R4「内応の前段階」）: 私的な情報提供（PrivateInformation）、相手当主の出撃見合わせ（PrivateStanddown）、単発の点検協力、個人の直属合意、不戦交渉、敵対意思の宣言と撤回。
- **未実装**: 内応そのもの、離間・流言・偽書・密偵・暗殺・煽動、発覚と追及、独立・離反（BD-46 は foundation）。

### 決定

| # | 論点 | 決定 |
|---|---|---|
| K1 | 実行の形 | **本人も委任もできる**。本人が現地へ行って実行するか、配下・雇った者に任務として任せる。任せた場合は実行者が実際に歩いて行き、結果は返報で届く。返報が届くまで、うまくいったかは分からない。既存の任務・委任・返報をそのまま使う |
| K2 | 入れる計略 | **4系統すべて**。<br>・情報系：流言・偽書・密偵<br>・調略系：離反・内応<br>・破壊系：放火・破壊・強奪・煽動<br>・暗殺<br>**自分の家の中（主君・同僚）にも仕掛けられる**（下天禄にはない、梟雄プレイのため。信長の野望 蒼天録のイメージ）。例：不満を抱える同僚の城主と「時が来たら一緒に立とう」と密約を結ぶ（共同独立の約束）、主君の重臣に流言を流して仲を裂く |
| K3 | 成否の決め方 | **種類ごとに分ける**。調略系・情報系は相手の判断（相手NPCが利害・関係・不満・性格・自分の知識から判断）。破壊系・暗殺は成功率で判定する |
| K4 | 成功率の表示 | **手応えの段階だけ**（例「勝算はある」「危うい」「ほぼ不可能」）。成功率は内部でだけ計算する。本人が知らない警備の強さは手応えに反映されないので、事前に密偵や点検で調べる価値が生まれる |
| K5 | 発覚 | **証拠が伝わって発覚する**。証拠は、現場で見られる・実行者が捕まって吐く・密書が押収される・密約の相手が密告する、のどれかで生まれる。証拠が書状や噂で届いた人だけが知る。知った主君は、詰問・監視・処分・討伐、または知らぬふりを自分で判断する。本人は、密書が届かなかったことも押収されたことも、すぐには知らない |
| K6 | 暗殺の対象 | **誰でも狙えるが、護衛で難しくなる**。当主・大名ほど護衛が厚く、居城の奥ではほぼ不可能。道中や少人数での移動中が狙い目で、所在を知るために密偵が要る。実行すると護衛との少人数の接触戦になり、成否は確率（K3）。失敗や捕縛で証拠が生まれる（K5）。どの歴史モードでも起きうる（決定9） |
| K7 | 入れる順番 | **系統ごとに、土台ができた直後に割り込ませる**。<br>1 関係 → 2 勲功・顔 → **2a 情報系（流言・偽書・密偵）** → 3 仕事 → 4 能力 → 5 賊の接触戦 → **5a 破壊系** → **5b 暗殺** → 6 家督 → **6a 調略系（離反・内応・共同独立）** → 7 募兵 → 8 一族 |

### 例

**流言（情報系・家の中へ）**
1. 本人は織田家の家臣。同僚の重臣が邪魔なので、「あの方は今川と通じている」という流言を流したい。
2. 配下に任務として任せる。配下は清洲の城下で噂を撒き、返報を送る。
3. 噂は人から人へ伝わり、聞いた人の認識に「そういう噂がある」として入る。
4. 主君は、自分が知っている事実と照らし合わせて判断する。
   - 「先月、その重臣に恩賞を与えた」「重臣は一族だ」なら信じない。ただし噂があったことは覚えている。
   - 重臣に「恩賞の沙汰がない」不満があると主君が知っていれば、疑い始める。
5. 噂の出どころを辿られて配下が捕まれば、証拠が生まれる（K5）。

**共同独立の密約（調略系・家の中へ）**
1. 本人は城主。同じ家の城主Aには「恩賞の沙汰がない」という不満の事実がある。
2. Aと現地で密かに会い、「時が来たら共に立つ」と密約を結ぶ。Aは利害・関係・不満から判断して応じる。
3. 密約は密書として互いに保管される。押収されれば証拠になる。
4. 本人が独立を宣言したとき、Aが本当に立つかはその時点のA自身の判断で決まる。密約は約束であって、強制ではない（BD-46）。

**放火（破壊系）**
1. 甲府の蔵を焼きたい。手応えは「勝算はある（蔵の見回りは不明）」。
2. 先に密偵を送り、「見回りは夜半に手薄」と知る。手応えが「勝算が高い」に上がる。
3. 実行者が夜に蔵へ近づく。見回りに見つかれば少人数の接触戦か逃走になる。
4. 火がつけば、蔵の実米が実際に減る（既存の地域経済の台帳）。

**暗殺**
1. 対象の居場所で手応えが変わる。
   - 清洲城の奥：ほぼ不可能
   - 城下の寺での茶会：危うい
   - 熱田への道中（供10人）：勝算はある
2. 密偵で道中の日程を知ってから、実行者を待ち伏せさせる。
3. 失敗して実行者が捕まると、依頼主が露見する可能性がある（K5）。

| J5 | 官位・官途名 | **取次で奏請＋主君の許可＋自称**。正式な官位は、公家や武家伝奏などの取次ぎを経て朝廷に奏請し、献金を納めて得る（書状で往復し数ヶ月かかる）。家臣は主君の許可が先に要る。官途名・受領名は主君が許す（例「以後、内蔵助と名乗れ」）か自称でも名乗れるが、自称は信用が低い。効果は BD-54 どおり認知・取次・信用・資格だけで、所領や軍勢は得られない |
| J6 | 幕府職（守護など） | **正統性として効かせる**。幕府へ取次いで申請し、将軍の判断で補任される。正統性は**大義名分**という根拠の事実として持ち、判断の材料になる。<br>・根拠の強さの例：守護職（将軍から正式に補任）＝強、〇〇守（朝廷から正式に任官）＝中、〇〇守（主君が許した受領名）＝弱、〇〇守（自称）＝ごく弱、将軍の御内書・旧主の仇討ち・血縁による継承権＝案件ごと<br>・**開戦**：敵対意思の宣言に大義名分を書いた檄文を添えられる。家臣・国人は軍役に応じるかの判断に使い、大義のない私戦では渋る・遅れる者が出る<br>・**他家の反応**：中立・同盟の家が正当な戦かを判断し、援軍や非難の材料にする<br>・**支配の後**：その国の守護職があれば、国人・寺社・村は「守護に従う理由」を持った状態で始まる。なければ服従は利害と恐れだけで決まる<br>・大義名分は檄文や書状が**届いた人だけが知る**。実際の支配や兵は得られず、それでも従わない国人はいる |
| J7 | 登用 | **条件を提示して誘う**。浪人には現地で会うか書状で、扶持・知行・役職・席次の条件を示す。相手は条件・関係・他家からの誘い・旧主への思いから判断する。他家の家臣への誘いは計略の「離反」（K2）として扱い、発覚がある（K5）。家臣の本人が誘う場合は、自分の配下にする（自分の米で養う）か、主君に推挙して直臣にする（推挙は勲功にもなる）を選べる。配下を一括で移すことはしない（I06） |
| J8 | 順番 | **家中は早く、中央は最後**。<br>1 関係 → 2 勲功・顔 → 2a 情報系 → **2b 席次・登用（条件提示）** → **2c 家中役職（常設・任命・上申）** → 3 仕事 → 4 能力 → 5 賊 → 5a 破壊系 → 5b 暗殺 → 6 家督 → 6a 調略系 → **6b 家の規模の段階** → 7 募兵 → 8 一族 → **9 官位・幕府職・大義名分（中央政治 BD-53〜56 と一緒に）**。9 までは、開始時の史実の官位・守護職を表示だけする |

### 例

**奉行の空席への任命**
1. 織田家で奉行の席が一つ空く。
2. 信長NPCは、自分が知る範囲で候補を比べる。候補Aは譜代で勲功帳8行・政務が高そう、候補Bは新参で勲功帳12行、本人は新参で勲功帳6行。
3. 本人は、顔の利く村井に取次ぎを頼む書状を送る。村井が信長に推挙する。
4. 信長は候補Aと本人で迷い、譜代の候補Aを選ぶかもしれない。席次が効く場面。

**浪人の登用**
1. 本人は浪人の前田に、扶持 月米30・席次 新参を提示する。
2. 前田には今川家から月米40の誘いもある。ただし本人とは熱田で共に働いた事実がある。
3. 前田は「米は少ないが、貴殿の下なら」と応じる。

**守護職と大義名分**
1. 美濃を攻め取った後、美濃守護職を望み、幕府の奉公衆に取次ぎを頼む。
2. 将軍が自分の知る情勢で判断し、補任の御内書が届く。
3. 美濃の国人には「守護に従う理由」ができ、旧主の斎藤家より正統性で上回る。それでも従わない国人はいる。

## 12. 家督の相続（後継順位・誓紙・家督争い）

2026-10-30 にユーザーと1件ずつ相談して決定した。直系が絶えたときの候補の考え方は、ユーザーが示した図（当主の子がいなければ、当主弟・前当主弟・他家に出た血筋・婿養子・主家の息子から次期当主が選ばれることが多い）に基づく。

### 現状（2026-10-30時点）
- **実装済み**: 生前の当主交代（`HouseSuccession`）のみ。当主が現地にいる成人の直属家臣を後継に指名し、本人が確認すると交代する。候補の基準は直属かどうかだけで、血縁は見ていない。
- **未実装**: 親子・兄弟・夫婦のデータ、死亡による相続、遺言、家督争い（BD-45 は foundation）、婚姻・養子縁組（BD-43 は design_only）。
- **設計の方針**: 候補は血統・養子・遺言・家法・家臣の支持・城の占有を根拠に立て、どれか一つでは自動決着しない。争いは係争と暫定管理へ進む（BD-45）。主人公の操作は、生前に指定・認識された成人の家族・養子・後継候補へ移せる（BD-07）。

### 決定

| # | 論点 | 決定 |
|---|---|---|
| S1 | 候補の範囲 | **4種類すべて**：子・兄弟・叔父（家内の血縁）、他家に出た血筋（姉妹・叔母が他家に嫁いで産んだ子など。呼び戻すにはその家の同意が要る）、婿養子・養子、主家など強い家からの養子。加えて、**当主が後継を指名し家臣に事前の承認を求める**（信長の野望 蒼天録の形）、**後継の順位が家臣の忠誠に影響し、家督争いにつながる**ようにする |
| S2 | 後継の順位 | **既定の順位＋当主が変えられる**。家法の既定順位（嫡男 → 次男以下 → 当主弟 → 叔父 → 他家に出た血筋 → 婿養子 → 養子）があり、当主はそれを入れ替えて嫡子を指名できる。既定から外れた指名ほど家臣の反発や、外された候補の不満が生まれる。例：次男を嫡子とすれば、嫡男に「廃嫡された」事実が残る |
| S3 | 家臣の承認 | **重臣へ個別に説き、誓紙を取る**。当主が重臣・城主に面会か書状で「嫡子は○○」と伝え、納得した者から誓紙（起請文）を取る。各家臣は関係・席次・候補との関係で判断し、留保や拒否もある。誓紙は物理的な書状として保管され、後で「約束したはず」の根拠になる。当主の画面には「承認○人／留保○人／未達○人」が出る |
| S4 | 忠誠への影響 | **候補との関係で家臣ごとに**。家臣はそれぞれ推したい候補を持つ（候補との関係・席次・母方の家・正統性から）。指名が推しと一致すれば当主への好意が増し、違えば不満の事実が残る。既定順位から外れた指名ほど「道理に合わない」反発が大きい。不満は勲功の不満（決定2）と同じ事実として、辞去・離反・後の家督争いの判断材料になる。例：嫡男の傅役は廃嫡に不満、次男と親しい重臣は好意が増す |
| S5 | 家督争い | **家臣が各自つく側を選ぶ**。訃報が届いた家臣から順に、誓紙・推し・関係・利害でどちらにつくかを判断する。各候補は支持を集め、説得（所領を安堵して譲らせる）・調停（主家や寺社に頼む）・出家（敗れた側が寺へ）・合戦（稲生の戦いのように）のどれかで決着する。本拠を占有した側が有利だが絶対ではない。その間は暫定管理で、既存の委任は安全の範囲で継続する |
| S6 | 強い家からの養子 | **どちらからも申し入れられ、家臣が割れうる**。直系が絶えそうな家が主家に養子を頼むことも、主家が「我が子を迎えよ」と申し入れることもある。主家側は、家を取り込む調略（K2）としても使う。受けると主家が後ろ盾になるが、主家寄りの家臣が増え、旧来の血筋を推す家臣に不満が出る。断ると主家との関係が悪化する |
| S7 | 未成年の後継 | **後見人が代わりに治める**。家督は未成年の後継が継ぎ、後見人（一族の年長者・重臣・母など）が元服まで期限付きで政務を代行する。後見人が実権を握る、家臣が「乱世に幼君は危うい、叔父を当主に」と動く、などの種になる。主人公の操作は、認識済みの成人の後見人へ移せる（BD-07） |
| S8 | 順番 | **家督を3段に分ける**。<br>… 5b 暗殺 → **6-1 血縁データ・死亡・訃報・出生・成人** → **6-2 婚姻・養子縁組、後継順位・指名・誓紙** → **6-3 家督争い・後見・強い家からの養子** → 6a 調略系 → 6b 家の規模の段階 → 7 募兵 → … |

### 例

**廃嫡と家督争い**
1. 当主には嫡男（15歳）と次男（12歳）がいる。当主は次男を気に入り、「次男を嫡子とする」と指名する。
2. 重臣に個別に説いて回る。次男と親しい重臣は誓紙を出す。嫡男の傅役は不満を抱え、別の譜代は「少し考えさせていただきたい」と留保する。遠方の城主にはまだ使者が届いていない。
3. 数年後、当主が亡くなる。本拠を占める次男派に対し、嫡男は傅役と東の城主2人を味方につける。
4. 遠方の城主は訃報が届いてから、どちらにつくかを判断する。
5. 次男派は、嫡男に所領を安堵して譲らせる説得を試みる。決裂すれば合戦になる。

**主家からの養子（取り込み）**
1. 本人は大名。属下の国人家の当主が病弱で、直系の子がいない。
2. 本人は「我が三男を養子に迎えよ」と書状で申し入れる。
3. 国人家の当主は「直系がいない」「弟は家臣に不人気」と判断して受ける。旧臣の一部は「家を奪われた」と不満を抱く。
4. 三男が家督を継ぐと、国人家は実質的に本人の一門になる。

**幼君と後見**
1. 当主が亡くなり、嫡男は10歳。家督は嫡男が継ぎ、叔父（当主弟）が元服まで後見する。
2. 叔父が忠実なら、元服で政務を返す。実権を握れば、嫡男派と対立する。
3. 家臣の中には「叔父を当主に」と動く者も出る。

## 13. 内政（開発・奉行・治安・徴兵・一揆・城の普請）

2026-10-30 にユーザーと1件ずつ相談して決定した。開発の種類を増やす狙いは、**家臣に任せる仕事の種類を増やすこと**（ユーザー）。

### 現状（2026-10-30時点）
- **実装済み**: 村ごとの人口・働き手・季節の収穫・食料消費・飢え（全国30拠点に試作展開）、領主の内政操作3つ（年貢の徴収・救済・水利工事＝7日・米200）、村との相談と約束（不履行が続くと不信、労働協力の拒否）、代理行政と城主、NPCの地域運営、米・木材・武具の市場と工房、地域間の米の売買と運搬、家の財布と私財の分離。
- **設計のみ・残り**: 地域人口からの徴兵・逃散・帰還、史実の人口と産地、土地利用、生産のつながり、一般の普請（BD-33）、一揆・政治的な要求・広域救済（BD-52）、軍馬・火薬弾薬（BD-35）。
- **下天禄との差**: 商業・鍛冶・牧場の開発、開発の上限、治安・民衆、奉行による継続的な内政、城の改修、鉄砲などの生産、鉱山・港・城の特性がない。

### 決定

| # | 論点 | 決定 |
|---|---|---|
| N1 | 開発の軸 | **4つすべて**：農業（耕地・水利）、商業（市・町）、鍛冶・工房、牧場・鉱山・港（その土地にある場合だけ育てられる）。農業は今の水利工事の延長で収穫と年貢に、商業は市の規模・商人・品揃え・銭の収入に、工房は武具の月産と将来の鉄砲・火薬に、牧場は軍馬、鉱山は金銀、港は交易と船に効く |
| N2 | 開発の上限 | **土地と人の容量で決まる**。耕地は開ける土地（平地・水）、市は人口と街道、工房は原料と職人、牧場・鉱山・港は土地の条件で上限が決まる。人口が増えれば市や工房の上限も上がる。例：清洲（濃尾平野）は耕地の上限が広く、甲府（盆地）は耕地が早く尽きる代わりに金山がある。耕地が尽きることが外へ出る動機になる |
| N3 | 開発の進め方 | **普請の任務＋奉行の常置**。一つひとつの開発は普請の任務（働き手・物資・日数・村の協力・完了報告）で、家臣を担当に任じると勲功になる。奉行の役職（J1）に経費と方針（例「年間 銭3000文、農業を優先、収穫期は労働を取らない」）を渡すと、奉行が自分の判断で普請を次々に起こし、月ごとに報告が届く（委任） |
| N4 | 治安・民心 | **民心は事実、治安は賊と警固**。民心は村との関係の事実（約束の履行・救済・年貢の重さ・略奪など）で表し、画面は手応え（例「領主を頼りにしている」）と根拠（決定11と同じ形）。治安は「賊が実際にいるか・警固がいるか」で表す。賊は決定6の実在の集団で、放置すると商人が来なくなり村の不満が増える。警固や討伐は家臣の任務 |
| N5 | 兵の出どころ | **村の働き手から＋雇い兵**。知行・領地の村から働き手を兵として集める（村の労働が減り、収穫や普請に響く。秋に集めると村の不満）。市のある町では銭で雇い兵（浪人・足軽）を雇える（村は減らないが高く、負けが込むと逃げやすい）。合戦が終われば村の兵は村に帰る。兵と民を二重に作らない（BD-33） |
| N6 | 村の不満の行き着く先 | **段階的に、村が自分で判断する**。村の代表が、飢え・年貢・徴兵・略奪・領主との関係から段階を選ぶ：嘆願（書状が届く）→ 普請への労働の拒否（既存）→ 逃散（働き手が他の村へ移る）→ 隣村と連合 → 武装して一揆。どの段階でも減免・救済で交渉できる。武力で鎮めれば短期は静まるが不信は残る。一向宗など寺社が絡むと広がる |
| N7 | 城の防備 | **普請の一種として区画ごと**。堀・土塁・石垣・門・櫓を、開発と同じ普請の任務で整える。城は既存の「城門・本丸」のような区画を持ち、区画ごとに堅さがある。放火・破壊の計略や攻城で実際に傷つき、修繕も普請 |
| N8 | 順番 | **土台の直後に割り込ませる**（全体の順番は第14節） |

### 例

**普請奉行に任せる**
1. 当主は清洲の普請奉行に田中を任じ、「年間 銭3000文、農業を優先、収穫期は労働を取らない」と方針を渡す。
2. 田中は村の働き手と季節を見て、春に新田開発（働き手30人×30日、米200）を起こす。
3. 月ごとに報告の封書が届く。新田が開ければ次の秋の収穫が増え、田中の勲功になる。

**街道の賊と治安**
1. 熱田街道に山賊3人が出たと目撃される。警固はいない。
2. 放置すると、熱田の市に商人が来なくなり、村の不満も増える。
3. 家臣に討伐を命じる（決定6の少人数の接触戦）。追い払えば、村との関係に「賊を退治してくれた」事実が残る。

**凶作と一揆の手前**
1. 凶作なのに年貢を例年どおり取り立てる。
2. 村から「年貢を減じてくだされ」と嘆願の書状が届く。
3. 無視すると普請への労働を拒まれ、さらに取り立てると働き手の一部が逃散する。
4. 減免や救済を届ければ収まる。武力で鎮めれば静まるが、不信は長く残る。

## 15. 外交（贈り物・婚姻同盟・人質・従属・勧告・国人衆・取次・仲裁）

2026-10-30 にユーザーと1件ずつ相談して決定した。朝廷・将軍への取次と国人衆への外交も含める。

### 現状（2026-10-30時点）
- **実装済み**: 敵対意思の宣言と撤回（`FactionStances`）、不戦交渉と確認書・承継（`TruceNegotiations` ほか）、正式条約（`TreatyNegotiations`、PR37：不侵略・通行・補給・防衛援軍の独立条項と解除予告期間、同一版の承諾の到達で成立）、解除の通知、援軍・補給の要請と受領・辞退。ゲームの動きに反映されている条項は今のところ不侵略だけ。
- **本線で作業中**: 条約による補給の実物の受け渡し（`TreatySupply`）。本線の「次の五件」に「一般条約・同盟・人質」がある。
- **未実装**: 実援軍の出陣・到着、違反の裁定と制裁（BD-42）、婚姻（BD-43）、人質（BD-44）、従属・勧告、贈り物、諸勢力との交渉、NPC大名の自主外交。朝廷・将軍への取次と仲裁（BD-53〜56）はコードに何もない。国人は開始身分「国人領主」と家どうしの条約があるだけで、従属契約・自治・合議（BD-49・50）は未実装。

### 決定

| # | 論点 | 決定 |
|---|---|---|
| D1 | 贈り物 | **使者が実物を運ぶ**。銭・米・名物・馬などを使者が実際に運び、届いて初めて相手の当主との関係に「贈答を受けた」事実が残る。相手の好み（名物好き・実利好き）や使者の格で効きが変わり、格が低いと「軽んじられた」と取られることもある。返礼が来ることも、途中で奪われることもある |
| D2 | 婚姻同盟 | **婚姻と条約は別、縁戚は関係に効く**。婚姻は縁組の案件（当人と両家の同意・輿入れの移動）で、成立すると両家に「縁戚」の事実が生まれ、関係や後継の候補（他家に出た血筋）に効く。同盟の義務は別に正式条約を結ぶ（同時に結ぶこともできる）。縁戚だからといって裏切らないとは限らない（例：織田と浅井） |
| D3 | 人質 | **実在の人物が移り住む保証**。条約や従属の保証として、子や兄弟が相手の城下に実際に移り住む。人質はそこで育ち、預かり先との関係が生まれる（徳川家康の今川家時代のように）。約束が破られたときの処遇（返す・留め置く・処断）は預かり先の当主が判断し、処断は周りの家からも「苛烈」と見られる重大な政治責任になる。奪還の計略も可能。忠誠メーターや自動処刑にはしない（BD-44）。**本線の人質の作業へ入力として渡す** |
| D4 | 従属 | **条約と同じ仕組みで条項を選ぶ**。本線の正式条約（条項ごと・版・解除予告）に従属の条項を足す：軍役（何人出すか）、献上、通行、外交の制限（敵と結ばない）、人質、本領安堵（主家が所領を認める）。決めなかったことは自治に残る。条項を守らなければ違反。離脱は解除予告＋独立（BD-46）。**本線の条約の作業へ入力として渡す** |
| D5 | 勧告 | **相手が知る力と大義で判断する**。勧告の書状に従属の条件（本領安堵・軍役・人質など）を書いて送る。相手は自分が知っている軍勢の差・周りの家がどうしたか・大義名分（J6）・条件の良さ・関係から判断する。近くに大軍を置くと効く。断られたら攻めるかどうかは当主次第 |
| D6 | 国人衆 | **合議で決める連合＋個別にも切り崩せる**。国人衆は一揆契状で結ばれた連合として、外からの従属・勧告には合議で答える（賛成の条件は連合の決まり次第）。構成員はそれぞれの家なので、個別に調略・従属させることもできる。抜けた家は連合から「裏切り」と見られる。例：甲賀郡中惣（10家）で6家賛成・4家反対なら、決まり次第で拒否。反対派の1家を調略で従属させると、次の合議で賛成が増えるかもしれない |
| D7 | 取次の人脈 | **実在の公家・奉公衆と関係を築く**。京には実在の公家・武家伝奏・幕府の奉公衆がいて、面会・贈り物・紹介状で関係を作る（決定11と同じ関係の事実）。取次はその人が自分の判断で引き受ける。公家が地方に下向してくることもあり、連歌・茶の湯などの素養が関係づくりに効く。取次を通じて頼めること：官位の奏請（J5）、守護職の申請（J6）、御内書の依頼、和睦の仲裁の依頼 |
| D8 | 仲裁 | **仲裁案を受けるかは各家が判断する**。取次を通じて将軍・朝廷・有力寺社に和睦の仲裁を頼む。仲裁案（不戦・境の取り決めなど）が両家に届き、各家は権威・戦況・大義・関係で受けるか判断する。受ければ既存の条約として成立する。断れば「将軍の仲裁を蹴った」事実が残り、大義名分で不利になる（BD-56） |
| D9 | 順番 | **土台の直後に割り込ませ、人質と従属は本線へ渡す**。1a 贈り物、6-2 に婚姻同盟、7b 勧告、7c 国人衆の合議、9 に取次・仲裁（第14節に反映済み）。人質（D3）と従属の条項（D4）は、本線が進めている一般条約・人質の作業への入力として渡す |

### 例

**国人の従属と人質**
1. 水野家（国人）が織田家に従う。従属の条約で、軍役は出陣に50人、通行は織田軍に認める、外交は今川と結ばない、人質は嫡男、本領安堵は刈谷・緒川、と決める。年貢と家中の人事は自治に残る。
2. 嫡男（10歳）は清洲に移り住み、信長や家臣との関係ができていく。
3. 水野家が離反すれば、信長は人質を返す・留め置く・処断のどれかを判断する。

**勧告**
1. 美濃を取った後、南近江の六角家に「本領安堵、軍役100人、人質」で勧告する。
2. 六角家は、国境に織田の大軍がいること（物見の報告）、美濃の国人が皆従ったと聞いたこと、織田が将軍を奉じていること（大義）を見て判断する。
3. 観音寺城に自信があれば拒む。織田は攻めるか、周りを先に固めるかを選ぶ。

**取次と仲裁**
1. 織田は、尾張に下向した公家の山科言継をもてなしており、面識がある。
2. 山科に紹介状を頼み、奉公衆の細川藤孝につないでもらう。
3. 斎藤家との戦が長引いたので、細川を通じて将軍に仲裁を頼む。将軍の御内書「一年の和睦、境は現状」が両家に届く。
4. 戦況が有利な斎藤家は断りたいが、断れば「将軍の仲裁を蹴った」事実が残り、織田の大義名分が強まる。

## 16. 家中の集権化と技術（改革の案件・職人と原料）

2026-10-30 にユーザーと1件ずつ相談して決定した。問題意識は「初期の大名は国人の寄り合いの代表者のようなもので、段々中央集権化していく。それを研究ツリー（CIV式）以外でどう表すか」「鉄砲鍛冶や生産物の技術アンロックはゲームに合うか」（ユーザー）。

### 基本の考え方
- **研究ツリーは入れない**。百代鏡の主役は武将個人で、家単位で研究点を貯める抽象は家臣・浪人のプレイから手が届かない。また「研究完了で全国の自領で一斉に作れる」という瞬間的な変化は、人と物が実際に動いて効く原則と合わない。史実でも集権化は研究ではなく、家臣・国人との力関係の中で改革を一つずつ通した結果。
- **集権化＝改革の案件の積み重ねが、土地と契約の状態として残ったもの**。
- **技術＝職人と原料が、人と物として伝わること**。知る（噂・報告）→ 職人を得る（招く・雇う・引き抜く）→ 原料を得る（市場・運搬）。

### 決定

| # | 論点 | 決定 |
|---|---|---|
| H1 | 集権度の見せ方 | **状態から導き、画面は「家中の様子」**。集権度の数値は持たない。家臣の所領（本領か恩給地か）、従属の条項の重さと残る自治、家臣の城（自前の城か城下住まいか）、直轄地の割合、定めた家法、指出・検地の済んだ範囲を並べ、全体の手応え（例「国人の寄り合いから抜け出しつつある」）を出す |
| H2 | 改革の種類 | **すべて**：指出・検地（役人が村を回って所領の実態を調べる。指出は自己申告で軽く、検地は実測で重い）、分国法（家法。条文ごとに選ぶ：喧嘩両成敗、婚姻の許可制、他国との書状の禁止、後継の既定順位など。家臣の判断の既定値が変わり、破れば「法を破った」事実）、城割り・城下集住（離反しにくく動員が速いが、在地の支配は弱まる）、知行替え・楽市・関所撤廃（最も強い集権と反発、寺社・国人の既得権との衝突） |
| H3 | 改革の通し方 | **家臣ごとに判断し、強行もできる**。当主が改革を宣すると対象の家臣・国人に書状が届き、それぞれが当主の権威（勲功に報いたか・大義名分・力）と自分の損得で「従う・渋る・拒む」を選ぶ。拒んだ者には説得・解任・討伐。従属の国人には従属の条項の改定を交渉する。強行すると不満の事実が残り、離反や家督争いの種になる。分国法など家全体の決まりは重臣の合議にかけることもできる |
| H4 | 改革の前提の見せ方 | **前提は目安で、無視しても試せる**。改革の一覧に手応え（「通りそう」「反発が出そう」「危うい」「ほぼ不可能」）と「通りやすくするには」（例：城割りは検地・家法の後、大義名分があると通りやすい）を出す。満たさなくても試せるが、拒否や反発が大きい。研究ツリーの「次に何ができるか」の見通しの代わり |
| H5 | 改革の後戻り | **状態として残るが、崩れうる**。当主交代・家督争い・離反で、家臣が城を構え直す、家法を守らなくなるなど、状態が崩れることがある。家法は新当主が再確認するまで、守るかは各家臣次第（既存の当主交代の流れ） |
| H6 | 技術の種類 | **すべて**：鉄砲・火薬（鉄砲鍛冶を招く。火薬の硝石と玉の鉛は堺や南蛮貿易から。尽きれば撃てない）、石垣（穴太衆などの石工を招くと、城の普請（N7）で石垣を組める。いなければ土塁まで）、鉱山（灰吹法などの技術者を招くと、鉱山（N1）の金銀が増える）、南蛮船・大砲・南蛮の品（港・商人・宣教師との関係を通じた南蛮貿易。主に西国） |
| H7 | 職人の扱い | **実在の職人集団（技を持つ人）**。職人は個々の武将ではなく「国友の鉄砲鍛冶 十人」のような集団で、交渉の相手はその長。招くには条件（扶持・屋敷・特権）を示し、紹介状や商人との関係が効く。他家からの引き抜きは計略の「離反」（K2）。一部を別の拠点に分けて弟子を育てれば、数年でそこでも作れるようになる。城を取られれば職人も奪われる |
| H8 | 時代の流れ | **歴史モードで切り替える**。史実尊重は史実の時期に各地の職人集団が増え、周りのNPC大名も鉄砲を得ていく（例：1560年に堺・根来・国友に鍛冶、1570年代に各地へ）。準史実は時期が数年前後する。仮想は職人の移動と引き抜きだけで広がる（誰も招かなければ広がらない世界もありうる） |
| H9 | 順番 | **土台の直後に割り込ませる**（第14節に反映済み）：3c 職人集団と技術、3d 指出・検地、5d 城の普請＋石垣の職人、6c 改革と「家中の様子」 |

### 例

**改革の順序そのものが遊びになる**
1. 国人の寄り合いの代表のような家で、当主がいきなり城割りを命じると、国人衆の合議（D6）で拒否されるか、離反を招く。
2. そこで、まず勲功に恩賞で報い、指出で所領を把握し、分国法を重臣の合議に通し、大義名分を得てから城割りに進む。
3. 城割りの命令が届くと、恩給地の家臣は対象外、勲功に報いた柴田は従い、従属の国人の水野は「条約にない」と渋り、岩倉の旧臣は拒む。水野とは従属の条項の改定を交渉し、岩倉の旧臣は解任か討伐。

**家臣の立場での関わり方**
- 検地を当主に上申する、検地奉行として村を回る、城割りを命じられて従うか密約を結んで抗うか、を選べる。

**鉄砲の伝わり方**
1. 「南蛮渡りの鉄砲というものがある」という噂が届く。
2. 堺の商人との関係から紹介状を得て、国友の鉄砲鍛冶十人を清洲に招く。月に鉄砲10挺（試作値）。
3. 硝石と鉛を堺から運ばせる。途切れれば撃てない。
4. 3人を岐阜に分けると、弟子が育ち、数年で岐阜でも作れるようになる。
5. 他家の鍛冶を引き抜けば、それは計略の「離反」になる。

## 17. 征夷大将軍への道（天下人の到達点）

2026-10-30 にユーザーと1件ずつ相談して決定した。

### 現状と基本設計との関係
- 基本設計 BD-55 は、初回版では既存の将軍家の候補を擁立する政治案件だけを扱い、「新たな将軍への就任はシナリオの制度データで資格を持つ人物だけ。任意の作成武将が汎用ボタン一つで即将軍になる経路は初回対象外」としている。
- **この決定は BD-55 の変更にあたる**。「ボタン一つで将軍になる道はない」は守り、「条件を満たした者が奏請や朝廷の打診を経て任じられる道」だけを初回版に足す。採用するときは、変更の理由・影響・版・再検査を Decisions に記録する（基本設計の変更の手順どおり）。
- 位階・官職の下書き（[RANKS_AND_OFFICES_V1.md](RANKS_AND_OFFICES_V1.md)）では、天下人の到達点として太政大臣・関白（五摂家の猶子）がすでにある。ここに征夷大将軍を並べる。

### 決定

| # | 論点 | 決定 |
|---|---|---|
| Y1 | 入れる版 | **初回版に入れる**（BD-55 の変更として記録）。天下人の到達点を、太政大臣・関白・征夷大将軍の3つにする |
| Y2 | 源氏の条件 | **源氏であることが要るが、系図で得られる**。元から源氏の家（足利一門・新田一門・甲斐源氏・佐竹など）はそのまま資格がある。そうでない家は、系図を整える案件（公家や寺社に系図を調べさせる、源氏の家の養子・猶子になる）を経て、朝廷に源氏と認められて資格が生まれる（徳川家康の形）。自称ではなく朝廷が認めることが要る。源氏を名乗ったことは周りの認識にも残る |
| Y3 | きっかけ | **自分から奏請する道と、朝廷から打診が来る道の両方**。取次（D7）を通じて自分から奏請できる。加えて、覇者の段階で京を押さえていると、朝廷の側から「関白・太政大臣・将軍のいずれかに推任したい」と打診が届く（三職推任）。受けるか、どれを望むか、保留するか、断るかは自分で決める。将軍を望むなら源氏の条件が先 |
| Y4 | 現将軍との関係 | **空位が要る。廃するなら大義名分に傷が付く**。将軍は一人。現将軍が死去・辞任・京からの追放で空位になるか、朝廷が現将軍を解くのが先。自分で追放すれば「将軍を追った」事実が残り、大義名分で不利になる。追放された将軍が地方で正統を主張し、御内書を送り続けることもある（足利義昭の鞆での活動のように） |
| Y5 | 将軍の権限 | **幕府職を与える側になる**。守護・探題の補任、栄典（御相伴衆・偏諱など）の授与、和睦の仲裁を出す側（D8）になり、大義名分が最上位になる。幕府を開けば幕臣（奉公衆など）を持てる。ただし BD-54 のとおり、称号だけで所領・軍勢・全国への命令権は得られず、従うかは各家の判断で、従わない家は討伐が要る |
| Y6 | 順番 | **中央政治の最後に 9a として**（第14節に反映済み） |

### 例

**三職推任**
1. 覇者の段階で京を押さえていると、朝廷の勅使が本拠に届く。「関白・太政大臣・将軍のいずれかに推任したい」。
2. 選択肢は「関白を望む」「太政大臣を望む」「将軍を望む」「答えを保留する」。
3. 将軍を望むなら、源氏の条件（Y2）と空位（Y4）が先に要る。関白を望むなら、五摂家の猶子になる案件が先に要る。

**源氏の系図（家康の形）**
1. 元は源氏でない家が、公家に系図を整えさせ、新田一門の流れと称する。
2. 朝廷が源氏と認めると、将軍の資格が生まれる。

**将軍を追う**
1. 京にいる将軍を追放する。「将軍を追った」事実が残り、大義名分に傷が付く。
2. 追放された将軍は地方で正統を主張し、各地の大名に御内書を送り続ける。
3. 朝廷が現将軍を解くまで、自分は将軍に任じられない。

## 18. 画面での見せ方（4つの動詞・評定・陣触れ・手帳）

2026-10-30 にユーザーと1件ずつ相談して決定した。問題意識は「これまで決めたコマンドを、今の画面でどうユーザーに分かりやすく見せるか。従来型のコマンドボタンをポチポチ押す以外に、ゲームに合った形はあるか」「月一回・年一回の評定で家の方針を決めたり、一斉の出陣のために家臣に仕事を持たせないようにすることは考慮されているか」（ユーザー）。

### 基本の考え方
- コマンド一覧から選ぶのではなく、**「誰に・どうやって」から始める**。今の画面（連続地図、下部会話帯、受信箱）の上にそのまま乗せる。BD-57（主画面は連続地図、人物・拠点・線を左で選択）に沿う。
- これまで決めたコマンドは、ほぼすべて4つの動詞に入る。

| 動詞 | 使う場面 | 下天禄のコマンドだと |
|---|---|---|
| 会う | 同じ場所にいる人と、下部会話帯で話す | 訪問・茶会・登用・贈物・紹介状・師事・密約 |
| 書く | 遠くの相手へ書状を出す | 外交・勧告・取次・仲裁の依頼・誓紙の依頼・改革の布告・陣触れ |

### 決定

| # | 論点 | 決定 |
|---|---|---|
| U1 | 入口の構成 | **4つの動詞＋評定＋手帳＋予備の一覧**。地図の下の帯に [会う] [書く] [任せる] [動く] [評定] [手帳] […一覧] を置く。地図で人や場所を選ぶと、その相手に合う動詞だけが明るくなる。どこからも行けない操作のために、従来型のコマンド一覧を予備として残す。下部会話帯を開いている間は、帯の邪魔にならないようにする |
| U2 | 会うと書くの切り替え | **相手の所在で自動、両方選べる場合もある**。同じ拠点にいれば「会う」、遠くにいれば「書く」が前に出る。近くにいても書状を渡したい場合（誓紙を取る、紹介状を書かせる）は両方選べる。所在は本人が知っている範囲で判断する（実際には移動していることもある） |

| U4 | 定例の評定の頻度 | **年始＋毎月朔日、臨時も**。1月1日の「評定始め」で一年の方針を決め、毎月1日は小さな評定（案件を裁く・方針の微修正）。侵攻・訃報などの大きな出来事では、当主が臨時の評定を召集できる。どれも世界の時間の中の行事で、月ごとのターンではない（BD-21）。家臣は実際に本拠に集まる |
| U5 | 家の方針の効き方 | **家臣の判断の既定値で、違えば逸脱表示**。方針（外交・内政・軍事・人事の重点）は、家臣や奉行が自分で判断するときの既定値になる（BD-30 の委任の方針と同じ扱い）。方針と違う行動もできるが「方針に外れる」と表示され（PW06）、当主の評価に響く。方針を知らない家臣は古い方針のまま動く。例：「普請は控える」と決めれば、普請奉行は新田開発を見送って米を蓄える |

| U7 | 陣触れと他の仕事 | **警告するが、引き受けられる**。当主が「○月○日、○○に集合。軍役○人」と陣触れを書状で出すと、届いた家臣に出陣の予約が付く。集合の日までに終わらない仕事は灰色で「陣触れに間に合わない」と表示されるが、それでも引き受けられる（独断、PW06）。遅参すれば勲功や関係に響く。NPCの家臣は原則として引き受けない。奉行は兵糧・武具の調達へ切り替え、家臣は自前の兵を軍役の人数まで募る。陣触れが届かなかった家臣には予約が付かず、集合に遅れる。予約は BD-21 の本人の拘束の判定に組み込む（未来の時刻に拘束を入れておく形で、新しい時計は作らない） |
| U8 | 手帳の目標 | **自分で選び、候補を提案する**。今の身分と状況から候補をいくつか出し（浪人なら「仕官する」、家臣なら「城主になる」「扶持を増やす」「婚姻を結ぶ」「自分の家を興す」、当主なら「美濃を取る」など）、選んだ目標には手応えと「次の一手」が付く。複数持てる。既存の個人目標（仕事の報酬・扶持の受取・扶持の支払）はこの中に入る |
| U9 | 順番 | **画面の土台を最初に、他は機能と一緒に**（第14節に反映済み）。0 画面の土台（4つの動詞・手帳・予備の一覧。既存の操作をこの入口に並べ替える）、2c で評定（案件を裁く）、3b で定例の評定と家の方針、7 で陣触れ |

## 19. 時間の速さと年代記（G-X1）

2026-10-30 にユーザーと1件ずつ相談して決定した。

### 問題
- 年代記は1560〜1650年の90年（BD-08）。速度は実装で最大60倍（毎実秒60ゲーム秒）、設計でも最大360倍（BD-23）。60倍でゲーム内1年が現実の約6日、360倍でも1年に約1日かかり、90年で約2,000時間になる。世代交代を重ねる遊びが成り立たない。
- 高速にすると、今の「1秒ずつ全員を計算する」方式では計算が追いつかない（1秒に1日進めると毎実秒86,400回、全国3000人では不可能）。

### ユーザーの意図
- 「百代鏡」はとても長い時間のイメージだが、**3世代くらい遊べれば十分**。
- 90年を過ぎたら区切りとして総括や実績を出し、史実の制御だけ外して、続けたい人はそのまま遊べる（HOI4のような形）。基本設計 BD-08（1650年に総括して、史実の追加事件を保証しない仮想継続を選べる）と同じ。

### 決定

| # | 論点 | 決定 |
|---|---|---|
| T1 | 1年の長さの目安 | **標準的な遊び方で、ゲーム内1年を現実の約1時間**。1か月は約5分、1世代（30年）は約30時間、90年で約100時間。合戦や会話の間は秒の単位でゆっくり進み、何もない平時は日の単位で速く進む、という平均の目安 |
| T2 | 年代記の長さ | **90年のまま（1560〜1650年）**。1650年に総括と実績を出し、その後は史実の制御を外して続けられる（BD-08） |
| T3 | 速度の段階 | **秒の段階＋日の段階＋次の出来事まで**。秒の段階は1・10・60倍（合戦・会話用）、日の段階は実1秒あたり半日・1日・3日（平時用）。さらに「次の出来事まで」で、書状の到着や期限などに飛ぶ。どれも同じ世界の時計を速く進めるだけで、別の時計は作らない（BD-23）。例：清洲→京（5日）は「1日/秒」で約5秒、途中で賊に遭遇すれば自動で止まる |
| T4 | 開始年 | **固定のシナリオを最低3つ。ただし仕組みは何年開始でも動くように作る**。初回版は1560年を完成させ（BD-01・BD-02 のとおり）、後続で史実の節目の年を足す（候補：1551年 信長の家督の頃、1570年 信長包囲網、1582年 本能寺の変、1467年 応仁の乱）。暦・役職・人物の生没などは最初から何年開始でも動くようにし、年ごとのデータが揃えば開始年を足せる。ユーザーの理想は開始年を自由にずらせること（例：1467年）で、年ごとのデータが十分に揃った後の目標とする |
| T5 | 自動の停止と減速 | **重要なもので止まり、近づいたら減速する**。止まる：重要な書状の到着、遭遇・襲撃、合戦の開始、期限の直前、評定、訃報。減速する（日の段階→秒の段階）：敵の軍勢が近づいた、会う相手の拠点に着いた。止まるのは本人が知った出来事だけで、知らない遠方の事件では止まらない（BD-28）。各項目は設定で入切りできる |
| T6 | 高速での計算 | **次の出来事までまとめて進める**。何も起きない区間（移動中・待機中・書状の配送中など）は、次に何かが起きる時刻までまとめて計算する（既存の「静止区間だけ次のイベントへまとめて進める」仕組みを広げる）。結果は1秒ずつ計算した場合と同じになるようにする（BD-23 の受入条件：速度を変えても同じ種と入力時刻から同じ結果）。途中で何かが起きそうなとき（遭遇など）だけ細かく計算する。遠方は簡略にしても同じ判断材料で動かす（BD-58） |

### 基本設計との関係
- T3 の日の段階は、BD-23 の速度プリセット（1・10・60・360）を広げるもの。BD-23 は「速度は調整可能」としているので、プリセットの追加として扱える。
- T4 の「固定シナリオを最低3つ」は、初回版を1560年の1シナリオとする BD-01・BD-02 を変えない（追加は後続版）。ただし後続版の目標として明記する。
- T1〜T6 は他のすべての機能の前提になるので、第14節の順番では先頭（0a）に置く。

### 例
```
平時（日の段階 1日/秒）
  5/1  清洲を出発（京へ5日）
  5/3  ……（2秒経過）
  5/3  敵の軍勢を目撃 → 減速（秒の段階へ）
  5/3  通り過ぎたので日の段階へ戻す
  5/6  京に着いた → 減速（会う相手の拠点）
       公家の山科と会う（会話の間は秒の段階）

[次の出来事まで ▶▶]
  5/6 → 5/20 武田家からの返書が到着 → 止まる
```

## 20. 全国NPC（G-X5）

2026-10-30 にユーザーと1件ずつ相談して決定した。

### 現状
- 基本設計 BD-58：NPCは合法・物理的可能性を確かめたうえで、任務・既知の危険・生存・忠誠・利害・性格・人間関係から候補を比べる。新しい情報・命令・危険・期限・資源の変化をきっかけに判断し直し、同じくらいなら今の計画を続けて揺れを抑える。遠方は更新の頻度と描画を簡略にしても、同じ判断材料と主要な結果を保つ。NPCは本人の知識だけで判断する（I03）。
- 実装済みは、家臣の移動・不達報告・再送・帰還、現地NPCの自動依頼（NpcWork）、NPC当主の地域運営、NPCの軍の往復、限定的な初回判断（最大8人）など。大名同士の戦争・外交・家督を動かす全国のNPCはない（進捗表の残り「NPCの総合優先度、遠方簡略と詳細の全機能同値」）。

### 決定

| # | 論点 | 決定 |
|---|---|---|
| W1 | 動かす範囲 | **全員同じ仕組みで、重要度で判断の頻度を変える**。大名から浪人まで同じ判断の仕組み（BD-58）で動く。頻度の例：大名・重臣と本人の近くの人は毎日、遠方の家臣・城主は週に1回、遠方の浪人・村は月に1回。どの人も、きっかけ（書状の到着・危険・期限・命令）があればすぐ判断する。判断は時間の仕組み（T6）の「次の出来事まで」と同じ流れに乗る |
| W2 | 大名の方針 | **プレイヤーと同じ評定と方針を使う**。NPCの大名も年始・毎月の評定（U4・U5）で家の方針を決め、家臣はその方針を既定値にして動く。重臣の意見（それぞれの知識・性格・利害）も当主の判断材料になる。家臣として遊んでいると、当主の方針が書状で届き、評定に上申できる |
| W3 | 開戦の判断 | **目標と好機と大義で判断する**。家の目標（領土・仇敵・大義）があり、自分が知っている相手の弱み（家督争い・他との戦・凶作）を好機と見て、大義名分（J6）と条約（不侵略など）を照らして判断する。性格（野心・慎重）で積極さが変わり、兵糧が足りなければ始めない。例：慎重な当主は「噂だけでは動かない」 |
| W4 | 遠方の合戦 | **同じ戦いの規則を簡略に計算する**。遠方の合戦も、兵数・士気・地形・兵糧の同じ規則で勝敗と損害を計算する。一人一人の動きや描画は省き、部隊単位でまとめて計算する。本人が近づいたり参加したりしたら、その時点の状態から詳細な計算に引き継ぐ（BD-58 の受入条件：簡略と詳細で主要な状態と資源が一致）。結果は噂や書状で届く |
| W5 | 人物らしさ | **性格＋史実人物ごとの志**。性格（BD-14：野心・義理・慎重・勇敢・情愛・利得）に加えて、史実の主要人物には「志」を持たせ、目標の選び方に効かせる（例：上杉謙信＝義の戦と関東の秩序、毛利元就＝家の存続で天下を望まない）。志は強制ではなく判断の重み |
| W6 | 歴史モードの差 | **史実の目標・同盟への志向の強さが変わる**。史実尊重は史実の目標（例：織田は美濃、武田は信濃）や同盟を好む重みが強い。準史実は弱め。仮想は史実の重みなし（性格と志と状況だけ）。どのモードでも判断の仕組み・知識・時計は同じ（BD-02） |
| W7 | 本人への関わり | **難易度で選べる**。設定で「入門・標準・対等」を選ぶ。入門は本人に仕事や誘いの機会が届きやすい、標準は少しだけ、対等は本人を特別扱いせず、NPCは自分の利害だけで動く。どの段階でも、世界の規則（権限・知識・物理）は同じで、変わるのは依頼主が相手を選ぶときの重みだけ |
| W8 | 順番 | **段階的に、各機能と一緒に広げる**（第14節に反映済み）。0b でNPCの判断の土台を入れ、その後は各機能（勲功・外交・計略・家督・合戦など）を入れるたびにNPCも使えるようにし、**「NPCも使えて初めてその機能の完成」**とする。NPC大名の評定は 3b、開戦の判断は 7 と一緒 |

## 21. 合戦（兵種・陣形・天候と地形・負傷兵・攻城・開城・捕虜）

2026-10-30 にユーザーと1件ずつ相談して決定した。

### 現状
- 基本設計：軍勢は作戦上の集合、部隊は編成・兵数・装備・士気・疲労・統制を持つ単位。足軽・弓・鉄砲・騎馬・輸送の役割を編成に割り当て、招集・集合・編成・出発を分ける（BD-37）。布陣線・進軍経路・撤退経路・予備隊を作戦線で指定し、軍議の決定を任務として配送する（BD-38）。移動・射撃・近接・損害・統制低下・敗走・再集結を状態にし、城は包囲・遮断・強襲・救援・交渉・開城の複数の経路で扱う（BD-39）。補給の遮断は段階的に効く（BD-40）。城の占有は門・本丸などの主要区画の実支配と引渡しの合意で判断する（BD-47）。
- 実装済み：120mの戦場で3分隊を作戦線で配置、演習相手との接触戦（同時損害・士気25で敗走・60秒で再集結）、携行兵糧、軍勢の拠点間行軍、城門と本丸の引渡し。
- 未実装：兵種、陣形、天候、負傷兵、攻城、開城の判断、捕虜。

### 決定

| # | 論点 | 決定 |
|---|---|---|
| C1 | 兵種 | **持っている装備で決まる**。兵に配れる装備（槍・弓・鉄砲・軍馬）の在庫で、編成できる兵種が決まる（鉄砲が50挺なら鉄砲兵は50人まで）。兵種は槍（足軽）・弓・鉄砲・騎馬・輸送（小荷駄）の5つ。兵科適性（決定8）はここで効く。鉄砲は火薬と玉、騎馬は飼料を消費する（BD-40） |
| C2 | 陣形 | **作戦線の形の型として**。陣形は分隊の並べ方の「型」で、魚鱗（中央に厚く、突破向き）・鶴翼（横に広く、包囲向き）・方円（守り）などを選ぶと、作戦線と分隊の配置がその形になる。効果は数値の補正ではなく、実際の位置（厚み・幅・予備の位置）から生まれる。自分で線を引くこともできる |
| C3 | 天候と地形 | **兵種と動きに具体的に効かせる**。雨：鉄砲が撃ちにくい（火縄が湿る）、道がぬかるんで遅くなる。霧：見える範囲が狭まり、奇襲しやすい。川：渡る間は動きが遅く守りが弱い。森：騎馬が動きにくく、弓・鉄砲が届きにくい。坂：上から攻める方が有利。天候は日ごとに変わり、本人が知る天候（空の様子）で判断する。例：桶狭間のように雨と霧に紛れて本陣を襲うと、敵は近づくまで気づかない |
| C4 | 損害と負傷兵 | **損害の一部は負傷兵になり、本陣・城で回復する**。損害を戦死・逃亡・負傷に分ける。負傷兵は戦えないが残っていて、本陣や城で休むと回復する（兵糧を消費）。逃亡した兵は村に帰る（村の働き手に戻る、N5）。負けた側は逃亡が多い。例：100人の分隊で戦死8・負傷20（本陣で5日休むと半分が復帰）・逃亡12（村へ）、残り60 |
| C5 | 攻城 | **区画を順に攻める＋兵糧攻め・調略**。力攻めは、外堀→門→二の丸→本丸と区画を順に奪う（既存の城門・本丸の引渡しを広げる。区画の堅さは城の普請 N7）。包囲して補給を断てば兵糧攻め、城内に内応者がいれば門が開く（計略 K2）。水攻めは低地の城だけで、堤の普請が要る。救援の軍勢が来れば、包囲している側は挟まれる |
| C6 | 開城 | **城内の判断＋条件の交渉**。籠城側の将は、兵糧の残り・救援の見込み（知っている範囲）・大義・主家への忠誠・城兵の士気から開城を考える。攻める側は条件（城兵の助命・安全な退去・本領安堵・将の切腹）を示して交渉する。合意すれば既存の城門・本丸の引渡しへ進む（BD-47）。救援の便りが届けば交渉を打ち切ることもある |
| C7 | 捕虜 | **戦場の状況で捕まり、処遇は捕えた側が判断する**。敗走して逃げ遅れた、囲まれた、負傷した武将が捕まる（確率だけで決めない）。捕えた側の当主が、登用の誘い・返還・身代金・交換・留め置く・処断を判断する。処断は重大な政治責任で、周りから「苛烈」と見られる（BD-44：暴力的な処遇を自動にしない）。登用に応じるかは捕虜本人の判断（忠誠・義理・条件） |
| C8 | 本人の操作 | **今の形を保ち、身分で操作の範囲が変わる**。本隊は地点指定、配下の分隊には作戦線を伝令で送る（PW05）。総大将なら軍勢の全部隊に作戦線を送れる。部将なら自分の部隊の分隊だけで、総大将からの命令が届く（従うかは本人、独断は PW06）。一兵卒なら本人と随行者だけ（少人数の接触戦、決定6）。他の部隊はその将が自分で動く |
| C9 | 順番 | **土台の直後に割り込ませる**（第14節に反映済み）。5e 兵種・天候と地形・負傷兵・陣形（賊の接触戦の後）、5f 攻城と開城（城の普請の後）。捕虜は人質と同じ拘束の仕組みなので、本線の人質の作業の後 |

### 例
```
雨の日の合戦（本人は部将、槍50・弓20・鉄砲20・騎馬10）
  総大将から作戦線が届く「鶴翼で右翼を受け持て」
  雨で鉄砲隊はなかなか撃てない、騎馬はぬかるみで遅い
  → 槍の足軽を前に出して支える
  戦いの後：戦死8・負傷20・逃亡12
  逃げ遅れた敵の侍大将を捕らえる → 当主が処遇を判断

岩倉城の攻城（籠城30日目）
  外堀は奪った、門は堅い
  城主の判断材料：兵糧あと10日、主家からの便りがない、城兵の士気が落ちている
  攻める側「城兵は助命、城主は安全に退去」
  → 城主が引き受け、城門の引渡しへ
  （救援の便りが届いていれば、交渉は打ち切られる）
```

## 22. 史実の事件（G-X7）

2026-10-30 にユーザーと1件ずつ相談して決定した。

### 現状
- 基本設計 BD-02：1560年開始の全国シナリオを初回版に収め、史実尊重・準史実・仮想の3設定を同じ制度の上で提供する（既定は準史実）。モードの差は事件の発生方針とAIの歴史志向に限る。事件の候補は出典と異説を持つ。
- BD-03：史実尊重は前提が成り立つ史実事件と歴史的な志向を優先、準史実は前提に応じた分岐、仮想は歴史的な誘導を外す。プレイヤーの行動の結果を強制に上書きしない。事件は死亡・所属・所在・支配・当事者の意思などの前提を再検査し、成り立たなければ不発。
- 実装はない（BD-03 は design_only）。

### 決定

| # | 論点 | 決定 |
|---|---|---|
| E1 | 事件の起こし方 | **前提がそろうと、当事者がそう判断しやすくなる**。事件は強制の台本ではなく、前提がそろったときに当事者（NPC）が史実どおりの判断を選びやすくなる重みとして作る。実際に起きるかは、他と同じ判断の仕組み（第20節）で決まる。例：本能寺の変は「信長が少数で京の本能寺にいる・光秀が大軍を率いて近くにいる・光秀に不満の事実がある・周りに有力な織田の将がいない」がそろうと、光秀が謀反を選ぶ重みが大きくなる。信長が大軍と一緒なら起きない |
| E2 | 歴史モードの差 | **重みの強さが変わり、仮想には事件の重みがない**。史実尊重は前提がそろえばほぼ起きる、準史実は起きることもある、仮想は当事者の志と状況だけ。どのモードでも、前提が崩れていれば起きない（第20節 W6 と同じ考え方） |
| E3 | 前提が崩れたとき | **すべて不発**。分岐の事件は用意しない。その後は NPC の判断に任せる（BD-03 の「不発」の側を採る） |
| E4 | 本人の関わり | **当事者になれるし、変えられる**。本人がその場にいれば事件の当事者になる（桶狭間で奇襲に加わる、本能寺の前に光秀から密かに誘われて乗る・断る・信長に知らせる）。本人の行動で前提を崩せば事件は起きない（光秀の不満を上申で取り除く、など）。本人が当事者のとき、本人の判断を事件が上書きすることはない |
| E5 | 事件の知らせ | **他の出来事と同じく、噂と書状で知る**。その場にいた人が知り、噂や書状で広がる。遠方には遅れて届き、誤報もある。事件の名前（「本能寺の変」）は年代記に記録されるときに付く。本人に関わる大きな知らせでは自動で止まる（T5）。例：備中の陣にいる本人は、翌日に京からの使者が着いて初めて知る（光秀方の密使が捕まっていれば、もっと早く知る） |
| E6 | 初回版の事件の範囲 | **天下の流れを変える大事件＋主要な家の節目**。大事件を中心に30〜50件（例：1560 桶狭間、1561 第四次川中島、1562 清洲同盟、1567 稲葉山城の攻略、1568 信長の上洛、1570 姉川、1571 比叡山焼き討ち、1575 長篠、1582 本能寺の変・山崎、1600 関ヶ原）と、主要な家の家督・改名・婚姻・死去。小さな事件は後で足す。どれも前提と出典を持つ（BD-02） |
| E7 | 事件の見せ方 | **その場にいれば世界の中で、いなければ知らせと年代記**。本人がその場にいれば、事件はいつもの3Dの世界と下部会話帯のまま起きる（特別な場面に切り替えない、I02）。いなければ、届いた知らせを読む。年代記の画面で、事件の名前と、本人が知った範囲の経緯を振り返れる（G-X4 の年代記の振り返りを兼ねる）。大事件には短い絵や立ち絵を添えてもよい |
| E8 | 順番 | **仕組みは早く、事件は関係する機能と一緒に**（第14節に反映済み）。0c で事件の仕組み（前提の検査・判断への重み・モードの差・年代記）を入れ、個々の事件は必要な機能がそろったところで足す（例：桶狭間は 5e の合戦・天候の後、清洲同盟は本線の条約、本能寺は 6a の調略系の後） |

### 例

## 23. 寺社（G-C4、BD-51）

2026-10-30 にユーザーと1件ずつ相談して決定した。

### 現状
- 基本設計 BD-51：寄進・保護・禁制・免税・通行・取次・武装協力を別々の案件にし、寺社の組織の利害と人脈を通じて合意する。宗教的な権威と実際の強制力は別。すべての寺社を武装勢力にはせず、建物と組織を分ける。寄進だけで服従や永続的な忠誠は買えず、宗派が同じだけで情報や軍隊を共有しない。権益を侵害すれば交渉・非協力・経済の抵抗・必要なときの武装へ分かれ、一律に反乱しない。
- BD-49：寺社そのものは直接プレイする主体にしない。
- 実装はない（BD-51 は design_only）。朝廷・将軍との取次は第15節（D7）で決めた。

### 決定

| # | 論点 | 決定 |
|---|---|---|
| R1 | 寺社の存在 | **大きな寺社は組織、小さな寺社は拠点の一部**。延暦寺・興福寺・本願寺・根来寺・大きな神社などは、代表者・僧・財源（寺領・関・座）・僧兵・人脈を持つ組織として動き、代表者は NPC として判断する（第20節）。村の寺や町の神社は拠点の一部として、村と同じく代表者と相談する。武装するのは一部の大寺社だけ |
| R2 | 関係の作り方 | **寄進・保護・禁制を案件として、関係の事実に残す**。寄進（銭・米・土地）、保護（寺領の安堵状）、禁制（兵の乱暴を禁じる札）をそれぞれ別の案件として取り交わし（BD-51）、結果は寺社の代表者との関係の事実（決定11）に残る。寄進だけで服従は買えない。統合案の当初案（G-C4 の貢献の台帳）は採らない（通貨のようにしない、決定4と同じ考え方）。例：寄進した・安堵状を出した、の一方で、家臣が門前で乱暴した（禁制違反）事実も残る |
| R3 | 頼めること | **仲裁・取次、情報と噂、僧兵・門徒の武装協力**。他家との和睦の仲裁（D8）や朝廷への取次（大寺社は朝廷・公家とのつながりが深い）。僧や御師は各地を旅するので遠方の噂を知っており、関係があれば教えてくれる（悪評を広めてもらうことも）。武装した大寺社には援軍を頼める（根来衆の鉄砲など）。どれも寺社が自分の利害で判断する。通行・商い・関の特権（免税）は今回の範囲に入れない |
| R4 | 権益の衝突 | **寺社が段階的に抵抗を選ぶ**。寺領・関・座・不入の権が大名の改革（検地・楽市・関所撤廃、H2）とぶつかると、寺社の代表者が権益の大きさ・大名の力・関係から段階を選ぶ：嘆願（書状）→ 非協力（取次・仲裁を断る）→ 経済の抵抗（座の商人が商いを止める）→ 敵対する大名と結ぶ → 武装。どの段階でも、権益の一部を残すなどの交渉で収められる（村の一揆 N6 と同じ形） |
| R5 | 一向宗 | **門徒の村は本願寺の檄に応じうる**。各地の村に「門徒が多い」という属性があり、本願寺が檄（蜂起を呼びかける書状）を出すと、届いた村がそれぞれ応じるかを判断する（領主との関係・飢え・信仰の強さ）。応じた村は一揆の段階（N6）に入る。宗派が同じだけで自動では動かない（BD-51）。加賀のように一揆が国を治める状態もありうる |
| R6 | 寺社への武力 | **攻められるのは武装して敵対している寺社だけで、評判の傷は小さめ**。僧兵を出して敵対している寺社は、合戦・攻城の仕組みで攻められる。その場合の大義名分や評判への傷は小さい。武装していない寺社や敵対していない寺社は攻められない。史実の比叡山焼き討ち（第22節 E6）は、延暦寺が武装して敵対している前提がそろったときの事件として扱う |
| R7 | キリスト教 | **宣教師は南蛮貿易と結びついた組織**。宣教師と教会を小さな組織として持ち、布教を許すと南蛮船や商人が来やすくなる（H6）。武将は入信でき（キリシタン大名）、南蛮との関係が深まる一方、寺社や一部の家臣との関係に響くことがある。主に西国 |
| R8 | 順番 | **土台の直後に割り込ませる**（第14節に反映済み）。1b 寺社の組織と寄進・保護・禁制、2a に寺社の情報と噂、3c にキリスト教、5e に僧兵・門徒の協力と寺社への武力、6c に権益の衝突、7a に一向宗の檄、9 に寺社の仲裁・取次 |

### 例
```
延暦寺との関係
  手応え：好意的だが用心している
  根拠：3月 銭3000文を寄進した / 5月 寺領の安堵状を出した / 7月 家臣が坂本で乱暴（禁制違反）

坂本の関を撤廃しようとする（楽市・関所撤廃、H2）
  延暦寺の判断
    1 嘆願「関は当山の古来の権なり」
    2 無視される → 朝廷への取次を断る
```

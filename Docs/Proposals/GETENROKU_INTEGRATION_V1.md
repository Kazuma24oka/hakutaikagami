## 1. 勲功と恩賞（G-A2）

### 下天禄では
- 仕事をするたびに勲功が貯まる。
- 放置すると不満が募り、忠誠が下がる。
- 論功行賞で知行・昇進・物品・金・感状を与えて消化する。

### 百代鏡での案
勲功を新しい通貨にはしない。**既存の審査（`MissionReview`）が「主君の手元に残る記録」になったもの**として扱う。

```
任務完了 → 返報が主君に届く → 主君の審査（既存）→ 評価通知が本人に届く（既存）
                                  ↓
                         主君の「勲功帳」に1行追加（新規）
                                  ↓
          恩賞の判断（主君NPCが勲功帳・関係・家の財布を見て決める）
                                  ↓
          恩賞の申し渡し（面会 or 書状）→ 本人の受領 → 給付・役目・知行の変更
```

- 勲功帳は**主君が知っていること**の記録。主君に届いていない働きは載らない。
  - 返報が不達なら勲功にならない。これは百代鏡の情報設計そのもの。
- 本人の画面に出すのは「自分が評価通知で知った分」だけ。主君の帳面を直接は見られない。
- 未消化の勲功は、数値の忠誠を減らすのではなく、**本人（NPC）が主君に対して抱く事実**として記録する。
  - 例: 「熱田の点検を3度果たしたが、恩賞の沙汰がない」
- NPCの家臣は、その事実を辞去や他家への仕官を考える判断材料にする（BD-14、BD-58）。

### 例: 本人が家臣側のとき
1. 1560年5月、本人は清洲で信長から熱田街道の点検を3回受けて、すべて返報した。
2. 3通の評価通知は、どれも「達成」だった。
3. 6月1日、信長側の勲功帳に3行がある。信長NPCの月初判断で「恩賞を与える」が選ばれる。
4. 清洲で面会すると、下部会話帯に次のように出る。
   > 信長「熱田の道の見立て、三度とも確かであった。今後は月に米二十を扶持として遣わす」
5. 既存の `HouseSalary` の提示として届く。本人が受ければ月額給付が始まる。
6. 勲功帳の3行に「恩賞済み」と記録される。

### 例: 本人が当主側のとき（録画の論功行賞に相当）
1. 配下の作成武将が、運搬を2回、点検を1回果たした。
2. 当主の画面「家中」に、配下ごとの未消化の勲功が並ぶ（自分の勲功帳なので正確に見える）。
3. 恩賞の種類から選ぶ。
   - 銭（私財から）
   - 扶持の加増（`HouseSalary` の新契約）
   - 役目（`WorkDuty` の担当や城主任命）
   - 物品（G-B5 の実装後）
   - 感状（書状として届く。名声の根拠になる）
4. 申し渡しは、配下が現地にいれば面会、遠方なら書状で行う。書状は配送中に失われることもある。

### データ追加（最小）
- `MeritRecord(Id, Principal, Subject, Task, Review版, KnownAt, Weight, Settled?)`
- `RewardGrant(Id, Principal, Subject, Kind, Amount/Term, Merits[], DeliveredBy, At)`
- 本人（NPC）の事実: `GrievanceFact(Subject, Principal, Merits[], Since)`。既存の `WorkTrustFact` と同じ形にする。

### 決めること
| 論点 | 案 | 推奨 |
|---|---|---|
| 勲功の重み | A: 達成なら一律1点 / B: 任務の種類と難度で変える / C: 金額換算 | **B**（点検1、運搬2、軍務の実働3など。試作値） |
| 不満が出るまでの期間 | A: 一律3ヶ月 / B: 性格で1〜6ヶ月 | **B**。ただし性格の実装（BD-14）までは一律3ヶ月で始める |
| 本人に見せる量 | A: 自分の勲功の数値 / B: 受け取った評価通知の一覧だけ | **B**。数値は主君の頭の中にあるもの |
| 下天禄の「発言力」に相当するもの | A: 消費する通貨として導入 / B: 導入せず、上申の通りやすさは勲功・関係から主君が判断 | **B**。上申の画面に「通りそうか」の手応えだけを出す（G-U1 の翻訳） |

## 2. 仕事の種類を増やす（G-B1）

### 下天禄では
- 酒場の仕事は5種類（退治・探物・護衛・物資・宅配）。
- 報酬の幅は100〜13000ほどあり、序盤の主な遊びになっている（録画の約4分の1）。

### 百代鏡での案
今ある「点検」「小口送金の運搬」に、**既存の部品を組み合わせるだけで作れる3種類**を足す。退治は個人戦が要るので後回しにする。

| 下天禄 | 百代鏡での仕事 | 使う既存部品 | 新規に要るもの |
|---|---|---|---|
| 宅配 | **書状の使い**：指定の相手へ封書を期限内に届ける | 物理配送、受領証、期限 | 本人が伝令役を務める入口 |
| 物資 | **買付納品**：依頼主の銭で米・木材を買い、指定の蔵へ納める | `MaterialMarkets`、`HouseLogistics`、預り金 | 依頼主がNPC商人・寺社の場合の財布 |
| 護衛 | **道中の同行**：商人・使者に付き添って次の拠点まで行く | `PersonalCompanions`（逆向き）、`TransportWork` | 依頼主側が随行される側になる形 |
| 探物 | **名物の探索**：特定の品を市で見つけて買う | 市場、G-B5（名物） | 名物の実装後 |
| 退治 | **賊の討伐** | — | 個人戦かそれに代わる仕組み（G-B2） |

### 例: 書状の使い
1. 熱田の神官NPCから相談される。
   > 神官「この書状を明後日の日没までに、清洲の村井殿へ届けてはもらえぬか。礼は三十文」
2. 引き受けると、本人の荷物に封書（未開封、本文は見えない）が入る。
3. 本人が清洲へ実際に歩く。途中で行先を変えれば、期限に間に合わないこともある。
4. 清洲で村井NPCに手渡すと、受領証を受け取る。
5. 熱田へ戻って神官に受領証を見せ、報酬を受け取る。
   - 戻らずに別の用事へ行ってもよい。その場合、報酬は未払いのまま残る（既存の未払い保持）。
6. 神官→本人の `WorkTrustFact` が1件増える。次は額の大きい依頼が来る（`WorkFollowup` と同じ考え方）。

### 例: 買付納品
1. 甲府の寺の僧から相談される。
   > 僧「普請に木材が二百斤要る。銭二千文を預けるゆえ、府中の市で買い、寺の蔵へ納めてくだされ。手間賃は五十文」
2. 預り金2000文を受け取る。私財とは別の扱い（既存の預り金と同じ）。
3. 市で木材を買う。相場が高ければ買える量が減る。
4. 寺の蔵に納め、余った金を返し、手間賃を受け取る。

### 決めること
| 論点 | 案 | 推奨 |
|---|---|---|
| 依頼の出どころ | A: 拠点ごとの「仕事の口」（下天禄の酒場相当）/ B: 現地のNPCに個別に相談される / C: 両方 | **B**。既存の「現地NPCの自動依頼」（NpcWork）を広げる。口入れ屋は後で拠点の施設として足せばよい |
| 最初に足す種類 | 書状の使い / 買付納品 / 道中の同行 | **書状の使い → 買付納品**の順。どちらも既存部品だけで作れる |
| 報酬の幅 | A: 20〜300文に留める / B: 名物探索などで数千文まで | **A**から始め、名物の実装時に広げる |

## 3. 能力と特技（G-A1）

### 下天禄では
- 4能力（7〜150）と武芸、兵科適性5種、特技のIDリストを持つ。
- 数値が成否や戦闘力に直接効く。

### 百代鏡での案
能力を「成功率」には使わない。**同じ行動をしたときの「質」と「時間」と「分かること」**に効かせる。

| 能力（BD-13） | 効く場面（既存機能） | 例 |
|---|---|---|
| 統率 | 部隊の布陣・再集結の速さ、敗走しにくさ | 再集結の60秒が、統率が高いと45秒になる |
| 武勇 | 接触戦の損害の与え方、士気の崩れにくさ | 士気25で敗走するところ、20まで持ちこたえる |
| 知略 | 点検で分かることの多さ、偽報の見抜き | 点検の報告に「封鎖の原因」まで書ける |
| 政務 | 給付・運搬・市場の手際（時間・手数料） | 買付で相場より安く買える、運搬の準備が早い |
| 交渉 | 相談の条件、不戦交渉の対案 | 運搬の手間賃を1段上で提示される |

- 特技は「固有の才」として、効果の種類と係数をデータ表で持つ（例: 「道に明るい」＝点検の所要時間−20%）。
- **本人の能力は正確に、他人の能力は推定で**見せる（BD-16）。
  - 例: 「知略：高そう（熱田の点検を2度共にした印象、5月）」
  - 一緒に働くほど推定の幅が狭まる。

### 例
- 知略の高い本人が熱田を点検する。
  - 報告に「橋の板が腐っている。十日もすれば通れなくなる」が加わる。
  - 主君の審査で差異の説明が厚くなり、勲功の重みが上がる（第1節とつながる）。
- 政務の低い本人が買付を引き受ける。
  - 市での交渉に時間がかかり、納品の期限ぎりぎりになる。失敗はしない。

### 決めること
| 論点 | 案 | 推奨 |
|---|---|---|
| 値域 | A: 1〜100 / B: 1〜20の段階 / C: 下天禄と同じ1〜150 | **A**（作成武将の予算計算が楽） |
| 兵科適性・個人武芸 | A: 入れる / B: 後で | **A**。データ項目だけ先に持ち、効果は合戦の拡張時に入れる |
| 他人の能力表示 | A: 段階＋推定幅＋出典 / B: 段階のみ | **A**（BD-16 どおり） |

## 4. 寿命・死亡・出生・成人（G-A3）

### 下天禄では
- 没年に達すると確率で死亡する。
- 子がランダムに生まれる。
- 成人すると出仕の会話が出る（録画の最後に発生）。

### 百代鏡での案
既存の**生前の当主交代（`HouseSuccession`）**を土台にし、「死亡による交代」を足す。
死亡も出生も**出来事として、書状や噂で人に伝わる**ようにする。

```
死亡（真実）→ 現地の人だけが即座に知る → 訃報の書状・噂が街道を伝わる → 遠方の人は遅れて知る
                    ↓
         家の当主なら：後継の決定（遺言 / 家中の合議 / 係争）
                    ↓
         既存の HouseSuccession の「適用」と同じ処理で個別に引き継ぐ
```

### 例: 遠方の主君の死（本人は家臣）
1. 本人は小田原への運搬の途中にいる。主君は清洲で病死する（没年の目安＋加齢による判定）。
2. 本人はまだ知らない。画面は今までどおり。
3. 2日後、清洲から本人宛ての書状（重要書状）が届き、自動停止する。差出人は家老。
4. 開封すると「殿、ご逝去。嫡子が家督を継がれた。急ぎ帰参されたし」と書かれている。
5. 本人が運んでいる荷と預り金の契約は、**元の家と元の依頼主のまま**残る（既存の個別承継の原則）。
6. 帰参すると、新当主と現地で奉公を確認し直す。これは既存の「個人奉公の再合意」をそのまま使う。

### 例: 子の成人（録画の場面の翻訳）
1. 1563年正月、本人の子が15歳になる。
2. 本人が自宅の拠点にいれば、下部会話帯でその場で会話が起きる。遠方にいれば、家族から書状が届く。
   > 子「父上、わたしも当家のお役に立ちたく存じます」
3. 選択肢は「主君に推挙する」「自分の随行者にする」「まだ早い」。
   - 推挙は既存の仕官の流れ、随行は `PersonalCompanions` を使う。

### 決めること
| 論点 | 案 | 推奨 |
|---|---|---|
| 死亡の決め方 | A: 史実の没年で確定 / B: 没年の目安＋加齢・病気・負傷で確率 / C: モードで切替 | **C**。史実尊重モードはAに近く、仮想モードはB |
| 出生 | A: 史実の子のみ / B: 架空の子も生まれる / C: モードで切替 | **C** |
| 主人公が死んだとき | A: 認識できる後継へ操作を移す（BD-07）/ B: 年代記を閉じる | **A**。後継がいなければB |
| 成人年齢 | 15歳 / 16歳 | **15歳**（試作値。既存の「成人家臣」の判定に合わせる） |

## 5. 一族を最小の部隊にする（G-B3）

### 下天禄では
- 主人公の家族5人がそのまま1部隊（小隊5つ）になり、合戦に出る（録画）。

### 百代鏡での案
既存の**家中の軍務（HouseholdMilitary）**と**随行（PersonalCompanions）**を合わせる。
**一族は「自分の家の家臣」**として、自分の軍務に連れていける。

### 例
1. 本人（家臣）が主君から軍務を受ける。既存の流れで兵100を預かる。
2. 本人の家には成人した子が2人いる。どちらも本人の家臣になっている。
3. 布陣では、預かった100人を3分隊に分け、分隊の現地指揮を子に任せられる。
   - 指揮の委任は既存の分隊別の命令で、配送も既存のものを使う。
4. 子が育つ（経験・能力の成長）と、分隊の崩れにくさや再集結の速さが良くなる（第3節とつながる）。
5. 戦死すると、家督の候補が減る（第4節とつながる）。

### 決めること
| 論点 | 案 | 推奨 |
|---|---|---|
| 一族の兵 | A: 一族が自前の兵を持つ（下天禄式）/ B: 兵は主家から預かるだけで、一族は指揮役 | **B**から始める（既存の兵の所有原則と合う）。A は所領を持つ身分の実装時に |
| 一族以外の家臣 | 同じ扱いにする / 一族だけ | **同じ扱い**。一族は忠誠の根拠が強い、という差だけを付ける |

## 6. 人物どうしの関係（G-A4）

### 下天禄では
- 全員の組み合わせの友好度（既定値50）を持つ。
- 訪問・贈物・茶会・紹介状で変化する。

### 百代鏡での案
既存の `WorkTrustFact`（仕事を根拠にした方向別の信頼）を**一般化**する。
**数値ではなく「根拠付きの事実」を貯め、判断のときに評価する。**

| 事実の種類 | 例 | 生まれるきっかけ |
|---|---|---|
| 仕事の信頼 | 「熱田の点検を果たした」 | 既存 |
| 恩 | 「恩賞を受けた」「米を分けてもらった」 | 第1節、給付 |
| 不満 | 「恩賞の沙汰がない」 | 第1節 |
| 面識 | 「清洲で会って話した」 | 訪問（新規）、茶会（後で） |
| 紹介 | 「村井殿の紹介状を持っている」 | 紹介状（新規）。面会できる相手が増える |
| 血縁・婚姻 | 「娘婿」 | 第4節、G-C1 |

### 例: 紹介状
1. 本人は浪人で、甲府の武田家に仕官したい。だが家中に面識がない。
2. 小田原で北条家の家臣と仕事を重ね、仕事の信頼が2件たまっている。
3. その家臣に頼むと、甲府の知人宛ての紹介状（封書）を書いてくれる。
4. 甲府でそれを渡すと面会でき、仕官の相談ができるようになる。
5. 紹介状は書状なので、なくすこともある。

### 決めること
| 論点 | 案 | 推奨 |
|---|---|---|
| 表現 | A: 事実の積み上げだけ（数値なし）/ B: 事実から好意・敬意・恐れ・敵意の4軸を計算して内部で持つ | **B**。ただし画面には事実と手応えだけを出す |
| 訪問の入口 | A: 現地の人物を選んで「話す」/ B: 用件を選んでから相手を選ぶ | **A**。既存の下部会話帯に乗せる |

## 7. 入れる順番の案（当初案。決定は第9節の12番）

| 順 | 内容 | 理由 |
|---|---|---|

## 10. 計略（G-B6・G-C5）

2026-10-30 にユーザーと1件ずつ相談して決定した。

### 現状（2026-10-30時点）
- **設計**: 謀略は5つある行動分類の1つ（BD-10）。身分ごとに試せる謀略が決まっている（浪人＝秘密交渉・情報提供、家臣＝内通・離間・密約、城主・国人＝独立の根回し・内応、大名＝密偵・離間・内応の委任）。独立・離反は「秘密の接触 → 支持を集める → 宣言 → 各人が従うか判断 → 独立／係争／失敗」（BD-46）。偽書は本物と同じ外形なら同じように停止する（I07）。
- **実装済み**（R4「内応の前段階」）: 私的な情報提供（PrivateInformation）、相手当主の出撃見合わせ（PrivateStanddown）、単発の点検協力、個人の直属合意、不戦交渉、敵対意思の宣言と撤回。
- **未実装**: 内応そのもの、離間・流言・偽書・密偵・暗殺・煽動、発覚と追及、独立・離反（BD-46 は foundation）。

### 決定

| # | 論点 | 決定 |
|---|---|---|
| K1 | 実行の形 | **本人も委任もできる**。本人が現地へ行って実行するか、配下・雇った者に任務として任せる。任せた場合は実行者が実際に歩いて行き、結果は返報で届く。返報が届くまで、うまくいったかは分からない。既存の任務・委任・返報をそのまま使う |
| K2 | 入れる計略 | **4系統すべて**。<br>・情報系：流言・偽書・密偵<br>・調略系：離反・内応<br>・破壊系：放火・破壊・強奪・煽動<br>・暗殺<br>**自分の家の中（主君・同僚）にも仕掛けられる**（下天禄にはない、梟雄プレイのため。信長の野望 蒼天録のイメージ）。例：不満を抱える同僚の城主と「時が来たら一緒に立とう」と密約を結ぶ（共同独立の約束）、主君の重臣に流言を流して仲を裂く |
| K3 | 成否の決め方 | **種類ごとに分ける**。調略系・情報系は相手の判断（相手NPCが利害・関係・不満・性格・自分の知識から判断）。破壊系・暗殺は成功率で判定する |
| K4 | 成功率の表示 | **手応えの段階だけ**（例「勝算はある」「危うい」「ほぼ不可能」）。成功率は内部でだけ計算する。本人が知らない警備の強さは手応えに反映されないので、事前に密偵や点検で調べる価値が生まれる |
| K5 | 発覚 | **証拠が伝わって発覚する**。証拠は、現場で見られる・実行者が捕まって吐く・密書が押収される・密約の相手が密告する、のどれかで生まれる。証拠が書状や噂で届いた人だけが知る。知った主君は、詰問・監視・処分・討伐、または知らぬふりを自分で判断する。本人は、密書が届かなかったことも押収されたことも、すぐには知らない |
| K6 | 暗殺の対象 | **誰でも狙えるが、護衛で難しくなる**。当主・大名ほど護衛が厚く、居城の奥ではほぼ不可能。道中や少人数での移動中が狙い目で、所在を知るために密偵が要る。実行すると護衛との少人数の接触戦になり、成否は確率（K3）。失敗や捕縛で証拠が生まれる（K5）。どの歴史モードでも起きうる（決定9） |
| K7 | 入れる順番 | **系統ごとに、土台ができた直後に割り込ませる**。<br>1 関係 → 2 勲功・顔 → **2a 情報系（流言・偽書・密偵）** → 3 仕事 → 4 能力 → 5 賊の接触戦 → **5a 破壊系** → **5b 暗殺** → 6 家督 → **6a 調略系（離反・内応・共同独立）** → 7 募兵 → 8 一族 |

### 例

**流言（情報系・家の中へ）**
1. 本人は織田家の家臣。同僚の重臣が邪魔なので、「あの方は今川と通じている」という流言を流したい。
2. 配下に任務として任せる。配下は清洲の城下で噂を撒き、返報を送る。
3. 噂は人から人へ伝わり、聞いた人の認識に「そういう噂がある」として入る。
4. 主君は、自分が知っている事実と照らし合わせて判断する。
   - 「先月、その重臣に恩賞を与えた」「重臣は一族だ」なら信じない。ただし噂があったことは覚えている。
   - 重臣に「恩賞の沙汰がない」不満があると主君が知っていれば、疑い始める。
5. 噂の出どころを辿られて配下が捕まれば、証拠が生まれる（K5）。

**共同独立の密約（調略系・家の中へ）**
1. 本人は城主。同じ家の城主Aには「恩賞の沙汰がない」という不満の事実がある。
2. Aと現地で密かに会い、「時が来たら共に立つ」と密約を結ぶ。Aは利害・関係・不満から判断して応じる。
3. 密約は密書として互いに保管される。押収されれば証拠になる。
4. 本人が独立を宣言したとき、Aが本当に立つかはその時点のA自身の判断で決まる。密約は約束であって、強制ではない（BD-46）。

**放火（破壊系）**
1. 甲府の蔵を焼きたい。手応えは「勝算はある（蔵の見回りは不明）」。
2. 先に密偵を送り、「見回りは夜半に手薄」と知る。手応えが「勝算が高い」に上がる。
3. 実行者が夜に蔵へ近づく。見回りに見つかれば少人数の接触戦か逃走になる。
4. 火がつけば、蔵の実米が実際に減る（既存の地域経済の台帳）。

**暗殺**
1. 対象の居場所で手応えが変わる。
   - 清洲城の奥：ほぼ不可能
   - 城下の寺での茶会：危うい
   - 熱田への道中（供10人）：勝算はある
2. 密偵で道中の日程を知ってから、実行者を待ち伏せさせる。
3. 失敗して実行者が捕まると、依頼主が露見する可能性がある（K5）。

| J5 | 官位・官途名 | **取次で奏請＋主君の許可＋自称**。正式な官位は、公家や武家伝奏などの取次ぎを経て朝廷に奏請し、献金を納めて得る（書状で往復し数ヶ月かかる）。家臣は主君の許可が先に要る。官途名・受領名は主君が許す（例「以後、内蔵助と名乗れ」）か自称でも名乗れるが、自称は信用が低い。効果は BD-54 どおり認知・取次・信用・資格だけで、所領や軍勢は得られない |
| J6 | 幕府職（守護など） | **正統性として効かせる**。幕府へ取次いで申請し、将軍の判断で補任される。正統性は**大義名分**という根拠の事実として持ち、判断の材料になる。<br>・根拠の強さの例：守護職（将軍から正式に補任）＝強、〇〇守（朝廷から正式に任官）＝中、〇〇守（主君が許した受領名）＝弱、〇〇守（自称）＝ごく弱、将軍の御内書・旧主の仇討ち・血縁による継承権＝案件ごと<br>・**開戦**：敵対意思の宣言に大義名分を書いた檄文を添えられる。家臣・国人は軍役に応じるかの判断に使い、大義のない私戦では渋る・遅れる者が出る<br>・**他家の反応**：中立・同盟の家が正当な戦かを判断し、援軍や非難の材料にする<br>・**支配の後**：その国の守護職があれば、国人・寺社・村は「守護に従う理由」を持った状態で始まる。なければ服従は利害と恐れだけで決まる<br>・大義名分は檄文や書状が**届いた人だけが知る**。実際の支配や兵は得られず、それでも従わない国人はいる |
| J7 | 登用 | **条件を提示して誘う**。浪人には現地で会うか書状で、扶持・知行・役職・席次の条件を示す。相手は条件・関係・他家からの誘い・旧主への思いから判断する。他家の家臣への誘いは計略の「離反」（K2）として扱い、発覚がある（K5）。家臣の本人が誘う場合は、自分の配下にする（自分の米で養う）か、主君に推挙して直臣にする（推挙は勲功にもなる）を選べる。配下を一括で移すことはしない（I06） |
| J8 | 順番 | **家中は早く、中央は最後**。<br>1 関係 → 2 勲功・顔 → 2a 情報系 → **2b 席次・登用（条件提示）** → **2c 家中役職（常設・任命・上申）** → 3 仕事 → 4 能力 → 5 賊 → 5a 破壊系 → 5b 暗殺 → 6 家督 → 6a 調略系 → **6b 家の規模の段階** → 7 募兵 → 8 一族 → **9 官位・幕府職・大義名分（中央政治 BD-53〜56 と一緒に）**。9 までは、開始時の史実の官位・守護職を表示だけする |

### 例

**奉行の空席への任命**
1. 織田家で奉行の席が一つ空く。
2. 信長NPCは、自分が知る範囲で候補を比べる。候補Aは譜代で勲功帳8行・政務が高そう、候補Bは新参で勲功帳12行、本人は新参で勲功帳6行。
3. 本人は、顔の利く村井に取次ぎを頼む書状を送る。村井が信長に推挙する。
4. 信長は候補Aと本人で迷い、譜代の候補Aを選ぶかもしれない。席次が効く場面。

**浪人の登用**
1. 本人は浪人の前田に、扶持 月米30・席次 新参を提示する。
2. 前田には今川家から月米40の誘いもある。ただし本人とは熱田で共に働いた事実がある。
3. 前田は「米は少ないが、貴殿の下なら」と応じる。

**守護職と大義名分**
1. 美濃を攻め取った後、美濃守護職を望み、幕府の奉公衆に取次ぎを頼む。
2. 将軍が自分の知る情勢で判断し、補任の御内書が届く。
3. 美濃の国人には「守護に従う理由」ができ、旧主の斎藤家より正統性で上回る。それでも従わない国人はいる。

## 12. 家督の相続（後継順位・誓紙・家督争い）

2026-10-30 にユーザーと1件ずつ相談して決定した。直系が絶えたときの候補の考え方は、ユーザーが示した図（当主の子がいなければ、当主弟・前当主弟・他家に出た血筋・婿養子・主家の息子から次期当主が選ばれることが多い）に基づく。

### 現状（2026-10-30時点）
- **実装済み**: 生前の当主交代（`HouseSuccession`）のみ。当主が現地にいる成人の直属家臣を後継に指名し、本人が確認すると交代する。候補の基準は直属かどうかだけで、血縁は見ていない。
- **未実装**: 親子・兄弟・夫婦のデータ、死亡による相続、遺言、家督争い（BD-45 は foundation）、婚姻・養子縁組（BD-43 は design_only）。
- **設計の方針**: 候補は血統・養子・遺言・家法・家臣の支持・城の占有を根拠に立て、どれか一つでは自動決着しない。争いは係争と暫定管理へ進む（BD-45）。主人公の操作は、生前に指定・認識された成人の家族・養子・後継候補へ移せる（BD-07）。

### 決定

| # | 論点 | 決定 |
|---|---|---|
| S1 | 候補の範囲 | **4種類すべて**：子・兄弟・叔父（家内の血縁）、他家に出た血筋（姉妹・叔母が他家に嫁いで産んだ子など。呼び戻すにはその家の同意が要る）、婿養子・養子、主家など強い家からの養子。加えて、**当主が後継を指名し家臣に事前の承認を求める**（信長の野望 蒼天録の形）、**後継の順位が家臣の忠誠に影響し、家督争いにつながる**ようにする |
| S2 | 後継の順位 | **既定の順位＋当主が変えられる**。家法の既定順位（嫡男 → 次男以下 → 当主弟 → 叔父 → 他家に出た血筋 → 婿養子 → 養子）があり、当主はそれを入れ替えて嫡子を指名できる。既定から外れた指名ほど家臣の反発や、外された候補の不満が生まれる。例：次男を嫡子とすれば、嫡男に「廃嫡された」事実が残る |
| S3 | 家臣の承認 | **重臣へ個別に説き、誓紙を取る**。当主が重臣・城主に面会か書状で「嫡子は○○」と伝え、納得した者から誓紙（起請文）を取る。各家臣は関係・席次・候補との関係で判断し、留保や拒否もある。誓紙は物理的な書状として保管され、後で「約束したはず」の根拠になる。当主の画面には「承認○人／留保○人／未達○人」が出る |
| S4 | 忠誠への影響 | **候補との関係で家臣ごとに**。家臣はそれぞれ推したい候補を持つ（候補との関係・席次・母方の家・正統性から）。指名が推しと一致すれば当主への好意が増し、違えば不満の事実が残る。既定順位から外れた指名ほど「道理に合わない」反発が大きい。不満は勲功の不満（決定2）と同じ事実として、辞去・離反・後の家督争いの判断材料になる。例：嫡男の傅役は廃嫡に不満、次男と親しい重臣は好意が増す |
| S5 | 家督争い | **家臣が各自つく側を選ぶ**。訃報が届いた家臣から順に、誓紙・推し・関係・利害でどちらにつくかを判断する。各候補は支持を集め、説得（所領を安堵して譲らせる）・調停（主家や寺社に頼む）・出家（敗れた側が寺へ）・合戦（稲生の戦いのように）のどれかで決着する。本拠を占有した側が有利だが絶対ではない。その間は暫定管理で、既存の委任は安全の範囲で継続する |
| S6 | 強い家からの養子 | **どちらからも申し入れられ、家臣が割れうる**。直系が絶えそうな家が主家に養子を頼むことも、主家が「我が子を迎えよ」と申し入れることもある。主家側は、家を取り込む調略（K2）としても使う。受けると主家が後ろ盾になるが、主家寄りの家臣が増え、旧来の血筋を推す家臣に不満が出る。断ると主家との関係が悪化する |
| S7 | 未成年の後継 | **後見人が代わりに治める**。家督は未成年の後継が継ぎ、後見人（一族の年長者・重臣・母など）が元服まで期限付きで政務を代行する。後見人が実権を握る、家臣が「乱世に幼君は危うい、叔父を当主に」と動く、などの種になる。主人公の操作は、認識済みの成人の後見人へ移せる（BD-07） |
| S8 | 順番 | **家督を3段に分ける**。<br>… 5b 暗殺 → **6-1 血縁データ・死亡・訃報・出生・成人** → **6-2 婚姻・養子縁組、後継順位・指名・誓紙** → **6-3 家督争い・後見・強い家からの養子** → 6a 調略系 → 6b 家の規模の段階 → 7 募兵 → … |

### 例

**廃嫡と家督争い**
1. 当主には嫡男（15歳）と次男（12歳）がいる。当主は次男を気に入り、「次男を嫡子とする」と指名する。
2. 重臣に個別に説いて回る。次男と親しい重臣は誓紙を出す。嫡男の傅役は不満を抱え、別の譜代は「少し考えさせていただきたい」と留保する。遠方の城主にはまだ使者が届いていない。
3. 数年後、当主が亡くなる。本拠を占める次男派に対し、嫡男は傅役と東の城主2人を味方につける。
4. 遠方の城主は訃報が届いてから、どちらにつくかを判断する。
5. 次男派は、嫡男に所領を安堵して譲らせる説得を試みる。決裂すれば合戦になる。

**主家からの養子（取り込み）**
1. 本人は大名。属下の国人家の当主が病弱で、直系の子がいない。
2. 本人は「我が三男を養子に迎えよ」と書状で申し入れる。
3. 国人家の当主は「直系がいない」「弟は家臣に不人気」と判断して受ける。旧臣の一部は「家を奪われた」と不満を抱く。
4. 三男が家督を継ぐと、国人家は実質的に本人の一門になる。

**幼君と後見**
1. 当主が亡くなり、嫡男は10歳。家督は嫡男が継ぎ、叔父（当主弟）が元服まで後見する。
2. 叔父が忠実なら、元服で政務を返す。実権を握れば、嫡男派と対立する。
3. 家臣の中には「叔父を当主に」と動く者も出る。

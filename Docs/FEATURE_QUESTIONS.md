# 百代鏡 — 機能・アイデア確認ログ

ゲームの機能について、質問された順番に確認結果を残すための一覧です。**このファイルは調査記録であり、仕様の確定・変更や実装の依頼ではありません。**

## 運用ルール

1. 新しい質問ごとに **No.001、No.002、No.003…** と番号を付け、このファイルの末尾へ追記する。既存番号を振り直したり、過去の質問を削除したりしない。
2. 原則として、質問時点の `prototype/godot-foundation` の実装と現行設計資料を読み取り専用で確認する。必要に応じて `design/foundation` も参照する。調査時のブランチ・コミットを記録する。
3. **アイデア・仕様の有無**と**実装の有無**を分けて判定する。資料に記載があっても、実装済みとは扱わない。
4. 記録するのは確認結果だけ。ゲームのソースコード、既存設計書、保存形式、他のブランチには変更を加えない。
5. 後日の再確認で状況が変わった場合は、元の記録を残して該当No.に日付付きの追記を行う。未確認事項を「なし」と断定しない。

### 判定の意味

- **アイデア・仕様**：`あり`／`一部あり`／`見当たらない`／`確認保留`
- **実装**：`実装済み`／`一部実装`／`未実装`／`確認保留`
- **内容**：何が想定され、現状どこまでできるのかを短く説明する。

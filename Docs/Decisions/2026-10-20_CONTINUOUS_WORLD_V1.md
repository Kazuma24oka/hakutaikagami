# 全国・連続地形 v1（2026-10-20）

ユーザー依頼「全部やって」：隣接地域、境界保存、全国との同一座標、表示負荷、命令・戦闘、全国展開、背景改善の7項目を一つの検証入口へ接続する。prototype/godot-foundation を使用。旧Main・既存保存規則・Confirmed・保護ブランチ・旧素材を保持する。

## 1. 一つの世界と地形正本

新ruleset continuous-world-v1 / world:continuous-world-v1 を追加。既存の WorldSession、秒時計、RegionalBattle、物理配送、返報、権限・拒否、接敵と同時損害、士気退却、GenerationSaveStore を共用する。ズームや区画の表示切替で世界を新規生成しない。旧プロファイルの地形や保存を新規則として読み替えない。

全国投影は既存 display-equirectangular-36N-138E-R6371000-v1。地形座標は既存 FieldWorld.ToWorld と同じ清洲基準の整数mm。10mの共通格子を80mずつ区切る。terrain:world/x/y は正負座標を床方向に分割し、頂点高さは区画内乱数でなく同一の世界座標から取得する。隣接区画の共有頂点は同一。三角形・経路の区切り・地面選択・保存高さ・武将の足元を共用する。

陸地全体を遅延生成する。Core/Data/japan-terrain-mask-v1.json は既存 Game/Data/Geography/japan-map-v1.json のコピーを独立Coreの資源として固定したもの。概略海岸線の陸海判定のみで、現代の道路・ビル・ダム・標高DEMを持ち込まない。海岸線は戦国期の復元ではなく、細かい入江・干潟・埋立差は未再現。既存カタログの出典・ライセンス情報を保持し、ファイルSHAを地形版へ結合する。

拠点周辺の約800mは支流・通行可能な橋・森・斜面・崖・木柵の砦を合成する。それ以外の陸も合成起伏と通行種別を生成する。配置は遊べる検証用で、清洲・三戸・府内等の実際の地形・城郭・植生・川の復元ではない。同じ型を各拠点へ適用しており、ご当地の外観制作の完成ではない。追加の史実・所有勢力・武将配置を捏造しない。

## 2. 自由布陣・全国街道・海路

陸上の地面指定は任意座標を保持し、周囲の10m格子で迂回する。半径1mの占有、木・壁・建物の占有矩形、水面・崖を共用する。A*探索は局所最大640m、探索16384セルで上限を持つ。遠隔地点への一発の自由地形探索は行わず、街道は既存の108拠点118経路へ接続する。部隊数に応じた布陣間隔を確保する。

海路は既存の12固定航路。陸地の自由移動を海へ広げない。全国経路は陸106・海12の概略リンクであり、歴史的な道筋の実測や10m格子に沿った全路線の復元ではない。拠点周辺の合成道路はその地域の実道路の詳細復元ではない。全国の経路線と局所の合成道路は、位置参照と移動モードを接続した段階で、すべての道の曲がりまで一致させたものではない。

野外からの街道移動は帰還・配送完了後に拠点へ入り、既存の本人移動を開始する。到着後に同じ世界時間のままその拠点の集合位置へ展開できる。集合位置は拠点代表点付近の試作配置で、城門内外の連続歩行演出は未実装。他の武将・敵・兵数・士気・損害をリセットしたり、到着先へ瞬間移動させたりしない。全国NPC AIや全国同時戦闘の大量部隊配置は今回の試作に含めない。

## 3. 保存復旧

schema2の任意Atlasは新rulesetでのみ必須。AnchorとTerrainVersionを検査し、地形版不一致を拒否する。旧保存にはAtlasを追加しない。共通SavePresentationの任意WorldCameraへ中心・幅・回転・追従・背景表現を保存し、manifestのハッシュへ結合する。省略した旧保存も読める。世界状態と表示設定は分離し、カメラを動かしても世界状態を変更しない。

保存地点を別Godotプロセスで復旧し、カメラ・区画ID・部隊姿勢・高さ・位置の一致を検査する。さらに同じ時刻まで続行して3D画面を比較する。世代読み込みによるRevisionの増加と停止は既存の仕様で、世界進行の同一性は移動・損害・配送等の意味のある状態と実画像で検証する。

## 4. 表示範囲と負荷

表示幅240m以下は最大5×5＝25区画、共有地形512三角形/区画、合計12800地面三角形。地面は表示用の色分けだけ細分化し、元の平面から頂点を動かさない。範囲外の区画を解放し、全国では詳細区画0。武将モデルは既存near/mid/far資産から画面上の大きさに応じて決定的に選択し、保存カメラから同じLODを復元する。独立した全国LODと局所詳細の2段階であり、中間倍率の起伏LODや滑らかな地形フェードは未実装。

視点中心を引いた座標で描画し、全国の巨大なmm値をそのままモデル座標へ流さない。通常の近傍更新では既存区画を再利用する。地形種別の派生キャッシュも65536エントリを目安に破棄し、世界保存へ入れない。全国108拠点を実GPUで巡回し、常駐25区画を確認する。36分隊は試作規模の検査であり、全国数万部隊の性能保証ではない。実測の更新時間はverification.jsonへ記録する。

既知の人物だけを既存RegionalBattle.Viewから描画する。カメラ移動や地形読込は未知の敵の真実の位置を公開しない。目撃が古くなれば最終目撃を表示する。公開拠点の表示と人物の所在情報を混同しない。

## 5. 背景品質と差し替え

道・草地・森・岩の材質を既存外観IDのカタログから取得する。決定的な細粒テクスチャ、複数段の樹冠、岩の面、砦の上層と屋根を追加する。背景切替でこの表現を比較できる。建物・柵の基部は占有範囲の地形高へ合わせる。これは既存最低ラインからの段階的改善で、最終アート品質の完成を意味しない。

岩・木・建物・壁は対応Visualがsceneなら既存SceneryVisualAssetsの静的モデル契約を使う。既定値は手続き形状で、素材比較では実際の .tres の道と .tscn の岩へ交換する。明示した外部テクスチャは細粒表現で上書きしないことを検査する。地表は材質交換で、形状や道幅・起伏・通行を変える場合は地形正本も版管理して再検証する。モデル・UV・配置は安定したIDを使い、カタログの列挙順やフレーム番号に依存させない。描画表現の切替は世界状態ハッシュが不変であることを検査する。

## 6. 操作と検証入口

Scripts/Show-ContinuousWorld.ps1：全国／地域／詳細、ホイール拡縮、視点回転、中ボタン移動、地面を左ドラッグして布陣、自動進行、現地の接敵・帰還、別働隊への配送、拠点出入り、行先選択・全国出発、保存・復旧、背景表現切替。

Scripts/verify_continuous_world.py でビルド・全単体テスト・実GPU・別プロセス復旧・画像比較・動画を再生成する。実画像点検を記録してから Scripts/check_continuous_binding.py で現在のコード・資産・DLL・画像・動画との一致を確認する。runtime-local は生成物でGit対象外。通常のマウス操作ツールは一切使用しない。

実測の件数、各ケース、保存点、画素比較、映像、負荷は Docs/Design/ContinuousWorldV1/verification.json を正とする。旧試作のbindingは共通コード更新で再検証まで失効する。検証済みの範囲を全国歴史地形や完成ゲームの保証へ広げない。

次はこの共通世界を通常のプレイループへ統合し、平時の任務と軍議の指示から移動・交戦・返報へつなげる。その後、中間倍率の地形表現と、拠点ごとの史実資料に基づく固有地形・城郭を順に改善する。

## 最終実測

.NET SDK 10.0.302 / net8、Godot4.5.2 .NET、Windows・RTX4060Ti/OpenGL Compatibility。ビルド警告/エラー0、774件（追加16）全合格。実Godot25プロセス、12ケース36保存点、GPU387検査、復旧/続行72比較と背景/ズーム復帰12比較＝84比較は差分0。背景差12比較は実際に変化、比較PNG168枚。全国108拠点を実GPUで巡回し詳細は常駐25以下、全国は0。素材交換ケースは岩396インスタンスと明示的な道テクスチャを確認した。

実Godot固定24fps動画26秒624フレームを全デコードし、0/3/5/9/12.5/16/20/24/25.6秒の場面と代表PNGを点検。収録実時間43秒で、対話時の24fps保証ではない。新画面では伝令の専用モデルは描画せず、配送経路・到着判断・返報の結果をUIへ接続している。画素一致は同じ表示環境・サイズ・資産の条件下での実測。Core/資産/バイナリ/出力SHAと更新時間はverification.jsonを参照。

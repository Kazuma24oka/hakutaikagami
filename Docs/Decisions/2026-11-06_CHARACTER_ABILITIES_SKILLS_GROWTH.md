## 1. 基礎能力と人物差

基礎能力は次の5つ、値域は従来どおり1〜100。旧「交渉」は技能へ移し、「魅力」を基礎能力に加える。

| 能力 | 担当する力 | 技能・関係との境界 |
|---|---|---|
| 統率 | 集団へ指示を行き渡らせ、連携・隊形・行動を保つ | 指揮する権利や相手の服従そのものを与えない。武器の熟練だけで補えない |
| 武勇 | 本人が戦い、身を守り、身体を使って実行する力 | 剣術・槍などが具体的な熟練。本人の強さから大軍の指揮能力を自動的に得ない |
| 知略 | 既知の情勢・相手の狙いを読み、方策・駆け引き・対案を考える力 | 専門知識や未知情報を自動取得する万能知能にはしない |
| 政務 | 人・物・金・制度を整え、継続して運営する力 | 農政・財務などが分野別の熟練。外交や権力闘争の巧拙と分ける |
| 魅力 | 本人への関心・親近感・期待を生み、人を惹きつける力 | 容姿・善良さ・既成の人望・名声・家格と分ける。実際の接触・働きかけと認識した評判を通じて作用する |

交渉の条件の見立ては知略、折衝の熟練は交渉技能が担う。魅力は話を聞く意欲や関係づくりに働き、全交渉へ単純に三重加算しない。相手の利害・義務・拒否条件と、双方の知識・権限・資源は維持する。

統率は集団の連携維持、武勇は本人の奮戦とそれを実際に見聞きした周囲への影響、魅力はその人物を支えたいという期待に役割を分ける。同じ士気へ3能力の無条件な補正を重ねない。低統率・高武勇の剣豪、高政務・低知略の実務家、高魅力でも指揮が不得手な当主を成立させる。

## 2. 採用する6分野・32技能

分野は人物帳と学習先の分類であり、「軍事レベル」「内政レベル」や人物の総合レベルは作らない。各技能を独立した0〜100のレベルと経験で持つ。0は未修得の初期状態を表し、その人物が実行条件を満たす行動を一律禁止する値ではない。

下表の主能力は代表的な行為の参照先。分野ごとに一律固定せず、計画・現場実行・個人使用・部隊運用を行為定義で区別する。各行為は経験の対象技能と主能力を明示する。

|---|---|---|---|
| 軍事 | 戦術 | 知略／統率 | 既知の地形と敵情からの作戦検討、部隊運用・撤退。見立て、連携、再集結の手際 |
| 軍事 | 兵站 | 政務 | 輸送・集積・配給の手配と管理。準備の手際、割当や不足の見落とし |
| 軍事 | 攻守城 | 知略／統率 | 城の偵察、包囲・防備・攻撃の準備。既知の区画や補給路を使う計画と実行 |
| 軍事 | 調練 | 統率 | 実際の兵を集めて訓練を計画・指導。隊形、指示の理解、再編の習熟を育てる |
| 軍事 | 水軍 | 統率／知略 | 実在の船と船員による海上輸送・護送・封鎖。航路の見立て、船団の連携と準備 |

| 軍事 | 槍 | 武勇／統率 | 槍の稽古・個人使用、槍隊の運用。個人の扱いと、指揮時の兵科理解 |

| 内政 | 治水 | 政務 | 堤・水路・排水・水利の調査と施工計画。水に関わる条件と維持管理の把握 |

| 教養・育成 | 連歌 | 知略／魅力 | 学習・連歌会。表現の熟練と、同席者に伝わる文化的な交流 |

「槍術」は「槍」の同義表記とし、別技能に数えない。直前の説明に出した剣術も今回の全採用に含める。表にない商政・航海・学問・取次などを、この採用から自動追加しない。

### 行動への接続と重複の整理

- 技能の効果は計画・成果の質、実作業の手際、知識に基づく調査・評価へ接続する。技能値から条件を無視した成功・失敗の抽選だけで決めない。
- 一つの工程には主技能を1つ置く。普請と治水、交渉と調停などの両方が必要なら、担当する実作業の区間を分ける。名称が関連するだけで補正や経験をすべて重ねない。
- 同じ資源・手順で熟練だけを比較する標準の時間補正は、実作業部分を「基準時間×(1−0.25×技能レベル/100)」とする。技能0は100%、50は87.5%、100は75%。移動距離、配送待ち、作物の生育、療養期間などの物理的な経過はこの一律短縮の対象外。
- 時間へ適用した同じ熟練を、同じ作業の生産量にも重ねて増益にしない。戦闘・交渉・鑑定など時間短縮だけが適さない行動は、上表の具体的な効果を使い、既存の接触・資源・権限・本人の判断の計算へ個別に接続する。
- 人材評価・情報・鑑定・医術は、実際の観測・史料・報告で到達できる材料を使う。隠れた能力・忠誠・遠方の真実・未来の病状を自動公開しない。
- 調練は本人の指導技能。兵の実際の訓練状態との接続を行うが、独立した部隊総合レベルは今回追加しない。水軍も初回の海上輸送・封鎖等の範囲を引き継ぎ、個艦直接操作を新設しない。
- 医術・鉱山・工房管理等は武将が持つ知識・実務・管理の熟練。医師・忍者・商人・鍛冶師を主職とする独立人生コースは、本書による追加対象ではない。医術の治療・療養への接続は[同日採用の健康設計](2026-11-06_HEALTH_RECOVERY_AND_DUTY_CONTINUITY.md)に従う。

## 3. 兵科適性と個人武芸の改定

旧§9決定8の「個人武芸を持たず武勇で代用」と、兵科適性を技能と別に並べる方式を、新方式では次のように更新する。兵の種類・装備・指揮権・陣形・資源の規則は維持する。

| 旧項目 | 新方式で参照する熟練 |
|---|---|
| 槍適性 | 槍技能 |
| 弓適性 | 弓技能 |
| 鉄砲適性 | 鉄砲技能 |
| 騎馬適性 | 騎馬技能 |
| 輸送適性 | 兵站技能 |
| 個人武芸は持たない | 武勇を基礎とし、剣術・槍・弓・騎馬・鉄砲の該当技能を参照 |

同名の兵科適性と技能を二重に成長・加算しない。個人が槍を扱う場合は武勇、槍隊を実際に動かす場合は統率を土台にする。戦いの見立てでは知略・戦術を使う。武器技能を高くしただけで低い統率の弱点を消さない。

剣・槍・弓・鉄砲・馬、弾薬・飼料は実在し、使用・確保・消費・移動を伴う。武器の熟練で持っていない装備を生成せず、天候・地形や通信にかかる時間も維持する。

## 4. 技能経験・レベルの初期調整値

以下を委任に基づく初版の調整値として採用する。将来の試し遊びで速度を調整できるが、変更は方式の版と適用範囲を記録する。

### レベルと必要経験

- 技能レベル：0〜100。
- レベルLからL+1への必要経験：7200×(L+1)。
- レベルLの累積経験の下限：3600×L×(L+1)。
- 初期経験と開始後の実獲得経験の合計から、到達した最大のLを求める。100を超えるレベルを作らない。
- 「1経験」は標準実務1秒分に相当する設計上の単位。経験は現実時間ではなくゲーム内の実働時間から得る。

| 到達レベル | 累積経験 | 標準実務の累計時間 | 人物像の目安 |
|---|---:|---:|---|
| 10 | 396,000 | 110時間 | 初歩を身に付けた |
| 20 | 1,512,000 | 420時間 | 基礎を習得した |
| 50 | 9,180,000 | 2,550時間 | 実務に熟練した |
| 80 | 23,328,000 | 6,480時間 | 高度な熟練を持つ |
| 100 | 36,360,000 | 10,100時間 | その分野を極めた |

人物像は表示の目安であり、各段階で無条件に権限・職・実績を付けるものではない。

### 経験を得る行為

| 行為 | 技能経験の倍率 | 条件 |
|---|---:|---|
| 実務・実戦・実際の交流や指導 | 100% | 本人が担当した実働。任務の最終成否だけで経験を取り消さない |
| 独習・自主修行 | 50% | 適切な場所・教材・道具等がある有効な練習。放置して時間だけ経過する待機は対象外 |
| 師事・指導を受ける | 100〜150% | 100%＋教師の教育技能×0.5%。教師の対象技能が学ぶ側より高く、双方が実際に時間を使う |

実務1時間なら3600経験、独習1時間なら1800経験。教育技能60の教師から1時間学ぶ場合は4680経験。教師が教育100なら5400経験。教師の専門技能を超える段階へ、師事だけで自動到達しない。上限に達した指導から余分な経験を貯めて後で跳び越させず、以後は別の師・実務・独習へ切り替える。

教育は教える上手さであり、知らない専門を教える能力ではない。教師側は実際に教えた時間を教育の実務として得る。教師と生徒の経験は別人の実働として記録する。同じ授業の人数が増えても、教師の経験を人数倍にはしない。

子への教育は[後続の育成設計](2026-11-06_CHILD_EDUCATION_AND_INDIVIDUALITY.md)に接続する。本書の経験曲線・専門と実時間の条件を共用し、年齢に伴う発達は別に扱う。1日8時間は子の標準日課にはせず、年齢・健康に応じて実行する。教育方針だけの経験や同じ学習の重複計上は行わない。

### 時間・保存・二重計上

- 経験へ計上する実働は、1人物・全技能合計でゲーム内1日8時間まで。これは行動そのものの禁止ではなく、学習効果を計上する上限。倍率適用前の時間を数える。
- 同じ実働時間を複数技能へ満額で重複加算しない。複数の技能を使う任務は実際の担当区間へ時間を配分し、その合計を実働以内に保つ。
- 指示を出しただけの待機、他人が担当した実作業、未着の返答待ち、稽古を開始して即中止する操作、報告の再閲覧には経験を付けない。
- 中断までに完了した有効な実働区間は一度だけ残し、未実行分は付けない。世界時計を止めた時間を加算しない。
- 人物・行動・実働区間・技能・方式の版・確定済み経験を結び付ける。同じ区間の再送・再開・保存読込で重複付与しない。
- 日付境界で実働を分け、倍率の端数は固定小数・余りとして保持する。画面内外、実行速度、まとめ計算の区切りで経験が変わらない。
- 作業時間の補正と教師倍率に参照する能力・技能は、行為または定義済みの実働区間の開始時に確定し、後で上がった値を過去の実働へ遡及適用しない。区間は描画フレームや計算の分割都合では変更しない。
- プレイヤーとNPCは同じ規則。NPCは自分の目標・役職・既知の教育者や設備を使い、すべての技能を自動で同時成長させない。

### 基礎能力の成長

基礎能力も実経験でゆっくり伸びるが、技能経験・勲功とは別に管理する。使用した主能力へ標準経験7,200,000（2000時間相当）で1上昇、上限100を初期値とする。

基礎能力経験の倍率は実務100%、独習50%、師事100%。教師による技能学習の上乗せは基礎能力へ重ねない。基礎能力も上記の1日8時間以内へ計上した同じ実働を使う。同じ時間を5能力すべてへ付けず、個人の槍稽古は武勇、部隊運用は統率というように行為の担当に対応させる。初期技能経験の換算や、技能レベルの閾値通過だけでは基礎能力を上げない。

## 5. 開始時の熟練と表示

- 人物ごとに32技能の開始熟練を持つ。史実武将の実務・従軍・学習などの経歴と根拠を付け、評価の確度・推定・試作を区別する。基礎能力の高さだけから全技能を高くしない。
- 初期レベルL0は累積経験3600×L0×(L0+1)へ換算し、「開始前の熟練」として保持する。この換算量は計算上の表現であり、開始前の実働時間が史料で実証されたという意味ではない。開始後の実行経験や主君への勲功と混同せず、経験を二重に付けない。
- 未採録の技能を「史実上未熟だった」と断定しない。内部の試作初期値を置く場合は、未採録・推定の印と根拠を持たせる。小田氏治等の能力を、この会話の人物評だけで確定採録しない。
- 作成武将は、基礎能力の既存予算と別の技能経験予算で開始熟練を選ぶ。初期調整は標準実務3000時間相当、1技能の開始上限50。各技能の累積経験を合計して予算内に収める。使わなかった予算は新規世界の開始時に失効し、開始後の任意振分けにはしない。
- 作成時には配分を省略できる経歴別の推奨配分を用意する。同じ予算・上限を使い、特定身分だけで技能・家格・資産を同時に無償付与しない。史実人物の採録値には作成武将の予算を強制しない。
- 本人は能力・技能レベル・次の上昇までの進み具合を見られる。他者は既知の実績・観察・受領した報告から推定幅・根拠・時点を示し、登用だけで正確値や内心を開示しない。
- 経験獲得の通知は行為の区切りにまとめる。時間を進めるたびに32項目の通知を出さず、伸びた技能とその理由を確認できるようにする。

## 6. 名家などの出自・家格

「名家」は採用するが、経験で上がる技能には数えない。名家の出・守護家の一門・公家出身・在地の旧家などを、家系・家との関係・認識される家格から説明する出自・特性として人物帳に表示する。

- 名家、守護家の一門など同じ根拠を言い換えた表示で、複数の一律補正を積み重ねない。
- 相手がその家を知り重んじる場合に、面会・取次・縁組・後継支持・再興支援などの判断材料になる。全員共通の忠誠加算や自動服従は作らない。
- 家柄、現在の身分や権限、本人の魅力、伝わった名声、相手との恩・義理・利害は分ける。養子や家督で立場が変わっても、他人が知らないうちに関係を一斉更新しない。
- 名家の出だが本人は好かれていない人物、家柄に恵まれなくても本人や実績を理由に支持される人物を両立させる。
- 本書の全採用は、列挙した能力・技能と出自の扱いを対象とする。未提示の固有才能・特殊効果一式を包括採用したことにはしない。

## 7. 新旧方式の扱いと実装への接続

本書の技能体系・経験曲線・基礎能力構成は、新規世界へ適用する版付きの方式とする。旧保存の7技能・定率経験・交渉能力・兵科適性はそのまま保持する。旧交渉能力を魅力と読み替えたり、新方式の経験曲線へ無断に再計算したりしない。

旧人物定義を新規世界で使う場合も、魅力と交渉技能の採録・設定は別に行う。兵科適性は新技能を採録する参考になり得るが、未定義の対応係数で機械的に全員を変換しない。互換処理・方式識別子・保存形式は実装工程で定め、既存の途中再開を壊さない。

| 接続先 | 完成へ残ること |
|---|---|
| BD-05・20 | 新能力・開始熟練・経歴・出自の採録、作成予算と推奨配分 |
| BD-13 | 32技能の行為参照、経験曲線、教育、実務との接続、旧方式との共存 |
| BD-14〜16 | 魅力と関係・名声の分離、正確値と推定表示、技能と出自を区別した人物帳 |
| BD-38〜40 | 兵科適性の技能への統合、個人武芸と集団指揮の分離、実物資と訓練への接続 |
| BD-57〜59 | 成長理由の表示、学習先の選択、NPCの役割別育成、文面と必要素材 |

進捗は設計採用だけで加点しない。60枠・重み・受入170件・進行中の実装工程を維持し、拡張した技能の実装・評価は対応工程で扱う。今回、固定基準や既存工程の完成記録を書き換えない。全体見積の再評価は、実装範囲・行為への接続を工程へ割り当てる際に行い、現在の見積が32技能の完成を保証するとは扱わない。

## 8. 今回の確認範囲

今回確認するものは、32技能の重複と件数、旧5適性すべての対応、経験式と例の一致、文書間参照、進捗の限定した更新と生成HTMLの一致。ゲーム実行・Core・保存復旧・GUI・長期成長バランスの実動作検査は未実施とする。

実装時には、個人戦の武器熟練だけで統率を代替しないこと、実務・独習・師事の経験、8時間上限と複数技能、教師の専門上限、初期経験と能力成長の分離、旧保存維持、再開とまとめ計算の一致、既知情報からの推定表示を関連検査で確認する。これは固定受入170件の無断追加ではない。

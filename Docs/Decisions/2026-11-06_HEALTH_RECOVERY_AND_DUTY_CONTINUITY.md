# 健康・療養と、可能な仕事の継続

- 採用日：2026-11-06（日本時間）。
- 根拠：疲労・負傷・病気・加齢を分け、その状態で支障のある行動へ影響させ、療養中も可能な政務や委任を続けられる方針に対し、ユーザーが「良いと思います」と承認した。
- 状態：設計採用。採用した医術と、食事・休息・負傷・自然死の既存実装を、本人の健康モデルへ総合接続したことを意味しない。
- 管理先：監査DG-04、BD-06・07・13・16・22・28・57〜59。基本設計・統合案への追補とする。
- 相談の進行：健康・療養の基本方針は本書で決定済みとして区切り、次はDG-05「子の教育と次世代の個性」。実装の進行中工程の順番は変更しない。

## 1. 状態を分け、行動への影響を対応付ける

健康・拘束・所在・所属・権限は別に管理する。健康面も次の状態を区別し、一つの値の低下だけで全行動を同時に止めない。

| 状態 | 持つ内容 | 行動と回復への接続 |
|---|---|---|
| 疲労 | 身体・集中への負担と回復の経過 | 行軍・仕事・修行等の実働で蓄積し、該当する動作や集中へ影響する。食事・睡眠・休息を回復に結び付ける |
| 負傷 | 傷の部位・重さ・経過と、必要な手当 | 脚なら移動や騎乗、腕なら武器の使用など、支障のある動作へ対応付ける。療養・治療・経過から回復を判定する |
| 病気 | 観測した症状・重さ・経過、診察による見立て | 身体活動に加え、集中や意思表示が難しい場合は政務・交渉等にも影響する。必要な療養・介抱を選べる |
| 加齢 | 年齢に伴う身体面・回復力の変化と個人差 | 全能力の一律低下にせず、具体的な負担や回復の経過へ作用させる。既得の知識・熟練とは分ける |

傷や病気は同時に存在し得る。同じ影響を複数の状態で重複計算しないよう、行動の必要条件と、現在支障がある理由を対応付ける。病状の段階・進行速度・回復量・個別の制限値は、実装時の調整表で定める。本書だけから特定の病名や死亡率を設定しない。

## 2. 療養中にできることを残す

行動可否は「体を動かせるか」「判断・意思表示できるか」と、その行為の所在・権限・時間・物資・拘束条件を合わせて決める。

| 状況の例 | 本人ができること・制約 |
|---|---|
| 軽い疲労・軽傷 | 状態に応じて行動を続けられる。時間・身体動作・集中など影響する部分を示し、休む選択もできる |
| 脚を負傷した当主 | 出陣・長距離移動・騎乗に支障があっても、状態が許せば面会・書状・評定・人事等を行える |
| 高熱等で判断が難しい人物 | 身体活動だけでなく、判断や集中を要する政務・交渉も制限される。意識があることだけで全政務を許可しない |
| 重傷だが意識・判断が明瞭な人物 | 負担の小さい短い面会・指示・上申・後継指名等を、状態と既存の手続が許す範囲で行える |
| 危篤 | 病状の危険度と意思表示の可否を分ける。危篤という区分だけで死亡や家督移転を確定しない |
| 意思表示できない人物 | 本人の新しい判断は行えない。以前から適法に委任された仕事は、受任者の権限と認識の範囲で続く |

書状の作成と配送・開封は従来どおり別。捕虜が書ける状態でも、監視・没収・許可の規則は通る。療養中という理由で自由な通信や新たな権限を得ない。

病気や負傷だけで役職・家督・所領・指揮権を自動移転しない。代理人を自動生成したり、代理人が本人の新たな意思を代わりに作ったりしない。療養からの復帰と、代理業務の終了・帳簿や物資の引渡しも個別に扱う。

## 3. 任務を抱えている人物の休養と責任

傷病や療養の必要は、任務や預り物がある場合にも発生する。重傷者が正式な部隊返還の完了まで休めない、といった制約にはしない。

- 実行できなくなった仕事は中断し、本人または既存権限を持つ者の報告、延期・取消・代理の依頼、返還や引継ぎへつなげる。通信不能の場合も身体の状態は進行する。
- 治療や休息を始めたことと、任務の免責・取消・期限変更・代理承諾の成立は分ける。上司や相手は、届いた知らせと把握した事情から判断する。
- 正式な処理まで、役職・指揮権・所有・預り物・未払い・既存の責任は保持する。自動で他人へ移したり、病気を理由に消去したりしない。
- 代行可能な仕事があっても、委任する権限、受任者の引受と能力、所在・通信・物資が必要になる。
- 復帰時には、今も有効な任務・許可・委任・引継ぎの状態を確認し、古い命令を無条件に再実行しない。

[PersonalLifeV1](../Design/PersonalLifeV1/README.md)の「預かった部隊や進行中任務がある間は休息を拒否する」は旧試作の記録として保持する。新方式ではこの一律制限を上の状態・義務・手続の分離へ置き換える。既存保存にこの変更を無断で後付けしない。

## 4. 医術・介抱・食事・環境と回復

[32技能の決定](2026-11-06_CHARACTER_ABILITIES_SKILLS_GROWTH.md)で採用した医術を、診察・手当・介抱・療養の手配へ接続する。

- 治療者と介抱する人は実在し、必要な場所・時間・道具・物資を用意する。食事・休養・療養場所と、その人物が実際に受けた処置を経過へ反映する。
- 医術は観測した症状の見立て、処置や手配の適切さに働く。未知の病状・未来の悪化・正確な残り寿命を自動取得せず、見立ての根拠と不確かさを持つ。
- 治療の準備や実作業の手際と、身体が回復する経過を分ける。技能の標準時間補正を療養期間全体へ一律適用せず、高い医術による即時全快や生存保証は作らない。
- 食事は実在の食料・所有・支払・消費に従う。今回の決定だけで食事を自動消費へ変えたり、食料不足による新たな強制死亡を加えたりしない。
- 療養も共通時計で進み、世界全体を個人のために別の速さで進めない。世界停止中は回復時間も進まない。通知・停止の既存設定を使い、療養開始だけで数日を自動的に飛ばさない。

## 5. 能力・技能と一時的な状態補正

一時的な疲労・負傷・病気で、基礎能力の記録や習得した技能経験を削除しない。実際の行動に影響する現在の状態補正を分け、回復すれば、その原因による制限や補正を解除する。

後遺症が残る場合は、部位・症状と支障のある動作や行動へ対応付ける。身体の後遺症を理由に知略・政務・すべての技能を一律に消さない。加齢も同様に、身体・回復力の変化と、積み上げた知識・経験を分ける。

治療を受ける・休む・回復を待つだけでは技能経験を得ない。診察・手当・介抱を担当した側や、療養中に実行可能な実務を行った本人は、32技能の実働・日上限・二重計上防止の規則に従う。実行不能だった仕事や、代理人が行った実務を本人の経験にしない。

## 6. 認識・NPC・死亡の扱い

本人に確認できる症状、実行への支障、診察で伝えられた見立てを表示する。他人の病状は面会・観察・受領した報告から知り、出典・時点・不確かさを保つ。療養中の遠方の人物が回復・悪化した真実を、未通知の相手へ即時に知らせない。

行動できない場合は、身体・判断・権限・拘束・物資等の理由を区別して示す。本人が認識した重要な変化は、既存の通知・自動停止と判断支援へ接続する。未知の危機で先回り停止しない。

NPCも同じ健康・実働・物資・通信の制約を使う。本人の知識・目標・責任に基づき、仕事の継続、休養、治療依頼、報告、代理依頼、復帰を判断する。

死亡時期は既存の史実尊重・準史実・仮想の方針と、戦死・暗殺等の別経路を維持する。新しい健康モデルや医術だけで、歴史モードの自然死方針を変更しない。危篤・意思表示不能・死亡・家督承認・プレイヤーの操作継承を一つの遷移にまとめない。死亡や継承の知らせも既存の伝達条件に従う。

## 7. データと既存実装への接続

| 区別して持つ内容 | 対応する原本・境界 |
|---|---|
| 状態と経過 | 人物、疲労、負傷の部位・重さ、病状、発生と進行の時点、加齢による補正、後遺症 |
| 行動への影響 | 対象となる動作・判断・集中と制限理由、開始・継続・中断・再開の条件 |
| 治療・療養 | 本人、治療者・介抱者、場所、観測・見立て・処置、実時間、消費・費用の原本 |
| 認識 | 観察者、本人や治療者の説明、報告の出典と時点、受領・開封、見立ての確度 |
| 任務・委任 | 既存の中断・延期・取消・代理・返還・復帰の案件への参照。権限や財産を重複作成しない |
| 保存の継続 | 適用方式の版、確定済みの経過・処置・消費・実働区間、進行中の待ち状態 |

食事・休息、兵の負傷と療養、家族への知らせ、出生・元服・自然死には既存の実装がある。それぞれの成功記録を保持し、本書をもって本人の健康・療養が実装済みとは扱わない。兵の集団としての療養と、武将本人の部位・行動制限も区別する。

新方式を適用する範囲・開始条件・保存の世代は実装工程で明示する。旧保存の休養時間から過去の治癒や経験を遡及発生させず、旧方式を無断に再計算しない。再開やまとめ計算の区切りによって回復・消費・通知・経験が重複しないようにする。

## 8. 今回の確認範囲

今回の作業は設計文書と関連する残件・根拠の更新に限る。採用範囲、状態と権限の分離、32技能や史実モードとの整合、参照先と進捗HTMLの一致を確認する。ゲーム実行・Core・保存復旧・GUI・療養バランスの実動作検査は未実施。

実装時は、脚の負傷と政務継続、判断困難時の制限、任務を抱えた人物の療養と引継ぎ、捕虜の通信、代理業務、治療資源の消費、回復と後遺症、観測前の病状を漏らさない表示、途中保存の継続を関連検査へ接続する。

設計採用による完成率の加点はしない。基本設計60枠・重み・受入170件・進行中の工程・固定済みの評価を維持し、実装と調整の残件を分ける。病名一覧、具体的死亡率、感染・流行の仕組みは今回の承認から自動追加しない。

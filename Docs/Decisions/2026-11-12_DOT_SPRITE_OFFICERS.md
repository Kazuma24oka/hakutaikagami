# ゲーム内の武将をドット絵にする（2026-11-12 ユーザー決定）

- 根拠：ユーザーが「3Dモデルでの武将があんまり納得いかないからドット絵での差し込みも検討」（2026-11-11）、続けて「ドット絵のアニメーションまでふくめてできました。有名武将は固有の一式装備を用意しています。他の武将は違和感ないように組み合わせてほしい。平時は和服をきて戦争中は甲冑をつけるスタイルです。兵士は足軽です。僧兵も一応あります。」（2026-11-12）。
- 置き換える範囲：地図・街道・合戦の場面に立つ武将と兵。BD-59 の「全周の3D」は、ドット絵（左向きと左右反転、待機・行軍・攻撃・被弾・勝鬨）に置き換える。会話の立ち絵（2Dイラスト）は別で、変えない。
- 3Dの武将の実装は消さない。ドット絵の束が無い環境では3Dのまま動く。

## 見た目の決まり
| 対象 | 平時 | 戦時（軍勢・戦闘中） |
|---|---|---|
| 有名武将 | 固有の和服 | ツールの固有の一式（信長・信玄・家康・謙信・政宗・幸村・忠勝・直政・秀吉・元就・義弘） |
| 大名・国衆 | 直垂・大紋と侍烏帽子 | 名将の兜＋一般の前立て（鍬形・日輪・水牛）・面頬・旗指物 |
| 家臣 | 裃・羽織袴・小袖と袴 | 星兜か筋兜＋鍬形（無しもある）・旗指物、刀・槍・弓 |
| 浪人 | 小袖・小袖と袴 | 頭形兜か星兜、刀・槍、旗指物なし |
| 公家 | 狩衣と立烏帽子 | 星兜＋鍬形 |
| 僧 | 法衣と袈裟、剃髪 | 僧兵の一式（行人包・薙刀） |
| 兵 | — | 足軽（陣笠・御貸具足、槍・鉄砲・弓）、寺社の武装勢力は僧兵 |

- 甲冑の色は家ごとにそろえる（織田＝黒漆、武田＝朱、北条＝萌黄、今川＝紫、大友＝銀白、島津＝鉄錆、それ以外は家から固定で選ぶ）。赤備え・金箔と、有名武将専用の前立て（三日月・鹿角・天衝・諏訪法性・馬藺・六文銭・歯朶・飯綱・三鍬形・上弦の月・南蛮兜）は一般の武将に使わない。
- 一般の武将は、身分×年齢（若・壮・老）×顔立ちの型から、人物IDで固定して選ぶ。老年は白髭・白髪が混じる。
- 平時の和服では武器を手に持たない。

## 素材の扱い
- 絵はユーザー自作の「甲冑アニメ工房」から、`Tools/DotOfficerBaker`（画面なしのブラウザで一括描画）で書き出す。ツール本体は変えない。
- 素体はちびコマドット絵作成機（商用版）の書き出し。素体の書き出しは規約上問題ない（2026-11-12 ユーザー確認。作者への問い合わせはちびコマの他のパーツの流用についてで、流用はしていない）。書き出した絵は `Game/Assets/DotOfficers/Sheets/` に置き、Git に入れる。

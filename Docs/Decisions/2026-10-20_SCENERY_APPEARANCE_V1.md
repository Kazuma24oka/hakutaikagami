# 背景外観の差し替え基盤 v1（2026-10-20）

ユーザー承認：道・岩などの見た目は暫定品質とし、後から改善できる構成を先に整える。同じ prototype/godot-foundation で実装。通常Main・Confirmed・main・design/foundationと既存素材は変更・削除しない。

## 正本とID

通行種別・速度・高さ・占有矩形は既存 RegionalScenery の正本を維持する。外観の都合で判定を書き換えない。Core/Appearance/SceneryAppearance.cs は描画契約のみを管理し、世界状態・世界定義ハッシュには追加しない。

- appearance:surface/road 等：役割を表す外観ID。
- visual:... / material:...：Game/Data/Scenery/scenery-appearance-v1.json 内の素材・モデルの対応先。
- region:kiyosu-trial-v1/rock:1/6 等：地域名前空間付き配置ID。元の通行障害物IDは SourceId として保持。
- variant:a / variant:b：固定Seedから決める形状選択。モデルの追加や並べ替えで既存選択を再抽選しない。

位置・寸法・向き・占有範囲は固定配置から得る。素材の色、ファイル名や列挙順を配置Seedに混ぜない。配置版 scenery-layout-v1 の変更は明示的な版管理を要する。地域IDの名前空間は用意したが、複数地域の地形接続は未実装。

## 差し替え可能な範囲

道・草・森地面・川・崖・斜面・橋床は共有三角形のまま、役割別の材質・テクスチャとワールドUVの反復寸法を変更できる。現在は StandardMaterial3D を使用する。頂点を動かすシェーダーや別形状の地表を単なる外観交換として受け付けない。道幅・起伏・川岸・通行を変える場合はCoreの地形定義も更新して再検証する。

木・岩・建物・城壁・橋柵は手続き形状、または静的PackedSceneへ対応付けできる。今回は岩だけを実モデルで交換して検証した。道の材質も実際の .tres を読み込む。交換例の道と岩は検証素材であり、高品質背景の完成品ではない。

外部モデルは res://Assets/Scenery/ 以下の .tscn/.glb、材質は .tres に限定する。glbはGodotで事前インポートする。ピボットは地面中央、ルート変換は恒等、単位m、+Yが上、+Xが東、-Zが北。カタログの AuthoringWidthMm/DepthMm/HeightMm はモデル制作時の基準寸法で、配置側寸法へ変換する。任意モデルの自動修復や自動最適化はしない。

許可するノードは静的Node3D/MeshInstance3D。スクリプト、衝突、ナビゲーション、アニメーション等を持つモデルは受け付けない。描画材質は静的StandardMaterial3D。地面下・過大な高さ・占有範囲からの張り出しを実メッシュ頂点で検査し、不適合なら代替形状へ戻す。4m未満の形状は通行障害物の占有範囲内に制限し、樹冠や庇だけ頭上の装飾を許す。岩は全体を既存通行不可セル内に限定する。

ファイル欠損・不適合は通知を残し、役割が同じ手続き形状へフォールバックする。未知のskinは基本外観へ戻す。独立した自動LOD、ホットリロード、全国性能の保証は今回の範囲外。

## 保存

SavePresentation に任意 ScenerySkin を追加。省略した旧保存は基本外観として読める。従来の2引数保存はJSON形状も従来どおり。世界本体、移動履歴、位置の保存契約は変更しない。skin IDを保存し、読み込み時点の対応表を使うため、素材改善だけなら世界保存の移行は不要。同じ対応表・素材で復旧した画面の一致を検証した。旧アプリによる新保存の読み込みは保証しない。過去の素材ファイルの永久固定・同梱保存はしない。

## 実測

.NET SDK 10.0.302、net8、Godot 4.5.2 .NET、Windows/RTX4060Ti OpenGL Compatibility。ビルド警告・エラー0、Core全758件（追加20）合格。実Godot21プロセス、10ケース30保存点。復旧・続行60比較、外観を戻す4比較、欠損/寸法不適合の代替2比較、計66比較は3D描画差分0。基本→交換の4比較では実際の見た目の変更も検出。108枚の比較証拠PNG、26秒624フレームの実Godot動画を保存し、代表画像と動画の抽出フレームを目視点検した。

詳細・ハッシュは Docs/Design/SceneryAppearanceV1/verification.json。verify_scenery_appearance.py → 実画像点検 → check_appearance_binding.py。コード・素材が変われば再検証する。旧GPU証拠を今回の実装の証拠に転用しない。マウス操作ツール不使用。runtime-localは生成証拠でGit対象外。

次は隣接地域の境界で、高さ・経路・移動・保存復旧を接続する。その後に全国規模の負荷と背景品質を段階的に改善する。

# 一地域の地形・命令・接敵・保存を統合した検証 V1

ユーザーの「検証、全部やってください」を受け、前の6段階を一地域の動く試作でつなぐ。製品全体や全国の地形制作が完了したという意味ではない。入口は `Scripts/Show-RegionalIntegration.ps1`。通常Mainと旧保存は維持する。

## 6段階で実装・確認するもの

| 段階 | 実装と確認 |
|---|---|
| 1 経路・部隊間隔 | 8方向経路、地形コストを悪化させない見通し平滑化、任意の布陣線、半径1m。途中の交差も相対移動の最接近で検査。先行部隊の到着先を迂回し、最大600秒の発進待ちでも安全でなければ保留。途中停止で予定が崩れたときは衝突する移動を直前の安全位置で止める。 |
| 2 起伏の共用 | 高さ0〜10mの合成斜面。経路所要・保存Location.HeightMm・3D地面の頂点・モデルの高さ・クリックの三角形交差判定が同じRegionalGround.Heightを使う。平面へのクリック投影で代用しない。 |
| 3 道路・道外・拠点 | 帰還して拠点に入り、既存の全国道路へ出発、熱田から帰着して野外へ戻る。移動中の行先判断は既存TravelControlを使う。道路画面も実際の世界座標を描く。道路・野外を別セーブや別時計にはしない。 |
| 4 接敵・士気・退却 | 毎秒の同時損害、士気低下、帰還先への敗走、兵数0で表示を消す。低士気だけで平時に勝手に敗走させず、被害後に判定。接敵・退却も世界時間を止めない。 |
| 5 武将判断と命令 | 自隊は現地判断。配下には既知の所在地へ物理伝令を送る。到達前は動かず、受領時に権限と服従を再判定。同時刻の矛盾命令は保留・返報。不在では受領せず失敗報告も帰路を移動する。返報を受けるまで差出人に内部結果を見せない。 |
| 6 縦断・規模・復旧 | 9分隊と36分隊、途中再指示・停止、戦闘と命令、途中保存、別プロセス復旧と続行を検査。視認外の位置・向き・兵数は最後の目撃で留める。 |

## 共通契約と保存

新ruleset `regional-integrated-validation-v1`、world `world:regional-integrated-validation-v1`。schema2へ任意のRegionモジュールを追加し、この規則では必須、旧規則では存在拒否。既存Field/Traffic/Travel/Courierモジュールと同じWorldSession・MessageFlow・GenerationSaveStoreを使う。旧Tickシミュレーターを併走させない。

地域内は同じ経過秒に、通行条件→本人の道中判断→経路位置→移動衝突→同時損害・士気退却→伝令の在所照合→共通配送→受領判断・返報→既存契約処理、の順で進む。各秒を一度だけ確定する。損害は時刻と部隊の組を一意に保存し、初期兵数・士気との差を照合する。経路は通行可否・連続性・速度・高さ由来の所要・終点を再検査する。命令IDの重複と古い画面版も検査する。

戦闘は距離4.5m・高低差3m以内で、敵兵数の1/10（最低1）と敵ごとの士気8を同時適用。被害後の士気25以下で敗走。道2m/s・草地1m/s・森0.5m/s・斜面0.4m/sに起伏の追加所要を加える。すべて検証値であり、兵種・地勢の本番バランス確定ではない。乱数を追加せず、同じ入力・秒刻み・保存から同じ結果を再現する。

近傍80mの目撃を記録し、他武将の真の結果を通常表示へ漏らさない。3Dモデルは分隊の代表であり全兵士の個別表示ではない。道路では見やすい代表拡大を使う。半径1mは試作上の分隊占有係数で、実際の100人の密集幅ではない。

## 検証証拠

`Docs/Design/RegionalIntegrationV1/verification.json` が入力・DLL・素材・TRX・実画像・動画と画像点検を結合する。再実行は `Scripts/verify_regional_integration.py`、実画像点検後に `Scripts/check_integration_binding.py`。出力と元3D素材はruntime-local／既存ローカル資産のみ。マウス操作ツールを使用せず、ゲーム内ボタン・入力信号とGodotの実GPU描画で確認する。

最終件数と画素比較はverification.jsonを正とする。HTMLは追加せず、26秒の実Godot動画を用意する。古い検証画像を新しい入力の証拠へ読み替えない。共通ソース変更により旧試作のbindingは再検証まで失効する。

## 今回の限界と次の制作

清洲の全国投影座標に置いた160m四方の合成区画であり、清洲の実際の起伏や戦国期の地形ではない。全国の主要拠点108・区間118の既存概略網は保持するが、全国の全城・山林・河川・地形ストリーミングやNPCの完成ではない。36分隊の検査を全国規模の性能保証とは呼ばない。

配下の服従は固定WillObey、敵はその場で接触に応戦する試作。複雑な戦術AI、補給、天候、騎兵、攻城、捕縛・戦死人物処理、地形遮蔽、全国への地形展開は未実装。敗走経路が確保できなければ停止する。見通しのない範囲は距離だけで判定し、森や尾根で遮蔽しない。新地域内伝令の専用再送UI・回収原本の再配送は今回の範囲外で、旧規則の再送検査を維持する。任意地点から道路へ瞬間転送せず、まず拠点へ帰還する。

次はこの共通高さ・地形契約を使い、一地域の下地を山・道・森・川・城の背景表現へ置き換える。表示だけ変えて通行可否と分離しない。その後に連続地形の複数地域化と、全国規模の負荷測定・AIを進める。

# 全国規模の地理・移動基盤 V1

## 最新の採用方針

ユーザーは測量精度を要求せず、戦国期の位置関係・道の接続・距離感がおおむね整合していればよいと明示し、推奨に従い全国規模まで進めることを依頼した。この指示を、以前の「座標付き測量図が得られるまで置換しない」という当該試作の制約より優先する。測量根拠があると主張する場合のSurveyRoadReviewは保持するが、概略のゲーム用接続に5m精度を要求しない。

新しいnational-inferred-routes-v1 / world:national-inferred-routes-v1で、推定で遊べる地理基盤を明示的に作る。既存の世界定義・保存を勝手に読み替えない。main・design/foundation・Confirmed・通常Mainは変更しない。

## 実装した全国規模

108拠点・118区間（陸106／海12）。尾張の既存7拠点に、既存の全国座標候補27地点と、概略の城館周辺・港・峠・交通拠点74地点を追加。関東・東北・中部・北陸・畿内・中国・四国・九州のほか、蝦夷地南部・淡路・対馬・奄美・琉球まで一つの接続網とした。これらは政治的な支配領域の設定ではない。北海道全域やすべての離島・城を埋めたという意味ではない。

国立歴史民俗博物館の中世海道資料、文化庁の歴史の道資料を通路・海上交流の参考にし、個々の区間は開発側の推定接続として記録。文化庁の一覧には江戸期を含むため、一覧だけで1560年の線形を確定しない。Wikidata座標は現在の代表点であり、当時の城域や所有者を確定する根拠にはしない。新設の地域座標も丸めた概略点で、測量値ではない。

陸路の距離は大円距離×1.25、海路は×1.10の概算。速度は徒歩1m/s、伝令2m/s、海上移動6m/s、海上伝令8m/sの試作値。表示の直線は概略の接続線で、実際の道の曲折を表さない。近接表示の地上速度はこの簡略表示と概算距離の比に影響され、実測速度の再現を主張しない。史料が得られた地域は、接続と距離を版管理して順次更新できる。

津軽海峡・関門・紀淡／鳴門・瀬戸内・平戸・壱岐／対馬・南島の接続はseaとして区別する。現代の大橋やトンネルを陸道として導入しない。海岸線は従来の現代概略データを位置参照に使うが、現代の道路・建物・ダム・標高は輸入しない。小さな水面や海岸との厳密衝突はまだなく、陸道と河川・小湾の細部照合は今後行う。

## Coreとゲーム画面

既存の単一世界時計、既知情報だけの経路探索、本人の移動、物理伝令と返報、位置の秘匿、世代保存を再利用。全国版の長距離移動には短距離試作の100万秒期限を流用せず、明示した長期期限を設定する。全国表示・地域表示・3D道中は別マップに切り替えず、同じ座標と状態から表示する。地域カメラは尾張固定をやめ、本人の現在地に追従する。全国表示でも陸路と海路が地面に埋もれない描画を行い、拠点名を表示する。

専用入口はScripts/Show-NationalWorld.ps1、sceneはGame/Scenes/NationalWorldTrial.tscn。初期表示は全国。行先リストから清洲以外の全拠点を選択して移動命令を発送できる。全国／地域／本人への拡大、回転、1日進行、速度切替、停止、保存復旧を操作できる。近接海上表示では人物が水面を歩く絵を出さず、簡易船マーカーで示す。随行や伝令の個別船体・乗船関係は未実装。全国の所有者や兵力を地図の公開拠点データへ混ぜない。

## 検証

Core631件合格（新21件）。全108拠点の往復経路、海路を封じると島へ陸道だけでは到達できないこと、根城・勝山館・首里・対馬・湯築・府内・江戸・月山富田への本人到達と物理返報、長期期限、陸上／海上の保存復旧と続行、未知の封鎖の秘匿、旧保存の読み替え拒否を確認。

Windows上のGodot4.5.2 .NET / .NET SDK10.0.302 / RTX4060Ti・Compatibilityで実行。実際の移動ボタンから発送し、全国・地域・道中・海上表示を確認。チェック・独立復旧・動画の3プロセス、12検査、15PNG。4段階の保存を別プロセスで復旧し、その後の続行を含む8比較で3D差分0画素。全国から地域へ拡大したカメラが本人を中央に置くことも検査する。

26秒・24fps・624フレーム・1100×720の実ゲーム動画を収録し全フレームをデコード。字幕・地図・地名・陸上と海上の表示・保存復旧場面を実画像で点検し、現行ソース・全国カタログ・基図・DLL・素材・PNG・動画と結合して記録。自己点検はユーザー採用を意味しない。動画・PNG・既存3D素材・ローカル保存はruntime-localに限定し、再配布しない。マウス操作ツールは不使用。

検証入口はScripts/verify_national_world.py、現行入力照合はScripts/check_national_binding.py。共通ソースが更新されたため、以前の試作の画像照合入口はその試作を再検証するまで失効する。過去の結果を新しい入力の検証結果に読み替えない。

## 到達した範囲と次の作業

全国規模の地理・移動基盤ができた。全国の政治・人口・経済・NPC軍団を稼働させたという意味ではない。現在の移動命令は既存Coreに合わせ清洲からの出発に限定され、到着地を次の出発点にする連続移動は未実装。次は任意拠点間の連続移動と道中変更を先に共通化し、港での乗船条件・待機／運休、その後に各地域の城と人物・勢力・生活圏を接続する。主要網から地域ごとの細部へ進み、全国の基盤を作るために測量資料待ちで停止しない。

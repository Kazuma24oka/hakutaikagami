# 全国での連続移動・出航待機 V1

本人が到着地から次の行先を選ぶ連続移動を追加。清洲→堺→淡路（洲本）→清洲の3回を同じ世界・全国108拠点118区間で検証した。主君から遠隔命令が瞬時に届く扱いにはせず、Actor=Executor=プレイヤー本人のMoveとして既存の権限・実行・効果台帳・配送・時計を共用する。出発確定まで1秒、他者への自動返報は作らない。道中の自由な取消／行先変更UIは次段階。

新ruleset national-personal-travel-v1 / world:national-personal-travel-v1。旧全国・地域の定義版と保存は保持し、新規則へ読み替えない。保管中の過去の旅は出発・到着・時系列を検査し、現在のLocationは最後の旅だけと照合する。主君は清洲のまま。

海路は到着（待機開始）→準備300秒→次の毎時境界で出航→距離／速度による到着。この準備時間と便間隔は検証係数で、当時の実在便の時刻表ではない。最短時間探索も出航待ちを含む。待機中は進行距離0・人間idle、出航後に船の簡易表示。伝令も同じ出航時刻規則を使い、途中保存で待機／移動を取り違えない。船数・定員・料金・運休・天候・港の入港許可は未実装。

信長／織田家・清洲、信玄／武田家・甲府（躑躅ヶ崎館代表点）、氏康／北条家・小田原を、自治体／県の資料で本拠との関係を確認して追加。参照URLはsource-manifest.jsonとTravelWorld.Peopleに固定する。これは当日の所在を復元したものではなく、初期配置候補。領土・家督・外交状態は設定せず、NPCは静止・汎用の試作外見。近傍80mだけ目撃表示し、遠方の生位置を全国画面へ出さない。

地理は既存の概略点・直線接続と粗い現代海岸線参照のまま。近景は平面の検証表示で、海上区間が粗い陸塗りに見えることもある。船は箱の仮表示。港の建物、当時の地形・道筋や政治的支配は復元していない。

# 百代鏡DBからの開始配置の決まり（2026-11-12 ユーザー決定）

史料の画面（百代鏡DB V1）を見たユーザーの指示。数値のうち「試作値」は Claude が置いた初期値で、遊んでから調整する。

## 1. 登場人数は支配領域の石高と金銭収入で決める
- 各勢力の登場武将の人数は、支配する郡の石高と金銭収入から決める。
- 試作値：収入を石に換算した合計 1万石あたり武将2人、最低は当主を含めて3人。銭は 1貫文＝2石で換算する。
- DBの人数が多すぎる勢力は、実在性が確かで著名な人を優先して残す（当主 → 当主の一門・直属 → 実在〇で記録の多い人 → △）。残らなかった人は世界に出さない（DBには残る）。
- 少なすぎる勢力は、オリジナルのモブ武将で埋める。
- 1560年の郡ごとの金銭収入は戦国DBにない。町・港・市の収入の決まりを経済の工程で作るまでは、金銭収入を0として石高だけで数える（そのことを画面と記録に明記する）。

## 2. 兵の上限は石高か金銭で賄える分まで
- 試作値：石に換算した収入 1万石あたり250人（軍役の目安）。銭で雇う兵も同じ換算で数え、合計を上限とする。

## 3. 武将一覧では実在性を 〇 △ × だけで示す
- 詳しい根拠は書かない。
- 〇：戦国DBで実在の確度 A〜C（ゲームと関係のない資料に時代・立場の合う人物として載る）。
- △：確度 D（暫定登録。典拠が見つかっていない）。
- ×：確度 E（架空・伝承）と、オリジナルのモブ武将。

## 4. 郡を単位として採用する
- 戦国DBの郡（1560年の支配の見積もりつき）をゲームの支配領域の単位にする。
- 郡の石高は戦国DBにまだない。当面は 慶長3年（1598年）の国の石高を、その国の郡に面積の割合で分けた推定とし、推定と明記する。郡ごとの史料の石高が入れば置き換える。

## 5. 城主不明の城は、支配地域の勢力の城とする
- その年の城主・持ち主が分からない城は、城のある郡を支配する勢力の城として扱う。決め方は「郡の支配者の城（城主不明）」と残す。

## 6. 年代に合った名前で登場させる
- 家康（1560年は松平元康）のように改名を挟む人物は、戦国DBに名乗りの変化と年を記録し、開始年に合う名前で登場させる。
- ゲームの中では、改名を出来事（改名の機能・イベント）として扱えるようにする。年の分からない改名は、順番だけを持ち、自動では起こさない。

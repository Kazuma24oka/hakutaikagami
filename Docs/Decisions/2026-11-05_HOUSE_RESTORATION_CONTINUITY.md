# 旧家の再興と権利義務の継続

- 採用日：2026-11-05（日本時間）。
- 根拠：ユーザーが「以前と同じ家としての再興を認める」A案を明示採用。正当な継承が認められれば、有効に残る旧家の権利と未払い・約束を引き継ぐ。
- 管理先：統合案§26 Z4、G-K4、BD-45・48。旧臣・従属家の判断はBD-46・50、NPCの目標と判断はBD-58へ接続する。
- 照合基準：作業ブランチ prototype/godot-foundation の 534f91b84995474f325baa82191b8e211385a5dc。
- 状態：設計採用済み。ゲーム実装の完了、工程変更、進捗の加点ではない。

## 1 採用内容

吸収・解散により活動を終えた家でも、正当な継承が成り立てば、以前と同じ家としての再興を認める。旧家に有効に残る権利だけを取り戻して、残る未払い・約束を切り離すことはできない。ただし、各契約の承継条件や第三者への有効な移転は維持する。

これは家の政治的な継続についての決定である。家名を掲げたこと、挙兵したこと、後援者を得たことを、正当な継承の成立や全員の服従と同一視しない。

| 分けるもの | 扱い |
|---|---|
| 旧家との連続性 | 過去の家とその記録を参照し、再興を後の出来事として残す。吸収・解散やその間の出来事をなかったことにしない |
| 候補者の主張と根拠 | 血縁・養子・遺言・家法・支持・占有を既存の家督案件で照合する。どれか一つだけで決着させない |
| 代表権と行為 | 正当な代表が行える範囲と、守備・会計等の有効な暫定権限を区別する。代表権未確定の候補に家全体の恒久処分権を与えない |
| 各人の認識と協力 | 面会・書状・噂などで知った範囲から、支持・留保・反対や協力を判断する。成立した事実を全員へ瞬時に知らせない |

正当性の照合は統合案S1〜S5とBD-45の既存規則を使う。全旧臣の一致、全債権者の同意、一定の支持人数、将軍の認定などを、新しい一律条件として追加しない。個別の原本や制度が要求する同意・手続きは、その範囲で満たす。争いがある間は係争と暫定管理を保持し、先着の宣言者や最大勢力を自動的な正当当主にしない。

## 2 引き継ぐ対象と戻さないもの

同じ家としての再興を、すべての権利と契約を同時に有効化する操作にしない。原本、当事者、期間、終了・承継条件、履行と清算、異議・係争を対象ごとに照合する。

| 対象 | 再興時の扱い |
|---|---|
| 家に有効に残る権利・債務・約束 | 残存分を旧家につながる対象として保持する。請求できる権利と履行すべき義務の双方を扱い、再興宣言だけで請求・支払い・返還を完了にしない |
| 成立済み契約の承継 | BD-48に従い、条項上の継続、承継への相手同意待ち、係争を区別する。同意待ちを自動消滅にも無条件の発効にも変えない |
| 未成立の提案・交渉 | 過去の案・版・返答を交渉履歴として保持するだけで、成立済みの義務や債務に数えない。必要なら権限ある当事者が交渉を続ける |
| 元当主個人の約束・債務・保証 | 家の債務へ自動的に付け替えない。本人死亡時の履行不能審査、相続財産の引受範囲、保証・担保を既存規則で個別に扱う |
| 有効に移転・清算された対象 | 吸収時などの適法な譲渡・債務引受・清算を巻き戻さない。同じ原本の債務を再興のために複製せず、別に成立している保証等はその根拠で保持する |
| 失効・終了・履行済みの対象 | 終了済みの契約や清算済みの債務を復活させない。未払い・同意待ち・係争というだけの対象を清算済みとも扱わない |
| 旧領・拠点・兵・旧臣 | 権利主張、安堵、実占有、現在の所属・主従・指揮、個々の協力を分ける。再興だけで旧領や旧臣が戻ったり、兵・米が生成されたりしない |

統治上の家法は[家法承継の決定](2026-11-05_HOUSE_LAW_SUCCESSION.md)の範囲を保つ。当主交代だけでは有効な家法が失効しないという規則を、吸収・解散で終了した条文の自動復活へ広げない。再興時も条文の有効性・対象・権限・自治留保を照合し、内容や適用を変える場合は既存の改定手続きへ進む。

有効な第三者の権利と再興側の主張が食い違う場合は、異議と既存の係争を残す。交渉、仲裁、譲渡、実力行使を同じ「権利回復」にせず、不当な実力行使が物理的に可能でも正当な取得へ読み替えない。

## 3 再興から残る約束への対応まで

以下はゲーム内の架空例であり、史実の尼子家の制度や存続状態の再現ではない。吸収・解散済みのX家について、成人候補Aの承継根拠があり、家の未払い給付と一つの権利が有効に残る一方、旧城の一つは他家へ適法に移っている開始状態を与える。誰がどの原本・出来事を知っているかは別に置く。

| 段階 | 人物の判断と実行 | 保持する状態 |
|---|---|---|
| 1 根拠を集める | Aが手元の文書と既知の相手への照会から、承継根拠と家に残る権利・約束を調べる | 未発見の遺言や未到着の返答を表示しない。失われた文書や不明な履行を都合よく補わない |
| 2 継承と支持を確かめる | 既存の家督案件を通し、旧臣・後援者は各自の証拠と利害から判断する | 正当な代表権、個人の支持、実際の占有・協力を分離。争いがあれば係争と暫定管理を続ける |
| 3 残存分を照合する | 権限あるAが権利の回復を請求し、未払いの相手と履行方法を調整する。承継同意が必要な契約は該当相手へ連絡する | 有効な残存義務は、新しい交渉を始めただけでは消えない。適法に他家へ移った城や清算済みの支出を取り戻したことにしない |
| 4 実際に立て直す | 支持者との合意、実集合・補給、拠点の確保、給付の引当・運搬・実受渡しを進める | 再興の承認と現地の回復・精算は別。本人・後援者・第三者の物資を一つの共有在庫にしない |
| 5 残件から次を選ぶ | 届いた報告と実在資源から、部分的な回復の維持、追加交渉、延期・撤退を判断する | 未回復の権利、未履行の義務、実消費と損害を保持する。活動中止だけで残る債務を消去しない |

再興が認められたことで旧家への請求が改めて届くこともあるが、請求書の到着だけで新しい債務を作らない。元の義務の成立・残高と、Aがそれを知った時点を分ける。すでに部分払いがあれば残額のみを扱い、再送や再興の再宣言で重ねて計上しない。

## 4 代表例外と確認条件

代表例外は二つに絞る。

- **候補者が競合し、根拠の知らせも遅れる**：AとBが同じ旧家の継承を主張し、後から別の誓紙が届く。家の原本・実物・債務は一つの履歴として保ち、候補ごとに複製しない。各人は受領した証拠から判断し、係争中の正当権限を超える恒久処分を認めない。
- **旧権利の一部はすでに移転・清算されている**：Aが旧城の返還や給付を求めるが、有効な移転・部分履行の記録が残っている。原本を照合して残存分を扱い、再興を理由に第三者の権利や完了済みの履行を巻き戻さない。通知の不達・遅着による誤認は、実際の移転・支払いとは別に残す。

実装時の確認例は以下のとおり。既存工程へ割り当てるもので、固定の受入170件への追加ではなく、今回の実行は未実施。

1. 同じ家としての再興から、権利の回復請求、未払い・約束の照合、実際の部分回復と履行までを、プレイヤーとNPCの双方で一巡できる。
2. 残存する家の義務、承継同意待ち、未成立案、元当主個人の債務、移転・清算済みの対象を区別し、権利だけの復帰や義務の二重計上を起こさない。
3. 代表権、本人の認識、支持、実占有を分け、上記の代表例外でも全知・自動服従・全資源の移転を起こさない。
4. 照会中・係争中・部分履行後の保存再開で、同じ原本・残高・既知情報・権限と将来の判断を再現する。旧保存は新しい再興規則へ無断で読み替えない。

## 5 記録と引継ぎ

- 政治的な継続は、旧家と再興案件・承継根拠・代表権・対象ごとの原本を結ぶことで記録する。CC-02のID再利用禁止とCC-03の関係・履歴保持を維持する。消去したIDの再利用や古い署名の書換えは行わず、具体的な保存形式はここで固定しない。
- [旧家の再興と支援の実行](../Proposals/MORI_MOTONARI_HOUSE_RESTORATION.md)の既存例に、吸収・解散後の分岐を接続する。G-K4、統合案Z4、BD-45・48を主な管理先とし、既存の家督・契約・旧臣の判断・配送を共用する。
- 本決定の根拠はユーザーのA案採用である。M40の動画本文や学術資料が、ゲーム上の同一の家としての再興を直接定めたとは扱わない。出典の確認範囲は[研究台帳](../References/MORI_MOTONARI_RESEARCH.md)に保持する。
- 比較用のB案「吸収・解散後は、旧家の名を掲げる新しい家として始める」を一律の既定値にはしない。別の家の創設全般を禁止したり、家名の利用だけで正当な再興を認めたりする決定ではない。
- 資料のみの変更。統合案の工程6d、現在工程NpcPurposeV1・固定基準v51、進捗率・見積・60枠・受入170件を変更しない。ゲームコード・main・保存形式は変更せず、Core全件・保存実動作・GUI・上記シナリオの検査は今回未実施。

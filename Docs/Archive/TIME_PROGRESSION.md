# 未確定：時間進行システム設計案

状態：検討中。以下は提案であり確定仕様ではない。

## 検討の方向
- 自動進行＋任意の一時停止を候補方式として優先検討する。
- プレイヤーが浪人・家臣・城主・大名のいずれでも、共通の時間基盤を利用する。
- 長期行動（旅・任務・内政）は継続実行可能とする案を検討する。

## 暫定パラメータ（すべて未確定）
| 項目 | 案 |
|---|---|
| 速度 | 停止・通常・高速・超高速 |
| 最小時間単位 | ゲーム内1時間 |
| 日付表示 | 年・月・日・時刻 |
| 通常速度 | 現実10秒＝ゲーム内1時間 |
| 高速 | 現実3秒＝ゲーム内1時間 |
| 超高速 | 現実1秒＝ゲーム内1時間 |
| 停止中の操作 | 命令入力可能 |
| 自動停止 | 重要イベント発生時 |

## 未決定の論点
1. 時間粒度と速度倍率：全国規模の年数経過と個人行動の両立、速度変更時のUI負荷。
2. 行動の処理：旅・交渉・内政・合戦の開始／終了、同時進行、割込み、キャンセル。
3. 自動停止：戦闘、主君命令、人物死亡、家督相続、外交などの優先度と通知設定。
4. 全国AI：非表示地域の処理間引き、決定論、セーブ／ロード時の再現性。
5. 合戦中の時計：通常時と同一時計か、戦闘専用時間か、停止条件。
6. プレイヤー不在時の長期イベント：史実再現モードとの整合性。

## 次の検討順
- まず「自動停止の対象と通知のみの対象」を分類する。
- 続いて、行動中断・同時進行と時間速度の調整を検討する。
- ユーザーが明示的に確定するまで Confirmed へ移さない。

## 確定済み原則と未確定詳細
- **確定**：共通世界時刻（F02）、因果関係・効力発生時点・依存関係を考慮（P0-A02）、権限判定の共通要素（P0-A01）、帰属の段階更新（P0-A03）、資源の数量整合（P0-A04）、決議と責任の分離（P0-A05）、権限・効力・伝達・認識・実行の接続（P0-A06）、案件別の発送時／到達時の返答基準（確定情報仕様）。
- **未確定**：期限ちょうどを原則有効とする詳細案、権限取消と代理受領の同時刻効力、競合の具体的な優先順位、同時刻徴税の配分、開城と援軍の勝敗、実装方式。

## 11項目の統合（B優先・未確定）
| 元項目 | 統合する扱い | 短い例 | 残る詳細 |
|---|---|---|---|
| 基本① 同時刻評価単位 | 同時刻の候補を集め因果依存・効力時点を評価 | 開城と援軍到着を同じ評価対象にする | 候補の収集単位・循環依存 |
| 基本② 権限取消・代理受領 | 取消効力・受領・相手認識・追認を分離 | 取消を知らない使者の受領を自動無効にしない | 善意保護・追認遡及 |
| 基本③ 返答・期限切れ | 案件別の発送／到達基準と境界を区別 | 15時期限の返書が15時到達 | 期限境界・失効 |
| 基本④ 開城・援軍 | 開城合意・占有移転・援軍の介入を分離 | 城門引渡し前に援軍が到着 | 介入条件・開城効力 |
| 基本⑤ 二重徴税・在庫 | 引当・出庫・消費を別取引で扱う | 米100俵への80俵ずつの請求 | 配分優先・債務 |
| 基本⑥ 軍令・組織決議・通知 | 指揮権・決議・到達・認識・忠誠・実行を分離 | 撤退決議が前線に未到達 | 矛盾軍令・責任 |
| 境界① 期限ちょうど | 案件別基準を確認し、ちょうどは原則有効とする案 | 15時までの案件で15時ちょうど到達 | 時刻精度・例外条件 |
| 境界② 取消・受領の境界 | 基本②の同時刻効力・認識・追認を詳しく扱う | 取消と受領が15時に重なる | 先後・第三者保護 |
| 境界③ 処理順序 | 基本①の因果依存を解決してから状態更新 | 援軍と落城の前提を照合 | 循環・確定順・再実行 |
| 境界④ 二重徴税の配分 | 基本⑤の引当・残量・取引履歴で配分を判断 | 実出庫合計は100俵以内 | どちらに何俵配るか |
| 境界⑤ 開城・援軍の境界 | 基本④の合意・占有・降伏・介入を詳しく扱う | 開城合意後、城門引渡し前に救援 | 占有移転の効力 |

## 重複と責任分界
- **基本①＋境界③**：共通イベント処理。境界③が依存解決後の競合更新を詳細化する。
- **基本②＋境界②**：権限取消・代理受領。境界②が同時刻の効力競合を詳細化する。
- **基本③＋境界①**：期限基準は確定情報仕様を優先し、期限ちょうど原則有効は追加の未確定案。
- **基本④＋境界⑤**：開城・占有・援軍。城の帰属は地理／合戦の状態遷移へ接続。
- **基本⑤＋境界④**：取引一意性・数量整合は共通会計、具体的配分は徴税・現地支配の裁定。
- **基本⑥**：軍令・組織決議・通知。確定情報仕様の本人認識と、軍制の指揮・服従を接続。

## 矛盾・曖昧さ
1. **期限ちょうど**：「原則有効」はユーザー選択済みBの**未確定詳細**。確定情報仕様の発送／到達基準と矛盾しないが、時刻精度・特別失効条件を決める必要がある。
2. **同時刻の処理**：因果関係を考慮することは確定。イベント登録順のみで判定しない。ただし同じ効力時点・依存関係なしの競合をどう裁定するかは未解決。
3. **権限取消と受領**：取消が有効か、相手が知らなかったか、事後追認するかは別。相手方保護と法的効力の結論は未解決。
4. **徴税**：同一現物の二重計上は不可。ただし有効な請求の優先権・按分・強制徴収の結果は未解決。
5. **開城と援軍**：合意成立・城門引渡し・占有移転・援軍交戦は別。必ず援軍優先／必ず落城優先とは決めない。
6. **通知と世界停止**：同時刻イベントの通知は確定情報仕様に従い集約する。停止は世界全体に適用され、個別行動の中断と区別する。

**判定**：11項目のB案と既存の確定基本原則に直接的な矛盾は見当たらない。基本6項目と境界5項目の重複は上記の6領域に統合可能。ただし具体的な優先順位・イベント再実行・セーブ再現性は未解決。

## 依存関係と検討順
1. 共通時刻・効力時点・期限精度・イベントID。
2. 同時刻の候補収集・因果依存・循環解決・競合更新。
3. 権限取消／受領、期限、在庫引当、開城／援軍、軍令／通知の個別裁定。
4. 通知集約、セーブ再現性、テストケースとバランス。

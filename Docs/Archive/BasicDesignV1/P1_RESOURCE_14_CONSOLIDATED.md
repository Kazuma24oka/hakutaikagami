## 統合元と保存先
- [費用・資源確定境界7項目](../P1_RESOURCE_COMMIT_BOUNDARIES_OPTIONS.md)：見積・引当・消費・返還・債務・競合・補償。例：普請木材100を引き当て40消費。
- [資源確定時点・同時刻競合7項目](../P1_RESOURCE_TIMING_CONFLICT_OPTIONS.md)：確定時点・部分実行・因果裁定・再評価・債務承継・損失・復旧。例：米100俵に兵糧70と交易60が競合。

## 確定済み原則（Confirmedを重複更新しない）
- **F01/P0-A01**：行為者・対象・管轄・権限根拠・有効期間を審査。例：城主が他家の米を無断担保にしない。
- **F02/P0-A02**：共通時刻、因果・効力時点を評価し制度別に競合裁定。例：同時刻の徴税と兵糧調達を入力順だけで決めない。
- **F03/P0-A04**：権利・実徴収・所有・保管・引当・債務・数量整合を分離。例：100俵を130俵引き当てない。
- **P0-A03/A05/A06**：家督・落城の帰属、責任、条約・軍令の効力と接続。例：当主死亡でも保証債務を自動消滅させない。

## 重複統合した共通処理
| 領域 | B優先の統合方針 | 具体例 | 保留する詳細 |
|---|---|---|---|
| 見積・承認 | 見積と支出権限・承認を分離 | 普請木材100を見積 | 承認権限・予算超過 |
| 引当 | 所有・保管・利用可能量・引当量を別管理 | 米100のうち60を確保 | 輸送中の扱い |
| 消費・成果 | 実消費と進捗・成果を別記録 | 木材40消費でも普請40%を保証しない | 進捗・損失換算 |
| 中断・返還 | 未使用引当を解除、使用済み・損失を別判定 | 木材100のうち40消費、残り60解除 | 返還不能・責任 |
| 不足・部分実行 | 最小成立量・分割可否で待機／縮小／拒否 | 徴税100要求で60のみ徴収 | 最小数量・期限 |
| 同時刻競合 | 因果・効力時点の後、制度別裁定 | 兵糧70と交易60が米100を要求 | 軍事優先の条件 |
| 競合後再評価 | 在庫・期限・権限を再評価 | 交易60を30へ縮小できるか | 再試行・通知 |
| 債務・担保 | 債務者・保証人・担保権・所有・保管を分離 | 大名死亡後の保証を再判定 | 担保処分・承継 |
| 補償・保存 | 確定済み効果は補償として追跡、引当等を整合保存 | ロード後も徴税を二重加算しない | 補償失敗・保存境界 |

## P0会計基盤とP1コマンド層の責任分界
| P0（整合性と制度の共通機構） | P1（操作と案件） | 例 |
|---|---|---|
| 資源残高・引当の原子的な整合 | 見積提示・承認申請・引当要求 | 米100に合計130の要求を拒否・裁定 |
| 同時刻因果・競合の検出 | コマンドの目的・緊急性・制度別条件を提示 | 敵襲中の兵糧と交易を比較 |
| 実消費・確定・補償の適用記録 | 進捗・中断・返還要求と通知 | 普請停止後に未使用60を解除 |
| 債務・所有・担保の帰属整合 | 借財・返済・担保設定の案件 | 家督変更後の債務を別評価 |
| セーブ復旧・重複適用防止 | 操作状態・結果報告・認識の復元 | ロード後も在庫一致 |

## 矛盾・依存関係の判定
- **直接的な基本原則矛盾なし**。ただし「引当＝消費」「返還＝消費取消」「債務者＝保証人」「同時刻＝先着順」を同一視しない。
- **依存順**：権限・世界時刻→見積・承認→在庫審査・引当→競合裁定→実消費・成果→中断・返還・債務→補償・セーブ復旧。
- **P0残課題**：同時刻裁定の制度別規則、資源引当の確定境界、補償失敗、保存単位。例：同時刻に米の要求が重なる。
- **P1残課題**：最小成立量、部分実行可否、期限、再評価、通知、担保・輸送のコマンド条件。例：兵糧30しか確保できない場合に出陣可能か。
- **P2候補**：市場価格やAI判断係数の詳細調整。例：商人ごとの値引き率。
- **確定判断**：B優先14項目は既存Confirmedの分離・整合原則を具体化するもの。新規独立基本原則なし、Confirmed追加なし。具体的な数値・例外は未確定。
- **完了判定**：設計の統合は完了。資源確定境界の詳細仕様および実装・試験は未完了。

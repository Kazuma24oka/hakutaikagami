## 2. 重複・矛盾・責任分界
- **権限**：F01とP0-A01/A06、外交・軍制の権限記述は重複する。共通基盤は権限の要素・効力・通知を扱い、制度固有の有効条件は外交・軍制に委ねる。
- **帰属**：F03/P0-A03/S01〜S05と帰属18項目は基本→具体化の関係。家督・安堵・占有・実効支配・忠誠を一括変更しない。
- **時刻／情報**：F02/P0-A02と情報仕様・同時刻11項目は共通時刻と書状到達・個人認識の区別で整合。登録順のみで勝敗を決めない。
- **会計／復旧**：P0-A04とP0-R01〜R04は数量整合とイベント重複防止を別層で扱う。補償の再試行で現物が増えない。
- **外交／軍制／NPC**：条約・軍令の効力と通知到達・本人認識を分離。誤情報で行動したNPCがいても客観事実は変更しない。
- **直接的な基本原則の矛盾は確認されない**。ただし**具体的な同時刻境界・承継・軍令競合・補償失敗**の最終結果は未決定であり、実装可能と断定しない。
- **資料管理上の注意**：READMEの古い節や比較履歴の「未選択」「未確定」表記は作成当時の状態を示す場合がある。後日の選択・確定記録とConfirmedを優先する。

## 4. 優先度別の残課題
### P0：実装前に必須
1. **イベント処理契約**：安定ID、適用記録、状態遷移、循環解除、競合裁定インターフェース。例：同じ徴税要求の再送を二重実行しない。
2. **同時刻の効力境界**：権限取消と代理受領、期限ちょうど、開城と援軍。例：返答期限ちょうどの書状を有効とするか。
3. **帰属・会計の確定境界**：城内占有・所領安堵・徴税引当・債務承継。例：城を占領しても村の年貢は自動移転しない。
4. **失敗復旧・セーブ検証**：補償の一意性、補償失敗、乱数・キュー保存、異常終了テスト。例：兵糧輸送中の強制終了後も米が二重計上されない。

### P1：並行検討可能
1. **政治・外交・在地社会**：家臣の安堵交渉、相続争い、条約再交渉、人質返還、国人の離反。例：安堵拒否で国人が交渉を続ける。
2. **軍制・合戦**：城内分裂、降伏・捕縛・援軍介入、軍令衝突。例：城主独立後も門番が旧主家に従う。
3. **NPC判断**：性格・忠誠・噂・誤認による個別判断。例：偽報で出陣を見送る。
4. **内政・経済**：政策、物流、徴税交渉、災害対応。例：凶作時に年貢減免を交渉する。

### P2：後続の調整
1. 忠誠・士気・徴税・補給の数値バランスと評価式。
2. 情報精度表示、履歴・デバッグUI、パフォーマンス・セーブ容量。
3. 時代別慣行・史実差・資料整備。

## 5. 依存関係と推奨工程
**共通時刻・権限・情報 → イベントの一意性・状態管理 → 帰属・会計の競合裁定 → 外交・軍制・NPCの具体的行動 → セーブ・異常復旧の検証 → P1ゲーム性の調整**。

推奨：P0の未決定事項は**実装前に必要な判定・状態遷移テスト**に集約し、P1の操作・制度設計は並行して進める。基本原則の再確認を繰り返さない。

## 6. 自律確定の判断
既存Confirmedにある分離・段階更新・因果評価・数量整合・重複適用防止・保存継続整合性の原則で必要な基本方針は既に規定されている。**今回は新たな独立基本原則を確定しない**。本書はレビュー・完了判定であり、詳細・例外はProposalsに残す。

> 後続決定（2026-10-19）：[基本設計V1](../../Design/BASIC_DESIGN_V1.md)／[委任採用・整合確認](../../Decisions/2026-10-19_BASIC_DESIGN_V1.md)で対応する基本判断BD-01〜60と共通境界C01〜10を解消。以下の旧未確定表記は当時の履歴で、現行の方針はV1を優先する。詳細係数・API・個別データ・実装受入は別に引き継ぐ。既存Confirmed原則は維持。


**状態：未確定（Proposals）／2026-10-17。** 基本9項目と詳細5項目のユーザー選択済みB案を統合した優先参照先。数値・実装・例外は未確定。F01〜F08および情報システムの確定仕様を変更しない。

## 1. 人物モデルの分離
- **基礎能力／技能／経験／状況補正／性格傾向／忠誠・信頼／個人間関係／所属・役職／他者からの評判・推定評価／本人の情報認識**を別概念として扱う。
- 能力と勲功、正式な権限と人望、社会的な関係種別と感情、客観的な実力と他者の推定評価を混同しない。
- 史実・準史実・仮想モードの人物初期値・変化制約は別途検討。

## 2. 能力・技能・経験・成長
- 行動結果を基礎能力・技能・経験・状況から評価する案。軍事・内政・外交などの行動・勲功と接続する。
- 実務・戦闘・修行・教育・加齢などによる成長・衰えを認める。基礎能力、習得技能、経験蓄積は独立に変化し得る。
- **保留**：能力・技能の名称と個数、値域、加算／乗算・成功率の計算、経験の効果、成長上限、加齢・傷病・個人差、修行の時間・費用。

## 3. 性格・価値観・忠誠
- 野心・義理・慎重さ・勇敢さ・情愛等の複数の性格傾向を持つ案。性格は比較的安定する一方、忠誠・信頼は待遇・恩賞・経験・事件によって変化し得る。
- 特定の主君・家・組織への忠誠と、個人の義理・主君への好意・敬意・恐れを分離する。
- 命令の正式な有効性と本人の服従意思を分離。忠誠が高くても常に服従するとは限らない。
- **保留**：性格軸・変化条件、忠誠の対象・複数所属、命令拒否・離反への影響、処罰と責任。

## 4. 個人間の関係と派閥
- 好意・信頼・敬意・恐れ・敵意を分離し、A→BとB→Aの感情を別々に扱う案。
- 親族・婚姻・主従・友人・仇敵・師弟等の関係種別は、感情と別。親族だから好意的とは限らない。
- 縁故・利害・忠誠・事件などを基に、家臣団の派閥・国人衆の連合・朝廷や将軍家への取次関係を形成・変化・分裂させる。
- 人脈の影響力と正式な交渉権・委任権限は別。派閥所属と主家所属・役職も別。
- **保留**：関係の保存粒度、派閥結成・分裂・再統合、秘密関係、複数感情の重み、代表者と組織決議。

## 5. 認識・評判・関係変化
- 恩賞・裏切り・救援・婚姻・人質・噂などを人物が実際に認識した際、その情報の解釈に応じて関係が変化し得る。事件発生だけで全員の感情を自動更新しない。
- **実際の能力・技能**と、他者が報告・評判・実績・観察から推定した評価を分離。誤認・誇張・過小評価を認める。
- プレイヤーへの他者の能力表示は情報の確度・鮮度・出典・観察経験に応じて変える方向。未確認の推定値を客観的な確定値として扱わない。
- **保留**：本人自身の能力表示、数値／幅／段階表示、誤報訂正・和解、人物調査、記憶の重み・情報の鮮度。

## 6. NPCの個性と行動
- NPCは能力・性格・関係・立場・利害と自身が認識した情報を用い、仕官・昇進要求・独立・外交・同盟・婚姻・主従判断などを個別に選択する。
- 未認識の世界の真実を直接利用しない。ただし既知情報からの推測は認める。
- **保留**：評価式、遠方AIの詳細／簡略切替、記憶・関係保存負荷、史実モード別の制約とセーブ再現性。

## 7. 重複・矛盾の整理
| 論点 | 統合した解釈 | 判定 |
|---|---|---|
| 基礎能力・技能・経験 | 別要素として行動結果へ寄与 | 整合、計算式未定 |
| 性格と忠誠 | 性格は比較的安定、対象別の忠誠・信頼は変化 | 整合、例外未定 |
| 忠誠と命令の有効性 | 感情・服従意思と正式権限を分離 | 整合 |
| 関係種別と感情 | 親族・主従等の関係と好悪・信頼等を分離 | 整合 |
| A→BとB→A | 非対称の人物別感情として管理 | 整合、保存粒度未定 |
| 人脈・派閥と正式権限 | 縁故の影響力と役職・委任・所属を分離 | 整合 |
| 事件発生と感情変化 | 本人が認識した情報と解釈に応じて変化 | 整合 |
| 実際の能力と評判 | 実値と人物別推定評価を分離 | 整合、表示未定 |
| NPCの性格と認識 | 性格・立場を反映しつつ全知判断を避ける | 整合 |

**結論**：選択済みB案と確定済みF01〜F08・情報システムに直接的な基本矛盾は見当たらない。能力・技能の評価式、忠誠対象、関係の保存粒度、人物能力表示の詳細は未決定であり、解決済みとは扱わない。

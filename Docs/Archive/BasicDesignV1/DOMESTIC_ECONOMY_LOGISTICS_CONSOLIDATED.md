# 内政・経済・兵站：統合設計案

## 1. 主体・権限と内政
- 大名・城主・奉行・国人領主・家臣が役職・委任・自治権に応じて内政を実施する案。
- 政策の決裁権、実務担当、徴税・収益権、資源の処分権、現地の実効支配を分離する。
- 正式権限があっても、現地支配・在地勢力の協力・軍事力等によって履行可否が変わる。実効支配のみで正式な権利が自動成立するわけではない。
- **保留**：越権・委任・追認、国人自治との境界、複数権限者の競合、徴税拒否への対応。

## 2. 生産・農業・人口・徴発
- 耕地・水利・農具・労働力・地形・季節・天候・災害・治安などから農業生産・収穫・備蓄を判断する案。
- 人口・労働・軍役・徴発・帰還・逃散・移住を連動させる。徴発による兵力確保と労働力減少は別に計算し、農業への影響は季節・期間・人口移動等で変わる。
- **保留**：人口と耕地の集計粒度、作期・作物・兵農関係の年代差、帰還・損耗・凶作の計算。

## 3. 商業・市場・流通
- 市場・商人・需要供給・流通路・通行権・治安・政策に応じて交易・物価・税収が変動する案。
- 商品の移動と売買、税収・関所収入、権益の帰属を区別。市場の設置だけで固定収益を無条件に生成しない。
- **保留**：商品分類、価格形成、座・商人組織・関所・港の権益、交易契約と独占。

## 4. 資源・在庫・徴税・俸禄・債務
- **所有者／保管場所／数量／取引履歴／債務**を分離し、所有権・処分権・保管責任・現物の所在・実際の消費を混同しない。
- **生産→徴税請求→実徴収→配分→支払→未納・債務**を別段階として追跡。正式な領有権・知行収益権・現地の実効支配と実際の徴収は別。
- 同一の生産物・物資を二重に生成・計上しない。係争地の二重請求と実際の複数回徴収は区別し、現物残量と収益・債務を整合させる。
- **保留**：資源の計量単位、取引ID、在庫引当・入出庫、輸送中の所有権・在庫、現物／銭換算、債務承継、二重徴税の優先関係。

## 5. 治安・民心・在地社会
- 年貢・飢饉・戦乱・徴発・救済・国人衆・寺社・村落共同体の利害を反映し、反発・逃散・一揆・交渉・鎮圧等に分岐する案。
- 不満と武装蜂起、在地組織の決議と構成員の参加・服従を同一視しない。短期的な鎮静化と長期の信頼・反発も分離する。
- **保留**：地域別・組織別の不満、指導者、宗教的背景、鎮圧・救済の評価。

## 6. 城・施設・土木・開発
- 城・館・港・市場・街道・灌漑・倉庫等の設備・規模・主副機能を区別し、労働・資材・時間・維持費を要する開発・修復・衰退を扱う案。
- 拠点の機能と城主職・領有権・実効支配は別。
- **保留**：施設種別・段階・工期・資材・維持費、年代差、開発の中断・引継ぎ。

## 7. 軍需物資・輸送・補給
- 兵糧・飼料・武器・弾薬などを用途・保管場所・在庫・消費・軍勢別の補給状態で区別する案。
- 道路・峠・河川・海路、季節・治安・輸送能力・敵の妨害・通行権を考慮し、**出発／輸送中／到着／損失**を分離する。勢力内の瞬間的な物資共有はしない。
- 補給線の遮断は即時壊滅を意味せず、軍勢の備蓄・代替路・現地調達・護衛・補給再開によって結果が変わる。
- **保留**：輸送中の資源の所在・引当、経路探索、補給線の遮断判定、消費率、腐敗・損耗、護衛・略奪。

## 8. 野戦・攻城・籠城と世界時刻
- 兵糧・弾薬・疲労・士気・補給遮断を野戦・攻城・籠城で状況に応じて反映する案。
- 戦闘内部の処理と共通世界時刻、全国の生産・輸送・期限を同期する。世界全体の一時停止と個別行動中断は区別する。
- **保留**：消費タイミング、複数合戦、包囲期間、補給突破・救援、士気と撤退の補正。

## 9. 災害・凶作・経済危機と救済
- 旱魃・洪水・疫病・凶作・物価高騰等の影響を地域・季節・備蓄・流通・政策から判断する案。
- 災害の発生、実際の被害、報告・認識、救済命令、物資の移動・到着、救済の実効、住民の反応を分離する。
- 備蓄・救済・流通・徴税調整・在地勢力の協力によって被害と反発が変化し得る。救済を決定しただけで被害が瞬時に消えない。
- **保留**：災害発生率、救済資源の配分、免税と債務・俸禄、史実イベント、逃散・一揆への波及。

## 10. NPCの判断
- NPCは能力・性格・利害・主従・人間関係・財政・在地勢力の対応・本人が認識した情報に基づいて政策・徴税・救済・補給を選ぶ。
- 遠方AIの簡略処理でも全知判断・瞬間輸送・資源の二重計上を許さない。
- **保留**：評価式、AI処理粒度、史実モード差、認識の更新とセーブ再現性。

## 11. 重複・矛盾の整理
| 論点 | 統合解釈 | 判定 |
|---|---|---|
| 正式権限と実効支配 | 政策の正当性と現地での実行可能性を分離 | 整合、競合条件未定 |
| 知行・年貢・俸禄 | 収益権・請求・実徴収・支払・債務を分離 | 整合、会計方式未定 |
| 資源所有と保管 | 所有者・処分権・所在・保管責任・数量を分離 | 整合 |
| 係争地の二重徴税 | 二重請求は許容、資源の二重生成は禁止 | 整合、実徴収順序未定 |
| 人口と徴発 | 労働力減少と兵力確保を季節・期間で評価 | 整合、粒度未定 |
| 一揆と治安 | 不満・組織決議・参加・武装蜂起を分離 | 整合 |
| 拠点と施設・権利 | 施設機能と所有・城主職・実効支配を分離 | 整合 |
| 補給路遮断と補給不能 | 経路・在庫・代替路・到着・消費を別判定 | 整合、経路規則未定 |
| 災害と救済 | 被害・情報・命令・物資到着・実効を分離 | 整合 |
| 世界時刻と合戦兵站 | 世界時刻を正本とし戦闘内部処理と同期 | 整合、同期粒度未定 |

**結論**：選択済みB案と既存の確定基本方針に直接的な矛盾は見当たらない。資源の会計一意性、同時刻入出庫、徴税権競合、合戦中の消費、救済の実効時点は未解決であり、解決済みと扱わない。

# P0共通基盤：統合設計案

**状態：未確定（Proposals）／2026-10-17。** P0の基本・詳細・例外処理で選択されたB案を統合。新規確定ではない。詳細な処理順序、データ型、数値、例外の解決条件は未決定。

## 1. 共通の不変条件
- プレイヤー主体は武将個人。国人領主・国人衆所属武将も操作対象となり得る。寺社・農民共同体はNPC主体。
- 世界の客観的な事実、正式な権利・効力、情報の配送、組織の情報保有、個人の認識、実際の行動・支配・収益を分離する。
- 確定済みの情報認識3階層（勢力／家臣団／個人）を維持し、社会組織の種類と混同しない。
- 各事件の効力発生時点と、当事者がそれを知った時点を区別する。
- 例外が起きても情報や資源を無条件に複製せず、世界時刻・因果関係・セーブ再現性を維持する方向で検討する。

## 2. P0-1 主体・所属・権限
- 個人・組織・役職・所属関係・委任・命令・権限を共通基盤として分離し、国人衆・寺社・村落・朝廷・幕府等に固有規則を設ける。
- 多重所属・役職兼任、直属主君と軍事指揮系統、代理受領・開封・回答の権限を別々に扱う。
- **命令の有効性**と**実行優先度**は別。管轄・委任範囲・緊急性・期限で優先度を評価しても、越権行為を自動的に有効化しない。
- 権限取消と代理受領が同時刻なら、取消の効力発生、受領時点、相手の認識・善意、事後追認・紛争を区別する。厳密な同時刻判定は未決定。
- 命令衝突時の確認・保留・拒否、責任・処罰、再委任、中央権威との管轄競合は未決定の詳細として残す。

## 3. P0-2 世界時刻・イベント処理
- 単一の世界時刻を正本とし、時刻付きイベントの因果関係・効力発生時点・優先度を考慮する。
- 通常進行中は合戦・全国AI・書状配送・期限も進行。ゲーム全体の手動／自動一時停止ではすべての時計を止める。個別任務の中断では世界時刻は進む。
- 返答発送・到達・期限切れは案件別の基準に従い、期限遵守・返答有効性・契約成立・本人認識を区別する。
- 同時刻の権限取消／受領、返答到達／期限切れ、落城／安堵は、単純な登録順やランダム順で処理しない案。
- **保留**：同時刻ちょうどの期限境界、同一時刻内の厳密な優先順位、複数合戦の同期、乱数・イベントID・二重適用防止・セーブ再現性の具体設計。

## 4. P0-3 地理・拠点・権利・会計
- 地理区分・所領・拠点・領有権の主張・知行収益権・実効支配・徴税権・実徴収・俸禄債務を別に管理する。
- 生産→徴税請求→実徴収→収益配分→支払→未納・債務を区別し、取引履歴で追跡する方向。
- 係争地で複数勢力が同時に徴税を試みても、同じ資源を二重に生産・計上しない。請求と実際の徴収、資源残量、債務は別。
- **保留**：土地・取引の粒度、同時徴税の先後、現物と銭の換算、徴収失敗・過徴収・債務相殺・主家交代時の承継、係争地の収益配分。

## 5. P0-4 家督・安堵・離反・落城の状態遷移
- 家督継承・正式安堵・家臣所属・軍勢忠誠・城の占有・所領の実効支配・権利主張を段階的に更新する。
- 複数相続人・二重安堵では、正式権利・家臣の支持・現地支配・交渉を別々に判断。暫定管理、異議、抵抗、離反、内応、合戦等の分岐を認める。
- 客観的な帰属変更と遠方関係者の情報認識・追随は別。独立宣言や落城だけで全員・全領地を一括移転しない。
- **保留**：複数候補の優先、二重安堵の裁定権限、城主と守備兵の対立、不可逆な結果と失敗時の扱い、状態遷移の厳密な順序。

## 6. P0-5 組織決議・通知・認識・責任
- 組織の決議成立・効力発生、通知の発送・到達、本人の認識、実際の実行・不履行、責任・処罰を分離する。
- 決議成立や正式代理人の受領だけで構成員全員に情報を自動共有しない。本人の認識は実際の受領・閲覧・目撃等に従う。
- 通知されなかった構成員の責任は、通知義務・本人認識・立場・故意／過失・実害・監督責任から判断する方向。無条件の免責／処罰にはしない。
- 重要書状の未開封本文は秘匿、通常書状の本人受領時自動認識、偽書、記憶保持、権限失効、事後追認などのConfirmed方針を維持。
- **保留**：決議の拘束力、通知義務の主体、認識・不知の立証、異議・不服従、複数代理、報告漏れと処罰。

## 7. 重複・矛盾の整理
| 重複する論点 | 統合解釈 | 判定 |
|---|---|---|
| 役職・委任・命令と情報アクセス | 権限・有効性・優先度・認識を分離 | 整合 |
| 同時刻の取消と代理受領 | 効力発生と実受領、相手の認識を分離。先後規則は保留 | 要詳細設計 |
| 同時刻の返答と期限 | 案件別基準を維持。期限境界は保留 | 要詳細設計 |
| 徴税権・徴収・収益・債務 | 権利と実績を分離し二重計上を防ぐ | 整合、取引粒度未定 |
| 家督・安堵・落城と実効支配 | 権利と支配、支持・忠誠を段階更新 | 整合、遷移条件未定 |
| 組織決議と構成員認識 | 決議の効力と通知・認識・実行・責任を分離 | 整合、責任条件未定 |
| 合戦中の全国進行と一時停止 | 通常は進行、世界停止時は全国停止 | 整合 |
| 情報認識の3階層と組織種別 | 情報階層と組織分類は別の軸 | 整合 |

**結論**：選択済みB案と既存の確定方針に直接的な基本矛盾は見当たらない。ただし厳密な同時刻処理、権限衝突、会計の一意性、帰属遷移、責任判定は未解決。解決済みと表記しない。

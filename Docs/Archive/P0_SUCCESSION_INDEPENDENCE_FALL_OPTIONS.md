# 家督相続・独立・落城：帰属処理のABC比較（6項目）

**状態：未確定（Proposals）／2026-10-17。** 6項目ともABC未選択。Bは推奨候補であり、正式な確定ではない。家督・権利・占有・実効支配・忠誠を段階的に更新する既存Confirmedを前提に、個別の承継・帰属条件を比較する。

## 1. 家督相続と家臣の所属
- **A**：新当主へ家臣が自動的に全員移籍。例：大名が死ぬと反対派も即座に新当主へ忠誠を誓う。
- **B（推奨）**：家督の正統性・安堵・直属主君・本人の認識・利害で家臣ごとに継続／保留／離反を判断。例：大名の死後、重臣Aは嫡男に従い国人Bは安堵を要求する。
- **C**：家臣が全員独立する。例：当主死亡と同時に家臣団が消滅する。
- **保留**：相続候補の優先・暫定命令・未成年後継・二重家督。

## 2. 独立宣言と城・所領の帰属
- **A**：独立した武将の役職下の城・領地を全て自動移転。例：城主が独立すると周辺の全村落が独立勢力になる。
- **B（推奨）**：独立宣言・城内占有・所領権利・実効支配・在地勢力の服従を個別判定。例：城主が独立しても周辺の国人や村は旧主君に従い続ける場合がある。
- **C**：独立しても城・所領は絶対に変化しない。例：城を実際に押さえても帰属状態は変わらない。
- **保留**：宣言効力・城内分裂・安堵・地域別の服従。

## 3. 落城・開城と守備兵・軍勢
- **A**：落城した瞬間に全守備兵が勝者へ移籍。例：降伏を拒否した兵も敵軍へ自動加入。
- **B（推奨）**：城内占有・降伏条件・指揮権・守備兵の忠誠・捕縛／退去／再編を段階更新。例：城門が開いても一部の守備兵は退去し、別の部隊は抵抗を続ける。
- **C**：落城後も全守備兵が旧勢力のまま城内に留まる。例：占領後も全軍が無条件に守備を続ける。
- **保留**：開城成立時点・援軍介入・捕虜処遇・部隊再編。

## 4. 条約・人質・保証の承継
- **A**：家督交代で全条約が自動継続。例：個人的な援助約束も新当主へ無条件継承。
- **B（推奨）**：条約当事者・条項・保証・人質・相手方同意・効力時点から継続／再交渉／失効を判断。例：家同士の不可侵は継続しても旧当主個人への援助は再交渉になる。
- **C**：家督交代で全条約が自動失効。例：大名死亡の瞬間に停戦も人質返還義務も消える。
- **保留**：承継同意・密約・越権追認・人質の返還期限。

## 5. 俸禄・債務・備蓄の承継
- **A**：新当主が全ての財産と債務を一括取得。例：国人の個人借金まで主家の債務になる。
- **B（推奨）**：債務の債務者・保証人・担保・契約当事者と、資源の所有・保管・実占有を区別して承継。例：城が落ちても城内の米の保管者が変わるだけで所有権まで自動移転しない。
- **C**：主君交代で全債務を消滅させる。例：未払俸禄が当主死亡で必ず帳消しになる。
- **保留**：個人／家の債務境界・略奪・徴税権・担保・不足分。

## 6. 複数相続人・二重安堵と家中分裂
- **A**：最年長者と最初の安堵を常に優先。例：次男を支持する家臣や現地の占有は無視する。
- **B（推奨）**：家督の主張・安堵文書・家臣支持・実効支配・朝廷／幕府の権威・情報認識を別に評価。例：嫡男は正式な後継候補でも次男が城を占有して家臣団が分裂する。
- **C**：軍事力が最大の者へ全権利を自動移転。例：兵が多い次男が即座に全所領の正式権利を取得する。
- **保留**：継承優先順位・裁定機関・偽書・停戦と内戦。

## 選択後の整合性確認
- **F01/F03／P0-A03**：家督・直属主君・所領権利・占有・実効支配・忠誠の分離と段階更新を維持。①②③⑥はこの確定原則の具体化。
- **P0-A01/A06／情報確定仕様**：外交条約・軍令の権限、効力、通知、認識、実行を分離。④は家督交代時の条約承継の詳細であり、自動承継・自動失効は採用しない。
- **F03／P0-A04／内政・兵站統合案**：債務・現物・所有者・保管者を分離。⑤で城の占有移転と財産の権利移転を同一視しない。
- **同時刻イベント統合案**：戦死・独立・落城・援軍が重なる場合は因果関係・効力時点を考慮し、イベント登録順だけで帰属を決めない。
- **武将・地理・外交・合戦の現行統合案**：各領域の既存B優先方針と直接的な基本矛盾なし。

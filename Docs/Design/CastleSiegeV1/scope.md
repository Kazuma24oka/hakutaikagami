# 攻城と開城・攻囲側の補給と水路

1. 現地の指揮下の実部隊で攻囲を開始し、外堀・門・二の丸・本丸を共通時計と区画防備に従って順に攻める
2. 攻め手・守り手の兵糧の実消費と、救援・補給の実到着を区別し、遠方の在庫を表示しない
3. 水路は実在の軍船の配置と維持で封鎖し、水路経由の実納入と封鎖中の待機・解除を区別する
4. 開城の条件と現地の同意・実引渡しを分け、支配・私財・家臣・生命を一括移転しない
5. 通常画面・兵糧と重複・救援競合・途中保存復旧・旧保存を代表例で検証する

第14節5f。C5/C6、Z1/Z2、補給遮断の補足に沿う。地形と築堤による水攻め・内応による開門は関連する工作・普請の入力で判断し、成立条件の未実装を成功扱いしない。

検査：隣城へ実移動後の攻囲、区画違い・無権限の拒否、米の一回消費、軍船未配置の封鎖拒否、実納入、合意と実占有の区別、途中の実保存・旧保存・通常画面の内部操作。

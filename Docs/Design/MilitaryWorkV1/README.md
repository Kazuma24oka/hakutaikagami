# 仕事から軍務の判断へ

## 完成条件
1. 仕事画面から軍務の申出・条件への同意・兵/兵糧の現地引受・返納・返報・指揮返還へ入れる。部隊の配置などは既存の軍務地図操作へ接続する。
2. 既存Coreの選択可否と入力を再利用し、未開封通知や遠隔真値から許可を作らない。相手の台詞は開封済み軍務通知だけから表示する。大名本人の内部判断を対話相手へ偽装しない。
3. 選択後の本人の台詞は続けるまで未確定。閉じる/ロードでは取消、同一世代で実行可能かを再確認する。軍務の所有と私財を混ぜない。
4. 通常/小画面で実Godotと別プロセス保存復旧を確認する。旧仕事一巡と既存野外軍務も回帰検査する。Core/Tests/入力/DLL/TRX完全一致の場合だけ前工程2183件を再利用する。
5. 実画像と短い実動作録画を確認し、検証入力と出力を固定して同枝commit/pushする。保護枝/既存素材/保存/マウス設定は触らない。

軍務ルール・保存形式・報酬額・戦略AIは変更しない。軍務の地図操作と個別隊の指示は既存画面に残す。会話の一時選択は保存しない。再開時に未確定操作を勝手に実行しない。

## 次の5件
1. 軍務導線の実画面・復旧確認とpush。
2. 仕事と軍務を往復する操作の読みやすさを確認。
3. 拠点の認識した需要から仕事を提示する設計。
4. その需要に対応する既存行動の接続と重複発注の防止。
5. 私財の使途と長い旅の遊びを段階的に検証。

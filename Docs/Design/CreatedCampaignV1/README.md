# 同じ武将の平時・本隊配置・帰還

通常入口の「作成武将で開始」に「織田家の家臣・本隊配置任務」を追加。試作兵100は主家の軍で、私有兵でも史実兵数でもない。配置・保持・帰還だけを期限付きの明示許可で扱い、交戦・他隊命令は拒否する。

人物・時計・世界・保存は共通。在所で点検を終え、清洲から本隊で出陣し、線へ移動して戻る。未着書状は行動可否を拘束せず、受領して開封した在所の点検は野外では待機する。野外からの理由書状・期限返報は地形上の第一行程を経て街道へ出る。発送時の物理所在を保存し、同時刻の出陣や復旧の管理回数によって変えない。

元の浪人/家臣開始、従来検証、利用者の保存を保持する。変更前の実物JSONを Tests/Fixtures/created-ronin-bea3d4f-*.json に保存し、欠落する追加項目と再出力を検査する。

## 検査

`Scripts/verify_created_campaign.py` は既存の開始方式96比較に、新方式3ケース×5保存点の復旧/続行30比較を追加する。合計32個の実GPUプロセス。全1047件（新37件）。表示領域を280px以上に保つ検査を維持する。通常UIのボタンと同じ処理を実行し、OSマウスは操作しない。

実行後はPNGを目視し、verification.json の visual_review に確認済み画像のハッシュを登録してから Scripts/check_created_campaign_binding.py で入力・実行物・全検査・画像の結び付きを照合する。未実施を成功として扱わない。

## 残る工程

交戦許可と損耗・主君への報告、物資の引当/返還、明示委任、仕官/解任の継続。現在の開始合意は架空の試作条件であり、史実人物の任命・初期権限の採録は別工程。

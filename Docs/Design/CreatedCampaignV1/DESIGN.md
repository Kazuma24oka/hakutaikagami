# 個人の世界と本隊配置を結ぶ境界

部隊表から指揮官を導出する。工場の既定ID配列は試作データの構築だけに残し、実行・観測・位置同期・認可に使わない。部隊の指揮官とUnitStateの指揮官/組織を一致させる。

新しいcreated-retainer-campaign-v1だけにCommandMandatesを必須化する。旧世界にはnullを出力せず、旧JSONでは欠落を許す。人物・主君・軍・対象部隊・Move/Hold/Retreat・有効期間・根拠を明示する。試作兵100は私有資産ではなく織田家の訓練用初期配置。史実兵力でも最終バランスでもない。大名や家臣という立場だけで許可せず、明示許可を実行直前にも再確認する。期限後の新布陣は拒否するが、率いている本隊の安全な帰還は可能とする。

NPCの平時仕事は軍事中は計画更新を止め、世界時計は共通。点検と返報を終え、在所で出陣する。単身旅行から他地点へ部隊を呼び出さないよう、この試作の出陣拠点は清洲に限定する。部隊を帰還位置へ戻してから在所へ復帰する。同じ世界・人物・保存・時計を保持し、別戦闘世界を生成しない。

通常書状には発送時刻・所在のスナップショットを保持する。政治書状の送り主の現在地から過去の出発点を再計算しない。旧CourierMissionの追加項目はnullを出さず、既存保存を読める。旧保存で項目がないときは旧式の位置再構成で検査する。新世界では必須とし、宛先/時刻/所在の整合を再検査する。街道移動は保存された旅程から再構成する。通常書状を野外のAtPositionから街道へ取り次ぐ第一行程を保存し、発送位置と地形上の経路・所要時間を検査する。軍事伝令の既存の野外経路は維持する。

同時刻の中断理由発送→出陣→配達→帰還でも、発送元の所在を後から書き換えないことを受入ケースへ入れる。全履歴を毎秒複製するのではなく、業務イベントの発送時に必要な所在だけ保存する。

競合補完：出陣後に届く書状と未認識期限を検査する。新世界で未認識任務は行動を拘束せず、未認識の失効について本人名義の返報を生成しない。受信・開封後も在所外の点検は待機し、帰還後に同じ任務を履行する。通常書状の野外第一行程をFieldLegで保存し、地形/速度/端点/時刻を再検査する。発送の物理所在は管理用Revisionを含めない独立の値であり、停止/復旧の管理回数で物理経路が変わらない。

# 城役の終了時点と解任状

同じ人物が開始時の城主職と後から受けた代官職を兼ねる例で、任命者が解任状を発行し、本人が受領するところまで実行した。未受領の時点で実保存し、ロードを挟んだ場合も受領後の世界データが一致した。受領で代官職が終了し、別に持つ城主職と土地支配は維持された。異なる任地を指定した解任状は拒否された。

城役そのものを終了させる経路では転封の辞令を用いた。現地明渡しと同じゲーム内時刻を処理順で比較すると、直前は城主、直後は離任済みとなる。過去の権限を照合する際にもこの順序を使う。

本丸受領を伴う他城の交渉と、転封による明渡し、兼務の解任状はそれぞれの代表経路で検査した。追加検証では他城の城主に代官を兼務させ、追随・城門受領後に旧主から代官の解任状を出した。次の時点に代官職が終了し、本丸受領と一通の報告が成立した。転封の明渡しも含む三重競合と外観の目視は未実施。

# 続ける・辞去する・別の家へ仕官する

4条件達成。仕事で縁のできた主君との会話から、今の主君のもとで働くか辞去を願うかを選べる。辞去の本人の返答を表示し、続けた場合は世界状態を変えない。辞去願いの発送だけで所属を消さず、主君が返報や預り物の引継ぎを待つ場合は返答を会話で示す。

通常入口の同じ作成武将で、仕事の縁→仕官→点検担当→軍務の兵/兵糧引受→辞去願い→引継ぎ待ち→実返納/返報/指揮返還→辞去通知の開封→浪人として小田原へ移動→北条家との新しい仕官合意まで実行。私財と過去の縁は保持し、武田家の兵や兵糧を北条家へ移さない。

通し確認で、新しい仕官を申し出ても旧案件の選択が残って回答を誤る画面の不具合を修正。通常の仕官入口と仕事の縁の入口の両方で、新規に申し出た案件を選ぶようにした。

既存の仕官契約25件成功（新規テスト0、失敗・スキップ0）。Coreは前工程の軍務帰還から変更せず、旧の合意・通知・引継ぎ規則を再利用。実Godot2プロセス、4保存地点の復旧/続行後8組で世界・3D/情報画像・全表示姿勢が一致。引継ぎ待ちの返答と、同じ人物が北条家に仕官した画面を実画像で確認した。全件テストは今回は未実行。

別の家への軍務引受は今回の完成に含めない。既存軍務は一主家の生涯台帳を保つ限定モデルなので、別主家の軍務は旧軍の権限・兵力・資産を流用しない分離が次に必要になる。

再実行は通常Godot入口へ --new-game-case=serviceway-normal と新しい --new-game-test-key を指定し、同じキーに --new-game-restore を加えた別プロセスで復旧する。

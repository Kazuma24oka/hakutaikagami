# 個人随行協力・待遇・同行・点検委任 V1

## 完成条件と結果

1. 現地で協力可能な成人と合意し、個人随行と直属家臣の協力を区別する。所属・主従・兵・財産を勝手に移さない。
2. 私財から相手の財布へ手当を実移転し、未払いを期間から導く。未払い中の新規用件を拒否し、協力終了でも債務を消さない。
3. 二人分の実移動と点検を共通Intent/Task/時計へ接続し、点検結果/到着の返報を現地で封書として渡す。片方の受付が失敗した同行を丸ごと取り消す。
4. 途中/到着の実世代保存と復旧後の将来世界・本人名簿を照合し、旧null版を維持する。共通3D配置の実Node3D数値を確認する。

4/4達成。関連435件成功（新規23、失敗0/スキップ0）、Gameビルド成功。[現コードの証拠](verification.json)。Godot4.5.2 --headlessで既存実戦5組と同行2組、計7組14世界/48Node3Dの座標/表示用データ一致。全2615件は未実施。GUI操作・画面取得・外観確認は未実施で、数値検査を見栄えの受入としない。

## 遊びと境界

新規通常開始のCompanionPolicyに明示。『同行者・配下』で現地の浪人またはもともとの直属家臣に協力を相談できる。他家の所属者/他人の家臣/当主/役職者を勝手に引き抜かず、忙しい相手や協力しない本人も強制しない。一般の忠誠乱数や全国の真実から拒否理由を作らない。史実開始で候補がいなければ候補なしを表示する。登録浪人を登場させた世界や、既存直属家臣のいる信玄開始などで利用する。新しい架空NPCや史実人物を自動生成しない。

合意は個人の協力契約で、正式な家臣登用・仕官とは別。浪人にも個人的な協力者を持てる。直属家臣のケースも既存主従はそのまま、私的な随行/点検協力だけを合意する。協力終了で家臣を自動的に浪人化しない。

手当は試作調整値の一日20文、初日分を前払い。相手の財布へ同額入り、貨幣を新規生成しない。以後は日ごとの期間から未払いを算出し、私財不足でも消さない。日境界ちょうどで終了した契約へ次の日分を追加しない。未払いがあれば新しい同行/点検を頼めない。家の蔵や軍の在庫は使わない。これは個人間の報酬で、正式な俸禄・家の債務制度全体ではない。

同行は一回の行先合意。二人の自分自身の移動Intentを原本から作り、まとめて受け付ける。別々の実経路・進捗・通行止め対応を持ち、相手の現在地へ瞬間移動しない。海路はこの初版の同行対象から除く。別の場所へ新たに移動した主人公をGPSで追跡する常時追従ではない。同行受付の片方だけを残さない。

点検は協力者の自己点検を明示引受の原本から共通Taskへ渡す。軍務や徴収の代理権は生成しない。現地で再会したときに本人から封書の返報を渡し、物理到達・開封前に内容を表示しない。主人公が先に離れれば、相手の完了を遠隔の名簿へ即時表示せず返報待ちにする。返報の宛先は作成時の現地に固定する。

## 保存・検査と次

合意/手当/指示の原本、現物財布、共通任務、独立した旅程、返報を通常世界へ保存。同行途中と到着後に実GenerationSaveStoreで復旧して世界/名簿が一致し、将来も一致。途中失敗の原子的取消、同一ID/古いrevision、未払い、同日終了、他家当主/他人操作、拒否、経路時間改変、旧版への混入を検査。軍務の兵100人と私的手当が同じ世界で混ざらず、過去の権限検査に未来の支払を混ぜない代表例も確認。

3D検査はNode/Node3Dだけで、Control/入力イベント/UIコールバック/モデル素材/画像を使わない。通常画面の導線と返報会話は実装・ビルドまで。外観・操作感は未確認。

正式な家臣登用/所属変更、性格全般、忠誠/派閥/成長、危険地の自主判断、遠隔の新指示、海上同行、能力に応じた高度な委任、集団の大量負荷は後続。最小の個人随行一巡で区切り、次はR4の交渉。全体概算20%は据置。

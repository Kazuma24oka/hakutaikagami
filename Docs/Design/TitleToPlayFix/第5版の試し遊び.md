# 第5版を遊ぶ
タイトルで「新規ゲーム」を選び、1560年の武将選択で織田信長を選んで開始する。初回の保存が済んだら、次の三つを好きな順に試せる。

- 家中の用件を開き、「中央への取次」を選ぶ。信長の開始地では京の取次役への案内が出る。奏請・任官には移動と資格が必要になる。
- 軍の編成画面を開く。兵を引き受ける前は軍務の案内が出る。引受後は、現地で一族に分隊指揮を依頼できる。
- 不戦交渉から「独立条項を選んで正式条約を交渉」へ進み、「包囲網の書状」を開く。発送するまでは宛先や条項を見比べられる。

通常入口から同一人物で上記三画面を開き、閲覧だけでは世界が変化しないこと、開始保存をロードして世界データが一致することをGodot 4.5.2の画面なし起動で確認した。任官・分隊指揮・包囲網の成立をこの開始直後のセーブで完遂するところまでは未検証。個別の実行例は[幕府の栄典](../SupremeOfficeV1/entry-verification.md)と[包囲網](../CoalitionV1/entry-verification.md)を参照。

# 委任配送の再送基盤

共通MessageFlowへ物理経路を結ぶ追加APIとゲーム内再送ボタン。本人の命令だけを、不達報告を本人が受領した後に再送する。既知の営地/観測・受領報告の所在地を使用し、相手を自動追跡しない。命令ID/本文を変えず最大3試行。同じ失敗試行の再操作は新たな便を作らない。

成功した便の発送元へ受令返書と到達報告を返す。配達された原本が複数ある場合は最初に受領した便を採用。失敗報告そのものが不達なら再送可とは表示しない。期限は新しい命令の受令許可の期限で、適法に着手済みの移動を自動取消する期限ではない。

物理照会/返報側の自律再送/中断理由は次工程。今回の成功だけでこれらを実装済みと扱わない。旧開始・既存保存の自動変換なし。

# 私的協力の相談と本人の返答

## 固定した完成条件

1. 現地で本人に相談してから、受諾条件または開示可能な断りを返す。遠隔では内心や用件を返さない。
2. 相談だけでは世界/財布を変えず、同じrevisionの確認で既存の単発依頼を実行する。
3. 忠誠/敵の機密/隠れた理由を返答データへ入れず、内部処理の例外文と会話を分ける。
4. 実世代保存復旧後も返答とその後の実任務が一致し、旧版を保持する。

支持形成は、この限定協力から自動的な主君支持・所属離脱へ進めない。点検一件の協力、継続雇用、正式な主従、独立宣言への支持は別の合意と履行にする。今回は返答の開示範囲と確認導線まで。一般の性格/忠誠比較、支持宣言、露見、城/兵の移転は未実装。

## 結果と開示範囲

完成条件4/4。新規12件を含む関連631件成功（失敗0/スキップ0）、Gameビルド成功。[証拠](verification.json)。受諾できる相談と本人が断る相談を実GenerationSaveStoreで保存/復旧し、返答が一致。確認後の共通点検・会計・将来世界も一致。既存15組30世界82Node3Dも現コードで照合。全2692件と実画面/外観は未実施。

返答データはRevision/CanConfirm/Fee/Speechの4項目だけ。忠誠値、WillObey、秘密の任務ID、遠隔位置、内部評価点や危険の真実を渡さない。本人に実際に会った相談の結果として「今は手が離せない」「今回は引き受けられない」を伝える。内心の理由を性格/忠誠から捏造しない。遠隔の返答は、協力する人物/しない人物で同じ一般文になる。

未払いなら先の精算、継続中ならその契約の点検依頼、仕事中なら完了待ち、所持金不足なら私財の準備という次の行動が分かる返答にする。相談だけでは世界・知識・金銭を変更せず、忠誠や関係を加点しない。拒否の理由を世界の自動ログに配信しない。

会話の確認は提示されたrevisionを使用。状況が変われば再相談し、二重支払いや古い合意の適用を防ぐ。UIには既存の下部会話を使い、本人の返答とプレイヤーの確認選択を分ける。例外文字列をNPCの台詞として使わない。外観/画面操作は未確認。

## 支持形成の境界

単発点検の合意は、その一件に限る。継続協力を引き受けること、現在の主君を離れる意思、独立候補を支持すること、兵や城門を実際に引き渡すことは、それぞれ別の案件と権限・履行を必要とする。面識精算や依頼成功だけで「支持者」「裏切り者」に自動変更しない。既存BD-14/16/41/46/58に沿う境界整理であり、新しい支持機能が完成した意味ではない。

性格・忠誠・利害の一般的な判断、正式な支持宣言、露見/処罰、主従や軍権の移転は後続。旧v1は新しい相談を利用できず、既存保存bytesを維持する。キャラクター素材や外観の採用状態は変更していない。

# 工程9b 包囲網の検証
外交画面で対象家・招請先二家・条項を指定し、発送中に保存した。再開後も両家の宛先表示と3D配置が一致した。Godot 4.5.2 の画面なし起動で確認した。

石山から堺へ出陣した軍を道中で保存した。復旧後、盟主が開いた報告の行動原本と出陣時刻が一致した。単独和睦・離脱・密告は個別の書状として届く。固定Seed 42の別経過では、呼びかけ人の自然死を現地の家臣が目撃し、遠方の署名家は配送中の保存を復旧して訃報を受領・開封した時点で解散を認識した。

包囲網の統合シナリオと旧保存互換の計2件が成功。全件テスト、画面外観、全国長期プレイは未実施。1570年の史実事件の重みと民間・寺社からの自発的な呼びかけは別途扱う。

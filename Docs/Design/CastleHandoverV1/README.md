# 合意による城門・本丸の引渡しと軍事占有 V1

実装前固定基準approval-baseline-v18.json。新規v19のみ。既存の引受/軍勢/街道/共通時計を再利用する。

最初の範囲は、本人が現地の旧主側締結権者として、安全な退出と財産保全を条件に、現地へ実到着した外国指揮官へ城を引き渡す一巡。相手の協力意思と実在部隊を確認する。敵AIが全国で自主的に開城判断すること、無条件の強制占領/攻城戦の完成ではない。

同一条件の提示・本人確認、城門引渡し、次の時刻境界に予定する本丸引渡しを分ける。合意だけで占有しない。本丸に旧主側実部隊/救援が残る場合、または相手/本人が不在なら未引渡し分を保留する。既に渡した門を取り消して巻き戻さない。守備を退かせてから新たに本丸引渡しを申し込める。

対象は門と本丸の軍事占有のみ。蔵・財産は引渡し範囲外で旧所有者に保持する。領有記録、所属、直属、役職、兵の所有/指揮、家の資産、私財、給付債務を一括移転しない。旧主による自己財産の取扱いを合意が保護する。

現地の当事者だけが引渡し操作する。離れた後は自分の立会日時までの記録とし、遠方の現在の守備/蔵を表示しない。軍事占有者の部隊が現場から去れば現在の占有維持とは分ける。所有の色と軍事占有表示を混同しない。

未登録の城郭守備を史実の兵数ゼロと断定しない。試作は既存の明示登録軍勢と合意の関係だけを検証し、全国の守備採録、攻城戦、旧主の移住/家督/領有権争い、第三者救援の一般化は後続。GUI/外観は別受入。

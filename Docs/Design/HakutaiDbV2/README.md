## 書き出し（Tools/HakutaiDb/export_1560.py → Core/Data/hakutai-db-1560-v2.json）

- 人物ごとに開始時の名前（StartName）と名乗りの変化。1560年に名前が替わるのは46人（松平元康・長尾景虎・木下秀吉・武田晴信・大友義鎮・飯富昌景など）。誤りを避けるため、別人の表示名・苗字のない名前・1字の本姓で始まる名前・8字以上は使わない。

## 開始配置の決まり（Core/Contracts/HakutaiDbStart.cs）
- 登場人数＝石に換算した収入 1万石あたり2人（最低3人）。兵の上限＝1万石あたり250人。銭は1貫文＝2石（郡の金銭収入はまだ0）。
- 寺社・朝廷は人数の決まりの対象外（DBの全員）。
- 残す順：当主 → 1560年の所属が記録による人 → 推定の所属（推定の所属で家の国の外の人はさらに後ろ）。同じ段では 〇 → △ → ×、記録の多い順。
- 足りない分はオリジナルのモブ武将（×）。名前は家の人に多い苗字＋よくある通称から、家と番号で決まる。
- 実在性：〇＝確度A〜C、△＝D、×＝E とモブ。

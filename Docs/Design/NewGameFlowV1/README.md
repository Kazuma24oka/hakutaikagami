# 新規ゲームから同一人物の生活・保存再開

2026-10-22。ユーザーが五工程の接続、実動作確認、同じprototype/godot-foundationへのcommit/push、操作できる候補の提示を承認。通常起動への採用判断は最後に残す。通常project.godot、旧Main、旧WorkHub、旧保存を保持する。

## 入口と画面

候補 Game/Scenes/NewGameFrontEnd.tscn。Scripts/Show-NewGameCandidate.ps1 は現在のソース/試験/実画像の照合が通った候補だけを起動する。

スタート（新規ゲーム/ロード/武将作成・管理/設定）→開始条件→登録武将（登場なし/個別複数/一グループ）→配置・勢力調整→世界確定→操作人物選択→同じ人物の生活、を実装。

管理は元の登録を左約6割、グループを右約4割。独立コピー、グループ改名、名前/生年/能力/立場/収録拠点/直属相手を編集し、既存3Dの顔・髪・髭・肌・具足・兜を同じ外見データへ保存。3Dの全方向で同じモデル/骨格/共通肌色を使う。新素材の制作は行わない。グループ選択では複製元を指す直属関係を、一意な同グループの複製へ解決する。複数候補は明示修正を要求し、勝手に先頭を選ばない。

管理ライブラリ user://officer-library-v1 と、開始済み世界 user://new-game-v1/campaigns は独立。編集/インポートは開始済みの人物を変更しない。登録JSONの旧schema1はLook省略を許し、旧形の出力を保持。破損登録は保持し、読み取り不可を表示する。ロードと実在武将だけの開始は利用できる。

配置画面では大名の本拠を含む領土、旧大名の取り込みを指定。同じ城の要求を検出し、次へ進めない。この開始だけの登場場所修正で競合を解消でき、元登録やグループへ上書きしない。全領土喪失時の随行主従維持、残領への移転、旧本拠取得者への明示取り込みはNewGameSetupV1の規則を維持。

世界確定は操作人物の選択より先。全国地図の拠点ピン、地域/拠点へのジャンプ、そこにいる人物一覧、名前検索、名前/能力での並べ替え、一覧の人物を地図で見る操作を連動。未成年は世界に登場できるが操作不可。未採録の能力を0と偽らず「未採録」と表示する。

## 開始世界と既存Core

NewGameWorldは新ruleset new-game-personal-world-v1。旧プロファイルを無断で一般化/移行しない。確定配置の全人物・所属・個人主従・役職・拠点支配・外見・Seedを別の開始定義に記録し、既存WorldSession/全国経路/物理配送/世代保存へ変換する。登録と勢力配置から初期状態を再計算し、開始定義や確認結果の改ざん/不一致を拒否する。旧データにNewGameを強制追加せず、他プロファイルでの混在も拒否。

移動の初期点は各人物の確定した登場拠点。清洲への固定や瞬間移動はしない。既存の経路・所要時間・海路の出航待ちを再利用。世界の時刻はWorldSessionだけ。3D地形の位置・高さは既存の共通投影/地表から表示する。表示の回転/全国地図は世界を変えない。視点・表示速度・補間位相も世代保存する。

現地点検と現地の任意依頼を接続。依頼は現地の成人へ本人が相談したときの限定会話試作。封書到達/開封/本人承諾/実行/相手への物理返報を既存契約で処理。自主的な全国仕事AIや報酬・出世の完成ではない。返書は原依頼の面会拠点へ送り、相手の現在GPSを追わない。大名等の開始だけで軍・徴収権・物資を作らない。

同じ拠点に複数人物がいる場合もCoreの所在をずらさず、自己と同じ点の他人は3Dで重ねて描かない。同地点の他人は代表表示にする。各人が城内を歩く空間配置の完成ではない。

開始前の全人物一覧を、開始後の本人知識へコピーしない。ゲーム画面の任務/書状はActorView、周囲の人物は既存の局所目撃から表示。封書の未開封内容や遠隔人物の現在位置をUIで開示しない。

## 保存と切替

NewCampaignStoreは開始レシピと初期ハッシュを新しいGUIDフォルダへCreateNewで保存。以降の進行は既存GenerationSaveStore。開始直後と保存ボタンで世代保存。ロード一覧は検証できた進行だけを表示し、読めないファイルを削除しない。開始レシピを選択後にも読み直す。既存人物から新規/別保存への切替は実ゲーム内で確認し、取消で同じ人物と世界を保持。読み戻しが成功するまで元の人物を破棄しない。

スタートへ戻る際は同じ世界を保持・停止し、「いまの武将へ戻る」で再開。文字設定はこの起動中の表示変更（16/18）であり世界保存やOS設定を変更しない。以前の試作と保存は専用の保持した入口から開く。

## 試作データ・未実装の境界

初回方針どおり1560年/準史実。NationalPersonnelの出典付き3人と所属・本拠候補、108拠点/118経路を使用。城主・勢力代表・拠点支配はこの接続のための明示した試作初期条件であり、1560年当日の史実権限や全国領土の採録完了ではない。未収録の支配先は未設定とし、全国を3家へ勝手に分配しない。拠点支配は離散的な指定で、国境ポリゴンや農地範囲の確定ではない。

操作資格の18歳、能力0～100/開始予算1000（能力合計+支配拠点100/個人配下50）は当プロフィールの版付き試作値。元服年齢や製品バランスを正式確定しない。範囲外は開始前に理由を示す。史実人物の能力は未採録。年齢/能力/開始立場/外見は保持するが、年齢進行・能力成長・効果係数の完成ではない。

新しい入口と開始世界の限定接続であり、既存CareerMilitaryの仕官/辞去/軍務全経路、給与、全国政治AI、合戦/捕縛、全国人物完成をこの新規開始へ統合済みとしない。従来の検証済み軍務等は元の入口に保持する。外見も既存素材の範囲で、最終アート品質の完成ではない。

## 検証

Scripts/verify_new_game_flow.py：登場なしの実在人物、個別複数、グループ、旧大名取り込み、競合を一時配置で修正、未成年、破損ライブラリの7ケース。実ボタン/ピン/リスト/ゲーム内確認/非ネイティブファイル選択の信号を使い、登録→開始→任意依頼→移動→点検→保存→通常ロードと、別プロセスで4保存点の復旧/続行を比較する。入力装置・マウス設定・OSポインターは操作しない。

本人情報/全世界状態/モデルの姿勢・外見と3D領域の画像を比較。動画は別の試験データで、実画面と自動進行の描画フレームから作る。ユーザーの保存/登録へ試験を書かない。実画像確認後にcheck_new_game_flow_binding.pyでソース・バイナリ・試験・画像・動画を照合する。runtime-localの画像・動画・試験保存はローカル保持。

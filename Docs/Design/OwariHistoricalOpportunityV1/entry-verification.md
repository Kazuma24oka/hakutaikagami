# 清洲で道の様子を尋ねられる

清洲にいる織田家当主信長の既知の点検需要に、1560年だけ偵察候補の重みを加える。浪人が実際の依頼を開封して引受・点検・返報・受領する通常入口と中途復旧を確認。

清洲城を出発地とする史料は[清須市の清洲城紹介](https://www.city.kiyosu.aichi.jp/shisetsu_annai/kanko_shisetsu_sonota/kiyosujo.html)。道路を偵察する依頼はゲーム内の選択であり、史実の命令原本ではない。対象は新規の史実尊重・準史実開始。信長不在、別人物、1561年以降、事件版未指定の旧保存では新加重が付かないことを検査。旧保存から事件版を省略しても復元でき、バイト列が一致する。通常入口の通しは史実尊重。桶狭間の両軍の出陣・遭遇・帰結は未実装。外観と全件は未実施。

# 家の規模で数える旧国

城や館の所在を自治体・文化財の資料に照らした対応表。記録済みの拠点のうち一つを押さえた国を一国と数える。国全域の領有率は表さない。戦国期の国境ポリゴンや現代の県境は使用しない。

|拠点|旧国|参照|
|---|---|---|
|一乗谷|越前|[福井県文化財](https://bunkazai.pref.fukui.lg.jp/search_category/content?detail_id=588-0)|
|七尾城|能登|[七尾市](https://www.city.nanao.lg.jp/syougai/nanaojoushi.html)|
|人吉城|肥後|[文化遺産データベース](https://online.bunka.go.jp/db/heritages/detail/139887)|
|府内・大友氏館|豊後|[大分市](https://www.city.oita.oita.jp/o204/documents/dai3syou.pdf)|
|甲府・躑躅ヶ崎館|甲斐|[甲府市](https://www.city.kofu.yamanashi.jp/rekishi_bunkazai/documents/tiikikeikaku2.pdf)|

試作値は大名3拠点、大大名8拠点かつ2国、覇者15拠点かつ4国。未照合の拠点は拠点数にだけ含める。

# 百代鏡DB V1 の範囲（2026-11-12）

基準：approval-baseline-v100（BD-20 8→22）。2026-11-12 ユーザー指示「戦国DBを参考に百代鏡DBを作成してくれてかまわない」。

## 入れるもの
- 戦国DB（C:\Workspace\Projects\Data\SengokuDB）の特定のコミットから、1560年の家・人物・城を一方向に書き出す道具（Tools/HakutaiDb/export_1560.py）と、その書き出し（Core/Data/hakutai-db-1560-v1.json）。
- Core の読み込みと検査（Core/Contracts/HakutaiDb.cs）：参照の切れ・生没年と開始年の矛盾・日本の外の位置・知らない項目を拒否する。
- 推定の決め方を値ごとに保持（所属・置き場所の城・直属の上司・当主・城の持ち主）。
- 知識の区分：城の名前・位置は公知の地理、持ち主・顔ぶれ・関係はその年の情勢。
- 既存の開始人物・家（信長・信玄・氏康・義元など11人と8家）との対応。
- DBの全員のドット絵の型（朝廷＝公家、寺社＝僧、当主＝大名、ほか家臣）。
- 開始前の史料の画面「史料：1560年の勢力と人物」。

## 百代鏡側の採用（戦国DBは変えない）
- 当主は家の本拠に置く（戦国DBの見積もりは本人の城の記録を先に使い、今川義元が清洲城、北条氏康が山中城になっていたため。40人を置き直し）。
- 1560年の名簿の外の父は指さない。

## 入れないもの（残件）
- 全国の開始配置（DBの全員を世界に置く。BD-04 の全国規模の性能とあわせて）。
- 官位・官職の1560年の在職者、史実事件30〜50件、能力・技能・性格・志、名乗りの年ごとの変化（1560年の家康は松平元康）。
- 武将以外（公家・僧の多く）。戦国DBの person_year_status が軍事の人だけを対象にしているため。

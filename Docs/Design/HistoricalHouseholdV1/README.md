## 採録と試作設定の区別

[長野市・武田典厩信繁の墓](https://kawanakajima.nagano.jp/tour/tour-333/)の公式解説を2026-10-24閲覧。実弟として信玄を支えた関係を短く採録し、戦記由来の会話・兵数・忠誠値はデータ化しない。画像転載なし。甲府での開始、直属主従、家の家臣としての扱いは試作用の初期条件で、1560年1月1日の所在・個人随行・知行・軍職権限は未採録。副将という説明だけで指揮権を発生させない。生年や能力も未採録のまま。

名簿には家の家臣として置き、個人被官の自動追随を史実として付けない。登録武将の配置で旧主家を置き換える場合は既存の家臣配置規則を適用する。初期主従は本人が知っている関係、他者の秘密情報とは区別する。

旧3人版/旧5人版のJSONや世界定義を移行しない。旧9入口/rendererの今回再実行はなし。1000人は静止した測定用登録人物で、全国自律NPC/多数軍勢/fpsの合格ではない。

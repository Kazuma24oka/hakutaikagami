# 携行物資の境界

BD-37/40の所有・保管・実在庫を分ける。新しい補給付き架空演習だけに、主家所有の兵糧と取扱許可を置く。初期在庫は試作用の明示シナリオ値。CreatedCampaign/EngagementMissionの旧初期世界は変えない。

単位は「一人を一秒養う量」の整数（ration-person-second）。一人日=86400単位。100人の兵糧2日分は17280000単位。暦を短縮した試作用の食事間隔を作らず、実兵数×経過秒で同じ量を消費する。兵数の変化前後を分け、同じ兵数の連続区間をまとめて毎秒の履歴増加を避ける。損耗確定時刻までの一秒は直前の兵数で計上する。

ResourceLotに省略可能なMobileHolderを追加し、携行ロットのSiteは積載/返還の登録拠点、実位置はMobileHolderのLocationStateを参照することを明示する。旧ロットはnullを出さず従来のSiteを物理所在とする。携行分もResourceLotsの同じ数量であり別の在庫を複製しない。積載/返還の原子的な数量移動と消費の区間台帳を保存し、保存検査で全ロットの収支へ含める。

城と本人が同じ登録拠点にいる場合だけ直接受渡し可能。遠隔補充・他軍への横流し・私有化を許可しない。同じ操作IDは再度処理せず、数量を変えた再使用は競合とする。減った分は消費台帳から証明できることを必須にする。不足は表示するが、兵や人物の死亡を即時に生成しない。輸送隊・飢餓の疲労効果・日次生産・最終物価は次工程であり、実装したと偽らない。

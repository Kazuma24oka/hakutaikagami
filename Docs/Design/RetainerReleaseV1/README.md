# 旧主の承諾による家臣の辞去 V1

## 固定した完成条件
1. 現地の本人が、私的接触の精算・実仕事・返報を経て旧主へ自分の辞去願いを送る。申し出だけで主従/所属を変えない。
2. 旧主の実受領と独自判断、承諾の本人受領と引継ぎ、結果のプレイヤー受領/開封を分ける。
3. 不承諾/未着なら元の関係を保持し、成立しても兵/土地/財産/記憶を移さず新主への加入を別の合意にする。
4. 各段階の実保存復旧後も関係・知識・位置・将来進行が一致し、旧v1/v2/v3へ新権限を足さない。

新規v4で、役職・軍を持たない家臣の円満辞去に限定。旧主の裁定は既存の静的協力可否と実引継ぎを使う試作であり、性格/忠誠の一般比較や旧主への強制命令ではない。独立/出奔/旧主の追及/城や兵の引渡しは後続。

## ゲーム上の流れ

精算済みの私的情報交換と点検一件の実仕事/開封済み返報がある家臣本人へ、現地で辞去の相談をする。開始時の主君がNPC当主で、本人が役職/軍を持たず協力意思がある場合に本人から願書を発送する。プレイヤーの操作で旧主の承諾を代行しない。申し出では費用も主従/組織所属も変わらない。

旧主は本拠に届いた原本を実際に受領して判断する。手が離せない間は返答を待つ。本人に対する旧主発行の用件は完了と旧主の返報認識を確認する。限定試作の裁定は既存の静的協力可否を使い、不承諾なら元の所属/直属が続く。現状の一般家臣への旧主任務発行は未接続であり、引継ぎ条件の全組合せを実証したとはしない。性格・忠誠・利害に基づく一般裁定は後続。

旧主が承諾しただけではまだ関係を終えない。承諾書が本人へ届いて受領し、引継ぎ条件も満たしてから、旧組織所属と旧主従に終期を付ける。組織・旧主の城や兵・個人財産・既知の観測記録は移さない。第三者の所属や主従も追随させない。新しい主君へ仕えるかどうかは別の合意で、先に本人の結果通知を開き、必要なら継続協力20文と直属合意を改めて選ぶ。

## 配送と認識

願書の宛先は申し出時に特定した旧主本拠、返書/最初の結果通知は元の面会場所に固定。現在位置を自動追跡しない。プレイヤー向け一覧は、本人からの結果通知を開くまでは「結果待ち」で統一し、実際の成功/不承諾や旧主の秘密の仕事を漏らさない。未開封の成功を同行者の種別変更からも漏らさない。

通知を受け取れない場所へ移動すると配送失敗になり得る。本人に再会して「辞去結果を問い合わせる」と、本人が既に受領して知る結果だけを新しい封書で受け取る。新しい書状の到達/開封後に認識する。旧主の辞去承諾や主従終期を二重に作らない。願書/旧主返書そのものの再送UI、取消、代理決裁は未対応で、不達なら未決のまま保持する。

配送失敗の実検査で見つかったID長の問題は、原本IDと段階から固定長ハッシュのメッセージIDを生成するよう修正。配送失敗報告まで共通のID制限内に収める。固定宛先への不達、再会・再受渡し・開封まで実行した。

## 再現性と範囲

願書/判断/本人受領の当事者・本文・宛先・時点・原本連鎖を保存して照合する。プレイヤーからNPCの承諾・拒否・受領出来事を直接入力すること、承諾返書の受取人のすり替え、本人受領前の主従終期、同一IDの二重実行を拒否。原本の主従/所属関係に終期を付け、記憶・私財・旧主の所領・既存の自己行為権限は保持。旧主の新規機密を新たに提供する機能は追加しない。

新規通常開始だけv4を使用し、旧v1/v2/v3へ辞去行為を追加しない。開始時の旧主からの円満辞去に限定し、任意の新主を何度も替える汎用NPC仕官系が完成したとはしない。直属合意後の個人関係の解消は既存の別手続きで扱う。

通常画面の相談/結果問い合わせ/通知開封は実装・ビルドまで。GUI/外観確認とキャラクター素材の加工は行っていない。無断出奔・旧主の追及/債務裁定・政治的支持・独立・城門開放・兵の引渡しは後続。R4全体完成ではない。

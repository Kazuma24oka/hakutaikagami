# 本人の目標・後見・包囲網への誘い V1（BD-08・BD-07・BD-03・BD-41、2026-11-13）

- 目標：所領維持（決めたときに自分の家が持っていた城を、一年ごとの日にすべて持っていれば一年）、主家支援（主家〈自分の家の上の家、なければ自分の家〉が決めたときの城の数以上を持っていれば一年）、報復（相手の死を本人が知ったとき：自分で討った、現地で見届けた、本人に訃報が届いた・自然死を見届けた）。達成後も続けられる。報復の相手は、本人が姿や消息を記録した人・会いに行った人・同じ拠点にいる人から選ぶ（保存の検証は、相手が実在して生きていたことだけを確かめる）。
- 後見：成人の後継候補がなく、本人が知っていた未成年の子がいれば、その子のもう一方の実の親か、亡くなった本人の兄弟姉妹（生きている成人）を後見として続けられる。記録の理由は guardian、後見する子を持つ。子が元服したら、隠居の最初の候補としてその子へ譲れる。
- 包囲網への誘い：包囲網ができると、包囲する相手と境を接し、相手と約束のない、操作する人物が当主の家へ、包囲網の最初の家の当主から誘いの書状が届く。開いた後に一度だけ「加わる・断る」を選べ、加われば包囲網の各家と二年の同盟を結ぶ。返書が誘った当主へ届く。画面は「誘い」。
- 生活の画面に残っていた説明口調の文言（休息・道中の注記）を消した。

## 確かめたこと
- 目標の年数の数え方、報復の相手の選び方と、時間を進めた後の保存の検証・復旧（PersonalGoalsTests）。
- 未成年の子の後見で続け、元服後に子へ譲れること、後見の記録の改ざんの拒否（ControlSuccessionTests）。
- 誘いが届き、開く前は答えられず、加わると同盟ができて返書が届き、答えは一度だけ（NationalStrategyTests）。書状を実際に運んで開く流れは、全国の世界を数日進める必要があるため、検査では開いたことにして確かめた（未実施）。

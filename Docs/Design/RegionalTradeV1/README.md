# 3地域の米売買と現物移送

清洲・甲府・小田原の現地商人（米各2000kg/銭各4000文）と、本人の私財・携行米を扱う明示v3。初期数量と価格は調整用で史実値ではない。家・軍の財布/備蓄と混ぜない。v2保存へ勝手に追加しない。

## 価格・権利・現物
購入の見積は現地で記録し、一日以内の合意で米と本人の銭を引当。見積から七日以内の受取時に、銭を商人へ渡し米を私物として受領する。見積だけでは支払わず、引当した銭は他の手当・情報料・船賃に使えない。購入前なら元の商人の現地で取消、期限切れなら約定により解放する。

米は既存の本人移動と一緒に運ぶ。納入先へ飛ばさない。未知の封鎖は計画へ漏らさず、現地で従来の通行停止/迂回判定を使う。売買v3は交通処理を明示的に有効化。現地確認は移動の終了時刻から判定し、後の返報で更新された任務の版を過去の売買へ流用しない。旧運搬契約の判定は変更しない。

行先の現地で買取見積を聞き、一日以内の納入で米を商人の在庫へ移す。この時点では代金は本人へ増やさず、商人の支払資金を債務分だけ保護する。精算の現地操作で本人へ銭を渡す。納入済み債務は時間経過・取消で消さない。

受取後の取りやめでも米は携行したまま。元の地域へ戻り、現地の買取価格で売却を相談できる。元値の返金は保証しない。処分権を持つ当主本人が現地で明示した場合は、私有米を家の蔵へ移せる。これは私財への返金ではなく、以後は家の米として工事/救済に使う。外国の蔵への供給を無断許可しない。

3地域の基本売値は2/4/3文/kg。現地自由在庫の減少に応じて上がり、買取は売値から1文を引く（最低1文）。後の価格変化で過去の約定を書き換えない。遠隔地の現在在庫/資金/将来価格をUIへ出さない。画面へ出すのは現地の条件と本人の契約履歴。

米は商人在庫＋私物の携行中＋家へ供給済み＝初期総量、銭は商人の実残高＋本人への売買純移動＝初期総額を原本から検査。本人の既存財布には実決済だけを反映し、保護済み代金は自由残高から控除する。売買以外の支払は従来の別原本を保持する。

# S02 死亡・後継・操作継承（MortalSuccessionV1）

基準：Docs/Development/ProgressV1/approval-baseline-v155.json（実装の前に固定）。新規の全国開始の一覧の `MortalSuccession` がある世界だけ。今の保存は変わらない。

- 危篤（重さ3の傷病の峠の前）と意思表示不能。意思表示できない当主の家は出陣を決めない。指名・書状の決裁・評定は既存の判断の制限で止まる。
- NPCの家の家督：申立が2人以上なら決着（家法の後継順位・家臣の意向・指名・年長）。指名・成人の実子・同じ家の成人の兄弟姉妹（百代鏡DBを含む）・家中の筆頭格の順。敗れた人は家中に残る。
- 遺産：死亡の時点の私財（銭）を、指名の後継・成人の実子・配偶者の順で相続人へ。家の財・兵・所領・役職・主従は移さない。
- 本人の手当に医術が効く。重傷の後遺症は治った後180日まで残る。
- 操作の引き継ぎに兄弟姉妹。候補がいなければ年代記の終わりに没日・家・当主・城の数。

後回し（工程表に戻り先つき）：全契約の承継 → S06、NPCの当主の隠居・元服での希望の振り返り → S09。

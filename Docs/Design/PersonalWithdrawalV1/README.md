# 本人の退避と部隊の撤退の分離

BD-02/23/26/32/37/39/40、CC-01/02/04/05/07/08/14/17/19を維持する。対象は既存の拠点周囲120mの架空演習貸与で、史実の兵力・開戦ではない。

## 完成条件
1. 本人・3部隊・兵糧運搬の正本を分離し、兵糧の現地引継ぎなしの本人だけ退避を拒否する。主家所有・所属・残兵を維持。
2. 本人は共通地形を歩いて退避・既知場所への再合流・指定地点への移動を行う。本人の到着だけで部隊・兵糧・指揮を返納しない。古い合流地点で会えなくても行き止まりにしない。
3. 撤退命令は最後の現地観測地点へ既存MessageFlowで配送する。原本・試行・正式受領・業務効果・返書を分離。新しい現地計画を旧命令で戻さず、本人への結果認識は返書の実到達後。
4. 通常入口の同じ選択人物・3D・荷駄・伝令を接続。4ケース48保存点を別プロセス復旧し、同じ続行後の全世界・描画実数・3D領域/情報欄の画像を誤差0で比較。
5. 全単体、新旧入口/軍務/交戦と地形材質の実GPU回帰を確認。実PNG・短い実動作動画を点検し、現行ソース・実行物・結果を結合して同ブランチへcommit/push。

## 正本と互換性
- 任意の`NewMilitaryState.Withdrawal`に本人経路・現地観測・部隊宛の経路/業務結果を保存。旧保存では項目そのものを省略。定義パック・旧世界を無断変換しない。
- 主家兵糧は明示的な現地引渡しの後だけMobileHolderを本隊IDへ変更し、所在は部隊経路から取得する。所有者と運搬者は別。人物のLocationに同じ人物や架空の武将を増やさない。
- 本人不在の隊は受領済み任務を続ける。既存の兵が担う本隊の撤退命令受信役を明示し、他家への指揮権や新しい人物経歴を作らない。

## 共通配送への接続
- 原本・Attempt・正式受領・受取先の認識・失敗返報は既存`MessageFlow`を使用する。別の配送時計や正式受領を作らない。独自部分は人物間の街道配送と同様、地形経路/受信役の在所/業務適用のアダプターに限定する。
- 受信役と伝令の識別子を明示して共通配送へ登録する。受信役の受令記録を武将の知識/人物Evidenceへ混入させない。人物の代理権も付与しない。
- 命令の送信元は本人の実在所、宛先は最後の現地観測、返書宛先は発送地点に固定する。相手の未知の現在位置を使って追跡しない。不在なら共通の失敗報告を同じ地形経路で戻す。
- 入力ID・原本ID・試行ID・適用する配置OrderのIDを別にする。再入力は同じ受付を返し、効果を二度適用しない。新しい現地計画がある場合は受領しても旧撤退命令を適用しない。
- この部隊宛アダプターの照会/再送/遅着回収は次工程。未登録の試行やタイマーだけの遅着を保存へ入れた場合は拒否する。既存の人物間配送の再送機能は維持する。

## 描画検査
- 本人・部隊・荷駄・伝令の座標と回転を実数配列で比較する。Godotの構造体を既定JSONで空オブジェクトにしてしまう検査上の不足を修正し、カメラ・表示寸法・実地形メッシュも比較する。
- 非表示の伝令モデルも座標を初期化し、前の場面の描画状態を残さない。実数検査で検出した非表示座標3成分の差と元画像はcorrectionsに保持する。
- 部隊全景は実際の表示領域の縦横比に合わせて引きの距離を調整し、足元の点だけでなく頭位置まで収まるか検査する。小さい表示領域で切れていた元画像はcorrectionsへ保持する。
- 復旧直後の比較は画面配置の確定を待つ。3D領域と情報欄は画素の許容差0、全世界は正規化ハッシュで比較する。ドロップダウンの選択状態等の一時表示を画面全体の一致と称しない。
- 地形境界で検出した1画素差、材質生成順固定だけでは再現した記録、旧仕官の配置確定前比較の失敗はruntime-local/correctionsへ保持する。地形は400m単位の決定的な共通描画原点へ統一し、隣接する境界頂点とモデル変換を揃える。Coreの地形・高さ・経路は変更しない。
- 可視25区画の上限を保つ。原点跨ぎの再構築と材質の世界UV整合を実GPUで検査する。全国規模の性能達成を本工程では主張しない。

## 検証の正本
`Scripts/verify_personal_withdrawal.py` → 実画像点検 → `--finalize` → `Scripts/check_personal_withdrawal_binding.py`。現行合格はverification.jsonの記録だけで判断する。旧報告は当時の実測。固定60fps動画は性能測定ではない。

健康/捕縛/死亡、自動敗走/再集結、再任/複数案件、遠隔の全命令種別、全国戦争AIは未完成。次は自動敗走/再集結、部隊宛の照会/返報回復、再任/複数案件、観測と敵対による対象、全国負荷を順に継続する。重要な未承認の方針だけをユーザーへ確認する。マウス操作ツールとOS入力設定の変更は禁止のまま。

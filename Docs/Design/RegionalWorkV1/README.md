# 複数拠点の実在人物から受ける任意点検

独立入口Game/Scenes/RegionalWorkTrial.tscn / regional-peace-work-v1。初期位置は既存の清洲で、甲府・小田原へは全国街道と同じCoreで実移動する。別保存先user://regional-work-v1。旧規則・旧保存を読み替えない。

## 歴史とゲーム設定

RegionalWork.Rolesに出典URLと確認日2026-10-21を保持。清須市の人物伝は信長の清須拠点、山梨県砂防史は信玄の甲斐国主としての立場、小田原市「四代氏政の時代」は氏康の1559年家督譲渡を示す。氏康を1560年の現役当主として登録しない。各人物の本拠候補は旧TravelWorldの試作配置を継承し、1560年当日の所在の史実確定とはしない。出典に含まれない領域・主従・具体的命令を追加しない。

現地点検の任意依頼はプレイ検証用の設定。史実の依頼ではない。Inspectionだけの合意許可を追加し、土地/徴税/軍事権・架空の主従関係を加えない。歴史的立場を汎用命令権へ変換しない。拒否意図を発送可否へ漏らさない。

## 配送・認識・保存

同所にいる3武将の一人から既存Intent/Task/Messageで依頼する。未着は非表示、未開封は本文非表示、受諾まで作業しない。辞退や期限・権限失効は既存Coreで中止。既存効果台帳が重複受付/再開封/再送による二重実行を防ぐ。

新規則だけ、点検依頼と返報をTask.Scopeの拠点へ物理配送。既存の清洲固定や自己移動の宛先規則は維持。途中で相手の現在地に書き換えたり自動追跡しない。失敗返報は元の発送地点へ既存TrafficWorld規則で返す。保存検査では固定宛先/任意性/点検範囲/期間/署名済み入力を検証する。役職/出典を含む新しい規則の版とシナリオIDで旧セーブを拒否する。

3Dの本人はCoreの現在位置と共通地形高さに置く。拠点代表点にいる人物を見栄えだけで別位置へ動かさない。通常画面の時計を増やさず、画面は投影するだけ。3拠点の合成地形は史実復元ではない。

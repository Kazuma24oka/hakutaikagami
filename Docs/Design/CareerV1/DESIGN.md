# 時点と責任

BD-01/08/09、CC-01/03/04。人物IDを関係のIDとして兼用せず、申し出ID/配送便/主君判断/期間付き関係/開封履歴を分ける。Careerの出来事は追記式、実関係はその履歴から検査。NPCが受領した入力と宣言した検証条件を根拠にし、遠方の真の完了で引継ぎを済ませない。

合意の効力は同意便の主君受領。本人の表示は開封した通知/身分照会返答だけ。開封にも共通時計と保存順を記録し、回答前に知っていた条件を検査。過去の任務種別は発行時刻と発行時の保存順から検査。後着/後開封の通知は元の効力時刻と順序で比較し、後の身分を戻さない。

通常開始の主君は申し出を承諾し、返報確認後の辞去を認める限定の架空設定。非承諾と任務終了後解除は検証時だけ初期条件を変える。実際の採用/人事の複雑な判断を実装済みと扱わない。役職・軍務・徴税・財産/債務の引継ぎは別の権限案件で、この平時段階には追加しない。

通知は共通の封書/開封、街道は既存の物理伝令、保存は既存の世代保存を使用。独立時計や別の配送実装を加えない。新Careerモジュールは指定した開始だけに存在し、旧開始のJSONへ出さない。旧浪人開始と旧NPC判断の文字列実物を維持する。

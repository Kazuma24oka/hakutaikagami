# 工程：健康と療養 V1（BD-06・BD-07・BD-13）

入力：[健康・療養と、可能な仕事の継続（2026-11-06 採用）](../../Decisions/2026-11-06_HEALTH_RECOVERY_AND_DUTY_CONTINUITY.md)

## 完成条件
1. 負傷（脚・腕・胴）と病（熱）を、部位・重さ・発症時刻で区別して持ち、支障のある行動だけを止める。脚の深手は遠出・出陣、腕と胴の深手は戦闘、高熱は修行と評定の裁決を止める。それ以外（面会・書状・生活）は続けられる。
2. 手当：本人か、同じ拠点にいる同行者が一度だけ手当でき、残りの経過が縮む。即時の全快はない。加齢は回復を遅くするだけで、能力・技能の記録は変えない。
3. 本人の知識：本人には症状と回復の見立て（幅付き）を示す。他人の傷病は同じ拠点で見た範囲だけで、回復の見込みは示さない。
4. NPC も同じ制約で判断する（病の NPC は修行・遠出を選ばない）。発症時に続けられない修行を中断し、役目・預り物・責任は動かさない。
5. 遊べる一巡：賊との戦い・固定シードの病で傷病を負う → 生活の画面で状態とできないことを見る → 手当を頼む → 回復して再開。途中保存からの復旧で同じ未来になる。

## 版と互換
- 新規開始の判断設定 `HealthEdition=1` だけで有効。旧保存・旧方針の開始には付かない（付けた保存は読み込みで拒否）。
- 保存するのは手当の原本だけ。傷病は既存の原本（賊との接触）と固定シードから導出する。

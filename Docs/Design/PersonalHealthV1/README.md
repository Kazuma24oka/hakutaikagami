# 健康と療養 V1

武将本人とNPCが、負傷（脚・腕・胴）と病（熱）を負い、手当を受けて回復する。傷病は支障のある行動だけを止め、面会・書状・生活は続けられる。

- 入力：[健康・療養と、可能な仕事の継続（2026-11-06 採用）](../../Decisions/2026-11-06_HEALTH_RECOVERY_AND_DUTY_CONTINUITY.md)
- 実装：`Core/Contracts/PersonalHealth.cs`、暮らしの画面 `Game/Scripts/NewGameRuntime.PersonalLife.cs`
- 版：新規開始の判断設定 `HealthEdition=1`。旧保存・旧方針には付かない。

## 仕組み
| 項目 | 内容 |
|---|---|
| 負傷 | 賊との接触戦が終わった時点で、受けた損害の量から軽傷・深手・重傷。部位は接触と人物から固定 |
| 病 | 30日ごとの固定シード。年齢で起こりやすさが上がる。直前90日に候補があれば重ねない。微熱・高熱・危篤 |
| 止まる行動 | 脚の深手＝遠出・出陣、腕と胴の深手＝戦闘、重傷＝遠出・戦闘・修行、高熱＝修行・評定の裁決、危篤＝さらに遠出・戦闘 |
| 手当 | 本人か同じ拠点の同行者が一度だけ。残りの経過が3/5になる。即時の全快はない |
| 加齢 | 46歳以上は回復が遅くなる（1歳ごとに3%）。能力・技能の記録は変えない |
| 知識 | 本人には症状と回復の見立て（幅付き）。他人は同じ拠点で見た症状だけで、見込みは示さない |
| NPC | 同じ制約で、遠出（点検）と修行の候補を選ばない。発症時に続けられない修行を中断 |
| 保存 | 保存するのは手当の原本だけ。傷病は既存の原本と固定シードから導出し、検証時に照合する |

危篤は死亡や家督の移転を意味しない。自然死・暗殺の既存の経路は変えていない。

## 確認したこと
- Core：健康10件（旧設定には付かない・偽造の拒否・進め方の分割で同じ結果・高熱で修行を止める・手当で経過が縮む・他人には見立てを出さない・病のNPCは修行を選ばない・途中保存3段階から同じ未来）と、NPC判断・評定・賊・暮らしの関連97件。
- Godot（通常開始の入口、内部入力と自前描画）：賊との戦いで胴の深手 → 暮らしの画面に状態と見立て → 自分で手当（残り14日→約8.4日） → 保存復旧で同じ世界 → 回復。画像は runtime-local/ui。
- 旧保存の資料を使う検査（verification.json）。

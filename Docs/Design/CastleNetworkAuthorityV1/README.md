# 城の移動網の世界の権利の記録と重さ V1（2026-11-12）

基準：approval-baseline-v106（BD-04 18→20）。設計 Docs/Proposals/NATIONAL_PLACEMENT_DESIGN_V1.md 第4節2。

- 調べる権利を拠点ごとに作らない軽い作り方（CompactPersonalAuthority、人物1人に2件）は以前からあった。城の移動網の世界は、この作り方でしか作れないようにした（NewGameWorld の検査）。
- 権利の判定で、城の移動網の世界は拠点の一覧を毎回なめず、索引で引く（WorldNetwork.HasCastleWorldSite）。
- 城の移動網の世界で、今川義元が今川館に着いてそこを調べ、用件が終わるまでを確認した（CastleNetworkWorldTests）。

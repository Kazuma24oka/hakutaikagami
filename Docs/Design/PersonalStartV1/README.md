# 作成人物の個人開始

固定の試作奉行を置換せず、person:created/playerを別の成人浪人として追加する。本人の知識・主従・所属・軍・資産は元人物からコピーしない。既存の史実3人と試作人物はそのまま残る。開始前にStartConfigurationのRonin/Created/準史実・零予算検査を通す。1560年、開始拠点は既存清洲の試作点。全国データが完全採録された歴史シナリオではない。

本人移動と3か所の任意点検だけを明示許可する。徴税/再委任/軍権/家臣/土地は持たせず、既存のNPC依頼・物理配送・受諾・返報・街道/港移動を共用する。新規則created-person-peace-v1、名前とSeedを含む定義版、別保存先user://personal-start-v1。既存世界・人物ID・旧保存は変更しない。史実人物の開始権限は引き続き詳細採録待ち。

現在の画面はPersonalStartTrial独立入口。通常WorkHubへの選択UI追加は次段階。共有画面の固定人物参照をWorldSession.PlayerControlへ統一し、受信箱・受諾・既知部隊・3D本人を同じIDから表示する。旧プロフィールでは同じ旧IDとなる。

完成検査：追加15件を含む全985件、現在の通常入口14実GPUプロセス/36復旧等比較、作成人物2ケース（現地依頼/甲府への移動）×別プロセス復旧、10保存点/20比較。比較は同じ実寸法の指定表示範囲を差分0で照合する。自動検査はGodot信号を使い、OSマウスを操作しない。結果が出るまではverification.jsonを成功扱いにしない。

# 地形参照キャッシュ V1

全速度処理の実測で地形生成に約102～357msを要した。色/模様の周期の同じ台帳参照を頂点ごとに反復していたため、有限のskin/kind単位で同値を保持する。地形座標・メッシュ・UV式・道・移動判定・Core・保存形式は変更しない。

完成条件5件：
1. 同じskin/kindは同じ色/周期を使い、skin切替は別キー。保持はこのrenderer内の有限台帳だけ。メッシュ原点と25区画制限を維持する。
2. 変更前の実10/60/360倍の保存と公開入力列を使い、変更後の復旧で全世界・画面・3D座標を12組一致させる。
3. 新しい六つの高速/変更/保存/通知試験を12GPUで再実行し24世界画像/数値比較。共有rendererを使う旧軍務・戦闘・材質・三つの基本起動も9GPUで再実行。基準復旧3を含め24GPU。過去62回を現行試験と呼ばない。
4. 現行実フレームと地形更新時間を記録し、材質UVの世界周期/切替/原点跨ぎ/復旧も確認。Core2055試験は304入力/TRX/DLLの厳密一致時だけ再利用。性能値は1000静止人物+操作本人の移動の範囲。
5. 実画像を直接確認し、現行入力/実行物/証拠/コミット実体を照合して同枝push。主枝/設計枝と無関係な素材を保護する。

別環境の同じ公開入力列で約102～357msから23～104msへ短縮し世界/画像/数値が一致した。これは事前調査で、本体の現行検証とは分ける。キャッシュでもメッシュ生成自体は残り、一定fpsや実時間倍率を保証しない。

次の五件：地形参照の検証/push、通常判断の待ち時間、全国人物/役職、同時処理負荷、実プレイ体験確認。判断不要なら継続。

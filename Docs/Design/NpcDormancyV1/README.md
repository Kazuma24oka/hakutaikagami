# 遠方の人物の休眠 V1（2026-11-12）

基準：approval-baseline-v108（BD-04 22→25）。設計 Docs/Proposals/NATIONAL_PLACEMENT_DESIGN_V1.md 第4節3。

## 決まり（版 `player-nearby-hourly-30km-v1`、Core/Contracts/NpcDormancy.cs）
- 新規ゲームの開始の版 `NewGameState.NpcDormancyPolicy` に持つ。版のない世界（今までの開始と旧保存）は全員が日課の手番を持つまま。
- 続けての日課の版（ContinuingRules）の世界だけで使える。
- 世界時計の1時間ごとの区切りの時刻に、操作する人物と本人の道の上の位置が30km以内の成人だけが、次の区切りまで日課の手番を持つ。遠方の人物は判断をせず、判断の記録も、その検査もない。
- 区切りの時刻には必ず一度止まり、起きた人物に手番を渡す。区切りは世界時計で決まるので、進める速さや細かさで起きる人は変わらない。
- 判断の記録の検査は、その判断の時刻に本人が起きていたことも確かめる。

## 同じ未来のための区切りの追加（休眠の版の世界だけ）
版のない続けての日課では、日課を待っている間に「記録が古くなる」時刻（観察から3600秒）と「直前に知った記録が使えるようになる」1秒後が区切りになっておらず、進める細かさで判断の時刻が変わっていた（城の移動網の世界で、一度に2日進めた場合と777秒ずつ進めた場合で判断の時刻が違う）。
休眠の版の世界では、この2つの時刻のうち判断の入力が変わるものを区切りにした（NewGameNpcRoutine.InputChanges、LocalWorkDemand.NextStale）。旧保存と版のない世界の決まりは変えていない（旧保存を新しい決まりへ読み替えないため）。

## そのほかの直し
- 城の移動網で、史料の座標が同じ城（4組）が同じ位置にあり、位置から拠点を1つに決められず止まっていた。後の城を北へ約33mずつずらし、拠点の位置がすべて異なることを検査する（Tools/HakutaiDb/build_castle_routes.py、CastleRoutes.Validate）。城の移動網の世界は2026-11-12 に作ったばかりで、遊ぶ画面からはまだ選べないため、保存はない。
- 移動の検査で、旅の区間ごとに道の一覧（約2,700）をなめていたのを、ID の索引にした（BranchRoutes.Validate）。
- 拠点 ID から拠点を引くとき、全国の拠点の一覧をなめていたのを索引にした（WorldNetwork.NodeOfSite）。

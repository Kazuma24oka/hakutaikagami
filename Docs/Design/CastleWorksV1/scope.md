# 城の区画普請と石工

1. 外堀・城門・二の丸・本丸ごとに堀・門・土塁・櫓・石垣を選び、完成後に当該区画だけ防御が上がる
2. 既存普請の人手・米・木材・銭・工期・村の協力と競合を維持する
3. 石垣には雇用済みの現地石工と加工済み切石が必要で、現物を一度だけ消費する
4. 災害の損傷を区画に記録し、修繕で同じ区画の防備を回復できる
5. 通常画面・途中復旧・旧保存の代表例と重複・権限を検証する

統合案第14節5d（第13節N7、第17節H6）。攻城の部隊行動・破壊計略は続く5f/5aが同じ区画防備を利用する。数値は試作。

検査：区画選択・完成時刻・資源競合・石工と切石・同区画修繕、旧形式の通常普請、途中保存の同じ未来、通常画面の内部操作と描画。

# 開発の普請と造船

実在する試作職人集団の交渉・給付・現地食糧と実移動、原料の取引・本人の実運搬・工房と製作日数、鉄砲・火薬・鉱山精錬・石工・南蛮技術の在庫を接続。港の実船と積荷・船員・往復の海路・運休待機・帰港後決済と未払いを分離。宣教師の組織・布教許可・個人の入信・商人との面識を分け、NPCの自発招請・調達・製作と採算判断を実装。

関連18件・実保存復旧・代表旧保存3件・通常画面の内部入力と自前描画が成功。

職人・商人・教会・価格・船足は試作定義。史実採録と歴史モード別の追加出現、弟子育成、征服時引継ぎ、難破・海賊、遠洋航海、航海の3D船モデル、未払い回収分岐の通しは後続。通常画面の通しは工房・職人・製作・教会と保存復旧、実航海と運休・原料運搬はCoreで確認。全レシピの個別通し・全件・全国長期性能・ユーザー試遊は未実施。

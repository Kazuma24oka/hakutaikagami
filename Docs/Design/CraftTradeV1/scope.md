# 職人・技術・宣教師と交易船

1. 実体を持つ試作職人集団の条件交渉・実移動・現地設備を分け、職人だけで技術が瞬間拡散しない
2. 原料の現地購入・輸送・製作時間と鉄砲・火薬・鉱山・石工・南蛮技術の実在庫を接続する
3. 港の実在する交易船・荷・資金を出し、実航海と帰港でのみ収支を確定する
4. 宣教師・教会の組織、布教許可と個人の入信・商人との関係を分け、NPCも同じ条件で使う
5. 関連重大不具合・途中保存の同じ未来・通常入口と代表旧保存を確認する

検査：職人の所在と設備・原料不足・未完成の製品禁止・船と荷の二重利用・帰港前の利益禁止・通行止め・途中復旧・宗教と所属の分離。全件と全国長期性能は未実施とする。実名の職人集団や史実産地の確定値を新規に採録しない。


### 最終の代表検査（実行前の指定）
CraftTradeTestsの15件：職人の面前交渉・実移動・停止再開、設備/原料/工期、製作中・航海中・荷運び中の実保存復旧、船の二重利用と帰港前利益の禁止、運休の取りやめと帰路の待機、宗教と主従の分離、NPCの自発招請・調達・製作、硝石の取引と火薬、採掘精錬、原料の実運搬。依存3件はSocialWorldTests.GiftMovesExistingCoinsExactlyOnceAfterLocalReceipt、BrokerWorkTests.PurchaseDeliverySettlementConservesActualMoneyAndMerchantWood、PublicWorksTests.RealPortConstructionBuildsOwnedShipAndMaintenanceSpendsRiceAndCoins。共通の財布・市場・船を変更したため選ぶ。全件は行わない。

初回の招請は現地の私財から給付と移動食50kgを実際に用意する。遠方の蔵から瞬間支出しない。移動食は既存市場の米在庫と銭に反映する。以後の給付更新・製作は現地の家の資源から別に支出する。職人は村の200人台帳とは別の外来職能集団で、人数10人を固定し武将・軍・農民を増やさない。船員10人は地域労働の確保として控除する。

未実施/後続：史実の職人採録と歴史モード別の出現追加、弟子の分離育成、征服時の引継ぎ、難破・海賊、遠洋航海の段階解禁、航海の3D船モデル、未払い受領分岐の一巡、全レシピの個別通し・全国長期性能・ユーザー試遊。通常画面の通しは工房・職人・鉄砲の製作・教会と実保存復旧を確認し、実航海・運休はCoreで確認する。

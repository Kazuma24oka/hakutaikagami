## 境界
本工程は分隊原本の物理遅着と一度だけの効力。個別分隊原本の取消配送は次工程。旧本隊撤退の保持・取消と受信役を混同しない。保持方針なしの旧原本は引き続き再送だけを使う。80m視認、120m演習、600秒通常期限は試作値で、全国負荷・最終背景品質の合格ではない。

次の5件：本工程の検証/push、分隊原本の取消、実在勢力の権限、全国負荷、通常操作の整理。重要なユーザー判断が必要になるまで継続する。

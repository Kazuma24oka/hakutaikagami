# 家臣による街道補給と物理書状

実装前基準：approval-baseline-v15.json。新規v17のみ。元の拠点で当主本人と同意する成人直属家臣が、実在する未引当米・同じ軍務/軍/所有家・固定の到着先拠点を合意する。既存の野営地補給の現物台帳を拡張し、移動は共通の陸路、取消/報告は既存の封書配送を再利用する。

一回100kg以内、期限は30日という試作値。受け取りは、合意した拠点で同じ軍務の本人と部隊が実際に再集合し、容量が空いている時だけ。いなければ荷を保持して待つ。取消は相手が物理受領してから新しい受渡しを止め、既に渡した米は巻き戻さない。進行中の共通街道行程を安全に終えてから元の家へ帰還し、未使用米を実返納する。期限切れでも米は消さない。

未知の封鎖は現地で確認。停止・受渡し・帰還を時点付きで実配送し、開封前の結果や遠隔地の現在の荷を表示しない。不達後の再送は既存の既知不達/同一観測/上限を保持する。

固定拠点での受渡しを対象とする。移動中部隊の追跡・道中引継ぎ・海上輸送・護衛/略奪・軍馬飼料/弾薬は後続。到着しただけで城の支配や入城権を作らない。旧v16以下は自動昇格しない。外観/GUI操作とコード/データの検証を分ける。

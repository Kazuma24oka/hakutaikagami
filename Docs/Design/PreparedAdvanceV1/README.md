# 1倍速の次秒先行計算 V1

前工程PlayableLoopV1は8ee529cで5/5。現在の完成判定は本工程verification.jsonだけとする。

## 完成条件5件
1. 実際の私有・変更済みでない世界世代を捕捉し、別作業で同じCore計算と全検証を行う。未来の結果/世界/表示は確定前に公開しない。発行元の同一セッション・同一世代参照・確定順・時刻が合う時だけ一回反映する。取消・別世界・ロード・競合・失敗は前の世界を保つ。
2. 1倍速の通常画面で次の1秒を先に準備し、その秒境界までは反映しない。作業は一画面一個まで。通常入力は継続でき、命令/停止/保存/ロードで古くなった準備は捨てる。表示用の独立コピーも別作業で用意し、更新時の画面内の全世界コピーを避ける。
3. 実画面で1000人の選択人物移動、準備を保持したままの停止/視点操作、保存・ロード、明示した故障と再試行、重要書状での停止と一回押しでの再開を確認する。11保存地点から同じ世界・位置・操作タブ・3Dと同じ未来へ復旧する。
4. 既存のNPC/地域仕事も含む30追加/全2040テスト、私有世代の書換え監視、実GPU回帰と実フレーム観測を照合する。クリック時間と連続動作を混ぜない。先行計算を使わない速度・通常の判断・開始/停止操作の残る重さを明記する。
5. 現在ソース・DLL・試験・実画像/動画を直接照合してから同じブランチにcommit/pushする。

## 境界
新しい保存形式や別時計は作らない。保留中の準備は保存しない。Coreセッションは初期の深いコピーと、検証を終えた新しい深いコピーの差替えだけで更新する。捕捉した私有世代を直接変更しない。この所有規則の静的監視は補助であり、全呼出し先の純粋性の証明とは言わない。振舞い試験とレビューを併用する。

対象は自動進行1倍速の秒更新。10/60/360倍、通常の命令/開始/停止操作は従来の同期処理で、すべての重さの解消や固定fpsを保証しない。測定専用1000人は静止人物と選択人物の移動で、全国自律NPC・多数同時合戦ではない。

次の5件：本工程の検証/push、開始/停止など通常入力の重さの整理、初回プレイの案内、全国人物/同時処理の拡張、実プレイの体験確認。判断不要なら継続する。

# S09D 領地と寺社と朝廷の個別の案件（Cases2V1）

基準：Docs/Development/ProgressV1/approval-baseline-v166.json（コードを書く前に固定）。一覧の Cases2 の新規の全国開始だけ（Domestic2・Persons2・Armies2・Politics2 を使う）。今の保存は変わらない。

- 水利の争い：8月に凶作の国で、隣り合う二つの拠点の村が用水を争う（国ごとに一つ）。翌月、郡代が調べ、同じ家の村なら裁定、他家の村となら仮の合意を結び、普請（米200・銭20貫、40日）に入る。普請が終わって初めて効き、田畑の被害が減り、裁定で勝った村の不信が減って負けた村は増える（合意は両方とも減る）。
- 寺社への願い：本人は寺社の代表者に寄進・安堵・禁制・免税・通行・取次・仲裁・噂を願い出る。安堵・禁制・免税は寺社の領主の当主だけ。通行と噂は関係1以上、取次は3以上、仲裁は4以上で応じる（本人の寄進・安堵の分だけ関係が上がる）。
- キリスト教：南蛮の港の国（肥前・豊後・薩摩）を持つ商の方針の家は布教を許す。その家の南蛮船の品は倍になり、その国の寺社との関係が2下がる。
- 惣国：一揆の拠点が国の城の半分以上で一年続けば惣国。その国の拠点からは年貢を取れない（全国の家の内政の10月の年貢）。半分を下回れば崩れる。
- 徳政：借銀のある家の拠点で一揆が起きた月、借銀が年貢の半分を超える家は徳政を出して借銀を棒引きにし、その拠点の一揆が静まる。
- 客将：4月に、2倍以上強い同盟の家は、この半年に戦った弱い同盟の家へ、戦術の高い家臣を一年の客将として貸す。客将は決めた国の戦を率い、その戦術が効く。期限で、元の家が3倍以上強ければ延長（半年）、そうでなければ道のりの日数をかけて帰る。
- 任命の再承認：家督が代わった月、新しい当主は家中の役を改めて認め、家督を争った相手の役を解く。
- 朝廷の官職：国司の名乗りの当主はその国の城を攻めるとき力が5%増える。京官の名乗りの当主は官位の願いが通りやすい（年5%→10%）。
- 幕府への申請：本人（当主）は探題・栄典を書状で願い、京に届いた後、将軍と幕府奉行人（将軍家の文筆と裁許の高い二人）が城の数で決め、返事が道のりの後に届く。許されれば栄典になる。
- 中央の仲裁：この半年に同じ相手に城を二つ以上奪われ、取次のいる家は将軍に仲裁を願う。攻め手が3倍以上強くなければ一年の和睦を結び、攻め手はその家の城の囲み（区画の攻城）を解く。

案件の計算は1か月あたり約4ミリ秒。同じ月の凶作・一揆の記録は、全国の戦略の今の月の状態から読む（書き込まれる前の世界から読むと、同じ月の記録が見えない）。

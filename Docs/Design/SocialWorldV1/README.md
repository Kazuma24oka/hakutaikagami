# 人物関係・贈答・寺社・名声

方向別の人物関係、実在銭の贈答と使者の実往復、地域の小寺社との寄進・保護・禁制、既知の名声と噂を接続。関連32件・実保存復旧・旧保存270件・通常入口の内部操作と自前描画に成功。

贈答品は銭のみ。寺社は地域の小寺社の試作代表で、史実大寺社と人物は未採録。修行の武名は戦功と区別。宗教紛争・軍事協力・全件・全国長期性能・ユーザー試し遊びは未実施。約10ポイントの作業単位は継続中。

贈答の受領結果は使者の帰着前に送信者へ漏らさない。通行止め時は実物を保持して戻り、二重受領・二重返却を拒否。本人に未知の命令は面会不能の根拠にしない。寺社への寄進は主従・軍事同盟を成立させない。

# 人物関係・贈り物・寺社・名声

固定基準v56。ユーザーの明示指示で4機能を一まとまりにする。

1. 面識・仕事・恩と不満の根拠を方向別に集約し、内部4軸と画面の事実・手応えを分離する。
2. 実在の銭を差し出し、本人または同意した運搬者が運び、相手の受領・拒否・返却を経て贈答を確定する。二重受領や資金増殖を起こさない。
3. 寺社の建物・組織・代表者を分け、寄進・保護・禁制を別案件として扱う。権限と実効の範囲を保ち、寄進で服従を買えない。
4. 武名・仁徳・悪名・文名を本人に届いた事実から評価し、古い噂の風化と地域差・判断への影響を持たせる。未受領の情報は漏らさない。
5. 通常画面から4機能の一巡を操作し、重大な不具合・代表途中保存の同じ未来・影響する旧保存互換を確認する。

既存の主従・所属・所有権・指揮権は一括移動しない。大規模な宗教紛争・僧兵・宗教改革・一向宗の檄・朝廷取次は統合案の後続工程に残す。

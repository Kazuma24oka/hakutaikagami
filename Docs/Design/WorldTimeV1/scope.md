# 0a 時間の仕組み（T1〜T6）

2026-11-05開始。NPC用件・修行のPR57統合後、統合案第14節の順序に従う。固定基準v52。分母・重みは維持し、検証終了までは加点しない。

1. 通常開始から日の速度で移動し、本人への知らせで停止、再開、到着で減速、保存と再開まで一巡できる。秒の1・10・60倍と半日・1日・3日毎秒を同じ時計で扱い、旧360倍も復元する。
2. 次の本人向け出来事まで進める操作と種類別の停止・減速設定を実装する。本人が未認識の遠方の出来事・未着の本文・未観測の敵位置を公開せず、設定を切っても世界の実際の経過や配送を変えない。
3. 開始日から暦を計算し、1650年の総括を一度提示し、明示的な仮想継続の選択を保存する。史料付き開始は初回1560年を保持し、未採録の他年の人物を捏造しない。
4. 静かな区間は出来事境界でまとめて進め、接触・観測を要する区間は必要な細かさを維持する。秒刻みと主要状態・判断・実物の一致を比較し、代表場面の処理時間と境界数を測る。1年約1時間の遊び方の目標と実測達成を区別する。
5. 実保存からの復旧と同じ未来、旧保存のバイト一致、速度切替・待ち取消・ロード時の未確定世代の非公開を検査する。Gameビルドとゲーム内部入力・自前描画を確認し、未確認範囲を明記する。

## 範囲と進め方

通常開始→日単位で移動→受領した知らせで止まる→再開→到着で減速→保存から再開、を最低限の一巡とする。

既存のWorldSession.NextBoundary、世代を照合するPreparedAdvance、共通書状・移動を再利用する。本人の観測と通知を使う。従来保存は新方針へ自動で読み替えない。古い360倍の表示値も保持する。

評定・訃報・襲撃の未実装の発生源は後続機能へ接続する境界を用意し、発生源自体の完成には数えない。役割別NPC頻度は0b、事件と年代記の詳細は0c、全体UIの再編は0でまとめて行う。

代表例外は未認識の遠方の出来事で停止しないこと、速度変更・取消時に未確定の将来を表示しないこと。検査中は関連テストとビルド。工程末尾に全件・途中保存・旧保存互換を一度行う。画面はGodot内部の操作と自前描画を使い、OS操作は行わない。第1版（0系）の完成まで機能単位の試し遊びは依頼しない。

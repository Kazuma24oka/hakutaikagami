# 0a 時間の仕組み

通常開始へ日の速度・本人向け通知による停止/減速・次の知らせ待ち・設定・暦・1650年総括を接続。全件4,053件、9段階の実保存復旧、旧保存261件のバイト一致、Godot配置3組と通常入口の内部操作・自前描画を確認。停止設定の有無で同時刻のNPC判断を変えない。

1年約1時間は遊び方の目標であり、全国NPCの90年性能を達成した意味ではない。開始データは1560年。評定・訃報・襲撃の発生源は後続工程。次の知らせ待ちは3日ごとに計算を区切って通知まで続行し、途中で中断可能。ユーザーの試し遊びは0系が揃ってから。

## 実際の操作

通常の新規開始で速度欄から半日/秒・1日/秒・3日/秒を選ぶ。本人が重要書状を受領した場合は本文を開く前に停止する。目的地到着や認識した敵軍の接近では60倍以下へ減速する。時間の設定で種類ごとの応答を変更できる。次の知らせ待ちは計算区切りを越えて通知まで続行し、途中の停止操作で未確定の計算を破棄する。保存には確定した世界・設定・速度だけを含める。

1650年の総括は本人の完了用件と既知記録をその時点で固定し、一度だけ提示する。継続は明示選択で保存する。史料未採録の別年の人物配置を生成しない。

## 検査の範囲

通常開始のNPC方針を保持したまま、出発・自動進行・到着減速・停止・保存・ロード・時間設定・速度切替・出来事待ち取消をゲーム内部から実行した。Godot自身の描画画像を確認し、暦・速度・現在地が読めることを確認。OS操作・画面取得は使用していない。

全件の最初の実行は1,099件通過時点で同時刻NPC処理の問題を見つけて中断した。中断結果は成功に算入せず、修正後のfull-fixedを統合根拠にする。単秒比較は代表120秒区間、全経路は別の到着・接近・復旧ケースで検査する。最初の全経路単秒検査も時間を要したため中断し、未完了記録を保持した。

通常入口の一巡の実測はverification.jsonに記録。全件テスト併走中の機能検査時間であり、単独性能の比較値ではない。1年約1時間はゲームの遊び方の目標で、今回の往復移動を全国長期性能に換算しない。無事件の検査用世界は1年を1境界で処理する。

固定基準v52の範囲内で 46.540% → 47.003%。分母・重みは変更しない。

# 軍議：担当者と作戦線の入力

入口：`Scripts/Show-CouncilInput.ps1`。在所から野外へ出て軍議を開き、本隊/別働隊を選び「作戦線を引く」で地面をドラッグする。青い線は未送信。「この線で命令」で初めて発送し、送信済みの線を金色で表示する。別働隊は到達後に判断し、返報までは結果未確認。

線は布陣目標で、部隊が実際に通る経路ではない。本人指示と配下への伝令を区別する。軍議が開いている間のドラッグは下書き専用で、不意に本隊を動かさない。軍議を閉じた通常の地面ドラッグは従来の本隊移動。時間は画面を開くだけでは止まらない。

送信済みの担当と線を既存保存から描画する。未送信の下書きは保存しない。命令・保存契約を変更していないため既存officer-mission-entry-v1を使用し、旧保存の読み替えは行わない。既存のローカル生成3D素材を使用し、今回公開対象を増やさない。

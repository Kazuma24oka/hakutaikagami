# 私有物・紹介状・名物と茶会

私有米・木材・武具を売買原本から実物の贈答へ接続。一点物の購入・所有履歴、紹介者の既知情報に限る紹介状、招待状・本人承諾・参集を分ける茶会を実装。関連49件・実保存復旧・代表旧保存3件・通常画面の内部操作と自前描画に成功。

名物は架空の試作一点物。茶会は地元での実参集を対象とし、遠方のNPC客は欠席を選ぶ。贈った物の転売・史実名物・名馬・宗教紛争・軍事協力・全件・全国長期性能・ユーザー試し遊びは未実施。約10ポイントの作業は継続中。

所有者・運搬者・所在・取得履歴を区別。既存の買付荷を丸ごと贈ると売却・消費・家への納入に再利用できない。茶会の同席者は開催時点に固定し、後で移動しても経緯を作り替えない。贈答と売買の携行枠を合算し、NPCは積めない実物の受領を断る。

# 私有物と紹介・名物と茶会

固定基準v57。贈答品と関係づくりを同じ実配送へ接続する。1〜1cの残件と1dをまとめ、既存の人物・物資・輸送を重複実装しない。

1. 私有米・木材・武具と一点物を現物の所在・所有・履歴を保って贈答し、二重使用を拒否する
2. 紹介状は紹介者が実際に知る相手に限り、本人が実物を届けて使う
3. 茶会は招待状の受領・本人の承諾と実際の参集を分け、同席者の関係と既知文名へ反映する
4. 通常画面で購入・物の贈答・紹介・茶会を操作できる
5. 関連重大不具合・代表保存復旧・影響旧形式の互換を確認する

名物は架空と明示した試作用の一点物。史実名物の由緒は捏造しない。物資贈答は携行中の私有売買原本を丸ごと使い、家の預かり物・私有物を混同しない。宗教紛争・軍事協力と茶会の密約は後続。

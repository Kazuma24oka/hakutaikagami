## 仕組み

`NpcArmies.Policy`をNewGameStateとNewCampaignProfileへ明示した開始だけで有効になる。旧Factory・通常開始の既定値はnullのまま。開始時には空の台帳を持つだけで、既存の勢力を勝手に敵にしない。

引受は実在のNPC当主が自分の本拠で行う。兵100人（40/30/30の三部隊）・初期兵糧10日分は既存の軍務試作と共通の試行値で、史実の動員数ではない。携行量2日分を元の在庫から移し、実際に共通任務が開始した後の人秒を消費する。帰還時に未消費分を元の倉へ戻す。読み込みや帰還で100人・10日分へ戻さない。

所有者+拠点の安定IDをNewGameMilitaryと共有する。別の主家のプレイヤー軍は共存できる。同じ駐屯軍が既に貸与台帳を持つ場合のNPCへの引継ぎ、またはNPC引受済み軍のプレイヤーへの貸与は、この版では明示して拒否する。二重に生成して取り繕わない。

NPCの道路移動は別シミュレーターを持たずTravelWorld/BranchRoutes/共通Taskを使う。海路は初期計画と実行時の再計画の両方から除く。既存の現地通行止め処理を有効にして、未知の封鎖は現地で発見してから迂回する。封鎖を発見しても、他の人物の知識へ自動で追加しない。

この版の限定的な自律処理は、当主が自分で記録した有効な敵対意思だけを使い、既知の対象本拠付近までの短い往復を行う。所要時間が携行量の範囲に収まる候補だけを選ぶ。到着後30秒待機して戻る。拠点の近傍へ到着しても城の支配は変えない。NPCの自律的な開戦判断・攻城・全国の補給判断は作っていない。

指揮官を軍と一緒に動かすため、個人の点検を同時に実行しない。以前のNPC判断履歴を削除せず、各時点の引受・返納を根拠に個人行動の可否を復元する。

帰還後の再出陣や、既存貸与軍の引継ぎはこの版の対象外。行き止まりからの新しい自由移動/救出、携行分が尽きた後の損耗/調達は未実装。現在の版を一般的な戦略AI・全補給制度の完成として扱わない。

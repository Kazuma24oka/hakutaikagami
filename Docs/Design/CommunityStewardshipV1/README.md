# 現地の限定代理行政と時点付き報告

実装前契約：approval-baseline-v6.jsonの5条件。主君/直属家臣の現地の合意だけで30日以内の委任を作り、村の救済500kg/月・既定年貢1000kg/月・水利200kg/月の上限を持つ。家の所有/主従/兵/一般役職は移さない。代理官は現地にいるときだけ自分の処分枠を使い、俸禄引当と村の協力条件を守る。委任先がPCなら自動操作しない。

当主不在でもNPC代理官は限定運営でき、観測日付き報告は既存の封書配送で合意時に指定した宛先へ運ぶ。原本作成・配送・受領・開封・効力・本人の認識を混同しない。遠隔画面へ現在の真の台帳/代理官の真の所在地/受領状態を渡さない。取消は代理官へ物理到達して効き、当主の認識は別の返報到達/開封後。報告の再送は同じ観測値を保つ。

新規v7のみ。旧v6以下と仮素材を保持。数量・期間は試作用で史実行政制度の全国確定ではない。Computer Use未使用、画面なし配置と外観受入を区別する。

## 検証で確定した挙動

報告が当主より先に固定返報先へ着けば不達になる。代理官は不達の通知を本人が受け取って知った後、1日以上を置き同一観測を最大3通まで再送する。現在地追尾・新しい観測へのすり替え・現物処分の再実行はしない。取消の不達再照会/再送UIの一般化は後続で、合意期限は独立して失効する。

新規32件を含む関連841件、5段階の実世代復旧と将来世界一致、Godot画面なし45組90世界154Node3Dを最終ソースで確認。追加の公開API通し確認では当主の実移動→遠隔取消→代理官到達→支出停止→返報開封を照合。外観/UI操作・全2877件は未実施。村落の相談ボタンが当主にも無効になる表示版の不一致を修正し、当主/家臣の可否表示をテストへ追加した。

## 操作導線（実画面の外観・クリック操作は未確認）

新規ゲームの武田信玄/武田信繁の現地から「代理行政・報告」を開く。範囲・日数・返報先の拠点を決めて合意する。代理官がPCなら同パネルで処分/報告、NPCなら当主の移動後も現地で日ごとに判断する。届いた封書は同パネルまたは共通受信箱で開き、観測日時付きの数値を読む。取消もここから発送し、返報は別に開く。通常の旧保存はv7へ自動更新されない。

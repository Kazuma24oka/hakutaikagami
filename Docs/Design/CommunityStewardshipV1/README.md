# 現地の限定代理行政と時点付き報告

実装前契約：approval-baseline-v6.jsonの5条件。主君/直属家臣の現地の合意だけで30日以内の委任を作り、村の救済500kg/月・既定年貢1000kg/月・水利200kg/月の上限を持つ。家の所有/主従/兵/一般役職は移さない。代理官は現地にいるときだけ自分の処分枠を使い、俸禄引当と村の協力条件を守る。委任先がPCなら自動操作しない。

当主不在でもNPC代理官は限定運営でき、観測日付き報告は既存の封書配送で合意時に指定した宛先へ運ぶ。原本作成・配送・受領・開封・効力・本人の認識を混同しない。遠隔画面へ現在の真の台帳/代理官の真の所在地/受領状態を渡さない。取消は代理官へ物理到達して効き、当主の認識は別の返報到達/開封後。報告の再送は同じ観測値を保つ。

新規v7のみ。旧v6以下と仮素材を保持。数量・期間は試作用で史実行政制度の全国確定ではない。Computer Use未使用、画面なし配置と外観受入を区別する。

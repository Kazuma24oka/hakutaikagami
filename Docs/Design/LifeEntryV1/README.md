# LifeEntryV1

名前を決めて浪人から同じ人生を続ける、入口と操作画面の独立候補。既存の軍務・照会・再送・保存へ接続し、ゲーム判断を別実装にしない。通常の起動画面は変更していない。

実行対象 Game/Scenes/LifeEntryTrial.tscn。実検査 Scripts/verify_life_entry.py → 実画像点検 → Scripts/check_life_entry_binding.py。通常名/最大長の名前の2ケース、34保存点/68画像・全世界比較。Coreの追加機能なし。マウス操作ツールなし。

開始入力の事前検査では、LineEdit.Textへのプログラム代入だけでは実際の文字編集信号が出ないことを確認。実編集と同じTextChanged信号へ検査を修正し、空名で開始ボタン無効、入力後有効を確認。ゲームの名前検証を緩めたものではない。

3D背景/武将は既存の仮素材。画面密度・入口の採用はユーザーに実画像を提示して確認する。通常起動の切替、旧タブ/旧Mainの削除はこの候補の作成に含めない。

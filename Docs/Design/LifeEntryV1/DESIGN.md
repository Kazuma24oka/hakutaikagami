# 同じ人生の入口と操作画面の独立候補

LifeEntryTrial.tscn は WorkHubTrial の LifeFirst=true だけを指定する独立候補。project.godot の通常起動は WorkHubTrial のまま変更しない。既存タブの順序と機能を残し、候補だけが「武将の人生」タブから開く。旧Main/保存/原素材/保護ブランチを保持する。

StartSelectionPanel.Simplified は開始と表示だけを整理する。9種類の技術試作を選ばせず、既存 CareerMilitary.Create の浪人初期世界をそのまま用いる。初期世界と開始包の再生成ハッシュを照合。名前/開始/保存再開/現在の人物へ戻る/切替確認を維持し、別試作の保存は元の入口に残す。

ContinuousWorldTrial.LifeView は保存された世界・位置・判断・知識・資源・時間速度を変更しない。開発用の区画数/三角形数/素材比較を隠し、既知の身分/軍務と届いた仕事、必要な操作、世界時間を表示。兵糧は宣言済みの100人に対する約何日分かで表示し、内部の整数在庫は変えない。本人が在所の詳細表示では重なる部隊名を抑制し、3D座標をずらさない。

軍務返還を自分で願い出た後は、主君が実際に返還処理したかとは無関係に、画面からの再出陣を選ばせない。自分の帰還後報告を発送済みなら追加報告の操作も隠す。返還通知未着中に真の許可終了時刻をボタンの有効/無効から推測させないためで、Coreの権限/履歴/受領判断を変更するものではない。取消・再任は今回追加しない。

通常名と最大24文字の名前で、実際の名前編集信号/開始/仕官/軍務/布陣/帰還/辞去/街道移動を実行。17保存点を別プロセスで復旧し、同じ続行と保存時停止を再現して本人表示/3D領域の画素と全世界ハッシュを完全一致させる。旧タブ往復で同じ人物/時計が保持され、人物切替の取消で既存保存の全バイトが保持されることも検査する。

通常起動への採用は候補の検証と提示後に扱う。この工程では旧初期表示を置き換えない。新しい交戦/昇進/史実人物開始/完成アートは範囲外。

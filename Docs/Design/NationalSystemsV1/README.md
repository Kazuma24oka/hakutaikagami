# 全国の開始で仕組みを動かす V1（2026-11-13）

工程の表（2026-11-12 に Claude が出した7行）の6行目「残りの枠を全国の開始で一通り動かす」。地方の版で作った仕組みの多くが、全国の開始では有効になっていなかった（94のうち63。Tests/NationalCoverageProbe.cs で数えた）。

- 仕掛け：`NationalSystems.Current` に名前を足し、その仕組みの `Enabled` に `NationalSystems.On(w,"名前")` を加える。新規開始のときに一覧を `NewGameState.NationalSystems` に写して保存し、保存済みの世界は変えない。専用の設定（SocialPolicy など）を持つ仕組みは、`NationalStart.Create`・`New` でその設定を渡す。
- 有効にしたもの：生活と目標、同行者、人間関係、婚姻、養子、密書、天候、治安（賊）、家督、歴史モード（`NewGameState.History`。全国の家の戦略の史実の出陣の重みに効く）、健康と診療・傷病死、和睦と同盟の交渉、合戦での捕縛と処遇、家臣が NPC の軍を率いること（RetainerCommand）、NPC の自分からの手当（NpcSelfCare）、他人の能力の推定（AbilityReputation：家の当主と同じ家の者は評判で、面識のある相手は狭い幅で、段階・推定幅・出典・時点を出し、真の値は渡さない。BD-16）、遠方の合戦（StrategyBattle）、家の滅亡と再興（StrategyRestoration）、従属の離反（StrategyDefection）、戦・兵站・輸送・航海・道（Codex が接続した24項目。記録は Docs/Design/NationalWarfareV1）。
- 開始条件の画面の説明口調の文言を名前だけにした。
- 領地（LiveTerritory、2026-11-14）：普請・職人と交易・検地と布告・常設の奉行を全国の開始で有効にした。地方の版では当主が毎回の変更のたびに自分から動くが、全国では約200家が一度に動いて止まらなくなったので、毎時の区切り（起きる人が決まる時刻）に、操作する人物の近くで起きている当主・奉行だけが動く（LiveTerritory.Acting）。開始時の家の銭は0なので、検地（銭30）は収入が入ってから。
- 私財の計算の軽量化：寺社・贈答・警固・賊・職人・口入れ・名物・家中・捕虜の銭の出入り（SocialWorld.Net）を、記録に名前が出てくる人だけ計算する（出てこない人は0）。銭が一度でも動くと、全員の私財を変更のたびに数え直して重かった。直す前と後で世界は同じ。
- 全国の開始で有効でない仕組み（2026-11-14 に数え直し、102のうち25）：18は世界の規則そのもので切り替わる別の開始の仕方の試作（Career・CreatedCampaign・MissionEntry など）で、全国には使わない。時間の止め方（WorldTimeControl）は新規ゲームの画面が全国でも有効にしている。地域の経済（RegionalEconomy）は清洲の試作の村の約束で、全国は郡の帳簿（RegionalDomains）を使う。NPC の判断の土台（NpcJudgment、日課の版 v4：性格と知っていることによる選択・空き時間の修行）も、2026-11-14 から新規の全国開始で有効（それまでの全国の保存は v2 のまま）。全国で v4 にすると、起きている約215人が開始直後から修行・検分の依頼・開封を一斉に始めて重かった（ゲーム内1時間240秒）。結果を変えずに次を直した：検分を頼む相手探しで動いたことのある人だけ居場所を求める（NpcLocalOffers.Recipients）、報酬の請求の判定と受け取りで世界を写さず受信箱も作らない（NewGameWork.CanRequest・AssessmentNotice.LatestKnownMessageFor）、依頼を受ける処理で検分の依頼の ID を1回だけ集める、開封の後の手番の初めに「することがあるか」を写さずに確かめる（WorldSession.Peek。郡の帳簿・村の行政は日の初めでなければ戻る）。直す前と後で世界は同じ。重さはゲーム内1時間 240秒→65秒、6時間 90秒。
- 変更の写しの軽量化（2026-11-14）：変更・手番・試しの適用（TransactionalWorld）で世界を JSON で写していた（1回約0.15秒、全国の世界は約18MB）。記録（record）と配列の中身は書き換えない約束なので共有し、世界そのもの・世界の配列・書状の状態・ID の番号だけを新しくする（ContractWorld.CopyForChange）。環境変数 HAKUTAI_JSON_COPY=1 で今までの写し方に戻せ、両方で世界が同じことを確かめた。あわせて、家中の届いた文書を1回だけ集める・返答済みの文書を先に除く・評定の時間外を先に除く（HouseholdCourt）、銭が足りない検地を試さない（LandSurvey）、日課の頻度の判定で今の版なら世界を写さず当主の一覧を覚える（NpcJudgment.CadenceAt）。全国の開始の6時間 90秒→59秒、開始後の落ち着いた2時間 18.7秒→約10秒。いずれも直す前と後で世界は同じ。私兵の解散の約束（PrivateStanddown：当主に銭を払って次の出陣を見合わせてもらう）は 2026-11-14 に全国で有効にした。
- 城代と城の受け渡し（CastleAdministration、2026-11-14）：全国の開始で有効にした。城の持ち主は、落城などで変わった後はその時点の持ち主の家（NationalStrategy.Owner）。

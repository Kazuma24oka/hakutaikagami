# 任務受信の試作

主君の点検命令と配下からの任意依頼を、既存の物理配送・開封・受諾・返報で扱う。重要書状の到着で停止し、未開封内容は伏せる。開封時点で命令は既存履行判定に進み、任意依頼は本人が受諾/辞退する。期限は発送時の絶対期限で、開封待ちでも進む。

新しい規則版と独立IncomingMissionTrial.tscnを使用し、旧保存を移行しない。試作発送ボタンはNPC計画AIではない。理由は本人が知る受諾状態と既存公開状態のみ。服従拒否・権限喪失の真の動機は推測せず、既存の「照会が必要」を保持する。

検証：Scripts/verify_incoming_mission.py。実行には既存ローカル3D素材とGodot .NET環境が必要。生成PNGと保存はruntime-local（非追跡）。共有ソース変更により過去段階の検証書は今回バイナリの証明には使えない。

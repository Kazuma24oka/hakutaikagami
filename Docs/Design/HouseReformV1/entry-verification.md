# 家中改革の通常入口と旧保存の検証

2026-11-06。Godot 4.5.2 .NET を画面なしで起動し、HouseReformCheck シーンでゲーム内の家中画面を操作した。

- 当主が「家中の様子」から改革の相談を送り、配送中にディスクへ保存してロードした。
- 時間を進め、戻った返書を画面で開封して、当該拠点の他国私信禁止を制定した。
- 制定後も保存・ロードし、画面に家法の発効済み表示が出ることと、保存前後の3D配置データの一致を確認した。終了コード0、結果 HOUSE_REFORM_UI_PASS。
- HouseScaleV1 の legacy-probe を一時フォルダで現行Coreに対して再ビルドした。inputs.json が指定する RegionalDomainsV1 の旧保存3件を読み、WorldSessionを構築して再出力したバイト列は3件とも元データと一致した。
- この検査はゲームの通常画面内部の操作・表示文字列・配置データを扱う。画面の外観と全旧版保存の網羅検査は未実施。

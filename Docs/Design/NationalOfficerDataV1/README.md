# 全国人物の生年と基礎能力 V1

全国1560年の新規開始に、百代鏡DBの明記生年と、推定根拠・確度を分けた生年を接続した。能力は統率・武勇・知略・政務・魅力の5項目を1〜100で保持する。能力値は史実の確定評価ではなく、DBの役割語に基づく確度の低い試作値で、根拠がない魅力は50とした。既存の交渉値は魅力へ移さない。

表はDB 4,583人分を版・元DBコミット・SHA-256付きで保存する。明記生年は変えず、親子の年代が合わない推定だけを親から子へ一方向に調整する。明記生年同士または没年制約と両立しない親子リンクは全国開始では不採用にする。本人のカードには5基礎能力を表示し、他人には能力の数値を公開しない。旧全国開始版・旧保存へ新しいデータ版を遡及適用しない。

固定基準は `Docs/Development/ProgressV1/approval-baseline-v115.json`。完成条件と実測は同じフォルダーの `scope.md`、`completion.json`、`verification.json`、`integration.json` に記録する。

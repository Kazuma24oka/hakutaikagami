# 全国人物の生年と基礎能力 V1

## 範囲
1560年の新規全国開始だけに、百代鏡DBの明記生年と、根拠の層を分けた不明生年の推定を反映する。統率・武勇・知略・政務・魅力の5基礎能力を1〜100の試作推定値として接続し、既存の「交渉」は魅力へ転用しない。

## 固定基準

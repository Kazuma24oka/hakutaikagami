# 武将の平時任務・軍議から共通世界へ

入口：`Scripts/Show-OfficerLoop.ps1`。新規則 `officer-peace-war-loop-v1`。通常Mainは切り替えない。

在所で点検と徴税委任→返報→野外展開→軍議の線を配送→本隊の地点移動→帰還配送→在所の次任務、という一巡の試作。拒否、返報前の離脱による結果未確認、交戦も別ケースで検査する。

軍議の布陣指示は固定線。返報は受令判断で、到着の報告とは区別する。税率・経済全体・多様な任務生成・評価は未実装。新規則だけ在所の担当者拘束と出陣条件を厳格化し、旧保存は読み替えない。

次は、①目的と制約を入力できる任務/軍議、②主君・配下の任務提示と評価、③全国各地の人物と仕事、④中間ズームLOD、⑤各拠点の地形・城郭と外観品質を順に進める。各段階で保存復旧と情報秘匿を検査する。

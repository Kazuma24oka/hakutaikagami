# 全国移動網へ川・道・山を反映 V1

基準：approval-baseline-v111。設計 `Docs/Proposals/NATIONAL_PLACEMENT_DESIGN_V1.md` 第4節5。全国開始を、地形が移動時間と到達可能性に反映される一巡へ進める。

## この工程で満たすこと

1. 新しい全国移動網の版を追加し、川・湖・標高と、出典を確認できる道筋を使って経路を作る。史実の道筋を確認できない区間は「推定」と明記する。現代道路を戦国期の道として登録しない。
2. 道・川の渡河点・山地を通る移動が、同じ移動網上の経路と所要時間に反映される。山は一律の通行禁止にせず、通れる斜面は地形に応じて遅くする。
3. 1560年全国開始は新しい版を使う。従来の全国移動網、既存の v1 世界、旧保存の内容と結果は変えない。
4. 全国開始から城を選んで出発し、道・渡河・山地の代表経路を実際に移動する。途中保存の復旧後も位置・経路・到着時刻が一致する。
5. 全国開始・1日の進行・保存復旧で致命的な性能退行がなく、地形データの出典・加工方法・不確実性を再生成できる形で記録する。

## 境界

- 表示だけの陰影データを高度の正本として扱わない。標高から移動コストを作る場合は、元データの標高値・解像度・欠損値と加工手順を保存する。
- 地図上の川線だけから実在の橋・渡し・浅瀬を史実として断定しない。採録根拠のない横断点は推定表示にする。
- 旧版の移動距離・速度・保存値は書き換えない。新しい規則はバージョン付き全国開始だけに接続する。
- 城の増減、1560年の人物・家の採録、戦闘地形、季節や大雨による通行変化は含めない。

## 実行する検証

- 新旧移動網の道・距離・速度・保存ハッシュの分離
- 川・湖を横切らない経路と、渡河点を通る代表経路
- 山地を含む往路の所要時間、同じ入力・復旧後の未来一致
- 全国開始の1日計測と、変更箇所に関係する全件検査

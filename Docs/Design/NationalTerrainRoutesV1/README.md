# 全国移動網の川・湖沼・標高反映 V1

1560年の全国開始だけで使う移動網の版を追加した。城・経路の接続は v1 のまま固定し、陸路の所要時間へ標高由来の傾斜負荷と、河川線・湖沼水面との推定交差負荷を加える。全国開始の地図もこの同じ v2 カタログを描く。既存の v1 世界と保存は v1 の距離を保つ。

## データと計算

- 標高：国土地理院「地球地図日本」30秒 GeoTIFF。格子値は約25m単位として読み、値0は欠損・水面として傾斜計算から除外。城間端点を約500m間隔で結ぶ直線上で平均絶対勾配を求め、係数 `min(1.5, 1 + 平均絶対勾配)` を掛ける。
- 河川：同地球地図の `riverl` 線を標高格子へ写し、同じ直線の標本上で連続した河川線を推定交差として数える。
- 湖沼・広い川面：ゲーム内の `terrain-v1.json` に収録した国土地理院由来の水面輪郭を使い、河川線として数えなかった辺について、輪郭と直線が交わるポリゴンを推定交差として数える。
- 推定交差1回につき312.5m相当を加算する。河川線と水面輪郭の重複は同じ辺で二重計上しない。山・水面による通行禁止は作らず、海路の距離・速度は変えない。
- 経路の形状・接続・基本距離は入力カタログのものを維持する。裏付けのない城間の線は「推定」の根拠表記を維持し、現代道路を戦国期の道路として登録しない。橋・渡しの存在も主張しない。

生成：`python Tools/HakutaiDb/build_castle_routes_v2.py`。入力の地球地図 ZIP 2点と `Game/Data/Geography/terrain-v1.json` の SHA-256 をカタログに記録する。利用条件は `Game/Data/Geography/CREDITS.md` を参照。

## 確認と限界

`verification.json` に関連検査・全国開始・保存復旧・Godot の内部操作と描画の記録を置く。全国規模の1日進行は前段の実測（4,014人、起きている216人で32.5秒）を基準にし、この工程で日々の進行処理は変更していない。

地形負荷は地図格子・端点間の推定線に基づく試作値で、個々の戦国期街道の正確な線形・橋・渡し・浅瀬・季節別の通行性を示すものではない。裏付けのある具体的な道筋は、史料の採録工程で置き換える。

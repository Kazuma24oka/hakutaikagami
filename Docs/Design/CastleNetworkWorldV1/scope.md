# 城の移動網を世界ごとの版で使う（範囲）

基準：approval-baseline-v102（BD-04 15→18・BD-20 25→28）。設計 Docs/Proposals/NATIONAL_PLACEMENT_DESIGN_V1.md 第4節1の残り。

- 入れる：新規ゲームの世界ごとの移動網の版（NewGameState.NetworkPolicy）。版が城の移動網の世界は、拠点の一覧・道・経路探索・拠点の検査・名前・天候の地域を城の移動網で引く。
- 入れない：全国の武将の配置、権利の記録の作り直し（城の世界でも調べる権利の記録は今の101拠点の分だけ）、遠方の休眠、新規ゲームの画面での選択、画面側（地図・ゲーム中の画面）の城の拠点への対応。

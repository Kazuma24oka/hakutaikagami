# 運搬の物理報告・取消と野営地への補給

実装前基準：approval-baseline-v13.json。v14で共通の封書配送による時点付き報告と取消、v15で既存120m戦場内の固定野営地への現物補給をまとめる。1ポイントで作業を区切らず両方の接続を完成条件にする。

購入/返却の報告は観測原本を固定して封書で送り、到着・開封まで内容を出さない。取消も発送と受領と返報を分け、相手が不在なら共通配送の不達とする。現在位置の透視追尾はしない。発送後も、届くまでは当初の合意に従う。

野営地補給は現地当主が空いている成人直属家臣へ、元の家の未引当米と固定の集合地点を合意する。既存の地形経路で最後の区間を歩き、軍と実際に合流し容量が空いて初めて携行兵糧へ渡す。受取不能なら待機/取消後の実帰還で原物を返す。元の家/軍務原本/所有権を固定し、瞬間移動・遠隔出庫・兵の生成はしない。

現行の本人軍務の活動範囲は拠点周囲120m。その制限を隠さず、この工程で全国の軍隊道路行軍まで完成したとは扱わない。一般隊商/輸送事故/護衛戦/略奪は後続。旧v13以下は自動昇格させず保存バイトを保持。Computer Useを使わずCLI/API/ファイルとheadless Godotで検証する。

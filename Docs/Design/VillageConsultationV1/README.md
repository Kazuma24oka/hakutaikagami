# 村落との相談・履行・反応

F05と基本設計BD-49/50/52に従い村落共同体は独自の利害を持つNPC組織、施設・土地・家とは別ID。3地域の試作用の代表2名を役務名で収録し、30日ごとの交代を代理不在の検証に使う。史実の惣村制度を全国共通に断定しない。

現地の領主が水利工事または救済量を提案し、代表が食糧・空き労働・過去の履行に基づき返答。1日以内に同じ代表版を確認、7日以内に現物を渡す/合意した工事を開始。代表交代は未確認の返答だけを古くし、成立済みの義務や履行を消さない。救済は一部履行可、工事は従来の20人・200kg・7日。工事着手と完了を区別。

約束だけでは米や労働を生まない。家の現物・俸禄引当・村の労働を従来台帳で照合。v5では直接の工事操作も村との合意を要する。緊急の直接救済は可能だが、他の約束の履行へ自動で付け替えない。

期限後/取消/一部履行と工事完了を履行履歴から評価し、次の工事の返答へ反映。現在の反応は現地の会話だけで知る。土地/主従/一般忠誠/兵/旧保存は変更しない。

完成条件はapproval-baseline-v4.jsonの5項目。外観/UI操作はComputer Use禁止のため未確認、CLIの保存復旧/画面なし座標一致と区別する。

# 全国の家の戦略 V1（BD-01・BD-03・BD-07、2026-11-12）

全国開始の世界で、操作する人物の家でない各家が月の初めに出陣を決め、翌月の初めに決着する。勝てばその城の支配が移る。

- 版：`NewGameState.StrategyPolicy = national-strategy-v1`（全国開始だけ）。記録は `ContractWorld.Strategy`（出陣・結果・家督）。
- 判断：城の移動網で境を接する家との強さ（DBの兵の上限×開始時に対する今の城の数）を比べ、1.5倍以上の相手へ月に6%で出陣。従属先がある家（DBの Overlord）は主家・同じ主家の家を攻めない。
- 史実の出陣（14件、公知の通説）：前提（当事者の家・境の城・当主がその人物）がそろうと、史実尊重90%・準史実50%で選ぶ。仮想では重みなし。前提が崩れていれば不発。結果は強制しない。
- 決着：翌月の初めに、強さの比で城を落とすか退く。結果は境の城にいる人物から双方の当主へ書状で届く（城に誰もいなければ書状はない）。
- 家督：当主が亡くなった家は、成人した実子の年長者、いなければ家中の筆頭格の成人が継ぐ（`HouseSuccession.Head` に反映）。
- 操作する人物の家への出陣と、操作する人物から30km以内の城への出陣は行わない（実際の軍勢で行うのは後の工程）。

## 残り

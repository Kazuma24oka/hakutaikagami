# 全国の家の戦略 V1（BD-01・BD-03・BD-07、2026-11-12）

全国開始の世界で、操作する人物の家でない各家が月の初めに出陣を決め、翌月の初めに決着する。勝てばその城の支配が移る。

- 版：`NewGameState.StrategyPolicy = national-strategy-v1`（全国開始だけ）。記録は `ContractWorld.Strategy`（出陣・結果・家督）。
- 判断：城の移動網で境を接する家との強さ（DBの兵の上限×開始時に対する今の城の数）を比べ、1.5倍以上の相手へ月に6%で出陣。境は自分の城と、自分に従う家（DBの Overlord）の城の隣。従う家・主家・同じ主家の家は攻めない。
- 外交：共通の強い隣を持つ二つの家は月に20%で二年の同盟を結ぶ（同盟の根拠にその強い家を残す。同じ家を根拠にした同盟が重なれば、その家への包囲網になる）。三か月で同じ相手に城を二つ以上奪われた家には将軍（足利将軍家の当主）が和睦を勧め、攻めた側が相手の3倍より強くなければ一年の和睦になる。約束の相手には出陣しない。
- 包囲網：同じ強い家を相手にした同盟が三つ以上重なると、その家への包囲網を記録し、加わる家へ書状が届く（同じ家への包囲網は二年に一度）。
- 包囲網への誘い：操作する人物が当主の家が包囲する相手と境を接し、相手と約束がなければ、包囲網の最初の家の当主から誘いの書状が届く。開いた後に一度だけ「加わる・断る」を選べ、加われば包囲網の家それぞれと二年の同盟を結ぶ。返書が誘った当主へ届く。
- 将軍：将軍家が城をすべて失うと空位を記録し、空位の間は京の主が将軍家の生きている成人を擁立して山城の城を一つ渡す。
- 上洛：京の主（山城の城の過半を押さえる家）でない家は、境に山城の城があり相手の2倍以上強ければ、月に30%でその城を目指す。京の主が変わった月を記録する。
- 破約：約束の相手が3倍以上弱ければ、当主は月に3%で約束を破って攻める（破られた時刻を約束に残す）。決着した二つの家は三か月は互いに出陣しない。
- 史実の出陣（34件、公知の通説。桶狭間・川中島・稲葉山城・上洛・永禄の変・三方ヶ原・石山合戦・手取川・耳川・沖田畷・摺上原など）：前提（当事者の家・境の城・当主がその人物）がそろうと、史実尊重90%・準史実50%で選ぶ。仮想では重みなし。その月の結果を「出陣・不発（前提が崩れた）・見送り（当主が選ばなかった）」で残す。結果（落城か退却か）は強制しない。史実の出陣の知らせには事件の名を付ける。
- 決着：翌月の初めに、強さの比で城を落とすか退く。守る側の同盟の家（攻める側と約束のない家）は兵力の半分で援軍に出て、結果に残る（同盟の義務）。結果は境の城にいる人物から双方の当主へ書状で届く（城に誰もいなければ書状はない）。
- 遠方の合戦（W4、2026-11-14、`StrategyBattles`）：全国の開始の一覧（StrategyBattle）を持つ世界では、決着を強さの比のくじでなく、実際の合戦と同じ接触の規則（ContactCombat）で計算する。両軍を500人ずつの部隊に分けて横一列に並べ、数の多い側の余った部隊は相手の部隊へ順に重なる。1秒ごとに兵は接触している敵の兵の10分の1、士気は接触している敵の部隊の数×8ずつ減り、士気25以下の部隊は崩れる。開始の士気は出陣ごとの固定のくじで70〜100。守る側が崩れて攻める側が残れば落城、同時に崩れれば落ちない。兵数・士気・損害・秒数を結果（StrategyOutcome.Battle）に残し、保存の検証で計算し直して一致を確かめる。旧保存はくじのまま。
- 家の滅亡と再興（2026-11-14、`StrategyRestoration`、全国の開始の一覧の StrategyRestoration を持つ世界だけ）：決着で最後の城を失った家を、その城と落とした家とともに記録する（StrategyState.Falls。人物・所属・私財は動かさない）。滅んだ家の当主（家督を継いだ者を含む）が生きていて拘束されておらず、旧城を持つ家の支配が揺らいだ（1年以内に当主が代わった・3か月以内に戦に負けた）とき、当主は月に30%で旧臣を集めて旧城へ挙兵する（兵は旧の兵の上限の3分の1）。決着は通常の出陣と同じで、勝てば旧城を取り戻す。
- 従属の離反（2026-11-14、`StrategyDefections`、一覧の StrategyDefection を持つ世界だけ）：主家（DBの Overlord）の支配が揺らいだとき、主家の半分以上の強さの従う家の当主は月に10%で離れる（StrategyState.Defections）。離れた後は主家の境の城に数えられず、互いに攻め合える。離れるのは家どうしの従属だけで、城・家臣・兵・約束は動かさない。操作する人物の家は離れず、離れられもしない。
- 家督：当主が亡くなった家は、成人した実子の年長者、いなければ家中の筆頭格の成人が継ぐ（`HouseSuccession.Head` に反映）。
- 近くの合戦を実際の軍勢で（2026-11-14、全国の開始の一覧の StrategyRealArmies を持つ世界だけ）：操作する人物の家への出陣と、操作する人物から30km以内の城への出陣も選ぶ。そのときは攻める家の当主が相手の家へ30日の敵対を表明し（表明の ID は出陣の ID から決まる。表明できなければ出陣しない）、NPC の軍（NpcArmies）が毎時の初めに出陣を考えて、出陣の城へ向かう。着いて留まり終えた秒に、月の初めと同じ計算（強さ・同盟の援軍・遠方の合戦の計算）で決着する（StrategyCampaign.Real、NationalStrategy.ResolveArmies）。大将が捕らえられた・兵がいない・行軍に失敗した・着く前に帰った軍は退いたものとする。軍が出なかった出陣は翌月の初めに今までどおり決着する。本人の軍が近くにいれば、今の交戦（WorldClashes）で戦える。旧保存の世界は今までどおり近くへは出陣しない。検査は Tests/StrategyRealArmyTests（近くの城への出陣を置いて、軍の出陣・到着の決着・保存から戻して同じ未来）。
- 重さ：月の初めの処理は全国開始で約2.3秒（2026-11-12 測定）。

## 残り
- 離反を主家の当主へ知らせる書状、本人の画面の従属関係（NationalFactionRelations）への反映。城主・家臣の個人の内応（BD-46 の秘密接触から宣言まで。地方の版の JointIndependence を全国へつなぐこと）。
- 再興の挙兵への他家の後援・国人の加勢（今は旧臣だけなので大きな家にはまず勝てない）。滅んだ家の旧臣が再興を志として持つこと（W5）。本人の家の滅亡と再興（本人の家は戦略の対象外）。
- 近くの合戦を実際の軍勢（NPC軍）で行うこと。本人が近づいたときに遠方の合戦の状態を実際の軍勢へ引き継ぐこと。合戦の損害を家の兵力に残すこと（今は強さを城の数から求めるので、損害は記録だけ）。地形・兵糧を遠方の合戦に入れること。
- 噂による伝わり方、地図の勢力の色（Codex の担当）。
- 城の支配を読む他の仕組み（開始時の持ち主を直接読む14ファイル）の切り替え。

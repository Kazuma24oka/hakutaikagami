# 指出・検地と年貢の方針

1. 指出の申告と検地の実測を別の現地仕事とし、人手・米・銭・工期と完成帳面を分ける
2. 当主と担当者は現地で帳面を読むか、時点付きの物理報告を開いてからだけ調査値を知る
3. 年貢の軽減・平常・重課を現地の布告と効力日で決め、過去の課税額や実物の米を読み替えない
4. 村は公開された税負担を自分の反応と労働協力へ反映し、NPCも同じ調査と布告を使う
5. 関連重大不具合・途中保存の同じ未来・通常入口と代表旧保存を確認する

検査計画：申告と実測の違い、未読値の漏出、工期・実支出・労働競合、布告前後と過去債権の保持、労働協力の反応、NPC同一規則、途中復旧と通常入口。全件・全国長期性能は未実施。村の申告を自動で不正認定・処罰しない。


共通処理の修正：同じ世界時計の時刻に複数NPCが支出するときも、成功した候補ごとに確定順を一つ進める。失敗した候補はコピーごと破棄し、確定順も支出も残さない。過去の原本・税率・価格の版や保存の書式を変更せず、後の支出が先に確定した支出を見落とさないための順序付け。普請・職人・恩賞・登用・取引の代表と保存復旧を追加確認する。


NPCの一巡を通常開始へ接続：新規キャンペーンにだけLiveTerritoryの版を記録し、普請・職人・調査・定例評定の空台帳を起動時から有効にする。浪人で始めてもNPCが領地運営を続けるための接続。旧プロファイルはその版を持たず、旧保存へ台帳を自動追加しない。実物経済の依存として、製品は現地で売って相手の実在銭を受け取れるようにする。無限の市場資金・徴税権・人口を生成しない。

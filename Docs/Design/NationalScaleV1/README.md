# S10 全国規模の性能（NationalScaleV1）

基準：Docs/Development/ProgressV1/approval-baseline-v168.json（直す前に固定）。速さの直しは答えを変えない形だけにし、直す前と後で同じ世界を同じ時間進めた結果の要約が一致することを確かめた。新しい振る舞いは、一覧の CastellanResend の新規の全国開始だけ（今の保存は変わらない）。

## 測った速さ（この機械）
- 全国の信長の開始で、ゲーム内の1日：46.7秒（最初の2時間28.7秒、残りの22時間18.0秒）。目安は60秒以内。
- 全国の家の戦略の月の計算（1560年6月〜1561年12月の19か月）：平均0.88秒（最初の月3.1秒、その後の平均0.76秒）。目安は1秒以内。
- 全国の拠点（1958か所）どうしの書状の道の計画：1回2.26ミリ秒。敵を避ける書状の日数：0.23ミリ秒。目安は10ミリ秒以内。

## 直したところ
- 依頼の検査：直前に確かめた状態から変わっていない先頭の依頼は確かめ直さない。申し出・書状・仕事の表は配列ごとに一度だけ作る。
- 見聞の記録：本人の知った書状の見聞を作るとき、ID を覚えておき、すでにある見聞をなめ直さない。
- 離反の判断：動揺した家（一年以内の代替わり・90日以内の負け）を家ごとに出陣をなめ直さず、一度に数える。
- 書状の道の計画：全地点をなめて次の地点を選ぶ形から、優先度つきの並びに。同じ距離なら ID の順、同じ距離の道なら道の名の順という選び方は変えない。
- 書状を結ぶこと：月の決着と同盟・包囲網の書状は、まとめて一度に道を結ぶ（送った順に結ぶので同じ結果）。
- 療養の判断：判断の制限だけを調べ（疲れの計算を省く）、手当をする家族は所属の表で引く。任務の併用の表では人ごとに一度だけ調べる。

## 城主の報告の再送（一覧の CastellanResend）
NPC の城主は、報告が届かなかった知らせを開いた後、同じ観測の報告を三通まで送り直す。再送の原本の ID は元の報告から決まり、一覧の無い世界では認めない。全国の2時間は再送を入れても28.7秒で、延びていない。

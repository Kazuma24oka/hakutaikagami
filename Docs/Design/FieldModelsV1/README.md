# 既存配置を保つ背景モデル

既存の役割・配置ID/Seed・占有範囲を変えず、静的な岩/木/試作用城郭を追加する。原素材と手続き形状を同役割の代替として保持。現在の合成地形の試作用であり、実在城郭や戦国期の建築を復元したモデルではない。

地面中央/+Y上・m単位。4m以下はCoreの占有矩形内、樹冠/軒だけ4mより上で張り出す。スクリプト・衝突・アニメーションは入れない。形状はScripts/generate_field_models.pyから再生成できる。

岩はGame/Tools/author_field_rocks.gdで輪郭と面法線を固定してArrayMeshを生成する。保存時のランダムUIDは取り除き、再生成した全モデル/メッシュのハッシュ一致を検査する。配色は既存カタログから生成時に取得し、変更時は再生成する。岩36三角形/個の静的形状。

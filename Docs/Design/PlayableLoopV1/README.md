前工程MilitaryAuthorityV1の現在証跡を確認してから着手。完成判定は本工程verification.jsonだけとする。

## 完成条件5件
1. 史実3人と測定専用の登録0/100/1000人を区別して測定する。実行時108拠点・118経路は地域7/7＋全国カタログ101/111。多数の自律NPCや同時軍勢の合格としない。
2. 新規開始でだけ点検権限を重複の少ない形式にする。既存全拠点・全行動との権限比較、未収録拠点・他人・未成年・改ざん拒否、旧JSON省略、実保存世代と同じ未来を維持する。固定開始定義の再利用は全入力バイトを照合し、私有の4件/4MiB以下のキャッシュに限定。変動する権限・位置・世界状態の検査は省略しない。
3. 静止人物の近距離表示を権威ある位置標本と照合し、道中と保存復旧でも一致させる。表示キャッシュは同じ世界インスタンス・確定順・時刻・停止状態だけで使う。
4. 移動・仕事、軍務、書状・仕官を通常操作で開ける欄へ整理し、3D表示の余白を確保する。部隊や印の位置を変えず文字の重なりを減らす。選択欄も同じ保存世代から復旧する。実在大名・登録大名・家臣の出陣→配置→帰還・返報・指揮返還を実画面で通す。
5. 新規40件を含む全2010件と現在ソース/DLL、実GPUの世界・数値位置・実画像の保存前後、短い動作映像を照合してから同ブランチへcommit/pushする。実測の遅い部分と未実施を明記する。

全国の全人物・全城・領土・NPC自律行動・多数の同時合戦、最終背景品質は別工程。フレーム観測は実行機上の値で、固定fpsや製品品質の保証ではない。

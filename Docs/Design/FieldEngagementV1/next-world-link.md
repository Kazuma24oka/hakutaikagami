# 実戦一巡に続けて接続する依存関係

2026-10-26。交戦任務の原本/配送/本人開封/取消を実装した時点での作業順。基本設計の変更ではなく、R1を完成させるための依存関係の整理。

1. **敵対の真実と認識**。世界の敵対状態、発令者が許可した対象、本人が得た情報を分離する。所属名や対象選択で世界の敵対を生成しない。停戦/同盟全体は後続でも、敵対の根拠・開始/終了時点・本人に伝わる通知は必要。
2. **同じ地図を移動するNPC軍**。既存の全国道路で拠点間を進み、最後の配置だけ地形上の経路へ接続する。現在の地形経路は640m以内、本人の貸与軍の配置は120m以内であり、これを全国経路へ拡張したことにしない。部隊の所有/指揮/兵数と位置の正本を一つにし、軍務の申出で同じ兵を再生成しない。
3. **実際の接触と効果**。FieldEngagementへ、上の世界状態と実在の部隊・位置・時点を渡す。同秒の損耗は既存ContactCombatを利用する。架空演習の相手を実在勢力名へ変えるだけの代用を禁止する。自衛と任務攻撃、無許可攻撃の責任を区別する。
4. **損害/撤退/返報**。実損耗を貸与軍と兵糧消費へ反映し、帰還した人数・物資・指揮返還と発送時点の報告を結ぶ。兵ゼロを武将死亡と同一視しない。敵の未確認の現在兵数を本人や報告へ漏らさない。
5. **一巡の保存復旧と画面**。NPC軍の道中、接敵直前、交戦中、撤退中、返報配送中から復旧する。世界・位置・知識・軍務台帳・実3D/会話を同じ将来まで比較し、R1の3条件を照合する。条件を満たしたら地域経済へ進み、軍事機能だけを増やし続けない。

## 史実データの扱い

現行の人物版は元の3人に西国の2人・家臣1人を加えた限定版で、全国道路の拠点数と史実の支配/人物/軍の採録は別。存在する全国地図の城に、対応する領主・軍・敵対がすべて採録済みとはしない。

次の地域候補を考える際の確認資料は以下。初期敵対の採用や新しい人物版の実装はまだ行っていない。

- [長野市・川中島関連年表](https://kawanakajima.nagano.jp/timeline/)：武田/長尾の対立・対陣・和睦を時系列で確認する一次の自治体資料。戦いがあったことを、その全期間の常時交戦フラグに変換しない。
- [長野市・松代城の歴史](https://www.city.nagano.nagano.jp/n151100/contents/p006083.html)：海津城を1560年に築いたという紹介。表示される現在の復元建物は江戸期末の姿であり、戦国期3Dの確定資料に転用しない。
- [新潟県公開の上杉謙信紹介資料](https://www.pref.niigata.lg.jp/uploaded/attachment/317092.pdf)：1561年の上杉姓/政虎・輝虎、1570年の謙信という改名を区別する。1560年の新規人物版へ後年の名を無説明で当てはめない。

資料の内容とゲーム用の簡略化・推定は別欄で記録し、既存の人物版と保存を上書きしない。未採録の史実を、実装上便利という理由で後付けしない。

# 実戦工程：交戦条件のCore実装（進行中）

## 工程の完成条件

1. 軍務の許可と敵対・自衛の条件を確認して接敵する。
2. 損害・撤退・帰還が任務の結果と本人への返報につながる。
3. 途中保存から復旧しても世界と表示が一致する。

この3条件は通常ゲームでの接続までを対象とする。現時点は0/3。交戦判定単体の完成と工程全体を区別する。攻城・兵種・全国補給・政治的処分全体は後続。最小一巡の完了後は地域経済へ進む。

## 今回実装した部分

`FieldEngagement.Resolve`は確定済みの世界事実から、その秒に成立する攻撃と損耗を返す副作用のない関数。主従所属だけ、敵対だけ、近接だけでは攻撃しない。任務は指揮官/所有勢力/軍/部隊/対象勢力と、原本到着・効力・期限・取消の秒を照合する。部隊の行動意思も別条件。自衛は同秒の実際の攻撃への応戦に限定する。

無許可攻撃は対象部隊を明示した場合だけ別根拠で記録し、国同士の開戦や政治的許可を自動生成しない。同勢力への攻撃を許可しない。敗走/撤退中は攻撃しない。複数原本で攻撃回数を水増しせず、同秒の損害は同じ事前状態から既存`ContactCombat`で計算する。

この関数自身は発令権限を授与せず、原本を配送せず、世界へ損耗を適用しない。入力は権威ある世界処理で検証済みであることが前提。任意のフラグをUIから渡して許可を偽造できるAPIとして公開してはならない。現在の軍務許可は移動・待機・撤退のみで、攻撃への拡張は行っていない。

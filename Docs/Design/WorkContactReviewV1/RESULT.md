# 新旧の主君との縁を見返し、新しい役目を得る

4条件達成。仕事で縁のできた人物を選び、確認済みのやり取りをそれぞれ見返せる。相手が現地にいなければ本人の記録として表示し、相手が今語っているようには見せず、現地の仕官や軍務の選択肢を出さない。現在地も開示しない。確認済み資料がない人物を一覧へ増やさない。

同じ武将で武田家の仕事/軍務→辞去/引継ぎ→小田原へ移動→北条家に仕官→新しい点検→評価を開封→北条家の点検担当を明示引受まで実行。武田家への評価や担当を引き継いだことにせず、二つの評価と別の主従期間の担当合意を保持した。新主家で旧主家の軍務台帳をそのまま見せる選択肢も出さない。

関連39件成功（新規0、失敗・スキップ0）。Coreは変更せず、既存の関係認識・仕官/担当契約を使用。実Godot2プロセス、5保存地点の復旧/続行後10組で世界・3D/情報画像・全表示姿勢が一致。旧主君の記録と新主君の担当確認を実画像で点検した。全件統合確認は別の実行として記録し、この39件と混同しない。

モデルは仮素材。ユーザーはTripo/GPT等で制作し外部ツール由来の要素を含むこと、正式キャラは後で別途制作することを説明した。出自の説明は再配布条件の確認完了ではない。現行モデルはローカルのまま、差替え前提を保持する。

新主家の軍務は、旧軍の権限/兵力/資産を流用しない台帳分離が未実装。派閥や感情全体の実装、NPCの内心を公開する画面とも区別する。今回の完成を製品全体の完成とは呼ばない。

# 工程9a 天下人の到達点

1. 既存の将軍の在職・空位・擁立と追放の経緯を時点付きで区別する
2. 公家・寺社の系図調査、養子・猶子などの根拠と朝廷の認定を資格に反映する
3. 自発の奏請と京を押さえた覇者への三職推任から本人が希望・保留・辞退を選ぶ
4. 任官後に幕府職の補任・栄典・仲裁を行い、所領・軍勢の実効支配と区別して通常画面・保存復旧を確認する

近衛家の代表には第16代当主・近衛前久（1536年生）を置く。京は試作の面会拠点、個々の猶子相談はゲーム内の出来事として扱う。[東京大学の近衞家史紹介](https://www.u-tokyo.ac.jp/biblioplaza/ja/C_00176.html)。

## 関白の交代（ユーザー決定）

五摂家との関係を満たす候補者について、現職の関白がいても朝廷は交代を裁可できる。裁可の時点で旧任の在職が終わり、同じ時点で後任が就く。奏請中・打診中は現職が続く。裁可の知らせが本人に届く時点と在職の切替時点を区別する。征夷大将軍には従来どおり空位を要する。

# 本人の所在と世界の進行

新しい継続世界の演習開始のみFieldPresenceモジュールを持つ。野外にいる人物の名簿と、同じ時計で動くRegionを分ける。本人が入城してもRegionを停止せず、他隊/伝令を消さない。本人の地域仕事・街道移動・兵糧は本人の出陣状態と実所在を検査する。旧開始/保存はモジュール欠落を許し、従来Region.Activeの挙動を維持する。

別働隊は初期シナリオで自家軍の演習移動を行う。プレイヤーの指揮許可とは別で、org:houseの所有と主従はそのまま。主家に無断移籍させず、操作可能な軍として追加しない。NPC初期の自発移動を生成根拠として定義し、通行/予約の既存経路を使う。

本人が野外にいないときは、本人の位置を部隊の代表点で上書きしない。観測原点・書状発送・BranchViewも本人の街道/拠点の位置を使う。野外の人物だけ部隊位置と同期する。本人が帰還すると既知の在所点検が始まり、野外では待機する規則を維持する。

本人の部隊が帰還していれば、他隊の移動や未認識の返報だけで入城を拘束しない。画面は本人の状態を示しつつ、把握した他隊は地図上へ表示する。指揮権の拡張、領地/私有兵の付与、敵の真位置表示は行わない。

動く部隊・交戦・本人の街道移動がない区間だけ、次の業務イベントまでまとめて進める。静止部隊の最終観測は同じ時刻へ更新する。兵糧は不足する秒を整数の満額区間/端数一秒/空在庫区間に分け、一秒ずつ進めた場合と同じ台帳にする。管理上のコミット回数と実際の兵数・位置・知識・数量を混同しない。

# 本人が入城しても続く野外世界

継続世界の演習を別開始として追加。本人は在所から始まり、org:houseの別働隊は自家の初期演習任務で動く。本人の指揮対象に無料追加せず、所属/主従/所有は変えない。本人が在所で点検・街道移動していても同じ時計で部隊が動き、入城で他隊を停止/瞬間移動させない。

本人の所在・野外の名簿・野外処理の稼働を分離。BranchView/書状発送/観測原点/3Dも本人の実所在を使う。携行兵糧は本人の出陣区間だけで消費する。旧モジュールのない開始/保存は従来規則を保持する。

静止し、交戦も本人の街道移動もない区間だけ次の業務イベントまでまとめて進める。兵糧が途中で尽きるときも満額の秒/端数一秒/空在庫を固定し、刻み方で台帳が変わらない。管理上の更新回数は物理状態と区別する。

全1114件（追加20）、実GPU41プロセス、156保存/続行比較+3素材寿命比較を同じ実行物で検査する。旧補給開始の実物初期状態と定義ハッシュ一致も確認。verify_field_presence.py → 実画像点検 → check_field_presence_binding.py。厳密なエンジンGCHandle競合原因は引き続き未確定で、既存の素材保持対策と強制GC検査を維持する。

他隊指揮の明示許可・到達報告は次工程。全国のNPC全員の行動・人口・物資まで完成した段階ではない。

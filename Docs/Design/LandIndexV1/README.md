# 地表判定の緯度索引

海岸線の辺を緯度帯へ分類し、旧ray判定と同じ式を候補だけへ適用する。経度の近似や点の丸め・結果キャッシュで判定を変えない。横の辺と頂点の規則、穴の除外を旧式のまま保持する。世界/地形データの版は変更しない。

旧実装をテスト用の独立比較基準として残す。実海岸線の頂点周辺、固定乱数5000点、穴/凹形状/負緯度を比較。12件追加後の全945テストを固定契約で実行し、実行Core/DLLとTRXを照合する。

全テストの期待件数はScripts/current_test_contract.jsonで固定。Core/Testsの集合または実行Coreが変われば過去の証拠を再利用せず、フィルタなしで全945件を実行する。旧NPC段階の933件は履歴として保持し、現行試験の代替にしない。

原点変換が毎回108座標の再投影を呼んでいたため、既存の静的原点だけを遅延取得して再利用する。値と呼出側配列の非連動を検査し、全国データや規則版は変えない。

島と辺の両方を緯度帯で絞る。候補辺は不変の数値列へ変換し、元の式と演算順序を保持する。原点は静的データから一度だけ取得し、公開配列の変更へ連動しない。

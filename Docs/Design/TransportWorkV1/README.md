# 小口送金の運搬を世界へ接続（L2）

完成条件は、1.現地の依頼主と固定宛先から任意契約を作る、2.現物と私財を分け保存する、3.同じ受渡しを再送しても増えない、4.途中の世界保存復旧と同じ未来を検査する、5.通常の会話入口と実3D表示を確認し同枝push。

最初は個人所有の銭100文の封包、運賃20文という試作値。荷主の財布から封包へ移し、本人の財布へは入れない。届け先の保管になっても所有は荷主。売買・組織送金・第三者物資の権限は扱わない。各依頼主の小口依頼は一度だけ。宛先は開始時の配達指定で、他人の隠れた現在地で変えない。受取人不在なら渡せない。

新アクションを実行した世界だけ省略可能TransportWork台帳を作成する。旧保存へ自動で仕事や銭を足さない。既存軍務と同様、独自の現物受渡し記録から資源増減を再構成し、全体の保存・残量保存則へ照合する。本人の移動は既存経路を利用する。

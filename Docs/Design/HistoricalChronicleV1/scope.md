# 0c 史実の事件と年代記：実装前の完成条件

根拠：統合案22節E1〜E8、Z11。固定基準v54。

1. 前提が成立した事件だけが本人に既知かつ実行可能な候補へ重みを加え、本人の選択・権限を上書きしない。
2. 史実尊重・準史実・仮想で重みが変わり、前提不成立は不発、1650年後の明示継続では史実加重を外す。
3. 本人の認識済みの記録だけを出典・発生日と認識日時付きで年代記と家別表示に出す。未開封・未受領・他人の秘密を漏らさない。
4. 通常のゲーム画面から年代記を開いて記録を振り返る一巡を内部操作と自前描画で確認する。
5. 関連する重大不具合、代表保存復旧と同じ未来、影響する旧保存形式の互換をP13に従って確認する。

世界の真実に関する前提と、NPCが判断に使える知識を分離する。未採録人物や未来の出来事を既知情報として補完しない。史実事件の実データには出典を付け、史料未確認の事実を捏造しない。

検査計画：前提不成立・未知情報・本人判断優先・モード差・二重記録・代表復旧を検査。全件・全国長期・例外の網羅は統合条件にしない。

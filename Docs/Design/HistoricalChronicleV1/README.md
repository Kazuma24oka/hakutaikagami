# 0c 事件の前提と年代記

0cの事件前提ゲートと本人の既知記録だけの年代記を実装。関連9件、通常入口の内部入力・実保存復旧・自前描画、旧保存270件のバイト一致が成功。

史実事件の個別データ30〜50件と各行動への候補登録は、関係する合戦・調略等の工程で追加する。今回の前提ゲートはそのための共通APIであり、未登録の史実事件を自動実行しない。家別表示は本人の認識済み証拠がその家を対象とする記録のみ。未採録の家の年表を生成しない。全件・全国長期性能・ユーザー試し遊びは未実施。

前提の真実と行為者の知識を分けて受け取り、両方が成立した候補だけに既存NPC評価の史実加重を付ける。許可・同意を作らず、本人の選択を上書きしない。仮想と1650年後の明示継続では史実加重を外す。実在事件の前提を架空の事実で埋めない。

時間操作欄の「年代記」から開く。本人の認識日時・分かる場合の発生日時・出典を表示。書状は開封後のみ、他人の年代記は除外。家の名前はその家について本人が認識した証拠がある場合だけ候補へ出す。表示は派生データのため保存形式の追加は不要。

最初の復旧単体検査は検証データのIDカウンタ不足で失敗し、正しいカウンタを設定して再検査に成功した。実画像で見つかった内部ID中心の文面も修正した。

# 評価通知・訂正・本人応答

独立AssessmentNoticeTrial、officer-assessment-notice-v1。評価者が知る返報・理由の発送時点の内容を固定し、版・前版・根拠書状を付けて重要封書で物理配送。未開封では本文と版を隠す。新しい根拠の後着は新通知を作り、古い封書を上書きしない。本人表示は知った版の最大番号を用いるため、古い原本の物理再送で巻き戻らない。

本人は開封後に受領確認か再審査希望を物理返送する。評価者はそれを受け取るまで回答を知らない。回答の受領だけで責任確定・処分・免責をしない。根拠は本人申告等の書状であり、世界の真実とは断定しない。主君の発送操作は検証用に明示した操作である。

新たな保存断面や時計は作らずMessaging/Knowledge/Evidenceを再利用。保存読込では版の連鎖・本文と根拠・発送時認識・応答者を検査する。下書きは保存しない。旧入口・旧保存・通常Mainを保持する。Scripts/verify_assessment_notice.pyとcheck_assessment_notice_binding.pyを使用。実PNG・保存はruntime-local。既存ローカル素材は公開しない。

通常起動画面への入口案はDocs/Proposals/MainEntryIntegration.patchに用意し、適用可能性だけ確認した。通常Mainへの変更は未適用。既存タブを保持して「武将の任務」タブを追加する3行の案で、通常起動への統合後の実動作は承認後に検証する。

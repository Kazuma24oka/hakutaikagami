# 兵種・天候地形・陣形・損害と陣中供給

1. 装備の実在在庫と受渡しで槍・弓・鉄砲・騎馬・輸送を編成し、火薬・玉・飼料を実消費する
2. 同じ世界時計で兵種別の接触・射撃と日ごとの天候・地形・視認範囲を反映する
3. 陣形を実際の作戦線・分隊位置へ適用し、負傷・戦死・逃亡を分けて兵糧による回復を行う
4. 寺社との条件付き武装協力と寺社への武力行使を本人の判断・実際の兵と供給へ接続する
5. 代表一巡・重大不具合・途中復旧・代表旧保存・通常3D表示を確認する

検査計画：実在装備・弾薬の上限と消費、視認と攻撃権限、陣形位置、負傷と回復の人数・米の保存、寺社合意、途中復旧と旧保存、通常画面。全件と全国長期性能は停止条件にしない。

# Claude担当への接続依存：傷病死

現時点のmainのFamilyMortality.Applyは、DateInYearに一致する自然死専用。FamilyMortality.Validateも同じ日時条件を要求する。傷病死をこの自然死記録へ偽装して呼ぶことはできない。Assassinationの致死結果も別の死因なので流用しない。

必要な接続は、健康側が条件ID・本人・発生時刻・処理版を渡すと、既存の死亡処理（本人の死亡確定、実行中行動の終了、訃報、後継操作への接続）を一度だけ適用する入口。医療側は傷病の原因・時点を版付き原本に記録し、死亡/後継処理は再実装しない。旧自然死原本の条件は維持する。

FamilyMortality・ControlSuccession・BD-07はClaude担当のため、Codexは変更しない。この依存が未解決でも、非致死の健康拡張は独立して進める。共有記録へはPR直前に自分の項目だけ反映する。

2026-11-13 担当更新：生活・健康はClaude担当に変更。Codexはここまでの診療コード（2ac898c9）への追加変更を止める。HealthPolicy/HealthState.Clinic/ClinicalHealth/病状報告/診療UIを作業ブランチに保存済み。実保存復旧を含む関連5件とGodotの診療一巡は成功。全国開始へのhealthPolicy指定も同コミットに含むため、Claude側のNationalSystems経由へ統一するときはこの明示指定を置き換える。残るNPC診療・致死処理の接続は未完了であり、健康枠の完了とは扱っていない。

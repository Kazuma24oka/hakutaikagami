# 傷病死の接続（2026-11-13）

危篤（重さ3）の傷病は、発症から7日を過ぎた最初の正午に峠を迎え、固定シード・年齢・峠までの手当で生死が決まる（Core/Contracts/HealthMortality.cs）。死亡は自然死と同じ記録（NaturalDeaths）に原因の傷病（Condition）を付けて残し、本人の死亡・行動の終了・訃報・後見・家督は既存の死亡の流れがそのまま扱う。暗殺の致死や自然死の日時の条件は流用しない。

- 有効なのは診療の版（ClinicalHealth）を持つ新規開始だけ。全国の開始でも有効にした。旧保存の自然死の条件は変えない。
- 危険：病25％・負傷20％、50歳を超えた分1年ごとに1ポイント、上限80％。峠より前に手当を受けていれば三分の一。
- 保存の検証：原因の傷病の峠の時刻と生死の判定を再計算して一致を確かめる。
- 残り：NPC が自分から診療を受ける判断は未接続。

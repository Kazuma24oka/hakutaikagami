# 健康拡張 V2

固定基準は本フォルダのapproval-baseline-v118.json。BD-06 30→65。新しい健康方針のみで、医術の治療・実完了時間と経験、移動と交戦からの疲労、重傷後の後遺症、戦場武将の負傷、危篤時の行動/裁決制限、観測時点付きの物理報告を接続する。本人とNPCで同じ制約を用いる。

旧健康v1の保存を読み替えず、追加台帳は新規開始だけに適用する。疲労・後遺症は恒久能力/技能経験から分離する。手当は即時全快にせず、実完了後の経験のみ加える。所属・役職・所領・預り物は自動移転しない。旧7技能の列挙を無断で増減しない。

PersonalHealth・共通時計・交戦原本を再利用し、戦略の判断やClaude担当の死亡/後継処理は変更しない。致死接続の依存はhandoff-to-claude.md。共通死亡APIがない間、致死部分は未接続と明記して非致死部分を実装する。全件検査はfullsuite.lockで排他し統合前の一度にまとめる。

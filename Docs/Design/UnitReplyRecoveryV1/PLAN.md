# 次工程：返書自身の不達回復（未実装）

既存の返書原本/初回不達を不変に保つ。返書の受取人が不在なら、その不達報告を匿名伝令が返書発送時に知る部隊の所在地へ実際に持ち帰る。受信役が直近不達を実受領した場合だけ共通MessageFlowで最大3便の同じ原本を再送する。宛先は書状発送時の既知本人所在であり、真の現位置へ追跡しない。部隊も移動して不達報告が届かなければ、自動で失敗を知ることはない。旧保存へ自動の再送を遡及適用せず、新しい照会原本へ省略可能な配送方針を明記してから適用する。受信役の判断/往復経路/匿名運搬役/共通正式受領/返書の時点内容を保存して、元の不達台帳を変更せず、同じ未来と3Dを検査する。次は実物保持された便の遅着回収と競合へ続ける。ユーザー判断が必要な根本変更がなければ継続。

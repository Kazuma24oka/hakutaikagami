# S07B 全国の家の内政（Domestic2V1）

基準：Docs/Development/ProgressV1/approval-baseline-v161.json（実装の前に固定）。一覧の Domestic2 の新規の全国開始だけ。今の保存は変わらない。

遠方の家は日々の細かい仕組みでは眠っている（NpcDormancy）ので、全国の家の内政は、全国の家の戦略（NationalStrategy.Apply）の月の初めの計算で行う（Core/Contracts/Domestic2.cs）。

- 方針と専門職：当主が毎年1月に方針（農・商・軍備・普請・倹約）を決め、家老・郡代（国ごと）・勘定奉行・普請奉行・目付・取次・寺社奉行・代官（拠点ごと）を家臣の技能で置く。
- 家計：10月の年貢（石高×率×作柄×被害×働き手）、毎月の銭、給付と軍勢の按分、緊急の救済の転用と補償、赤字が続いたときの給付の削減か借銀、余りの払い出し。
- 監督：代官→郡代→目付・勘定奉行→当主。不正を見つけた知らせが当主に届いた時に罷免する。
- 生産：職人集団（鉄砲鍛冶・石工・灰吹・金山）が歴史の設定に従って現れ、鉄砲・火薬・硝石・金銀・軍馬を作る。原料が無ければ作れない。5年で本拠に弟子が分かれる。
- 災害：台風・大雪・地震・作柄。被害が拠点に残り、普請奉行が直す。知らせは道のりに応じて遅れて届く。
- 徴募と逃散：出陣の兵は拠点の働き手から集め、決着の次の月に討死の分を除いて帰る。同じ拠点を二つの出陣が求めたら、くじで一方に出る。
- 一揆：嘆願→労働の拒否→逃散→連合→一揆。領主（不在なら郡代・家老）が救済・鎮圧・減免を選ぶ。年貢の布告は届いた時から効く。本願寺の檄、同盟の家への救済。
- 寺社：大寺社17の寄進・安堵・禁制と違反、楽市での権益の侵害への段階的な抵抗、譲歩、僧兵の加勢。
- 破壊の計略：軍備の方針で戦う家の放火と、目付による発覚。
- 幕府職：1560年・1467年の在職、探題・管領代・侍所・政所・御相伴衆・国持衆・准国主・申次衆の補任、探題の和睦と加勢、関白・征夷大将軍の奏請。与姓・偏諱。
- 口入れ：本人のいる拠点の仕事（書状の使い・買付納品・道中の護衛・賊の討伐）を一つの口にまとめる。探物は名物（S08）の後。
- 本人が当主なら、人物の画面で方針と年貢を決められる（WorldSession.DecideDomestic）。家の記録（家系・歴代・家格・帳面・役）を人物の画面に出す。

記録は毎年1月に、一年より前のものを間引く（一揆・檄・寺社・和睦・奏請・職人・楽市・譲歩と、家と国ごとの最後の布告は残す）。

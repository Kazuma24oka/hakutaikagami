## プレイヤーの流れ

新規通常開始の当主は『不戦交渉』で相手と1〜90日の期間を選び、署名した提示を相手の既知の本拠へ送る。提示の段階で同盟や平和状態を生成しない。相手当主は実際に届き開封した後に返答する。相手が本拠を離れていれば届かない場合があり、現在地へ自動追跡しない。

初版のNPC判断は『30日を超える拘束を避ける』という明示した共通の調整方針。30日以下は同じ版へ承諾し、長い提示には30日の第2版を返す。史実人物固有の性格/高度な戦略AIとしない。対案はプレイヤーが開封し、その版に改めて承諾する必要がある。辞退もできる。未開封の対案の版/期限を名簿や選択肢へ漏らさない。

本文の版は原提案・親の原本・当事者・始期・終期・返答期限を持つ。返信期限は到達基準で最長7日、短い提示では期間の終わりまで。同じ版への双方の署名が当事者へ到達した時点を成立とし、効力は成立/始期の遅い時刻以後。書いたことや発送だけでは成立しない。対案は元の署名を別の版の承諾へ流用しない。

最後の承諾を受け取った当事者は、開封して成立を認識した後に成立確認書を相手へ送る。相手もその確認書を受け取り開くまで、最終到達を知ったことにしない。本人が成立を知るまでは、成立前の認識を勝手に更新しない。

## 効力と既存の軍務

合意の履行は本人が認識した範囲で始める。自家の現在の敵対意思を自家の権限で撤回し、その変更も従来の方針通知へ渡す。他家の意思や過去の開封済み書状を上書きしない。認識済みの不戦期間中は新しいNPC出撃/先制攻撃の任務根拠を抑える。実軍の名簿/兵糧/位置は維持し、既に出た軍を瞬時に本拠へ戻さない。既存軍は道路上の行動境界から帰還へ進む。

実際に引き受けた100人の部隊、実在当主の開封済み交戦許可、再度の敵対表明がある代表例でも、不戦を認識した対象への許可を有効な攻撃根拠から除くことを検査。相手の攻撃への即時自衛を一律に禁止する変更は入れず、既存交戦/自衛の回帰検査も実行する。この例は戦場での停戦交渉の見た目を認定したものではない。

過去の交戦履歴を再計算するときは、その時刻・版・本人開封までの交渉状態だけを見る。後から届いた成立確認で過去の損害を変えない。新規通常開始だけTrucePolicyを明示し、旧null版保存/開始hashを維持する。

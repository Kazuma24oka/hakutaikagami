# 全国の認識済み実効支配色 V1

初期の郡支配原本を変えず、本人が開封した落城報告または自ら発信した報告の範囲だけを、城の実効支配から表示する。NationalStrategy.Ownerを参照し、同刻の未認識の別結果が上書きしている場合は読んだ報告の持ち主を保持する。未着・未開封・敗報から第三者の支配を公開しない。戦略の判断・外交・出陣・Outcomesには変更を加えない。

郡内の城を基に塗り分け、並立は帯で示す。全国画面の城の印も同じ認識状態から更新する。近代地図の羽前/羽後を出羽、陸前/陸中/岩代/磐城を陸奥へ対応付け、分割郡と史料の郡を結び付ける。これは表示上の推定であり所領・石高や現金収入を変更しない。

代表3件19秒・ゲームビルド・開封前後の自前描画は成功。全件検査は共有ロック待ち。未実施を成功として扱わない。詳細はverification.json。共有進捗はPR直前にmainを取り込んでから更新する。

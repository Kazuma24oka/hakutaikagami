# 成果から陸路点検の担当へ

完成条件：1. 主君の開封済み履行評価と現地面会を条件に、担当・一件20文の手当を提示する。2. 本人の明示引受で同じ主従期間・拠点に限った担当を保存し、表示する。3. 引受後に発行された同じ主君/拠点の点検命令だけに20文の債務を作り、完了報告・評価開封後に実在の私財から一度だけ払う。4. 辞去で担当は終了するが既発行の条件と未払いは残り、保存復旧と実画面が一致する。

政治上の役職・城・徴収権・軍事指揮権は与えない。現地で提示された役目を本人が引き受ける相互合意として記録し、遠隔の任命通知を省略する手段にしない。20文は試作値。旧保存は新しい任命欄を省略でき、旧任務に手当を後付けしない。役職昇進・俸禄制度全体とは別。

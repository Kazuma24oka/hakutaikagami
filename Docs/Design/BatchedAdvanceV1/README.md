## 境界
速度は希望する進行率であり、計算量によって実際の進み方は変わる。区間は概ね選択速度の0.2秒分を基準に積残しを含め、一回で選択速度の1秒分以下とする。特に高速では世界の表示更新は粗くなり得る。全速度で固定fpsや選択率の常時達成を保証しない。

通常の判断・初回開始/ロード/QAチェックポイントは別工程。1000人は静止した架空登録人物と選択本人の移動で、全国自律NPCや多数同時合戦ではない。保持ゲートは競合の正しさだけに使い、通常動作の性能根拠と混ぜない。再生用内部フックは公開要求の時刻を与えるだけで、私有未来の世界や結果を注入しない。

9つの旧入口/材質/基本起動試験は今回再実行せず、関連実装/アセットの入力が変わったら限定再利用を拒否する。動画は保存点と実180描画フレームの確認で、実時間性能のベンチマークではない。

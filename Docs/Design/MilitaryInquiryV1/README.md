# MilitaryInquiryV1

軍務の条件/許可/返還通知が不達でも、物理照会の返書から本人の認識を回復。原本の受領記録を捏造せず、現地引受は別のまま。本人が不達報告を知った軍務書状の原本再送と、回収した原本との二重到達を既存の配送へ接続する。

正本：[DESIGN.md](DESIGN.md)。実行 Scripts/verify_military_inquiry.py → 実画像点検 → Scripts/check_military_inquiry_binding.py。マウス操作なし。4ケース24保存点/48画像・全世界比較。

最初の単体検査で道路配送が時計だけの遅着を拒否したため、その禁止を維持し、失敗地点・局所地形経路・受令者の実所在を持つ回収台帳を追加した。未着通知を一覧に期待していた検査と、時刻進行による部隊Revisionを所有移転と比較した検査も、実際の情報/所有契約へ修正。比較許容は緩めない。

回収の実証は清洲の距離0の局所引渡し。非ゼロ回収経路/長距離/海路/発見確率AI/一般書状の回収は未実施。再任・交戦・給与は追加しない。旧開始・旧保存・原素材・通常初期表示・保護ブランチは保持。

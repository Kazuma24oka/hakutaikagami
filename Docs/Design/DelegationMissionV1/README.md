# 他家演習軍の明示指揮と別返報

共同演習の開始を追加。org:house/army:clerkの所有と主従を保持し、架空の合意に基づき対象3部隊の配置・保持・帰還だけを一時指揮する。織田家への移籍、私有兵、他隊交戦、再委任の許可は作らない。

軍議で知らされた営地または本人の観測/受領報告による位置へ伝令を送る。NPCの真の位置を追尾しない。私的な拒否意思を送信前の可否へ出さず、受領時に判断する。受令判断だけの返報と、目標到達後の自己申告を別の物理書状で送る。未知の結果/敵情報を画面へ出さず、責任・処分は未審査のまま。

新しい計画は本人が送った直前の計画を差し替える。中間版が不達でも後続の自足した指示を受けられ、実経路で遅れて到達した祖先の原本を再実行しない。時刻だけでコピーを出現させず、長い経路の原本と、本人が野外へ出て近くから送る差替えを使って検査する。

到達申告は受令時に保存した目標・経路・予定時刻と自隊の損害台帳へ結ぶ。発送後に別の命令を出しても本文を更新しない。受領報告の位置は古い報告時刻で表示し、新しい直接目撃を巻き戻さない。行動中断理由と返報不達の照会/再送は次工程。

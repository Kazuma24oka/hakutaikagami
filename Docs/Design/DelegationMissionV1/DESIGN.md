# 他家軍の所有を保つ一時指揮

BD-10/11/12/38。既存の別働隊はorg:house/army:clerkであり、織田家の兵へ移籍しない。新たな共同演習開始だけに、当該家の主権者/本人/受令武将が知る架空の開始合意を定義する。所属、直属主君、私的忠誠、物資所有を変更せず、配置・保持・帰還の指示を出す範囲だけを付ける。交戦や他軍への再委任は不可。

継続世界を使い、本人が在所でも伝令と他隊が同じ時計で動く。別働隊は共同演習の営地で待命する初期条件。営地は軍議で通知された既知の配送先であり、NPCの真の現在地を追尾しない。服従意思は送信前のUIへ出さず、本人の受令判断で拒否され得る。

新しい計画は送信済みの直前の計画を明示的に差し替える完全な指示。相手が親を未受領でも自足した新指示を実行でき、後続が適用済みなら祖先の旧原本が届いても戻さない。実配送経路が長い旧原本と、本人が野外へ出て近くから送る差替えを同じ時計で試す。中間版の不達も試す。単なる遅延タイマーで原本を再出現させない。

受令時には受令判断だけを返す。別働隊の全対象部隊が目標に到達し、その指示の移動が終わった後、別の到達報告を送る。受令時の経路/目標/予定到達時刻を保存して早すぎる到達申告を拒否し、到達報告は発送時の自隊スナップショットを固定する。敵の隠れた数値を混ぜない。報告は本人申告で、責任・処分の確定ではない。

受領した自隊到達報告だけを古い報告時刻の位置情報として地図へ重ね、より新しい直接目撃を巻き戻さない。伝令不達や移動中の停止で到達報告がなければ「未確認」のままとし、不服従・罪を推定しない。行動中断理由の自発返報や不達の照会/再送は次の小段階で扱う。

# 下部会話帯 V1

ユーザーは画面占有を抑える下部会話帯と左右の顔アイコン案を試作承認。地図を残し、相手は右/自分は左、話者を明るくする。選択時だけ用件の要点と返答を帯のすぐ上に表示する。以前の全画面の会話画面は通常の仕事表示から置き換える。

完成条件5件：
1. 通常の会話帯の高さは画面の約22%（検査上限26%）。地図を暗くせずに保持。3Dから直接描画する左右の顔アイコンを用い、相手の台詞/自分の返答で明暗と話者名が切り替わる。
2. 台詞は自動で消さず、明示操作で選択欄を開く。場所/期限/報酬と返答は同じ小枠に集約。選択欄は帯の上で重ならず、帯と選択欄の合計面積43%以下。詳細ログは履歴へ。報告時も結果を同じ位置で確認する。
3. 自分の返答を選ぶと左のアイコンが明るくなり、返答を読んで「続ける」を押すまで命令/受諾を確定しない。相談取消/閉じる/保存復旧で未確定の返答を勝手に実行しない。引受後は既存の地図上の仕事枠へ戻す。Core/配送/期限/返報は維持。
4. 任意依頼/主君の命令、1280×900/1100×720の実画面、保存復旧、選択前の世界不変、実受諾と実返報を検査する。全世界/実画像/左右顔の骨格/外見/表示文を照合。317のCore入力/TRX/DLL完全一致時だけ以前の2122件を再利用する。
5. 実画像と短い実録画を直接確認し、検証した実装を同じブランチへcommit/push。main/design、既存素材/保存を保護。マウス操作/OS入力設定変更はしない。

## 範囲
顔アイコンは現在の3Dモデルを別の小さい描画領域で直接描画する。新しい画像生成、表情差分、専用立ち絵は未作成。右の顔は話者を示す肖像で、地図上の相手の在席・現在地を示すものではない。相手不在時の書状は話者名に書状と明記する。
会話の開閉/選択枠/未確定の自分の返答は一時的UI。世界への正式入力や保存データを増やさず、ロード後は保存された本人の知識から用件を再表示する。報酬/評価/新しい点検情報/巡回モーションは今回追加しない。
選択時だけ一時的に表示面積が増える。履歴はユーザーが明示的に開く別画面であり、通常の会話帯の面積上限の対象外。録画は実コード/シーン/データ/DLL一致のコピーでviewportだけ変更し、固定30fpsで記録。実時間の速度測定ではない。

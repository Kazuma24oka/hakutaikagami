# 全国の京の朝廷と将軍家 V1（BD-53・BD-54・BD-55・BD-56、2026-11-13）

全国1560年の開始で、京の取次・将軍家の取次・将軍との往来（奏請・系図・守護職・栄典・追放・擁立）を使えるようにする。

- 版：全国開始の版を `hakutai-1560-national-v2` に上げた（新規開始だけ）。v1 の保存は朝廷の人々を持たず、京の往来も開かない（旧保存は変えない）。
- 朝廷の人々：百代鏡DBの家「朝廷」（G-000241、城なし）の29人を、家に属さず兵を持たない人物として二条御所の拠点に置く。
- 京の取次は朝廷の公家それぞれ（天皇を除く）。本人が最後に会った公家へ奏請し、その公家が本人との関係で引き受けるか断るかを決め、引き受けた公家が朝廷へ提出する。地方開始の版では山科言継だけ。将軍は足利義輝、将軍家の取次は将軍家のうち二条御所にいる当主以外の筆頭（名簿の順）。京は二条御所の拠点。地方開始の版の人物・拠点はそのまま。
- 将軍職：全国の家の戦略で将軍家が城をすべて失えば将軍職も空き、京の主が将軍家の成人を擁立すれば、その人が将軍になる（奏請による補任が後なら、そちらが優先）。
- 近衛前久は百代鏡DBにいないため、猶子・関白の往来は全国では開かない。堺の寺社代表も置かない。

## 確かめたこと
- 全国の新しい版で、朝廷の人々が二条御所にいて家に属さないこと。v1 の版は変わらないこと。
- 足利義輝が京で山科言継に会って進物を贈り、従五位下を奏請すると、取次が（日課の仕事を終えてから）引き受けて朝廷へ取り次ぐこと。朝廷の審議（二か月）と返書は地方開始の版の検査で確かめ、全国では未実施。保存から戻して同じになること。
- 全国の家の戦略の空位・擁立が京の将軍職の判定に効くこと。

## 残り
- 京・堺の仲裁の往復（和睦交渉は実際の軍勢の世界が前提で、全国ではまだ開かない）。
- 公家は日課の仕事で出払うことが多く、検査では山科言継以外の公家に会う一巡を確かめられていない（未実施）。
- 遠方の人物が京まで上る旅程の作り込み（今は城の移動網の道で行く）。

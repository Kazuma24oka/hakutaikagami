# 個人の直属合意 V1

## 固定した完成条件
1. 継続協力と実仕事/開封した返報・未払い解消を確認し、無所属の成人本人の合意を得る。
2. 個人間の実ServiceBondを作り、組織所属・土地・兵・指揮権・私財を移さない。
3. 手当契約の終了と直属関係の解消を分け、未払いを消さず、直属解消後も過去の合意を保持する。
4. 実世代復旧後も主従・会計・今後の仕事・配置データが一致し、旧保存には新しい権限を足さない。

新規v3限定。浪人も個人的な直属配下を持てる既存方針の最小一巡。独立・家督への政治的支持、他家家臣の離反、組織加入、軍権や兵の引渡しは別案件。既存の単発協力の成功だけで自動加入しない。

## 合意の流れと効力

継続協力している無所属の成人と仕事を完了し、本人から届いた返報を開封する。未払いを解消したうえで現地で相談し、本人が引き受ける条件を確認して直属合意を結ぶ。追加の加入料はない。単発の仕事や支払実績だけで自動的に主従関係を付けない。合意を選ぶ前は世界/主従/金銭を変更しない。

原本から実際の人物間ServiceBondを投影する。浪人のプレイヤーも個人の直属配下を持てる。相手の個人財産・知識・組織所属・役職・土地・兵・軍権はこの合意では移らない。プレイヤーが後に大名家へ仕官しても配下の組織所属を自動で転記しない。指揮権や徴収権を新しく発行しない。

一日20文の協力手当は従来の契約として独立して続く。手当契約を終えても直属関係は自動消去しない。直属関係を解いても手当契約や未払いは消えない。現地の仕事が進行中なら先に終える。直属の解消は現在の時間区間モデルに合わせて合意より後のゲーム秒で扱い、同じ秒での即時解消は拒否する。解消後も終期付きの関係履歴と支払原本を保持する。

## 制限と再現性

他家の家臣や、元から直属がある者をこの手順で引き抜かない。組織所属のある者、役職者、未成年、協力意思がない者、未払い/未完了の仕事がある者には成立させない。主従循環も拒否する。意思は既存の静的な協力可否による限定試作であり、性格・忠誠・利害の一般比較ではない。

原本の人物/時点/版から主従を再構築し、無根拠の主従追加・相手すり替え・加入料の差替えを拒否。古い操作版を拒否し同じIDを再送しても関係を増殖させない。過去の軍務を検査する際は未来の直属合意を除いた主従投影に戻す。旧v1/v2保存bytesを維持し、新しい主従行為は追加しない。

通常入口は新規v3を使用。既存の同行者/配下画面に「個人の直属として加わってもらう」「直属関係を解く」を追加し、手当契約と区別する。確認には本人の現地返答と同じrevisionを使用。画面の外観は未確認。

独立宣言への政治的支持、派閥、旧主への辞去/離反、露見/処罰、軍権・城門引渡しは別の後続案件。R4全体完成とはしない。キャラクター素材/形状/外観の採用状態は変更していない。

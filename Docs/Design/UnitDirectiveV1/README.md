3. 不達・期限切れ・経路不成立・旧指示・権限終了を受領時に判断し、返書を本人が物理受領するまで結果を通常画面へ漏らさない。返書不達の報告と再送は当該隊を使い、一つの原本を二重実行しない。
4. 任意の新項目を省略した旧JSONを保持し、全ロードで原判断・対象隊・経路・書状を再計算する。三隊と部分取消の32保存点を別プロセス復旧し、全世界・本人・認識・3D表示と同じ未来を照合する。

## 境界と次工程
分隊指示は新しい受信役と任意台帳で旧全隊命令から分離する。旧の再送・取消UIを分隊原本へ流用しない。分隊原本を指定した手動再送・取消は次工程。未発行の地図指定ジェスチャーは既存の配置線と同様に保存対象外で、発送後の原本・選択隊・表示を保存する。80m視認・120m演習範囲・600秒通常期限は試作値。全国性能や最終背景品質は今回の合格に含めない。

次の5件：本工程の検証/push、分隊別の再送/取消、実在勢力の権限接続、全国負荷、通常プレイの操作整理。ユーザーの創作判断が必要になるまで技術作業を継続する。

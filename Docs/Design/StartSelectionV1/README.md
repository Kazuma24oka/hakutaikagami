# 通常入口の作成人物開始

既存WorkHubの初期表示と二つのタブを保ち、三番目の「作成武将で開始」を追加する。1560年清洲・成人浪人・準史実既定の限定開始。名前はCoreで検査し、StartPackageを検査してから実世界を開く。六立場や史実人物がすべて遊べると表示しない。未接続の歴史誘導や立場を選択可能に偽装しない。

開始世界の内容ハッシュ/保存用インスタンスIDごとに別のフォルダを作り、同名・同Seedの新しいプレイも既存進行を上書きしない。保存用IDはファイルの分離用で、世界内の人物や要求のIDに乱数を入れない。開始包は新規作成のみ、既存メタデータは上書きしない。保存した進行がある人物だけを一覧に出し、名前/経過時間/開始日時で識別する。開始包を再検査し、選択後の変更と破損を拒否する。読めないデータも削除しない。

設定へ戻るだけなら同じセッションを保持して処理を止める。未保存状態の破棄を伴う新規開始や別の保存への切替はゲーム内で確認する。取消では旧世界を維持する。新しいシーンの初期化/復旧成功前に旧世界を解放しない。

作成人物かどうかは明示的な開始定義を優先する。Godotが同名ノードを自動改名しても別プロフィールへ変わらない。通常入口の既存NPC世界と新人物世界は試作として別世界/保存であることを既存見出しで維持する。

自動検査は専用保存Rootを用い、ユーザーの保存へ書かない。無効名・開始・依頼5保存点・別プロセス復旧/続行・戻る/同じセッションの再開・非表示の自動進行停止・切替取消/確定・別名/同名の保存分離・破損開始包の保持を実Godot信号で検査する。新UIの10比較と直前の56比較を同じ実行物で結合する。HTML/動画は今回は不要。

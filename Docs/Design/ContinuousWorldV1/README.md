# 全国・連続地形の確認

起動：Scripts/Show-ContinuousWorld.ps1。通常Mainは切り替えていない独立した試作入口。

- 「全国」「現在地・地域」「現在地・詳細」、ホイールで同じ世界の表示範囲を変更。
- 詳細表示では地面を左ドラッグして自隊の布陣線を指定。中ボタンで視点中心を動かし、「現在地・詳細」で本人へ戻る。
- 「自動進行」または「1秒」「10秒」で進める。「別働隊へ命令」は即時遠隔操作ではなく、伝令が現地へ届いて相手が判断し、返報が戻るまで結果未確認となる。
- 「境界を越えて布陣」「橋の対岸へ」「自隊・接敵」「帰還」は試作用の固定地点ショートカット。連打で全命令が成功するという保証ではなく、通行・占有・戦況によって保留される。
- 街道へ出るときは「帰還」して各分隊が帰着するまで進め、配送も終わってから「拠点に入る・野外へ」。行先を選んで「行先へ出発」。到着後に野外へ展開できる。世界時間・損害・他武将・過去の目撃は保持する。
- 「保存」「復旧」で世代保存。復旧時は停止する。「再開・停止」または「自動進行」で再開する。「背景表現切替」は描画だけを変更する。「素材比較」は外観IDの対応表から道の材質・岩モデルを交換する。

地形は全国の概略陸海マスク上に生成する合成地形。108拠点118経路は既存ネットワークを再利用しており、全ての日本の城や史実地形が完成したという意味ではない。詳細は表示幅240m以下・最大25区画、遠方は概略地図。中間倍率の立体地形LODは今後の改善事項。

検証：Scripts/Show-ContinuousWorld.ps1 -Verify または verify_continuous_world.py。全Core、move/order/combat/rout/refuse/bridge/scale/north/kyushu/travel/coverage/assetsの12ケース、別プロセス復旧、実GPUでの108拠点巡回、画面比較、26秒動画を生成する。生成後は実画像を確認してverification.jsonのvisual_reviewへ証拠SHAと所見を記録する。check_continuous_binding.pyが現行ファイルとの一致を確認する。runtime-localはローカル証拠でGitには含めない。

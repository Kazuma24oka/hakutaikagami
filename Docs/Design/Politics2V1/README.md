# S09C 外交・家中・国人の交渉（Politics2V1）

基準：Docs/Development/ProgressV1/approval-baseline-v165.json（コードを書く前に固定）。一覧の Politics2 の新規の全国開始だけ（Domestic2・Persons2・Armies2 を使う）。今の保存は変わらない。

- 約束の条項：同盟に「共同の出陣」（1年）・「不可侵」・「単独で和睦しない」（約束の期限まで）。境を接し力が3倍以上に開いた同盟は、強い側が従属への変更を求め、弱い側が受けると同盟を解いて従う。
- 本人への申し入れ：本人の家と境を接し、共通の強い隣を持つ家は、年に一度、書状で同盟を申し入れる。本人は人物の画面で受けるか断るかを決める（WorldSession.AnswerProposal）。
- 多者の和睦：この3か月に三家以上が攻め合っていれば将軍が呼びかけ、京から届いた家ごとに受けるかを決め、受けた家どうしが一年の和睦を結ぶ。
- 官位の願い：取次がいて銭のある家の当主は、朝廷へ願い（300貫）、京への道のりの後に従五位下を許される。
- 制裁の現地履行：裏切られた家の同盟の家は、裏切った家との隊商を2年通さず、裏切った家の銭は毎月5%減る。
- 従属の条項：毎年1月、従う家は主へ銭を納める（自治の強い家は5%、ほかは10%）。納められない・加勢の命を断った家は違反で、主は3倍以上強ければ従属を解いて攻めの的にし、ほかは抗議する。
- 婚姻と養子：同盟で成人の夫婦ができなかった家は未成年を婚約させ、15歳で輿入れし、道のりの日数の後に夫婦になる。成人の後継の無い50歳以上の当主の家は、強い同盟の家の当主の次男以下を養子に迎え、後継とする。
- 独立の伝達：独立の宣言は元の家の軍団長に道のりの日数で届き、一族でない軍団長は半々で独立した家に付き、その兵が独立した家の力になる。
- 派閥：家中の一門・譜代と外様の支持。勝てば譜代、城を失い給付を削れば外様へ動く。軍備の家の流言は敵の外様を5動かす。外様が6割を超え当主が若いか病なら、従う家の離反が10%から15%に上がる。
- 辞去と転籍：給付を削った家・裏切りの主の家臣は月に2%で辞去して主のない人になり、人手の足りない家に召し抱えられる。給付を削った家・裏切りの主の誘いには応じない。
- 捕虜の交換：互いの家の者を捕らえている二家は一人ずつ交換し、境で受け渡す（交換された人は捕らわれでなくなる）。
- 偵察と流言：出陣の判断は相手の力の見立て（年ごとの±20%の誤差を目付の技能で小さくする）を使う。目付のいる家は3か月ごとに境の敵を偵察する。

外交の計算そのものは1か月あたり約18ミリ秒。全体の時間の差（19か月で約4秒）は、従属への切り替えなどで世界の動き（出陣の数）が変わったため。

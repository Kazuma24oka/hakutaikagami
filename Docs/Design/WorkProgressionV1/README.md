# 成果が次の仕事につながる

地域一巡の基盤検証を終了し、機能追加を主とする。毎回の全件/GPU全組合せの再実行を原則にせず、変更範囲のテスト・代表画面・保存復旧を確認する。広い共有変更や未知の不具合がある時だけ範囲を広げる。

## 完成条件

1. 依頼主が実到達した完了報告と点検記録を認識して、履行を認める評価書を送る。
2. 本人が評価書を開くまで次の依頼への反映を漏らさず、同じ評価書の再開封で加算しない。
3. 同じ相手の評価を受けると小口運搬100文/運賃20文から、200文/30文の仕事を相談できる。旧契約を後から増額しない。
4. 保存復旧と実画面で評価→次の仕事を確認し同枝pushする。

新しい開始のWorkPolicyだけをV2にする。旧保存/旧Policyの受領確認・100文の運搬は保持。履行を認める判断は依頼主の受信済みの報告と記録に基づく。責任裁定、昇進、一般の人物能力成長まで完成したという意味ではない。金額は試作値。

# S11 画面と文面の仕上げ（ScreensV1）

基準：Docs/Development/ProgressV1/approval-baseline-v169.json（コードを書く前に固定）。新しい振る舞いは、一覧（NationalSystems）に Screens2 のある新規の全国開始だけ。今の保存は変わらない。中心は Core/Contracts/Screens2.cs、画面は Game/Scripts/NewGameRuntime.Screens2.cs。

## 遊ぶ人から見て
- 上の欄の「帳面」から7つの面を開く：書状・人物・判断・約束・家督・軍勢・表示。
- 書状：届いた書状と出した書状を種類（家・軍・外交・家族・報告・仕事・その他）で絞り込む。開いていない書状は中身を出さない。不達は、本人が不達の知らせを開いたものだけ。
- 人物：本人は5能力と6分野32技能の値・経験、出自の手がかり、成長の理由（任務の区切りでまとめる）、療養中にできること（面会・書状・政務・移動・武芸・修行と、できない理由の健康・権限・拘束）、教育（家の方針・師・学んでいる技能・中断・教師の見立て・元服の振り返り）。他人は評判と面識からの推定と、同じ場で見た病状だけ。
- 判断：知っている危機（敵の接近・本人の病・包囲網の誘い・出陣の機会）ごとに対処案を並べる。判断支援が「詳しい助言」なら準備・時間・代償・根拠・不確かさ、「要点だけ」なら時間と代償、「自分で判断」なら案の名前だけ。危機の中身と警告はどの設定でも同じ。
- 約束：家の約束（当主だけ、同盟・和睦）と、私の約束（村への約束・出陣の見合わせの約束・出陣の約束）を分ける。
- 家督：当主・後見・知っている子（年齢・養子・元服の年・後継）。当主は後継の指名と隠居に入れる。
- 軍勢：家の出陣中の軍（主の線・二の線）、本人の軍、命じた軍団。当主は国と率いる人と優先度を選んで軍団に出陣を命じ、月の初めに優先度の小さい命から、その国の境に攻められる城があれば一つだけ出陣する。
- 表示：文字の大きさ（16〜30、会話にも効く。ゲームの外の設定ファイルに保存）。
- 時間：本人が開いた訃報と、本人が知った重い病状（本人の重傷・危篤の始まり、開いた病状報告の重傷・危篤）で、時間の設定に従って止まるか遅くなる。設定の画面に「重い病状」が加わる。
- 開始の設定：ルールのコース（標準・史実のとおり・波乱・穏やか）と、5つのつまみ（史実の事件・脅威への敏感さ・捕縛・戦傷・出生、低い・標準・高い）。標準は前と同じ値。
- 史実の機会：本人が当主の家が史実の出陣の攻め手で、相手と境を接していれば、家中の者（本人と同じ城の者を先に）から上申の書状が届く。応じれば翌月の初めに出陣し、その時に相手と約束があれば競合で不発、断れば見送り、答えなければ流れる。
- 呼び方：宛名は目上「様」・同格「殿」・目下「へ」、結びは「恐惶謹言」「恐々謹言」「謹言」。職名は幕府職・守護・官途・家中の役・当主の順。会話の名前と書状の宛名で同じ関数を使う。
- 会話：立ち絵（res://Assets/Portraits/〈人物〉.png）と背景（res://Assets/Backgrounds/〈場面〉.png）の差し替え口。絵が無ければ今の仮の絵。Enter・Space で送り、Esc で閉じる。

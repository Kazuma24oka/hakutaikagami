署名者・宛先・期限を固定した確認書と返報の36件が成功後も続行。返報自体が失われた場合、NPC差出人が実際の不達返報を受け取ってから、同じ観測日時・内容・根拠・宛先で合計三通まで再送する。過去の事実の写しであり、新しい政治合意ではない。実装前基準28を保持して29へ追加し、重み・分母・既存評価は変更しない。

## 原本と認識の区別

- 現当主の政治署名と、隠居本人などの現地手配依頼者を別記する。元の組織間不戦合意を確認するだけで、旧承諾書の宛先・成立条件・元期限を変更しない。
- 既知の相手代表と本拠を固定する。相手代表が変わっていれば再確認を必要とし、未知の新代表や現在地を使って自動追尾しない。
- 相手への物理到達・本人開封の後だけ認識を更新する。受領返報は明記した依頼者へ戻し、差出人本人が知った不達も別の返報で依頼者へ届ける。実際に届いた返報を本人が開封するまでは、現在の遠隔到達状況を表示しない。
- 確認書原本の再送は、現地の現署名権者の同意と依頼者の既知不達を必要とし、同じ元期限・本文・宛先で三通まで。受領返報を知ったら原本の追加再送を止める。
- 受領/不達返報の写しは、NPC差出人が実際の不達返報を受け取ってから合計三通まで送る。観測日時・根拠・既存署名・宛先を固定し、新しい政治的約束として署名し直さない。本人を自動操作しないため、本人差出人の返報再送操作は後続。
- 原本の遅着は、既存の失敗伝令の実位置・80m以内の実地経路・受取人の現地所在を使う診断上の回収で再現する。タイマーだけの遅着注入は許可しない。回収はプレイヤーの遠隔追跡操作ではない。
- 原本と再送分の双方が到達しても、同じ成立原本の返報・履行を繰り返さない。期限後に届いた原本や返報も、古い合意の記録として保持し、不戦期間を延長しない。
- 受信箱から下部会話へつなぎ、履歴は短い説明にする。検査はCLIと画面なしGodotのデータ照合。外観・GUI操作の合格ではない。

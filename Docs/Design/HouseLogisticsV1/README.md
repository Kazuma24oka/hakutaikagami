# 家の資金を預かる長距離仕入れ・帰還精算

仕入れ/運搬は新規v10以降、代理受領は新規v11のみ。現地の当主と本人（当主自身または直属家臣）が仕入先・品目・数量・前渡金・30日を合意する。家の現金を別の預り金へ実移転し、家全体/代理官と同じ月次調達枠を使う。私財と混ぜず、遠隔地の現在在庫や相場を提示しない。

本人が既存経路で仕入先へ実移動し、現地在庫と実価格を再確認して買う。預り金が足りなければ待機/引受返上。100kgの既存携行枠を共有し、個人取引との二重利用や家の荷の私的転売を許さない。本人の操作を自動化しない。

帰還先で当主と現物受渡しし、家の蔵へ品物と余金を実移転する。一度だけ完了し、私的報酬は生成しない。道中の本人による返上・30日超過・権限喪失では新規購入を止め、預り金/荷物/返却義務を消さない。古い受領先/所有者へ勝手に付け替えない。遠隔取消配送の一般化やNPC隊商は後続。

完成条件はapproval-baseline-v9.jsonの5件。旧v9保存・旧UIを変更せず、実保存復旧/将来一致/画面なしNode3Dを検査。外観/UI操作は未確認として分離。

## 現地代理受領への拡張（実装前固定）

当主不在で帰還精算だけが停止するため、同じ一巡に現地代理受領を追加する。新規v11の限定行政委任を合意する際に、家の仕入荷と未使用前渡金の受領も含むことを表示する。受領先の家/拠点と所有権は変えない。現地にいる有効な同一代理官だけが受け取り、取消の物理受領後・期限後・不在時は拒否する。代理官の私財へ入れず、元の家の現物/金銭台帳へ入れる。

受領証拠には受領者・観測日時・権限原本を固定し、後から当主や別代理官へ書き換えない。v9の実装前基準は保持し、v10集約基準から同じ承認後の実装増分を計算する。元の当主受領は残し、過去保存を自動拡張しない。

### 保存版の分離
当主受領だけのv10を保持し、代理受領は新規v11だけで明示有効にする。受領者指定/受領証の追加項目は旧v10では省略し、当主受領の保存バイトを保持する。通常の新規開始はv11、旧保存は自動昇格させない。

検証範囲：当主不在は実際の本人移動から受領者の資格判定と運搬者の遠隔納入拒否を検査。代理受領の実取引は当主在席で検査し、不在NPC当主を含む全経路の画面受入完了とは扱わない。

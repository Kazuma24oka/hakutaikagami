# 家の資金を預かる長距離仕入れ・帰還精算

新規v10のみ。現地の当主と本人（当主自身または直属家臣）が仕入先・品目・数量・前渡金・30日を合意する。家の現金を別の預り金へ実移転し、家全体/代理官と同じ月次調達枠を使う。私財と混ぜず、遠隔地の現在在庫や相場を提示しない。

本人が既存経路で仕入先へ実移動し、現地在庫と実価格を再確認して買う。預り金が足りなければ待機/引受返上。100kgの既存携行枠を共有し、個人取引との二重利用や家の荷の私的転売を許さない。本人の操作を自動化しない。

帰還先で当主と現物受渡しし、家の蔵へ品物と余金を実移転する。一度だけ完了し、私的報酬は生成しない。道中の本人による返上・30日超過・権限喪失では新規購入を止め、預り金/荷物/返却義務を消さない。古い受領先/所有者へ勝手に付け替えない。遠隔取消配送の一般化やNPC隊商は後続。

完成条件はapproval-baseline-v9.jsonの5件。旧v9保存・旧UIを変更せず、実保存復旧/将来一致/画面なしNode3Dを検査。外観/UI操作は未確認として分離。

# 全国1560年の名乗り時系列 V1

## 対象

- 新しく始める「1560年 全国」だけに適用する。旧保存や既存開始版は変更しない。
- `Core/Data/hakutai-db-1560-v2.json` の `NameHistory` から、1560年より後の年が明記された成人名乗りだけを出来事候補にする。幼名、年不明、開始名と同じ名称は将来の改名にしない。
- 元の人物ID・名前・年・段階・根拠を保持し、時期を補間したり人名を創作したりしない。
- 世界時計の年が到達したときに一度だけ反映し、遅い到着、保存復旧、再送で二重適用しない。
- 表示は操作人物が既に知っている人物に限る。未配置人物や第三者の未伝達情報を出さない。

## 完成条件

1. 年付きの名乗り候補が全国開始の新規世界にのみ生成される。
2. 年の到来で表示名が切り替わり、人物・家・所属・権利のIDは変わらない。
3. 世界を実ファイルへ保存し、別セッションで復旧した後に同じ日付まで進めると台帳・表示名が一致する。
4. 旧開始データは同一のまま読み込める。

## 対象外

官位・役職の叙任、諱の推測、同じ年の順序が不明な複数名乗りの細分化、人物の配置追加は扱わない。

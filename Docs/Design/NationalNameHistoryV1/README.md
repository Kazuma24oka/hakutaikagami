# 全国1560年の名乗り時系列 V1

新規の1560年全国開始で、百代鏡DBに年が明記された成人名乗りを共通世界時計の年境界へ接続する。

開始時に候補全件を世界データへ公開せず、時刻が到来した改名だけを保存台帳へ記録する。同年に複数の異なる名が記録された人物は順序を作らず、その年の候補から外す。没年以後の改名も適用しない。本人の改名は本人に表示する。他人の名は現地で対面して認識記録ができるまで旧名を表示し、遠方の変更を漏らさない。人物ID・所属・権利は変えない。

固定基準は `Docs/Development/ProgressV1/approval-baseline-v114.json`、範囲と完成条件は `scope.md`。検査と統合結果は `verification.json`・`completion.json`・`integration.json` に記録する。

# 既知部隊の中景表示

詳細は既存3Dモデル、中景240m超〜30kmは部隊記号。位置/兵数/観測時刻はRegionalBattle.Viewが返す本人の観測だけを使う。部隊の真の現在地から補完しない。現在把握は所属色、古い観測は灰色。指揮官ごとの代表ラベルに旧情報と明記する。未観測の部隊は記号を生成しない。

近景/全国・非展開時は中景記号を非表示。既存の操作範囲や移動規則は変更せず、記号をクリックして遠隔操作できるようにはしない。

検査ではセッションを変えず、描画に渡す複製だけ真の敵位置/損耗を変更して同じ記号になることを確認する。観測だけ削った複製では該当部隊が表示されないことも確認。画面の灰色凡例は旧目撃と明記する。

部隊名は5km以内でのみ表示し、投影矩形が地名や他の部隊名と重なる場合は間引く。記号自体と把握済み兵数の表示は維持。広域で近い記号が重なる場合は拡大して識別する。

部隊名のフォントは作成時から全倍率で同一に固定する。中景でのみ設定して詳細へ残る状態依存を避け、近景→中景→復旧の比較にも含める。

# 家の支給・待遇と本人の米

現地の家の処分権を持つ主君と、実際の直属関係がある家臣の間に、三回の月初給付契約を作る明示v4。米kgで管理し、個人の銭・家の米・軍の備蓄を分ける。旧v3保存へ自動追加しない。月額・NPC基準・履行評価の値は調整用で史実俸禄ではない。

## 相談と成立
現地相談で相手の返答を記録し、1日以内に同じ返答を確認して成立。NPC家臣は月20kg以上、NPC主君は月40kg以下を基本条件にする。未払いが残る同じ家へ追加約束を積まず、NPC家臣は遅配履歴が重いと更新を拒否する。プレイヤー自身の継続意思はこのNPC判断で強制しない。複数の未確認案を先に作っても、同一当事者に重複した有効契約を成立させない。

初回は翌月1日で、計3回。初月の日割りや自動更新はしない。成立時に「現地で将来分の終了を通知でき、過去の未払いは残る」条項を明示する。終了の現地受領と、所属/主従の解消は別操作。旧主従の変化だけではこの既成給付原本を削除しない。

## 債務・引当・現物
月初に期日到来額が増える。約束や期日だけでは家の米を減らさず、受領米や私財を増やさない。支払準備で家の米を1日引当し、他の工事/救済へ使えないようにする。準備取消・期限切れでは引当だけ解放し、未払いを保持する。

両者の現地受渡しで初めて家の米を減らし、当人の私有米を増やす。不足時の一部支給、終了後や実際の辞去後の旧債務の精算を認める。支給で役職・所属・兵を移さない。

私有米は既存の商人取引へ持ち込める。給与受領総量－取引への持込総量を本人の未使用米とし、商人在庫・既存携行米・家の米との保存則を確認する。納入で即金を生成せず、従来どおり納入→代金債務→現地精算を分ける。同じ米の再売却と二重受領を拒否する。

## 支給履歴への信頼
一般の性格/軍令服従/忠誠ではなく、受給者から支給した家への給付履行だけの限定評価。基準70、翌日までの履行は+3、遅配記録は-15、現在の未払いは追加減点。NPC家臣の次の約束判断に参照する。プレイヤー家臣には支給履歴を示すが、感情や更新意思を決めない。

主君が離れている相手の現在の内心を読み出すことはしない。自分の帳簿の期日/受領記録は保持し、相手の返答は現地でのみ示す。家臣画面へ主家の現在在庫を渡さない。

## 確認と限界
完成条件・対象の評価は実装前commit09806b7へ固定。verification.jsonの関連テスト/ビルド/実世代復旧/画面なしGodot Node3Dを確認し、外観と区別する。Computer Useは使わない。

全国の俸禄制度・定期現金給与・知行配分・一般の人格/忠誠・家督/死亡時の債務承継・NPCによる自律経理・荷役/積載/米の私的消費は後続。現在は初期の家の処分権と直属関係を用いる。固定3回の給付約束を、全雇用制度の完成としない。

## ゲームで試す入口
新規ゲームの武将選択で、主君側なら武田信玄、家臣側なら武田信繁を選ぶ。甲府で「家の支給・待遇」から相談/確認し、翌月1日以降に支払準備と受渡しを行う。受領した米は「米の取引」から商人へ持ち込み、買取見積→納入→精算する。甲府の直属配置と給付条件は試作であり、史実の俸禄を再現したものではない。
織田信長で直属家臣が現地にいない場合、給付相手なしになる。既存v3保存へ自動移行せず、新規v4で確認する。

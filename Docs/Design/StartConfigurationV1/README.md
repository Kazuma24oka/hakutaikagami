# 開始設定の検査契約

基本設計BD-02/05の採用方針を新規開始データの検査へ分解した。ライブ世界・セッション・既存保存・入口を変更しない追加API。六立場と三歴史モードの設定を持つが、歴史事件の実装や製品の新規ゲーム画面の完成ではない。

選択は定義ID/版/年代/Seed/開始世界全体/開発側予算定義のハッシュへ結合する。開始後の世界、未成年、未知ID、主従循環、未来の所属、未知の列挙値、役職や土地権の欠落を拒否する。立場を選ぶだけで関係・権限・兵・資源を作らない。城主はcastellan、国人/大名はhouse-headの明示役職を検査。これは開始時の整合条件であり、その役職から実行権限を導出しない。

作成人物はperson:created/の独立ID。土地権、直属随行、指揮兵数、私有資源を開発側の正の価格で計算する。家代表の開始では所属組織の土地権/資源も計算する。単位別価格欠落、予算超過、計算桁溢れは拒否する。価格表はシナリオの入力であり、テストの1000点等を製品バランスとして採用しない。技能配点は現在のCharacterStateに未実装で、無料の技能生成を提供しない。

現行人物台帳は本拠候補と所属の部分採録であり、開始時の身分/土地/指揮権を保証しない。史実人物は詳細採録前として選択を拒否する。六立場の正常例はすべて架空の試験世界。史実開始が遊べると報告しない。

保存は既存ContractJsonの全必須項目/未知字段拒否でStartPackageを往復し、選択/世界/予算を一緒に検査する。これは開始前の設定包であり、既存GenerationSaveStoreへの強制移行はない。

検証：25件の正常/失敗/不変/厳密保存を追加、期待総数970件の全テスト。Scripts/verify_start_configuration.pyが実行前後の全Core/Tests・方針・実行物・TRXを結合する。以前の地形画像検証116比較はc1a1897の履歴で、この段階の画像検査ではない。今回UIは未追加なので新規画像検査は対象外。

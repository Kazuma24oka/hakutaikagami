- Godot 4.5.2 .NET の通常ゲーム画面を画面なしで起動。家中の相談で旧大名から支持を求め、謀略の画面で城主の同意を得て挙兵した。配送中に保存・ロードし、現地の城主の応答後に家中画面で旧家の継続を記録。再ロード後の表示文と配置データが一致した。HOUSE_RESTORATION_UI_PASS、終了コード0。終了処理には描画リソースの解放警告が残った。外観は未確認。
- NPCの旧大名でも、現地で支持を得てから別に密約を取り、日をまたいで書状を発送し、城主の現地応答後に再興成立まで自律進行した。
- 関連90件成功。代表旧保存3件は現行Coreでロード・再出力し元のバイト列と一致。全件と長期全国性能は未実施。
- 旧扶持の回収・護衛隊の集合や撤退はそれぞれの条件を用意した個別試験。今回の一つの通しプレイですべてを起こしたものではない。

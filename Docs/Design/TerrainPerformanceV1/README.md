# 全国表示の負荷測定

全108拠点を1.5km/30kmで表示する。移動や時間進行は行わず同じ世界を保持。CPU Refreshの時間とプロセス使用メモリ、Godot報告の描画メモリを保存する。FPSやGPUフレーム時間の測定とは扱わない。

調整前後の同じ構図を実PNGで比較し、表示専用の頂点計算の再利用で外観とCoreを変えない。

共有頂点は33×33点を一度だけ計算し、SurfaceToolと交換済みメッシュを解放。地図は中心・倍率・表示寸法が同じなら再生成しない。回転/時間更新で無関係な海岸線を作り直さず、中心や倍率が変われば作り直す。冷間更新と再利用時更新を別々に記録。メモリ上限はプロセス1GiB・Godot描画512MiB。

# 次工程：敗走と再集結（未実装）

BD-37/39に従い、損害・士気低下・敗走・到達・再集結を独立させる。敗走は武将の死亡/捕縛/主従解除ではない。
1. 本人と独立した部隊の受領済み任務を保持し、士気閾値で自動撤退の原判断を記録する。本人は瞬間移動させない。
2. 地形と相互予約を通る本隊/分隊の退避経路を固定し、兵糧運搬実体も追随。既知の命令/自動判断/真の現在位置を分ける。
3. 命令伝令が届く前後の敗走と取消・重複再送を検査し、後から届いた旧命令で過去の結果を巻き戻さない。
4. 拠点/退避先へ到達後の再集結待ち、現地合流、残兵返報を別々に記録する。士気の回復値は試作値と明記する。
5. 実GPUで敗走中/再集結待ちを保存復旧し、同じ続行の全世界・荷駄・伝令・3D表示を比較する。

技術実装と検査は既存承認内で継続。健康/捕縛の制度を作り替える等、根本方針の変更だけをユーザーへ確認する。

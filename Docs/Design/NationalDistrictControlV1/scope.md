# 全国郡支配の初期色 V1

基準：`approval-baseline-v112`。設計：`Docs/Proposals/NATIONAL_PLACEMENT_DESIGN_V1.md`。新規1560年全国世界にある郡ごとの初期支配情報を地図へつなぐ。

## この工程で満たすこと

1. 637郡の1560年支配・複数家の持分・根拠を新規全国世界へ記録する。
2. 全国開始前の史料地図と世界内3D地図で同じ初期台帳を使い、単独・並立・未確定・郡名推定を区別する。
3. 勢力色は安定した勢力IDから決める。出典のない色や支配は追加しない。
4. 地図の表示切替、全国開始、実保存・復旧で支配状態が変わらない。既存版の開始と保存は維持する。

## 対象外

- ゲーム中の征服・城主交代による郡台帳の動的更新、家どうしの従属関係。
- 名乗りの年代変化、郡の収入、人物の能力・生年、全国規模の性能受入。
- 色・素材の最終調整。現在はIDに結び付いた仮色を使う。

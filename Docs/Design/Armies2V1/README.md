# S09B 全国の軍勢の編成・指揮・攻城（Armies2V1）

基準：Docs/Development/ProgressV1/approval-baseline-v164.json。一覧の Armies2 の新規の全国開始だけ（Domestic2・Logistics2・Persons2 を使う）。今の保存は変わらない。
この基準を固める前に、コード（Core/Contracts/Armies2.cs）の下書きを書いてしまった。基準の条件は下書きに合わせず、工程表の S09B の中身から作った（基準の notes に記録）。

- 作戦線：城10以上で、目標が天下か国の統一の家は、主の線（兵の6割）と別の国への二の線（4割、4割でも相手の1.5倍）を同じ月に出せる。二の線はその国の軍団長が率いる。
- 軍団と一族の分隊：城15以上の家は、本拠の国の外の国ごとに軍団長を置く（当主の子・兄弟を先に、ほかは戦術と調練の高い家臣）。
- 兵種の編成：家の鉄砲・軍馬（兵に対して各30%まで）と残りの槍。山城・平山城の攻めは鉄砲、ほかは騎馬が効き、率いる人の鉄砲・騎馬の技能で効き目が変わる。
- 募兵：軍備の方針で銭千貫以上の家は、銭の1割で3か月の雇い兵（千貫ごとに100人）を雇う。負けると逃げる。
- 現場の裁量：二の線の軍団長は、相手が自分より強ければ戦わずに退く。
- 区画の攻城：山城（4）・平山城（3）は、落とせなかった攻めでも優勢なら区画を一つ取り、次の攻めで守りが弱い。半分を取られた城は城兵の退去を条件に開城する。落ちれば記録は消える。
- 救援の到着：同盟の家の援軍は、本拠から城まで15日（山城は30日）を超えれば間に合わない。
- 競合する命令：攻める家に従う家が守る家と約束を結んでいれば、約束が1年より長く残るなら約束を守り、そうでなければ主に従う。
- 逃げた人の帰還：逃げた拠点から本拠まで道のりの日数をかけて戻る。知らせは着いた時に届く。
- 追跡補給：実際に動く軍勢への兵糧は、その時の軍勢の位置までの日数で運ぶ（Logistics2 の陣への補給）。

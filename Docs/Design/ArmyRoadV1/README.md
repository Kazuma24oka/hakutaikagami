# 自軍の拠点間行軍と現地調達

実装前基準：approval-baseline-v14.json。新規v16のみ。許可を得て引き受けた同じ部隊を本人が率い、共通の陸路・時計・通行止め判定で拠点間を移動する。貸与元/元の蔵/名簿/軍務原本は変えず、部隊の現在の集合地を別に持つ。到着は拠点周辺であり城の支配・入城権を自動生成しない。

既知経路の見込み兵糧を用意してから出発。迂回で次の区間の兵糧が不足する場合は、実際の区間始点で停止する。消費を道路行軍/帰還前の在外待機/既存の現地展開へ分け、二重消費・将来米の借用を防ぐ。元の拠点へ戻ってから貸与兵糧/返報/指揮返還を処理する。

到達した市場では本人の私財で自由在庫の米を実購入し、部隊の実容量へ移す。遠隔の家の財布や在庫は使わない。携行量2日分の現行試作値を保持し、長い行程は途中の拠点で現地調達する。海上の軍輸送・全国の補給隊・護衛/略奪・部隊と別れての広域個人行動は後続。旧v15以下は自動昇格せずバイト互換を保つ。

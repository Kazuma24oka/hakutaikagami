# 登用・常設の家中職・評定

固定基準v60。統合案第14節の2b・2cを、同じ人物・所属・文書・役職権限を使う一巡としてまとめる。別々に仮の所属や権限を作ることを避けるため。

1. 登用の条件書・実物の支度金・本人の引受を分け、所属と直属だけを個別に成立させる
2. 席次と家の規模を区別し、常設職は任命文書の受領と本人承諾の後にだけ効力を持つ
3. 常設職の権限を拠点と役割・月枠に限り、解任・辞任・当主交代時の個別再確認を保つ
4. 実際に集まる評定で本人に届いた上申だけを審査し、認めた調達・救済を実在資源へ反映する
5. 通常画面・NPCの同じ仕組み・重大不具合・途中保存と同じ未来・旧形式の代表互換を確認する

登用の試作条件は一度の支度金と家への所属・直属。月々の扶持・知行・軍の指揮は既存の別契約で定め、登用だけで付けない。評定は地元での参集を対象とし、定例開催と家の方針は3b。役職は既存の役職表の共通の役割を使い、史実の家別の職名を捏造しない。

# 登用・常設の家中職・評定

条件書・支度金・本人承諾から所属と直属だけを成立させ、席次・常設職・月枠付き現地行政・当主交代時の個別再確認へ接続。家老の評定招集、実参集、NPCの上申と審査、承認から実在米の救済と木材買付を実装。関連26件・実保存復旧・代表旧保存3件・通常画面の内部操作と自前描画が成功。

登用は一度の支度金と所属・直属。扶持・知行・軍の指揮は別契約。常設職の主要接続は家老の招集と代官・城主の現地行政。家別職名・遠隔赴任・定例評定と家の方針・NPC自発登用・全件・全国長期性能・ユーザー試し遊びは未実施。

支度金は預り中・本人受取・実返還を区別。登用で兵・所領・毎月の扶持を付けない。行政の現地・処分枠と解任通知の到達を確認し、当主交代時に旧職を一括移転しない。NPCの資源不足時は実行候補のコピーを破棄し、途中の承認や支払を残さない。

通常画面では登用→代官の引受→NPCの木材買付上申→評定招集・招待・参集→承認→実在木材5の受領→実保存復旧と表示一致を確認した。

# 架空演習の交戦任務

配置だけの開始を保持し、別の開始選択で明示交戦・損耗・撤退・自隊現況の物理報告を試す。史実の開戦ではない。敵の隠れた兵数を本文へ混ぜず、主君は到達前に内容を認識しない。報告の内容は発送後の損耗によって変わらない。

全1068件（追加21件）、既存126比較と交戦5保存点の復旧/続行10比較を同じ実行物で検査する。実行後に実PNGを点検し、現在の入力・バイナリ・旧証拠へ結合する。正本は verify_engagement_mission.py → 実画像点検 → check_engagement_mission_binding.py。

攻城・捕縛・人物死亡の判定・補給・最終戦闘バランスはまだ未実装。既存の接触/同時損耗/敗走の試作数値を使用し、人物の生死や政治的離反を兵数から自動変更しない。

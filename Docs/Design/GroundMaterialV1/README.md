# 地表の材質と繰返し寸法

道/草の材質色は既存IDのまま、固定設定の無彩色土粒テクスチャを重ねる。外観用の画像で地形/占有/通行を変えない。旧材質は保持。非同期ノイズ生成を使わず、開発時に固定手順から画像/ミップマップを生成する。

UVの4m等の周期はカタログのTileSizeMmを正本とし、80m区画の近傍の周期原点から計算する。大きな全国座標をそのままfloatへ落とさず、区画境界では整数周期だけ異なるUVを使う。実メッシュのUV位相もカタログと照合する。

今回の周期は道路4m/草6m。80m区画に割り切れない周期も、実メッシュの各頂点のワールド座標とUV位相から検査する。

地表材質の追加のUV拡大/ずらしは使わず、繰返しを有効にしてカタログの周期を正本にする。素材の模様と色の分離を保つ。

共有地表の両面描画も統一し、材質読込の既定値で地面が消えないようにする。UV検査に加え、実投影した地面の画素が背景色のままでないことを全地域/復旧で確認。

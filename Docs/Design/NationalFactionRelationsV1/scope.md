# 全国1560年の勢力従属関係 V1

基準：`approval-baseline-v113`。対象は百代鏡DBの1560年 `Overlord` だけ。家どうしの直接の主家・従属を、その開始世界に存在する勢力ID間の有向関係として記録する。

## 完成条件

1. DBに記録された従属関係を、新規全国世界の版付き台帳へ保存する。世界に配置されない家も元の家IDと関係の根拠を保持し、勢力IDがない側を表示対象にしない。
2. 主家と従属家の家ID・勢力ID・根拠を保持し、郡・城・人物・軍・権限を自動で移さない。
3. プレイ中は操作人物の家に直接関わる関係だけを表示し、未記録・未配置の関係を「関係なし」と断定しない。
4. 実ファイル保存・復旧の前後と続行後に同じ関係を保ち、従属関係機能のない旧開始を変えない。

## 対象外

ゲーム中の離反・独立・従属の成立や解除、主従条約の履行、関係が第三者へ伝わる配送と噂は後続工程。

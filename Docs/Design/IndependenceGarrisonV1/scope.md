# 城主独立時の城内係争

1. 城主の独立宣言と同じ城にいる旧主側の守備を個別に追跡する
2. 旧主側の部隊が守る城では、宣言だけで城門・本丸・軍勢が移らない
3. 当事者が現地で確認した守備と引渡しの状況を通常画面に表示する
4. 宣言後の係争中に保存し、復旧後も部隊の帰属・城の実効支配・既存債務が一致する

実装前の確認では、JointIndependence.CastleControl は城主の権限と城の引渡し手続を参照する。守備部隊が旧主に留まる場合を既存の部隊・駐屯台帳と照合する。新たな資産を生成しない。重点検査は既存の密約・独立と城の引渡し、同一事例の途中セーブ復旧。

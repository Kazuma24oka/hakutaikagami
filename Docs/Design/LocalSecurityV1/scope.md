# 治安と警固

1. 現地の家臣本人が期限付き警固を引き受け、他任務と二重就業しない
2. 賊の実在・警固の現地配置・討伐実績から安全を判定し、賊を消さずに警固で通行を守る
3. 無警固の放置が商人の新規取引と村の反応へ影響し、履行済み契約・現物を消さない
4. 本人が現地で確認した時点付き情報と警固の相談を通常画面に出す
5. 代表一巡・権限と重複・途中保存復旧・旧保存を確認する

統合案5c。第14節N8表記は同案第13節N4の治安・民心を参照する。既存討伐・護衛を再利用。商人の常駐市場の新規取引見合わせを先に接続し、商人個体の全国巡回は後続。

検査は関連する代表一巡、二重受付と遠隔権限拒否、警固中の保存復旧、旧保存3件、通常画面の内部入力。全件・長期性能は未実施として扱う。

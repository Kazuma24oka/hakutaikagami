# 分隊取消原本の実物保持・遅着 V1

前工程UnitDirectiveCancelRetryV1はd54e40eb0bc66a327f19af6096bc7b14d5cad0b6で検証済み。1905件・25GPU・172比較・24保存点は前工程の当時実績。現行の完了判定は本工程verification.jsonだけとする。

## 完成条件5件
1. 新規発送時に明示した取消原本だけを実際の帰路終了から保持する。旧取消から紙を追加せず、初回不達・元対象・指定時刻・元期限を変えない。
2. 近くにいる実保持者から、同じ受信隊の既知固定地点へ実物を届ける。所在・全積荷・伝令の描画を一致させ、期限切れ・不在・別隊・再受渡し・権限終了を拒否する。
3. 実物と再送が同時/前後に到着しても取消の効力は元原本につき一度だけ。後発命令・他隊・終了権限を巻き戻さない。
4. 遅着受領の返書と将来効力の通知は物理配送する。不達なら実保持と本人回収まで結果を知らせず、三場面24保存点から世界・認識・選択・3Dと同じ未来へ復旧する。
5. 新規18件を含む全1923件と関連実Godot回帰、実画像/動画・現行ソース・DLL・証跡を照合して同じブランチへcommit/pushする。

# 木材・武具の生産・取引・消費と全国拠点の市場契約

実装前固定：approval-baseline-v7.jsonの5条件。初回用途BD-35に合わせ、既存の米に木材（kg）と武具一式（組、携行換算5kg）を追加。見積・引当・現地受取・輸送・納入・代金債務・精算・私有物の家への供給は同じ契約を使用し、商品名だけで別財布を作らない。携行上限は全商品共通100kg、一件の運搬中取引。

3地域の工房は有限の加工前在庫から木材/武具を生産し、家の食糧不足・空き労働・商人の自由資金を確認して賃金を住民の別財布へ払う。住民の購入はその財布内、木材は燃料消費、武具は住民保有へ移す。給付債務や商人の売却代金引当を生産で使わない。家の木材は別在庫で水利工事に10kgを実消費する。武具在庫だけで兵や軍権を作らない。

全国網の城館候補27地点と既存3地域・京都/堺などの拠点へ同じ市場契約を展開する。市場の所在地と商人組織は別ID。史実の市場存在/在庫/相場/生産地の断定ではなく、史実候補地点の上に置く調整用の市場プロフィールと明記。全国の農業・人口を完成扱いしない。

新規v8のみ有効、旧v7以下を保持。素材は変更しない。Computer Use禁止のため外観/UI操作と画面なし数値検証を区別する。

## 試作係数と境界

各市場の初期在庫は米2000kg・木材200kg・武具40組、商人資金4000文。3工房は加工前木材1000kg・加工前武具100組の有限在庫を持つ。加工前在庫の生産地/採掘/鍛冶工程は抽象化した開始条件で、無制限の生成源ではない。住民の開始資金300文は既存村落組織の別財布。木材は空き労働10人で月上限20kg、武具は5人で2組。賃金は木材2kgにつき1文（端数切上）、武具1組5文を商人から住民へ支払う。

住民は資金と自由在庫内で木材2kg/月を燃料消費し、武具1組/月を合計10組まで保有する。商人の支払債務引当を賃金で使わず、空き労働/食糧不足/在庫目標/有限加工前在庫により生産を抑制・停止する。家は木材20kg・武具10組から開始し、私有物からの納入は現地の当主権限を要する。武具は在庫のみで、装備外観や兵の生成・兵種変更には接続しない。

全国30市場は城館候補27地点・清洲・京都・堺。同じ実運搬/支払契約を使うが、30市場の実在を史料確認したという意味ではない。動的な食糧/労働/工房/住民購入は既存3地域のみ。他市場は有限の初期在庫と売買により変化する。全国農業/人口・家の自律調達・軍馬/弾薬・混載・荷役/荷重減速・代理官の物資調達権と木材の遠隔報告は後続。旧代理行政の報告は米・食糧/水利の観測を維持する。

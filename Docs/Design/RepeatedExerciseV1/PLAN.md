# 反復演習と生涯の損耗（次工程・未実装）

## 完成条件（5件）
1. 新しい版を明示した交戦入力だけで二回目の架空演習を開始できる。旧入力と旧保存の一回分の結果を再計算し直さない。
2. 自隊の残兵・消費兵糧・士気を引き継ぎ、開始し直すだけで回復させない。士気50への回復は既存の実到達・60秒・交戦終了を満たした再集結に限る。
3. 交戦・敗走・到達・再集結を回ごとに区別し、過去の経路や効果を消さない。終了と次の開始が同秒でも損害と消費を重ねない。
4. 各時点の実効権限・許可期限・認識・所在地・兵糧・生存兵を検査する。古い書状や別案件で新しい交戦を許可しない。
5. 二回の演習、二回目の敗走・再集結、途中保存と復旧、同じ未来と実3D表示を検査し、全テストと必要な回帰・実画像点検後に同ブランチcommit/pushする。

## 境界

相手は明示された架空演習の対象であり、史実の敵軍を生成・復活させる機能ではない。新しい演習相手と自隊の生存履歴を区別する。実在勢力間の開戦や独自の敵軍AIは別工程とする。

現在の許可期限を勝手に延長しない。前の指揮返還と新しい軍務の許可は分け、士気・兵数の自動回復を追加しない。既存の60秒/士気50等は試作係数であり、最終の遊び心地を確定した値ではない。

本計画の作成時点では未実装・未実施。現在実行中の再任検証とは別の開発段階として扱う。

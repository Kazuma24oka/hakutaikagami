# 工程7の動作確認

Godot 4.5.2 .NETを画面なしで起動し、家臣の家中画面で受領前には予約が出ず、陣触れを開くと軍役6人の予約が表示されることを確認。予約中に保存・ロードして期日を過ぎてから本人が集合すると「軍役6人のうち0人で参集（遅参）」が表示された。再ロード後の表示と3D配置も一致（MUSTER_UI_PASS）。外観は未確認。

関連108件が成功。家の預け兵と自前の兵、村の働き手、雇い兵の賃金と米、使者が運ぶ陣触れ、集合と遅参を検査。堺・石山・京都の三家で盟主が現認した場合と遠方に留まった場合を交戦直前から実保存復旧し、連続進行と同じ世界バイトになることを確認した。新規ゲーム機能より前の初期・活動中の保存2件も現行Coreで読み戻し、元のバイト列と照合した。

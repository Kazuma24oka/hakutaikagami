# 委任先への物理照会

明示した本人の委任案件だけを照会する。宛先は通知済み営地、または本人が指定したMove線の先頭。現在地の自動追跡ではない。営地と指定先が外れれば照会も不達になる。問い合わせ自体は命令・再命令ではなく、部隊を動かさない。

相手が質問を受領した後、自分が知る受令判断と行動中/停止/別計画/到達の申告を独立した物理返答へ固定する。停止理由は自隊の通行・接触停止状態に関する自己申告で、全原因の裁定や責任確定ではない。追加の嘘判定・処罰は実装しない。

原本の到達報告が不達でも、返答が不変の到達報告を引用すれば情報として知る。原本の正式受領/原本の知識レコードは追加しない。表示の位置は元の到達時刻の旧情報で、新しい直接目撃を戻さない。返答本文の時刻は別に表示する。

照会返答も不達になり得る。未着の内容をUIへ出さず、失敗報告自体が未着なら不達の確定もしない。返報側の自律再送は次工程。現在の再送ボタンは前工程の本人発行命令だけ。

新しい開始包/部隊/権限を増やさず、既存の共同演習開始で明示操作したときだけ新しいregion-query/region-query-replyを保存。旧開始・旧保存を自動変換しない。

検証：verify_delegation_inquiry.py→実PNG点検→check_delegation_inquiry_binding.py。停止理由の単体検査は明示した停止済み状態のfixture。移動衝突自体の回帰と区別する。

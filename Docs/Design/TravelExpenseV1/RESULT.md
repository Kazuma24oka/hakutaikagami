# 仕事・旅費・軍務の一巡：実測結果

新規開始には船賃規則を保存し、標準の試作値は1航程10文。港で待つ間・出航前取消・運休では支払わず、実際の出航時だけ一度支払う。本人の財布だけを使い、他人の預り金や主家の兵糧は使わない。運航者の受取勘定と合算して金額を保存し、出航後の取消で二重の払戻しを作らない。

金欠なら港に留まる。陸路限定の出発が選べ、所持金0から徒歩で仕事先へ移動し、通常の会話で仕事を引き受けて報酬を得られる。途中の行先変更・迂回も、陸路指定を勝手に海路へ変えない。海を徒歩で渡れる意味ではない。

通常の新規ゲーム・武将グループ登録から、壱岐→博多への渡海→陸路→仕事と20文の受領→仕官→部隊の出陣/布陣→帰還/報告/指揮返還を、同じ架空武将で実行した。通常の私財は1000→990→1010文。金欠の検査だけ明示した高額船賃1000文を使い、1000→0→徒歩/仕事→20文まで実行した。通常プレイへ高額値を混入していない。

全2308件が最終のCore/Tests/データ入力で成功（追加32、失敗/スキップ0）。実ゲームとテストのCore DLLは一致。実GPU16実行・142組について、別プロセスの途中復旧と続行後の世界状態、3D/情報欄の画像、全表示/姿勢数値を照合して一致した。通常10点、小画面10点、金欠10点、取消4点、既存運搬7点、預り金と軍務の同居7点、既存兵糧6点、既存軍務17点。

旧プロフィールはVoyageRules等を省略したまま読め、料金規則を後付けしない。旧の海路の振る舞いと文字通りの旧JSON復旧を検査した。新しい原本だけに陸路指定を保存する。

これは地域一巡の技術検証。全国の政治・人物成長・商業・戦争や製品受入の完成ではない。運航者の経営、船/港の専用モデル、宿泊、一般市場、使者/軍勢の運賃は未実装。移動時間や10文の値は試作値で、史実の料金の断定や実時間FPSの認定ではない。

次は一巡の操作量、会話と移動中の見せ方が好みに合うかの確認段階。技術上の再承認を求めず、確認結果を次の見せ方の調整に反映する。

# 全国1560年の開始の版 V1（2026-11-12）

基準：approval-baseline-v110（BD-04 27→35・BD-20 35→45）。遊べる版の単位（PROCESS_V2 第1節）。設計 Docs/Proposals/NATIONAL_PLACEMENT_DESIGN_V1.md 第4節4。

## 遊べるようになったこと
スタート →「新規ゲーム」→ 開始の選択で「全国」→「登録武将の選択へ」→ 武将の一覧から当主（例：織田信長）を選び「この武将で始める」。
全国約4,000人の武将がいる世界で、移動の行き先に城（例：小田井城）を選んで出発できる。

## 中身
- 開始の版 `hakutai-1560-national-v1`（Core/Contracts/NationalStart.cs）：百代鏡DBの家252・登場武将4,014人（DBの人物と地域の名のモブ、HakutaiDbStart の名簿）・城1,958（持ち主のある城1,853）。琉球の家と城は置かない。複数の家の名簿に出る人物は ID の順で先の家に置く。DBの ID に英数字以外があれば SHA-256 の先頭12桁にする。
- 世界は城の移動網・調べる権利の軽い作り方・続けての日課・遠方の休眠で作る。保存の開始定義（NewCampaignProfile）に移動網と休眠の版を持たせた。
- 遊ぶ画面の行き先の一覧は、城の移動網の世界では城の拠点を含む（他の世界は今までどおり）。
- 休眠の版では、開始の人数の上限（3,000人）を起きている人数で見る。

直したこと：
- 世界の写し：自分で書いたデータの写しでは外向けの検査と二重の解析を省く（ContractJson.Copy）。
- まとめた手番の間は写さずに直接変える（休眠の版、前後を比べる処理が働く世界は除く。途中で失敗したら1人ずつやり直す）。判断の時点の番号は先に取る。
- ID の判定を正規表現から文字ごとの判定に（20万件の文字列で同じ判定を確認）。財布の ID を覚える。
- 起きている人の判定で、人物の位置をまとめて求める（最初の拠点の一覧なめをやめる）。
- NPC の判断の検査で、検査済みの前の状態と同じ判断は過去の入力の計算をやり直さない（休眠の版）。財布の受け渡しの合計を財布ごとに一度だけ数える。
- 作成 約4.7秒・保存 約11MB。

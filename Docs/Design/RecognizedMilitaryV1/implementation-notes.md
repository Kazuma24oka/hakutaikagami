# 認識表示の実装時に落とさない条件

- RegionalSight/RegionalView の現時点・過去の区別を利用。現在地80mは既存地域戦の試作係数。最終の地形遮蔽範囲は別工程で、今回の合格と混同しない。
- 画面用の投影に真の次秒座標や現在残兵を一緒に載せない。過去情報は記録時の位置/人数/士気/状態/観測秒/情報源だけ、静止した過去印として描く。
- 武将の位置を中心に視認し、カメラを全国へ動かしても知識を増やさない。
- CourierFramesは物理診断APIのまま。通常用は近傍の見える使者のみで、未確認IDは不透明化し、所持文書や未開封本文・不達結果を渡さない。
- 本隊へ渡した兵糧モデル、本人退避後の本隊モデル、演習相手も同じ観測ゲートを通す。ラベルだけを隠してモデルが残る状態を不合格にする。
- 部隊全景ボタンは視点の広さだけで、未観測地を観測した扱いにしない。
- 全隊の現在残兵/士気集計や交戦開始の可否から遠い隊の未知損耗を漏らさない。視認表示の段階からこの抜け道を試験する。
- 最後の明示TroopSighting（1mの現地宛先証拠）は観測記憶と別物。80m表示範囲に見えたことだけで伝令の受渡し・受信役への宛先更新を許可しない。
- UnitPostInquiryAnswer は部隊役0の自隊のみ。返書を開いたときだけ、その報告時点の本隊情報へ統合。左右分隊へ知識を複製しない。引用で原本受領/FailureKnownを追加しない。
- 回別の架空相手IDを維持。新演習の相手と旧目撃の相手を同一視せず、旧記憶を削除せず、現在の敵モデルへ流用しない。
- 新保存の任意観測は版付き。未指定旧保存の原本/結果/JSONを変えず、開始前の視認履歴を捏造しない。自動観測の記憶が必要なら、保存・BeforeState・全再実行検証まで一式で実装し、画面内キャッシュで済ませない。

検査の対：本人の認識が同じ二世界で、見えない隊の位置・損耗・配送結果を変えても通常画面の投影/操作候補が同じ。現地目撃または返書開封の後だけ差が出る。距離境界、カメラだけ移動、古い返書、未開封、別案件、同秒順序、復旧を追加する。

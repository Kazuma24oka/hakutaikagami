# 次工程：保持原本の実物遅着（未実装）

保持台帳の原本/未受領報告について、現地で受渡しできる実在の運搬者と所持紙を根拠にする。タイマーだけで古い便を復活させず、保持位置→本人または明示した既知受信点の実経路を登録する。旧初回不達/再送/文面を変えず、共通MessageFlowのLateDueAtを登録済み物理便だけに使う。受取人が移動して不在なら正式受領を捏造しない。同一原本の再送分と競合しても一度だけ正式受領し、業務効果も重複しない。保持者の所在/受渡し/紙の消費を保存し、旧世界へ自動遅着を遡及させない。保持しただけで内容を知ったり、未受領報告が部隊のFailureKnownになったりしない。原命令の保持/再送競合への拡張は明示配送方針で版を分ける。改ざん拒否/同じ未来/実描画座標/3Dを検査し、判断不要なら同ブランチpushまで継続する。

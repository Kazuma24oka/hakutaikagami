# 休眠の世界の手番のまとめた検査 V1（2026-11-12）

基準：approval-baseline-v109（BD-04 25→27）。

- 休眠の版の世界では、1つの区切りに起きている人物の日課の手番を1人ずつ変更し、世界全体の検査は手番の終わりに1回だけ行う（WorldSession.NpcRoutine.cs、WorldSession.Change の deferValidation）。
- まとめた検査に通らないとき、または手番の途中で例外が出たときは、手番の前の状態に戻して、1人ずつ検査する今までのやり方でやり直す。
- 検査用に、まとめた検査をわざと通らなくする仕掛けを置き、やり直した世界がまとめて通った世界とバイト一致することを確かめた（Tests/NpcDormancyTests.cs の NpcBatchValidationTests）。
- 版のない世界は今までどおり1人ずつ検査する。

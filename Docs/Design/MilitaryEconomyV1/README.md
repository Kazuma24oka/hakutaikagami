# 地域の補給労働と家の米を既存の軍務へ接続

実装前基準：approval-baseline-v11.json。新規v12のみ。既存の100人の駐屯兵は増やさず、出動支援の地域労働20人を現地引受から実際の部隊返還まで確保する。兵の数と民の人口を新しく二重生成しない。人口200は既存の民間共同体の試作台帳、駐屯兵は既存の軍台帳であり、この工程で農民を兵へ変換しない。

支援人手は工事/工房と同じ労働枠を使い、季節収穫は実際に拘束された人秒を積算して減らす。収穫直前に一瞬だけ返還して損失を回避できない。工房は現在の労働力に応じて生産量を調整する。

新規軍用倉は0から開始。現地で家の米を軍用倉へ実移転し、既存軍務の人秒単位へ換算する。試作配給係数0.6kg/兵/日＝1kgあたり144000人秒。家/村/私財/既存俸禄引当を分け、所有と現地の許可を検査。携行消費後に残る端数は軍用倉の人秒として保持し、返却は取り出せる整数kgだけ。原資なしの初期10日分を新規版では生成しない。

NPC当主は自分の現地支配拠点の米120kgと支援人手で既存2日携行分を用意する。不足なら招集待機。送信した撤退命令や本人だけの退避で人手/携行兵糧を解放せず、部隊の現地帰還で返納する。

兵種・武具による新規編成、地域人口からの一般徴募、行軍する補給隊、戦死/捕縛による民間戸口変更は後続。係数は調整用で史実値ではない。旧v11以下を保持し、実保存復旧と画面なし3D配置を検証。外観/UI操作は別に未実施とする。

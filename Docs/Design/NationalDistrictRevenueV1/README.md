# 全国の郡収入と現地公金 V1

新規全国v4だけで、DBの郡支配持分を年10石につき1文の試作収入へ換算する。史実の徴税率ではない。月境界の端数を累計で持ち越し、同じ時計から同じ収入額を算出する。家の初期収集本拠の現地公金へ入り、私財と分離する。本拠を失った月は収入を止め、勝者へ旧家の財布を自動移管しない。城のない家には受領先がなく、本工程では未受領。

既存の公金・予算・市場の有限在庫・実支払を再利用する。旧全国v1〜v3、人物方針付きv2の保存を保持する。実保存復旧後の世界・表示・1秒後の未来と将来収入額が一致した。全件4,535件成功。短い検査で見つかった時刻直接変更の旧テストは当時のv3へ固定し、修正後の全件で確認した。

Godotの公金ボタン入力と自前描画で、郡収入4,764文・支出後公金4,760文・私財1,000文を確認。試作モデルがない場合の仮表示を用意し、最終実行は例外なし。OS画面取得・操作は未使用。正式な外観受入、全国3,000人/1,000拠点/500軍のFPS測定は未実施。

固定基準v116の完成条件4件。実測と統合先はverification.jsonとintegration.json。CentralCourtCatalogのv4判定追加は分担更新前の作成済み差分であり、同ファイルの追加変更は行っていない。今後はClaude担当とする。

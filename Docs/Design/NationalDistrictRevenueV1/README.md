# 全国の郡収入と現地公金 V1

新規全国v4だけで、DBの郡支配持分を年10石につき1文の試作収入へ換算する。これは史実の徴税率ではない。月境界で整数の端数を持ち越し、同じ世界時刻から常に同じ累計額を計算する。公金は家の初期本拠の現地台帳へ入り、私財と分離する。収集拠点を失った月は収入を止め、旧家の財布を勝者へ自動移管しない。城のない家の収入は本実装では受領先なしとして扱う。

既存の現地公金・予算・市場の有限在庫・実支払を再利用する。旧全国v1〜v3と人物方針付きv2の開始定義は保持。完成条件は固定基準v116の4項目。検証は進行中であり完成扱いしない。

初回の代表検査は全国走査が重複して1時間を超えたため中断した。索引化後の再検査は12分11秒で収入・現地購入・私財分離・重複拒否まで通り、ロード時に必ず停止する既存仕様をテストが考慮していなかったため最後の完全一致で失敗した。保存前の停止を明示し、再検査する。この検査は300秒を超えたためHeavyへ分類する。

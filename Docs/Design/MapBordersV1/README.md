# 国と郡の境界の表示 V1（2026-11-12）

基準：approval-baseline-v104（BD-20 30→32）。2026-11-12 ユーザーの指示。

- 「郡地図 Ver 1.1」（郡地図研究会、CC BY 4.0）を加工して、国74・郡725の境界の線と名前を作った（Tools/HakutaiDb/build_borders.py → Game/Data/Geography/borders-v1.json、約940KB）。出典は Game/Data/Geography/CREDITS.md。
  - 国は明治の区分（陸奥・陸中・陸前・磐城・岩代、羽前・羽後など）。北海道は国「蝦夷」、渡島国の範囲は郡「渡島」。ほかの北海道の郡は出さない。
  - 郡は明治の郡（戦国期の郡は分からないため）。明治の市・区（仙台市・函館区など）は郡にしない。
  - 線は隣と接する境目だけ（海岸は描かない）。約200mで間引き、日本測地系から世界測地系へ近似で変換。
  - 琉球・小笠原の国名は出さない（地図の「琉球王国」の名前だけ）。
- 地図の左上に「経路」「国」「郡」の切り替え。国の線は赤茶、郡の線は淡い灰色、経路は青灰。
- 国名は1ドット4kmより寄ったとき、郡の線は2.5kmより、郡名は0.8kmより、城の名前は0.35kmより寄ったときに出す。名前どうしが重なるときは国→郡→城の順に先のものを出す。
- 「蝦夷地」の名前は国名「蝦夷」に置き換えた。

確かめたこと：[verification.json](verification.json)。

## 修正（2026-11-12 ユーザーの指摘、加点なし）
- 郡名の色を青緑にした（城の名前と区別する）。
- 郡が国の線の外にはみ出す所があった（31郡。郡地図の「国地図」と「郡地図」の2つのファイルの境目の食い違い）。国（国地図）を基準にし、郡を国に合わせた：郡の線は、その郡の国の中にある部分だけを描き（国の線ちょうどで切る）、隣の国にはみ出した部分は、はみ出した先の国の郡に取り込む（線を描かない）。郡名は自分の国の中に置く。国名の位置は、その国の形の重心を面積で重み付けした点。
- 国境・郡境が途切れる所があった（2つの形の境目の点がぴったり一致しない所）。境目の作り方を、辺のすぐ両側（約150m）がどの国・郡に入るかを調べ、両側が違えば境目とする方法に変えた。国の線165→354本、郡の線1,865→2,070本。
- 国の形の穴を湖として水の色で塗る（15か所：琵琶湖・猪苗代湖・宍道湖・印旛沼・洞爺湖など）。2つの国にまたがる湖（霞ヶ浦など）や海につながる湖は穴になっていないため、まだ描けない。
- 境界線を地図の陸地に合わせて整えた（Tools/HakutaiDb/build_borders.py の finish）：海の上の部分を消して海岸で切る、海岸の手前で止まる端は海岸まで伸ばす、途中で止まる端は近くの線につなぐ、湖や川で途切れた線は対岸の続きとまっすぐつなぐ（霞ヶ浦の常陸・下総など）、形のずれから出た2km未満の切れ端は消す。描いた湖（国の形の穴）も水として扱う。明治の市・区の範囲は、接する長さが一番長い同じ国の郡に含めた。琉球の線は描かない。
- 結果：海岸にもほかの線にも届かない端が0（borders-v1.json の Dangling、画面の検査で確認）。国の線349・郡の線2,136。
- 湖を描くため、国土数値情報「湖沼」（W09-05、商用可）と Natural Earth の湖・川（10m）を取り寄せたが、使わなかった（湖沼は今の湖でダム湖を含み、八郎潟などは干拓後の形。Natural Earth の湖は日本では琵琶湖だけ）。取り寄せたものは戦国DBの資料フォルダ（MAPDATA/ksj-W09-05、MAPDATA/natural-earth-9380cca）に置いた。
- 2026-11-12 再修正（ユーザーの指摘：海岸まで届かない国境・郡境）：線の端を自分自身の先の点につないで「つながった」と見なしていたのを止め、最後の検査を「海・水まで約250m 以内か、別の線の点にぴったり重なる」に厳しくした。地球地図日本の湖・広い川面も水として扱い（地図にいつも描く）、海岸まで伸ばす長さを12kmに広げ（明治以降の埋め立て地のため）、どれにも届かない端は4km 以内のほかの線につなぐ。厳しい検査で届かない端0。国の線420・郡の線2,269。
- 同時に、城の道を作り直した（Tools/HakutaiDb/build_castle_routes.py）：湖を横切る道を作らない（国の形の穴の湖と地球地図日本の湖・広い川面を避ける）、城の移動網では全国の拠点どうしをまっすぐ結んだ陸の推定の連絡路（湖や海を横切る長い直線）を使わず、全国の拠点も近い城と結ぶ（CastleRoutes.KeptNationalEdges）。尾張の細かい道と海路は残す。今までの世界（101拠点）の移動網は変えない。道2,699（海路14）。
- 湖・広い川面（地球地図日本）は地形の切り替えに関係なくいつも描く。地形の切り替えは山の陰影と川の線。

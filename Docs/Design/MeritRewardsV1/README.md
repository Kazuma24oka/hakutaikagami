# 勲功・恩賞・不満・顔

主君が認識した点検の評価と本人の開封を分け、同行者の返報審査・評価通知・実物の恩賞へ接続。銭・私有物・感状・与姓・拝領字、本人だけの不満と現地上申、既存扶持の実支給確認と顔を実装。関連58件・実保存復旧・代表旧保存3件・通常画面の内部操作と自前描画が成功。

勲功の対象は点検の評価と同行者の点検返報。実戦・輸送の勲功、知行の恩賞、返却後の再沙汰、家中全体の論功と正式官位は後続。拝領字は別名札として記録し元の名と同じ人物IDを維持。全件・全国長期性能・ユーザー試し遊びは未実施。約10ポイントの作業は継続中。

恩賞の沙汰と実際の受領は別。配送の結果は送り主へ物理報告が帰るまで見せず、本人にも未到達の沙汰を漏らさない。恩賞で仕事代・家の給付債務を消さない。茶会後の次操作も追加検査し、配列を含む履歴の比較を内容一致へ修正。

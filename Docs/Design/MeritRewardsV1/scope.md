# 勲功・恩賞・不満・顔

固定基準v58。統合案第14節の2。勲功は通貨にせず、評価原本と本人の認識を用いる。

1. 主君の受領した評価原本だけを勲功帳へ集め、本人には開封済みの評価だけを表示する
2. 銭・私有物・感状・与姓と偏諱は実際の申し渡しと受領を経て確定し、受領前に恩賞済みとしない
3. 未報奨への不満と顔を既知の経緯から導き、上申・NPCの判断と結び付ける
4. 既存の給与・任命契約は権限と同意を保って論功の画面から利用できる
5. 関連重大不具合・途中保存の同じ未来・旧形式の代表互換と通常画面の一巡を確認する

既存の給与・役職は独立した合意と権限を維持する。新しい知行の自動割当や全国一律の忠誠減少は行わない。

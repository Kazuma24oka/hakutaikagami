# 0b NPCの判断の土台

通常開始に歴史設定・本人への関わりを接続。共通評価で日・週・月の裁量判断、6性格と4人物の志、現地の相手選び・本人承諾・点検・返報・実支払を確認。関連40件、実保存復旧6段階、旧保存270件のバイト一致、Godot内部操作と自前描画・保存前後の表示一致が成功。

評定は3b、開戦は7、遠方合戦は合戦拡張。歴史設定を領土目標・同盟へ適用する部分は、その候補を追加する後続工程で接続する。志は史料を根拠としたゲーム上の解釈であり、全人物の採録・作成画面での指定は未完了。全国長期性能・ユーザーの試し遊びは未実施。

## 操作と確認

新規開始で歴史への寄せ方（史実尊重・準史実・仮想）と本人への関わり（入門・標準・対等）を選ぶ。既定は準史実・標準。現地で届いた依頼は書状を開くと下部会話に表示され、本人が引受・辞退する。点検後の返報を開き、相手と現地で実在の銭を受け渡す。NPC同士も同じ任務・開封・同意・返報・支払を使う。

日・週・月の間隔は裁量行動を選び直す頻度であり、移動や配送・既存軍務を間引かない。遠方のNPCの所在地を主人公へ公開しない。仮想でも性格と志は保持する。主従や役職・無料報酬・強制受注を加える難易度ではない。

会話はロード時に閉じる既存仕様を保持するため、3D表示の厳密比較は会話を閉じた同じ状態で実施した。世界データは会話に依存せず一致。Godot自身の描画を確認し、OSの画面取得・操作は使用していない。

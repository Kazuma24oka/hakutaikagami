# 0b NPCの判断の土台：実装前の完成条件

固定基準：approval-baseline-v53.json。旧v1〜v3の挙動は保持し、新規開始の版だけへ接続する。

1. 通常開始の同じ成人NPCが既知の用件を優先し、点検・修行・現地の依頼先を共通規則で選ぶ。依頼の受領・本人承諾・実行・返報まで一巡する。
2. 日・週・月の裁量判断を出来事境界へ接続し、既知命令・危険・期限・実行中の作業を待たせない。描画頻度と時間の刻みを変えても判断結果が一致する。
3. 六性格・出典を区別した志・歴史モードの重みを実行する候補へ反映する。重みは知識・権限・同意・実在資源を上書きしない。
4. 入門・標準・対等による本人への関わりを実際の相手選択へ接続する。無料報酬・強制受注・見えない相手の採用をしない。
5. 判断理由と設定を保存し、途中復旧後の同じ未来・旧保存のバイト一致・全件テスト・通常入口の内部操作を工程末尾に検査する。

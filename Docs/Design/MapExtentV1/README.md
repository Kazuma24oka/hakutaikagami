# 地図の範囲と寄り引き V1（2026-11-12）

基準：approval-baseline-v103（BD-20 28→30）。2026-11-12 ユーザーの指示。

- 朝鮮半島の城（倭城など）は百代鏡DBと城の移動網に入れない（書き出しで 129.0°E より西・33.9°N より北を除く。対馬は残る）。城は1,855。
- 地図に今の日本の範囲を描く。今の海岸線（Natural Earth の日本）に北方領土がないため、jpn-atlas 1.0.2（国土地理院「地球地図日本」をもとにした TopoJSON、BSD-3-Clause）から択捉島・国後島・色丹島・歯舞群島の形を取り出して表示だけに足した（Tools/HakutaiDb/build_northern_territories.py → Game/Data/Geography/northern-territories-v1.json）。世界の陸地の判定の海岸線は変えない。
- 琉球（琉球王国）・蝦夷地（アイヌの地）・小笠原の島々は色を変え、操作できない地域として名前を出す。
- 地図の基準の位置は九州〜東北。ホイールでマウスの位置を中心に寄り引き、つかんで移動、Home キーで基準の位置。一番引くと全域（与那国〜北方領土〜南鳥島）、一番寄ると1ドット40m で、城の名前が出る（1ドット350m より寄ったとき）。
- 地図の描き方を軽くした（海岸線の投影を最初の1回だけにし、画面の外の形は描かない）。

確かめたこと：[verification.json](verification.json)。気付いた点：清洲城と清州城が別の城として2つある（戦国DBの重複の候補）。

## 修正（2026-11-12 ユーザーの指摘、加点なし）
- 画面の文言から括弧書き・操作案内・注記を外した（「琉球王国」「蝦夷地」だけ。小笠原には何も書かない。史料の画面の説明文・「推定」「未収録」なども外した）。根拠は記録にだけ書く。
- 琉球につながる道を描かない。城の移動網からも琉球の拠点（首里・那覇・奄美と首里城）を外した（CastleRoutes.Outside）。今までの世界の移動網は変えない。
- 対馬の北に残っていた道は、朝鮮半島の城（西生浦倭城）だった。34.75°N より北・130.5°E より西も朝鮮半島として除いた。
- 地図の海岸線の海の上にあった城（26か所。小さな島が海岸線にない・位置が目安の城）を、一番近い陸の点（15km まで）へ寄せた。城の拠点はすべて陸の上（検査で確認）。城の拠点は1,853・道2,630（海路11）。

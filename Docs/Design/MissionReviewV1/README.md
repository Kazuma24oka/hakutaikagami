# 任務との差異・返報後の暫定審査

BD-29〜32とCC-11に対応する独立試作。入口MissionReviewTrial.tscn、officer-mission-review-v1。既知の担当点検を本人が中断し、既存停止・返報・物理配送へ渡す。主君の取消命令を偽造する操作ではない。中断記録はChronicle、理由は既存Messagingの独立書状に保持。

成果申告・指示との差異申告・本人理由・責任未審査を別欄にする。返報/理由が未認識なら真の結果や内部理由を表示しない。理由だけ先着しても成果は未確認。危険回避は本人の申告であり危険の証明ではない。主君パネルは検証用別人物視点で、主人公への評価通知ではない。処分・忠誠変化は未実装。Task.AssessmentのConfirmedを処分確定と読み替えない。

旧規則・旧保存は保持。新しい保存断面を追加しない。Scripts/verify_mission_review.pyで全テスト、実Godot、別プロセス復旧/続行/画像比較。check_mission_review_binding.pyでソース・バイナリ・テスト・実画像を照合。runtime-localと既存ローカル素材は公開しない。返報不達の故障注入は自動検査のみ。

未送信の理由選択は下書きで保存しない。発送後は既存書状本文から復元し、選択欄は初期値へ戻す。審査欄は直近1件に限定し、Coreは全件を返す。主君の審査内容を主人公が受信したとは扱わない。

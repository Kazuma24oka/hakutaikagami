# 全国の試作地域台帳と家の現地調達

実装前固定：approval-baseline-v8.jsonの5条件。既存30市場拠点へ人口200/労働100/季節・食糧・水利・工房の共通契約を展開する。人口等は調整用で史実値ではない。開始配置から所有者を参照し、所有者未設定なら家の米・木材/武具・金銭を0、領主/処分権を作らない。村落組織と商人は独立。

所有済み地域の家の資金は試作初期500文。本人私財/商人資金/村落資金とは別。現地当主が月次調達予算（初期200文、上限1000文）と任意の私財拠出を設定する。調達は現地の即時取引で、見積・現物受領・支払を別の証拠として同じ原子的操作へ記録する。別地域からの物資輸送/信用買いをこの処理で瞬間移送しない。

NPCは現地の食糧不足を優先して米、次に水利工事に必要な木材を調達する。NPC当主/新規v9で調達月200文までを含むと明示合意した代理官だけ。PC本人の購入は手動、当主不在/代理なしは待機。商人の既引当・納入後の債務資金と家の予算を保護する。予算を下げても旧支払を消さない。

代理官の封書報告に観測時点の家の金銭/物資/予算を加え、物理到達・開封後にのみ当主へ提示。再送は同一観測を維持し、取消は既存の物理受領と認識を分ける。旧v8以下は保持、新規v9のみ。大量の地域で同じ過去を何度も計算しないよう、過去入力の不変性を確認した場合のみ既検証の接頭部を再利用し、ロード/改竄時は全検査する。

全国の史実人口/産地、長距離の家の調達物流、戦時動員と本格AI、外観/UI受入は後続。Computer Use未使用。

# S09A NPCの判断と人物の一生（Persons2V1）

基準：Docs/Development/ProgressV1/approval-baseline-v163.json（実装の前に固定）。一覧の Persons2 の新規の全国開始だけ（全国の家の内政 Domestic2 を使う）。今の保存は変わらない。

- 志：史実人物は立場（当主か）・技能の手がかり・信仰から推定（印つき）。作成武将は本人が人物の画面で選ぶ。兵科適性（槍・弓・騎馬・鉄砲のA〜C）を人物の画面に出す。
- 家の目標と計画：NPCの当主は天下・国の統一・家の存続・奉公のどれかを持ち、家督・京の主・城を二つ失った月・毎年1月に見直す。次に取る国を計画し、出陣の的は計画の国の城を先に、目標ごとの力の差（存続は3倍、天下は1.2倍）で選ぶ。
- 断る条件：約束を破って攻められた家は10年、本拠を奪われた家は5年、相手との同盟を断る。期限が来ると考え直す。理由は知らせが届いた人だけが知る。
- 自発登用：人手の足りない家は、領地にいる主のない成人を一人ずつ召し抱える（全国の家の内政の家中に数える）。
- 役の目標：毎年1月、1年以上務めた郡代（国で一揆・連合）・普請奉行（被害が三つ以上残る）・勘定奉行（赤字・借銀）を振り返り、果たせなければ役を解く（翌月に替わりを置く）。
- 実務の技能：開始の熟練＋役の年数（1年に2、20まで）＋子のうちに家中の師から教わった分（10）−55歳からの衰え（1年に2）。全国の家の役の選び方・普請・監督と、当主の戦術として合戦の力に効く。
- 隠居：60歳を過ぎた当主（毎年1月に3割）か、半年以上意思表示できない当主は、成人の後継がいれば存命のうちに家督を譲る。隠居は名乗りに残る。
- 元服：15歳の年の1月、親の得意な技能から表明した希望を振り返り、家中に師がいれば修行、いなければ役を務めながら学ぶ道を選ぶ。
- 改名の台帳：1467年・1600年の開始でも、その年代の名乗りの記録から年の分かる改名を入れる。

# データの側の範囲の追加（3回目の再評価）

採用した機能の「データの側」（史実人物の値の採録・拠点の新しい値・作成武将での設定）を、60枠の数と重みを変えずに3枠へ足した（2026-10-31 ユーザー決定）。全体は 48.961% → 48.387%（表示50%のまま）。再評価として記録し、加点ではない。コード・テスト・素材は変更していない。

1回目・2回目は統合案の決定の表とバックログの項目を「仕組み」の枠に対応づけたため、値を入れる作業（採録・設定）が、どの決定にも書かれていない横断的な作業として漏れていた。今回、人物・家・拠点に持たせる項目を [Docs/Proposals/CHARACTER_DATA_FIELDS_V1.md](../../Proposals/CHARACTER_DATA_FIELDS_V1.md) に一覧にし、その採録と設定を範囲に入れた。

次の工程（NPCの既知の用件と空き時間の修行）は approval-baseline-v49.json に凍結し直した（v46〜v48 は置き換え済み）。目標は同じ（BD-13 55→60、BD-58 70→71）。

| 枠 | 旧 | 新 | 足した範囲 |
|---|---|---|---|
| BD-05 | 65% | 55% | 作成武将での新しい項目の設定（生年・家系・兵科適性・志・信仰など。Proposals/CHARACTER_DATA_FIELDS_V1） |
| BD-18 | 65% | 50% | 拠点の新しい値の持ち方（開発の4軸と上限・民心・治安・門徒・城の区画の堅さ・寺社の組織・職人集団・名物の所在。CHARACTER_DATA_FIELDS_V1 §3） |
| BD-20 | 12% | 8% | 史実人物の新しい項目の採録（生年・没年・血縁・家系・兵科適性・志・席次・官位・初期の名物など）と拠点の新しい値の初期データ（CHARACTER_DATA_FIELDS_V1） |

# 本人の知識から選ぶNPCの現地依頼

NpcWorkTrial / npc-local-work-v1 / user://npc-work-v1。地域仕事の別規則で、手動発送ボタンを出さず、現地の人物が任意点検依頼を発送する。平時だけの最小試作。通常Main・旧地域仕事・軍議・旧保存を保持する。

## 判断入力と再現

現地の視認範囲80m内に主人公がいること、本人のInspect許可、本人の発送した任意点検、本人が物理返報から知った結果、再提示可能時刻だけを使用する。主人公のWillObeyや未知のNPC事情、遠方の現在値を点数へ混ぜない。実受付は既存Submitで合法性/所在地/拘束を再検査し、不成立なら同じ情報で毎秒試さない。

本人の未確認返報があれば新依頼を重ねず、返報既知でも前発送から3600秒は待つ。間隔は試作用調整値。返報紛失で実際には完了していても、NPCはそれを未確認のまま扱う。新しい本人情報・目撃・期間の変化で再判断し、入力ハッシュが同じなら維持する。NextBoundaryを共通秒時計に加え、処理予算に最大3人の判断/受付6処理を予約する。別時計や画面更新依存のNPC更新はない。

## 保存と履歴照合

ContractWorldのNpcWork欄は新規則だけ必須、旧規則では省略し既存JSONを変えない。共通の厳格JSON読込で任意拡張として明示登録。判断ごとに日時・参照Revision・入力・入力ハッシュ・根拠コード・提案ID・受付結果を保持する。同じ秒の発送後に増えた本人任務を入力へ逆混入させないよう、参照Revisionを保存する。

保存時は記録時点の実移動経路から視認を再検査し、当人の発送履歴とその時点までの受領知識、許可期間、再提示期間から入力/根拠を再構成する。ハッシュだけ合わせた虚偽入力も拒否。内部判断記録を主人公のUIへ流さない。世界と主要結果は固定Seed/入力で再現し、粗い時間進行と細かい進行でも依頼・履行の主要結果を比較する。

初期版ではNPCは本拠候補に固定した既存配置。生死/任命/移動の完全な人物史を追加したときは、過去照合の入力履歴を対応させる必要がある。新平時プロファイルは野外展開を拒否し、過去の戦場位置を不正に推測して照合しない。これはゲーム全体から戦時を削る変更ではない。

## 描画差分の修正

最初の実GPU比較で小田原の樹冠の1画素が復旧後に異なった。許容差は増やしていない。重なった樹冠の多面体の同位相面と描画順による深度競合と推定し、3層それぞれに固定角0.17rad刻みを付けて重なりを解消。半径・配置・Core通行判定は維持する。修正後の同じ5復旧比較で差分0を確認し、全体を再実行する。全環境の無差分を保証したとは扱わない。

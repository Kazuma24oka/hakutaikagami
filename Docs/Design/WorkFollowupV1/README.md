# 任務の結果から次の用件へ

完成条件は4件。1. 新規開始のV3で、運搬の受渡し・現地報告・運賃受領の完了により、同じ荷主の次の荷物が100→200→300文（上限）、運賃20→30→40文になる。点検評価からの既存200文開始も継承する。2. 荷物を預かる前の中止は増減せず、預かった荷物を返却した場合は次を100文/20文から再開する。処罰や過失認定ではない。未返却・報告待ち・未払い中は重複発注しない。3. 会話で次の用件が変わった理由と固定条件を示し、古い原本や他の荷主の条件は変えない。4. 実在の私財・預り金・運賃を動かし、途中保存・復旧と実3D表示まで確認して同じ枝へpushする。

旧V1/V2保存の発注回数・金額規則は維持し、新規開始だけをV3にする。300文/40文は試作上限であり、政治役職、一般の信用度、他人に見えない成果、責任処分を自動で付与しない。次の条件はその原本発行より前に確定した受渡し履歴から算出する。元の依頼を取り消して金額だけ付け替える操作ではない。

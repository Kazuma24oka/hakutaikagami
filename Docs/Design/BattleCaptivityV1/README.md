# 合戦での捕縛と処遇 V1（BD-44・BD-06・C7、2026-11-13〜14）

本人の軍が打ち崩した敵の軍の大将を捕らえ、捕らえた家の拠点に留め置き、当主が明示に処遇を選ぶ。統合案§21 C7 と、捕虜交換（Docs/Proposals/MORI_MOTONARI_CAPTIVE_EXCHANGE.md）の前提になる拘束の原本。

- 捕縛：交戦の手番で、本人の軍の部隊が打撃を与えた敵の軍の全部隊の士気が初めて30以下になったとき、その軍の大将を固定シード（人物と日）で35％の確率で捕らえる。死んでいる者・すでに拘束中の者は捕らえない。記録は交戦の手番（WorldClashStep.Captures）に残し、保存の検証で手番の前の世界から再計算して一致を確かめる。
- 拘束：捕らえた家の出陣した城に留め置く。所在（PersonalCompanions.PhysicalSiteAt）と道の上の位置（RegionalCampaign）は捕縛の秒の後から城になる。拘束中は HostageCustody.HeldAt が真になり、日課・相談・政務など拘束を見る仕組みは新しい行動を始めない。拘束中の当主は家の権限（FactionStances.ResolveAuthority）を持たない。
- 処遇（WorldSession.ManageCaptive）：捕らえた家の当主権限を持つ者が、留め置いている拠点で選ぶ。何もしなければ留め置く。
  - 解放：拘束が終わり、本人が自分で旅に出るまでその拠点にいる。
  - 登用の誘い：応じるかは捕虜本人の判断。元の家の当主は応じない。それ以外は捕縛ごとに固定の判定で4割ほどが応じる。断られたら同じ捕縛の間は誘い直せない。応じると所属と主従だけが捕らえた家と誘った当主へ移る（NewGameService の所属の再計算に BattleCaptivity.Relations を差し込む）。所領・兵・私財・役職は移さない。
  - 処断：その場で死亡する。死亡記録（NaturalDeath.Execution に操作のID）は寿命・傷病による死と同じ流れ（訃報・後見・家督）に乗る。
- 亡くなった本人が自分に出す行動の報告は、この規則の世界では出さない（FamilyMortality。道の途中で亡くなると報告の出発点がなく、配送の割り当てで止まっていた）。保存の検証は、死亡で止めた本人の行動に報告がないことを認める。
- 版：全国の開始の一覧（NationalSystems の BattleCaptivity）と、検査用の地方の版の方針（NewGameState.CapturePolicy）だけで有効。旧保存は変えない。
- 自動の処刑・登用・解放はしない。

## 確かめたこと（Tests/BattleCaptivityTests）
- 捕縛・拘束・保存から戻して同じ・捕縛の記録の改ざんを読まない。
- 拠点にいなければ処遇できない。城に戻れば解放でき、解放の後は処断できない。
- 処断で死亡し、死亡記録は処断の操作を指す。死亡記録から処断を消した保存は読まない。死者には何もできない。
- 登用の誘い：検査の場面の捕虜は元の家の当主（織田信長）なので断る。断った後は誘い直せない。返答を書き換えた保存は読まない。
- 登用に応じた場合の所属と主従の付け替え（記録を直接作って確かめた）。実際の合戦の場面で当主以外の大将が応じる一巡は未実施（その場面を作れる全国の開始での検査が要る）。
- 各処遇の後、保存から戻して1時間進めて同じ。

## 残り
- 身代金・捕虜交換の書状と受渡し。当主が捕らえられた家には返事をする権限者がいないため、当主以外の大将が捕まる場面（全国の開始）で作る。
- 処断が周りから「苛烈」と見られること（名声の仕組みが未実装）。
- 捕らえた者の護送（今は捕らえた時点から城に留め置く）。
- 相手の家が捕縛を知る経路（今は本人の家だけが知る）。
- 本人の側の武将が捕らえられること。NPC どうしの合戦（全国の家の戦略）での捕縛。
- 大将を失った軍の扱い（今は捕らえる前の行軍がそのまま続く）。

# 合戦での捕縛と処遇 V1（BD-44・BD-06・C7、2026-11-13〜14）

本人の軍が打ち崩した敵の軍の大将を捕らえ、捕らえた家の拠点に留め置き、当主が明示に処遇を選ぶ。統合案§21 C7 と、捕虜交換（Docs/Proposals/MORI_MOTONARI_CAPTIVE_EXCHANGE.md）の前提になる拘束の原本。

## 家臣が NPC の軍を率いる（NpcArmies、RetainerCommand）
- NPC の当主は、城にいる直属の家臣（同じ家の成人で当主に直接仕え、ほかの用件・軍・拘束・療養がない者。人物IDの順で最初の者）を大将にして軍を出す。いなければ当主自身が率いる。
- 出陣を決めるのは当主（NpcArmyMuster.Lord）。権限と既知の敵対意思は当主のものを使い、当主は城に残る。命令は同じ城で直接伝える。
- 全国の開始の一覧（RetainerCommand）と、捕縛の検査用の地方の版だけで有効。旧保存は当主自身が率いるまま。
- これで当主以外の大将が捕まり、当主が家の権限を保ったまま身代金などに答えられる。

## 出陣の決着での捕縛（2026-11-14、全国の開始の一覧の StrategyCapture）
実際の軍勢の出陣（NationalStrategy の Real）が退き、攻め手の軍が崩れていれば（遠方の合戦の計算のないときは常に）、守る家が軍の大将を35%で捕らえる（出陣と人物の固定のくじ）。拘束は合戦の捕縛と同じに扱い（StrategyOutcome.Capture を BattleCaptivity の捕縛の一覧に含める）、出陣の城に留め置く。軍は散る。守る家が本人の家なら本人が処遇できる。検査は Tests/StrategyRealArmyTests（くじを当たりに固定して記録・検査・留め置きを確かめる）。

## NPC の当主の処遇（2026-11-14、一覧の NpcCaptors）
NPC の家が捕らえた者は、捕らえた家の当主が、捕縛の1日後に捕虜の家の当主へ身代金500文を書状で求める（BattleCaptivity.NpcCaptorTurns）。相手の当主は届いた書状を開封して、私財で払えて上限以内なら払う（今までの返書の決まり）。返書が届けば捕らえた当主がすぐ開封し、払われていれば、その城にいるときに放つ。断られたら、返書の30日後に、その城にいるときに放つ。NPC は登用の誘い・処断をしない。互いに相手の家の者を捕らえている二つの NPC の家は、家の ID の小さい側の当主が身代金の代わりに書状で引き換えを申し入れ、相手の当主は開封して応じ（自分の家の者が戻るため）、自分の捕らえている者を放つ。受諾が届くと申し入れた側も放つ（Tests/NpcCaptorTests.cs の NpcCaptiveExchangeTests）。双方の護送と受け渡しの場は残り（今はそれぞれ留め置いた城で放つ）。検査は Tests/NpcCaptorTests（書状の配送の時刻まで時計を進め、求める・払う・放つ・銭の移りを確かめる）。

## 大将を捕らえられた軍は散る（2026-11-14）
全国の開始の一覧の ArmyRout と、捕縛の検査用の地方の版だけ。大将が捕らえられた軍は、次の手番で城へ帰らずその場で解ける（NpcArmyReturn.Routed）。携えた兵糧は使った分までで、城に残した兵糧は家へ戻す。兵は自分の城へ戻ったものとし（軍の位置は城）、交戦に加わらない。旧保存の全国の世界では今までどおりその場に残る。検査は BattleCaptivityTests の最初の検査に足した。
- 私財の計算の直し：捕虜の解放の願いで銭を受け取る当主は合戦の捕縛の記録にだけ名前が出るので、私財をまとめて求めるときの対象に入れる（SocialWorld.MoneyPeople。入れていなかったため銭の総量が合わなかった）。

## 捕縛と拘束
- 捕縛：交戦の手番で、本人の軍の部隊が打撃を与えた敵の軍の全部隊の士気が初めて30以下になったとき、その軍の大将を固定シード（人物と日）で35％の確率で捕らえる。死んでいる者・すでに拘束中の者は捕らえない。記録は交戦の手番（WorldClashStep.Captures）に残し、保存の検証で手番の前の世界から再計算して一致を確かめる。
- 捕らえた人の行動（軍の行軍など）は捕縛の秒で終わる。本人あての報告は出さない。大将を捕らえられた軍は新しい行軍を始めない。
- 拘束：捕らえた家の出陣した城に留め置く。所在（PersonalCompanions.PhysicalSiteAt）と道の上の位置（RegionalCampaign）は捕縛の秒の後から城になる。拘束中は HostageCustody.HeldAt が真になり、拘束を見る仕組みは新しい行動を始めない。拘束中の当主は家の権限を持たない。

## 本人が捕らえられる（BD-06、PlayerCapture）
- 本人が率いる本隊（本人が指揮する部隊、なければ最初の部隊）が NPC の軍の打撃で初めて士気30以下になったとき、同じ判定（固定シードで35％）で本人を捕らえる。当てた軍の家が、その軍の城に留め置く（捕らえた人の欄は軍を出した当主）。
- 捕らわれている間は軍務の判断を受け付けない。通常の用件も受け付けない（既存の拘束の判定）。ゲームは終わらない。
- 解放の願い（CaptiveAction.Plead）：本人が500〜3000文を差し出して、捕らえた家の当主へ解放を願う。当主がその城にいて権限を持つときだけ答え、本人の私財で払えれば応じる。応じると拘束が終わり、銭は本人から当主へ移る。願いは1日に1回。
- 捕虜の引き換え：捕らわれた本人が当主の家が、本人を捕らえた家の者を捕らえていれば、その者を放つことと引き換えに解放を願える（銭は要らない）。当主は自分の家の者が戻るなら応じ、二人はそれぞれ留め置かれていた城で放たれる（護送と受け渡しは残件）。
- 全国の開始の一覧（PlayerCapture）と、捕縛の検査用の地方の版だけで有効。

## 処遇（捕らえた家の当主権限を持つ者が選ぶ。何もしなければ留め置く）
- 解放（城にいるとき）：拘束が終わり、本人が自分で旅に出るまでその城にいる。
- 登用の誘い（城にいるとき）：応じるかは捕虜本人の判断。元の家の当主は応じない。それ以外は捕縛ごとに固定の判定で4割ほどが応じる。断られたら同じ捕縛の間は誘い直せない。応じると所属と主従だけが捕らえた家と誘った当主へ移る。所領・兵・私財・役職は移さない。
- 処断（城にいるとき）：その場で死亡する。死亡記録（NaturalDeath.Execution）は寿命・傷病による死と同じ流れ（訃報・後見・家督）に乗る。
- 身代金（書状、BattleCaptivity.Ransom）：捕虜の家の当主へ100〜3000文を求める。相手は届いた書状を開封した時点で、額が1500文以内で本人の私財で払えれば払い、そうでなければ断る（捕虜の本当の状態は知らない）。払う銭は返書と一緒に運ばれ、出した時点で相手の私財から減り、本人が返書を開封した時点で本人の私財に入る。受け取っても自動では解放しない。1回の捕縛で求められるのは1回。私財の規則（NewGameWork）のある世界だけ。
- 自動の処刑・登用・解放はしない。
- 亡くなった本人が自分に出す行動の報告は、この規則の世界では出さない（道の途中で亡くなると報告の出発点がなく、配送の割り当てで止まっていた）。

## 確かめたこと（Tests/BattleCaptivityTests）
- 当主自身が率いる軍：捕縛・拘束・保存から戻して同じ・捕縛の記録の改ざんを読まない。城にいなければ処遇できない。解放・処断（死亡記録の改ざんを読まない、死者には何もできない）・登用の誘い（当主なので断る、誘い直せない、返答の改ざんを読まない）。各処遇の後、保存から戻して1時間進めて同じ。
- 家臣が率いる軍：当主は城に残り権限を保つ。捕らえた家臣は本人の判断で登用に答える（この場面では断った）。身代金500文は払われ、当主の私財が500減り本人が500増える。2000文は断られ銭は動かない。支払額を書き換えた保存は読まない。保存から戻して1時間進めて同じ。
- 引き換え：同じ合戦で本人と相手の家臣が互いに捕らわれ、本人が家臣を放つことと引き換えに願うと、二人とも放たれ、それぞれの城にいる。引き換えの記録を消した保存は読まない。保存から戻して1時間進めて同じ。
- 本人の捕縛：退く途中で本隊が打ち崩され、本人が織田家の清洲城に捕らわれる。軍務の判断は断られる。100文の願いは受け付けず、500文の願いに城にいた信長が応じて解放され、銭が移る。差し出した額を書き換えた保存は読まない。保存から戻して1時間進めて同じ。
- 登用に応じた場合の所属と主従の付け替えは、記録を直接作って確かめた。実際に応じる一巡は、この場面の判定が断りのため未実施。

# 合戦での捕縛と処遇 V1（BD-44・BD-06・C7、2026-11-13〜14）

本人の軍が打ち崩した敵の軍の大将を捕らえ、捕らえた家の拠点に留め置き、当主が明示に処遇を選ぶ。統合案§21 C7 と、捕虜交換（Docs/Proposals/MORI_MOTONARI_CAPTIVE_EXCHANGE.md）の前提になる拘束の原本。

## 家臣が NPC の軍を率いる（NpcArmies、RetainerCommand）
- NPC の当主は、城にいる直属の家臣（同じ家の成人で当主に直接仕え、ほかの用件・軍・拘束・療養がない者。人物IDの順で最初の者）を大将にして軍を出す。いなければ当主自身が率いる。
- 出陣を決めるのは当主（NpcArmyMuster.Lord）。権限と既知の敵対意思は当主のものを使い、当主は城に残る。命令は同じ城で直接伝える。
- 全国の開始の一覧（RetainerCommand）と、捕縛の検査用の地方の版だけで有効。旧保存は当主自身が率いるまま。
- これで当主以外の大将が捕まり、当主が家の権限を保ったまま身代金などに答えられる。

## 捕縛と拘束
- 捕縛：交戦の手番で、本人の軍の部隊が打撃を与えた敵の軍の全部隊の士気が初めて30以下になったとき、その軍の大将を固定シード（人物と日）で35％の確率で捕らえる。死んでいる者・すでに拘束中の者は捕らえない。記録は交戦の手番（WorldClashStep.Captures）に残し、保存の検証で手番の前の世界から再計算して一致を確かめる。
- 捕らえた人の行動（軍の行軍など）は捕縛の秒で終わる。本人あての報告は出さない。大将を捕らえられた軍は新しい行軍を始めない。
- 拘束：捕らえた家の出陣した城に留め置く。所在（PersonalCompanions.PhysicalSiteAt）と道の上の位置（RegionalCampaign）は捕縛の秒の後から城になる。拘束中は HostageCustody.HeldAt が真になり、拘束を見る仕組みは新しい行動を始めない。拘束中の当主は家の権限を持たない。

## 処遇（捕らえた家の当主権限を持つ者が選ぶ。何もしなければ留め置く）
- 解放（城にいるとき）：拘束が終わり、本人が自分で旅に出るまでその城にいる。
- 登用の誘い（城にいるとき）：応じるかは捕虜本人の判断。元の家の当主は応じない。それ以外は捕縛ごとに固定の判定で4割ほどが応じる。断られたら同じ捕縛の間は誘い直せない。応じると所属と主従だけが捕らえた家と誘った当主へ移る。所領・兵・私財・役職は移さない。
- 処断（城にいるとき）：その場で死亡する。死亡記録（NaturalDeath.Execution）は寿命・傷病による死と同じ流れ（訃報・後見・家督）に乗る。
- 身代金（書状、BattleCaptivity.Ransom）：捕虜の家の当主へ100〜3000文を求める。相手は届いた書状を開封した時点で、額が1500文以内で本人の私財で払えれば払い、そうでなければ断る（捕虜の本当の状態は知らない）。払う銭は返書と一緒に運ばれ、出した時点で相手の私財から減り、本人が返書を開封した時点で本人の私財に入る。受け取っても自動では解放しない。1回の捕縛で求められるのは1回。私財の規則（NewGameWork）のある世界だけ。
- 自動の処刑・登用・解放はしない。
- 亡くなった本人が自分に出す行動の報告は、この規則の世界では出さない（道の途中で亡くなると報告の出発点がなく、配送の割り当てで止まっていた）。

## 確かめたこと（Tests/BattleCaptivityTests）
- 当主自身が率いる軍：捕縛・拘束・保存から戻して同じ・捕縛の記録の改ざんを読まない。城にいなければ処遇できない。解放・処断（死亡記録の改ざんを読まない、死者には何もできない）・登用の誘い（当主なので断る、誘い直せない、返答の改ざんを読まない）。各処遇の後、保存から戻して1時間進めて同じ。
- 家臣が率いる軍：当主は城に残り権限を保つ。捕らえた家臣は本人の判断で登用に答える（この場面では断った）。身代金500文は払われ、当主の私財が500減り本人が500増える。2000文は断られ銭は動かない。支払額を書き換えた保存は読まない。保存から戻して1時間進めて同じ。
- 登用に応じた場合の所属と主従の付け替えは、記録を直接作って確かめた。実際に応じる一巡は、この場面の判定が断りのため未実施。

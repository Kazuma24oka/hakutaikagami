# 合戦での捕縛 V1（BD-44・BD-06、2026-11-13）

本人の軍が打ち崩した敵の軍の大将を捕らえ、捕らえた家の拠点に留め置き、当主が明示に解放する。統合案§21 C7 の入口と、捕虜交換（Docs/Proposals/MORI_MOTONARI_CAPTIVE_EXCHANGE.md）の前提になる拘束の原本を作る。

- 捕縛：交戦の手番で、本人の軍の部隊が打撃を与えた敵の軍の全部隊の士気が初めて30以下になったとき、その軍の大将を固定シード（人物と日）で35％の確率で捕らえる。死んでいる者・すでに拘束中の者は捕らえない。記録は交戦の手番（WorldClashStep.Captures）に残し、保存の検証で手番の前の世界から再計算して一致を確かめる。
- 拘束：捕らえた家の出陣した城に留め置く（所在は PersonalCompanions.PhysicalSiteAt）。拘束中は HostageCustody.HeldAt が真になり、日課・相談・政務など拘束を見る仕組みはすべて止まる。捕らえた手番で、進行中の行動を終える。
- 解放：捕らえた家の当主権限を持つ者が、留め置いている拠点で行う（WorldSession.ManageCaptive）。解放された人は、自分で旅に出るまでその拠点にいる。所属・主従・所領・兵は動かさない。
- 版：全国の開始の一覧（NationalSystems の BattleCaptivity）と、検査用の地方の版の方針（NewGameState.CapturePolicy）だけで有効。旧保存は変えない。
- 自動の処刑・登用・解放はしない。

## 残り
- 身代金・捕虜交換の書状と受渡し、登用の勧誘、処断（いずれも当主の判断として）。
- 捕らえた者の護送（今は捕らえた時点から城に留め置く）。
- 相手の家が捕縛を知る経路（今は本人の家だけが知る）。
- 本人の側の武将が捕らえられること。NPC どうしの合戦（全国の家の戦略）での捕縛。

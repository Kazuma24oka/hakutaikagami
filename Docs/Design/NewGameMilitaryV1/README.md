# 新入口の同一人物における軍務貸与

## 完成条件
1. 選択人物の認識済み主君に現地で軍務を申し出、封書の提示・本人回答・相手の物理受領・本人の許可認識を区別する。
2. 許可だけでは兵を動かせず、現地引受後にのみ配置・保持・帰還と現地の兵糧受渡しができる。兵・米の所有は主家に残す。
3. 本人と隊を同じ継続世界の地形上で移動させ、兵糧を人秒で消費し、道路移動と野外行動を重ねない。
4. 帰還・残量返納・帰還後現況返報の主君受領・返還願い受領が揃って指揮を返す。軍務未返還なら辞去を待つ。
5. 通常入口からの操作、全単体テスト、複数開始条件の途中保存と別プロセス復旧で全世界・本人表示・3D画像の一致を確認する。

## 構成と試作条件
旧CareerMilitaryの清洲・信長専用初期世界は変えない。新入口用の人物別貸与台帳を、共通の世界時計・物理伝令・封書・地形経路・資源ロットへ接続する。全国の兵数や収入モデルを創作で確定させないため、開始配置に対応した貸与元演習名簿100人（40/30/30）と主家在庫10日分、携行上限2日分を明示する。これは史実兵数ではない。演習名簿・在庫の保存表現は最初の軍務申し出時に遅延実体化し、所属・許可からプレイヤーの私兵や私有米を生成しない。未使用の旧新規保存は従来の省略形を維持する。

開始DefinitionPackは不変とし、動的軍名簿は軍務モジュールの明示したArmyEntryから検査する。元のGenerationSaveStoreの定義一致検査を緩めない。

一人生一貸与の最小接続を先に検査する。交戦・損耗・再任・給与・出世は後続。自由な配置は共通地形経路と予約を用い、海上布陣を許さない。許可・返還の照会は物理返書で情報を回復し、原通知の正式開封は偽造しない。

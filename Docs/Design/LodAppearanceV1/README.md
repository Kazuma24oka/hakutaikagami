# 倍率をまたぐ外観と地名

中景も既存SceneryAppearanceの役割IDとskinから材質色を取得し、独自の固定パレットを持たない。粗い中景では材質色を使用し、細部テクスチャや実モデルは詳細表示の役割。skinとgeometryの変更を分離し、既存世界・移動判定・保存契約を保持。

地名は既存のシステムフォントで測定し、投影後の画面矩形で重なりと画面外を除く。現在の中心に近い順、同距離ならID順を固定。隠れた地名は削除せず、拡大/視点変更で再評価。文字と縁取りの描画順を経路線より前へ固定する。

中景で細い地形道路が省略されても、概略経路線は同じ道路/水面の外観IDの材質色を参照する。経路線は通行幅を示す地形ではなく概略表示。全国図の既存記号色は維持。

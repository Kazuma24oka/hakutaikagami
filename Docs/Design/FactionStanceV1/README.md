## 実装した挙動

`FactionStances`は借用中の軍務台帳ではなく世界に保存する。当主の敵対意思は方向を持ち、自家の意思を撤回しても相手の意思は終了しない。将来時刻の指定と、発効前の撤回を扱う。何も記録されていない既存開始では、勝手な敵対勢力を置かない。

これは当主の意思を表す段階で、二国間の条約・正式な宣戦通知・相手の承諾ではない。敵対意思の決定によって部隊や報酬を生成しない。軍務の現地引受の権限と政治判断の権限は別に検査する。

本人が知るのは自分の決定か、実際に開封した軍務書状の引用。書状には原判断のID・対象・期間・確認時刻を固定する。同じ主家というだけでは知識を与えない。照会返書を開いた場合も引用元の確認時刻を保つ。主君が後で撤回した場合、真実は変わっても古い書状の情報はそのまま残る。

`WorldSession.DecideFactionStance`は操作対象の本人だけを受け付ける。NPC側の判断処理が使うドメイン操作も、実在の当主権限を検査する。NPCの自律的な開戦判断・部隊出陣や新しいGUIはまだ接続していない。

# 1560年開始版の朝廷との取次

山科言継（1507〜1579）は戦国期の公家で、自筆日記『言継卿記』が残る。国書データベースの所蔵記録には永禄三年分の写本がある。[東京大学史料編纂所蔵の日記について](https://www.u-tokyo.ac.jp/focus/ja/articles/t_z0206_00009.html)・[国書データベースの書誌](https://kokusho.nijl.ac.jp/work/001486244)

新しい開始版では京を言継との初回面会地点に置く。この配置と依頼への返答はゲーム上の設定。開始日の在京、武家伝奏への補任、特定大名との交渉成立は史実として登録しない。面会や贈答は取次本人との関係に記録し、官位の授与や軍事権限は別の発給原本を必要とする。

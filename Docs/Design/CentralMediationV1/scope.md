# 中央政治の取次・任官と仲裁

1. 実在の取次役について人物と時期の根拠を記録し、現地の面会・贈答と本人の判断により取次を依頼する
2. 官位奏請と幕府職の申請を別の原本で扱い、返答が届いた受任者だけに実効範囲を付与する
3. 将軍・朝廷・寺社を通じた仲裁案を両家へ運び、同じ条件への各家の承諾を既存の条約へつなぎ、拒否の事実と認識時点を残す
4. 通常画面を通して未着情報・二重授与を防ぎ、途中保存と復旧後の成否・権限・表示を照合する

第14節の工程9。朝廷・幕府の取次・授与・仲裁の代表一巡を対象にする。将軍擁立・任官の到達点は次段9a。各枠の残りは時期別の史料整備・全国での長期運用など。

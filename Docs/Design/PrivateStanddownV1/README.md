## 完成条件

1. 本拠で当主本人に会い、本人への情報料精算を確認して提示原本に場所・本人・権限・時間・金額を固定する。
2. 打診では支払わず、同じ提示の30ゲーム秒以内の合意で私財100文を本人の財布へ同額移す。家の蔵・兵・主従は変えない。

4. 途中と期限後の実世代復旧で将来世界・財布・協力表示用データとNode3D座標が一致し、旧null保存を変えない。

## ゲーム上の流れ

現地の私的情報交換を精算した当主本人へ「秘密の協力」から相談する。1〜24時間の提示を聞き、同じ条件を30ゲーム秒以内に確認して私財100文を支払う。打診だけではお金も行動も変わらない。受け取るのは当主個人の財布であり、国庫や軍用備蓄ではない。

見合わせる対象は、未出陣の当主本人が次に駐屯兵を引き受ける行為だけ。当主が敵対意思を示しても期間中は本人の新規引受をしない。家全体の不戦や従属ではなく、他人の軍・既に出陣した軍・貸与済み駐屯兵を止めたり戻したりしない。期限後は通常の判断へ戻り、行軍時間・敵対期間・経路等を満たす場合だけ出陣する。期限到来が無条件の出撃命令になるわけではない。

費用100文、1〜24時間、確認期限30ゲーム秒、精算済み接触を必要とする条件は限定試作の共通調整値。歴史人物の実際の忠誠や性格を表現した数値ではなく、一般の内応成功率/対案/拒絶性格を完成させたものでもない。

## 知識と再現性

当事者以外へ自動通知しない。プレイヤーの協力一覧は自分の合意だけを表示する。敵側の隠れた新規状態を一覧へ加えない。正規APIは本人の操作とrevisionを確認し、同一IDの再送で二重払いしない。期限切れ・遠隔合意・時間の差替え・他人の操作・既存軍の引戻しを拒否する。支払原本・面識・提示時間を保存復旧でも再検証する。

履歴検査では未来の支払いを過去の財布に含めない。NPC自身の過去の判断入力も、その時点の依頼/移動履歴から所在地を復元し、現在の出陣位置で書き換えない。この修正は新しい明示版に限り、旧null/v1/v2/v3保存の入力を変えない。

## 実行と限界

実際に敵対通知が届き、当主が自分の敵対意思を示しても約束期限直前まで引受0件。期限到来後、通常の条件を満たして駐屯兵100人を引き受け、共通道路上の実移動へ進む。見合わせ中と出陣後をGenerationSaveStoreで保存/復旧し、世界全体と本人向け一覧、将来進行が一致。既存の交戦・不戦交渉・随行・経済・道/運搬/財布を合わせて607件実施した。

通常画面への導線と条件会話は実装・ビルドまで。実際の画面操作・画面取得・見た目確認はしていない。仮3D素材を追加していない。

正式な内応、一般家臣や全軍への約束、反故/返金、露見、主君の処罰、忠誠変化、自衛時の例外、城門開放、所属・城・兵の移転は未実装。R4全体完成とはしない。

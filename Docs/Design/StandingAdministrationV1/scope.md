# 奉行の常置・定例評定と家の方針

1. 常設奉行に年度経費と優先分野・収穫期の回避を示し、本人受領・承諾後だけ普請を任せる
2. 奉行が現地の既知資源・労働・年度残枠から同じ普請を実行し、現地の観測月報を物理配送する
3. 年始と毎月朔日の定例評定を既存の招集・実参集に接続し、NPC当主も同じ評定を使う
4. 評定で決めた家の方針は本人の受領後に判断へ反映し、遠方の結果・未受領方針を漏らさない
5. 関連重大不具合・途中保存の同じ未来・通常入口と代表旧保存を確認する

検査：本人の受領前後・現地・年度残枠・収穫期・解任と当主交代・月報の開封前後・実参集・途中保存復旧を代表確認。全件と全国長期性能は未実施とする。

# 身分別の生活・待遇・戦時負担 V1

実装前固定基準approval-baseline-v17.json。新規v18のみ。金欠でも徒歩移動と仕事探しを続ける。

食事は明示操作。給付された私有米か、本人が現地商人から実購入した米を消費する。家の米・軍の兵糧とは別。食料不足で強制死亡や移動封鎖を追加しない。

拠点で無料4時間の野外休息、有料10文/2時間の宿泊休息を選ぶ試作値。全世界は共通時計で進む。自動で時間を飛ばさず、通常の進行と停止を使う。途中中止しても時間と支払は戻さない。休養時間を記録するが負傷治療/能力上昇/移動速度ボーナスを捏造しない。預かった部隊や進行中の任務がある間の休息は拒否する。

認識済みの所属/直属と、私財・給付債権/債務・私有米・引受済み軍務/現物預りを分けて表示。遠隔の現在庫や部下の本心は出さない。身分だけで他人の資源を使わせない。

当面の個人目標は仕事報酬の受領、扶持米の受領、家臣への扶持支払の三種。設定後の実受領だけを積算し、後で売却/消費しても既達成を失わない。途中変更可能、目標達成で世界を終了しない。

将来の飢餓/健康・宿の実史料・疲労の速度影響・全NPCの生活・家督と全国収支の製品調整は後続。GUI/外観とCLIデータ検証は分ける。

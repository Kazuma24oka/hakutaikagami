# S12 最初の完成版の一巡の受入と試し遊び（FirstReleaseV1）

基準：Docs/Development/ProgressV1/approval-baseline-v170.json（コードを書く前に固定）。新しい振る舞いは、一覧（NationalSystems）に Finish2 のある新規の全国開始だけ。中心は Core/Contracts/Finish2.cs。

## 残りの機能（条件1〜5）
- 勲功：陣へ兵糧を届けた家の兵站の者に「兵糧」の勲功。出陣が決着した月に当主が手柄を比べて順を定め（落城・加勢・兵糧）、兵糧の者が先を争えば理由を示して裁く。名声の風化は前からある（SocialWorld の RenownStrength：大きな評判は1年に1、普通は30日に1減る）。
- 通行：境に攻める城の無い家は、同盟の家の領地を通って先の城を攻めることがあり、通る家に申し入れる。許せば出陣、断られれば見送るか、無断で通って抗議を受け盟約が切れる。
- 駐屯兵：帰還したNPCの軍の駐屯兵と大将は、次の出陣に割り当て直せる。
- 兵糧攻めの開城：城の兵糧が足りず、守り手の水軍が攻め手を上回らず（水路から米が入らない）、攻め手が1.5倍以上なら開城する。
- 大将の身の武勇：武勇と剣術（3対1）。兵種の技能は統率を上限に別に足す（二重に足さない）。
- 務め：傷病のある本人は、頼まれた務めを返還・代理・延期で返上でき（帳面の人物の面）、癒えたら復帰の確かめを記録する。陣触れは併用の表に入り、捕らわれ・療養の者は応じない。役は代わりの者へ一人ずつ分けて引き継ぐ（Duties2）。開封は家老がいなければ後見、それもいなければ正室。
- 兵糧の援け：兵糧の足りない家は同盟の家へ書状で援けを求め、余りのある家は送り、敵を避ける道の日数で届く。
- 外交と中央：同盟を結んだ次の月に弱い側の一族を人質に出し、盟約が終われば預かる家の当主が返すか留め置くかを決める（処刑はしない）。将軍の仲裁で和睦すると「単独で和睦しない」の盟約や包囲網に背くなら、理由を添えて断る。従属の不履行は、証拠（記した者）・当主が知る日・責任（当主か、不在の間に代わって決めた家老か）を分けて記録する。流言の出所を目付が突き止める。栄典に御相伴衆・裏書御免・屋形号・塗輿の免許・申次衆・御部屋衆を足した。
- 人物と史料：寺社の住持・別当（推定）、未成年の子の開始時の興味（推定）、登用の例外（60歳以上は隠居を望む・天下を志す者は京の主にしか仕えない・家を滅ぼした家には仕えない）。

## 直した不具合
- 離反の記録の検証が、国人の鞍替えの通知で解けた従属と、主家が違反で従属を解いた記録（違反の記録は一年で間引かれる）を拒んでいた。10年の長い受入で保存の検証が通らないことで見つかった（前の工程 S09C・S09E からの不具合）。

## 長い受入（条件6）
全国の信長の開始を、月の家の戦略で1560年6月から1570年12月まで進めた（この機械で約5分）。出陣1018・落城480・約束393・包囲網60・滅亡126・離反25・家督18・婚姻25・史実の事件8・人質271など。最後の2年も出陣と外交が起き、1565年1月の保存から続けた世界と同じ要約になった。1650年の総括、全国の開始の武将の負傷も確かめた。日ごとの細かい進行（1日46.7秒）で10年を進めることはしていない。

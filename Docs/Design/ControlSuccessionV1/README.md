# 操作の引き継ぎ V1（BD-07・BD-08、2026-11-12・後見 2026-11-13）

操作する人物が死ぬと世界が止まり、本人が知っていた成人の実子・養子から一人を選んで続ける。後継に指名した人が先頭、あとは生年の順。候補がいなければ年代記を閉じてスタート画面へ戻る。存命のうちの隠居でも、同じ候補へ操作を譲れる。

- 版：`NewGameState.ControlPolicy = control-handover-v1`。新規ゲームと全国開始で付く。版のない旧保存は今までどおり（死んでも止まらず、引き継ぎはない）。
- 記録：`ContractWorld.ControlHandovers`（前の人・次の人・時刻・版・理由〈death / retire / guardian〉、後見なら後見する子）。書き換えは検査で拒む。
- 未成年の後継：成人の候補がなく、本人が知っていた未成年の子がいれば、その子のもう一方の実の親か、亡くなった本人の兄弟姉妹（生きている成人）を後見として続けられる。子が元服したら、隠居で最初の候補としてその子へ譲れる。
- 操作の引き継ぎと家督は別。家督・所領・兵・私財・記憶は移さない。次の人は自分の知識だけで続ける。
- 過去の記録の検査は「その版で操作していた人物」で行う。版（at・rev）を受け取る関数（Core の約450）と、記録を順に検査するループの先頭で `ControlContext` に版を置き、その間に読む `PlayerControl` はその版で操作していた人物になる。引き継ぎの記録がない世界では何も変わらないので、今までの世界の結果は変わらない（短い段 2,821件で確認）。
- 調べ方：検査の仕掛け（`HAKUTAI_HANDOVER_PROBE`）で、既存の検査が作る新規ゲームの世界ごとに「別の成人へ隠居した写し」も検査し、通らない場所を集めて直した。
- 全国開始では、百代鏡DBの父を実の親（`BirthParents`）として持つ（今川義元→氏真など）。DBの生没年は自然死の重みにだけ使い、没年に強制しない（死因を区別しないため）。

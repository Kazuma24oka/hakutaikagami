# 全国人物台帳・在所の仕事 V1

1560年・準史実の最小データ段階。全国108拠点のうち、既存の信長/信玄/氏康の3本拠候補と3勢力を出典付きで再確認。残る105拠点は人物・勢力未収録と明示。城郭や領域、当主の権限、1560年1月1日当日の所在を確定する資料ではない。

## 正本と境界

Core/Data/national-personnel-v1.jsonを埋込読込し、旧TravelWorldの人物ID/勢力/本拠候補との整合を検査する。Catalogは複製を返す。Coverageは全国拠点を正本から列挙し未収録も落とさない。版はデータ全体のハッシュ。既存世界のVersionや保存定義は変更しない。参照台帳の変更だけでセーブを移行扱いにしない。

清須市・山梨県・小田原市の公式解説を2026-10-21に閲覧し、事実の短い要約とURLを保持。本文や画像は転載しない。小田原資料は1995年度執筆であり、現代研究による網羅的再検討ではない。伝承の本拠を現在地として表示しない。

## 仕事

主君命令/書役依頼の2件は既存fixtureの架空の検証設定。実在3人へ権限や試作の主従関係を付け足さない。発送側検証画面でのみ操作できる。所在地・成人/権限・主従関係の有効期間・受令者の拘束・野外状態を確認し、既存IncomingMission.BuildのIntentをそのままSubmitする。可否理由は共通文言で他人の未知事情を漏らさない。失効時は再検査する。Task/Message/時計/保存の別管理は追加しない。元の実行時の権限再検査も保持。

## 画面

通常Main→武将の任務→収録台帳。全国の拠点を選び、部分収録/未収録と史料付き本拠候補を表示する。シナリオの収録管理情報であり主人公の現在の認識ではないことを明記。開閉や選択で世界の状態を変えない。仕事の発送ボタンは既存位置に保持し、台帳アダプターで発送する。

## 検証

Scripts/verify_national_personnel.pyでビルド・全単体テスト・通常Mainからの台帳開閉/3拠点選択・未収録拠点・仕事発送・通知/訂正/再送・保存復旧/続行と旧入口を実GPU確認。台帳のPNGを含め実画像を点検し、check_national_personnel_binding.pyで対象ソース/定義/バイナリ/テスト/実PNGを結ぶ。旧段階の記録は履歴として維持し、共有コード変更後の現行成功に読み替えない。

未実装：全国の仕事自動生成、実在武将の役職/主従/権限の収録、NPC自主選定、全武将/城/領域。今回の部分台帳を全国政治シミュレーション完成とは扱わない。

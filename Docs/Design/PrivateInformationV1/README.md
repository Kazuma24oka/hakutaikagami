## プレイの流れ

新規通常開始の『私的な情報交換』で現地の相手に条件を聞く。本人の直接観測がなければ提供できず、打診だけでは情報料を取らない。相手が話せるのは、自分が見て記録した陸路の通行情報だけ。主家全体の機密や世界の現在の封鎖を読んで売ることはしない。

条件に合意すると本人から封書を受け取る。実到達と本人の開封後だけ、出典と観測時点を持つ情報が本人の経路判断へ入る。後から実際の道が封鎖されても、相手の古い『通行できた』という記録を最新の封鎖情報へ置き換えない。条件提示の台詞でも観測時点を伝え、既に知っている/古い記録の再提供を新情報と偽らない。

開封後に現地で情報料を私財から払う。初回20文、同じ相手へ支払った実績があれば次回15文は試作の共通調整値。全武将への評判更新や忠誠値の購入ではない。当事者が覚えている支払実績だけを使う。他の相手は初回条件のまま。未払いがあれば、その相手との次の情報交換は先の取引を終えてからになる。私財不足でも情報と未払いは消えず、会話を閉じた後も『未精算の情報を確認』から開き直せる。

同じ観測記録の再提供もあり得る。観測日は更新しないため、重複記録が最新の現況や新しい発見になったと扱わない。情報の新規性・鮮度を見て見送れる。

## 知識・会計と旧版

原本は相手の直接観測ID・提示相手・面会場所・費用・時刻を固定する。経路検証は開封記録と元の観測を照合してこの提供経路を認め、単に識別子の接頭辞だけで検査を省かない。開封前に通行情報を知ること、他人の観測へのすり替え、観測日の更新を拒否する。

情報交換の封書は当事者だけに届け、相手の主君へ自動通知しない。主従・所属・兵・所領を変えず、財布も家や軍用備蓄と混同しない。個人間で同額を移し、世界の貨幣を増やさない。過去の軍務等を検証するときは未来の情報料と学習済み事実を取り除く。旧null版の開始hash/JSONへ新しい情報や権限を追加しない。

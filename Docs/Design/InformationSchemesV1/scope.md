# 情報系の計略と寺社の情報

固定基準v59。統合案第14節の2a。殺害・放火・離反を先に実装せず、情報と各人の認識だけを扱う。

1. 流言と偽書を真実と別の伝聞として、実際に聞いた人物だけの認識と判断へ反映する
2. 書状の実物・名義・持参者を区別し、本人の現地照合と伝達された否認だけで訂正する
3. 本人または同意した密偵が実移動し、現地の観測を物理帰還と開封の後にだけ依頼者が知る
4. 寺社は自分が現地で認識した噂・寄進・保護の情報だけを本人へ伝える
5. 通常画面の代表一巡・重大不具合・途中保存と同じ未来・旧形式の代表互換を確認する

流言は定型の未確認情報、密偵の観測は到着拠点に隣接した陸路が対象。遠隔の真実や他人の内心・蔵の在庫は取得しない。否認だけで犯人を確定しない。

検査計画：新規の情報・現物・密偵11件、既存の贈答30件、茶会後の履歴1件、点検勲功の基礎1件を実行する。共有する現物台帳・知識・停止位置を確認するためで、無関係な全件テストは行わない。旧形式は代表3件、途中復旧は密偵の復路と通常画面で確認する。

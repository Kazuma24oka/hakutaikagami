# 情報系計略・書状照合・密偵

流言と真実・書状の名義と持参者・本人の照合を分離。聞いた人だけの伝聞と判断、寺社の既知情報、同意した密偵の実往復・現地の陸路観測・帰還返報と開封後の地図反映を実装。関連43件・実保存復旧・代表旧保存3件・通常画面の内部操作と自前描画が成功。

流言は定型の未確認情報。密偵の観測は陸路と到着拠点に隣接する道路が対象。帰路の救助・返報自体の不達再送・NPC自発派遣・破壊や処分・全件・全国長期性能・ユーザー試し遊びは未実施。約10ポイントの作業は継続中。

NPCは聞いた伝聞だけを伝え、自分名義の書いていない書状は本人の知識で否認する。否認だけで犯人を確定しない。密偵が道の入口で進路を失うときは実在端点で停止し、旧保存の停止位置は変更しない。未開封の返報から地図へ道路情報を漏らさない。

# 3地域の人口・労働・収穫・食糧不足・救済

清洲・甲府・小田原の村と家の蔵を別々に管理する試作。開始は1560-01-01。人口200人・働き手100人・村米10000kg・家米3000kgは調整用の仮値で、史実人口/実際の気候を主張しない。人口変動・民兵徴発は未実装。

## 振る舞い
- 毎月一日に村の米1000kgを消費。不足は未充足食糧として保持し、救済米/収穫米で実際に充足する。
- 9月の作柄は世界Seed・地域・年から決定。干ばつ50%/洪水70%/平年100%。観測前は「未観測」、他地域の実帳簿や未来の作柄を画面へ出さない。
- 10月に収穫し30%を未徴収年貢として計上。徴収は別操作。村の一月分1000kgは徴収不可。
- 水利工事は家の米200kgと働き手20人を7日確保。収穫時の確保労働は収穫を減らす。食糧不足では休止し、充足後に残り日数から再開する。完成時は水利+10、最大130。
- 同時刻では工事完成→作柄→収穫→月次消費→操作。収穫前の不足は作柄に加えて収量を半減する。
- 村米＋家米＋実消費＋工事支出＝初期米＋実収穫を再計算検証。私財の文と軍用の人秒備蓄は増減しない。
- 当主本人が現地にいる場合だけ帳簿と操作を提供。操作は表示時の状態版を固定し古ければ再確認、原本ID再利用で二重支出しない。
- 現地にいる所属武将から月一回、当主の固定宛先へ封書を配送。自己メモは現地にいるプレイヤー当主に限定。本文は観測地・不足量・観測時点だけで、後の救済で書換えない。現地証人がいなければ遠隔へ自動通知しない。

# S09E 任務・配送・命令の全般（Duties2V1）

基準：Docs/Development/ProgressV1/approval-baseline-v167.json（コードを書く前に固定）。一覧の Duties2 の新規の全国開始だけ（Cases2 までを使う）。今の保存は変わらない。

- 併用の表：捕らわれ・療養は家の役・軍団長・客将と重なれない（出陣中は重なれる）。重なれば家中の手の空いた者に移し、戻れば元に戻して代わりの者へ20貫の補償。
- 書状の届け方：敵（この半年に戦った家）の領地を避ける道の日数。避けられなければ2割で失われ、使者を継いで送り直す（日数が倍）。同じ家が同じ月に三通を超えれば一通ごとに1日遅れる。宛先の当主が本拠にいないか意思表示できなければ家老が開封する（同盟の申し入れ・将軍の仲裁・和睦の呼びかけに使う）。
- 命令の競合：従う家の自分の当主の出陣と主家の出陣が同じ月に重なれば、自分の当主の命に従い、主家の加勢の命は退けたと記録する。
- 子の形成：未成年の子は毎年1月に、家の方針（軍備は戦術、商は商取引）か親の得意から興味が育ち、元服のとき志（武名・文名・立身・家の存続）が定まる。
- 先読み：手強さの設定が「強い」なら、出陣の判断で相手の同盟の家の援軍（力の半分）を見込む。
- 役以外の技能：取次の交渉60以上の家は従属への変更を断れる。当主の兵站は陣への兵糧の傷みを減らし、調練は雇い兵を増やす。
- 後見：当主が15歳未満なら家老が後見人、15歳で帳簿を返して終わる。
- 代理と追認：当主が不在の月の方針・布告は家老の代理の決定として記録し、当主が戻った月に追認（8割）か改める。
- 国人連合：包囲網の盟約の家は1・4・7・10月に合議し、半数以上が賛成すれば的の家の境の城へ共同で出陣する。反対の家は賛成の家へ負担100貫を払う。
- 配下の攻撃の責任：放火が見つかった月に、相手が抗議し、当主は否む（2倍以上強い）・償う（倹約、200貫）・罰するを決める。
- 婚姻と養子：夫婦の家どうしが戦い、両家の約束が無ければ離縁、あれば続ける。養子は本人の志が天下なら断り、ほかは本人と両家の当主の合意を記録する（断られた養子は後継にならない）。
- 鞍替え：従う家の離反は、新しい主（境の一番強い家）への接近と、元の主への通知として記録し、届いた月に効く。
- 恩と忠誠：50＋勲功×5（恩賞があれば×10）−給付の削減20＋一族20。辞去する人（忠誠の低い順）と、独立の時に付く軍団長（50未満）の判断に使う。
- 身代金と医療：NPCどうしの捕虜は、身代金（300貫、当主の一族1000貫）が払えれば放たれ、捕らわれの間は捕らえた家が月5貫の手当を負う。
- 兵糧の見聞：決着した出陣の兵糧の運びを、目的の城の隣の家の目付が見て、±3割の誤差の量と見た日で記録する。

計算は1か月あたり約23ミリ秒。全体の時間は、包囲網の共同出陣で合戦が増えた分だけ長くなった（S10 で扱う）。

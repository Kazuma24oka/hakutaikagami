# 一件だけの私的点検協力 V1

## 固定した完成条件

1. 精算済みの面識と本人の協力意思、現地所在と仕事の空きを確認する。
2. 一件20文を私財から本人へ移し、継続雇用・日当債務・所属・軍権を作らない。
3. 当人の共通任務で実点検し、本人だけが新しく観測する。返報の実到達と開封を分ける。
4. 仕事中/返報開封後の実世代保存復旧で世界・財布・将来進行・配置データが一致し、旧版の行為と保存を維持する。

新しい明示v2だけに追加。一般の裏切り/忠誠/機密売買/城・兵の移転はこの点検と別。現地で会える成人のうち、役職を持たず、他の用件中でなく、本人の協力意思がある者が対象。当主/役職者は対象外。前払い20文は試作調整値。既存の継続協力契約中は専用の点検依頼を使い、二重契約にしない。

外観確認は行わず、CLI/API・ビルドと画面なしGodotデータで確認する。結果は検証後に追記する。

## 結果

完成条件4/4。新規12件を含む関連619件成功（失敗0/スキップ0）、Gameビルド成功。実GenerationSaveStoreの仕事中/返報開封後を復旧し、全世界・財布・本人向け一覧・将来進行が一致。[証拠](verification.json)。Godot4.5.2 --headlessの15組30世界82Node3D一致。全2680件とGUI/外観は未実施。

4ゲーム秒の共通点検が完了してから担当本人の道路観測を作る。依頼者への返報は完了状況だけで、開封しても詳細な道路知識を自動共有しない。詳細は別の私的情報交換で日付付き原本を受け取る。面識未精算・拒否・他の用件中・金額変更を拒否し、同一IDの再送で二重払いしない。単発協力から継続雇用/同行/日当契約は生まれない。旧v1保存は新行為を拒否してbytesを維持する。

20文は試作調整値。本人の意思は既存の協力可否による限定条件で、性格/忠誠/利害の一般判断や裏切り成功率は未実装。主君への背信や機密提供を買う仕様ではない。会話導線は実装・ビルドまで、外観未確認。R4全体完成とはしない。

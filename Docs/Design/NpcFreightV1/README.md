# 家臣へ任せる現物仕入れ・帰還補給

新規v13のみ。現地の当主が、同じ場所の協力意思を持つ成人直属家臣へ品目・数量・仕入先・前渡金・30日を合意する。本人の移動や私財を自動操作しない。既存の家の運搬原本と予算・市場・経路を共用し、新しい輸送シミュレーターを作らない。

家臣は共通の陸路で移動し、現地の実価格/在庫で購入、元の家へ帰還して現物と余金を一度だけ返す。購入不可/期限切れは資産を消さず帰還へ切り替える。通行止めは共通経路の判定に従い、通れなければ待機。出発後の取消が遠隔で即時発効する機能は作らない。現地での取止めと実際の精算後の再依頼は可能。

派遣側の表示は合意原本と現地で受領した証拠に限る。遠隔の現金・荷・現在価格を即時公開しない。戦場の前線へ直接補給する隊商、NPC当主による一般的な広域物流、道中の引継ぎ/再委任は後続。完成条件はapproval-baseline-v12.json。

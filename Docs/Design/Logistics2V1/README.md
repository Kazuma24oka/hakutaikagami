# S08 全国の水運・交易・補給と名物（Logistics2V1）

基準：Docs/Development/ProgressV1/approval-baseline-v162.json（実装の前に固定）。一覧の Logistics2 の新規の全国開始だけ（全国の家の内政 Domestic2 の帳面を使う）。今の保存は変わらない。

全国の家の戦略（NationalStrategy.Apply）の月の初めの計算と、遠方の合戦の決着（Settle）で行う（Core/Contracts/Logistics2.cs）。

- 名物：通説で知られる茶器と刀12点の目録（持ち主・時期は要確認の試作値）。開始の年の持ち主の家の本拠か、堺・博多の商人の売り物。落城で奪われ、当主が勲功の多い家臣に恩賞として与え、売り物は市の近くの国の豊かな家が買う。持ち主の履歴を残す。
- 探物：本人のいる市の人物が名物を探す仕事を出す。名物のある拠点へ行って見つけ（売り物なら預り金で買い）、依頼主のところへ戻って精算する。人物の画面で引き受け・見つける・精算ができる。
- 水軍と海を渡る出陣：海に面した国の城と水軍の技能から家の水軍を決める。別の島の城を攻めるとき、水軍が無ければ渡れず、相手（と同盟の家）の水軍が倍を超えれば力が半分。相手の水軍が上回れば海路の兵糧を封鎖する。
- 交易船：港の国の家が3か月ごとに出し、航海の日数のあと銭と品（九州の港からは硝石と南蛮の鉄砲）を持ち帰る。台風の季節は難破しやすく、瀬戸内の水軍の家が通行銭を取るか奪う。
- 陣への補給：出陣の兵糧は家の蔵米から持ち出し、本拠から遠い分は運ぶ荷になる。道のりと荷の量で遅れ、傷み、賊と封鎖で減り、届いた分だけで戦う。守る城の兵糧が尽きかければ守りが弱る。封鎖だけで在庫を消さない。
- 消耗：軍馬は飼料の米を食べ、無ければ減る。工房の鉄は武具になり、合戦で傷む。
- 隊商：品の余る家から無い家へ、複数の荷を運ぶ。通る家の境で護衛を引き継ぎ、遅れ・傷み・賊は陣への補給と同じ。買い手と戦っている家の領地を通れば差し押さえられる。

実際に地図の上を動く軍勢へ荷が追いかけて届く補給と、別行動の部隊の広い範囲の指揮は S09、全国規模の速さの受入は S10。

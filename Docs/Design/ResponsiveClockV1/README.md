# 開始・停止の画面応答 V1

前工程PlayGuideV1は0430839で5/5。本工程の完成条件は次の5件。

1. 実際の私有・不変な世界世代から、既存SetPausedと同じ処理を別作業で準備する。世代参照・発行元・確定順・時刻が一致する時だけ一回反映する。取消、失敗、ロード、別セッション、先行計算との競合は現在の世界を保つ。
2. 自動進行/停止ボタンは準備を依頼して画面へ戻る。待ち中も停止による上書き、視点、手引き、メニューを扱う。保存や新しい命令の重複処理は防ぐ。一画面の準備作業は一個までとし、先行計算の取消終了を待って開始する。
3. 実際の1000人データ、開始待ちの取消、明示した故障/再試行、重要書状の停止/再開を確認する。9保存地点から別プロセスで同じ世界・本人・操作タブ・3Dと同じ未来へ復旧する。
4. 15追加/全2055テストと私有世代監視、49実GPU起動を照合する。クリックが戻る時間と開始/停止が確定する時間、連続動作のフレームを分離する。実在/登録/重要書状では手引きの12回の開閉も確認する。
5. 実画像と動画を直接点検し、現行ソース・DLL・試験・証拠を照合して同じブランチにcommit/pushする。

停止待ちでは自動進行を一旦保留するが、準備した世界を先に見せない。確認中の命令/保存を別に実行しない。保存形式と通常SetPausedの同期・観測・検証を省略しない。Coreの私有世代は従来どおり初期深いコピーと検証済み深いコピーの差替えだけで更新する。

改善対象は開始/停止の画面応答で、確定計算の完了を即時とは言わない。通常の判断・保存内容の捕捉・10/60/360倍の進行は同期処理を維持する。1000人は静止した架空登録人物と選択本人の移動であり、全国自律NPCや多数同時合戦の性能承認ではない。

次の五件：本工程の検証/push、通常判断と保存捕捉の待ち時間整理、全国人物/役職の採録、同時処理の負荷確認、実プレイの体験確認。判断不要なら継続する。

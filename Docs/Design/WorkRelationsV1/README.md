# 仕事で生まれた縁から、次の働き方へ

完成条件：1. 本人が知った任務の履行と報酬の実受領から、方向別の仕事上の信頼の根拠を導く。履行を認めた相手→本人と、約束の報酬を受け取った本人→相手を混同しない。第三者・再開封・未開封・単なる取消で一律に加点しない。2. 画面は確認済みの言葉・受渡し・日時を示し、NPCの内心の真値を公開しない。3. 現地で縁のある相手との会話から仕官申出/条件回答、家臣なら担当や軍務の相談へつなぐ。既存の合意到達・効力・通知開封を省略しない。4. 同じ人物で実会話→仕官→軍務相談まで動かし、保存復旧・3D表示を確認して同枝pushする。

V3開始の既存記録から導く限定的な仕事関係。新しい全国評判や万能の関係点は作らない。派閥・好意/敬意/恐れ/敵意の全実装を意味しない。信頼の根拠があっても仕官や軍の権限を自動成立させず、従来の一般仕官申出も禁止しない。関係の会話は権限付与ではなく、経験に基づく次の行動への入口。基礎の主従関係や原本を改変しない。

# 今川家の1560年開始

1. 1560年の今川家、氏真、義元、駿府の本拠候補を出典に結び、採用した家督解釈と開始時点の仮定を明記する
2. 新規開始の一覧と全国地図の駿府から両名を選べ、開始人物・所属・開始位置が一致する
3. シナリオで定める当主にのみ当主権限を与え、他の武将の兵力・権限は実際の任命に従う
4. 旧版の人物・家・初期配置を保存復旧で保持し、新版の開始と再開でも同じ人物と位置を示す

## 家督と軍事行動

静岡市歴史博物館は1557年の譲位と1560年の義元の出陣を年譜の別項目に置く。[今川義元展の年譜](https://scmh.jp/special_exhibition/20240427.html)

『国史大辞典』の氏真項は1558年の文書発給から国務の一部を委ねられたとし、相続を義元討死後とする。[今川氏真](https://japanknowledge.com/introduction/keyword.html?i=587)

駿府は今川氏の本拠を表す既存ノード sunpu を使う。各人が開始日にそこにいたことや、駿河・遠江・三河全域の城を直接支配したことまで推定しない。[静岡市歴史博物館の基本展示](https://scmh.jp/basic_exhibition.html)

ユーザー決定：1560年は義元が当主、氏真は後継者として開始する。国史大辞典の家督解釈に沿う。父子はいずれも選択でき、当主の決裁は在任中の義元に属する。

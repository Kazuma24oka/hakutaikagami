## 実際に変わること

当主は自家の対外方針で対象を選び、敵対意思の表明または自家の撤回と通知を一回の確定で行う。初期の試作用有効期間は30日。相手の既知本拠へ封書を送り、相手当主が出発済みなら不達となる。対象の現在地を真実から追跡して届けない。

NPCは到達して自分が読んだ書状を根拠に、別の自家の判断として応答する。秘密の撤回は相手へ即時反映されず、後から届いた期限/撤回通知だけで更新する。返書も物理配送され、プレイヤーは到達・開封後に既知情報として読む。既存の下部会話帯と履歴へ接続する。

応答したNPCは現地の実駐屯兵を引受け、共通道路・命令・時計で行軍する。実在する双方の軍と受領済み任務/自衛条件から同時損害を出し、実残兵・兵糧・返報へ反映する。対外交渉全体/無条件の開戦AIではない。

## 保存と履歴の版

旧null/v1/v2を変更せず、新規通常開始だけhead-led-owned-garrison-sparse-local-combat-v3。v3は実際に損害が起きた秒だけ記録する。読込時は実移動の接触可能区間と効力境界から再計算し、欠落/余分な損害を拒否する。同じ時計境界後の開封/取消で既存損害を書き換えない。兵数一定の連続消費も統合し、兵糧切れ後の待機履歴増殖を抑える。

固定標本はテスト生成の旧v1プロフィールと実際の4d8ac2f v2検証世界であり、ユーザー保存ではない。旧613d/v1/v2のbyte同値を検査する。

# NPCの既知の用件と空き時間の修行

成人NPCが本人の既知の用件と点検の必要を優先し、空き時間に30分の修行を選ぶ。引受済みの協力・同行では修行を中断し、実完了した場合だけ技能経験を得る。全件4,017件、7段階の実保存復旧と同じ未来、旧保存254件のバイト一致、Gameビルド、通常入口の配置確認・実データ作成・20秒のNPC判断、Godot配置7組が成功。

外観・GUI操作は未実施。全国の戦略的な目的選択や役割別の判断頻度は後続0b。旧保存の行動方針は変更しない。修行中断分には経験を付けない。

通常の新規ゲームで成人NPCが点検後に修行へ進み、既存の配下相談から協力や同行を引き受けると用件を優先する。旧世代を読み込んだ場合は以前の方針を保持する。

固定基準v51に従う。全体概算 46.443% → 46.540%。分母・重み・他の枠は変更しない。

2026-11-05の家法・改革・再興・毛利元就の研究追加資料を取り込み、工程順と本工程の基準が変更されていないことを照合した。本人の認識と客観的な事実、権限と実行可能性を分ける。

# 家族の生死と知らせ

子が生まれると名簿に加わり、15歳で元服する。成人後の奉公は別に合意する。遠方の家族は出生・元服・死去を届いた封書で知る。

関連11件・実保存復旧・代表旧保存3件・通常画面の内部入力と自前描画が成功。

史実出生と自然死は各1人の代表例。出生の月日・拠点、自然死の日・確率は試作値。全国長期試遊、全件検査、ユーザーの外観評価は未実施。

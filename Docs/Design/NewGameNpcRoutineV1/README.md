# 新入口の限定NPC初回判断 V1

同じ世界時刻で複数の本人が自分の点検を進める段階。新しいプロフィールだけ明示NpcRoutinePolicyを保存する。旧3人/5人/6人版のプロフィールや保存へ後付けしない。

完成条件5件：
1. 最大8人の史実名簿の非操作人物だけ、自分の在所・自分の権限・自分の仕事と実受領した返報から初回点検を判断する。新入口6人から信長で開始した専用ケースはNPC5人。登録測定人物を自律人物として数えない。
2. 同じSubmit/Task/Message/世界時計と私有計算を使う。別時計・配送・タスク処理を作らない。旧NpcWork.Enabledを新世界へ拡張して旧fixtureの規則を誤適用しない。イベント予算はNPC処理の上限分も事前予約し、不足時に途中だけ進めない。
3. 点検を発送したら自分の返報を待ち、結果を知った後は不要に繰り返さない。判断入力と根拠を検査し、他人の秘密による変化・改ざん・二重着手を拒否。旧実プロフィール3版の初期hashを保つ。定期再点検/新しい必要の発見/戦略AIは後続とする。
4. 18追加を含む全2122単体試験を新規実行、317入力を固定。46実GPU210組の世界・画像・数値で初回判断/長期待機/1000静止登録人物/旧6人版ロード、仕事・辞去・軍務・退避・旧3/5人版を照合。追加10保存点20組を別プロセス復旧する。
5. 実画像を直接確認し、ソース/試験/バイナリ/実コミットの一致後に同じ枝commit/push。main/designと既存素材・保存を保護する。判断不要なら継続。

## 範囲と修正根拠

当初の毎時点検案は、長距離移動中に不要な履歴が増え、実際の完了待ちの検査に失敗した。診断ログを保持し、待ち時間の検査を緩めずに、初回点検と既知結果での待機へ変更した。40万秒進行でも不要な要求/判断履歴が増えないことを検査する。これはNPCが必要を見つける一般的なAIの完成ではない。

専用長期待機の2段目は既存CoreのQA用Advanceで時間を進める。3600秒分の実時間動画ではない。実操作の10秒進行では実UIの私有workerと同期Coreの全世界を照合する。

既存QAのTasks.Single/完了判定は操作人物のタスクと効果IDへ絞り直す。他のNPCの成功を主人公の成功として数えない。実際の対象タスクの開封・返報・主従の元の検査は保持する。

1000人の登録人物は静止した負荷用データ、5人の史実NPCが今回の自律対象。全国3000人・多数の軍勢・一定fps・完了時間保証へ読み替えない。名前/主従の出典と試作配置はHistoricalHouseholdV1を継承し、史実NPCの行動を再現したとの主張はしない。旧9入口/renderer試験は今回再実行しない。

# 作成家臣の開始と主君命令

開始画面で浪人と「織田家の家臣（作成人物の架空の開始合意）」を選ぶ。新規則created-retainer-peace-v1、織田家所属と信長直属を別の期間付き関係として保持する。架空の開始合意の根拠IDと両当事者の初期認識を明示する。史実人物の任命を再現したという意味ではない。旧浪人・旧NPC・旧保存は変更しない。

軍・土地・徴税・他家の指揮権を増やさない。主君の点検はBindingOrder、他家の点検はVoluntaryRequest。同じ既存の配送/開封/履行/返報を使う。未着/未開封の種類や内容を漏らさず、主君命令は認識後に履行判定へ進む。本人は既知の担当命令を中断でき、自己判断の理由は別書状で物理配送する。理由送信だけで相手認識にせず、責任・処分は自動確定しない。相手の審査内容を本人画面へ直接表示しない。

開始包には役割と世界を固定し、既存の内容ハッシュ/保存インスタンスによる分離を共用する。旧包は今まで通り読める。全1010件（追加25件）、既存20GPU/66比較と、通常の家臣選択からの3ケース（命令履行/本人中断/甲府への移動と他家依頼）6GPU・15保存点/30比較を同じ実行物で検査する。管理通知や停止ボタンの違いを除く、人物の認識/依頼と3D表示の実寸範囲を差分0で比べる。成功はverification.jsonと実画像点検の結合後に判断する。

日付の背景資料はsource-review.json。後年の城主権限や領地を1560年へ転用しない。全国108地点の年代別確認や史実武将の開始権限採録を完了したとは扱わない。出陣/軍権委任と継続的な仕官案件は次段階であり、本段階は初期設定と平時の任務。

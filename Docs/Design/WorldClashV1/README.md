## 実装と境界

接触処理は世界に保存する実部隊だけを読む。NPCの攻撃根拠は実在当主の現地引受時に記録した自家の任務、プレイヤーの攻撃根拠は配送され本人が開封した交戦任務。許可だけで敵対関係を作らない。相手が近いだけでも自衛の損害を出さず、実際の攻撃を受けた場合に応戦する。

任務の対象外から攻撃を受けた場合や任務が期限切れになった場合も、直近の危険に対する自衛は残る。同じ相手への任務攻撃と自衛を二回数えない。敗走/撤退中の攻撃停止は維持する。人物死亡、勢力の消滅、政治的離反を兵数減少から自動で発生させない。

損害は`WorldClashes`へ共通時計の境界として記録する。読込では実出陣期間の境界が欠落していないか確認し、それぞれの時点の所有部隊・実位置・効力/開封/取消を復元して再計算する。検証済みのライブ状態からの追記にだけ過去部分の検査を再利用する。

通常の個人点検や軍務の原本を別シミュレーターへ移さない。実損耗は既存の兵数表示・消費・現況返報へ渡す。新しい実在軍の版で旧架空演習を同時に重ねない。

前工程の`head-led-owned-garrison-common-land-travel-v1`を変更せず、実接触を有効にする開始は別の`head-led-owned-garrison-local-combat-v2`へ固定した。旧v1には損害台帳を追加しない。旧プロフィールの初期hashも保持する。通常開始の既定値は旧nullを保ち、明示v2プロフィールをCore/APIから作成した場合だけ接続する。新規ゲームから自動的にこの実戦へ入れる完成版ではない。

3D側は配置関数を共有し、視認範囲にいるNPC軍だけを現在の目撃として表示する。遠隔の軍勢を表示するために世界の真実をUIへ渡さない。接触した攻撃の履歴を攻撃表示へ使い、アニメーションの終わりで命中を決めない。部隊モデルそのものの品質/重なりは今回の数値検査で認定しない。

この版はプレイヤーが野外にいる間の局地的な接触の基盤。画面外の全NPC同士の戦争、全国の政治AI、実戦由来の自動敗走経路、射撃/兵種/攻城、一般的な補給・再出陣は未完了。空の秒も履歴へ持つ現在の実装は、長時間大規模戦闘の性能認定ではない。

# 同一人生の軍務と現地引継ぎ

既存開始と保存を変えず、created-career-military-v1を追加する。浪人からの仕官とは別に軍務を申し出、物理封書の条件を開封して回答する。120秒の期限は主君の回答受領まで。許可通知を開封しても兵は移転しない。清洲で本人と主君・待機本隊が揃って初めて指揮を引き受ける。

主家の試作兵100と主家兵糧。配置・保持・帰還だけを許可し交戦不可。個人の所有/役職/所領は増やさない。一人一件の軍務に限定し、再任/期限付き現役軍務/実戦での個人退却は後続工程。主家兵糧を携行・秒単位消費して残量を返す。本隊帰還・本人在所・残量0・主君が受領済みの自隊現況返報が揃ってから、物理返還願いを受領した主君が指揮を引き取る。現役軍務が残る間は辞去の引継ぎ未了。

軍務前の本隊は主君が指揮。引受/出陣/帰還/返還で本人の座標を跳ばさない。本人が在所/街道にいるときに遠い本隊を自動観測せず、未許可の遠隔命令を拒否。全方向の表示は保存済み認識から作る。準備済み兵糧台帳は取扱権ではない。

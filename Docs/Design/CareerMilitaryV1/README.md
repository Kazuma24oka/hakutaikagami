# CareerMilitaryV1

同じ作成人物の浪人→仕官→平時任務→別の軍務合意→現地指揮引受→兵糧携行→配置→帰還→返報/残量/指揮返還→辞去→街道移動を接続する追加開始。旧Career/従来開始は保存包も含めて保持。

正本はDESIGN.mdと実装。実検査は Scripts/verify_career_military.py、現行実行物との照合は Scripts/check_career_military_binding.py。実GPU17保存点を別プロセスで復旧し、同じ操作と保存時停止を再現して全世界ハッシュと実画面の完全一致を検査。OSマウス操作は使用しない。

新開始は配置だけ。交戦・損耗・給与・昇進・再任・軍務許可通知の照会再送は未実装。既存の交戦試作は別開始として保持。人員/物資の私有化や史実兵数への主張はしない。

preflight.logは入口の立場検査が将来の軍務機能を初期家臣と混同した失敗記録。開始時の立場を独立させて修正し、preflight2.logで通常操作が完走。最終の実行証拠はverification.json。

初回の実画面比較で世界状態一致/初期ラベル1724画素差を検出。viewport確定後の再描画を追加し、差分許容を広げず再検査。元失敗画像/ログはimage-correction.jsonで保持。

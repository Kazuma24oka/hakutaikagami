# 清洲の地域経済・最小一巡 V1

## 完成条件

1. 明示契約の一地域で季節収穫と年貢額を記録し、現地支配/当主権限を検査する。
2. 年貢の計上と現物徴収を分け、村/家の蔵/使った米を保存し、二重徴収・赤字・私財混入を拒否する。
3. 工事の米と7日間、完成後の水利/収穫を同じ時計へ接続し、救済は実米を村へ戻す。
4. 工事中と徴収後の実世代保存・復旧後の将来世界と本人向け帳簿を照合し、旧null版保存を維持する。

4/4達成。新規19件を含む関連412件成功、Gameビルド成功。[現コードの検証記録](verification.json)。全2592件は未実施。画面操作/画面取得/外観は未実施であり、UI実装とビルドの成功と分ける。

## プレイで変わること

新規開始で清洲に現地支配を持つ当主は「地域の帳簿」から年貢の現物受渡し、村の救済、水利工事を選べる。他家の人物・浪人や遠隔地から帳簿を覗いたり支出したりできない。一般の地位だけで徴収権を作らず、新規プロフィールのEconomyPolicyが清洲の試作契約の原本となり、実行時の所属/当主職/現地支配と現地所在を再確認する。既存の開始根拠は従来どおり軍/徴税権を単独では与えない。

10月1日の収穫は共通時計の期限で処理し、速度や途中の保存で飛ばさない。収穫と年貢計上を行っても米は村にあり、徴収を実行した分だけ家の蔵へ動く。家の蔵から村へ救済するか、水利工事へ使うかを選ぶ。工事の費用は実際に減り、7日後の完成で以後の収穫が増える。工事中に収穫期が来た場合は試作用の労働競合で収穫を10%減らす。完成と収穫が同時なら完成を先に反映する。

## 数量と範囲

数値は全て試作調整値で、史料からの収穫/税率の採録ではない。単位kgは試作の米換算。村800、家の蔵300から開始、標準年収穫1000、水利100（工事一回で+10、最大130）、年貢計上は収穫の30%、村の保護備蓄500、工事米200/7日。未徴収額は翌年へ保持する。初期値は新規版だけにあり、旧保存へ米を注入しない。

家の蔵と村の米はこの地域会計の正本であり、同じ米を別のResourceLotにも二重作成しない。既存の兵糧は開始時に軍用へ別途割当済みの試作備蓄、個人財布は文であり、今回のkgとの自動換算・軍用庫への入出庫は行わない。人口・民兵の動員・日々の食料消費/飢饉・売買相場・俸禄支払・遠隔の代官/帳簿配送は後続。救済は米の現物が村へ戻った範囲で、幸福度や人口増加はまだ生成しない。

## 検査と次

工事中/徴収後に実GenerationSaveStoreへ書き込み、復旧後の世界全体とLocalEconomyViewが一致。実陸路で離れた後は閲覧/支出を拒否し、帰還後に再び確認できる。年貢の二重徴収、赤字、工事重複、同じ操作ID、改変した会計/イベント、旧版への混入を検査。通常開始と同じ各版を組み合わせ、個人財布と軍用在庫への副作用がないことを確認。

現バイナリで既存の実戦保存復旧5組10世界/40Node3Dの配置データも回帰確認。これは経済画面の見た目を検査した証拠ではない。Control/入力イベント/UIコールバック/画面取得を使わない。

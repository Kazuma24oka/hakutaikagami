# 倍率境界のカメラ

正投影の横幅基準を統一。30kmまでは横幅を表示範囲に一致させ、30km〜500kmで画面縦横比へ滑らかにつなぐ。全国では以前の縦幅基準と同じ画角となり日本全体を収める。既存保存のSpan/Yaw/Centerを維持し、表示変換のみ変更する。

詳細から中景への注視点の高さも連続して変える。境界前後の世界上の基準点の画面距離を計測し、倍率差を除いた変化を2%以内とする。移動判定はCoreのまま。

旧画面の比較で外部ポインターのボタン強調だけが混入したため、自動検査指定時のControlだけMouseFilter.Ignoreとする。OSポインターの位置・表示・権限は変更しない。通常プレイには適用せず、検査では従来どおり実ボタン信号を発火する。UIを含む比較範囲と差分0は維持。

# 駿府で出陣を決める

義元が駿府で敵対を決裁し、軍務を引き受け、家の米を軍用倉から携行して掛川へ出発。街道上の保存復旧で世界と3D配置が一致した。

Godot 4.5.2 .NET の画面なし実行で IMAGAWA_START_PASS。ビルド10秒、警告・エラー0件。氏真には決裁権がなく、敵対通知が届く前は信長に内容が漏れないことを確認。兵糧枯渇の既存検査は前回成功した結果を利用。検査では軍務と行軍を通常画面と共通の公開コマンドで操作した。画面の外観・掛川到着・NPC義元が自発的に開戦する経路は未検査。

2026-11-10　街道の実保存をロードして掛川に到着。掛川に市場台帳がなく購入可能量が0であることを確認。同じ到着状態から浜松への行軍命令を受理し、帰還を選んだ場合は駿府に到着した。駿府で米1kgの購入による市場在庫・私財・携行米の増減を照合した。Godotの画面なし検査に成功。

浜松以西の実測（2026-11-10）。同じ軍の携行米の表示は掛川84kg、浜松61kg、吉田33kg、岡崎7kg。吉田・岡崎の現地購入可能量は0kg。行軍中と到着後の市場の案内を実態に合わせた。Godot 4.5.2 の画面なし検査で吉田の案内文、各到着と掛川の保存からの帰還分岐を確認した。外観は未確認。

補給を準備する分岐も実行。通常開始の義元が駿府で氏真に米60kgの岡崎への配送を依頼し、同じ行程を進んだ。岡崎到着時7kg、1時間後に携行米65kgを確認。Godotの検査シーンで HAKUTAI_IMAGAWA_CONVOY=1 を指定すると再現できる。

岡崎から善照寺砦まで。補給なしでは8kg不足で出発拒否、資源・任務は不変。氏真の補給を受けた場合は再出発後に保存形式で途中復旧し、善照寺砦到着時の携行米49kgを確認した。軍務履歴の再検算に後発の経路が混ざる進行停止を修正。関連3件成功。

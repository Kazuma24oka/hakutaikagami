# 核の遊び（下書き 2026-11-18、ユーザーと一緒に決める）

## 一言で
戦国の小さな国で、一人の侍として生き、足で運ぶ知らせと人の縁を頼りに、家を興し、次の代へつなぐ。

## プレイヤーは何者か
- 大名ではなく、一人の人。最初は鷹野家の近習（佐伯源三郎）。
- 見えるのは自分の目と耳で知ったことだけ。遠くで起きたことは、人が運んでくる知らせでしか分からない。
- 死ねば、子や養子が後を継ぎ、その人として続ける（代を越えて家が続く）。

## 繰り返し（時間の大きさごと）
| 大きさ | プレイヤーがすること | 返ってくるもの |
|---|---|---|
| 数分 | 地面を押して歩く。人に会って話す。書状や荷を渡す。賊と戦う。談判する | 道の険しさ、出会い、噂、手傷 |
| 1日 | 朝、殿や村の人から務めと頼みを受ける。どれを受けるか選び、こなして報告する | 勲功・銭・仲。受けなかった務めは誰かが行く |
| 1か月 | 噂を聞き、出来事（国境の争い・賊・市）に自分から関わるか決める | 争いの行方が変わる。役目と馬、やがて所領 |
| 一生 | 縁を結ぶ（婚姻・恩・恨み）。家を大きくするか守るか | 子の育ち、家の格、次の代の始まり |

## 面白さの柱（これに効かないものは足さない）
1. **生きている世界**：自分がいなくても人は日課を回し、争いは進み、賊は襲う。（Kenshi のように）
2. **知らせは足で運ぶ**：情報は遅れて、欠けて届く。誰に何を伝えるか、自分で運ぶかが選択になる。
3. **人と家の縁**：仲・恩・恨みが積み重なり、代を越えて返ってくる。

## 今はしないこと
- 全国4000人・約100拠点の世界（小さな国で面白くなってから広げる）
- 大名として国を動かす画面（内政・外交の一覧で数字を操作する遊び）
- 大軍の合戦の細かい采配（まず一人の戦いと小競り合い）

## 試作で確かめる問い（遊んでもらって答えをもらう）
1. 歩いて移動するのは楽しいか、面倒か。どのくらいの頻度で自動で向かいたいか。
2. 毎朝の務めの中から選ぶとき、迷う楽しさがあるか。
3. 噂で知って自分から動く（話し合いに立ち会う・賊を討つ）のは気持ちいいか。知らなかったことに後で気づく悔しさはあるか。
4. 勲功で馬をもらう、などの「上がっていく」実感はあるか。

## 決まったこと（2026-11-18 ユーザーの答え）
- **視点**：上から見下ろして地面を押す形に加えて、拠点に入る・人と話すときに近づいて見る場面も作る。
- **時間**：今のまま（歩いている間と待つ間だけ進む）。
- **戦い**（2026-11-18 ユーザー「関ケ原とかの陣取りみたいにどの部隊はどこで陣取って…と、武将のステータスやスキルが部隊の強さに影響するのを描きたい。信長の野望・新生が近い？」）：陣取りと武将の能力・技能が軸。案（ユーザーの確認待ち）：
  - 合戦の前に、同じ地図の上で各隊が陣を取る（丘・川の渡し・道の口）。陣の場所の地形が強さに効き、柵などは時間をかけて作る。相手の陣は物見の知らせでしか分からない。
  - 隊の強さは、兵の数と装備に、大将の能力（統率は守り・武勇は攻め・知略は伏兵や見抜き）と技能が掛かる。士気・疲れ・挟み撃ち・退き口（崩れたときの逃げ道）がある。
  - 他の陣への命令は使番が運ぶので遅れる。忠誠の低い隊や調略を受けた隊は、動かない・早く退く・寝返る（関ケ原の小早川のように）。
  - 身分が低いうちは自分の隊だけを動かし、大将になると布陣と命令を出す側に回る。
  - **軍議**（2026-11-18 ユーザー「事前に軍議を開いて、だれがどこに陣取るか、どのタイミングで仕掛けるかを決めるのを再現したい」）：合戦の前に大将のもとで軍議を開き、各隊の陣の場所・道筋・仕掛けの合図（狼煙・太鼓・使番）と時刻を決める。武将は能力と気性で意見を言う（逸る者・慎重な者・別の思惑がある者）。身分が低いうちは軍議に出て意見を言い、割り当てを受ける側。
  - **決めたとおりに行かない駆け引き**（同「抜け駆けしたり、ちゃんと配置につかなかったり、相手に先にとられていたり」）：功を焦る武将の抜け駆け、遅れる・道に迷う・動かない隊、忠誠の低い隊の日和見と寝返り、相手が先に取っていた陣、合図が届かない・遅れる。相手も軍議を開いて動いているので、物見と調略で相手の段取りを読むのが勝負になる。
  - **見えない敵**（同「相手の具体的な位置がわからない感じ、諜報次第で位置が視界に出たり視野が広がったり」）：敵の位置は、自分や味方の隊が見える範囲に入ったときだけ地図に出る。見える範囲は地形で変わる（丘の上は広く、森の中は狭い）。見えなくなった敵は「最後に見た場所と時刻」の印として残り、時間とともに薄れる。物見・忍びを出すと、その者が見て持ち帰った（または狼煙で知らせた）位置が出る。諜報の能力と技能が高いほど、見える範囲が広く、知らせが早く確か。調略された物見は嘘の位置を持ち帰ることもある。
- **代替わり**：プレイヤーの代替わりは後。先に NPC の家で、当主が死ぬと後継ぎが継ぎ、忠誠しだいで支城の城主が謀叛する、を試作で作る。

## 次の試作で足すもの（案、上の答えで変える）
1. 出来事の場所を地図に印で出す（話し合い・杭打ち・賊）
2. 話す内容を増やす（相手の知っていること・仲で変わる）
3. 務めと事件の種類を増やす（数日で一巡しないように）

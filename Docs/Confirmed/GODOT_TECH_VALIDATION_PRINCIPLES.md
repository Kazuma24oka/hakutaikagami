# Godot技術検証7項目：承認済み検証方針

**決定日：2026-10-18。** ユーザーが技術検証7項目の推奨B案すべてを承認した。これは**検証方針の決定**であり、実機検証の合格・Godot正式採用・本格製造開始を意味しない。実装方式・合格数値・例外は[Proposals](../Proposals/GODOT_TECH_VALIDATION_7_OPTIONS.md)で管理する。

1. **HD-2D表現**：2D武将＋3D風背景・照明を小規模検証。例：城下の背景に武将を重ねて視認性を確認。
2. **武将パーツ**：共通素体＋顔・髪・兜・衣装をID・基準点で合成。例：同じ素体から武将3人を生成。
3. **アニメーション**：共通モーションと表情差分を組合せる。例：待機・頷き・驚きを共通化。
4. **会話・謀略**：汎用会話画面に2人の武将・背景・選択肢・NPC返答を接続。例：内応勧誘→承諾／拒否→報告。
5. **世界時間・配送**：共通時刻に沿った進行・停止・命令到達・NPC処理を検証。例：書状発送→翌日到達→NPC判断。自動進行＋任意停止の正式仕様は未決定。
6. **C#ゲームロジック**：表示から独立したC#ドメイン層で権限・資源・イベントを試験。例：徴税100に対して60納入し二重適用を防ぐ。
7. **セーブ・テスト**：版付き保存＋未処理・適用済み・乱数を復元し自動／画面試験。例：ロード後も在庫と徴税結果が一致。

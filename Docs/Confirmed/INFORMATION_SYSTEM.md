# 情報・書状・通知・代理権限 統合設計（確定方針）

> **状態：Confirmed / 基本設計方針を確定（2026-10-17）。** この文書の基本ルールとユーザーが選択した方向性を確定。詳細な数値・実装方法・明記された未決定事項は未確定のままとし、Proposalsで管理する。

## 1. 全体原則
- 時間は自動進行＋任意停止を優先検討。全国の出来事は主人公に即時公開しない。
- 事件の真実（EventTruth）、情報として伝えられる報告（Report）、物理的な書状（Letter）、配送・目撃（Transmission/Observation）、組織の情報保管、アクセス権（AccessPolicy）、個人の認識（KnowledgeRecord）、通知・停止（Notification）を分離。
- 勢力／家臣団／個人の3階層。組織が情報を保有しても全構成員が知るとは限らず、閲覧権限のみでは認識しない。
- 使者・書状・噂・密偵・目撃による伝達遅延と誤報を認める。書状は使者などで運ばれる媒体であり独立した移動方法ではない。
- 一度個人が実際に知った情報は離反後も保持。旧組織の新規機密情報へのアクセスは失効し、物理資料の所持と記憶を混同しない。

## 2. 認識と受領の時点
| 事象 | 案 |
|---|---|
| 本人が目撃・報告受領・資料閲覧 | 観測／受領した内容だけを個人の認識へ登録 |
| 組織が保有／本人に閲覧権限があるだけ | 本人は未認識 |
| 通常書状を本人が適法に受領 | 操作省略として内容を自動認識 |
| 重要書状が本人へ到達 | 未開封のまま受信箱へ。開封時に本文を認識 |
| 正式代理人が受領 | 案件の到達条件を満たし得るが、本人は未認識 |
| 代理人が開封 | 代理人だけが本文を認識。本人への報告が別途必要 |
| 盗難・偽書 | 所持や配達だけで認識させず、閲覧・受領等を要する。真実を書き換えない |

通常書状の「自動認識」は本人への正当な内容受領を簡略化したもの。代理人が受領しただけでは本人へ自動転記しない。重要書状は自動停止しても未開封本文を認識しない。

## 3. 通知・自動停止
- S：自動停止、A：条件付き停止、B：通知、C：履歴のみ、を優先検討。
- **二段階評価**：事件発生時には内部的な基礎重要度を設定。主人公が情報を認識した時点で関係性・所在地・緊急性などを踏まえて通知／停止重要度を再評価する。
- 例外：直接遭遇した危険は即時停止候補。未開封の重要書状は、本人が知り得る差出人・外形・期限・信用度などから**到達時**に停止候補を判定する（本文は秘匿）。
- 偽書も信用度や状況次第で停止候補。ゲーム内部だけが知る真偽で判定せず、真偽がUIの停止挙動から漏れないようにする。
- 同時刻のイベントは集約し停止を原則1回にする。重複報告・訂正報は内容変化を考慮する。

## 4. 書状の状態と期限
- 状態例：作成→発送→配送中→到達→受領／開封→認識→返答→履行／失効。紛失・盗難・偽造・再送は別分岐。
- 通常書状は自動認識、重要書状は開封確認。重要書状の自動停止は緊急性・期限・内容の要求行動で判断し、未開封時は外形メタデータだけを利用。
- **期限起点**は案件ごとに発送時／到達時／開封時から選択。正式な受領権限のある代理人の受領は到達時起点を満たす案。開封時起点の先延ばし対策として案件自体の失効期限を検討。
- **返答の期限判定基準**は案件ごとに返答発送時／相手への到達時を選択。回答期限と行動実行期限は別。
- 期限切れの結果は案件ごとに設定（命令不履行、交渉決裂、勧誘失効、欠席など）。返答の期限遵守、受領者の認識、契約・合意成立は別の状態。
- **返書紛失**：発送時基準で期限内発送なら有効性を維持。到達時基準で未到達なら未成立。ただし有効な返答でも相手が知らなければ行動に反映されない。
- 紛失が認識された場合に再送を判断。紛失未発覚で自動再送しない。

## 5. 偽書・代理権限・責任
- 偽造・看破・流言は武将の能力・人脈・情報源・状況に依存する案。偽書はReportとして表現しEventTruthは変更しない。盗難書状は閲覧した者の諜報・情報漏洩源になり得る。
- 役職の基本権限に個別の委任・取消を重ね、受領／開封／回答を別権限とする案。
- **再委任**は正当な権限者が許可した場合のみ可能。元の有効権限の範囲を超えない。
- 越権回答・偽装権限は原則無効。ただし相手が正当だと信じて行動した場合は紛争が生じ得る。
- 権限者による事後追認を認める案。**遡及可否は案件別**。遡及しても期限違反や第三者損害が自動的に解消するわけではない。
- 報告義務違反の責任は委任範囲・代理人の故意／過失・実害・身分関係・本人の監督責任で評価する。正当な代理受領の到達効力は報告漏れだけで消えない。
- 回答の効力、本人の認識、相手の認識、処罰・信用への影響を別々に評価する。

## 7. 整合性の解消と保留
1. **発生時／認識時の重要度**：内部基礎重要度は発生時、主人公向け停止／通知は認識時（未開封緊急書状は到達時）に評価する二段階案として統一。
2. **到達／認識**：正式代理受領は到達条件を満たしても本人の認識とは別。通常書状の自動認識は本人への受領のみ。
3. **期限／成立／合意**：期限起点、返答の有効基準、契約成立、事後追認の遡及可否を独立属性として整理。
4. **紛失／偽書**：配送状態、報告の真偽、個人の認識、相手の行動を分離。
5. **権限／記憶／責任**：権限失効は記憶削除ではない。越権の効力と処罰は別。

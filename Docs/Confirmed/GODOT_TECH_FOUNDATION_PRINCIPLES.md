# Godot技術基盤：確定基本方針（2026-10-18）

**ユーザー承認：Godot技術基盤7項目はすべて推奨B案を採用・決定。** 対象は技術基盤の基本方針であり、エンジンの実機検証、個別ライブラリ、数値、ファイルスキーマ、製造開始は別の判断とする。

1. **開発言語**：C#中心。Godot固有の画面・演出で必要な場合に限りGDScriptを併用。例：徴税とNPC判断はC#、会話演出でGDScriptを検証。
2. **データ管理**：静的定義・実行時世界状態・画面表示状態を分離しID参照。例：城主交代でも城IDを維持。
3. **セーブ・互換性**：バージョン付き保存を採用し未処理イベント・適用記録・乱数状態を保持。例：ロード後に徴税を二重適用しない。
4. **武将パーツ**：共通素体＋顔・髪・衣装・装飾等のレイヤーをIDと基準点で管理。例：同じ素体に髭と兜を差し替える。
5. **アニメーション・会話**：共通モーション・表情差分・背景演出を組み合わせる。例：密談で表情と照明を変更。
6. **テスト**：ロジック自動テスト＋Godotシーン操作試験＋段階的CI。例：徴税の重複防止を自動検証。
7. **素材管理**：採用素材・定義・ライセンス記録をGitで管理し、生成原本・大容量作業データは別保管。例：採用PNGはGit、学習用原本は別保管。

## エンジン選定の境界
- **Godot 4系を第一候補とする方針を決定**。Unityを第一候補とした過去の未確定比較より新しい選択として扱う。
- **Godotの正式採用は実機技術検証後**。この決定は試作実装の承認ではない。
- HD-2D風の世界＋2Dパーツ合成武将を目指す。描画構成の最終仕様は検証後に確定。

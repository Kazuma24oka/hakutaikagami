# ゲームコンセプト（確定事項）

- 日本語タイトル：**百代鏡**。
- 英語タイトル：**Mirror of Ages**。
- 舞台は日本の戦国時代。可能な限り史実を尊重する。
- 主体は大名家ではなく**武将個人**。浪人としての遍歴・武功・仲間集め、家臣としての勲功・俸禄・知行・出世、城主・国人領主・独立大名としての活動を目指す。
- 全国の城・国人衆まで扱い、大勢力だけが目立つゲームにはしない。
- 全国表示は勢力色分け、拡大時は旧国・城・領地・国人衆などを詳細表示する多段階マップを目指す。
- 時間進行はゆったりとし、短期間で容易に統一できない複雑な政治・社会関係を重視する。
- 史実・準史実・仮想のモードを構想し、史実に近い再現度を調整可能とする。

※具体的なシステム構造・数値・実装範囲は未確定。詳細はProposalsを参照。

# 戦国下天禄 ver1.8b 解析と百代鏡の不足機能

2026-10-29 / 参考資料（百代鏡の確定仕様ではない）

ローカルにインストールされた戦国下天禄（no0作、2009〜2010年、VC++ / DXライブラリ）を解析した。
読んだのは同梱マニュアル45ページ、更新履歴、data/・mdata/・sdata/ のバイナリ構造。
目的は仕組みを参考にすることだけ。数値・人物データ・画像は流用しない（同梱readmeでデータの無断使用が禁止されている）。

### 設計上の教訓
- 人物を**固定枠の配列＋添字（ID）参照**で持つため、父・母・伴侶・上司も整数の添字になっている。並べ替えや削除に弱い。
- 能力の「初期値の控え」を同じレコードに複製している → 百代鏡の「定義と状態の分離」（CharacterDefinition）の方が筋がよい。
- 友好度は**疎な有向辺**（観測者・対象・値・根拠）で持てば十分。百代鏡の WorkTrustFact の形が近い。

## 2. 百代鏡の現状との突き合わせ

百代鏡のCoreを調べた結果（2026-10-29時点、`prototype/godot-foundation`）:

- `Core/Characters/Character.cs` が持つのは **Id・所属・役職・城の4つだけ**。
- 能力は `NewGameSetup.OfficerAttributes`（統率・武勇・知略・政務）として**作成武将の登録時にだけ**存在し、ゲーム中の判断や成長には使われていない。
- Core と Game/Scripts をコード検索した結果、次の概念が**一つも見つからなかった**:
  - 特技 / 性格 / 忠誠値 / 友好度 / 親子・伴侶 / 寿命・没年 / 物品 / 昇進・階級
  - 婚姻 / 養子 / 人質 / 捕虜 / 個人戦 / 計略 / 天候 / 攻城
- 進捗表（`Development/ProgressV1/progress.json`）の該当行もこれと一致する。
  - BD-13（能力・成長）、BD-06・07（負傷・死亡）、BD-45（家督）、BD-46（独立）は **foundation**（データ・関連基盤のみ）
  - BD-43（婚姻）、BD-44（人質）、BD-47（開城）、BD-51（寺社）、BD-53〜56（中央政治）は **design_only**（設計のみ）
  - BD-32（功績・処分・昇進）は **isolated**（独立試作のみ）

一方で、書状の配送・不達・再送・取消、兵糧台帳、任務の委任と返報は非常に厚く作り込まれている。
つまり百代鏡は**「情報と物流の器」はできているが、その器を流れる「人物の中身」と「人生の出来事」がまだ薄い**。
下天禄はちょうどその逆で、器は単純（月ターン・全知・瞬時）だが、中身の種類が豊富。

## 3. 補うべき機能（優先順）

各項目に「下天禄の作り」「百代鏡に合わせて変える点」を付けた。百代鏡の原則（I01〜I10、BD境界）に反する部分は採らない。

### A. 人生ループの土台（最優先：これがないと他が積めない）

#### A1. 人物の能力・特技・適性（BD-13）
- **下天禄**: 4能力（7〜150）＋武芸＋兵科適性5種（0〜15）＋特技のIDリスト（最大22個）＋戦術リスト。特技は「効果パラメータ表」と「説明文表」をデータ化している。
- **百代鏡で**: 設計にある5能力（統率・武勇・知略・政務・交渉）に加えて、次の2つを足すと戦闘と人物の個性が出る。
  - **兵科適性**
  - **個人武芸**（一騎打ち・護衛・負傷のしやすさに使う）
- 特技は「ID＋効果の種類＋係数」のデータ表にして、コマンドからは効果の種類で引く。BD-13の「熟練は行為ごと」とは別枠の「固有の才」として扱う。
- 定義（初期値）と状態（現在値）を分ける。

#### A2. 生年・没年・死亡・出生・成人（BD-07・BD-45）
- **下天禄**: 生年・没年を持ち、没年に達すると確率で死亡する（ルール設定で「寿命死なし」も選べる）。子はランダムに生まれる（男女・なしを設定可能）。成人すると、親が死亡済みなら血縁者の元へ移る。嫡子・嫡孫は裏切りにくい。
- **百代鏡で**: 1560〜1650年の世代交代が主題なので**最重要**。
  - 必要なもの: 没年は「目安」とし、加齢・病気・負傷で死亡確率を変える。親子・伴侶の関係を持つ。架空の子を生成する。
  - 必要なもの: 主人公の死亡時に「認識できる後継」へ操作を引き継ぐ。

#### A3. 勲功・論功行賞・昇進（BD-32）
- **下天禄**:
  - 仕事ごとに勲功が貯まり、**未消化のまま放置すると不満が募り忠誠が下がる**。不満になるまでの量は性格で決まる。
  - 褒美の好みも性格で変わる（物欲型は金・物品、名誉型は感状・昇格）。
  - 階級が率いる兵数の上限を決め、知行がその兵を養えないと昇格できない。総功が城主任命の目安になる。
  - 陪臣の勲功は半分が上司に入る。
- **百代鏡で**: 既にある「任務 → 返報 → 評価通知（AssessmentNotice）→ 報酬（WorkPayment）」の流れの先に「勲功の台帳」を足すだけで、出世という縦の目標が生まれる。
  - 不満は忠誠一点にせず、対象別の感情（BD-14）へ流す。

#### A4. 人物間の関係（BD-15）
- **下天禄**: 友好度の全組み合わせ行列（既定値50）、訪問で門前払いされる、紹介状、茶会（最大5人、招待客同士の友好も上がる）、贈物、師事・教育。
- **百代鏡で**: 行列ではなく**疎な有向関係**（好意・敬意・恐れ・敵意の4軸、根拠と時刻付き）で持つ。WorkTrustFact を一般化する形が自然。
  - 「紹介状で会える相手が増える」は百代鏡の書状システムとよく噛み合う。

### B. 設計書にまだ無い要素（基本設計書で出現数0）

#### B1. 名声・悪名
- **下天禄**: 個人と大名家の両方に名声があり、悪名は徴収・略奪・計略で上がる。登用・外交・勧告の成否と、与姓・与字の効き目に影響する。
- **百代鏡で**: BD-26（信用・鮮度）の上に「**評判は伝聞として広がる**」形で載せる。全国一律に即時更新しないのが百代鏡らしい。

#### B2. 物品・名物・茶器
- **下天禄**: 101種。名刀は武芸、名馬は移動消費半減、兵法書は能力補正と戦術付与。価値1〜10。論功行賞・贈物・茶会の燃料になる。店の品揃えは城の商業値・特性・貿易港で変わり、半年ごとに入れ替わる。
- **百代鏡で**: 既存の所有・保管・運搬の台帳（I04）にそのまま乗る。名物の贈与は外交・忠誠の強い手段になる。

#### B3. 浪人の生活コンテンツ（個人戦・酒場・道場）
- **下天禄**:
  - 酒場の仕事5種（退治・探物・護衛・物資・宅配）
  - 道場（武芸師事・代稽古）、手合わせ、用心棒（8ヶ月で去る）
  - 最大4人の個人戦（攻撃・秘技・防御・物品、気力が毎ターン+10）
- **百代鏡で**: 「浪人としての遍歴・武功・仲間集め」はコンセプトに明記されているのに、設計書に対応する仕組みが無い。
  - 既存の「仕事」の枠組み（TransportWork・LocalWorkDemand）に**宅配・物資・護衛**はほぼそのまま入る。
  - **退治**だけは個人戦の仕組みが新たに要る。

#### B4. 計略・調略
- **下天禄**: 流言（対象と上司の友好↓）、煽動（一揆）、放火（内政↓）、破壊（城防御↓）、強奪、暗殺、離反（謀反を唆す）、偵察。成功率は実行城と対象城の警備・諜報に左右され、偵察していない城が相手だと大きく下がる。
- **百代鏡で**: BD-25・26（情報取得・虚偽・流言）と BD-46（離反）の具体的な遊び方になる。特に**流言**は、「真実・報告・認識の分離」（I03）を最も活かせる題材。

#### B5. 合戦の味付け
- **下天禄**: 陣形13種（前後列と攻・防・速補正）、天候（雨雪で鉄砲不可）、負傷兵（本陣・城で回復）、包囲（3隊隣接で防御低下、城の4方を囲むと毎日士気低下）、現在士気と最大士気の二層、何もしないと軍略回復、略奪。
- **百代鏡で**: BD-37〜40 の「一般の野戦・兵種」の残件に対応する。
  - 負傷兵と包囲は連続世界でもそのまま意味を持つ。
  - 陣形は作戦線（BD-38）の隊形として翻訳できる。

#### B6. 与姓・偏諱（与字）
- **下天禄**: 総功5000以上で、自分の姓や名の一字を与えて改名させる。名声が高いほど効き、与えすぎると効果が薄れる。
- **百代鏡で**: 史実色が強く安価な恩賞の手段。人物定義と表示名を分けておけば実装は軽い。

#### B7. ルール設定（「範囲」系のつまみ）
- **下天禄**: 計略・登用・援軍・移動・外交の範囲を「近隣のみ ⇔ 全域」で切り替えられる。戦死率・捕縛率・出生・女性の扱い・歴史事件・架空人物もつまみになっている。
- **百代鏡で**: BD-02 の「史実尊重・準史実・仮想」の下に、**個別のつまみ**として置くと調整がしやすい。

### C. 下天禄の簡易版が参考になる design_only 項目
- **婚姻・養子（BD-43）**: 縁組（血縁の女性と配下）・養子（0〜16歳）・婚姻願い・養子願い（上司の子、発言力を消費）。**跡継ぎ予定の者は選べない**。
- **人質・捕虜（BD-44）**: 戦後の捕縛率、捕虜の登用率。合戦の攻撃側も敗北時に確率で捕虜になる。
- **開城・攻城（BD-47）**: 城の防御値が0で落城、60日守り切れば防御側の勝利。籠城中は治安・民衆が日ごとに下がる。
- **寺社・朝廷（BD-51・53〜56）**: 「諸勢力」として一括りにし、贈物で**貢献**を貯めて依頼に使う（調停・宣伝・貿易・攻撃・物資・調略・悪評）。規模は贈金で上がる。朝廷だけは全国どこからでも交渉できる。
  - 百代鏡の第一段として「貢献台帳＋依頼メニュー」から入るのが現実的。
- **独立（BD-46）**: 軍団長・城主の独立コマンドと、計略の「離反」。

### D. 採らない方がよい点
- 月ターン制と、手番を身分順に処理する方式（百代鏡の連続時間と矛盾する）。
- 全知の数値表示（他者の能力・忠誠がそのまま見える。BD-16 と矛盾する）。
- 忠誠一本で裏切りを判定すること（BD-14 と矛盾する）。
- 固定枠の配列と密な行列（上記の教訓）。
- 身分×コマンドごとの個別分岐。更新履歴の大半が権限まわりのバグ修正だった。
  - 百代鏡の権限レイヤー（MilitaryAuthority 等）を一般化して一か所で判定する方針が正しい。

## 4. 次の一手の提案

最小で効果が大きいのは **A1 → A3 → A2** の順。

1. `CharacterDefinition` に「能力・適性・武芸・特技ID・生年・目安没年・親子」を持たせる（定義）。
   `Character` には「現在値・経験・勲功・健康」を持たせる（状態）。
2. 既存の評価通知・報酬の流れに勲功台帳をつなぎ、論功行賞と昇進を1つ通す。
3. 年の切り替わりで加齢・死亡判定・成人・出生を行い、主人公が死亡したら後継へ操作を移す。

ここまでできると、既存の書状・任務・物流の作り込みが「誰が、なぜ動くか」という中身を得て、ゲームとして回り始める。

### 5.3 録画から分かった、マニュアルに書かれていない点

1. **序盤のゲームの中心は酒場の仕事と個人戦**
   - 最初の約13分は、ほぼ「仕事を受ける → 個人戦 → 報酬」の繰り返しだった。
   - 仕事は「仕事・目標・報酬・必要行動」の一覧から選ぶ。報酬は護衛264、探物12960など、桁が大きく違う。
   - 個人戦は**3人対2〜4人**の小規模戦。一覧には体力・気力・武芸が並ぶ。秘技ごとに気力消費（30〜50）と短い説明文がある。
   - 能力150の一族が武芸65の山賊を一撃で倒しており、作成武将のせいで戦いが**作業化**している。

2. **一族＝自分の部隊**
   - 主人公の家族5人が、そのまま1つの部隊（小隊5つ）になって合戦に出る。
   - 配下一覧は兵・錬度・金・兵糧・馬・鉄砲・知行の表。各人が自分の資源を持つ設計が画面に直結している。

3. **身分を行き来する一続きの経歴**
   - 浪人 → 仕官 → 一般として参戦 → 城取りに挑戦 → 再仕官 → 一族に論功行賞 → 発言力を貯めて城主任命願い、を1本の人生で通している。
   - **発言力は所持量と必要量を並べて表示**する（2500（2728））。目標までの距離がひと目で分かる。

4. **合戦の画面構成**
   - 戦場マップ:
     - 地形タイルに番号付きの部隊コマと城を置く。天候（雨のエフェクト）と経過日数を常に表示する。
     - 上下に敵味方の部隊表を出す（体力・軍略・兵科・兵・負傷・士気 現在/最大・疲労・状態・前後列）。
     - 陣形名（龍尾・方円・箕形・鶴翼・魚鱗など）を家名の横に出す。
   - 交戦すると戦闘画面に切り替わる。
     - 小隊ごとに「行動（白兵など）」と「目標」を選び、「決定」か「自動」で進める。
     - 特殊戦術の一覧には、兵科条件・軍略消費・疲労・効果が並ぶ。条件を満たさない戦術は灰色で表示される。
   - 攻城では「城名・防御値・効果125%」を表示し、使う技能（水攻めなど）を選ぶ。
   - 開戦時に「戦闘開始（指示）／（自動）」と「直接采配を取りますか？」を選べ、**手動と自動を切り替えられる**。

5. **見えない情報の扱い**
   - 未偵察の城は数値が「????」と表示される。全知ではない。
   - 人物一覧には「見知り／未知」の区分がある。

6. **UIの細部**
   - 画面下にショートカットの帯がある（訪問A・酒場S・売買D・道場F・茶会Z・移動X・地図拡縮C）。
   - 数値の入力は ±1・±10・±100・±1000・±10000 のボタン式。
   - ターン終了・行動終了には必ず確認ダイアログが出る。

7. **世代交代の兆し**
   - 子が成人すると、自分から出仕を申し出る会話イベントが起きる。録画の最後（1553/9）で発生した。

### 5.4 百代鏡への示唆（第3節への追加）

- **B3（浪人の生活コンテンツ）の優先度を上げる**
  - 実際のプレイでは、序盤の4分の1が仕事と個人戦だった。
  - 百代鏡の既存の「仕事」（点検・運搬・返報）は、ここに相当する遊びの器として既にある。
  - 足りないのは2つ。
    - 仕事の**種類**（護衛・探物・退治・宅配・物資）
    - **報酬の幅**
- **家族・一族を最小の軍事単位にする**
  - 一族が自分の部隊になる構造は、BD-12（随行者と配下）と HouseholdMilitary にそのまま合う。
  - A2（出生・成人）を入れれば、「子が育って自分の隊が強くなる」という世代の手応えが出る。
- **発言力・勲功は「所持 / 必要」の形で常に見せる**
  - 出世の目標が数値で見え、次の行動を決める動機になる。
- **手動 / 自動の切り替えを合戦の単位ごとに用意する**
  - 録画では、手動で戦う合戦とCOMに任せる合戦が混在していた。
  - 百代鏡の委任（BD-30）の考え方を、合戦の入口にも置くとよい。
- **待ち時間の削減**
  - 「COM思考中」や観戦のように何もできない時間は、百代鏡の連続時間方式では「全速度＋重要時の自動停止」（BD-28）で吸収できる。
- **作成武将の能力上限**
  - 能力150の一族で個人戦が作業化していた。
  - BD-05 の「作成人物は開始予算で制約する」は正しい判断で、維持するべき。

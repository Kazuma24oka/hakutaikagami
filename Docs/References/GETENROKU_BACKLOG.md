## 取り込み方針：今のゲーム性を壊さないために

### 守るべき百代鏡の中核
百代鏡の遊びの芯は、[PLAYER_PEACE_WAR_FLOW](../Proposals/PLAYER_PEACE_WAR_FLOW.md) の1行にある。

> 本人が情報を得る → 自分の目的・任務を決める → 本人が行動する／人に任せる → 届いた結果から判断し直す

下天禄の要素はほとんどが「メニューを選ぶ → その場で数値が変わる」形をしている。
これをそのまま入れると、この循環が短絡して百代鏡が「よくある戦国SLG」に寄ってしまう。

### 取り込みの5原則
1. **翻訳して入れる。移植しない**
   - 下天禄の「何が面白いか（動機）」だけを取り、「どう処理するか（即時のメニュー効果）」は百代鏡の流れで作り直す。
2. **新要素は既存の流れを通す**
   - 結果は「任務・書状・返報・台帳」として届ける。
   - 例: 恩賞は通知として届く。流言は噂や偽書として伝わる。名物は運搬で動く。
3. **数値は本人の認識を通して見せる**
   - 本人の能力は正確に見せる。他人の能力・名声・感情は推定幅と出典で見せる（BD-16）。
4. **成否は相手の判断で決める。乱数一発にしない**
   - 登用・婚姻・勧告・恩賞の受け取り方は、相手のNPCが「知識・性格・利害・関係」から判断する（BD-58）。
   - 能力は確率ではなく、判断材料と実行の質に効かせる。
5. **段階導入し、旧保存を壊さない**
   - これまでの「版固定」と同じく、新しい要素は新規ゲームの版から有効にする。旧保存に後付けしない。
   - 1件ずつ入れて、既存の受入試験が通ることを確かめてから次へ進む。

**△ 慎重に（別のゲームが混ざる危険がある）**

| ID | 危険 | 推奨 |
|---|---|---|
| G-B2 個人戦 | RPG風のターン制戦闘は、連続時間・3D・史実寄りの雰囲気から浮きやすい。録画でも作業化していた | 独立したミニゲームにはしない。「護衛中の襲撃」「手合わせ」など**場面の中の出来事**として短く扱う。本人の判断は「戦う・逃げる・交渉する」程度に絞り、武芸と装備で結果を出す |
| G-B9 ルール設定のつまみ | 数を増やすほど史実モードの意味が薄れ、試験の組み合わせも爆発する | 3つのモード（史実尊重・準史実・仮想）の中身として内部で使い、プレイヤーに出すのは数個に絞る |
| G-U6 待ち時間削減 | — | 既に PW07（自動進行＋停止）で解決済み。追加作業は不要 |

### 進め方の目安
1. まず ◎ の G-A2（勲功）か G-A3（家督）から1件だけ入れる。どちらも既存の通知・書状の上に乗るので、今の遊びを変えずに「出世」「世代」という長期の目的が加わる。
2. 入れたら、通常入口で今までどおり遊べることと、旧保存の再開を確認する。
3. ○ は1件ずつ、上の「入れ方」を詳細設計に書いてから着手する。
4. △ は、◎と○が揃って「足りない」と感じた時点で改めて判断する。

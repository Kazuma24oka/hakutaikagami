# 地域間取引・現物移送の最小一巡（2026-10-27）

基準はapproval-baseline-v2.json。前回承認時の約21.3%を固定し、評価補正/重み変更で加算しない。

対象は3地域の現地商人と米。価格・初期在庫・銭は調整用の仮定値。価格は現地の在庫/需要から見積時に固定し、受渡しまで保証する範囲と期限を示す。売買用の米/銭、本人の携行米、主家の米を別に扱う。

本人が現地で購入見積→引当→支払と米の受取→既存経路を移動→現地で売却条件確認→米の納入→代金債務→精算。売却納入前は私物のまま。主家への供給は支配/処分権のある本人が現地で明示実行し、私有米を家の蔵へ移す。相手の未来価格/遠隔地の残高は表示しない。

予約期間中の他用途支出で購入引当を食いつぶさない。未受取なら取消/期限で予約解放。受取後の取消で現物を消さず、元の地域へ持ち帰って現地の買戻し価格で相談する。途中で期日を過ぎても荷と既成債務を削除しない。

5完成条件は基準JSONと同一。全国商品市場、物価の史実再現、商人専業の人生、債務保証人/担保、緊急転用と補償、全物資の同時按分は後続。技術確認と外観確認を区別し、Computer Useは使わない。

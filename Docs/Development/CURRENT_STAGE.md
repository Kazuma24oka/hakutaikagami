# 現在段階：同じ世界で本隊を配置して帰還

## 完成条件（実装前固定）

1. 戦闘の指揮官を固定人物IDではなく部隊定義から取得し、UnitStateとの一致を検査する。以前の初期世界/保存JSONの実物も読める。
2. 作成家臣の別開始条件として、主家所属の試作兵100の配置任務を明示する。所属/主従だけでは軍権にせず、部隊/行為/期限を持つ指揮許可で検査。新たな交戦命令や協力隊の指揮は許可しない。
3. 同一セッション/世界時刻で点検/返報→清洲で出陣→本隊の線への移動→帰還→在所の仕事が成立する。単身で遠方へ行っても清洲の部隊を瞬間移動させない。
4. 発送時の所在を保存し、同時刻に出陣しても発送済みの政治書状の出発点を変えない。野外の通常書状は地形に沿う街道への第一行程を保存し、到達まで相手の認識を更新しない。
5. 途中保存/別プロセス復旧の位置と3Dを厳密比較し、全テスト/既存96比較を再検査してcommit/pushする。

## 次の五段階

1. 本隊配置と帰還（今回）。
2. 交戦任務と損耗・報告を接続。
3. 兵と物資の引当/消耗/返還。
4. 他武将への明示委任と逸脱評価。
5. 継続的な仕官/解任と人生継続。

## 競合検査による条件4の見直し

未認識の任務が行動を拘束すると、未着内容を可否から漏らす。新世界では自己依頼/認識後の活動だけが拘束し、在所の点検は野外では待機して帰還後に履行する。野外返報を拒否する当初の条件4ではこの競合を閉じられないため、通常書状の地形に沿う街道への第一行程を実装し、物理時間/保存/履行との競合を検査する。全履歴複製や受入条件の緩和ではなく、同一世界の依存処理の補完。

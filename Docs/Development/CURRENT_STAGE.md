[60判断の現状](../Design/ImplementationAuditV1/README.md)。部分基盤の参照と全製品受入を区別する。

## 完成条件（実装前固定）

1. 1560年/三歴史設定/成人/史実と作成を、既存世界を変更しない開始設定として定義。
2. 六立場の名称から権限を生成せず、所属・主君・役職・権利/資産・明示指揮の整合を個別検査。
3. 作成予算/ID衝突/参照欠落/主従循環/期限/未成年/不正値を拒否し、入力不変を検査。
4. 厳密保存復旧とSeed一致、全テスト。旧世界/保存/通常入口は変更しない。

## 次の五段階

2. 検査済み設定を使う開始選択画面。
3. 個人の開始設定と移動・仕事・保存を結合。
4. 同一世界の平時→出陣→帰還。
5. 資源消費と補給から身分変化へ接続。

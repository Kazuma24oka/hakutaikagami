# 現在段階：返報側の既知不達後の原本再送

## 完成条件（実装前固定）

1. 本人が物理照会で原返報の再送も依頼した場合だけ、相手が自分の不達報告を受領済みの受令返書/到達報告を同ID/本文/報告時刻のまま最大3便で再送する。照会だけでは従来挙動を変えない。
2. 相手が実際に受領した本人の書状のうち最新の発送時点で知らされた返書先を使う。古い書状の遅着で新しい宛先へ戻らず、真の現在地で追尾しない。
3. 未認識の不達・失敗報告自体の不達・上限・重複・旧照会JSONの互換と、途中保存/別プロセス復旧/続行を検査する。
4. ゲーム画面で照会/原返報の再送依頼/正式な原本受領を区別し、必要なら通知済み営地への照会へ切り替える。全体検証後に同じブランチへcommit/pushする。

## 次の五段階

1. 既知不達後の原返報再送と既知返書先（今回）。
2. 継続的な仕官/解任と人生継続。
3. 一人分プレイの通し検査と操作整理。
4. 史実開始/全国人物・権限の段階採録。
5. 最小プレイ全体の受入検査と創作判断が必要な箇所の提示。

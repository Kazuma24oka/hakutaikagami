# 現在段階：明示した他家軍の指揮許可と別返報

## 完成条件（実装前固定）

1. 他家演習軍の所有/既存主従を保ち、主権者の架空の開始合意による一時指揮許可を別開始に定義する。対象軍/武将/部隊/Move・Hold・Retreat/期間/根拠を限定し、他隊交戦・私有化・再委任は許可しない。
2. 軍議で通知された営地または本人が知る位置へ伝令を送る。私的服従意思を送信可否から漏らさず、受令時に期限・権限・拒否を判断する。同じIDは再実行しない。
3. 受令判断の返報と、実際に配置/帰還した後の自隊到達報告を別の物理配送にする。本人が知った報告だけ表示し、敵の真情報は含めず責任・処分を自動確定しない。
4. 差替えは既知の直前の計画IDへ連結し、親の不達・後続到達・旧原本の物理遅着でも古い計画へ戻さない。途中保存/別プロセス復旧/続行で任務・部隊・報告・3Dが一致する。
5. 全テスト/既存156保存比較+3素材寿命比較と新規ケースを実行し、同じブランチにcommit/pushする。

## 次の五段階

1. 明示指揮許可・受令判断・到達の別返報（今回）。
2. 返報不達の照会/再送と行動中断理由の申告。
3. 継続的な仕官/解任と人生継続。
4. 最小の一人分プレイの通し検査と操作整理。
5. 史実開始条件と全国の初期人物・権限データの段階採録。

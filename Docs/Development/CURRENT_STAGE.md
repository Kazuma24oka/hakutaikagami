# 現在段階：本人の所在と野外世界の進行を分ける

## 委任の前に必要な依存処理

現在の試作ではRegion.Activeが本人の野外状態と全軍の進行を兼ねている。他隊へ任務を出して本人が帰還すると、他隊やその伝令まで止まるため、BD-12/17と共通世界時計を満たせない。新たな継続世界の開始を追加して分離し、旧開始/保存の挙動は保持する。

## 完成条件（実装前固定）

1. 本人の在所/野外と野外の部隊シミュレーションを別に保存し、所属や兵の所有は変えない。
2. 本人が在所で点検・街道移動していても、演習中の別働隊が同じ時計で進み、本人の帰還で瞬間移動・停止しない。
3. 本人の位置・移動可否・書状の発送元・3D表示は実所在を使う。未知の他隊任務や隠れた真の位置を可否/表示から漏らさない。
4. 兵糧は本人の出陣区間だけで消費し、入城後は他隊の活動だけを根拠に消費しない。在所点検も成立する。
5. 保存/別プロセス復旧/続行の位置・野外進行・兵糧・表示、旧開始・全テストを検査し、同じブランチにcommit/pushする。

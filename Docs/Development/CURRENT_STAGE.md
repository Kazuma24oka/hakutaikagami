# 現在段階：新規ゲームから同一人物の生活・保存再開まで

ユーザーが五工程を一括承認。技術判断で途中停止せず、実動作を確認して同じprototype/godot-foundationへcommit/push。通常起動への採用判断は最後に残す。旧入口/保存/保護ブランチ/素材は維持。

## 完成条件（実装前固定）
1. 武将管理で独立グループ、直属関係、既存3D外見、収録拠点を編集し、改名/インポート/書出しを実画面の処理で検査。
2. 開始条件→登録選択→領土/旧大名処遇の調整→競合解消→世界確定を接続。確認後の変更を検出し、未確定状態をゲームへ渡さない。
3. 全国/地域の地図上の拠点と人物一覧を連動。実在/登録の両方を一人として選択し、未成年等の不可理由を示す。
4. 確定した同じ人物/所属/主従/外見/場所を既存WorldSessionへ変換。実際に移動・現地点検・書状を扱い、世代保存と別プロセス復旧/続行後の状態・3D表示が一致。
5. 旧起動/旧保存を回帰検証し、実画面と短い操作動画を点検。同ブランチへcommit/pushし、操作できる候補入口を提示。通常起動の変更は未実施とする。

初回1560年・準史実。人物台帳の部分収録と開始前の試作配置を史実領土の確定と混同しない。未採録の全国人物/軍制/政治AIを完成扱いにしない。開始前の投影からプレイ後の個人の知識へ全世界情報をコピーしない。既存の旧軍務/戦闘試作は旧入口に保持。

## この後の五工程
1. 新規ゲーム候補の操作感をユーザーが確認し、通常起動への採用判断。
2. 開始人物と既存の仕官・任務・軍務の一般化を統合。
3. 個人と部隊を分けた交戦・撤退と負傷/捕縛。
4. 全国人物・役職・領土の史料採録と追加データ検査。
5. 製品範囲の通し受入と負荷・外観改善。

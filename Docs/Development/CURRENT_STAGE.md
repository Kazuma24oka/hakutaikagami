# 現在段階：仕官・離職後の同一人生

## 完成条件（実装前固定）

1. 同じ成人作成人物/世界/Seed/時計のまま、浪人の申し出→相手の条件提示→本人回答→相手の受領と効力→封書通知→本人認識を接続する。所属と直属を別の期間付き関係とし、軍/役職/土地/私有物資を自動取得しない。
2. 辞去合意と、明示した検証条件による担当解除を履歴として記録し、通知前は本人へ終了の真実を漏らさない。失職しても同じ人物/記憶/任務/物資/位置で移動・任意の仕事を続ける。懲罰的な人事AIの完成とは扱わない。
3. 面談/合意/任務の発行時点を保存した順序で扱い、後の身分変更で昔の命令本文を変えない。引継ぎは相手が受領した返報から確認し、未到達の完了を知った扱いにしない。
4. 未開封・不承諾・通知遅延/不達・重複・途中保存/別プロセス復旧/続行と、実際の3D位置・本人向け表示の一致を検査する。旧開始のJSON実物/定義を保持する。
5. 全テストと必要な既存回帰を行い、同じブランチへcommit/pushする。

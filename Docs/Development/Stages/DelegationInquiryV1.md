# 現在段階：委任先への物理照会

## 完成条件（実装前固定）

1. 本人が発送した委任命令について、通知済み営地または自分が指定した配置先へ照会を送る。真の所在地を追尾せず、照会は部隊行動を変更しない。
2. 相手が実際に受け取った後、自身の認識/自隊の行動中・停止・別計画・到達の申告を返す。返答到達前には内容を出さず、責任/処罰は未審査のまま。
3. 到達報告原本が不達でも、照会返答が同じ不変報告を引用して情報回復できる。原本の正式受領を偽造せず、古い報告で新しい目撃を戻さない。
4. 照会/返答自体の不達・二重操作・途中保存/別プロセス復旧/続行を検査し、実際のGodot表示を確認する。
5. 全テスト・既存の保存比較を必要範囲で再検証し、同じブランチへcommit/pushする。

3. 継続的な仕官/解任と人生継続。
4. 一人分プレイの通し検査と操作整理。
5. 史実開始/全国人物・権限の段階採録。

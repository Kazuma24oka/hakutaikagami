# 家の収支と待遇の最小一巡

事前基準はapproval-baseline-v3.json。主家の米と個人の銭/米を分離する。

試作は、現地で直属関係のある主君と家臣が相談し、本人確認で成立する3回の月初給付約束。希望額20〜200kg/月は調整用。NPC家臣は20kg以上、NPC主君は40kg以下を基準に返答する。未来の家の資産は保証せず、約束だけで在庫を消費/引当しない。組織・主従・軍権は変えない。

期日で家に米の給付債務が生じる。現地で支払米を用意すると1日の引当になり、救済/工事へ二重使用できない。両者の現地受渡しで家の米を減らし、家臣の私有米を増やす。未払い・一部払いを保持し、終了しても過去債務を消さない。期限前の終了は現地で当事者が確認し、将来分だけを止める。旧主従の変更だけでは原本の既成給付約束を削除しない。3回後の自動更新はしない。

俸禄への信頼は、その家臣から支給した家への対象別・限定指標。未払い期間と実受領の履歴に基づき、次の約束への返答へ反映する。一般の忠誠/人格や軍令服従へ一律適用せず、遠隔の相手の本心や家の現在在庫を漏らさない。

本人が受領した米は既存の現地市場へ持ち込み売却できる。私有米の減少と商人在庫増加を照合し、同じ米を繰り返し売らない。

5完成条件を検証してから数値評価。全国の俸禄制度、知行配分、一般の遺産・家督承継、人格AI、全物資の配分は後続。Computer Useは使わず、画面外観未確認を明記する。
